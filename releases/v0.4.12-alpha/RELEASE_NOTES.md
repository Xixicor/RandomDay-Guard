# RandomDayGuard v0.4.12-alpha

RandomDayGuard turns available Abiotic Factor dedicated-server records into
readable server, daily, player, case, and Guard-health reports.

## Highlights

- Strictly separated report routes with worked examples.
- Explicit source coverage, expected-empty states, and evidence references.
- Current and retained player history kept distinct.
- Review-only defaults and optional protected Admin.ini enforcement.
- Portable Saved-root discovery with one explicit override file.
- English documentation plus 27 localized entry pages.

Read `INSTALL.md` before replacing an existing installation.
