# Ажилласан үйлдлийн жишээ

> **Каноник англи эх сурвалж:** [EXAMPLE_RUNS.md](../../EXAMPLE_RUNS.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Эдгээр жишээнүүд нь хүлээгдэж буй төлөвийн шилжилтийг тайлбарлахын тулд зохион бүтээсэн утгыг ашигладаг; Эдгээр нь амьд нийцтэй байдал эсвэл тоглогчийн нотолгоо биш юм.

<a id="successful-current-cycle"></a>
## Одоогийн мөчлөг амжилттай

Оруулга: унших боломжтой идэвхтэй бүртгэл, version/boot/epoch, `poll_id=41`, одоогийн санал асуулга дууссан, бичих боломжтой accounting/history/report үндэс, удаан хайлтыг хориглох бодлого байхгүй.

Хүлээгдэж буй:

```text
server_status = full
player_activity = full or limited_expected_empty
case_review = full or limited_expected_empty
daily_rollup = full or limited_expected_empty
critical_guard = full or limited_expected_empty
```

Идэвхжүүлсэн маршрут бүр JSON/TXT гаралт ба `route_proof.json`. Маршрутын статус нь ерөнхий амжилтын мессежээс бус өөрийн субьектуудаас хамаарна.

<a id="expected-empty-player-and-case-routes"></a>
## Хүлээгдэж буй хоосон тоглогч болон хэргийн маршрутууд

Оролт: одоогийн мөчлөгийн баталгаа дууссан; одоогийн болон хадгалагдсан тоглогчийн эгнээ байхгүй; хадгалагдсан тохиолдол байхгүй ба одоогийн байхгүй REVIEW/BAN-ELIGIBLE бүртгэл.

Хүлээгдэж буй:

```text
player_activity.route_proof_status = limited_expected_empty
player_activity.expected_empty = true
player_activity.players = []

case_review.route_proof_status = limited_expected_empty
case_review.expected_empty = true
case_review.cases = []
```

Орчуулсан тайланд эрх бүхий хязгаарлагдмал субьект ажиглагдаагүй гэж хэлсэн. Тэд мөн энэ нь хэн ч хэзээ ч холбогдоогүй эсвэл ямар ч контекст байхгүй гэдгийг нотлохгүй гэж тэд хэлэв. Орлуулагч байхгүй player/case үүсгэгдсэн.

<a id="partial-bounded-scan"></a>
## Хэсэгчилсэн хязгаарлагдмал скан

Оролт: шинэ гүйдэл log/poll; `scan_checkpoint.json` эсвэл `scan_progress.json` байгаа; скан хийгдээгүй; анхдагч `slow_world_scan_blocks_current_reports=false`.

Хүлээгдэж буй:

```text
world_save_scan.status = partial
source accounting = partial
server_status may still be full for fresh current state
historical routes name the scan limitation
```

Тохируулах `slow_world_scan_blocks_current_reports=true` зөвхөн оператор нь одоогийн тайлангуудыг хаах нэмэлт удаан эх сурвалжийг хүссэн үед л. Сэргээх нь шалгах цэгийг устгах биш, сканнерыг үргэлжлүүлэхийг зөвшөөрөх явдал юм.

<a id="missing-current-cycle-proof"></a>
## Одоогийн мөчлөгийн нотолгоо дутуу байна

Оруулга: идэвхтэй бүртгэл боломжгүй, `poll_id=0`, эсвэл boot/epoch/last-poll удам байхгүй.

Хүлээгдэж буй:

```text
current_cycle_proof_complete = false
all route proof statuses = missing
each configured route envelope status = suppressed_current_cycle
delivery_eligible = false
delivery_attempted = false
```

Дарагдсан дугтуй нь дараалалд байгаа хүргэлт биш аудитын бүртгэл юм. Хуучин эцсийн бүртгэл нь зөвхөн түүхэн хэвээр үлддэг. Эхний дутуу lineage/source талбарт оруулаад шинэ мөчлөг үүсгэнэ үү.

<a id="malformed-optional-adminini-source"></a>
## Алдаатай нэмэлт Admin.ini эх сурвалж

Оролт: `Admin.ini` байгаа боловч бүтцийн баталгаажуулалтыг хийж чадахгүй байна.

Хүлээгдэж буй:

```text
admin_ini.status = malformed
source reference preserved
write/enforcement path closed
```

Файлыг хадгалж, шалгасан цэвэр форматыг сэргээнэ үү. Тайлбар бичвэрийг ажиллах үеийн нотолгоонд хадгалах; тус бүр `Admin.ini` оруулахыг хориглох нь зөвхөн `BannedPlayer=<ID>`.

<a id="required-active-log-probe-error"></a>
## Шаардлагатай идэвхтэй бүртгэлийн шалгалтын алдаа

Оролтууд: шаардлагатай хязгаарлагдмал идэвхтэй бүртгэлийн датчик нь ариутгасан унших алдаатай бүтэлгүйтсэн.

Хүлээгдэж буй:

```text
source_accounting.sources[active_log].status = error
source_accounting.sources[active_log].detail = "bounded active-log probe failed: <sanitized reason>"
coverage_status = unavailable
all route proof statuses = missing
```

`error` нь хязгаарлагдмал дэлгэрэнгүй мэдээлэлтэй эх мөрөнд үлдэнэ. Дээд түвшний тайланд `unavailable`, мөн чиглүүлэлтийн баталгаа хэвээр байна `missing` шинэ одоогийн мөчлөг шаардлагатай эх сурвалжийг батлах хүртэл.

<a id="incompatible-or-stale-baseline"></a>
## Тохиромжгүй эсвэл хуучирсан суурь

Оруулга: өөрчлөгдсөн package/source таних тэмдэг эсвэл stale/incompatible суурь манифест.

Хүлээгдэж буй: баталгаажуулалт эсвэл ажиллах үеийн төлөв нь үл нийцэх байдлыг бүртгэдэг; сканнерийн төлөв нь дахин ашиглахыг шаардахгүй. Урьдчилсан нотолгоог хадгалж, тодорхой суурь сэргээн босголтыг эхлүүлж, шинэ терминалын нотолгоог хүлээнэ үү. Бүртгэгдсэн шалтгаангүйгээр албадан сэргээлт нь өгөгдмөл сэргээлт биш юм.

<a id="paired-report-write-failure"></a>
## Хосолсон тайлан бичих алдаа

Оролт: JSON амжилттай бичих боловч TXT бичих амжилтгүй эсвэл эсрэгээр.

Хүлээгдэж буй:

```text
route_proof_status = missing
completed = false
coverage_status = unavailable
output_write_detail = "paired JSON/TXT write failed: <sanitized reason>"
next_action = repair both route output writes
```

Зохиолч нь бүтэлгүйтлийн үед нэгдэхийн тулд ах дүү хоёрыг дахин бичдэг. Амжилтанд хүрсэн нэг ах эгч амжилтанд хүрсэн гэж үлдэж чадахгүй. Хязгаарлагдмал бичих мэдээлэл нь тав дахь дээд түвшний хамрах хүрээний утгыг үүсгэдэггүй.

<a id="route-proof-write-failure"></a>
## Маршрут хамгаалалттай бичих алдаа

Оролтууд: чиглүүлэлтийн хосууд бичигдсэн боловч `route_proof.json` орлуулах боломжгүй.

Хүлээгдэж буй: бүх тайланг дахин бичсэн `missing`, бүх мэдэгдлийн үр дүн `route_proof_write_failed`, ямар ч дугтуйг хүлээн авахгүй. Тохируулсан маршрут нь `suppressed_current_cycle` хүргэлтийн туг бүхий аудитын дугтуй худал. Гаралтын үндсийг засаж, ижил гүйдлийн циклийг сэргээнэ үү.

<a id="review-only-enforcement-example"></a>
## Зөвхөн хянан үзэх боломжтой хэрэгжүүлэх жишээ

Тохиргоо:

```lua
review_only_mode = true
auto_ban = false
write_admin_ini = false
```

Хүлээгдэж буй: оноо, тохиолдол, зөвлөмжийг бичиж болно; `Admin.ini` өөрчлөгдөөгүй хэвээр байна. Энэ бол нийтийн өгөгдмөл.

<a id="approved-write-success-example"></a>
## Зөвшөөрөгдсөн бичих амжилтын жишээ

Зөвхөн тусад нь зөвшөөрөгдсөн тест нь бүх гурван бичих шилжүүлэгчийг тохируулж болно. Энэ нь мөн цэвэр тоон таниулбарыг батлах ёстой, trust/moderator хасалт, босго шалгуур, хүчинтэй Admin.ini path/parse, нөөцлөлт амжилт, амжилттай бичих, дахин унших тэгш байдал, бүртгэлд хамаарах нотлох баримт.

Хүлээгдэж буй:

```text
runtime/backups/Admin_<timestamp>_<source-fingerprint>_<clean-ID>.ini
Admin.ini contains one clean BannedPlayer=<ID>
runtime/enforced_bans.jsonl and evidence mirror record success
```

Амжилттай жишээ нь бусад акаунтын автомат хэрэгжилтийг идэвхжүүлээгүй.

<a id="writereadback-failure-with-rollback"></a>
## Write/readback буцаах үед алдаа гарсан

Оролтууд: урьдчилан бичих хаалга бүрийг дамжуулсан; солих бичих эсвэл дахин унших боломжгүй; `rollback_on_readback_failure=true` ба баталгаажуулсан нөөцлөлт бэлэн байна.

Хүлээгдэж буй: бүтэлгүйтлийн нотлох баримт нь үе шатыг бүртгэж, `rollback_success`; эх Admin.ini байт сэргээгдсэн бөгөөд бүртгэл амжилттай хэрэгжсэн гэж мэдэгдээгүй. Хэрэв буцаах үйлдэл амжилтгүй болбол бичихээ зогсоож, хоёуланг нь хадгал files/evidence ба нөөцлөлтөөс гараар сэргээнэ үү.

<a id="local-outbox-example"></a>
## Орон нутгийн гадагш илгээх хайрцагны жишээ

Оруулга: `local_file_outbox` горим, чиглүүлэлт идэвхжсэн, дууссан маршрутын баталгаа, аль нэг нь `full` эсвэл тодорхой зөвшөөрөгдсөн хүлээгдэж буй хоосон.

Хүлээгдэж буй дугтуй:

```text
schema = randomdayguard.notification/v1
completed_output = true
status = ready_for_local_consumer
delivery_eligible = true
delivery_backend = none
delivery_attempted = false
```

missing/ineligible гаралт, ижил зам нь оронд нь `status=suppressed_current_cycle`, `completed_output=false` болон `delivery_eligible=false`. Аль ч файл нь зөвхөн локал бичвэрийг баталгаажуулдаг. Ямар ч үйлчилгээ үзүүлэгч, тээвэрлэлт, хүргэлт, уншсан баримтыг багцалсан эсвэл таамаглаагүй.
