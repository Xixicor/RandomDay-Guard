# Илрүүлэх дохио

> **Каноник англи эх сурвалж:** [DETECTION_SIGNALS.md](../../DETECTION_SIGNALS.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Дохио нь автомат буруутгах биш, шалгах оролт юм.

<a id="signal-table"></a>
## Дохионы хүснэгт

| Дохио | Утга | Хэрэв... | Өөрөө хангалттай биш |
|---|---|---|---|
| Нэвтрэх таниулбар | Газрын зургийн нэрийг бүртгэлийн ID руу оруулна. | ConnectID байгаа | Хориглох |
| Цэвэр чөлөө | Энгийн сессийг хаах | Нэгдэж, тохирохыг орхих | Сэжигтэй байдал |
| Шуурхай дахин холбох | Churn/probing контекст | Хурдан давтагдана | Хориглох |
| Бохир салгасан | Үйл ажиллагаа цэвэр хаагдсангүй | Гэмтэлүүдийг давтах буюу давхцуулах | Хориглох |
| Гэмтлийн давхцал | Гэмтлийн ойролцоо бүртгэл идэвхтэй байна | Ижил бүртгэл давтагдана | Хориглох |
| Гэмтлийн дараах өгөөж | Дахин эхлүүлсний дараа данс буцаж ирнэ | Үе үе давтагдана | Нэг үйл явдлаар хориглох |
| Анхааруулга | Серверийн анхааруулах цонх | Зурагласан сешнүүдийг давхцуулж байна | Нэг удаа хориглох |
| Жүжигчин хадгалах мэдрэгчтэй | Дэлхийг хадгалах контекст | Үйл ажиллагаатай холбоотой | Нотлох use/theft |
| Объектийн гурвалжин | World/class өөрчлөлт | Үйл ажиллагаатай холбоотой | Зөвхөн тоолохыг хориглох |
| Давлага хийх тохиолдол | Олон дансны кластер | Төв данс давтагдана | Бүх бүртгэлийг хориглох |

<a id="login-identity"></a>
## Нэвтрэх таниулбар

Шилдэг эх сурвалж:

```text
Login request
Name=
ConnectID=
UniqueId=
```

Үүнийг газрын зураг дээр ашиглах:

```text
display/log name -> account_id -> ban_id
```

<a id="rapid-reconnect"></a>
## Шуурхай дахин холбох

Загвар:

```text
join -> leave -> join -> leave -> join
```

Дахин давтах үед хянуулах зорилгоор ашиглах.

Аюулгүй байдал:

```text
churn_alone_never_bans = true
```

<a id="crash-overlap-and-post-crash-return"></a>
## Гэмтлийн давхцал болон ослын дараах өгөөж

Загвар:

```text
account active before crash
server restarts
same account returns quickly
```

Үе үе давтагдах үед хянуулах зорилгоор ашиглах.

Аюулгүй байдал:

```text
single_crash_never_bans = true
```

<a id="warning-bursts"></a>
## Анхааруулга

Жишээ нь:

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

Зурласан сесс болон босготой холбогдох хүртэл контекст болгон ашиглана уу.

<a id="actor-save-touch"></a>
## Жүжигчин хадгалах мэдрэгчтэй

Утга:

```text
The server evidence referenced a class or actor.
```

Утга биш:

```text
A player opened it.
A player stole from it.
A player duplicated through it.
A player damaged it.
```

<a id="raid-cases"></a>
## Давлага хийх тохиолдол

Дайлдлагын хэрэг бүртгэлүүдийг цаг хугацаа болон хуваалцсан цонхоор нь бүлэглэдэг.

Дүрэм:

```text
Do not auto-ban every account in a raid case.
Each account needs account-specific evidence.
```
