# Үйл ажиллагааны дэвтэр

> **Каноник англи эх сурвалж:** [OPERATIONS_PLAYBOOK.md](../../OPERATIONS_PLAYBOOK.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Энэ бол RandomDayGuard. Та мэдэх шаардлагагүй JSON, Git, checksums эсвэл эрүүл серверийг шалгах командын мөрийн хэрэгслүүд.

<a id="daily-operator-flow"></a>
## Өдөр тутмын операторын урсгал

1. Нээх `runtime/final_logs/server_status_latest.txt`. Энэ нь Guard одоогийн серверийн ажиллагааг хянаж байгаа эсэх, түүний сүүлийн мөчлөг хэзээ дууссан, хэдэн тоглогч холбогдсон, эх сурвалж эсвэл скан дутуу байгаа эсэхийг хэлж өгнө.
2. Нээх `runtime/final_logs/daily_rollup_latest.txt` өдөрт нэг удаа. Энэ нь тухайн өдрийн хуралдаан, гарц, нэрлэсэн кейс ажил, хэн болохыг тодорхойлох бүртгэл, эх сурвалжийн хамрах хүрээ зэргийг тус бүр бүртгэл бүрийг давталгүйгээр нэгтгэн гаргадаг.
3. Нээх `runtime/final_logs/player_activity_latest.txt` зөвхөн өдрийн турш сервер нэгдэх, гарах эсвэл идэвхтэй сесс хийх үед л.
4. Нээх `runtime/final_logs/case_review_latest.txt` зөвхөн тухайн сэдвийг нэрлэсэн үед. Тайлан нь бүртгэл, хяналтын төлөв, оноо, таниулах эх сурвалж, дараа нь нээх бүртгэлийг өгдөг.
5. Нээх `runtime/final_logs/critical_guard_latest.txt` зөвхөн Guard өөрийн эхлүүлэх, хянах цикл эсвэл тайлан бичих явцад алдаа гарсан тухай мэдээлэх үед.

Хэрэв замд мэдээлэх зүйл байхгүй бол Guard хүлээгдэж буй хоосон үр дүнг бичнэ. Энэ бол дутуу тайлан биш, дууссан шалгалт юм.

<a id="what-to-read-inside-a-report"></a>
## Тайлан дотор юу унших вэ

Эдгээр хэсгийг дарааллаар нь уншина уу:

1. **Дүгнэлт** - энэ тайланд юу багтдаг.
2. **Харуул ажигласан зүйл** - энэ чиглэлд цуглуулсан бодит цагийн тэмдэг, тоо, бүртгэл, сесс, төлөвийн утгууд.
3. **Энэ нь юу гэсэн үг вэ** - тэдгээр бичлэгийн энгийн хэл дээрх тайлбар.
4. **Юу үл мэдэгдэх** - үр дүнд нөлөөлөх эх сурвалж эсвэл сканнерын хязгаарлалт.
5. **Дараагийн алхамыг санал болгож байна** - хяналт тавих, нэрлэсэн сэдвийг хянах, эсвэл Хамгаалагчийг засах эсэх.
6. **Нотлох баримтын хил хязгаар** - тайлангийн хамрах хүрээний хязгаар.

Техникийн бүртгэл болон эх сурвалжийн лавлагаа нь нарийн зохион байгуулалттай нотлох баримтыг шалгах шаардлагатай уншигчдад зориулж төгсгөлд харагдана.

<a id="when-a-report-is-missing"></a>
## Тайлан байхгүй үед

Нээх `runtime/final_logs/route_proof.json` зөвхөн уншигдахуйц тайлан байхгүй эсвэл одоогийн нотлох баримт байхгүй гэж хэлсэн тохиолдолд. Маршрут бүр дараах үр дүнгийн аль нэгтэй байна:

| Үр дүн | Утга |
|---|---|
| `full` | Харуул одоогийн маршрутын эзэмшиж буй нотлох баримтаар замыг дуусгасан. |
| `limited_expected_empty` | Харуул замаа дуусгасан бөгөөд шаардлага хангасан үйл явдал олоогүй, эсвэл нэрлэсэн насны хязгаарыг бүртгэсэн. |
| `missing` | Шаардлагатай эх сурвалж, удам угсаа шалгах, эсвэл хосолсон тайлан бичиж дуусгаагүй. |

Алга болсон маршрутын хувьд нэрлэсэн эх сурвалжийг дагаж эсвэл тайланд алдаа бичнэ үү. Эхлээд холбоогүй маршрут эсвэл мэдэгдлийн тохиргоог бүү өөрчил.

<a id="after-a-crash-or-restart"></a>
## Гэмтэл эсвэл дахин эхлүүлсний дараа

1. Серверийн ажиллуулж байгаа шинэ цагийн тэмдэг болон хамгийн сүүлд дууссан хяналтын мөчлөгийн Серверийн статусыг уншина уу.
2. Одоогийн эхлүүлэх эсвэл санал асуулгад алдаа гарсан тохиолдолд Critical Guard-г уншина уу.
3. Тоглогчийн үйл ажиллагааг зөвхөн тухайн өдрийн сесс нэгдсэн, гарсан эсвэл амьдралын мөчлөгийн өөрчлөлтийн дараа буцаж ирсэн тохиолдолд л уншина уу.
4. Тохиргоог өөрчлөхөөс өмнө иш татсан эх сурвалжийн бичлэгийг хадгална уу.

<a id="before-enabling-optional-adminini-writes"></a>
## Заавал бишийг идэвхжүүлэхийн өмнө Admin.ini бичдэг

Өгөгдмөл багц нь өөрчлөхгүйгээр харж, мэдээлдэг `Admin.ini`. Нарийвчилсан операторууд файлын хуулбар дээр туршиж үзсэний дараа заавал хэрэгжүүлэх замыг идэвхжүүлж болно. Дараа нь Guard нь цэвэр тоон бүртгэлийн ID шаарддаг, итгэмжлэгдсэн акаунтуудыг хамгаалж, нөөцлөлт үүсгэж, баталгаажуулж, нэгэн зэрэг өөрчлөлт оруулахаас татгалзаж, хадгалсан файлыг буцааж уншиж, баталгаажуулалт амжилтгүй болбол нөөцлөлтийг сэргээдэг. [`ADMIN_INI_ENFORCEMENT.md`](%D0%90%D0%94%D0%9C%D0%98%D0%9D%D0%AB_%D0%A5%D0%AD%D0%A0%D0%AD%D0%93%D0%96%D0%98%D0%9B%D0%A2.md) бүрэн тохиргоо болон туршилтын журмын хувьд.
