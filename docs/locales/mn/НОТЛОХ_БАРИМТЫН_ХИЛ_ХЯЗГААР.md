<a id="evidence-boundary"></a>
# Нотлох баримтын хил хязгаар

> **Каноник англи эх сурвалж:** [EVIDENCE_BOUNDARY.md](../../EVIDENCE_BOUNDARY.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Юу болохыг шийдэхийн тулд энэ хуудсыг ашиглана уу RandomDayGuard мэдээлэх боломжтой бөгөөд юуг хүний ​​хянан шалгах шаардлагатай хэвээр байна.

<a id="core-rule"></a>
## Үндсэн дүрэм

RandomDayGuard сервер эзэмшдэг файлуудаас хязгаарлагдмал ажиглалтыг бүртгэдэг. Энэ нь материаллаг дүгнэлт бүрийн эх сурвалж, хамрах хүрээ, цуглуулах байдал, хязгаарыг тодорхойлох ёстой.

Бүтэцлэгдсэн нотолгоо нь эрх мэдэлтэй. Орчуулсан тайлан нь нотлох баримтыг тайлбарладаг; Энэ нь бүтэцлэгдсэн бүртгэлд байхгүй баримтуудыг нэмж чадахгүй.

<a id="evidence-source-classes"></a>
## Нотлох эх сурвалжийн ангиуд

| Эх сурвалжийн анги | Ердийн хэрэглээ | Өөрөө нотлохгүй |
|---|---|---|
| `admin_ini` | Одоо байгаа удирдлагын төлөв болон аудит хийгдсэн write/readback контекст | Хэн осол гаргасан |
| `active_log` | Одоогийн server/session үйл явдал идэвхтэй бүртгэлд харагдана | Зорилт, эзэмшил эсвэл шууд хохирол |
| `recent_backup_logs` | Түүхэн бүртгэлийн контекст | Одоогийн үйл явдал болсон |
| `playerdata_filenames` | Цэвэр акаунт танигч байгаа эсэхийг батлах | Ид танигчаас гадна зан байдал, гэм буруу эсвэл хувийн өмчлөлийн |
| `existing_cases` | Урьдчилан шалгах нөхцөл | Өмнөх тайлбар зөв хэвээр байна |
| `existing_reports` | Өмнөх хураангуй болон шийдвэрүүд | Одоогийн баталгаагүй одоогийн үнэн |
| `existing_evidence` | Түүхэн бүтэцлэгдсэн нотлох баримт | Одоогийн үйл ажиллагаа |
| дэлхийг хадгалах хязгаарлагдмал скан | Удаан world/class контекст | Тоглогчийн үйлдэл, эзэмшил, хулгай, давхардал, гэмтэл |

Эх сурвалж бүрийг бүртгэдэг availability/readability, файлын тоо, эх сурвалжийн лавлагаа, одоогийн эсвэл түүхэн хамрах хүрээ, тодорхой `does_not_prove` мэдэгдэл.

<a id="source-states"></a>
## Эх сурвалжийн төлөвүүд

| Төлөв | Операторын утга |
|---|---|
| `available` | Эх сурвалжийг унших боломжтой бөгөөд нотлох баримт цуглуулсан. |
| `expected_empty` | Эх сурвалж нь унших боломжтой байсан бөгөөд хууль ёсны дагуу тохирох бичлэг байгаагүй. |
| `partial` | Зарим нотлох баримт цуглуулсан; хамрах хүрээ бүрэн бус байна. |
| `deferred` | Хязгаарлагдмал ажлыг санаатайгаар хойшлуулсан. |
| `unavailable` | Эх сурвалж энэ орчинд байхгүй байна. |
| `malformed` | Эх сурвалж байгаа боловч аюулгүй задлан шинжлэх боломжгүй. |
| `permission_denied` | Харуулын нохой унших зөвшөөрөлгүй байна. |
| `error` | Өөр бүртгэгдсэн шалтгаанаар цуглуулга амжилтгүй боллоо. |

Боломжгүй хоосон нь хүчинтэй ажиглалт юм. Үүнийг хэзээ ч зохиомол тоглогч, хэрэг, хэрэг, буруутгал болгон хувиргаж болохгүй.

<a id="current-versus-historical-evidence"></a>
## Одоогийн болон түүхэн нотлох баримтууд

Одоогийн нотлох баримт нь идэвхтэй цуглуулах цонх эсвэл серверийн эринд хамаарна. Түүхэн нотлох баримтууд нь өмнөх бүртгэл, хэрэг, тайлан, нотлох баримтын бүртгэл, нөөцлөлт эсвэл үндсэн мэдээллээс ирдэг.

Түүхэн нотлох баримт нь контекстийг өгч чадна. Энэ нь одоогийн нотлох баримтын цоорхойг чимээгүйхэн дүүргэж чадахгүй. Тайлангууд нь хамрах хүрээг хоёуланг нь тэмдэглэж, эх сурвалжийг тусад нь дурдах ёстой.

<a id="corroboration-rule"></a>
## Баталгаажуулах дүрэм

Эдгээр нь ашигтай контекст боловч шууд нотлох баримт биш:

- нэр эсвэл нэрийн ижил төстэй байдлыг харуулах;
- цаг хугацааны давхцал;
- холболтыг салгах эсвэл дахин холбох;
- нэг осол эсвэл анхааруулга;
- анги, зам, жүжигчин, газрын зураг эсвэл объектын тооллын токенууд;
- автоматаар бүлэглэсэн тохиолдолд гишүүнчлэл;
- Одоогийн эх сурвалжийг баталгаажуулаагүй өмнөх тайлангууд.

Баримтыг шууд илчлэх нотлох баримтгүйгээр гэм буруу, санаа зорилго, залилан мэхлэх, өмчлөх, хулгайлах, давхардуулах, шууд хохирол учруулсан, шууд контейнер ашиглах, бараа материалын шууд үйлдэл, яг бодит координат, шууд ping эсвэл санах ойн түвшний зан үйлийг бүү мэдэгд.

<a id="truthful-report-language"></a>
## Үнэн мэдээлэх хэл

Ашиглах:

```text
Observed: the account was active in the recorded crash window.
Interpretation: repeated overlap warrants operator review.
Unknown: the cause of the crash.
Does not prove: that the account caused the crash.
Next action: compare the cited current session and lifecycle records.
```

Зайлсхийх:

```text
The player crashed the server.
The player stole or duplicated items.
The world token proves who used the object.
```

<a id="report-reading-order"></a>
## Уншсан дарааллыг мэдээлнэ үү

Олон нийтэд зориулсан илтгэл бүрийг тайлбарлах ёстой:

1. Энгийн утга.
2. Яагаад чухал вэ?
3. Техникийн баталгаа ба эх сурвалжийн лавлагаа.
4. Дараагийн үйлдэл.
5. Хязгаарлалт, үл мэдэгдэх зүйл, нэхэмжлэл нотлогдоогүй.
