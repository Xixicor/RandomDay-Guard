# ID зураглалыг хориглох

> **Каноник англи эх сурвалж:** [BAN_ID_MAPPING.md](../../BAN_ID_MAPPING.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Тоглогчийн нэрийг сейф болгон хөрвүүлэхдээ энэ хуудсыг ашиглана уу `Admin.ini` хориглох шугам.

<a id="core-rule"></a>
## Үндсэн дүрэм

Дэлгэцийн нэр нь хоригийн ID биш юм.

`Admin.ini` ашигладаг:

```ini
BannedPlayer=<raw numeric player ID>
```

<a id="evidence-hierarchy"></a>
## Нотлох баримтын шатлал

| Зэрэглэл | Эх сурвалж | Ашиглах |
|---:|---|---|
| 1 | Серверийн бүртгэл `Login request` | Шилдэг нэрээс ID-н зураглал |
| 2 | `Player_<ID>.sav` | ID байгаа эсэхийг баталгаажуулна |
| 3 | Одоо байгаа `Admin.ini` | Одоо байгаа bans/moderators |
| 4 | Гадаад мэдэгдэл эсвэл хостинг самбарын үйл ажиллагаа | Time/name зөвхөн контекст; үнэмлэх биш |
| 5 | UE4SS focus/player мөр | Presence/context зөвхөн |
| 6 | Системийн амьдралын мөчлөг эсвэл контейнерийн бүртгэлүүд | Зөвхөн хостын амьдралын мөчлөгийн контекст; үнэмлэх биш |

<a id="extract-the-clean-id"></a>
## Цэвэр ID-г задлах

Түүхий жишээ:

```text
ConnectID=2535422284688820_+_|0002d07b...
```

Цэвэр `Admin.ini` утга:

```ini
BannedPlayer=2535422284688820
```

Бүү буулга `_+_|...`.

<a id="verify-with-playerdata"></a>
##  PlayerData

Шалгах:

```text
Saved/SaveGames/Server/Worlds/<WorldName>/PlayerData/Player_<ID>.sav
```

Утга:

```text
The ID exists in the world save.
```

Хязгаарлалт:

```text
PlayerData may not prove the display name unless another source maps it.
```

<a id="when-not-to-ban"></a>
## Хэзээ хориглохгүй вэ

Хэрэв дараах үед хоригийн ID оноож болохгүй:

```text
the name only appears in an external notification
the name only appears in hosting-panel activity
UE4SS shows a name but no ConnectID
only system lifecycle or container logs exist
the ID is trusted or moderator
```
