# Өөрчлөлтийн бүртгэл

> **Каноник англи эх сурвалж:** [CHANGELOG.md](../../../CHANGELOG.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


<a id="v0412-alpha"></a>
## v0.4.12-alpha

- Тодорхой эх сурвалжийн хамрах хүрээ, тодорхой бус байдал бүхий хязгаарлагдмал сервер-өгөгдлийн цуглуулгыг нэмсэн.
- Унших боломжтой серверийн статус, өдөр тутмын цуглуулга, тоглогчийн үйл ажиллагаа, тохиолдлын тойм, хамгаалалтын чухал тайлангуудыг хатуу чиглүүлэлтийн эзэмшилтэй нэмсэн.
- Одоогийн болон түүхэн тоглогчийн хувийн мэдээллийг салгах, сессийн хураангуй, нотлох баримтын лавлагаа, хүлээгдэж буй хоосон тайлангийн төлөвийг нэмсэн.
- Нэмэгдсэн нэмэлт Admin.ini итгэмжлэгдсэн дансны хамгаалалт, босго, нөөцлөлт, зэрэгцэн өөрчлөлтийг илрүүлэх, буцаах, буцаах зэрэг бүхий хэрэгжилт.
- Зөөврийн нийтийн тохиргоо, яг Saved-root хүчингүй болгох, бүрэн гаралт, алдааны лавлагаа, ажилласан тайлангийн жишээг нэмсэн.
- Англи хэлний иж бүрэн номын сан болон локалжуулсан 27 нэвтрэх хуудас нэмсэн.
- Хувилбарын багцыг тодорхойлогч, каноник тохиолдол болгон баталгаажуулсан UE4SS зохион байгуулалт, хувийн тохиргоо, хүргэлтийн итгэмжлэл, ажиллах үеийн өгөгдөлгүй.
