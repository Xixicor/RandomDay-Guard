# Дэлхийг хадгалах фолдерын өөрчлөлт

> **Каноник англи эх сурвалж:** [WORLD_SAVE_FOLDER_CHANGES.md](../../WORLD_SAVE_FOLDER_CHANGES.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Идэвхтэй ертөнцийн хавтас өөрчлөгдөх үед энэ хуудсыг ашиглана уу.

<a id="normal-layout"></a>
## Ердийн байрлал

```text
Saved/SaveGames/Server/Worlds/<WorldName>/
```

`SavedRoot.txt` нь:

```text
AbioticFactor/Saved
```

дэлхийн хавтас биш.

<a id="case-1-same-world-renamed"></a>
## Тохиолдол 1: ижил ертөнцийн нэрийг өөрчилсөн

Жишээ нь:

```text
Worlds/OldName/
Worlds/NewName/
```

Хүлээгдэж буй үйлдэл:

```text
Reuse cached evidence where fingerprints match.
Rescan files whose path/cache no longer matches.
Preserve old evidence.
```

<a id="case-2-different-world-or-restored-backup"></a>
## Тохиолдол 2: өөр ертөнц эсвэл сэргээсэн нөөцлөлт

Хүлээгдэж буй үйлдэл:

```text
Preserve old completed baseline.
Start a new baseline generation.
Do not overwrite old baseline until the new one completes.
```

<a id="case-3-partial-scan-existed-before-the-change"></a>
## Тохиолдол 3: өөрчлөлт хийхээс өмнө хэсэгчилсэн скан хийсэн байна

Хүлээгдэж буй үйлдэл:

```text
Mark the old checkpoint stale.
Preserve partial evidence.
Start a new baseline for the current world.
```

<a id="case-4-completed-baseline-existed-before-the-change"></a>
## Тохиолдол 4: өөрчлөлт хийхээс өмнө дууссан суурь үзүүлэлт

Хүлээгдэж буй үйлдэл:

```text
Load the old baseline for visibility.
Mark it as previous-world context.
Build a new baseline safely.
```
