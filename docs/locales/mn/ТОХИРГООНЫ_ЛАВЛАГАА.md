<a id="configuration-concepts"></a>
# Тохиргооны ойлголтууд

> **Каноник англи эх сурвалж:** [CONFIG_REFERENCE.md](../../CONFIG_REFERENCE.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Энэ тайлбар нь үндсэн тохиргооны хэсэг бүр юуг хянадаг, хэзээ ажилладаг, нотлох баримт болон аюулгүйн хаалгатай хэрхэн харьцдаг талаар тайлбарласан болно. Энэ нь яг талбарын каталог эсвэл профайлын процедурыг эзэмшдэггүй.

Даалгаварт чиглэсэн урьдчилан тохируулга болон аюулгүй өөрчлөлтийн алхмуудыг ашиглахын тулд [`CONFIG_PROFILES.md`](%D0%9F%D0%A0%D0%9E%D0%A4%D0%90%D0%99%D0%9B%D0%A3%D0%A3%D0%94%D0%AB%D0%93_%D0%A2%D0%9E%D0%A5%D0%98%D0%A0%D0%A3%D0%A3%D0%9B%D0%90%D0%A5.md). Тодорхой эх үүсвэрийн талбар, өгөгдмөл, төрөл, инвариант, гаралтын эффект, сэргээх дүрэм бүрийн хувьд үүсгэсэн [`CONFIG_FIELD_CATALOG.md`](%D0%A2%D0%9E%D0%A5%D0%98%D0%A0%D0%93%D0%9E%D0%9E%D0%9D%D0%AB_%D0%A2%D0%90%D0%9B%D0%91%D0%90%D0%A0%D0%AB%D0%9D_%D0%9A%D0%90%D0%A2%D0%90%D0%9B%D0%9E%D0%93.md); баталгаажуулагч нь илгээсэн зүйл бүрт нэг мөр шаардлагатай `config.lua` навчны талбар.

<a id="reading-this-page"></a>
## Энэ хуудсыг уншиж байна

Тохиргооны хэсэг бүр дараах хариултыг өгнө:

```text
What it controls
When it runs
What to check
What can go wrong
```

<a id="top-level-safety"></a>
## Дээд түвшний аюулгүй байдал

| Сонголт | Өгөгдмөл | Утга |
|---|---:|---|
| `enabled` | `true` | Хамгаалалтын мастер унтраалга |
| `enforcement.review_only_mode` | `true` | Record/recommend зөвхөн |
| `enforcement.auto_ban` | `false` | Өгөгдмөлөөр автоматаар хориглож болохгүй |
| `enforcement.write_admin_ini` | `false` | Бичиж болохгүй Admin.ini өгөгдмөлөөр |

Сервер эзэмшигч гаралтыг шалгах хүртэл эдгээрийг аюулгүй байлгаарай.

<a id="saved"></a>
## `saved`

Харуул серверийг хэрхэн олохыг хянадаг `Saved/` фолдер болон аль файлын бүлгийг сканнердаж болох.

Хэзээ ашиглах:

```text
Saved root auto-detection fails.
World folder changed.
Provider or container path is unusual.
```

Шалгах:

```text
runtime/saved_path_probe.json
RandomDayGuard/SavedRoot.txt
```

Дүрэм:

```text
SavedRoot.txt -> AbioticFactor/Saved
not -> Worlds/<WorldName>
```

<a id="log_tail"></a>
## `log_tail`

Шууд бүртгэл уншихыг хянадаг.

Ашигтай сонголтууд:

| Сонголт | Аюулгүй утга | Яагаад |
|---|---|---|
| `enabled` | `true` | Шууд хамгаалалтад шаардлагатай |
| `start_at_end_on_first_run` | `true` | Хуучин логуудыг шууд үйл явдал болгохоос зайлсхийдэг |
| `tail_backup_logs` | `false` | Нөөцлөлтийн бүртгэлүүд нь амьд биш харин түүх юм |
| `max_lines_per_poll` | хязгаарлагдсан | Санал асуулгын гогцоонд хариу үйлдэл үзүүлдэг |

Шалгах:

```text
runtime/log_offsets.tsv
runtime/evidence/session_events.jsonl
runtime/current/poll_status.json
```

<a id="runtime"></a>
## `runtime`

Санал хураалт болон төсвийг хянадаг.

Эрүүл мэндийн үндсэн дүрэм:

```text
poll_id increases
poll_in_flight returns false
poll_scheduled is true
```

Шалгах:

```text
runtime/current/poll_status.json
```

Хэрэв `poll_id` зогссон, ямар нэг зүйл давталтыг хааж байна.

<a id="source_accounting"></a>
## `source_accounting`

Тодорхой нотлох баримтын хамрах хүрээ, хамрах хүрээг хянадаг.

| Түлхүүр | Өгөгдмөл | Утга |
|---|---:|---|
| `enabled` | `true` | Нийтийн маршрутын тайлангийн эх сурвалжийн бүртгэлийг бичнэ. |
| `require_terminal_status` | `true` | Эх сурвалж бүр нь тодорхой терминал эсвэл бүрэн бус төлөвийг харуулахыг шаарддаг. |
| `distinguish_current_from_historical` | `true` | Одоогийн болон түүхэн баримтуудыг тусад нь хадгалдаг. |
| `slow_world_scan_blocks_current_reports` | `false` | Одоогийн тайланд хязгаарлагдмал ертөнцийг сканнердах нь хойшлогдсон эсвэл хэсэгчилсэн байна гэж хэлэх боломжийг олгоно. |
| `changed_file_manifest` | суурь манифест зам | Хязгаарлагдмал historical/world нягтлан бодох бүртгэл. |

Эх төлөв нь `available`, `expected_empty`, `partial`, `deferred`, `unavailable`, `malformed`, `permission_denied`, эсвэл `error`.

Тохиргоо `source_accounting.enabled = false` нь төлөвийн гаралтыг чимээгүйхэн арилгадаггүй. Дамжуулах хоолой `runtime/final_logs/source_accounting_latest.json` `enabled=false`, `status="unavailable"` болон `disabled_reason="source_accounting_disabled"`. Энэ нь мөн нягтлан бодох бүртгэлийн боломжгүй түүхэн байдлын бүртгэлийг бичдэг. Эх сурвалжийн бүртгэл нь тайлангийн гэрээний нэг хэсэг учраас бүх маршрут `missing`; Нягтлан бодох бүртгэл идэвхгүй байхад ямар ч маршрут дууссан гэж үзэхгүй.

<a id="reports"></a>
## `reports`

Ерөнхий орон нутгийн тайлангийн шугамыг хянадаг.

Өгөгдмөл нь бүх таван маршрутыг идэвхжүүлж, `runtime/final_logs`:

```text
server_status
daily_rollup
player_activity
case_review
critical_guard
```

Маршрут бүр нь бүтэцлэгдсэн, орчуулагдсан гаралт, баталгааг `route_proof.json`. Маршрутыг идэвхгүй болгосноор `missing` нотлох баримт нь дууссан мэт дүр эсгэхээс илүүтэй.

<a id="notification"></a>
## `notification`

Нэмэлт ерөнхий дотоод файлын гадагш илгээх хайрцаг. Энэ нь анхдагчаар идэвхгүй бөгөөд гадны үйлчилгээ үзүүлэгч рүү юу ч илгээдэггүй.

Өгөгдмөл:

```lua
notification = {
    enabled = false,
    mode = "local_file_outbox",
    include_expected_empty = false,
},
```

Мэдэгдэл бүрийг анхдагчаар идэвхгүй болгосон. Санаатайгаар идэвхжүүлсэн тохиолдолд гадагшаа хайрцаг нь `route_proof.json` бичигдсэн байна. Орон нутгийн нотлох баримт, тайлан нь эрх мэдэлтэй хэвээр байна. Үйлчилгээ үзүүлэгчийн тусгай хүргэлт, хүргэх эцсийн цэгүүд, итгэмжлэлүүд болон гүүрүүд нь олон нийтийн хараат бус харуулын гэрээний нэг хэсэг биш юм.

<a id="scanning"></a>
## `scanning`

Суурь скан хийх, шалгах цэг болон өөрчлөгдсөн файлын шинэчлэлтийг хянадаг.

Хэзээ ашиглах:

```text
building first world baseline
resuming after crash
refreshing changed files later
```

Шалгах:

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/scan_complete.json
runtime/baselines/file_manifest.tsv
```

Чухал тохиргоо:

```lua
scanning = {
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
    changed_file_detection = true,
},
```

<a id="forensic_rollup"></a>
## `forensic_rollup`

Өдөр тутмын хурдан байршуулах багц болон энгийн хэл дээрх эцсийн бүртгэлийг хянадаг.

Гаралт:

```text
runtime/current/forensic_today.json
runtime/current/forensic_today.md
runtime/current/forensic_today.txt
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

Хэзээ ашиглах:

```text
You want one daily folder that summarizes what happened.
You want a plain-language TXT to upload for quick analysis.
```

Шалгах:

```text
runtime/forensic_days/YYYY-MM-DD/forensic_day_summary.json
runtime/forensic_days/YYYY-MM-DD/players.tsv
runtime/forensic_days/YYYY-MM-DD/ban_recommendations.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

Дүрэм:

```text
Daily summaries are rebuildable indexes.
Source evidence remains authoritative.
```

<a id="logging"></a>
## `logging`

Үйл явдлын хэмжээ болон бага ач холбогдол бүхий нэгтгэлийг хянадаг.

Хэзээ ашиглах:

```text
actor-touch events are noisy
raw event files grow too quickly
```

Аюулгүй загвар:

```lua
logging = {
    low_importance_mode = "aggregate",
    write_low_importance_raw_events = false,
},
```

<a id="retention"></a>
## `retention`

Файлуудыг хэр удаан, хэзээ хадгалахыг хянадаг JSONL лог эргэлддэг.

Хэзээ ашиглах:

```text
disk usage grows too fast
you need more audit history
you need shorter live-history windows
```

Чухал сонголтууд:

```text
detailed_retention_days
rotate_jsonl_when_bytes_exceed
max_raw_events_lines
keep_enforced_forever
keep_evidence_forever
```

<a id="warning_bursts"></a>
## `warning_bursts`

Анхааруулга-цонхны илрүүлэлтийг хянадаг.

Жишээ нь:

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

Дүрэм:

```text
Warnings are context until correlated with mapped sessions and thresholds.
```

<a id="crash_correlation"></a>
## `crash_correlation`

Удирдлага давтагдсан crash/reconnect хянан үзэх.

Аюулгүй өгөгдмөл:

```lua
crash_correlation = {
    single_crash_never_bans = true,
    require_same_account = true,
},
```

Ашигтай тоолуур:

```text
server_crash_overlap_count
post_crash_reconnect_count
unclean_disconnect_count
```

<a id="join_leave"></a>
## `join_leave`

Далгиан болон нэгдэх долгионыг хянах.

Аюулгүй өгөгдмөл:

```lua
join_leave = {
    churn_alone_never_bans = true,
},
```

Үүнд ашиглах:

```text
rapid reconnect loops
join waves
short-session patterns
```

<a id="raid_detection"></a>
## `raid_detection`

Бүлгүүдийн бүртгэлүүд холбогдох цонхонд идэвхтэй байна.

Дүрэм:

```text
A raid case groups accounts for review.
It does not make every account guilty.
```

Хэрэгжүүлсэн бүртгэл бүрд бүртгэлтэй холбоотой нотлох баримт шаардлагатай хэвээр байна.

<a id="object_registry"></a>
## `object_registry`

Хяналтууд object/class уншигдах боломжтой Хадгалсан нотлох баримтаас токен гаргаж авах.

Гаралт:

```text
runtime/object_registry_partial.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
```

Дүрэм:

```text
Object/class context is not a ban reason by itself.
```

<a id="world_state"></a>
## `world_state`

Хяналтууд boot/current/session дэлхийн төлөв байдлын агшин зуурын зураг.

Гаралт:

```text
runtime/world_state/current/world_state_latest.json
runtime/world_state/sessions/<date>/<session_id>_<account_id>/
```

Сургуулийн тойм болон дэлхийн нөхцөл байдалд ашиглах.

<a id="enforcement"></a>
## `enforcement`

Зөвлөмж болон бодит байдлыг хянадаг Admin.ini бичдэг.

Харуул хориг нэмэхээс өмнө доорх мэдэгдэл бүр үнэн байх ёстой:

```text
review_only_mode == false
auto_ban == true
write_admin_ini == true
ban_id is clean numeric
account identity is mapped
not trusted
not moderator
threshold is met
```

Хэрэв нэг мэдэгдэл худал эсвэл шалгах боломжгүй бол хамгаалагч гарна `Admin.ini` өөрчлөгдөөгүй бөгөөд шалтгааныг бичнэ.

<a id="admin_ini"></a>
## `admin_ini`

Аюулгүй файл бичихийг хянадаг.

Дүрэм:

```text
Back up before writing.
Preserve existing bans.
Preserve moderators.
Write clean BannedPlayer=<ID> only.
```

<a id="restart_request"></a>
## `restart_request`

Операторын эзэмшдэг өөр процесс шалгаж болох нэмэлт локал маркер файлуудыг хянадаг. Энэ нь серверийг дахин эхлүүлэх эсвэл устгахгүй.

Өгөгдмөл:

```lua
restart_request = {
    enabled = false,
    restart_marker_file = "runtime/request_restart.flag",
    restart_reason_file = "runtime/restart_reason.json",
},
```

Гаралт:

```text
runtime/request_restart.flag
runtime/restart_reason.json
```

Хостинг самбар, үйлчилгээ үзүүлэгчийн гүүр эсвэл дахин эхлүүлэх автоматжуулалт байхгүй. Тэмдэглэгээ үүсгэхийг идэвхжүүлснээр гадны процесс нь хүсэлтийг дуусгасан эсвэл серверийг дахин эхлүүлсэн болохыг батлахгүй.
