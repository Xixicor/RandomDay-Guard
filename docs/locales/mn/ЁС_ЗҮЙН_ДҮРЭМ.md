# Ёс зүйн дүрэм

> **Каноник англи эх сурвалж:** [CODE_OF_CONDUCT.md](../../../CODE_OF_CONDUCT.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу. Энэ орчуулга нь мэдээллийн чанартай; англи хуулийн текстийн хяналт.


Хэлэлцүүлгийг техникийн, тодорхой, нотолгоонд суурилсан байлга. Нийтийн асуудалд хувийн тоглуулагчийн өгөгдөл, серверийн итгэмжлэл, шууд тохиолдлын бүртгэлийг бүү нийтлээрэй.
