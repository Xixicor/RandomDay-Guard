# FAQ

> **Каноник англи эх сурвалж:** [FAQ.md](../../FAQ.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


<a id="is-randomdayguard-the-randomday-mod"></a>
## Энэ нь RandomDayGuard RandomDay Мод?

Үгүй. RandomDay Мод нь серверийн туршлагыг өөрчилдөг. RandomDayGuard серверийн нотлох давхаргыг хардаг.

<a id="does-live-defense-work-before-the-scan-completes"></a>
## Шууд хамгаалалт нь скан хийж дуусахаас өмнө ажилладаг уу?

Тийм. Шууд хамгаалалт нь бүртгэл болон сессийн үйл явдлуудыг ашигладаг. Суурь скан нь дараа нь контекстийг сайжруулдаг.

<a id="why-can-the-first-scan-take-a-long-time"></a>
## Яагаад эхний скан хийхэд удаан хугацаа шаардагддаг вэ?

Эхний хайлт world/object контекст, файлын манифест, дахин ашиглах боломжтой үндсэн өгөгдөл.

<a id="what-do-i-check-first-after-startup"></a>
## Би эхлүүлсний дараа юуг хамгийн түрүүнд шалгах вэ?

```text
runtime/current/poll_status.json
```

Хайх:

```text
scheduler_status=running
poll_id increasing
poll_in_flight=false
```

<a id="where-are-player-summaries"></a>
## Тоглогчдын хураангуй мэдээлэл хаана байна?

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

<a id="where-is-the-daily-quick-review-package"></a>
## Өдөр тутмын хурдан шалгах багц хаана байдаг вэ?

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

<a id="which-file-should-i-upload-for-fastest-review"></a>
## Хамгийн хурдан шалгахын тулд аль файлыг байршуулах ёстой вэ?

```text
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="can-it-write-bans-automatically"></a>
## Энэ нь автоматаар хориг бичиж чадах уу?

Зөвхөн тодорхой идэвхжүүлсэн тохиолдолд.

Өгөгдмөл:

```lua
review_only_mode = true
auto_ban = false
write_admin_ini = false
```

<a id="what-does-adminini-receive"></a>
## Юу вэ Admin.ini хүлээн авах уу?

Зөвхөн:

```ini
BannedPlayer=<ID>
```

Нэр, тайлбар, шалтгаан, дагавар байхгүй.

<a id="is-a-display-name-enough-to-ban"></a>
## Дэлгэцийн нэр нь хориг тавихад хангалттай юу?

Үгүй. Серверийн бүртгэлийг ашигла `Login request` `ConnectID` эсвэл түүнтэй адилтгах серверийн нотолгоо.

<a id="can-one-crash-ban-someone"></a>
## Хэн нэгнийг гэнэт хориглож болох уу?

Өгөгдмөл байдлаар үгүй.

<a id="can-object-count-alone-ban-someone"></a>
## Хэн нэгнийг хориглож болох уу?

Өгөгдмөл байдлаар үгүй.

<a id="should-savedroottxt-point-to-the-world-folder"></a>
## Хэрэгтэй SavedRoot.txt дэлхийн хавтас руу чиглүүлэх үү?

Үгүй. Үүнийг `AbioticFactor/Saved`.

<a id="what-if-the-world-folder-changes"></a>
## Дэлхийн хавтас өөрчлөгдвөл яах вэ?

Үүнийг үндсэн таних өөрчлөлт гэж үзнэ. Хуучин суурь үзүүлэлтийг хадгалж, шинээр үүсгэнэ үү.
