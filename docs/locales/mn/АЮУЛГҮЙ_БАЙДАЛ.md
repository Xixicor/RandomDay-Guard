# Аюулгүй байдлын бодлого

> **Каноник англи эх сурвалж:** [SECURITY.md](../../../SECURITY.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


<a id="report-a-vulnerability-privately"></a>
## Эмзэг байдлын талаар нууцаар мэдээлэх

Ашиглах [GitHub хувийн эмзэг байдлын тайлан](https://github.com/Xixicor/RandomDay-Guard/security/advisories/new) нууц тайланг хадгалах газрын эзэмшигч рүү илгээнэ үү. Хэрэв энэ маягт байхгүй бол [эзэмшигчийн нийтийн GitHub профайл](https://github.com/Xixicor) эмзэг байдлын дэлгэрэнгүй мэдээллийг оруулахгүйгээр хувийн холбоо барих сувгийг хүсэх.

Мөлжих алхмууд, итгэмжлэлүүд, хувийн серверийн замууд, тоглогчийн таниулбаруудыг агуулсан нийтийн асуудлыг бүү нээ. `Admin.ini`, Хадгалсан өгөгдөл, вэб дэгээ URL эсвэл шууд нотлох баримт файлууд.

<a id="include-useful-evidence"></a>
## Ашигтай нотлох баримтыг оруулах

Болно уу:

- нөлөөлөлд өртсөн RandomDayGuard хувилбар буюу амлалт;
- нөлөөлөлд өртсөн бүрэлдэхүүн хэсэг болон хүлээгдэж буй аюулгүй байдал;
- ариутгасан бэхэлгээ ашиглан нөхөн үржих хамгийн бага алхам;
- ажиглагдсан нөлөөлөл ба түүнийг давтах боломжтой эсэх; болон
- хувийн мэдээллийг задруулдаггүй аливаа санал болгож буй бууруулах арга хэмжээ.

Бодит нууцыг бүү илгээ. Асуудлыг дахин гаргахад шаардлагатай бүтцийг хадгалахын зэрэгцээ хувийн зам, бүртгэлийн таниулбар, хостын нэр болон жетоныг тодорхой орлуулагчаар солино уу.

<a id="expect-review-first-handling"></a>
## Хамгийн түрүүнд хянан үзэх

Тайлан нь серверт хандах, шууд зорилтот тест хийх, ашиглалтын дэлгэрэнгүйг нийтлэх эсвэл бүтэлгүйтсэн хаагдсан өгөгдмөл тохиргоог сулруулах зөвшөөрөл биш харин засварлагчийн хяналт шалгалтын нотолгоо юм. Эзэмшигч нь хувийн тайлангаар дамжуулан хамрах хүрээг баталгаажуулж, аливаа тодруулгыг зохицуулах болно.
