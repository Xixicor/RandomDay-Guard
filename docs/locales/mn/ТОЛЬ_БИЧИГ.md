# Толь бичиг

> **Каноник англи эх сурвалж:** [GLOSSARY.md](../../GLOSSARY.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


| Хугацаа | Энгийн утга | Яг техникийн утга |
|---|---|---|
| Идэвхтэй бүртгэл | Шинэ нотлох баримтад ашигласан одоогийн серверийн бүртгэл. | Шаардлагатай `active_log` эх сурвалж; Маршрутыг дуусгахад уншигдах чадвар болон одоогийн удам угсаа шаардлагатай. |
| Ачаалах ID | Нэг харуулын процесс эхэлнэ. | Өмнөх ачааллаас татгалзахад ашигласан одоогийн ажиллах цагийн танигч errors/reports. |
| Epoch ID | Нэг серверийн тасралтгүй байдлын интервал. | Тасралтгүй байдлын логик өөр эрин үе эхлэх хүртэл хэвийн ажиллах хугацааг хамардаг танигч. |
| Санал асуулгын ID | Хязгаарлагдмал санал асуулгын нэг боломж. | Эерэг монотон мөчлөгийн талбар; zero/missing маршрутыг гүйцээж чадахгүй байна. |
| Эх сурвалжийн шинэлэг байдал | Одоогийн эх сурвалж болон санал асуулгын удам тохирч байгаа эсэх. | `fresh_current_poll` эсвэл `stale_or_unproven` цагийн тэмдэг, идэвхтэй бүртгэлийн төлөвтэй. |
| Эх сурвалжийн бүртгэл | Нотлох баримт олдоц ба хязгаарлалтын тооллого. | `randomdayguard.source-accounting/v1` найман эх ангитай ба current/historical хамрах хүрээ. |
| `available` | Эх сурвалжийг олж уншсан. | Терминал эх сурвалжийн төлөв `available=true`, `readable=true`. |
| `expected_empty` | Нэмэлт эх сурвалжийг шалгаж, хууль ёсны дагуу absent/empty. | Терминал унших боломжтой эх сурвалжийн төлөв; хэзээ ч субьект үйлдвэрлэдэггүй. |
| `partial` | Хязгаарлагдмал ажил нь ашигтай боловч бүрэн бус үр дүнтэй байдаг. | Терминал бус source/accounting төлөв; эзэмшигч ажилтнаа үргэлжлүүлнэ үү. |
| `deferred` | Ажил санаатайгаар хүлээгдэж байна. | Терминал бус эх сурвалжийн төлөв; алдаа эсвэл дуусгавар биш. |
| `unavailable` | Эх сурвалжийг одоогоор ашиглах боломжгүй. | Терминал завсар; шаардлагатай эх үүсвэрийн зөрүү нь нягтлан бодох бүртгэлийг ашиглах боломжгүй болгодог. |
| `malformed` | Эх сурвалж байгаа боловч бүтцийн хувьд хүчингүй байна. | Баталгаажуулалтын нарийвчилсан мэдээллийг хадгалж, хамааралтай бичвэрүүдийг хаадаг терминалын цоорхой. |
| `permission_denied` | ҮС нь хандалтаас шууд татгалзсан. | Терминал хоорондын зай missing/unavailable. |
| `error` | Хязгаарлагдмал ажиллагаа гэнэт бүтэлгүйтэв. | Нэрлэсэн сэргээх шаардлагатай терминалын алдаа; Олон нийтийн тайланд ямар ч нууц мэдээлэл байдаггүй. |
| `complete` | Бүх бүртгэлд хамрагдсан эх сурвалжууд нь хоосон зайгүй терминал юм. | Дээд түвшний эх сурвалжийн нягтлан бодох бүртгэлийн төлөв. |
| `complete_with_gaps` | Шаардлагатай одоогийн нотлох баримтууд; нэмэлт терминалын цоорхой хэвээр байна. | Дээд түвшний нягтлан бодох бүртгэлийн байдал; чиглүүлэлтүүд өөрсдийн шаардлагад нийцсэн хэвээр байна. |
| `full` | Шаардлагатай хоосон бус гэрээгээр дууссан маршрут. | Дууссан гүйдлийн мөчлөгийн гаралт бүхий чиглүүлэлтийн баталгаат дугаар. |
| `limited_expected_empty` | Маршрут дууссан бөгөөд тохирох зүйл олдсонгүй subject/failure. | Маршрут нотлох дугаар `completed=true`, `expected_empty=true`. |
| `missing` | Маршрут дууссаны нотлох баримт байхгүй эсвэл амжилтгүй болсон. | Маршрут нотлох дугаар `completed=false`; хэзээ ч гадагшаа имэйл илгээх эрхгүй. |
| Бүтцийн тайлан | Машинаар унших боломжтой маршрутын гаралт. | `<route>_latest.json` `randomdayguard.report/v1`. |
| Орчуулсан тайлан | Ижил маршрутын хүн унших боломжтой дүрслэл. | `<route>_latest.txt` Тогтмол Ажиглагдсан-Эх сурвалж-лавлагаатай. |
| Маршрутын баталгаа | Маршрут дамнасан бөглөх дэвтэр. | `route_proof.json` холбох version/boot/epoch/poll/freshness/output зам. |
| Одоогийн нотлох баримт | Идэвхтэй мөчлөгийн эзэмшдэг ажиглалт. | Хамрах хүрээ `current`; хуучин filenames/reports. |
| Түүхэн нотлох баримт | Өмнөх мөчлөгүүдээс хадгалагдсан контекст эсвэл удаан хайлт. | Хамрах хүрээ `historical`; хянан мэдээлэх боловч одоогийн байгаа эсэхийг шаардах боломжгүй. |
| Зөвхөн хянан үзэх боломжтой | Хяналтын нотлох баримтыг Admin.ini бичдэг. | Өгөгдмөл `review_only_mode=true`, `auto_ban=false`, `write_admin_ini=false`. |
| Хориглох жагсаалтын аюулгүй байдлын шалгалт | Өөрчлөхөөс өмнө хамгаалагч нэг асуултад хариулах ёстой `Admin.ini`. | Энэ нь акаунт болон оноог баталгаажуулах, итгэмжлэгдсэн акаунтууд болон хуулбарыг оруулахгүй байх, нөөцлөлтийг баталгаажуулах, гадны өөрчлөлтүүдийг илрүүлэх, төлөвлөсөн шинэчлэлтийг хадгалах, файлыг бүрэн баталгаажуулах эсвэл аюулгүй сэргээх ёстой. |
| Орон нутгийн гадагш илгээх хайрцаг | Үйлчилгээ үзүүлэгчээс хамааралгүй мэдэгдлийг шилжүүлэх. | JSON файлууд `delivery_backend="none"` болон `delivery_attempted=false`. |
| Суурь | Хязгаарлагдмал Хадгалагдсан файлын контекст агшин агшинг дуусгасан. | Manifest/object/world төлөвийг зөвхөн нийцтэй, хангалттай шинэлэг үед дахин ашигладаг. |
| Шалгах цэг | Дутуу скан хийх ажлын байрлалыг үргэлжлүүлнэ үү. | `scan_checkpoint.json`; Устгах нь анхдагч сэргээх арга биш юм. |
| Дахин бүтээх боломжтой индекс | Сэргээх боломжтой хураангуй. | Daily/weekly/forensic/final гаралтыг хянах; эх сурвалжийн нотлох баримтууд хүчин төгөлдөр хэвээр байна. |
| Нотлох баримтын хил хязгаар | Эх сурвалж юуг дэмжихийг хязгаарлах. | Тодорхой `does_not_prove`, үл мэдэгдэх, таних чадвар, хамрах хүрээний дүрэм. |
