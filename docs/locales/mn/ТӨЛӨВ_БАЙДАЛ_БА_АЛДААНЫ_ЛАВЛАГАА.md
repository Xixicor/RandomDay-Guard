# Төлөв байдал ба алдааны лавлагаа

> **Каноник англи эх сурвалж:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Энэ эшлэлийг [Алдааг олж засварлах](%D0%90%D0%9B%D0%94%D0%90%D0%90%D0%93_%D0%9E%D0%9B%D0%96_%D0%97%D0%90%D0%A1%D0%92%D0%90%D0%A0%D0%9B%D0%90%D0%A5.md). Алдаагаар нэрлэгдсэн бүтэцлэгдсэн статус файлыг уншина уу. Ялгаатай кодууд нь аюулгүй байдал, амьдралын мөчлөгийн тодорхой төлөвийг илэрхийлдэг; Тэдгээрийг ерөнхий "Харуул амжилтгүй болсон" илэрц болгон задалж болохгүй.

<a id="route-and-source-states"></a>
## Маршрут болон эх сурвалжийн төлөвүүд

| Утга | Утга | Операторын хариулт |
|---|---|---|
| `full` | Одоогийн мөчлөгийн эх сурвалжийн нотолгоогоор дууссан маршрутын гэрээ. | Маршрутын нотолгооны хил хязгаарыг унших; засвар хийхгүй. |
| `limited_expected_empty` | Дууссан зам болон дутуу үйл ажиллагаа нь энэ мөчлөгт хууль ёсны юм. | Синтетик байхгүй player/case үйл явдал үүсгэх ёстой. |
| `missing` | Шаардлагатай гаралт, удам угсааны талбар эсвэл эх сурвалжийн нотолгоо байхгүй байна. | Маршрутын шалтгаан болон нэрлэсэн эх сурвалжийн төлөвийг шалгана уу. |
| `available` | Нэрлэсэн эх сурвалж нь унших боломжтой, ашиглах боломжтой байсан. | Үйлдэл алга. |
| `expected_empty` | Эх сурвалжийг шалгасан бөгөөд хууль ёсны дагуу мөр байхгүй байна. | Үйл ажиллагаа бие даан хүлээгдээгүй л бол ямар ч үйлдэл хийхгүй. |
| `partial` / `complete_with_gaps` | Ашиглах боломжтой нотлох баримтууд байгаа ч нэрлэсэн эх сурвалжийн ангиуд бүрэн бус байна. | Дүгнэлтийг цуглуулсан нотлох баримтаар хязгаарла. |
| `deferred` | Хязгаарлагдмал ажил нь хожим ажилчдад зориулагдсан болно. | Тохиргоог өөрчлөхөөс өмнө ахиц дэвшлийг баталгаажуулна уу. |
| `unavailable` | Орчин нь эх сурвалжийг өгөөгүй. | Хязгаарыг тэмдэглэх; зөвхөн батлагдсан зам эсвэл зөвшөөрлийн асуудлыг засна уу. |
| `malformed` | Эх сурвалжийг унших боломжтой боловч бүтцийн баталгаажуулалт амжилтгүй болсон. | Үүнийг хадгалж, эх сурвалжийг засах; бүү таа. |
| `permission_denied` | Эх сурвалж байгаа боловч унших боломжгүй. | Зөвхөн шаардлагатай нарийн унших зөвшөөрлийг олгоно уу. |
| `error` | Бичигдсэн шалтгаанаар цуглуулга амжилтгүй болсон. | Алдааг хадгалж, тухайн үе шатыг оношилно уу. |

<a id="playerdata-and-inventory-codes"></a>
## PlayerData болон бараа материалын кодууд

| Код | Утга | Аюулгүй хариулт |
|---|---|---|
| `saved_root_unavailable` | Нийтийн дамжуулах хоолойд баталгаажсан Хадгалсан үндэс байхгүй байна. | Зөв `SavedRoot.txt` болон замын шалгагчийг дахин шалгана уу. |
| `unsafe_playerdata_root` | PlayerData илрүүлэлт нь хязгаарлагдмал Хадгалсан язгуураас гадуур шийдэгдсэн. | Замыг засах; хил хязгаарыг хэзээ ч сулруулж болохгүй. |
| `playerdata_discovery_not_run` | Хязгаарлагдмал илрүүлэх ажилтан хараахан ажиллаагүй байна. | Хуваарьлагч болон ажилчдын явцыг шалгана уу. |
| `playerdata_discovery_read_failed:*` | Илгээлтийн гаралтыг уншиж чадсангүй. | Дагаврын дэлгэрэнгүйг хадгалж, хязгаарлагдмал бараа материалын командыг баталгаажуулна уу. |
| `inventory_command_open_failed` | Бараа материалын процессыг эхлүүлж чадсангүй. | Ажиллах хугацаа нь тохируулсан тушаалын гүүрээр хангагдсан эсэхийг шалгана уу. |
| `inventory_command_read_failed` | Унших явцад бараа материалын гаралт амжилтгүй болсон. | Хэсэгчилсэн гаралтыг хадгалж, үндсэн алдаа зассаны дараа л дахин ажиллуулна уу. |
| `inventory_command_close_failed` | Бараа материалыг найдвартай хаалтын үр дүнгүйгээр дуусгасан. | Эх сурвалжийг бүрэн бус гэж үзнэ. |
| `identity_ledger_row_limit_exceeded` | Тогтвортой таних тэмдэг нь нийтийн аюулгүй байдлын хязгаараас хэтэрсэн. | Архивлах, дэвтэртэй танилцах; Үүнийг бүрэн нотлох баримт болгон дуугүй таслах хэрэггүй. |

<a id="adminini-enforcement-codes"></a>
## Admin.ini хэрэгжүүлэх кодууд

Энэ хэсгийн бүх кодууд хаагдсан байна. Тэд гараар хориглохыг өөрсдөө зөвшөөрдөггүй.

| Код | Утга | Аюулгүй хариулт |
|---|---|---|
| `admin_ini_write_disabled` / `admin_ini_disabled` | Нийтийн аюулгүй бичих хаалга унтраалттай байна. | Зөвхөн хянах боломжтой. |
| `admin_ini_backup_disabled` / `backup_safety_gate_disabled` | Шаардлагатай нөөцлөх бодлого идэвхгүй байна. | Бичлэгийг идэвхгүй болго. |
| `enforcement_disabled` / `ban_on_threshold_disabled` / `auto_ban_disabled` | Нэг тодорхой хэрэгжүүлэх хаалга унтраалттай байна. | Зөвхөн олон нийтийн хянан үзэх өгөгдмөл үед хүлээгдэж буй; Үүнийг бичих алдаа гэж дахин бүү тайлбарла. |
| `review_only_mode_enabled` | Зөвхөн хянах горим мутацийг зориудаар блоклодог. | Зөвхөн нотлох баримтыг хянана уу. |
| `duplicate_prevention_disabled` | Давхардсан хамгаалалт идэвхгүй болсон. | Аюулгүйн хаалгыг сэргээх хүртэл бичихийг идэвхгүй байлгана уу. |
| `readback_safety_gate_disabled` / `rollback_safety_gate_disabled` | Бичсэний дараах баталгаажуулалт эсвэл буцаах хамгаалалт идэвхгүй болсон. | Бичлэгийг идэвхгүй байлгах; Эдгээр хаалгыг хэзээ ч бүү тойрон. |
| `clean_id_safety_gate_disabled` / `account_specific_evidence_gate_disabled` | Цэвэр таниулбар эсвэл акаунттай холбоотой нотлох баримтын хэрэгжилтийг идэвхгүй болгосон. | Аливаа шалгалтын өмнө хаалгыг сэргээнэ үү. |
| `moderator_preservation_disabled` / `existing_ban_preservation_disabled` | Хамгаалагдсан бүртгэл эсвэл одоо байгаа хоригийг хадгалахыг идэвхгүй болгосон. | Бичлэгийг идэвхгүй болго. |
| `clean_numeric_identity_required` | Санал болгож буй ID нь бүрэн хүлээн зөвшөөрөгдсөн холболтын маягт эсвэл цэвэр тоон ID биш юм. | Баталгаажсан зураглал авах; дурын угтварыг хэзээ ч бүү хас. |
| `identity_strength_below_minimum` | Таних нотолгоо нь тохируулсан босго хэмжээнээс сул байна. | Зөвхөн нотлох баримтыг хянана уу. |
| `playerdata_verification_required` | Тохируулга шаардлагатай PlayerData баталгаажуулалт, бүртгэлд байхгүй байна. | Зөвхөн нэр дэвшигчийн шүүмжийг хадгалах; файлын нэрнээс өмчлөлийг бүү гарга. |
| `trusted_or_moderator_identity` | Бүртгэл нь итгэмжлэгдсэн эсвэл зохицуулагчаар хамгаалагдсан. | Бичихийг зөвшөөрөхгүй. |
| `admin_ini_path_invalid` / `admin_ini_path_outside_saved_root` | Зорилтот зам хүчингүй эсвэл Хадгалагдсан үндэсээс зайлсхийж байна. | Зөв тохиргоо; Замын хамгаалагчийг хэзээ ч тойрч болохгүй. |
| `admin_ini_unavailable` | Унших боломжтой тохиргоо хийгдээгүй байна Admin.ini олдсон. | Хязгаарлагдмал замыг засах эсвэл хэрэгжилтийг идэвхгүй байлгах. |
| `admin_ini_read_failed` | Эрх бүхий байтыг уншиж чадсангүй. | Мутацийн өмнө зогсоо. |
| `admin_ini_parse_failed` | Admin.ini баталгаажуулалт илүү тодорхой бүтцийн кодгүйгээр амжилтгүй болсон. | Файлыг хадгалж, хэсэг болон мөрийн бүтцийг шалгана уу. |
| `admin_ini_contains_nul` | Файлд NUL байт бөгөөд текст хэлбэрээр хүлээн зөвшөөрөгдөөгүй. | Файлыг хадгалаад Guard-н гадна засаарай. |
| `admin_ini_duplicate_banned_players_section` | Нэгээс олон `[BannedPlayers]` хэсэг байна. | Зогссон үед хэсгүүдийг гараар нэгтгэнэ үү. |
| `admin_ini_banned_player_outside_section` | Гадаад хоригийн мөр `[BannedPlayers]`. | Бүдүүвчийг гараар засна уу. |
| `admin_ini_invalid_banned_player_line` | Хориглох мөр нь яг дэмжигдсэн ID мөр биш юм. | Алдаатай мөрийг засна уу. |
| `admin_ini_backup_failed` | Өвөрмөц нөөцлөлт нь байт-ын хувьд адилхан бичиж, уншаагүй. | Мутаци хийхийг зөвшөөрөхгүй. |
| `admin_ini_external_change_detected` | Өөр зохиолч Guard-ийн агшин зуурын зургийн дараа файлыг өөрчилсөн. | Гадаад байтыг хадгалж, зохиолчдыг зохицуулсны дараа дахин оролдоно уу. |
| `atomic_rename_unavailable` | Атомыг солих хүсэлт тавьсан боловч Луа өгөөгүй `os.rename`. | Бичих итгэл байхгүй; дэмжигдсэн ажиллах цаг ашиглах эсвэл хэрэгжилтийг идэвхгүй байлгаарай. |
| `admin_ini_write_failed` | Хяналттай орлуулалт дуусаагүй. | Бүртгэгдсэн орлуулах алдаа болон нөөцлөлтийг шалгана уу. |
| `post_write_verification_failed` | Үйлдвэрлэлийн байт нь нэр дэвшигчтэй тэнцээгүй. | Шалгах `rollback_success` болон `rollback_refused_external_change` аливаа үйлдлийн өмнө. |

<a id="startup-scheduler-and-backlog-states"></a>
## Эхлүүлэх, төлөвлөгч болон хоцрогдсон бүртгэлийн төлөвүүд

Эдгээр утгууд нь чиглүүлэлтийн баталгаа биш харин амьдралын мөчлөгийн нотолгоо юм. Тэдгээрийг одоогийн санал асуулга, тайлангийн ажилтан болон чиглүүлэлтийн баталгаатай файлуудын хамт уншина уу.

| Утга | Утга | Аюулгүй хариулт |
|---|---|---|
| `not_started` | Нэрлэсэн эхлүүлэх эсвэл төлөвлөгчийн үе шат эхлээгүй байна. | Эхлүүлэх явцад баримтжуулсан интервалыг хүлээнэ үү; дараа нь өөрчлөгдөөгүй эхний үе шатыг шалгана уу. |
| `main_lua_loaded` / `starting` | Каноник дуудагч ажиллаж, Guard эхлүүлсэн. | Дараагийн үе шат руу үргэлжлүүлэх; Энэ нь дангаараа бэлэн байдал биш юм. |
| `saved_root_found` / `log_tail_initialized` / `epoch_started` | Үндсэн эх сурвалж болон тасралтгүй ажиллагааг эхлүүлэх дэвшилтэт. | Дараагийн үе шат урагшлахаа болихоос нааш ямар ч үйлдэл хийхгүй. |
| `admin_state_written` / `playerdata_index_written` | Анхны хязгаарлагдмал индексүүдийг экспорт хийсэн. | Үйлдэл байхгүй; хуваарь гаргагчийн шилжүүлгийг дагаж мөрдөх ёстой. |
| `watchdog_started` | Тайлан болон санал асуулгын ажиглагч бүртгэгдсэн. | Дараа нь төлөвлөгч болон санал асуулгын явцыг баталгаажуулна уу. |
| `ready_degraded` / `scan_running` | Хязгаарлагдмал түүхийн скан хүлээгдэж байхад хамгаалалт ажиллаж байна. | Анхааруулга, алдаа биш; явцын тоолуурын урагшлахыг баталгаажуулна уу. |
| `ready` | Эхлүүлэх ба одоогийн хязгаарлагдмал скан бэлэн байдалд хүрсэн. | Маршрутын баталгааг тусад нь шалгана уу. |
| `scan_failed` / `error` | Эхлүүлэх эсвэл сканнердсан алдаа бүртгэгдсэнээр дуусгавар болсон. | Нэрлэсэн алдаа эсвэл төлөвийн файлыг хадгалж, тухайн үе шатыг оношлох. |
| `running` | Хуваарьлагч нь ирээдүйн санал асуулгын боломжуудыг эзэмшдэг. | Баталгаажуулах `poll_id` болон `poll_completed_count` урьдчилгаа. |
| `manual_only` | Дагцаалтын хуваарь боломжгүй байсан; зөвхөн тодорхой ажил ажиллуулж болно. | Хараа хяналтгүй ажиллагааг боломжгүй гэж үзнэ. |
| `stopped` | Хуваарьлагчийн ажиллагаа дууссан. | Дахин эхлүүлэхийн өмнө өмнөх зогсолт болон алдааны нотолгоог шалгана уу. |
| `active_log_caught_up` | Уншаагүй идэвхтэй бүртгэл байхгүй. | Түүхэн скан хийж магадгүй. |
| `active_log_unavailable_nonblocking` | Идэвхтэй бүртгэл байхгүй байсан ч эхлүүлэхийг хориглосонгүй. | Эх сурвалжийн хязгаарыг тэмдэглэж, бусад эх сурвалжийг баталгаажуулна уу. |
| `active_log_read_failed` | Идэвхтэй бүртгэл байсан боловч унших боломжгүй. | Алдааг хадгалж, зөвхөн батлагдсан зам эсвэл зөвшөөрлийн асуудлыг засаарай. |
| `budget_exhausted` / `active_log_has_unread_bytes` | Хязгаарлагдмал сүүлний дамжуулалт зогссон бөгөөд хоцрогдол үлдсэн. | Дараагийн санал асуулгаар уншаагүй тоог багасгахыг баталгаажуулна уу. |
| `offset_commit_failed_after_events_applied` | Үйл явдлуудыг боловсруулсан боловч лог офсетийн тогтвортой байдал амжилтгүй болсон. | Гүйцэтгэх ажиллагаа хойшлогдсон; өөр мөчлөгт найдахаасаа өмнө офсет хадгалах санг засаарай. |

<a id="scheduler-report-and-notification-codes"></a>
## Хуваарьлагч, тайлан, мэдэгдлийн кодууд

| Код эсвэл төлөв | Утга | Аюулгүй хариулт |
|---|---|---|
| `poll already in flight` | Одоогийн санал асуулга нь амьдралын мөчлөгийг эзэмшиж байх хооронд хоёр дахь дуудлага ирсэн. | Одоо байгаа санал асуулгын дэвшлийг баталгаажуулах; өөр давталт эзэмшигч нэмж болохгүй. |
| `no_log_files_found` | Тохируулсан идэвхтэй эсвэл нөөцлөлтийн бүртгэл олдсонгүй. | Хадгалсан эх ба эхийн тохиргоог баталгаажуулна уу. |
| `current_poll_error` | Одоогийн мөчлөг нь санал асуулгын эх сурвалжийн алдааг бүртгэсэн. | унших `runtime/current/poll_error.json`. |
| `cadence_deferred` | Дуусгах диспетчер хараахан болоогүй байна. | Дараагийн хязгаарлагдмал боломж хүртэл хүлээгдэж байна. |
