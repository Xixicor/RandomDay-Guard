# Гаралт ба төлөвийн схемийн лавлагаа

> **Каноник англи эх сурвалж:** [OUTPUT_SCHEMA_REFERENCE.md](../../OUTPUT_SCHEMA_REFERENCE.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Энэ нь үүсгэсэн оператортой холбоотой файлуудын стандарт гэрээ юм. Энэ нь дангаараа яг гаралтын зам, талбарын нэр, зөвшөөрөгдсөн утга, удам угсааны шаардлага, маршрутын схемийг эзэмшдэг. Процедурын удирдамжийг эдгээр баримтуудыг дахин тодорхойлохын оронд энд холбоно уу.

Ажиллах үеийн нотолгоо нь эрх мэдэлтэй; файлын нэр, төлөвлөгчийн зүрхний цохилт, орчуулсан тайлан эсвэл локал илгээсэн имэйлийн объект нь өөрийн талбар болон удам угсаагаас илүүг нотлохгүй.

<a id="public-report-routes"></a>
## Нийтийн тайлангийн маршрутууд

Тайлангийн ажилтан `runtime/final_logs/`:

| Маршрут | Гэрээ | `full` шаардлага | Хүлээгдэж буй хоосон утга |
|---|---|---|---|
| `server_status` | Одоогийн хуваарилагч, идэвхтэй бүртгэл, скан-хүлээгдэж буй болон эх сурвалжийн хамрах хүрээ. | Одоогийн boot/epoch/poll удам угсаа, шинэ идэвхтэй бүртгэл, accounting/history бичих ба JSON/TXT хос. | Өөрөө эрүүл гүйдлийн мөчлөгт ашиглагдаагүй; алга болсон удам угсаа нь `missing`. |
| `daily_rollup` | Одоогийн day/window сервер, тоглуулагч, кейс, сканнер, хамрах хүрээг хамарсан тасралтгүй байдал. | Түүхэн нягтлан бодох бүртгэлийн терминал нь маршрутад хангалттай бөгөөд одоогийн мөчлөгийн баталгаа бүрэн. | Хадгалагдаагүй тоглогч байхгүй, хяналтын тохиолдол байхгүй. |
| `player_activity` | Одоогийн болон түүхийг салга player/account ажиглалт. | Одоогийн мөчлөгийн баталгаа нэмэх нэг буюу түүнээс дээш current/historical мөр. | Хязгаарлагдмал оролтонд тохирох тоглогчийн эгнээ байхгүй; синтетик сэдэв байхгүй. |
| `case_review` | Нэрлэсэн хадгалагдсан тохиолдол болон одоогийн review/BAN-ELIGIBLE нэр дэвшигчид. | Одоогийн мөчлөгийн баталгаа болон эх сурвалжийн лавлагаа бүхий нэг буюу хэд хэдэн нэрлэсэн тохиолдол. | Хяналтын шалгуурыг хангасан нэрлэсэн тохиолдол байхгүй; синтетик тохиолдол байхгүй. |
| `critical_guard` | Одоогийн ачаалах хуваарь, эхлүүлэх, санал асуулга эсвэл нотлох баримтын бүрэн бүтэн байдлын алдаа. | Одоогийн мөчлөгийн нотолгоо болон одоогийн ноцтой алдаа. | Одоогийн ноцтой гэмтэл байхгүй; Хуучин текстийн алдаанууд энэ замыг эзэмшдэггүй. |

Идэвхжүүлсэн маршрут бүр бичдэг `<route>_latest.json` болон `<route>_latest.txt`. `runtime/final_logs/route_proof.json` нь ижил хувилбар, ачаалах, эрин үе, санал асуулга, эх сурвалжийн шинэлэг байдлыг бүртгэдэг.

<a id="report-json-schema"></a>
## мэйл JSON схем

Бүх маршрут JSON нь `schema="randomdayguard.report/v1"`.

| Талбар | Төрөл | Утгатай, өөрчлөгддөггүй |
|---|---|---|
| `schema` | мөр | Яг `randomdayguard.report/v1`. |
| `generated_ts`, `report_date` | мөр | Үйлдвэрлэлийн цагийн тэмдэг болон тайлагнасан огноо. |
| `version` | мөр | Runtime/package энэ мөчлөгийн таних тэмдэг. |
| `boot_id`, `epoch_id` | мөр | Одоогийн ачаалах процесс ба серверийн тасралтгүй байдлын эрин үе. Хоёуланг нь дуусгахад шаардлагатай. |
| `poll_id` | бүхэл тоо | Эерэг одоогийн санал асуулгын тодорхойлогч. Zero/missing маршрутыг гүйцээж чадахгүй байна. |
| `source_freshness` | объект | `status`, `checked_ts`, идэвхтэй бүртгэлийн төлөв, сүүлийн санал асуулгын цаг, хамгийн сүүлд дууссан санал асуулгын цаг. |
| `current_cycle_proof_complete` | бүлийн | Удам угсаа, шинэхэн үед л үнэн active-log/current-poll нотлох баримт зөвшөөрч байна. |
| `route` | тоо | Дээрх таван маршрутын нэг. |
| `route_proof_status` | тоо | `full`, `limited_expected_empty`, эсвэл `missing`. |
| `coverage_status` | тоо | Яг `complete`, `complete_with_gaps`, `partial`, эсвэл `unavailable`. |
| `completed`, `expected_empty` | бүлийн | `completed` нь зөвхөн `missing`; `expected_empty` нь зөвхөн `limited_expected_empty`. |
| `observed` | мөрийн массив | Бетоныг хадгалсан facts/counts/statuses. |
| `interpretation` | мөрийн массив | Нотолгоонд тохируулсан болгоомжтой утга. |
| `unknown` | мөрийн массив | Таны мэдээлэл, түүх, эх сурвалж эсвэл контекст дутуу байна. |
| `does_not_prove` | мөрийн массив | Нотлох баримтаар нотлох боломжгүй дүгнэлт. |
| `next_action` | мөр | Хамгийн аюулгүй хязгаарлагдмал операторын үйлдэл. |
| `source_references` | мөрийн массив | Эрэмбэлэгдсэн өвөрмөц runtime/Saved лавлагаа. |
| `enforcement_authority` | бүлийн | Үргэлж худал. Тайлан хэзээ ч бичихийг зөвшөөрдөггүй. |
| `output_paths` | хоёр мөр | JSON болон TXT замуудыг хосолсон бичихийн өмнө нэмсэн. |

`coverage_status` нь зөвхөн дээд түвшний нягтлан бодох бүртгэл юм. Эх сурвалжийн бүртгэлүүд нь `available`, `expected_empty`, `partial`, `deferred`, `unavailable`, `malformed`, `permission_denied` болон `error`. Маршрутын баталгаа нь `full`, `limited_expected_empty` болон `missing`; үнэт зүйлс хэзээ ч эдгээр хил хязгаарыг давдаггүй.

Маршрутын өргөтгөлүүд:

- `server_status`: `scheduler_status`, `active_log_status` болон `server_metrics`. Хэмжигдэхүүнүүд нь одоогийн эрин үе, хамгийн сүүлд дууссан санал асуулгын цагийн тэмдэг, ID, идэвхтэй тоглогчийн тоо, active/backup-log тоолно, скан хийнэ үү pending/progress утгууд ба configured/usable/unavailable эх сурвалжийн бүлгийн нягтлан бодох бүртгэл. Ямар ч эх сурвалж эдгээр баримтыг илчлэхгүй байхад тэд ажиллах хугацаа, дахин эхлүүлэх тоо, нөөц цагийн тэмдэг, тасалдал зэргийг зохион бүтээдэггүй.
- `player_activity`: `player_activity_present`, `movement`, `same_day_sessions`, `current_player_count`, `current_evidence_player_count`, `historical_player_count`, `historical_session_count`, `current_players`, `historical_players` болон нийцтэй байдлын массив `players`. Нэг өдрийн сесс бүр өөрийн сесс ID, бүртгэлийн ID, мэдэгдэж байгаа үед дэлгэцийн нэрийг хадгалдаг, join/leave цагийн тэмдэг, цэвэр гарах болон амьдралын мөчлөгийн туг, эх сурвалжийн лавлагаа. Хадгалсан таних тэмдэг болон PlayerData байгаа эсэх нь өнөөдрийн үйл ажиллагааны нотолгоо биш харин контекст хэвээр байна.
- `case_review`: `cases`, `review_subjects`, `current_case_count` болон `retained_case_count`. Одоогийн хянан үзэх сэдэв нь case/account ID, мэдэгдэж байгаа үед харуулах нэр, статус, оноо, таних итгэл, first/last ажиглалт, анхааруулах тоо, шалтгаан, одоогийн байгаа туг, эх сурвалжийн лавлагаа. Хадгалагдсан тохиолдлууд нь одоогийн сэдвийг өөрөө үүсгэдэггүй.
- `critical_guard`: `critical_failure_present` болон `current_boot_error_only=true`.
- `daily_rollup`: `daily_maturity`, `once_per_day_continuity`, `dedupe_window` болон `daily_metrics`. Энэхүү хэмжигдэхүүн нь тайлангийн огноо, идэвхтэй тоглогчид, нэг өдрийн үйл ажиллагаатай бүртгэлүүд, нэгдэх, орхих, цэвэр болон цэвэр бус гаралт, амьдралын мөчлөгийн өгөөж, одоогийн нэрлэгдсэн хянан үзэх сэдвүүд, хадгалагдсан тохиолдлууд, current/retained таних тоо, эх сурвалжийн бүлгийн хамрах хүрээ.

<a id="translated-txt-schema"></a>
## Орчуулсан TXT схем

Хосолсон текст файл нь операторын унших боломжтой илэрцийг хүргэж, удам угсааны дэлгэрэнгүй мэдээллийг эцэс хүртэл зөөнө. Энэ нь яг энэ хэсгийн дарааллыг хадгалдаг:

```text
RandomDayGuard <route title>
Generated: <timestamp>

Summary
<one plain-language route summary>

What Guard observed
- ...

What it means
- ...

What remains unknown
- ...

Recommended next step
...

Evidence boundary
- ...

Rating explanation
- ...

Technical record
- Route: <route>
- Version: <version>
- Cycle: boot=<boot> epoch=<epoch> poll=<poll>
- Source freshness: <status>
- Route result: <full|limited_expected_empty|missing>
- Coverage: <status>

Translation notes
- ...

Source references
- ...
```

Орчуулга нь зөвхөн бүтэцлэгдсэн тайлангийн талбарууд болон батлагдсан толь бичгийн зураглалыг ашигладаг. Энэ нь бүтэцлэгдсэн тайланд байхгүй тоглогч, тохиолдол, хүргэлт, шалтгаан, өмчлөл, зорилго эсвэл хэрэгжүүлэх эрх зэргийг нэмж чадахгүй. Унших боломжтой үр дүнг солихгүйгээр техникийн дэлгэрэнгүй мэдээлэл боломжтой хэвээр байна.

<a id="source-accounting-schema"></a>
## Нягтлан бодох бүртгэлийн эх сурвалжийн схем

`runtime/final_logs/source_accounting_latest.json` нь `randomdayguard.source-accounting/v1` үеийн reason/status, enablement/disabled шалтгаан, current/historical ялгаа, өөрчлөгдсөн файлын манифест, эх сурвалжийн бүртгэл, usable/unavailable ангийн жагсаалт, нэхэмжлэлийн хязгаар.

Эх сурвалж бүрд:

| Талбар | Төрөл | Утга |
|---|---|---|
| `source_class` | мөр | Доорх найман ангийн нэг. |
| `scope` | `current` эсвэл `historical` | Цагийн эзэмшил; хамрах хүрээг хэзээ ч чимээгүй нэгтгэдэггүй. |
| `required` | бүлийн | Зөвхөн `active_log` нь одоогийн мөчлөгийн маршрутын шинэлэг байдалд шаардлагатай. |
| `status` | тоо | Эх илэрцийг доор жагсаав. |
| `terminal` | бүлийн | Зөвхөн `partial` болон `deferred`. |
| `available`, `readable` | бүлийн | Зөвхөн `available` болон `expected_empty`. |
| `file_count` | бүхэл тоо | Хязгаарлагдмал бүртгэлтэй file/reference тоо. |
| `source_references` | массив | Ангилсан өвөрмөц эх сурвалж paths/references. |
| `detail` | мөр | Хязгаарлагдмал үр дүн эсвэл алдааны дэлгэрэнгүй. |
| `does_not_prove` | мөр | Хүртээмжтэй байх нь зорилго, эзэмшил, хохирол, давхардал эсвэл хэрэгжүүлэх баталгаа биш юм. |

Эх сурвалжийн ангиуд:

| Эх сурвалжийн анги | Хамрах хүрээ | Үүний хувь нэмэр юу вэ | Юуг баталж чадахгүй байна |
|---|---|---|---|
| `active_log` | одоо байгаа, шаардлагатай | Унших боломжтой идэвхтэй серверийн бүртгэл ба санал асуулгын шинэ үе. | Бүрэн түүх эсвэл тоглогчийн буруу. |
| `admin_ini` | одоогийн, сонголттой | Бүтцийн хувьд хүчинтэй гүйдэл moderator/ban төлөв эсвэл байхгүй байх. | Тоглогчийн зан байдал эсвэл хүчинтэй шалтгааны мета өгөгдөл. |
| `recent_backup_logs` | түүхэн | Унших боломжтой rotated/backup бүртгэлийн лавлагаа. | Одоо байгаа эсвэл одоогийн ачаалах төлөв. |
| `playerdata_filenames` | одоогийн контекст | Сонгосон Хадгалсан үндэс дор хязгаарлагдмал уншигдах боломжтой файлын нэрийн лавлагаа. | Файлын эзэмшилт, шууд байгаа байдал, таних контент эсвэл буруу үйлдэл. |
| `existing_cases` | түүхэн | Хадгалагдсан нэрлэсэн тохиолдол files/index одоогийн гаралтаас өмнө авсан бичлэг. | Одоогийн үйл ажиллагаа эсвэл хуучин дүгнэлтүүдийн зөв байдал. |
| `existing_reports` | түүхэн | Хадгалагдсан final/forensic/warning тайлангийн лавлагаа. | Эрх бүхий эх сурвалж солих. |
| `existing_evidence` | түүхэн | Хадгалагдсан нотлох баримтууд. | Сервер хэзээ ч ил гаргаж байгаагүй үйл явдлуудын бүрэн байдал. |
| `world_save_scan` | түүхэн | Бүрэн, хэсэгчилсэн, хойшлогдсон эсвэл боломжгүй хязгаарлагдмал scan/checkpoint төлөв. | Тоглогчийн тодорхой үйлдэл эсвэл эзэмшил. |

Эх төлөвийн утгууд:

| Төлөв | Терминал | Операторын утга ба үйлдэл |
|---|---:|---|
| `available` | тийм | Унших боломжтой ашигтай эх сурвалж байна; түүний лавлагааг шалгана уу. |
| `expected_empty` | тийм | Нэмэлт эх сурвалжийг шалгаж, хууль ёсны дагуу absent/empty. Өгөгдөл зохиож болохгүй. |
| `partial` | үгүй | Хязгаарлагдмал ажил эсвэл бараа материалын хязгаар бүрэн бус байна; үргэлжлүүлэхийг зөвшөөрнө үү. |
| `deferred` | үгүй | Ажил санаатайгаар хүлээгдэж байна; эзэмшигч ажилтнаа хүлээнэ үү. |
| `unavailable` | тийм | Source/path/tool байхгүй эсвэл ашиглах боломжгүй; зөвхөн замд шаардлагатай тохиолдолд засварлана. |
| `malformed` | тийм | Агуулгын бүтцийн баталгаажуулалт амжилтгүй болсон; хадгалж, форматыг засаарай. |
| `permission_denied` | тийм | Хандалтыг шууд хориглосон; хамгийн бага эрх унших эрхийг сэргээх. |
| `error` | тийм | Эх сурвалжийн түвшний хязгаарлагдмал probe/read гэнэтийн амжилтгүй болсон; шалгах `detail` нууцыг задлахгүйгээр. |

Дээд түвшний `coverage_status` нь яг `complete`, `complete_with_gaps`, `partial`, эсвэл `unavailable`. Шаардлагатай эх түвшний `error`, `malformed`, эсвэл `permission_denied` дээд түвшинд хүртэл эргэлддэг `unavailable`; эх түвшний `deferred` дээд түвшинд хүртэл эргэлддэг `partial`. Эх сурвалжийн бүртгэлийг идэвхгүй болгосноор боломжгүй статусыг бичиж, бүх маршрутыг `missing`.

<a id="historical-status-schema"></a>
## Түүхэн төлөвийн схем

`runtime/final_logs/historical_backfill_latest.json` нь `randomdayguard.history/v1`: `generated_ts`, нягтлан бодох бүртгэл `status`, `resumable=true`, `changed_file_refresh=true`, `current_evidence_is_not_history=true`, эх сурвалжийн нягтлан бодох бүртгэлийн массив, боломжгүй ангиуд, хязгаарлагдмал `next_action`.

`runtime/history/public_accounts.tsv` нь энэ гарчигтай олон нийтийн түүх юм:

```text
account_id	ban_id	display_name	identity_confidence	status	score	first_seen	last_seen	source_references
```

Мөрүүдийг бүртгэлийн ID-аар эрэмбэлсэн, талбарууд нь single-line/tab-safe, лавлагаа нь sorted/unique. Энэ файл нь чимээгүй дахин эхлүүлэх үед түүхэн нөхцөл байдлыг хадгалдаг; энэ нь түүхийг одоогийн байгаа байдалд хэзээ ч хувиргадаггүй.

<a id="route-proof-schema"></a>
## Маршрут нотлох схем

`runtime/final_logs/route_proof.json` нь `randomdayguard.route-proof/v1` ба дээд түвшний үеийн үеийн тэмдэг, хувилбар, ачаалах, эрин үе, санал асуулга, эх сурвалжийн шинэлэг байдал, одоогийн мөчлөгийн бүрэн байдал, зөвшөөрөгдсөн төлөвүүд болон `routes` массив.

Маршрутын оруулга бүр route/status, version/boot/epoch/poll, эх сурвалжийн шинэлэг байдлын объект, одоогийн мөчлөгийн бүрэн байдал, гаралтын замууд, эх сурвалжийн лавлагаа. Идэвхгүй болсон маршрутын бүртгэл `status="missing"` болон `reason="route_disabled"`. Маршрутын баталгаа бичих амжилтгүй бол зам бүрийг incomplete/missing ямар нэгэн мэдэгдлийн нэр дэвшигчийг хүлээн авахаас өмнө.

<a id="notification-schemas"></a>
## Мэдэгдэлийн схемүүд

Заавал биш нийтийн горим нь зөвхөн дотоод файлын гадагш илгээх хайрцаг юм.

`runtime/notifications/pending/<route>_latest.json` нь `randomdayguard.notification/v1` үүсгэсэн цагийн тэмдэгтэй, version/boot/epoch/ poll/source шинэлэг байдал, зам, `completed_output`, чиглүүлээгүй байдал, бүтэцлэгдсэн болон орчуулагдсан тайлангийн зам, эх сурвалжийн лавлагаа, `delivery_backend="none"` болон `delivery_attempted=false`. Зөвшөөрөгдсөн гаралтын хэрэглээ `status="ready_for_local_consumer"`, `delivery_eligible=true` болон `delivery_allowed=true`. Тохируулсан боловч missing/ineligible чиглүүлэлт нь `status="suppressed_current_cycle"`, хүргэлтийн туг хоёулаа худал ба `suppression_reason="route_or_completion_policy_blocked"`. Тиймээс `pending/` гэдэг нь дангаараа дараалалд орсон эсвэл шаардлага хангасан гэсэн үг биш юм.

`runtime/notifications/notification_status.json` нь `randomdayguard.notification-status/v1` ижил удамтай, `generic_local_outbox_only=true`, `delivery_attempted=false`, мөн маршрут тус бүрээр `queued`/`outcome` мөр. `full` эрхтэй; expect-empty нь зөвхөн `include_expected_empty=true`; `missing` хэзээ ч тохирохгүй. Маршрутгүй бичих алдааны төлөвийн үр дүн `route_proof_write_failed`; дарагдсан аудитын дугтуйг бичсэн хэвээр байж болох ч үүнийг хүлээн авахгүй.

## Алдаа болон сэргээх матриц

| Бүтэлгүйтэл | Шаардлагатай төлөв | Аюулгүй сэргээх | Буруу дүгнэлт |
|---|---|---|---|
| Одоогийн удам угсаа absent/stale | Бүх маршрутууд `missing`. | Сэргээх active-log/current-poll нотлох ба дахин үүсгэх. | Хуучин маршрутын файлууд одоогоор дуусаагүй байна. |
| Нэмэлт эх сурвалж хоосон байх төлөвтэй | Эх сурвалж `expected_empty`; зохих маршрут `limited_expected_empty`. | Эх сурвалж байхгүй бол засвар хийхгүй. | Хоосон байх боломжгүй бөгөөд байхгүй гэдгийг нотлохгүй. |
| Скан хийж дуусаагүй | Эх сурвалж `partial` эсвэл `deferred`. | Хязгаарлагдмал анкетыг зөвшөөрөх; Одоогийн маршрутын бодлогыг тодорхой байлгах. | Хэсэгчилсэн нь авлига биш юм. |
| Шаардлагатай эх сурвалж байхгүй | `coverage_status=unavailable`; хамааралтай замууд `missing`. | Засварыг сонгосон Saved/log хандалт. | Бусад эрүүл эх сурвалж шаардлагатай эх сурвалжийг орлохгүй. |
| Шаардлагатай эх сурвалж шалгах алдаа | Эх сурвалжийн төлөв `error` хязгаартай `detail`; `coverage_status=unavailable`; хамааралтай замууд `missing`. | Нэрлэсэн source/probe шинэ мөчлөг үүсгэнэ үү. | Эх сурвалжийн алдаа нь дээд түвшний хамрах хүрээний тав дахь утга биш юм. |
| Хосолсон тайлан бичих амжилтгүй | `coverage_status=unavailable`; маршрут `missing`. | Файлын системийг засч, хос гишүүн болон нотлох баримтыг хоёуланг нь дахин бичнэ үү. | Нэг дүүгийн файл дуусаагүй, бичих алдаа нь дээд түвшний биш байна `error`. |
| Чамшруулалтгүй бичих амжилтгүй | Дахин бичсэн маршрут бүр дутуу; зохих гадагшаа хайрцаг байхгүй; тохируулсан маршрутууд нь дарагдсан аудитын дугтуйг хүлээн авч болно. | Маршрутгүй бичихийг засварлаж, ижил мөчлөгийн гаралтыг сэргээнэ үү. | Хүчтэй харагдах тайлан JSON эсвэл дарагдсан дугтуй нь маршрутын баталгаа биш юм. |
| Мэдэгдэл бичих амжилтгүй | Үр дүн `local_outbox_write_failed`. | Дотоодын гаралтын үндэсийг засах; дууссан тайлангаас дахин үүсгэх. | Гадаад хүргэлт хийгдээгүй. |
| Admin.ini гүйлгээ амжилтгүй боллоо | Хэрэгжүүлэхийг backup/write/readback/rollback нотлох баримт. | Баталгаажсан нөөцлөлтийг сэргээх; зөвхөн хянан үзэх боломжтой хэвээр байна. | Босго хэмжээ эсвэл тайлан нь сэргээхийг тойрч гарах үндэслэл болохгүй. |
