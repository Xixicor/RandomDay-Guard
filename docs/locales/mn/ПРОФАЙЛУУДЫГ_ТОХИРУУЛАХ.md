# Тохиргооны профайл

> **Каноник англи эх сурвалж:** [CONFIG_PROFILES.md](../../CONFIG_PROFILES.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Практик тохиргооны профайлыг сонгох, хэрэглэхийн тулд энэ хэрхэн зааварчилгааг ашиглана уу. Тохируулгын бүлгүүд хэрхэн харилцдаг тухай тайлбарыг [`CONFIG_REFERENCE.md`](%D0%A2%D0%9E%D0%A5%D0%98%D0%A0%D0%93%D0%9E%D0%9E%D0%9D%D0%AB_%D0%9B%D0%90%D0%92%D0%9B%D0%90%D0%93%D0%90%D0%90.md). Яг талбарууд, өгөгдмөл, төрөл, өөрчлөгдөөгүй тохиолдолд үүсгэсэн [`CONFIG_FIELD_CATALOG.md`](%D0%A2%D0%9E%D0%A5%D0%98%D0%A0%D0%93%D0%9E%D0%9E%D0%9D%D0%AB_%D0%A2%D0%90%D0%9B%D0%91%D0%90%D0%A0%D0%AB%D0%9D_%D0%9A%D0%90%D0%A2%D0%90%D0%9B%D0%9E%D0%93.md).

Доорх Луа блок бүр нь ачуулсан доторх тохирох оруулгуудыг орлох дээд түвшний оруулгуудын багц юм `return { ... }` хүснэгт.

<a id="profile-chooser"></a>
## Профайл сонгогч

| Нөхцөл байдал | Энэ профайлыг ашиглах |
|---|---|
| Эхний суулгах | Эхлээд аюулгүй суулгах |
| Сервер тогтворгүй бөгөөд байнга гацдаг | Удаан хайлтгүй одоогийн нотлох баримт |
| Та хүсэж байна object/world контекст | Бүтэн суурь үзүүлэлт |
| Та хуучин бүртгэлүүдийг шалгахыг хүсэж байна | Шүүх эмнэлгийн нөхөн дүүргэлт |
| Та зөвлөмж өгөхийг хүсч байгаа ч бичихгүй | Хэрэгжүүлэх шалгалт |
| Та хамгаалагчид хориг бичихийг зөвшөөрөхөд бэлэн байна | Хэрэгжүүлэхийг идэвхжүүлсэн |
| Диск хязгаарлагдмал | Дискний өсөлт бага |
| Та цэвэр суурь үзүүлэлтийг дуусгасан | Наалттай нөөцлөлтийн тохиргоо |

<a id="safe-first-install"></a>
## Эхлээд аюулгүй суулгах

Үүнийг эхлээд шууд сервер дээр ашиглаарай.

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

log_tail = {
    enabled = true,
    start_at_end_on_first_run = true,
    tail_backup_logs = false,
},

scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

Энэ юу вэ:

```text
Tracks live sessions.
Starts the baseline scan.
Does not edit Admin.ini.
Avoids treating old backup logs as fresh live events.
```

<a id="current-evidence-without-slow-scan"></a>
## Удаан хайлтгүй одоогийн нотлох баримт

Хэрэв сервер тогтворгүй бөгөөд танд хэрэгтэй бол үүнийг ашиглаарай crash/reconnect хүнд скан хийхээс өмнө нотлох баримт.

```lua
log_tail = {
    enabled = true,
},

scanning = {
    full_scan_on_start = false,
},

enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

Энэ юу вэ:

```text
Tracks logins, joins, leaves, reconnects, crashes, and unclean sessions.
Delays heavy world scanning.
```

<a id="full-baseline"></a>
## Бүтэн суурь үзүүлэлт

Сервер скан хийхэд хангалттай удаан ажиллах боломжтой болсны дараа үүнийг ашиглана уу.

```lua
scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},
```

Энэ юу вэ:

```text
Builds object registry.
Writes world-state context.
Creates file manifest.
Enables changed-file refresh later.
```

<a id="forensic-backfill"></a>
## Шүүх эмнэлгийн нөхөн дүүргэлт

Үүнийг зөвхөн түүхийн бүртгэлийг зориудаар шалгах үед ашиглана уу.

```lua
log_tail = {
    start_at_end_on_first_run = false,
    tail_backup_logs = true,
    backfill_backup_logs_on_start = true,
},
```

Үүнийг ашиглахаас өмнө:

```text
Back up runtime/log_offsets.tsv.
Expect old events to be reprocessed.
Return to live settings when finished.
```

<a id="enforcement-testing"></a>
## Хэрэгжүүлэх шалгалт

Үүнийг бодит болохоос өмнө ашиглаарай Admin.ini бичих.

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},
```

Юуг шалгах вэ:

```text
runtime/account_evidence.json
runtime/warnings/
runtime/forensic_days/YYYY-MM-DD/ban_recommendations.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="enforcement-enabled"></a>
## Хэрэгжүүлэхийг идэвхжүүлсэн

Үүнийг зөвхөн хяналтын үр дүн зөв болсны дараа ашиглана уу.

```lua
enforcement = {
    review_only_mode = false,
    auto_ban = true,
    write_admin_ini = true,
    require_clean_ban_id = true,
    preserve_existing_bans = true,
    preserve_moderators = true,
},
```

Идэвхжүүлэхээс өмнө:

```text
Trusted IDs are configured.
Moderator IDs are preserved.
Admin.ini backups work.
Ban recommendations are understandable.
Thresholds are accepted by the server owner.
```

<a id="low-disk-growth"></a>
## Дискний өсөлт бага

Ажиллах үеийн файлууд хэт хурдан өсч байгаа үед үүнийг ашиглана уу.

```lua
logging = {
    low_importance_mode = "aggregate",
    write_low_importance_raw_events = false,
},

retention = {
    detailed_retention_days = 7,
    rotate_jsonl_when_bytes_exceed = 5242880,
    max_raw_events_lines = 20000,
    compact_json_outputs = true,
},
```

<a id="sticky-backup-setup"></a>
## Наалттай нөөцлөлтийн тохиргоо

Эхний дууссан үндсэн үзүүлэлтийн дараа ашиглана уу.

Эдгээр нь байгаа эсэхийг шалгана уу:

```text
runtime/scan_complete.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
runtime/world_state/current/world_state_latest.json
```

Дараа нь тэдгээрийг `config.lua`, `SavedRoot.txt` болон `Admin.ini`.
