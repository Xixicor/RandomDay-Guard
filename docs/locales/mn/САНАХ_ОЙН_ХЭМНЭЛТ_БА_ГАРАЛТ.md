# Санах ой хэмнэлт ба гаралтын файлууд

> **Каноник англи эх сурвалж:** [MEMORY_ECONOMY_AND_OUTPUTS.md](../../MEMORY_ECONOMY_AND_OUTPUTS.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Энэ хуудсанд ямар файл өсөх, ямар файлыг дарж бичих, хурдан шалгахын тулд юу байршуулахыг тайлбарлана.

<a id="fast-answer"></a>
## Шуурхай хариулт

| Асуулт | Нээлттэй |
|---|---|
| Харуул амьд уу? | `runtime/current/poll_status.json` |
| Хэн харсан бэ? | `runtime/account_evidence.json` |
| Сурцуудад юу тохиолдсон бэ? | `runtime/evidence/session_events.jsonl` |
| Өнөөдөр юу болсон бэ? | `runtime/forensic_days/YYYY-MM-DD/` |
| Энгийн хэлний хураангуй гэж юу вэ? | `runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt` |
| Скан хийх явц гэж юу вэ? | `runtime/scan_progress.json` |
| Дэлхийн нөхцөл байдал юу вэ? | `runtime/world_state/current/world_state_latest.json` |
| Ямар хоригууд бичигдсэн бэ? | `runtime/enforced_bans.jsonl` |

<a id="output-model"></a>
## Гаралтын загвар

| Төрөл | Зан төлөв | Жишээ |
|---|---|---|
| Одоогийн агшин зуурын зургууд | Дахин бичсэн | `runtime/current/*.json` |
| Үйл явдлын бүртгэл | Зөвхөн хавсаргах боломжтой | `runtime/evidence/*.jsonl` |
| Хүснэгтүүд | Шинэчлэгдсэн эсвэл хавсаргасан | `*.tsv` |
| Суурь үзүүлэлт | Дууссаны дараа дахин ашигласан | `runtime/baselines/*` |
| Өдөр тутмын цуваа | Одоо шинэчлэгдсэн | `runtime/forensic_days/YYYY-MM-DD/*` |
| Эцсийн бүртгэлүүд | Энгийн хэл дээрх өдөр тутмын хураангуй | `runtime/final_logs/YYYY-MM-DD/*` |

<a id="current-snapshots"></a>
## Одоогийн агшин зуурын зургууд

Эдгээр нь жижиг хэвээр байгаа бөгөөд "одоо юу үнэн бэ" гэж хариулдаг.

```text
runtime/current/poll_status.json
runtime/current/session_state.json
runtime/current/active_accounts.json
runtime/current/forensic_today.json
runtime/current/forensic_today.md
runtime/current/forensic_today.txt
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/world_state/current/world_state_latest.json
```

<a id="player-summaries"></a>
## Тоглогчийн хураангуй

Эдгээр нь бүртгэл шалгах эсэхийг шалгах эхний файлууд юм.

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

Тэдгээрийг нэгтгэн дүгнэж хэлэхэд:

```text
account_id
ban_id
name
identity_confidence
first_seen
last_seen
join_count
leave_count
status
score
```

<a id="event-logs"></a>
## Үйл явдлын бүртгэл

Эдгээр нь цагийн хуваарийг хадгалдаг.

```text
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/warning_events.jsonl
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/evidence/live_defense_events.jsonl
```

<a id="daily-forensic-rollups"></a>
## Өдөр тутмын шүүх эмнэлгийн багцууд

Эдгээр нь хурдан байршуулах багцууд юм.

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

Хурдан хугацааны шинжилгээ хийлгэхийг хүсвэл эдгээр фолдеруудын аль нэгийг байршуулна уу.

<a id="scan-and-baseline-files"></a>
## Скан хийж, үндсэн файлууд

Дэлхийн контекст хэсэгчилсэн эсвэл бүрэн эсэхийг ойлгохын тулд эдгээрийг ашиглана уу.

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/scan_complete.json
runtime/object_registry_partial.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
```

<a id="enforcement-files"></a>
## Хэрэгжүүлэх файлууд

Эдгээрийг зөвхөн хэрэгжилтийг идэвхжүүлсэн үед ашиглана уу.

```text
runtime/enforced.txt
runtime/enforced_bans.jsonl
runtime/ban_queue.json
runtime/evidence/enforced_bans.jsonl
```

`Admin.ini` зөвхөн хүлээн авах ёстой:

```ini
BannedPlayer=<ID>
```

<a id="what-updates-when-a-player-joins"></a>
## Тоглогч нэгдэх үед юу шинэчлэгдэх вэ

Хүлээгдэж буй шинэчлэлтүүд:

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/current/session_state.json
runtime/forensic_days/YYYY-MM-DD/players.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="what-updates-when-the-server-crashes-or-restarts"></a>
## Сервер гацах эсвэл дахин ачаалах үед ямар шинэчлэлт хийх вэ

Хүлээгдэж буй шинэчлэлтүүд:

```text
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/account_evidence.json
runtime/forensic_days/YYYY-MM-DD/crash_reconnects.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="what-updates-when-the-scan-progresses"></a>
## Скан хийх явцад ямар шинэчлэлтүүд гарах вэ

Хүлээгдэж буй шинэчлэлтүүд:

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/object_registry_partial.json
runtime/world_state/current/world_state_latest.json
runtime/forensic_days/YYYY-MM-DD/forensic_day_summary.json
```

<a id="what-to-upload-for-quick-analysis"></a>
## Шуурхай шинжилгээ хийхийн тулд юу байршуулах вэ

Шилдэг багц:

```text
runtime/final_logs/YYYY-MM-DD/
```

Илүү бүрэн багц:

```text
runtime/forensic_days/YYYY-MM-DD/
```

Бүрэн нотлох баримтын багц:

```text
runtime/account_evidence.json
runtime/evidence/session_events.jsonl
runtime/server_lifecycle_events.jsonl
runtime/warning_events.jsonl
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```
