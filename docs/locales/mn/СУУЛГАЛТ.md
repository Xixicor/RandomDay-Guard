# Суулгах RandomDayGuard

> **Каноник англи эх сурвалж:** [INSTALL.md](../../../INSTALL.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Энэ гарын авлагыг суулгана `v0.4.12-alpha` аль хэдийн ашигладаг Abiotic Factor зориулагдсан сервер дээр UE4SS. Мод нь нэг хостинг компани эсвэл хяналтын самбартай холбогдоогүй байна.

<a id="before-you-begin"></a>
## Эхлэхээсээ өмнө

Танд хэрэгтэй:

- зориулалтын серверийг зогсоож, эхлүүлэх боломжтой;
- серверийн UE4SS `Mods` хавтас;
- одоогийн хуулбар RandomDayGuard хавтас;
- Мод солихын өмнө таны ихэвчлэн хамгаалдаг серверийн өгөгдлийн нөөцлөлт.

The **Mods хавтас** нь `ue4ss/Mods/` лавлах. RandomDayGuard нь тухайн фолдерт шууд харьяалагддаг.

<a id="new-installation"></a>
## Шинэ суулгац

1. Зориулалтын серверийг зогсоо.
2. RandomDayGuard ZIP шинэ хоосон хавтас руу оруулна уу.
3. Тассаныг хуулах `RandomDayGuard` фолдерыг серверийн UE4SS `Mods` хавтас. Үр дүн нь нэг байх ёстой `Mods/RandomDayGuard/` хавтас, нэг секунд биш RandomDayGuard хавтас дотор нь суулгасан.
4. Нээх UE4SS `mods.txt` болон идэвхжүүлнэ үү:

   ```text
   RandomDayGuard : 1
   ```

5. Серверийг хэвийн эхлүүлнэ үү.
6. Хүлээгээрэй UE4SS болон тоглоомын серверийг эхлүүлж дуусгаад [Эхний тайланг уншина уу](%D0%AD%D0%9D%D0%94%D0%AD%D0%AD%D0%A1_%D0%AD%D0%A5%D0%AD%D0%9B.md).

Ажиллаж байгаа суулгац дээр шинэ хувилбарыг хуулж болохгүй. Шинэчлэгдсэн суулгац серверийн төлөвийн тайланг гаргах хүртэл нөөцлөлтийг хадгална уу.

<a id="update-an-existing-installation"></a>
## Одоо байгаа суулгацыг шинэчлэх

1. Серверийг зогсоо.
2. Бүрэн суулгасаныг хуулна уу RandomDayGuard фолдерыг аюулгүй нөөцлөх байршил руу шилжүүлнэ үү.
3. Хуучин програмын хавтсыг UE4SS `Mods`.
4. Шинэийг хуулах RandomDayGuard хавтсанд `Mods`.
5. Зөвхөн хянасан орон нутгийн тохиргоо болон хадгалсан нотолгоог сэргээнэ үү. Хэрэв тохиргооны гарын авлагад шинэ талбаруудыг жагсаасан бол бүх тохиргоог сохроор солихын оронд хянан үзсэн хуулбар руу нэгтгэнэ үү.
6. Баталгаажуулах `RandomDayGuard : 1` идэвхжсэн хэвээр байна.
7. Серверийг эхлүүлж, одоогийн серверийн төлөвийн тайланг уншина уу.

Энэхүү цэвэр хавтас шинэчлэлт нь оператороос програмын файлын нэрийг шалгахыг шаардахгүйгээр хуучин хувилбаруудаас хуучирсан файлуудыг устгадаг.

<a id="help-guard-find-the-server-records"></a>
## Харуулд серверийн бичлэгийг олоход тусална уу

Харуул ихэвчлэн абиотик хүчин зүйлийг олдог `Saved` лавлах автоматаар. Хэрэв чадахгүй бол `Saved` лавлах `SavedRoot.txt` дотор RandomDayGuard хавтас. `Saved`, түүнээс доош ганц бие даасан ертөнцөд биш.

Эхний серверийн төлөвийн тайланд бичлэгийн байршил олдсон эсэх, ямар эх сурвалжийн бүлгүүд боломжтой байсан тухай өгүүлдэг. [Алдааг олж засварлах](%D0%90%D0%9B%D0%94%D0%90%D0%90%D0%93_%D0%9E%D0%9B%D0%96_%D0%97%D0%90%D0%A1%D0%92%D0%90%D0%A0%D0%9B%D0%90%D0%A5.md) байршлыг унших боломжгүй үед.

<a id="first-run-behavior"></a>
## Анхны үйлдэл

Өгөгдмөл суулгац нь боломжтой бичлэгүүдийг харж, тайлан бичдэг. Энэ нь өөрчлөгдөхгүй `Admin.ini` эсвэл хориг нэмнэ үү. Энэ нь танд ямар нэгэн нэмэлт үйлдлийг идэвхжүүлэх эсэхээ шийдэхийн өмнө цуглуулга, орчуулга болон тайлангийн чанарыг баталгаажуулах боломжийг олгоно.

[Эхний тайланг уншина уу](%D0%AD%D0%9D%D0%94%D0%AD%D0%AD%D0%A1_%D0%AD%D0%A5%D0%AD%D0%9B.md)

<a id="disable-or-remove-randomdayguard"></a>
## Идэвхгүй болгох эсвэл устгах RandomDayGuard

1. Серверийг зогсоо.
2. Бүрэн хуулах RandomDayGuard фолдерыг аюулгүй архивт хадгална уу.
3. Модыг идэвхгүй болгохын тулд `RandomDayGuard : 0` UE4SS `mods.txt`.
4. Үүнийг арилгахын тулд RandomDayGuard хавтас `Mods` архивыг баталгаажуулсны дараа нээх боломжтой.
5. Серверийг эхлүүлээд Guard ажиллахаа больсон болохыг баталгаажуулна уу.

Хамгаалагчийг идэвхгүй болгох эсвэл устгах нь цаашид цуглуулах ажиллагааг зогсооно. Энэ нь тоглоомын өгөгдлийг устгах, архивлагдсан тайланг устгах, операторын тусдаа үйлдлийг буцаахгүй.

<a id="roll-back-an-update"></a>
## Шинэчлэлтийг буцаах

Хэрэв шинэ суулгац ачаалахгүй эсвэл одоогийн тайлан гаргаж чадахгүй бол:

1. Серверийг зогсоо.
2. Амжилтгүй суулгалтыг бүртгэлийг нь устгахгүйгээр хажуу тийш шилжүүлнэ үү.
3. Урьдчилсан шинэчлэлтийг бүрэн сэргээнэ үү RandomDayGuard хавтас.
4. Ижил нөөцлөлтөөс хянагдсан тохиргоо болон хадгалсан нотлох баримтыг сэргээнэ үү.
5. Мод идэвхжсэнийг баталгаажуулж серверийг эхлүүлнэ үү.
6. Дахин өөрчлөлт хийхээсээ өмнө сэргээгдсэн серверийн төлөвийн тайланг уншина уу.
