# Хувь нэмэр оруулж байна

> **Каноник англи эх сурвалж:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


RandomDayGuard нь задлан шинжлэгч, баримт бичиг, туршилт, олон нийтэд аюулгүй баталгаажуулалтын төвлөрсөн, давтагдах боломжтой сайжруулалтыг хүлээн авдаг. Өөрчлөлт бүрийг олон нийтийн төслийн гэрээнд хязгаарлаж, хамгийн түрүүнд хянадаг зан төлөвийг хадгал: Харуул явах ёстой `Admin.ini` өөрчлөгдөөгүй.

<a id="prepare-a-safe-workspace"></a>
## Аюулгүй ажлын байр бэлтгэх

1. Repository-г салгаж эсвэл клон хийж, төвлөрсөн салбар үүсгэ.
2. Дэмжигдсэн Python 3 орчуулагчийг суулгана уу. Lua-г өөрчлөхдөө Lua хөрвүүлэгчийг суулгана уу `luac -p` синтакс шалгах боломжтой.
3. [баримт бичгийн нүүр хуудас](%D0%91%D0%90%D0%A0%D0%98%D0%9C%D0%A2_%D0%91%D0%98%D0%A7%D0%98%D0%93.md), [архитектур](%D0%90%D0%A0%D0%A5%D0%98%D0%A2%D0%95%D0%9A%D0%A2%D0%A3%D0%A0.md) болон [нотлох баримтын хил хязгаар](%D0%9D%D0%9E%D0%A2%D0%9B%D0%9E%D0%A5_%D0%91%D0%90%D0%A0%D0%98%D0%9C%D0%A2%D0%AB%D0%9D_%D0%A5%D0%98%D0%9B_%D0%A5%D0%AF%D0%97%D0%93%D0%90%D0%90%D0%A0.md).
4. Шалгах `git status` хамааралгүй ажлыг засварлаж, хадгалахаас өмнө.
5. Зөвхөн синтетик эсвэл ариутгасан бэхэлгээ ашиглана уу.

Хувийн серверийн бүртгэл, Хадгалсан хавтас, тоглогчийн таниулбарыг хэзээ ч бүү илгээ, `Admin.ini`, хувийн мэдэгдлийн төгсгөлийн цэгүүд, итгэмжлэлүүд, хувийн замууд, ажиллах үеийн гаралт эсвэл хуулбарласан шууд нотлох баримтууд.

<a id="make-a-focused-change"></a>
## Төвлөрсөн өөрчлөлт хийх

- Одоо байгаа нэршил, формат, аюулгүй байдлын шалгалт болон модулийн эзэмшлийг дагаж мөрдөөрэй.
- Процедур эсвэл тодорхой баримт бүрт нэг каноник баримт бичгийн эзэмшигч байлга.
- Зан төлөв эсвэл нийтийн гаралт өөрчлөгдөх үед хэрэглэгчийн баримт бичиг болон жишээг шинэчилнэ үү.
- Боломжтой үед алдаа засахын тулд регрессийн тест нэмнэ үү.
- Бүртгэл баталгаажуулалт, итгэмжлэгдсэн дансны хамгаалалт, нөөцлөлт баталгаажуулалт, гаднах өөрчлөлт илрүүлэх, хадгалсан файлын харьцуулалт, сэргээх, эсвэл зөвхөн хянадаг өгөгдмөл тохиргоог ашиглан шалгалтын тэнцлийг гаргаж болохгүй.

<a id="run-the-relevant-checks"></a>
## Холбогдох шалгалтыг явуулна уу

Зөвхөн баримт бичигт өөрчлөлт оруулах бол дараахыг ажиллуулна уу:

```powershell
python -B tools\generate_documentation_audit.py --check
python -B -m unittest discover tests -p "test_documentation*.py"
git diff --check
```

Эх сурвалж, тохиргоо, баглаа боодол эсвэл туршилтын өөрчлөлтийн хувьд [Баталгаажуулалт ба хувилбарын хяналт](%D0%91%D0%90%D0%A2%D0%90%D0%9B%D0%93%D0%90%D0%90%D0%96%D0%A3%D0%A3%D0%9B%D0%90%D0%A5_%D0%93%D0%90%D0%A0%D0%93%D0%90%D0%A5.md), үүнд Lua синтакс шалгалт, репозиторын баталгаажуулалт, нийтийн дамжуулах хоолойн тест, нэгжийн тестийн бүрэн багц багтана. Алгассан эсвэл боломжгүй чек бүрийг мэдээлэх; үүнийг дамжуулсан гэж бүү тайлбарла.

<a id="submit-the-change-for-review"></a>
## Өөрчлөлтийг хянуулахаар илгээнэ үү

Зөвхөн бүх ялгааг шалгасны дараа төвлөрсөн татах хүсэлтийг нээнэ үү. Үүнд:

- асуудал ба төлөвлөсөн зан байдал;
- яг файлууд болон олон нийтийн гэрээнүүд өөрчлөгдсөн;
- ажиллуулах тушаалууд ба тэдгээрийн үр дүн;
- нууцлал, нийцтэй байдал, хэрэгжилтэд үзүүлэх нөлөө; болон
- үлдсэн хязгаарлалтууд эсвэл дараагийн ажил.

Өөрчлөлт нь тодорхой шаардаж, баталгаажуулахаас бусад тохиолдолд үүсгэсэн ажиллах үеийн нотлох баримтыг бүү оруул эсвэл архивыг гаргаж болохгүй. Хувь нэмэр нь гуравдагч этгээдийн сайт дээр гаргах, байршуулах, шууд серверийн туршилт, хэрэгжүүлэх арга хэмжээ эсвэл нийтлэхийг зөвшөөрөхгүй.

Эмзэг байдлын талаар мэдээлэх [хувийн хамгаалалтын маршрут](%D0%90%D0%AE%D0%A3%D0%9B%D0%93%D2%AE%D0%99_%D0%91%D0%90%D0%99%D0%94%D0%90%D0%9B.md), олон нийтийн асуудал эсвэл энгийн татах хүсэлт биш.
