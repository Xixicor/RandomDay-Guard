# Баталгаажуулах, гаргах

> **Каноник англи эх сурвалж:** [VALIDATION_AND_RELEASE.md](../../VALIDATION_AND_RELEASE.md). Энэ локалчлагдсан баримт бичиг нь яг командууд, замууд, түлхүүрүүд, төлөвийн утгууд, хэшүүд болон файлын нэрийг хадгалдаг. Хэрэв техникийн үг хэллэг өөр байвал англи эх сурвалжийг ашиглана уу.


Энэ хуудас нь хувь нэмэр оруулагчид болон хувилбарын засварлагчдад зориулагдсан болно. Серверийн операторууд суулгахын тулд эдгээр командыг ажиллуулах шаардлагагүй RandomDayGuard.

<a id="user-visible-proof"></a>
## Хэрэглэгчдэд харагдах баталгаа

Шинэ оператор суулгаж, серверийн төлөвийн анхны тайланг олж, тайлангийн таван маршрутыг ялгаж, жишээн дээр дурдсан нэг тодорхой үйлдлийг дагаж чадвал хувилбар нь ойлгомжтой болно. Уншигчийн даалгаврууд нь Git, PowerShell, Python эсвэл шалгах нийлбэрийн мэдлэг шаардах ёсгүй.

<a id="contributor-checks"></a>
## Хувь нэмэр оруулагчийн шалгалт

```powershell
python -B tools/validate_repo.py
python -B tools/test_public_pipeline.py
python -B -m unittest discover tests
```

Хэзээ `luac` боломжтой:

```powershell
luac -p RandomDayGuard/Scripts/main.lua
luac -p RandomDayGuard/Scripts/public_pipeline.lua
```

Луа бэхэлгээний туршилтууд нь ачигч, хуваарьлагч, тайлангийн маршрут болон нэмэлтүүдийг хамардаг Admin.ini гүйлгээ бичих. Гүйцэтгэх хэрэгсэл нь зөвхөн түр зуурын файлуудыг ашигладаг бөгөөд хэн болохыг баталгаажуулах, итгэмжлэгдсэн данснаас татгалзах, босго оноо, нөөцлөх, зэрэгцүүлэн өөрчлөхөөс татгалзах, дахин сэргээх, буцаах зэргийг баталгаажуулдаг.

<a id="package-proof"></a>
## Багцын баталгаа

```powershell
python -B tools/build_release_zip.py --check
git diff --check
```

- Бүх хувилбарын тэмдэглэгээ таарч байна `VERSION`.
- Зөвхөн одоогийн хувилбар нь `releases/`.
- The ZIP каноник `RandomDayGuard/Scripts/main.lua` зам ба жижиг үсгийн хувилбарт дуудагч байхгүй.
- Ажиллах үеийн гаралт, хувийн тохиргоо, итгэмжлэл, локал зам, кэш болон туршилтын олдворуудыг оруулаагүй болно.
- Олон нийтийн тохиргоо нь хэрэгжилтийг идэвхгүй болгосон тохиолдолд зөвхөн хянан үзэх боломжтой хэвээр байна.
- Таван ажилласан тайлангийн жишээ нь маршрутын эзэмшил болон хувилбарын туршилтын хэрэгсэлтэй нийцсэн хэвээр байна.
- ZIP байтыг агуулж, тодорхойлогч бөгөөд таарч `CHECKSUMS.sha256`.
- Бүх локал баримт бичгийн холбоосууд болон 27 хэлний оруулгын хуудсыг баталгаажуулна.

<a id="avoid-validation-environment-pitfalls"></a>
## Баталгаажуулах орчны алдаанаас зайлсхий

- Түр зуурын файлын маргаанаас зайлсхийхийн тулд репозитор бичих шалгалтыг цувралаар явуулна уу.
- Windows дээр давхардсан ачаалагч байгаа эсэхийг шалгахдаа жижиг жижиг үсгээр хайлт хийхээс илүү архивласан гишүүний нэр эсвэл тоологдсон замын зөв бичгийн дүрмийг шалгана уу.
- Дутуу `luac` команд эсвэл Lua ажиллах хугацаа нь синтакс эсвэл ажиллах үеийн тест биш харин боломжгүй боломж юм.
- Бэхлүүр нь зөвхөн загварчилсан оролтыг баталгаажуулдаг. Энэ нь шууд сервер одоогийн тайлан гаргасан болохыг нотлохгүй.
- Дууссан гэж бодохын оронд командын завсарлага болон хэсэгчилсэн гаралтыг тэмдэглэ.

<a id="repair-failed-repository-validation"></a>
## Амжилтгүй болсон репозиторын баталгаажуулалтыг засна

Эхний мэдээлсэн зам эсвэл гэрээгээр эхэл. Энэ зүйлийг засч, нарийн тестийг дахин ажиллуулж, дараа нь бүрэн матрицыг дахин ажиллуулна уу. Шаардагдах тестийг устгаснаар дутуу чадавхийг бүү нуу.

<a id="known-limits-and-release-decision"></a>
## Мэдэгдэж буй хязгаарлалт ба хувилбарын шийдвэр

Орон нутгийн шалгалтууд нь эх сурвалж, бэхэлгээ, багц болон баримт бичгийн гэрээг нотолж байна. Тодорхой серверийн суулгац, удаан хугацааны тогтвортой байдлын цонх эсвэл үйлчлүүлэгчийн дэлгэц нь тусдаа нэгтгэх үр дүнг шаарддаг. Тохирох зарга гаргахаасаа өмнө уг үр дүнг бүтээх, тохиргоо, үргэлжлэх хугацаа болон ажиглагдсан гаралтын хамт тэмдэглэнэ үү.
