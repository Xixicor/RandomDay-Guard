# RandomDayGuard Dokumentation

> **Kanonisch-englische Quelle:** [README.md](../../README.md). Diese lokalisierte Dokumentation bewahrt genaue Befehle, Pfade, Schlüssel, Statuswerte, Hashes und Dateinamen. Wenn der technische Wortlaut abweicht, verwenden Sie die englische Quelle.


RandomDayGuard liest Datensätze von einem dedizierten Abiotikfaktor-Server und wandelt sie in separate Berichte für den Serverzustand, den täglichen Verlauf, Spielersitzungen, Überprüfungsfälle und Guard-Fehler um.
