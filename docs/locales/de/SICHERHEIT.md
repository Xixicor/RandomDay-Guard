# Sicherheitsrichtlinie

> **Kanonisch-englische Quelle:** [SECURITY.md](../../../SECURITY.md). Diese lokalisierte Dokumentation bewahrt genaue Befehle, Pfade, Schlüssel, Statuswerte, Hashes und Dateinamen. Wenn der technische Wortlaut abweicht, verwenden Sie die englische Quelle.


<a id="report-a-vulnerability-privately"></a>
## Eine Schwachstelle privat melden

Verwenden Sie [GitHubprivate Schwachstellenberichterstattung](https://github.com/Xixicor/RandomDay-Guard/security/advisories/new) um einen vertraulichen Bericht an den Repository-Eigentümer zu senden. Wenn dieses Formular nicht verfügbar ist, verwenden Sie [Öffentlicher Eigentümer GitHubProfil](https://github.com/Xixicor) zum Anfordern eines privaten Kontaktkanals ohne Angabe von Schwachstellendetails.

Öffnen Sie kein öffentliches Problem, das Exploit-Schritte, Anmeldeinformationen, private Serverpfade, Spielerkennungen, `Admin.ini`, gespeicherte Daten, Webhook-URLs oder Live-Beweisdateien enthält.

<a id="include-useful-evidence"></a>
## Nützliche Beweise einschließen

Stellen Sie Folgendes bereit:

- die Betroffenen RandomDayGuardVersion oder Commit;
- die betroffene Komponente und das erwartete sichere Verhalten;
- minimale Reproduktionsschritte mit bereinigten Vorrichtungen;
- die beobachteten Auswirkungen und ob sie wiederholbar sind; und
- alle vorgeschlagenen Abhilfemaßnahmen, die keine privaten Daten preisgeben.

Versenden Sie keine echten Geheimnisse. Ersetzen Sie private Pfade, Konto-IDs, Hostnamen und Token durch eindeutige Platzhalter und bewahren Sie dabei die Struktur auf, die zur Reproduktion des Problems erforderlich ist.

<a id="expect-review-first-handling"></a>
## Erwarten Sie, dass die Überprüfung zuerst erfolgt.

Ein Bericht ist ein Beweis für die Überprüfung durch den Betreuer, nicht für die Berechtigung, auf einen Server zuzugreifen, ein Live-Ziel zu testen, Exploit-Details zu veröffentlichen oder fehlgeschlagene Standardeinstellungen zu schwächen. Der Eigentümer validiert den Umfang und koordiniert die Offenlegung durch den privaten Bericht.
