# FAQ

> **Канонический английский источник:** [FAQ.md](../../FAQ.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


<a id="is-randomdayguard-the-randomday-mod"></a>
## Есть RandomDayGuard RandomDay Мод?

Нет. RandomDay Мод меняет работу сервера. RandomDayGuard наблюдает за уровнем доказательств сервера.

<a id="does-live-defense-work-before-the-scan-completes"></a>
## Срабатывает ли живая защита до завершения сканирования?

Да. Живая защита использует журналы и события сеанса. Базовое сканирование позже улучшит контекст.

<a id="why-can-the-first-scan-take-a-long-time"></a>
## Почему первое сканирование может занять много времени?

При первом сканировании создается world/object контекст, манифесты файлов и повторно используемые базовые данные.

<a id="what-do-i-check-first-after-startup"></a>
## Что мне проверить в первую очередь после запуска?

```text
runtime/current/poll_status.json
```

Ищите:

```text
scheduler_status=running
poll_id increasing
poll_in_flight=false
```

<a id="where-are-player-summaries"></a>
## Где находится игрок сводки?

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

<a id="where-is-the-daily-quick-review-package"></a>
## Где ежедневный пакет быстрого просмотра?

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

<a id="which-file-should-i-upload-for-fastest-review"></a>
## Какой файл следует загрузить для быстрого просмотра?

```text
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="can-it-write-bans-automatically"></a>
## Может ли он автоматически записывать баны?

Только если явно включен.

По умолчанию:

```lua
review_only_mode = true
auto_ban = false
write_admin_ini = false
```

<a id="what-does-adminini-receive"></a>
## Что означает Admin.ini получать?

Только:

```ini
BannedPlayer=<ID>
```

Нет имен, комментариев, причин или суффиксов.

<a id="is-a-display-name-enough-to-ban"></a>
## Достаточно ли отображаемого имени для бана?

Нет. Используйте журнал сервера `Login request` с помощью `ConnectID` или эквивалентное свидетельство сервера.

<a id="can-one-crash-ban-someone"></a>
## Можно ли кого-то заблокировать в аварийном режиме?

Нет по умолчанию.

<a id="can-object-count-alone-ban-someone"></a>
## Может ли заблокировать кого-то только подсчет объектов?

Нет по умолчанию.

<a id="should-savedroottxt-point-to-the-world-folder"></a>
## Должен SavedRoot.txt указывать на мир папка?

Нет. Наведите на него `AbioticFactor/Saved`.

<a id="what-if-the-world-folder-changes"></a>
## Что если изменится мировая папка?

Считайте это изменением базовой идентификации. Сохраните старый базовый показатель и создайте новый.
