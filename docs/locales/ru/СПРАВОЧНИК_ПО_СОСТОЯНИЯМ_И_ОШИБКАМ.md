# Справочник по состоянию и ошибкам

> **Канонический английский источник:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


Используйте эту ссылку после того, как симптом был классифицирован в [Устранение неполадок](%D0%A3%D0%A1%D0%A2%D0%A0%D0%90%D0%9D%D0%95%D0%9D%D0%98%D0%95_%D0%9D%D0%95%D0%9F%D0%9E%D0%9B%D0%90%D0%94%D0%9E%D0%9A.md). Прочтите структурированный файл состояния, указанный в ошибке. Отдельные коды представляют отдельные состояния безопасности и жизненного цикла; не сворачивайте их в общий результат «Ошибка защиты».

<a id="route-and-source-states"></a>
## Состояния маршрута и источника

| Значение | Значение | Ответ оператора |
|---|---|---|
| `full` | Контракт маршрута завершен с подтверждением источника текущего цикла. | Прочитайте границу доказательства маршрута; восстановление не подразумевается. |
| `limited_expected_empty` | Маршрут завершен, и отсутствующее действие является допустимым для этого цикла. | Не должно создаваться синтетическое player/case событие. |
| `missing` | Отсутствуют необходимые выходные данные, поле происхождения или подтверждение источника. | Проверьте причину маршрута и состояние именованного источника. |
| `available` | Именованный источник был доступен для чтения и использования. | Нет действие. |
| `expected_empty` | Источник был проверен и на законных основаниях не имел строк. | Никаких действий, если активность не ожидалась независимо. |
| `partial` / `complete_with_gaps` | Полезные доказательства существуют, но именованные исходные классы являются неполными. | Ограничивайте выводы собранными доказательствами. |
| `deferred` | Ограниченная работа запланирована для более позднего исполнителя возможность. | Перед изменением конфигурации подтвердите прогресс. |
| `unavailable` | Среда не предоставила источник. | Запишите лимит; исправьте только проверенный путь или проблему с разрешениями. |
| `malformed` | Источник был доступен для чтения, но не прошел структурную проверку. | Сохраните его и исправьте источник; не угадывайте. |
| `permission_denied` | Источник существует, но не может быть прочитан. | Предоставьте только узкое необходимое разрешение на чтение. |
| `error` | Сбор не удался по записанной причине. | Сохраните ошибку и диагностируйте этот этап. |

<a id="playerdata-and-inventory-codes"></a>
## PlayerData и коды инвентаря

| Код | Значение | Безопасный ответ |
|---|---|---|
| `saved_root_unavailable` | Ни один проверенный сохраненный корень не был доступен общедоступному конвейеру. | Исправьте `SavedRoot.txt` и перепроверьте зонд пути. |
| `unsafe_playerdata_root` | PlayerData обнаружение разрешено снаружи ограниченный сохраненный корень. | Исправьте путь; никогда не ослабляйте границу. |
| `playerdata_discovery_not_run` | Ограниченный рабочий процесс обнаружения еще не запущен. | Проверьте планировщик и ход выполнения рабочего процесса. |
| `playerdata_discovery_read_failed:*` | Не удалось прочитать выходные данные обнаружения. | Сохраните детали суффикса и проверьте команду ограниченной инвентаризации. |
| `inventory_command_open_failed` | Процесс инвентаризации не удалось выполнить быть запущен. | Убедитесь, что среда выполнения предоставляет настроенный командный мост. |
| `inventory_command_read_failed` | Ошибка вывода инвентаризации во время чтения. | Сохраните частичный вывод и повторите запуск только после устранения основной ошибки. |
| `inventory_command_close_failed` | Инвентаризация завершена без заслуживающего доверия результата закрытия. | Лечить источник неполный. |
| `identity_ledger_row_limit_exceeded` | Долговременный ввод идентификационных данных превысил границы общественной безопасности. | Архивируйте и просмотрите реестр; не сокращайте его молча до полного доказательства. |

<a id="adminini-enforcement-codes"></a>
## Admin.ini Коды принудительного исполнения

Все коды в этом разделе являются аварийно-закрытыми. Они сами по себе не санкционируют блокировку вручную.

| Код | Значение | Безопасный ответ |
|---|---|---|
| `admin_ini_write_disabled` / `admin_ini_disabled` | Общественно безопасные шлюзы записи отключены. | Ожидается только для просмотра. |
| `admin_ini_backup_disabled` / `backup_safety_gate_disabled` | Требуемая политика резервного копирования не активна. | Оставлять записи отключенными. |
| `enforcement_disabled` / `ban_on_threshold_disabled` / `auto_ban_disabled` | Один явный шлюз принудительного исполнения — выключено. | Ожидается в настройках по умолчанию, предназначенных только для публичного просмотра; не интерпретируйте это как ошибку записи. |
| `review_only_mode_enabled` | Режим только для просмотра намеренно блокирует мутацию. | Просматривайте только доказательства. |
| `duplicate_prevention_disabled` | Защита от дублирования отключена. | Оставлять запись отключенной до тех пор, пока не будет восстановлен шлюз безопасности. |
| `readback_safety_gate_disabled` / `rollback_safety_gate_disabled` | Проверка после записи или защита от отката отключены. | Оставить запись отключенной; никогда не обходите эти шлюзы. |
| `clean_id_safety_gate_disabled` / `account_specific_evidence_gate_disabled` | Чистая идентификационная информация или проверка конкретных учетных записей отключена. | Восстановите шлюз перед любой принудительной проверкой. |
| `moderator_preservation_disabled` / `existing_ban_preservation_disabled` | Сохранение защищенной учетной записи или существующего запрета было отключено. | Оставлять записи отключенными. |
| `clean_numeric_identity_required` | Предлагаемый идентификатор не является полной принятой формой подключения или чистым числовым идентификатором. | Получить проверенное сопоставление; никогда не обрезайте произвольный префикс. |
| `identity_strength_below_minimum` | Доказательство личности слабее настроенного порога. | Просматривайте только доказательства. |
| `playerdata_verification_required` | Конфигурация требует PlayerData подтверждения, а у учетной записи его нет. | Оставьте кандидата только для проверки; не делайте вывод о владельце по имени файла. |
| `trusted_or_moderator_identity` | Учетная запись защищена статусом доверенного или модератора. | Запись запрещена. |
| `admin_ini_path_invalid` / `admin_ini_path_outside_saved_root` | Целевой путь недействителен или выходит за пределы сохраненного корня. | Правильная конфигурация; никогда не обходите защиту пути. |
| `admin_ini_unavailable` | Внутри сохраненного корня не обнаружено настроенных для чтения Admin.ini. | Исправьте ограниченный путь или отключите принудительное применение. |
| `admin_ini_read_failed` | Не удалось прочитать авторитетные байты. | Остановить раньше мутация. |
| `admin_ini_parse_failed` | Admin.ini проверка не удалась без более конкретного структурного кода. | Сохраните файл и проверьте его раздел и структуру строк. |
| `admin_ini_contains_nul` | Файл содержит NUL байт и не принимается как текст. | Сохраните файл и исправьте его вне Guard. |
| `admin_ini_duplicate_banned_players_section` | Существует более одного `[BannedPlayers]` раздела. | Объединить разделы вручную, пока они остановлены. |
| `admin_ini_banned_player_outside_section` | Снаружи появляется строка запрета `[BannedPlayers]`. | Исправьте макет вручную. |
| `admin_ini_invalid_banned_player_line` | Строка запрета не совсем чистая поддерживаемая строка идентификатора. | Исправьте неверную строку. |
| `admin_ini_backup_failed` | Уникальная резервная копия не записывалась и не считывалась вернуть идентично байт. | Мутация не допускается. |
| `admin_ini_external_change_detected` | Другой автор изменил файл после снимка Guard. | Сохраните внешние байты и повторите попытку только после координации авторов. |
| `atomic_rename_unavailable` | Запрошена атомарная замена, но Lua не предоставила `os.rename`. | Никакой записи не доверяют; используйте поддерживаемую среду выполнения или отключите принудительное применение. |
| `admin_ini_write_failed` | Управляемая замена не завершена. | Проверьте записанную ошибку замены и резервную копию. |
| `post_write_verification_failed` | Рабочие байты не соответствуют кандидату. | Проверьте `rollback_success` и `rollback_refused_external_change` перед любым действием. |

<a id="startup-scheduler-and-backlog-states"></a>
## Состояния запуска, планировщика и невыполненной работы

Эти значения свидетельствуют о жизненном цикле, а не о маршруте. Прочитайте их вместе с текущими файлами опроса, отчета-работника и маршрутизации.

| Значение | Значение | Безопасный ответ |
|---|---|---|
| `not_started` | Именованный этап запуска или планировщика не начался. | Во время запуска дождитесь задокументированного интервала; после этого проверьте первую неизмененную фазу. |
| `main_lua_loaded` / `starting` | Запустился канонический загрузчик, и Guard перешел в автозагрузку. | Перейдите к более поздним фазам; само по себе это не является готовностью. |
| `saved_root_found` / `log_tail_initialized` / `epoch_started` | Продвинута инициализация основного источника и непрерывности. | Никаких действий, пока следующий этап не прекратит продвижение. |
| `admin_state_written` / `playerdata_index_written` | Первоначальные ограниченные индексы были экспортированы. | Нет действий; передача обслуживания планировщика все равно должна последовать. |
| `watchdog_started` | Сторожевой таймер отчета и опроса был зарегистрирован. | Подтвердите ход выполнения планировщика и опроса. |
| `ready_degraded` / `scan_running` | Защита работает, а ограниченное историческое сканирование остается ожидающим. | Внимание, а не сбой; проверить прогресс счетчиков прогресса. |
| `ready` | Запуск и текущее ограниченное сканирование достигли состояния готовности. | Проверьте подтверждение маршрута отдельно. |
| `scan_failed` / `error` | Запуск или сканирование завершено с зарегистрированной ошибкой. | Сохраните указанную ошибку или файл состояния и диагностируйте этот этап. |
| `running` |  планировщику принадлежат будущие возможности опроса. | Подтвердите, что `poll_id` и `poll_completed_count` заранее. |
| `manual_only` | Циклическое планирование было недоступно; может выполняться только явная работа. | Считать автоматическую операцию недоступной. |
| `stopped` | Операция планировщика завершена. | Перед перезапуском проверьте предыдущую остановку и свидетельства ошибок. |
| `active_log_caught_up` | Непрочитанного журнала активного журнала не осталось. | Историческое сканирование может выполняться продолжить. |
| `active_log_unavailable_nonblocking` | Активный журнал отсутствовал, но запуск остался неблокирующим. | Запишите ограничение источника и проверьте другие источники. |
| `active_log_read_failed` | Активный журнал существовал, но не мог быть прочитан. | Сохраните ошибку и исправьте только проверенный путь или проблему с разрешениями. |
| `budget_exhausted` / `active_log_has_unread_bytes` | Ограниченный хвостовой проход остановлен, а невыполненная работа осталась. | Подтвердить последующие опросы уменьшают количество непрочитанных count. |
| `offset_commit_failed_after_events_applied` | События были обработаны, но устойчивое сохранение смещения журнала не удалось. | Принудительное исполнение отложено; восстановить хранилище смещения, прежде чем полагаться на другой цикл. |

<a id="scheduler-report-and-notification-codes"></a>
## Коды планировщика, отчета и уведомления

| Код или статус | Значение | Безопасный ответ |
|---|---|---|
| `poll already in flight` | Второй обратный вызов поступил, когда жизненный цикл принадлежал текущему опросу. | Подтвердите продвижение существующего опроса; не добавляйте другого владельца цикла. |
| `no_log_files_found` | Не обнаружено настроенного активного или резервного журнала. | Проверьте сохраненную корневую и исходную конфигурацию. |
| `current_poll_error` | В текущем цикле зафиксирован сбой источника опроса. | Читать `runtime/current/poll_error.json`. |
| `cadence_deferred` | Диспетчер завершения еще не настал. | Ожидается до следующей ограниченной возможности. |
| `reports_disabled` | Генерация общедоступных отчетов отключена. | Включите, только если предназначены отчеты. |
| `local_outbox_write_failed` | Переведенный локальный конверт не может быть записан. | Восстановите выходной каталог среды выполнения; это не ошибка транспорта уведомления. |
| `source_accounting_disabled` | Доказательство маршрута не может претендовать на полное покрытие источника. | Включите учет источника или явно примите отсутствующее доказательство. |
| `route_disabled` | Маршрут намеренно отключен. | Для этого маршрута доставка не ожидается. |
| `poll_owner_between_polls` | Обработчик отчета поставлен в очередь из-за заданного планировщиком перерыва между опросами. | Ожидается только в то время, пока временные метки и курсоры продолжают перемещаться. |
| `unsafe_shell_path` | Ограниченный инвентарь или путь оболочки не прошли проверку безопасности платформы. | Исправьте путь; никогда не ослабляйте кавычки или проверку пути. |
