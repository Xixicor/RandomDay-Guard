# Изменения папки сохранения мира

> **Канонический английский источник:** [WORLD_SAVE_FOLDER_CHANGES.md](../../WORLD_SAVE_FOLDER_CHANGES.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


Используйте эту страницу при изменении активной папки мира.

<a id="normal-layout"></a>
## Обычный макет

```text
Saved/SaveGames/Server/Worlds/<WorldName>/
```

`SavedRoot.txt` по-прежнему должен указывать на:

```text
AbioticFactor/Saved
```

не мир папка.

<a id="case-1-same-world-renamed"></a>
## Случай 1: переименован тот же мир

Пример:

```text
Worlds/OldName/
Worlds/NewName/
```

Ожидаемое поведение:

```text
Reuse cached evidence where fingerprints match.
Rescan files whose path/cache no longer matches.
Preserve old evidence.
```

<a id="case-2-different-world-or-restored-backup"></a>
## Случай 2: другой мир или восстановленная резервная копия

Ожидаемое поведение:

```text
Preserve old completed baseline.
Start a new baseline generation.
Do not overwrite old baseline until the new one completes.
```

<a id="case-3-partial-scan-existed-before-the-change"></a>
## Случай 3: частичное сканирование существовало до изменения

Ожидаемое поведение:

```text
Mark the old checkpoint stale.
Preserve partial evidence.
Start a new baseline for the current world.
```

<a id="case-4-completed-baseline-existed-before-the-change"></a>
## Случай 4: завершенное базовое состояние существовало до изменения

Ожидаемое поведение:

```text
Load the old baseline for visibility.
Mark it as previous-world context.
Build a new baseline safely.
```

<a id="what-to-check"></a>
## Что проверить

```text
runtime/scan_checkpoint.json
runtime/scan_progress.json
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
runtime/world_state/current/world_state_latest.json
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```
