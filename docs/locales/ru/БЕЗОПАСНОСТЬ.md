# Политика безопасности

> **Канонический английский источник:** [SECURITY.md](../../../SECURITY.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


<a id="report-a-vulnerability-privately"></a>
## Сообщить об уязвимости лично

Используйте [GitHub частные отчеты об уязвимостях](https://github.com/Xixicor/RandomDay-Guard/security/advisories/new), чтобы отправить конфиденциальный отчет владельцу репозитория. Если эта форма недоступна, используйте [общедоступный GitHub профиль владельца](https://github.com/Xixicor) для запроса частного контактного канала без указания сведений об уязвимости.

Не открывайте общедоступную проблему, содержащую шаги использования эксплойта, учетные данные, пути к частному серверу, идентификаторы игроков, `Admin.ini`, сохраненные данные, URL-адреса веб-перехватчиков или файлы живых доказательств.

<a id="include-useful-evidence"></a>
## Включите полезные доказательства

Укажите:

- затронутую RandomDayGuard версию или фиксацию;
- затронутый компонент и ожидаемое безопасное поведение;
- минимальные шаги воспроизведения с использованием очищенных приспособлений;
- наблюдаемое воздействие и его повторяемость; и
- любые предлагаемые меры по смягчению последствий, которые не раскрывают личные данные.

Не отправляйте настоящие секреты. Замените частные пути, идентификаторы учетных записей, имена хостов и токены понятными заполнителями, сохранив при этом структуру, необходимую для воспроизведения проблемы.

<a id="expect-review-first-handling"></a>
## Ожидайте обработки в первую очередь

Отчет является свидетельством для проверки сопровождающим, а не авторизации для доступа к серверу, тестирования активной цели, публикации сведений об эксплойте или ослабления настроек по умолчанию, закрывающихся при сбое. Владелец будет проверять объем и координировать любое раскрытие информации через личный отчет.
