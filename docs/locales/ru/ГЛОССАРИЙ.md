# Глоссарий

> **Канонический английский источник:** [GLOSSARY.md](../../GLOSSARY.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


| Срок | Простой смысл | Точное техническое значение |
|---|---|---|
| Активный журнал | Текущий журнал сервера, используемый для новых доказательств. | Обязательный `active_log` источник; для завершения маршрута необходима читаемость плюс текущая линия происхождения. |
| Идентификатор загрузки | Один запуск сторожевого процесса. | Текущий идентификатор времени выполнения, используемый для отклонения предыдущей загрузки errors/reports. |
| Идентификатор эпохи | Один интервал непрерывности сервера. | Идентификатор, охватывающий нормальное время выполнения, пока логика непрерывности не начнет новую эпоху. |
| Идентификатор опроса | Одна ограниченная возможность опроса. | Поле положительного монотонного цикла; zero/missing не может завершить маршрут. |
| Новизна источника | Согласуется ли текущий источник и происхождение опроса. | `fresh_current_poll` или `stale_or_unproven` с временными метками и статусом активного журнала. |
| Учет источников | Инвентаризация доступности и ограничений доказательств. | `randomdayguard.source-accounting/v1` с восемью исходными классами и current/historical областью действия. |
| `available` | Источник найден и прочитан. | Состояние источника терминала с `available=true`, `readable=true`. |
| `expected_empty` | Необязательный источник проверен и является законным absent/empty. | Статус источника, читаемого терминалом; никогда не создает предмет. |
| `partial` | Ограниченная работа дает полезные, но неполные результаты. | Нетерминальный source/accounting статус; возобновите рабочий процесс-владелец. |
| `deferred` | Работа намеренно отложена. | Состояние нетерминального источника; это не ошибка или завершение. |
| `unavailable` | Источник в настоящее время не может быть использован. | Пробел в терминале; разрыв обязательного источника делает учет невозможным. |
| `malformed` | Источник существует, но структурно недействителен. | Разрыв терминала сохраняет детали проверки и закрывает зависимые записи. |
| `permission_denied` | Операционная система явно отклонила доступ. | Разрыв терминала отличается от missing/unavailable. |
| `error` | A ограниченная операция неожиданно завершилась неудачей. | Сбой терминала, требующий именованного восстановления; никакие секретные детали не должны содержаться в общедоступных отчетах. |
| `complete` | Все учтенные источники являются окончательными и не имеют пробелов. | Состояние учета источника верхнего уровня. |
| `complete_with_gaps` | Требуемые текущие доказательства работают; необязательные пробелы в терминалах остаются. | Состояние учета верхнего уровня; маршруты по-прежнему применяют свои собственные требования. |
| `full` | Маршрут завершен с обязательным непустым контрактом. | Перечисление доказательства маршрута с завершенными выходными данными текущего цикла. |
| `limited_expected_empty` | Маршрут завершен, но не найдено ни одного подходящего subject/failure. | Перечисление доказательства маршрута с помощью `completed=true`, `expected_empty=true`. |
| `missing` | Доказательство завершения маршрута отсутствует или не выполнено. | Перечисление доказательства маршрута с помощью `completed=false`; никогда не имеет права на исходящие. |
| Структурированный отчет | Машиночитаемый вывод маршрута. | `<route>_latest.json` с помощью `randomdayguard.report/v1`. |
| Переведенный отчет | Человекочитаемая визуализация того же маршрута. | `<route>_latest.txt` с фиксированным порядком наблюдаемых ссылок на источники. |
| Подтверждение маршрута | Журнал выполнения перекрестных маршрутов. | `route_proof.json` привязка version/boot/epoch/poll/freshness/output пути. |
| Текущие доказательства | Наблюдение, принадлежащее активному циклу. | Область применения `current`; не реконструирован из старого filenames/reports. |
| Исторические свидетельства | Сохранен контекст из предыдущих циклов или медленного сканирования. | Область применения `historical`; может сообщать о проверке, но не может претендовать на текущее присутствие. |
| Только просмотр | Предоставить доказательства проверки без Admin.ini записями. | по умолчанию `review_only_mode=true`, `auto_ban=false`, `write_admin_ini=false`. |
| проверки безопасности списка банов | Один вопрос Охранник должен ответить, прежде чем он может измениться `Admin.ini`. | Он должен подтвердить учетную запись и оценку, исключить доверенные учетные записи и дубликаты, проверить резервную копию, обнаружить внешние изменения, сохранить запланированное обновление, а также проверить или безопасно восстановить полный файл. |
| локальному исходящему ящику | Необязательная передача уведомлений, не зависящая от поставщика. | JSON файлы с `delivery_backend="none"` и `delivery_attempted=false`. |
| базовым уровнем | Завершенный ограниченный моментальный снимок контекста сохраненного файла. | Manifest/object/world состояние повторно используется только в том случае, если оно совместимо и достаточно свежее. |
| Контрольная точка | Возобновить позицию для незавершенной работы сканирования. | `scan_checkpoint.json`; удаление не является восстановлением по умолчанию. |
| Перестраиваемый индекс | Сводка, которую можно создать заново. | Daily/weekly/forensic/final просмотрите выходные данные; свидетельства источника остаются авторитетными. |
| Граница доказательств | Ограничение того, что может поддерживать источник. | Явные `does_not_prove`, неизвестные, сила идентичности и правила области. |

Канонические определения схем находятся в [`OUTPUT_SCHEMA_REFERENCE.md`](%D0%A1%D0%9F%D0%A0%D0%90%D0%92%D0%9E%D0%A7%D0%9D%D0%98%D0%9A_%D0%9F%D0%9E_%D0%A1%D0%A5%D0%95%D0%9C%D0%95_%D0%92%D0%AB%D0%92%D0%9E%D0%94%D0%90.md); Условия конфигурации приведены в [`CONFIG_FIELD_CATALOG.md`](%D0%9A%D0%90%D0%A2%D0%90%D0%9B%D0%9E%D0%93_%D0%9F%D0%9E%D0%9B%D0%95%D0%99_%D0%9A%D0%9E%D0%9D%D0%A4%D0%98%D0%93%D0%A3%D0%A0%D0%90%D0%A6%D0%98%D0%98.md).
