# Профили конфигурации

> **Канонический английский источник:** [CONFIG_PROFILES.md](../../CONFIG_PROFILES.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


Используйте это практическое руководство, чтобы выбрать и применить практичный профиль конфигурации. Объяснение взаимодействия групп настроек см. в [`CONFIG_REFERENCE.md`](%D0%A1%D0%9F%D0%A0%D0%90%D0%92%D0%9E%D0%A7%D0%9D%D0%98%D0%9A_%D0%9F%D0%9E_%D0%9A%D0%9E%D0%9D%D0%A4%D0%98%D0%93%D0%A3%D0%A0%D0%90%D0%A6%D0%98%D0%98.md). Для точных полей, значений по умолчанию, типов и инвариантов используйте сгенерированный [`CONFIG_FIELD_CATALOG.md`](%D0%9A%D0%90%D0%A2%D0%90%D0%9B%D0%9E%D0%93_%D0%9F%D0%9E%D0%9B%D0%95%D0%99_%D0%9A%D0%9E%D0%9D%D0%A4%D0%98%D0%93%D0%A3%D0%A0%D0%90%D0%A6%D0%98%D0%98.md).

Каждый блок Lua ниже представляет собой набор записей верхнего уровня, которые могут заменить совпадающие записи внутри поставляемого `return { ... }` таблицу.

<a id="profile-chooser"></a>
## Профиля выбора

| Ситуация | Использовать этот профиль |
|---|---|
| Первая установка | Безопасная первая установка |
| Сервер работает нестабильно и часто выходит из строя | Текущие доказательства без медленного сканирования |
| Вам нужен object/world контекст | Полный базовый уровень |
| Вы хотите просмотреть старые журналы | Криминалистическая экспертиза backfill |
| Вы хотите рекомендации, но не записываете | Проверка соблюдения требований |
| Вы готовы разрешить охраннику запретить запись | Принудительное применение включено |
| Диск ограничен | Низкий размер диска |
| Вы выполнили чистую базовую настройку. | Настройка закрепленного резервного копирования. |

<a id="safe-first-install"></a>
## Безопасная первая установка

Используйте это сначала на работающем сервере.

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

log_tail = {
    enabled = true,
    start_at_end_on_first_run = true,
    tail_backup_logs = false,
},

scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

Что это делает:

```text
Tracks live sessions.
Starts the baseline scan.
Does not edit Admin.ini.
Avoids treating old backup logs as fresh live events.
```

<a id="current-evidence-without-slow-scan"></a>
## Текущие доказательства без медленного сканирования

Используйте это, если сервер нестабильен и вам нужны crash/reconnect доказательства перед тяжелым сканирование.

```lua
log_tail = {
    enabled = true,
},

scanning = {
    full_scan_on_start = false,
},

enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

Что это делает:

```text
Tracks logins, joins, leaves, reconnects, crashes, and unclean sessions.
Delays heavy world scanning.
```

<a id="full-baseline"></a>
## Полный базовый уровень

Используйте это после того, как сервер сможет работать достаточно долго для сканирования.

```lua
scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},
```

Что это делает:

```text
Builds object registry.
Writes world-state context.
Creates file manifest.
Enables changed-file refresh later.
```

<a id="forensic-backfill"></a>
## Криминалистическая экспертиза backfill

Используйте это только при намеренном просмотре исторических журналов.

```lua
log_tail = {
    start_at_end_on_first_run = false,
    tail_backup_logs = true,
    backfill_backup_logs_on_start = true,
},
```

Перед использованием:

```text
Back up runtime/log_offsets.tsv.
Expect old events to be reprocessed.
Return to live settings when finished.
```

<a id="enforcement-testing"></a>
## Проверка соблюдения требований

Используйте это перед фактической Admin.ini записью.

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},
```

Что проверять:

```text
runtime/account_evidence.json
runtime/warnings/
runtime/forensic_days/YYYY-MM-DD/ban_recommendations.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="enforcement-enabled"></a>
## Принудительное применение включено

Используйте это только после того, как выходные данные проверки верны.

```lua
enforcement = {
    review_only_mode = false,
    auto_ban = true,
    write_admin_ini = true,
    require_clean_ban_id = true,
    preserve_existing_bans = true,
    preserve_moderators = true,
},
```

Перед включением:

```text
Trusted IDs are configured.
Moderator IDs are preserved.
Admin.ini backups work.
Ban recommendations are understandable.
Thresholds are accepted by the server owner.
```

<a id="low-disk-growth"></a>
## Низкий размер диска

Используйте это, когда файлы среды выполнения растут слишком быстро.

```lua
logging = {
    low_importance_mode = "aggregate",
    write_low_importance_raw_events = false,
},

retention = {
    detailed_retention_days = 7,
    rotate_jsonl_when_bytes_exceed = 5242880,
    max_raw_events_lines = 20000,
    compact_json_outputs = true,
},
```

<a id="sticky-backup-setup"></a>
## Настройка закрепленного резервного копирования.

Используйте после первого завершенного базового показателя.

Проверьте, что они существуют:

```text
runtime/scan_complete.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
runtime/world_state/current/world_state_latest.json
```

Затем подкрепите их `config.lua`, `SavedRoot.txt`, а `Admin.ini`.
