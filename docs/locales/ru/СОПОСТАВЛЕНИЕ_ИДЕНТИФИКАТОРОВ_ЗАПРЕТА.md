# Запретить сопоставление идентификаторов

> **Канонический английский источник:** [BAN_ID_MAPPING.md](../../BAN_ID_MAPPING.md). Эта локализованная документация сохраняет точные команды, пути, ключи, значения статуса, хэши и имена файлов. Если технические формулировки отличаются, используйте источник на английском языке.


Используйте эту страницу при преобразовании имени игрока в безопасную `Admin.ini` строку бана.

<a id="core-rule"></a>
## Основное правило

Отображаемое имя не является идентификатором бана.

`Admin.ini` использует:

```ini
BannedPlayer=<raw numeric player ID>
```

<a id="evidence-hierarchy"></a>
## Иерархию доказательств

| Ранг | Источник | Использовать |
|---:|---|---|
| 1 | Журнал сервера `Login request` | Наилучшее сопоставление имени с идентификатором |
| 2 | `Player_<ID>.sav` | Подтверждает существование идентификатора |
| 3 | Существующий `Admin.ini` | Существующий bans/moderators |
| 4 | Внешнее уведомление или активность панели хостинга | Time/name только контекст; не удостоверение личности |
| 5 | UE4SS focus/player только строки | Presence/context |
| 6 | Журналы жизненного цикла системы или контейнера | Только контекст жизненного цикла хоста; не удостоверение личности |

<a id="extract-the-clean-id"></a>
## Извлечь чистый идентификатор

Необработанный пример:

```text
ConnectID=2535422284688820_+_|0002d07b...
```

Очистить `Admin.ini` значение:

```ini
BannedPlayer=2535422284688820
```

Не вставлять `_+_|...`.

<a id="verify-with-playerdata"></a>
## Проверьте с помощью PlayerData

Проверить:

```text
Saved/SaveGames/Server/Worlds/<WorldName>/PlayerData/Player_<ID>.sav
```

Значение:

```text
The ID exists in the world save.
```

Ограничение:

```text
PlayerData may not prove the display name unless another source maps it.
```

<a id="when-not-to-ban"></a>
## Когда не блокировать

Не назначайте идентификатор запрета, если:

```text
the name only appears in an external notification
the name only appears in hosting-panel activity
UE4SS shows a name but no ConnectID
only system lifecycle or container logs exist
the ID is trusted or moderator
```
