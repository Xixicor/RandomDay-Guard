# Código de conduta

> **Fonte canônica em inglês:** [CODE_OF_CONDUCT.md](../../../CODE_OF_CONDUCT.md). Essa documentação localizada preserva comandos, caminhos, chaves, valores de status, hashes e nomes de arquivos exatos. Se o texto técnico for diferente, use a fonte em inglês. Esta tradução é informativa; o texto legal em inglês controla.


Mantenha as discussões técnicas, específicas e baseadas em evidências. Não publique dados privados de jogadores, credenciais de servidor ou registros de incidentes ao vivo em problemas públicos.
