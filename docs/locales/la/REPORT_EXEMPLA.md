<a id="when-a-route-is-quiet"></a>
## Cum iter quietum

Iter quietum refert directum exitum sine filler ad Discordiam mittens:

> **Sedatus; nihil ad hanc famam.** Requisita monumenta in promptu erant et nulla adaptatio lusorum actuum, causa, vel defectus custodiae in hac fenestra nuntiationis fiebat.

Id est prorsus inanis effectus. Differt a relatione absentis, ubi requisitum principium sisti non potuit vel relegationis output creari non potuit.

Omnis fama lédibilis eandem viam sequitur:

```text
collected evidence -> normalized values -> dictionary mapping -> route calculations -> readable report -> Discord notification
```
