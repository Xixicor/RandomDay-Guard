# RandomDayGuard เอกสาร

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [README.md](../../README.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


RandomDayGuard อ่านบันทึกจากเซิร์ฟเวอร์เฉพาะของ Abiotic Factor และแปลงเป็นรายงานแยกกันสำหรับความสมบูรณ์ของเซิร์ฟเวอร์ ประวัติรายวัน เซสชันของผู้เล่น กรณีการตรวจสอบ และความล้มเหลวของการป้องกัน
