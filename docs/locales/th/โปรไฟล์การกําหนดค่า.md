# โปรไฟล์การกำหนดค่า

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [CONFIG_PROFILES.md](../../CONFIG_PROFILES.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


ใช้คำแนะนำวิธีการนี้เพื่อเลือกและใช้โปรไฟล์การกำหนดค่าที่ใช้งานได้จริง สำหรับคำอธิบายว่ากลุ่มการตั้งค่าโต้ตอบกันอย่างไร โปรดอ่าน [`CONFIG_REFERENCE.md`](%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B8%AD%E0%B9%89%E0%B8%B2%E0%B8%87%E0%B8%AD%E0%B8%B4%E0%B8%87%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B8%81%E0%B9%8D%E0%B8%B2%E0%B8%AB%E0%B8%99%E0%B8%94%E0%B8%84%E0%B9%88%E0%B8%B2.md). สำหรับฟิลด์ ค่าเริ่มต้น ประเภท และค่าคงที่ ให้ใช้ [`CONFIG_FIELD_CATALOG.md`](%E0%B9%81%E0%B8%84%E0%B9%87%E0%B8%95%E0%B8%95%E0%B8%B2%E0%B8%A5%E0%B9%87%E0%B8%AD%E0%B8%81%E0%B8%9F%E0%B8%B4%E0%B8%A5%E0%B8%94%E0%B9%8C%E0%B8%81%E0%B9%8D%E0%B8%B2%E0%B8%AB%E0%B8%99%E0%B8%94%E0%B8%84%E0%B9%88%E0%B8%B2.md).

แต่ละบล็อก Lua ด้านล่างคือชุดของรายการระดับบนสุดที่สามารถแทนที่รายการที่ตรงกันภายใน `return { ... }` ตาราง

<a id="profile-chooser"></a>
## ตัวเลือกโปรไฟล์

| สถานการณ์ | ใช้โปรไฟล์นี้ |
|---|---|
| ก่อน ติดตั้ง | ติดตั้งอย่างปลอดภัยก่อน |
| เซิร์ฟเวอร์ไม่เสถียรและล่มบ่อยครั้ง | หลักฐานปัจจุบันที่ไม่มีการสแกนช้า |
| คุณต้องการ object/world บริบท | ข้อมูลพื้นฐานทั้งหมด |
| คุณต้องการตรวจสอบบันทึกเก่า | การทดแทนทางนิติวิทยาศาสตร์ |
| คุณต้องการคำแนะนำ แต่ไม่มีการเขียน | การทดสอบการบังคับใช้ |
| คุณพร้อมที่จะให้เจ้าหน้าที่เขียนแบน | เปิดใช้งานการบังคับใช้ |
| ดิสก์ถูกจำกัด | การเติบโตของดิสก์ต่ำ |
| คุณเสร็จสิ้นการล้างข้อมูล baseline | การตั้งค่าการสำรองข้อมูลที่ติดหนึบ |

<a id="safe-first-install"></a>
## ติดตั้งอย่างปลอดภัยก่อน

ใช้สิ่งนี้ก่อนบนเซิร์ฟเวอร์ที่ใช้งานจริง

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

log_tail = {
    enabled = true,
    start_at_end_on_first_run = true,
    tail_backup_logs = false,
},

scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

สิ่งนี้ทำอะไร:

```text
Tracks live sessions.
Starts the baseline scan.
Does not edit Admin.ini.
Avoids treating old backup logs as fresh live events.
```

<a id="current-evidence-without-slow-scan"></a>
## หลักฐานปัจจุบันที่ไม่มีการสแกนช้า

ใช้สิ่งนี้หากเซิร์ฟเวอร์ไม่เสถียรและคุณต้องการ crash/reconnect หลักฐานก่อนการสแกนอย่างหนัก

```lua
log_tail = {
    enabled = true,
},

scanning = {
    full_scan_on_start = false,
},

enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

สิ่งนี้ทำอะไร:

```text
Tracks logins, joins, leaves, reconnects, crashes, and unclean sessions.
Delays heavy world scanning.
```

<a id="full-baseline"></a>
## ข้อมูลพื้นฐานทั้งหมด

ใช้สิ่งนี้หลังจากที่เซิร์ฟเวอร์ใช้งานได้นาน เพียงพอที่จะสแกน

```lua
scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},
```

สิ่งนี้ทำอะไร:

```text
Builds object registry.
Writes world-state context.
Creates file manifest.
Enables changed-file refresh later.
```

<a id="forensic-backfill"></a>
## การทดแทนทางนิติวิทยาศาสตร์

ใช้สิ่งนี้เมื่อตั้งใจตรวจสอบบันทึกประวัติเท่านั้น

```lua
log_tail = {
    start_at_end_on_first_run = false,
    tail_backup_logs = true,
    backfill_backup_logs_on_start = true,
},
```

ก่อนใช้งาน:

```text
Back up runtime/log_offsets.tsv.
Expect old events to be reprocessed.
Return to live settings when finished.
```

<a id="enforcement-testing"></a>
## การทดสอบการบังคับใช้

ใช้สิ่งนี้ก่อนเขียน Admin.ini จริง

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},
```

สิ่งที่ต้องตรวจสอบ:

```text
runtime/account_evidence.json
runtime/warnings/
runtime/forensic_days/YYYY-MM-DD/ban_recommendations.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="enforcement-enabled"></a>
## เปิดใช้งานการบังคับใช้

ใช้สิ่งนี้หลังจากผลลัพธ์การตรวจสอบถูกต้องเท่านั้น

```lua
enforcement = {
    review_only_mode = false,
    auto_ban = true,
    write_admin_ini = true,
    require_clean_ban_id = true,
    preserve_existing_bans = true,
    preserve_moderators = true,
},
```

ก่อนเปิดใช้งาน:

```text
Trusted IDs are configured.
Moderator IDs are preserved.
Admin.ini backups work.
Ban recommendations are understandable.
Thresholds are accepted by the server owner.
```

<a id="low-disk-growth"></a>
## การเติบโตของดิสก์ต่ำ

ใช้สิ่งนี้เมื่อไฟล์รันไทม์เติบโตเร็วเกินไป

```lua
logging = {
    low_importance_mode = "aggregate",
    write_low_importance_raw_events = false,
},

retention = {
    detailed_retention_days = 7,
    rotate_jsonl_when_bytes_exceed = 5242880,
    max_raw_events_lines = 20000,
    compact_json_outputs = true,
},
```

<a id="sticky-backup-setup"></a>
## การตั้งค่าการสำรองข้อมูลที่ติดหนึบ

ใช้หลังจากบรรทัดฐานแรกที่เสร็จสมบูรณ์

ตรวจสอบว่ามีอยู่:

```text
runtime/scan_complete.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
runtime/world_state/current/world_state_latest.json
```

จากนั้นสำรองข้อมูลด้วย `config.lua`, `SavedRoot.txt` และ `Admin.ini`.
