# การอ้างอิงสถานะและข้อผิดพลาด

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


ใช้ข้อมูลอ้างอิงนี้หลังจากอาการได้รับการจัดประเภทใน [การแก้ไขปัญหา](%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B9%81%E0%B8%81%E0%B9%89%E0%B9%84%E0%B8%82%E0%B8%9B%E0%B8%B1%E0%B8%8D%E0%B8%AB%E0%B8%B2.md) อ่านไฟล์สถานะที่มีโครงสร้างซึ่งตั้งชื่อตามข้อผิดพลาด รหัสที่แตกต่างกันแสดงถึงสถานะความปลอดภัยและวงจรการใช้งานที่แตกต่างกัน อย่ายุบลงในผลลัพธ์ทั่วไป "Guard failed"

<a id="route-and-source-states"></a>
## สถานะเส้นทางและแหล่งที่มา

| ค่า | ความหมาย | การตอบสนองของผู้ปฏิบัติงาน |
|---|---|---|
| `full` | สัญญาเส้นทางเสร็จสมบูรณ์พร้อมการพิสูจน์แหล่งที่มาของวงจรปัจจุบัน | อ่านขอบเขตหลักฐานของเส้นทาง ไม่มีการซ่อมแซมโดยนัย |
| `limited_expected_empty` | เส้นทางเสร็จสมบูรณ์และกิจกรรมที่ขาดหายไปนั้นถูกต้องตามกฎหมายสำหรับรอบนี้ | ไม่ควรสร้างเหตุการณ์สังเคราะห์ player/case |
| `missing` | ไม่มีเอาต์พุตที่จำเป็น ฟิลด์สายเลือด หรือหลักฐานแหล่งที่มา | ตรวจสอบเหตุผลของเส้นทางและสถานะแหล่งที่มาที่มีชื่อ |
| `available` | แหล่งที่มาที่มีชื่อสามารถอ่านและใช้งานได้ | ไม่มีการดำเนินการ |
| `expected_empty` | แหล่งที่มาได้รับการตรวจสอบและไม่มีแถวอย่างถูกต้อง | ไม่มีการดำเนินการใดๆ เว้นแต่คาดว่าจะมีกิจกรรมโดยอิสระ |
| `partial` / `complete_with_gaps` | มีหลักฐานที่ใช้งานได้ แต่คลาสแหล่งที่มาที่มีชื่อไม่สมบูรณ์ | จำกัดข้อสรุปไว้ที่หลักฐานที่รวบรวม |
| `deferred` | งานที่มีขอบเขตจำกัดถูกกำหนดไว้สำหรับโอกาสของผู้ปฏิบัติงานในภายหลัง | ยืนยันความคืบหน้าล่วงหน้าก่อนที่จะเปลี่ยนการกำหนดค่า |
| `unavailable` | สภาพแวดล้อมไม่ได้ระบุแหล่งที่มา | บันทึกขีดจำกัด; แก้ไขเฉพาะเส้นทางที่พิสูจน์แล้วหรือปัญหาการอนุญาต |
| `malformed` | แหล่งที่มาสามารถอ่านได้แต่การตรวจสอบโครงสร้างล้มเหลว | เก็บรักษาและแก้ไขแหล่งที่มา อย่าเดา |
| `permission_denied` | มีแหล่งที่มาแต่ไม่สามารถอ่านได้ | ให้สิทธิ์การอ่านที่จำเป็นแบบแคบเท่านั้น |
| `error` | การรวบรวมล้มเหลวด้วยเหตุผลที่บันทึกไว้ | รักษาข้อผิดพลาดและวินิจฉัยขั้นตอนนั้น |

<a id="playerdata-and-inventory-codes"></a>
## PlayerData และรหัสสินค้าคงคลัง

| รหัส | ความหมาย | การตอบสนองที่ปลอดภัย |
|---|---|---|
| `saved_root_unavailable` | ไม่มีรูทที่บันทึกไว้ที่ได้รับการยืนยันพร้อมใช้งานในไปป์ไลน์สาธารณะ | แก้ไข `SavedRoot.txt` และตรวจสอบเส้นทางอีกครั้ง |
| `unsafe_playerdata_root` | PlayerData การค้นพบได้รับการแก้ไขนอกขอบเขต รูทที่บันทึกไว้ | แก้ไขเส้นทาง อย่าทำให้ขอบเขตอ่อนแอลง |
| `playerdata_discovery_not_run` | ผู้ปฏิบัติงานการค้นพบที่ถูกผูกไว้ยังไม่ได้ทำงาน | ตรวจสอบตัวกำหนดเวลาและความคืบหน้าของผู้ปฏิบัติงาน |
| `playerdata_discovery_read_failed:*` | ไม่สามารถอ่านเอาต์พุตการค้นพบได้ | รักษารายละเอียดส่วนต่อท้ายและตรวจสอบคำสั่งสินค้าคงคลังที่ถูกผูกไว้ |
| `inventory_command_open_failed` | กระบวนการสินค้าคงคลังไม่สามารถ เริ่มต้นแล้ว | ตรวจสอบรันไทม์ว่ามีบริดจ์คำสั่งที่กำหนดค่าไว้ |
| `inventory_command_read_failed` | เอาต์พุตสินค้าคงคลังล้มเหลวในระหว่างการอ่าน | รักษาเอาต์พุตบางส่วนไว้และรันใหม่เฉพาะหลังจากที่ข้อผิดพลาดพื้นฐานได้รับการแก้ไขแล้วเท่านั้น |
| `inventory_command_close_failed` | สินค้าคงคลังเสร็จสมบูรณ์โดยไม่มีผลลัพธ์การปิดที่น่าเชื่อถือ | ปฏิบัติต่อแหล่งที่มาเป็น ไม่สมบูรณ์ |
| `identity_ledger_row_limit_exceeded` | การป้อนข้อมูลประจำตัวที่ทนทานเกินขอบเขตด้านความปลอดภัยสาธารณะ | เก็บถาวรและตรวจสอบบัญชีแยกประเภท อย่าตัดทอนเป็นการพิสูจน์แบบเต็ม |

<a id="adminini-enforcement-codes"></a>
## Admin.ini รหัสบังคับใช้

รหัสทั้งหมดในส่วนนี้ปิดไม่สำเร็จ พวกเขาไม่อนุญาตให้มีการแบนด้วยตนเอง

| รหัส | ความหมาย | การตอบสนองที่ปลอดภัย |
|---|---|---|
| `admin_ini_write_disabled` / `admin_ini_disabled` | ประตูการเขียนที่ปลอดภัยต่อสาธารณะปิดอยู่ | คาดว่าจะดำเนินการในการตรวจสอบเท่านั้น |
| `admin_ini_backup_disabled` / `backup_safety_gate_disabled` | นโยบายการสำรองข้อมูลที่จำเป็นไม่ทำงาน | ปิดใช้งานการเขียนต่อไป |
| `enforcement_disabled` / `ban_on_threshold_disabled` / `auto_ban_disabled` | ประตูบังคับใช้ที่ชัดเจนหนึ่งปิดอยู่ | คาดว่าจะเป็นค่าเริ่มต้นสำหรับการตรวจสอบสาธารณะเท่านั้น อย่าตีความใหม่ว่าเป็นความล้มเหลวในการเขียน |
| `review_only_mode_enabled` | โหมดตรวจสอบเท่านั้นจงใจบล็อกการกลายพันธุ์ | ตรวจสอบหลักฐานเท่านั้น |
| `duplicate_prevention_disabled` | การป้องกันซ้ำถูกปิดใช้งาน | ปิดใช้งานการเขียนต่อไปจนกว่าประตูนิรภัยจะได้รับการกู้คืน |
| `readback_safety_gate_disabled` / `rollback_safety_gate_disabled` | การตรวจสอบหลังเขียนหรือการป้องกันการย้อนกลับถูกปิดใช้งาน | ปิดใช้งานการเขียนต่อไป อย่าข้ามเกตเหล่านี้ |
| `clean_id_safety_gate_disabled` / `account_specific_evidence_gate_disabled` | การบังคับใช้ข้อมูลประจำตัวที่สะอาดหรือการบังคับใช้หลักฐานเฉพาะบัญชีถูกปิดใช้งาน | คืนค่าเกตก่อนการทดสอบการบังคับใช้ใด ๆ |
| `moderator_preservation_disabled` / `existing_ban_preservation_disabled` | การเก็บรักษาบัญชีที่ได้รับการป้องกันหรือการห้ามที่มีอยู่ถูกปิดใช้งาน | ปิดใช้งานการเขียนต่อไป |
| `clean_numeric_identity_required` | รหัสที่เสนอไม่ใช่รูปแบบการเชื่อมต่อที่ยอมรับอย่างสมบูรณ์หรือรหัสตัวเลขที่สะอาด | รับ การทำแผนที่ที่ตรวจสอบแล้ว อย่าตัดคำนำหน้าโดยพลการ |
| `identity_strength_below_minimum` | หลักฐานประจำตัวอ่อนแอกว่าเกณฑ์ที่กำหนดค่าไว้ | ตรวจสอบหลักฐานเท่านั้น |
| `playerdata_verification_required` | การกำหนดค่าต้องมี PlayerData การยืนยัน และบัญชีไม่มี | ให้ผู้สมัครพิจารณาเท่านั้น อย่าอนุมานความเป็นเจ้าของจากชื่อไฟล์ |
| `trusted_or_moderator_identity` | บัญชีได้รับการคุ้มครองโดยสถานะที่เชื่อถือได้หรือผู้ดูแล | ไม่อนุญาตให้เขียน |
| `admin_ini_path_invalid` / `admin_ini_path_outside_saved_root` | เส้นทางเป้าหมายไม่ถูกต้องหรือหนีจากรูทที่บันทึกไว้ | การกำหนดค่าที่ถูกต้อง; อย่าข้ามตัวป้องกันเส้นทาง |
| `admin_ini_unavailable` | ไม่พบการกำหนดค่าที่สามารถอ่านได้ Admin.ini ภายในรูทที่บันทึกไว้ | แก้ไขเส้นทางที่มีขอบเขตหรือปิดการใช้งานการบังคับใช้ |
| `admin_ini_read_failed` | ไม่สามารถอ่านไบต์ที่ได้รับอนุญาตได้ | หยุดก่อนที่จะเปลี่ยนรูปแบบ |
| `admin_ini_parse_failed` | Admin.ini การตรวจสอบล้มเหลวโดยไม่มีรหัสโครงสร้างที่เฉพาะเจาะจงมากขึ้น | เก็บรักษาไฟล์และตรวจสอบส่วนและโครงสร้างบรรทัด |
| `admin_ini_contains_nul` | ไฟล์มี NUL ไบต์ และไม่ได้รับการยอมรับเป็นข้อความ | เก็บรักษาไฟล์และซ่อมแซมนอก Guard |
| `admin_ini_duplicate_banned_players_section` | มีส่วน `[BannedPlayers]` มากกว่าหนึ่งส่วน | ผสานส่วนด้วยตนเอง ขณะที่หยุดอยู่ |
| `admin_ini_banned_player_outside_section` | แถวแบนปรากฏขึ้นด้านนอก `[BannedPlayers]`. | แก้ไขเค้าโครงด้วยตนเอง |
| `admin_ini_invalid_banned_player_line` | บรรทัดแบนไม่ใช่แถว ID ที่รองรับทั้งหมด | แก้ไขบรรทัดที่มีรูปแบบไม่ถูกต้อง |
| `admin_ini_backup_failed` | การสำรองข้อมูลที่ไม่ซ้ำกันไม่ได้เขียนและอ่านกลับแบบไบต์เหมือนกัน | ไม่อนุญาตให้มีการกลายพันธุ์ |
| `admin_ini_external_change_detected` | ผู้เขียนอีกคนเปลี่ยนไฟล์หลังจากสแน็ปช็อตของ Guard | เก็บรักษาไบต์ภายนอกและลองอีกครั้งหลังจากผู้เขียนประสานงานเท่านั้น |
| `atomic_rename_unavailable` | มีการร้องขอการแทนที่อะตอมมิก แต่ Lua ไม่ได้จัดเตรียม `os.rename`. | ไม่มีการเขียนที่เชื่อถือได้ ใช้รันไทม์ที่รองรับหรือปิดใช้งานการบังคับใช้ต่อไป |
| `admin_ini_write_failed` | การแทนที่ที่ควบคุมไม่เสร็จสมบูรณ์ | ตรวจสอบข้อผิดพลาดการแทนที่และการสำรองข้อมูลที่บันทึกไว้ |
| `post_write_verification_failed` | ไบต์ที่ใช้งานจริงไม่เท่ากับตัวเลือก | ตรวจสอบ `rollback_success` และ `rollback_refused_external_change` ก่อนดำเนินการใดๆ |

<a id="startup-scheduler-and-backlog-states"></a>
## สถานะการเริ่มต้น ตัวกำหนดเวลา และสถานะ Backlog

ค่าเหล่านี้เป็นหลักฐานวงจรการใช้งาน ไม่ใช่การพิสูจน์เส้นทาง อ่านด้วยโพลปัจจุบัน ผู้ปฏิบัติงานรายงาน และไฟล์พิสูจน์เส้นทาง

| ค่า | ความหมาย | การตอบสนองที่ปลอดภัย |
|---|---|---|
| `not_started` | ขั้นตอนการเริ่มต้นหรือตัวกำหนดเวลาที่กำหนดชื่อยังไม่ได้เริ่ม | ระหว่างการเปิดตัว ให้รอตามช่วงเวลาที่บันทึกไว้ หลังจากนั้นให้ตรวจสอบเฟสแรกที่ไม่มีการเปลี่ยนแปลง |
| `main_lua_loaded` / `starting` | ตัวโหลด Canonical ทำงานและ Guard เข้าสู่การเริ่มต้น | ดำเนินการต่อไปยังเฟสต่อๆ ไป เพียงอย่างเดียวนี้ไม่ใช่ความพร้อม |
| `saved_root_found` / `log_tail_initialized` / `epoch_started` | แหล่งที่มาหลักและความต่อเนื่องในการเริ่มต้นขั้นสูง | ไม่มีการดำเนินการใดๆ เว้นแต่ระยะถัดไปจะหยุดก้าวหน้า |
| `admin_state_written` / `playerdata_index_written` | ดัชนีขอบเขตเริ่มต้นถูกส่งออก | ไม่มีการดำเนินการ; แฮนด์ออฟของตัวกำหนดเวลายังคงต้องปฏิบัติตาม |
| `watchdog_started` | รายงานและการตรวจสอบการสำรวจความคิดเห็นได้รับการลงทะเบียนแล้ว | ยืนยันความคืบหน้าของตัวกำหนดเวลาและการสำรวจความคิดเห็นในครั้งต่อไป |
| `ready_degraded` / `scan_running` | Guard กำลังทำงานในขณะที่การสแกนประวัติแบบมีขอบเขตยังคงค้างอยู่ | ข้อควรระวัง ไม่ใช่ความล้มเหลว ตรวจสอบตัวนับความคืบหน้าล่วงหน้า |
| `ready` | การเริ่มต้นและการสแกนขอบเขตปัจจุบันถึงสถานะพร้อม | ตรวจสอบการพิสูจน์เส้นทางแยกกัน |
| `scan_failed` / `error` | การเริ่มต้นหรือการสแกนสิ้นสุดลงด้วยข้อผิดพลาดที่บันทึกไว้ | รักษาข้อผิดพลาดที่มีชื่อหรือไฟล์สถานะและวินิจฉัยขั้นตอนนั้น |
| `running` | ตัวกำหนดเวลาเป็นเจ้าของอนาคต โอกาสในการสำรวจความคิดเห็น | ยืนยัน `poll_id` และ `poll_completed_count` ล่วงหน้า |
| `manual_only` | การกำหนดเวลาลูปไม่พร้อมใช้งาน มีเพียงงานที่ชัดเจนเท่านั้นที่สามารถทำงานได้ | ถือว่าการทำงานแบบอัตโนมัติไม่พร้อมใช้งาน |
| `stopped` | การดำเนินการตามกำหนดเวลาสิ้นสุดลง | ตรวจสอบหลักฐานการหยุดและข้อผิดพลาดก่อนหน้าก่อนรีสตาร์ท |
| `active_log_caught_up` | ไม่มี Backlog ของบันทึกที่ใช้งานที่ยังไม่ได้อ่านเหลืออยู่ | การสแกนประวัติอาจดำเนินการต่อ |
| `active_log_unavailable_nonblocking` | ไม่มีบันทึกที่ใช้งานอยู่ แต่การเริ่มต้นระบบยังคงไม่ถูกบล็อก | บันทึกขีดจำกัดของแหล่งที่มาและตรวจสอบแหล่งที่มาอื่นๆ |
| `active_log_read_failed` | มีบันทึกที่ใช้งานอยู่แต่ไม่สามารถอ่านได้ | รักษาข้อผิดพลาดและแก้ไขเฉพาะเส้นทางที่พิสูจน์แล้วหรือปัญหาการอนุญาต |
| `budget_exhausted` / `active_log_has_unread_bytes` | การส่งผ่านที่มีขอบเขตหยุดลงโดยยังมีงานค้างเหลืออยู่ | ยืนยันการสำรวจในภายหลังจะลดจำนวนที่ยังไม่ได้อ่าน |
| `offset_commit_failed_after_events_applied` | เหตุการณ์ได้รับการประมวลผลแล้ว แต่การคงอยู่ของบันทึกออฟเซ็ตที่คงทนล้มเหลว | การบังคับใช้ถูกเลื่อนออกไป; ซ่อมแซมพื้นที่เก็บข้อมูลออฟเซ็ตก่อนที่จะใช้รอบอื่น |

<a id="scheduler-report-and-notification-codes"></a>
## รหัสกำหนดการ รายงาน และการแจ้งเตือน

| รหัสหรือสถานะ | ความหมาย | การตอบสนองที่ปลอดภัย |
|---|---|---|
| `poll already in flight` | การโทรกลับครั้งที่สองมาถึงในขณะที่การสำรวจความคิดเห็นปัจจุบันเป็นเจ้าของวงจรการใช้งาน | ยืนยันความก้าวหน้าของการสำรวจที่มีอยู่ อย่าเพิ่มเจ้าของลูปอื่น |
| `no_log_files_found` | ไม่พบบันทึกที่ใช้งานอยู่หรือสำรองข้อมูลที่กำหนดค่าไว้ | ตรวจสอบการกำหนดค่ารูทและแหล่งที่มาที่บันทึกไว้ |
| `current_poll_error` | รอบปัจจุบันบันทึกความล้มเหลวของแหล่งสำรวจความคิดเห็น | อ่าน `runtime/current/poll_error.json`. |
| `cadence_deferred` | ผู้มอบหมายงานเสร็จสิ้นยังไม่ถึงกำหนด | คาดว่าจะถึงโอกาสในขอบเขตถัดไป |
| `reports_disabled` | การสร้างรายงานสาธารณะถูกปิดใช้งาน | เปิดใช้งานเฉพาะในกรณีที่ตั้งใจจะรายงานเท่านั้น |
| `local_outbox_write_failed` | ไม่สามารถเขียนเอนเวโลปภายในเครื่องที่แปลแล้วได้ | ซ่อมแซมไดเร็กทอรีเอาต์พุตรันไทม์ นี่ไม่ใช่ข้อผิดพลาดในการขนส่งการแจ้งเตือน |
| `source_accounting_disabled` | การพิสูจน์เส้นทางไม่สามารถอ้างสิทธิ์ความครอบคลุมของแหล่งที่มาได้อย่างสมบูรณ์ | เปิดใช้งานการบัญชีต้นทางหรือยอมรับการพิสูจน์ที่ขาดหายไปอย่างชัดเจน |
| `route_disabled` | เส้นทางถูกปิดใช้งานโดยเจตนา | คาดว่าจะไม่มีการส่งมอบสำหรับเส้นทางนั้น |
| `poll_owner_between_polls` | ผู้ปฏิบัติงานรายงานถูกจัดคิวสำหรับช่องว่างที่ผู้กำหนดตารางเวลาเป็นเจ้าของระหว่างการสำรวจความคิดเห็น | คาดหวังเฉพาะในขณะที่การประทับเวลาและเคอร์เซอร์ยังคงดำเนินต่อไป |
| `unsafe_shell_path` | สินค้าคงคลังที่มีขอบเขตหรือเส้นทางเชลล์ล้มเหลวในการตรวจสอบความปลอดภัยของแพลตฟอร์ม | แก้ไข เส้นทาง; ไม่เคยทำให้การอ้างอิงหรือการตรวจสอบเส้นทางอ่อนลง |
