# หลักจรรยาบรรณ

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [CODE_OF_CONDUCT.md](../../../CODE_OF_CONDUCT.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ การแปลนี้เป็นการให้ข้อมูล; การควบคุมข้อความทางกฎหมายภาษาอังกฤษ


ให้การสนทนาทางเทคนิค เฉพาะเจาะจง และอิงตามหลักฐาน อย่าโพสต์ข้อมูลผู้เล่นส่วนตัว ข้อมูลรับรองเซิร์ฟเวอร์ หรือบันทึกเหตุการณ์สดในประเด็นสาธารณะ
