<a id="detection-signals"></a>
# สัญญาณการตรวจจับ

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [DETECTION_SIGNALS.md](../../DETECTION_SIGNALS.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


สัญญาณเป็นอินพุตการตรวจสอบ ไม่ใช่การกล่าวหาโดยอัตโนมัติ

<a id="signal-table"></a>
## ตารางสัญญาณ

| สัญญาณ | ความหมาย | แข็งแกร่งขึ้นเมื่อ... | ไม่เพียงพอโดยตัวมันเอง |
|---|---|---|---|
| ข้อมูลประจำตัวในการเข้าสู่ระบบ | ชื่อแมปกับรหัสบัญชี | มีConnectID | แบน |
| Clean leave | การปิดเซสชันปกติ | เข้าร่วมและออกจากการแข่งขัน | สงสัย |
| เชื่อมต่อใหม่อย่างรวดเร็ว | Churn/probing บริบท | ทำซ้ำอย่างรวดเร็ว | แบน |
| ไม่สะอาด ตัดการเชื่อมต่อ | เซสชันปิดไม่เรียบร้อย | เกิดซ้ำหรือทับซ้อนข้อขัดข้อง | แบน |
| ขัดข้องทับซ้อน | บัญชีใช้งานใกล้ขัดข้อง | บัญชีเดิมเกิดซ้ำ | แบน |
| หลังเกิดข้อขัดข้อง | บัญชีกลับมาหลังจากรีสตาร์ท | ซ้ำข้ามยุค | แบนหนึ่งเหตุการณ์ |
| คำเตือนต่อเนื่อง | หน้าต่างคำเตือนเซิร์ฟเวอร์ | ทับซ้อนเซสชันที่แมป | แบนหนึ่งครั้ง |
| Actor save touch | บริบทบันทึกโลก | สัมพันธ์กับเซสชัน | หลักฐานของ use/theft |
| Object delta | World/class การเปลี่ยนแปลง | สัมพันธ์กับเซสชัน | ห้ามนับเพียงอย่างเดียว |
| Raid case | คลัสเตอร์หลายบัญชี | บัญชีกลางซ้ำ | แบนบัญชีทั้งหมดโดยรวม |

<a id="login-identity"></a>
## ข้อมูลประจำตัวในการเข้าสู่ระบบ

แหล่งที่มาที่ดีที่สุด:

```text
Login request
Name=
ConnectID=
UniqueId=
```

ใช้มันเพื่อแมป:

```text
display/log name -> account_id -> ban_id
```

<a id="rapid-reconnect"></a>
## เชื่อมต่อใหม่อย่างรวดเร็ว

รูปแบบ:

```text
join -> leave -> join -> leave -> join
```

ใช้สำหรับการตรวจสอบเมื่อทำซ้ำ

ความปลอดภัย:

```text
churn_alone_never_bans = true
```

<a id="crash-overlap-and-post-crash-return"></a>
## การทับซ้อนของการชนและการส่งคืนภายหลังการชน

รูปแบบ:

```text
account active before crash
server restarts
same account returns quickly
```

ใช้สำหรับการตรวจสอบเมื่อทำซ้ำข้ามยุค

ความปลอดภัย:

```text
single_crash_never_bans = true
```

<a id="warning-bursts"></a>
## คำเตือนระเบิด

ตัวอย่าง:

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

ใช้เป็นบริบทจนกว่าจะเชื่อมโยงกับเซสชันและเกณฑ์ที่แมป

<a id="actor-save-touch"></a>
## Actor save touch

ความหมาย:

```text
The server evidence referenced a class or actor.
```

ไม่ได้หมายถึง:

```text
A player opened it.
A player stole from it.
A player duplicated through it.
A player damaged it.
```

<a id="raid-cases"></a>
## กรณีการโจมตี

กรณีการโจมตีจัดกลุ่มบัญชีตามเวลาและหน้าต่างที่ใช้ร่วมกัน

กฎ:

```text
Do not auto-ban every account in a raid case.
Each account needs account-specific evidence.
```
