# ตัวอย่างรายงาน Guard ทั้งห้ารายการ

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [REPORT_EXAMPLES.md](../../REPORT_EXAMPLES.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


ตัวอย่างเหล่านี้สร้างขึ้นจากข้อมูลตัวอย่างที่มาพร้อมกับการเปิดตัว มีการประดิษฐ์ชื่อและหมายเลขบัญชี โดยจะแสดงฟิลด์รายงานที่ทดสอบ การคำนวณ และขอบเขตเส้นทาง รายงานจริงจะแทนที่ด้วยข้อมูลที่รวบรวมจากเซิร์ฟเวอร์นั้น และแจ้งเมื่อไม่มีข้อเท็จจริง

แต่ละรายงานมีงานเดียว ความสมบูรณ์ของเซิร์ฟเวอร์ไม่แสดงประวัติผู้เล่นซ้ำ การตรวจสอบรายวันจะไม่ถูกส่งทุกๆ สองสามนาที และผู้เล่นที่เงียบหรือเส้นทางเคสจะไม่ได้รับข้อความเพิ่มเติม รายงานปัจจุบันอาจพร้อมในขณะที่การสแกนประวัติแบบมีขอบเขตยังดำเนินอยู่ ในกรณีนั้น รายงานจะตั้งชื่อช่องว่างแทนที่จะนำเสนอประวัติเก่าว่าเสร็จสมบูรณ์

## เมื่อเส้นทางเงียบ

เส้นทางที่เงียบสงบจะบันทึกผลลัพธ์โดยตรงโดยไม่ต้องส่งตัวเติมไปยัง Discord:

> **ตรวจสอบแล้ว; ไม่มีอะไรสำหรับรายงานนี้** มีบันทึกที่จำเป็นและไม่มีกิจกรรมของผู้เล่น กรณี หรือความล้มเหลวของ Guard ที่ตรงกันเกิดขึ้นในระหว่างหน้าต่างรายงานนี้

นั่นเป็นผลลัพธ์ที่ว่างเปล่าโดยสมบูรณ์ แตกต่างจากรายงานที่ขาดหายไป ซึ่งไม่สามารถตรวจสอบแหล่งที่มาที่ต้องการได้หรือไม่สามารถสร้างเอาต์พุตที่อ่านได้

รายงานที่อ่านได้ทั้งหมดจะมีเส้นทางเดียวกัน:

```text
collected evidence -> normalized values -> dictionary mapping -> route calculations -> readable report -> Discord notification
```
