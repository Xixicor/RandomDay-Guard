# FAQ

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [FAQ.md](../../FAQ.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


<a id="is-randomdayguard-the-randomday-mod"></a>
## เป็น RandomDayGuard RandomDay Mod?

ไม่ RandomDay Mod เปลี่ยนประสบการณ์เซิร์ฟเวอร์ RandomDayGuard เฝ้าดูเลเยอร์หลักฐานของเซิร์ฟเวอร์

<a id="does-live-defense-work-before-the-scan-completes"></a>
## การป้องกันแบบสดทำงานก่อนที่การสแกนจะเสร็จสิ้นหรือไม่

ใช่ การป้องกันแบบสดใช้บันทึกและเหตุการณ์เซสชัน การสแกนพื้นฐานจะปรับปรุงบริบทในภายหลัง

<a id="why-can-the-first-scan-take-a-long-time"></a>
## เหตุใดการสแกนครั้งแรกจึงใช้เวลานาน

การสร้างการสแกนครั้งแรก world/object บริบท รายการไฟล์ และข้อมูลพื้นฐานที่นำมาใช้ซ้ำได้

<a id="what-do-i-check-first-after-startup"></a>
## ฉันจะตรวจสอบอะไรเป็นอันดับแรกหลังจากเริ่มต้นระบบ

```text
runtime/current/poll_status.json
```

มองหา:

```text
scheduler_status=running
poll_id increasing
poll_in_flight=false
```

<a id="where-are-player-summaries"></a>
## สรุปผู้เล่นอยู่ที่ไหน

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

<a id="where-is-the-daily-quick-review-package"></a>
## แพ็คเกจการตรวจสอบด่วนรายวันอยู่ที่ไหน

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

<a id="which-file-should-i-upload-for-fastest-review"></a>
## ฉันควรอัปโหลดไฟล์ใดเพื่อให้ตรวจสอบได้เร็วที่สุด

```text
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="can-it-write-bans-automatically"></a>
## สามารถเขียนการแบนโดยอัตโนมัติได้หรือไม่

เฉพาะเมื่อเปิดใช้งานอย่างชัดเจนเท่านั้น

ค่าเริ่มต้น:

```lua
review_only_mode = true
auto_ban = false
write_admin_ini = false
```

<a id="what-does-adminini-receive"></a>
## อะไร Admin.ini รับหรือไม่

เท่านั้น:

```ini
BannedPlayer=<ID>
```

ไม่มีชื่อ ความคิดเห็น เหตุผล หรือคำต่อท้าย

<a id="is-a-display-name-enough-to-ban"></a>
## ชื่อที่แสดงเพียงพอที่จะแบนหรือไม่

ไม่ใช่ ใช้บันทึกเซิร์ฟเวอร์ `Login request` ด้วย `ConnectID` หรือหลักฐานเซิร์ฟเวอร์ที่เทียบเท่า

<a id="can-one-crash-ban-someone"></a>
## หนึ่งข้อผิดพลาดสามารถแบนใครบางคนได้หรือไม่

ไม่ใช่โดยค่าเริ่มต้น

<a id="can-object-count-alone-ban-someone"></a>
## การนับวัตถุเพียงอย่างเดียวสามารถแบนใครบางคนได้หรือไม่

ไม่ใช่โดยค่าเริ่มต้น

<a id="should-savedroottxt-point-to-the-world-folder"></a>
## ควร SavedRoot.txt ชี้ไปที่โฟลเดอร์ world?

ไม่ใช่ ชี้ไปที่ `AbioticFactor/Saved`.

<a id="what-if-the-world-folder-changes"></a>
## จะเกิดอะไรขึ้นหากโฟลเดอร์ world เปลี่ยนแปลง

ให้ถือว่าเป็นการเปลี่ยนแปลงข้อมูลประจำตัวพื้นฐาน รักษาพื้นฐานเก่าและสร้างฐานใหม่
