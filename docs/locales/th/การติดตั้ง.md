# ติดตั้ง RandomDayGuard

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [INSTALL.md](../../../INSTALL.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


คู่มือการติดตั้ง `v0.4.12-alpha` บนเซิร์ฟเวอร์เฉพาะ Abiotic Factor ที่ใช้ UE4SS อยู่แล้ว ตัวดัดแปลงไม่ได้เชื่อมโยงกับบริษัทโฮสติ้งหรือแผงควบคุมแห่งใดแห่งหนึ่ง

<a id="before-you-begin"></a>
## ก่อนที่คุณจะเริ่มต้น

คุณต้องการ:

- เข้าถึงเพื่อหยุดและเริ่มต้นเซิร์ฟเวอร์เฉพาะ
- ไดเรกทอรี UE4SS `Mods` โฟลเดอร์;
- ของเซิร์ฟเวอร์ สำเนาของโฟลเดอร์ RandomDayGuard ปัจจุบัน หากคุณกำลังอัปเดต;
- การสำรองข้อมูลเซิร์ฟเวอร์ที่คุณปกป้องตามปกติก่อนที่จะเปลี่ยน mod

ไฟล์ **โฟลเดอร์ Mods** คือ `ue4ss/Mods/` ไดเร็กทอรีภายในการติดตั้งเซิร์ฟเวอร์เฉพาะ RandomDayGuard อยู่ภายในโฟลเดอร์นั้นโดยตรง

<a id="new-installation"></a>
## การติดตั้งใหม่

1. หยุดเซิร์ฟเวอร์เฉพาะ
2. แยก RandomDayGuard ZIP ลงในโฟลเดอร์ว่างใหม่
3. คัดลอกที่แยกออกมา `RandomDayGuard` โฟลเดอร์ลงในโฟลเดอร์ UE4SS `Mods` โฟลเดอร์ ผลลัพธ์ควรเป็นหนึ่ง `Mods/RandomDayGuard/` ของเซิร์ฟเวอร์ ไม่ใช่โฟลเดอร์ RandomDayGuard ที่สองที่ซ้อนอยู่ข้างใน
4. เปิด UE4SS `mods.txt` และเปิดใช้งาน:

   ```text
   RandomDayGuard : 1
   ```

5. เริ่มเซิร์ฟเวอร์ตามปกติ
6. รอ UE4SS และเซิร์ฟเวอร์เกมที่จะเริ่มต้นให้เสร็จสิ้น จากนั้นปฏิบัติตาม [อ่านรายงานฉบับแรก](%E0%B9%80%E0%B8%A3%E0%B8%B4%E0%B9%88%E0%B8%A1%E0%B8%95%E0%B9%89%E0%B8%99%E0%B8%97%E0%B8%B5%E0%B9%88%E0%B8%99%E0%B8%B5%E0%B9%88.md).

อย่าคัดลอกรุ่นใหม่ทับการติดตั้งที่กำลังรันอยู่ เก็บข้อมูลสำรองไว้จนกว่าการติดตั้งที่อัพเดตจะสร้างรายงานสถานะเซิร์ฟเวอร์ปัจจุบัน

<a id="update-an-existing-installation"></a>
## อัปเดตการติดตั้งที่มีอยู่

1. หยุดเซิร์ฟเวอร์
2. คัดลอกโฟลเดอร์ RandomDayGuard ที่ติดตั้งเสร็จสมบูรณ์ไปยังตำแหน่งสำรองข้อมูลที่ปลอดภัย
3. ย้ายโฟลเดอร์โปรแกรมเก่าออกจาก UE4SS `Mods` แทนที่จะวางเลเยอร์ใหม่ทับไว้
4. คัดลอกโฟลเดอร์ใหม่ RandomDayGuard โฟลเดอร์ลงใน `Mods`.
5. กู้คืนเฉพาะการกำหนดค่าภายในเครื่องที่คุณตรวจสอบแล้วและหลักฐานที่บันทึกไว้ หากคู่มือการกำหนดค่าแสดงรายการฟิลด์ใหม่ ให้รวมลงในสำเนาที่ตรวจสอบแล้วแทนที่จะแทนที่การตั้งค่าทั้งหมดแบบสุ่มสี่สุ่มห้า
6. ยืนยัน `RandomDayGuard : 1` ยังคงเปิดใช้งานอยู่
7. เริ่มเซิร์ฟเวอร์และอ่านรายงานสถานะเซิร์ฟเวอร์ปัจจุบัน

การอัปเดตโฟลเดอร์ที่สะอาดนี้ยังลบไฟล์ที่ล้าสมัยออกจากรุ่นเก่าโดยไม่ต้องขอให้ผู้ปฏิบัติงานตรวจสอบโปรแกรม ชื่อไฟล์

<a id="help-guard-find-the-server-records"></a>
## ช่วยเหลือ Guard ค้นหาบันทึกเซิร์ฟเวอร์

Guard ปกติจะค้นหาไดเรกทอรี Abiotic Factor `Saved` โดยอัตโนมัติ หากไม่สามารถทำได้ ให้ใส่พาธแบบเต็มไปยังไดเร็กทอรี `Saved` นั้นใน `SavedRoot.txt` ภายใน RandomDayGuard โฟลเดอร์ ชี้ไปที่ `Saved` ไม่ใช่โลกใดโลกหนึ่งที่อยู่ด้านล่าง

รายงานสถานะเซิร์ฟเวอร์ฉบับแรกระบุว่าพบตำแหน่งบันทึกหรือไม่และกลุ่มแหล่งที่มาใดที่มีอยู่ ใช้ [การแก้ไขปัญหา](%E0%B8%81%E0%B8%B2%E0%B8%A3%E0%B9%81%E0%B8%81%E0%B9%89%E0%B9%84%E0%B8%82%E0%B8%9B%E0%B8%B1%E0%B8%8D%E0%B8%AB%E0%B8%B2.md) เมื่อไม่สามารถอ่านตำแหน่งได้

<a id="first-run-behavior"></a>
## ลักษณะการทำงานครั้งแรก

การติดตั้งเริ่มต้นจะคอยดูบันทึกที่มีอยู่และเขียนรายงาน มันไม่เปลี่ยนแปลง `Admin.ini` หรือเพิ่มการแบน ซึ่งช่วยให้คุณยืนยันการรวบรวม การแปล และคุณภาพรายงานก่อนที่จะตัดสินใจว่าจะเปิดใช้งานการดำเนินการเสริมใดๆ หรือไม่

[อ่านรายงานฉบับแรก](%E0%B9%80%E0%B8%A3%E0%B8%B4%E0%B9%88%E0%B8%A1%E0%B8%95%E0%B9%89%E0%B8%99%E0%B8%97%E0%B8%B5%E0%B9%88%E0%B8%99%E0%B8%B5%E0%B9%88.md)

<a id="disable-or-remove-randomdayguard"></a>
## ปิดใช้งานหรือลบ RandomDayGuard

1. หยุดเซิร์ฟเวอร์
2. คัดลอกโฟลเดอร์ RandomDayGuard ทั้งหมดไปยังไฟล์เก็บถาวรที่ปลอดภัย
3. หากต้องการปิดใช้งาน mod ให้ตั้งค่า `RandomDayGuard : 0` ใน UE4SS `mods.txt`.
4. หากต้องการลบออก ให้ย้ายโฟลเดอร์ RandomDayGuard ที่สมบูรณ์ออกจาก `Mods` หลังจากที่ยืนยันว่าสามารถเปิดไฟล์เก็บถาวรได้
5. เริ่มเซิร์ฟเวอร์และยืนยันว่า Guard ไม่เริ่มทำงานอีกต่อไป

การปิดใช้งานหรือลบ Guard จะหยุดการรวบรวมในอนาคต มันจะไม่ลบข้อมูลเกม ลบรายงานที่เก็บถาวร หรือย้อนกลับการดำเนินการของผู้ให้บริการแยกต่างหาก

<a id="roll-back-an-update"></a>
## ย้อนกลับการอัปเดต

หากการติดตั้งใหม่ไม่โหลดหรือไม่สามารถสร้างรายงานปัจจุบันได้:

1. หยุดเซิร์ฟเวอร์
2. ย้ายการติดตั้งที่ไม่สำเร็จออกไปด้านข้างโดยไม่ต้องลบบันทึก
3. เรียกคืนข้อมูลทั้งหมด อัพเดตล่วงหน้า RandomDayGuard โฟลเดอร์
4. คืนค่าการกำหนดค่าที่ตรวจสอบแล้วและหลักฐานที่บันทึกไว้จากข้อมูลสำรองเดียวกัน
5. ยืนยันว่า mod ถูกเปิดใช้งานและเริ่มเซิร์ฟเวอร์
6. อ่านรายงานสถานะเซิร์ฟเวอร์ที่กู้คืนก่อนทำการเปลี่ยนแปลงอื่น
