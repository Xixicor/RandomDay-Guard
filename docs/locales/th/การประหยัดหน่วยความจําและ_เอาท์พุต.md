<a id="memory-economy-and-output-files"></a>
# ประหยัดหน่วยความจำและไฟล์เอาต์พุต

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [MEMORY_ECONOMY_AND_OUTPUTS.md](../../MEMORY_ECONOMY_AND_OUTPUTS.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


หน้านี้อธิบายว่าไฟล์ใดขยายได้ ไฟล์ใดถูกเขียนทับ และสิ่งที่จะอัปโหลดเพื่อตรวจสอบอย่างรวดเร็ว

<a id="fast-answer"></a>
## คำตอบด่วน

| คำถาม | เปิด |
|---|---|
| ยามยังมีชีวิตอยู่หรือไม่ | `runtime/current/poll_status.json` |
| ใครเห็นบ้าง | `runtime/account_evidence.json` |
| เกิดอะไรขึ้นกับเซสชัน | `runtime/evidence/session_events.jsonl` |
| เกิดอะไรขึ้นวันนี้ | `runtime/forensic_days/YYYY-MM-DD/` |
| สรุปในภาษาธรรมดาคืออะไร | `runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt` |
| ความคืบหน้าในการสแกนคืออะไร | `runtime/scan_progress.json` |
| บริบทของโลกคืออะไร | `runtime/world_state/current/world_state_latest.json` |
| มีการเขียนข้อห้ามอะไรบ้าง | `runtime/enforced_bans.jsonl` |

<a id="output-model"></a>
## โมเดลเอาต์พุต

| ประเภท | พฤติกรรม | ตัวอย่าง |
|---|---|---|
| ภาพรวมปัจจุบัน | เขียนทับ | `runtime/current/*.json` |
| บันทึกเหตุการณ์ | ผนวกเท่านั้น | `runtime/evidence/*.jsonl` |
| ตาราง | อัปเดตหรือต่อท้าย | `*.tsv` |
| เส้นฐาน | ใช้ซ้ำหลังจากเสร็จสิ้น | `runtime/baselines/*` |
| การสรุปรายวัน | อัปเดตแล้ว | `runtime/forensic_days/YYYY-MM-DD/*` |
| บันทึกสุดท้าย | สรุปรายวันแบบธรรมดา | `runtime/final_logs/YYYY-MM-DD/*` |

<a id="current-snapshots"></a>
## ภาพรวมปัจจุบัน

สิ่งเหล่านี้มีขนาดเล็กและตอบว่า "สิ่งที่เป็นจริงในขณะนี้"

```text
runtime/current/poll_status.json
runtime/current/session_state.json
runtime/current/active_accounts.json
runtime/current/forensic_today.json
runtime/current/forensic_today.md
runtime/current/forensic_today.txt
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/world_state/current/world_state_latest.json
```

<a id="player-summaries"></a>
## สรุปผู้เล่น

ไฟล์เหล่านี้เป็นไฟล์แรกๆ ที่จะตรวจสอบเพื่อตรวจสอบบัญชี

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

สรุป:

```text
account_id
ban_id
name
identity_confidence
first_seen
last_seen
join_count
leave_count
status
score
```

<a id="event-logs"></a>
## บันทึกเหตุการณ์

เหล่านี้จะรักษาไทม์ไลน์ไว้

```text
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/warning_events.jsonl
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/evidence/live_defense_events.jsonl
```

<a id="daily-forensic-rollups"></a>
## การรวบรวมทางนิติวิทยาศาสตร์รายวัน

นี่คือแพ็คเกจการอัปโหลดด่วน

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

อัปโหลดหนึ่งในโฟลเดอร์เหล่านั้นเมื่อคุณต้องการการวิเคราะห์ในช่วงเวลาที่รวดเร็ว

<a id="scan-and-baseline-files"></a>
## สแกนและไฟล์พื้นฐาน

ใช้สิ่งเหล่านี้เพื่อทำความเข้าใจว่าบริบทของโลกเป็นบางส่วนหรือทั้งหมด

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/scan_complete.json
runtime/object_registry_partial.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
```

<a id="enforcement-files"></a>
## การบังคับใช้ files

ใช้สิ่งเหล่านี้เมื่อมีการเปิดใช้งานการบังคับใช้เท่านั้น

```text
runtime/enforced.txt
runtime/enforced_bans.jsonl
runtime/ban_queue.json
runtime/evidence/enforced_bans.jsonl
```

`Admin.ini` ควรได้รับเท่านั้น:

```ini
BannedPlayer=<ID>
```

<a id="what-updates-when-a-player-joins"></a>
## จะมีการอัปเดตอะไรบ้างเมื่อผู้เล่นเข้าร่วม

การอัปเดตที่คาดหวัง:

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/current/session_state.json
runtime/forensic_days/YYYY-MM-DD/players.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="what-updates-when-the-server-crashes-or-restarts"></a>
## จะมีการอัปเดตอะไรบ้างเมื่อเซิร์ฟเวอร์ขัดข้องหรือรีสตาร์ท

การอัปเดตที่คาดหวัง:

```text
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/account_evidence.json
runtime/forensic_days/YYYY-MM-DD/crash_reconnects.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="what-updates-when-the-scan-progresses"></a>
## มีการอัปเดตอะไรบ้างเมื่อการสแกนดำเนินไป

การอัปเดตที่คาดหวัง:

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/object_registry_partial.json
runtime/world_state/current/world_state_latest.json
runtime/forensic_days/YYYY-MM-DD/forensic_day_summary.json
```

<a id="what-to-upload-for-quick-analysis"></a>
## สิ่งที่ต้องอัปโหลดเพื่อการวิเคราะห์อย่างรวดเร็ว

แพ็คเกจที่ดีที่สุด:

```text
runtime/final_logs/YYYY-MM-DD/
```

แพ็คเกจที่สมบูรณ์ยิ่งขึ้น:

```text
runtime/forensic_days/YYYY-MM-DD/
```

แพ็คเกจหลักฐานฉบับเต็ม:

```text
runtime/account_evidence.json
runtime/evidence/session_events.jsonl
runtime/server_lifecycle_events.jsonl
runtime/warning_events.jsonl
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```
