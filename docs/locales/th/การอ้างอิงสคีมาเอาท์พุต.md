# การอ้างอิงสคีมาเอาต์พุตและสถานะ

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [OUTPUT_SCHEMA_REFERENCE.md](../../OUTPUT_SCHEMA_REFERENCE.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


นี่คือสัญญามาตรฐานสำหรับไฟล์ที่ผู้ปฏิบัติงานสร้างขึ้น มีเพียงเจ้าของเส้นทางเอาต์พุต ชื่อฟิลด์ ค่าที่อนุญาต ข้อกำหนดการสืบเชื้อสาย และสกีมาเส้นทางที่แน่นอนเท่านั้น คำแนะนำขั้นตอนการเชื่อมโยงที่นี่แทนที่จะกำหนดข้อเท็จจริงเหล่านั้นใหม่

หลักฐานรันไทม์เชื่อถือได้ ชื่อไฟล์ ฮาร์ทบีทของตัวกำหนดตารางเวลา รายงานที่แปล หรือออบเจ็กต์กล่องขาออกในเครื่องไม่ได้พิสูจน์มากกว่าฟิลด์และสายเลือดของตัวเอง

<a id="public-report-routes"></a>
## เส้นทางรายงานสาธารณะ

ผู้ปฏิบัติงานรายงานเป็นเจ้าของห้าเส้นทางภายใต้ `runtime/final_logs/`:

| เส้นทาง | สัญญา | `full` ข้อกำหนด | ความหมายที่คาดหวังว่างเปล่า |
|---|---|---|---|
| `server_status` | ตัวกำหนดเวลาปัจจุบัน บันทึกที่ใช้งานอยู่ รอการสแกน และสถานะความครอบคลุมของแหล่งที่มา | เหตุการณ์ boot/epoch/poll เชื้อสาย บันทึกที่ใช้งานใหม่ accounting/history เขียน และ JSON/TXT คู่ | ไม่ได้ใช้สำหรับวงจรกระแสไฟฟ้าที่ดี; สายเลือดที่ขาดหายไปคือ `missing`. |
| `daily_rollup` | เหตุการณ์ day/window ความต่อเนื่องทั่วทั้งเซิร์ฟเวอร์ ผู้เล่น กรณี การสแกน และความครอบคลุม | เทอร์มินัลการบัญชีตามประวัติที่เพียงพอสำหรับเส้นทางและการพิสูจน์วงจรปัจจุบันเสร็จสมบูรณ์ | ไม่มีผู้เล่นที่คงอยู่และไม่มีกรณีการตรวจสอบ |
| `player_activity` | แยกการสังเกตปัจจุบันและประวัติ player/account | การพิสูจน์วัฏจักรปัจจุบันบวกหนึ่งแถวขึ้นไป current/historical แถว | ไม่มีแถวผู้เล่นที่มีสิทธิ์ในอินพุตที่มีขอบเขต ไม่มีหัวเรื่องสังเคราะห์ |
| `case_review` | กรณีและปัญหาที่ระบุชื่อและผู้สมัคร review/BAN-ELIGIBLE ปัจจุบัน | หลักฐานรอบปัจจุบันบวกกับกรณีที่มีชื่ออย่างน้อยหนึ่งกรณีพร้อมการอ้างอิงแหล่งที่มา | ไม่มีกรณีและปัญหาที่มีชื่อตรงตามเกณฑ์การพิจารณา ไม่มีกรณีสังเคราะห์ |
| `critical_guard` | ตัวกำหนดเวลาการบูตปัจจุบัน การเริ่มต้น การหยั่งเสียง หรือความล้มเหลวด้านความสมบูรณ์ของหลักฐาน | การพิสูจน์รอบปัจจุบันบวกกับความล้มเหลวที่สำคัญในปัจจุบัน | ไม่มีความล้มเหลวที่สำคัญในปัจจุบัน ข้อผิดพลาดข้อความเก่าไม่ได้เป็นเจ้าของเส้นทางนี้ |

ทุกเส้นทางที่เปิดใช้งานเขียน `<route>_latest.json` และ `<route>_latest.txt` การจับคู่จะไม่สมบูรณ์จนกว่า `runtime/final_logs/route_proof.json` จะบันทึกเวอร์ชัน บูต ยุค โพล และความใหม่ของแหล่งที่มาเดียวกัน

<a id="report-json-schema"></a>
## รายงาน JSON schema

เส้นทางทั้งหมด JSON ใช้ `schema="randomdayguard.report/v1"`.

| ฟิลด์ | ประเภท | ความหมายและความคงที่ |
|---|---|---|
| `schema` | string | ทุกประการ `randomdayguard.report/v1`. |
| `generated_ts`, `report_date` | string | การประทับเวลาการสร้างและวันที่การรายงาน |
| `version` | string | Runtime/package ข้อมูลประจำตัวสำหรับรอบนี้ |
| `boot_id`, `epoch_id` | string | ยุคการบูตกระบวนการปัจจุบันและยุคความต่อเนื่องของเซิร์ฟเวอร์ จำเป็นต้องมีทั้งสองอย่างจึงจะเสร็จสมบูรณ์ |
| `poll_id` | จำนวนเต็ม | ตัวระบุโพลปัจจุบันที่เป็นบวก Zero/missing ไม่สามารถดำเนินการเส้นทางให้เสร็จสิ้นได้ |
| `source_freshness` | object | `status`, `checked_ts` สถานะบันทึกที่ใช้งานอยู่ การประทับเวลาโพลครั้งล่าสุด และการประทับเวลาโพลที่เสร็จสมบูรณ์ครั้งล่าสุด |
| `current_cycle_proof_complete` | บูลีน | จริงเฉพาะเมื่อเชื้อสายและหลักฐานใหม่ active-log/current-poll เห็นด้วย |
| `route` | enum | หนึ่งในห้าเส้นทางข้างต้น |
| `route_proof_status` | enum | `full`, `limited_expected_empty` หรือ `missing`. |
| `coverage_status` | enum | ทุกประการ `complete`, `complete_with_gaps`, `partial` หรือ `unavailable`. |
| `completed`, `expected_empty` | บูลีน | `completed` เป็นเท็จเฉพาะสำหรับ `missing`; `expected_empty` เป็นจริงสำหรับ `limited_expected_empty`. |
| `observed` | อาร์เรย์ของสตริงเท่านั้น | คอนกรีตถูกเก็บรักษาไว้ facts/counts/statuses. |
| `interpretation` | อาร์เรย์ของสตริงเท่านั้น | ความหมายที่ระมัดระวัง ปรับเทียบกับหลักฐาน |
| `unknown` | อาร์เรย์ของสตริงเท่านั้น | ข้อมูลประจำตัวที่หายไป ประวัติ แหล่งที่มา หรือบริบท |
| `does_not_prove` | อาร์เรย์ของสตริงเท่านั้น | ข้อสรุปที่หลักฐานไม่สนับสนุน |
| `next_action` | string | การดำเนินการที่มีขอบเขตที่ปลอดภัยที่สุด |
| `source_references` | อาร์เรย์ของสตริงเท่านั้น | เรียงลำดับที่ไม่ซ้ำกัน runtime/Saved การอ้างอิง |
| `enforcement_authority` | บูลีน | เท็จเสมอ รายงานไม่เคยให้สิทธิ์การเขียน |
| `output_paths` | สองสาย | JSON และ TXT ที่เพิ่มก่อนการเขียนที่จับคู่ |

`coverage_status` เป็นการบัญชีระดับบนสุดเท่านั้น แหล่งที่มาของบันทึกแยกกันเป็นของตัวเอง `available`, `expected_empty`, `partial`, `deferred`, `unavailable`, `malformed`, `permission_denied` และ `error`. หลักฐานเส้นทางเป็นเจ้าของแยกต่างหาก `full`, `limited_expected_empty` และ `missing`; ค่านิยมไม่เคยข้ามขอบเขตเหล่านี้

ส่วนขยายเส้นทาง:

- `server_status`: `scheduler_status`, `active_log_status` และ `server_metrics`. ตัวชี้วัดจะบันทึกการเริ่มต้นยุคปัจจุบัน การประทับเวลาและรหัสการสำรวจความคิดเห็นที่เสร็จสมบูรณ์ล่าสุด จำนวนผู้เล่นที่ใช้งานอยู่ active/backup-log นับ, สแกน pending/progress ค่า และ configured/usable/unavailable การบัญชีกลุ่มแหล่งที่มา พวกเขาไม่สร้างเวลาทำงาน การนับการรีสตาร์ท การประทับเวลาสำรอง หรือระยะเวลาการหยุดทำงานเมื่อไม่มีแหล่งที่มาใดเปิดเผยข้อเท็จจริงเหล่านั้น
- `player_activity`: `player_activity_present`, `movement`, `same_day_sessions`, `current_player_count`, `current_evidence_player_count`, `historical_player_count`, `historical_session_count`, `current_players`, `historical_players` และอาร์เรย์ความเข้ากันได้ `players`. แต่ละเซสชันในวันเดียวกันจะเก็บรหัสเซสชัน รหัสบัญชี ชื่อที่แสดงเมื่อทราบ join/leave การประทับเวลา แฟล็ก clean-exit และ lifecycle และการอ้างอิงแหล่งที่มา ข้อมูลระบุตัวตนที่เก็บไว้และการมีอยู่ของ PlayerData ยังคงเป็นบริบท ไม่ใช่หลักฐานของกิจกรรมในปัจจุบัน
- `case_review`: `cases`, `review_subjects`, `current_case_count` และ `retained_case_count`. หัวข้อการทบทวนปัจจุบันบันทึก case/account ID, ชื่อที่แสดงเมื่อทราบ, สถานะ, คะแนน, ความเชื่อมั่นในตัวตน, first/last การสังเกต จำนวนคำเตือน เหตุผล การตั้งค่าสถานะปัจจุบัน และการอ้างอิงแหล่งที่มา เคสที่เก็บรักษาไว้ไม่ได้สร้างหัวเรื่องปัจจุบันด้วยตัวเอง
- `critical_guard`: `critical_failure_present` และ `current_boot_error_only=true`.
- `daily_rollup`: `daily_maturity`, `once_per_day_continuity`, `dedupe_window` และ `daily_metrics`. ตัวชี้วัดจะบันทึกวันที่รายงาน ผู้เล่นที่ใช้งานอยู่ บัญชีที่มีกิจกรรมในวันเดียวกัน การเข้าร่วม การลาออก ทางออกที่สะอาดและไม่สะอาด การคืนวงจรชีวิต หัวข้อการตรวจสอบที่มีชื่อในปัจจุบัน กรณีที่ถูกเก็บไว้ current/retained การนับข้อมูลประจำตัว และความครอบคลุมของกลุ่มแหล่งที่มา

<a id="translated-txt-schema"></a>
## การแปล TXT schema

ไฟล์ข้อความที่จับคู่นำไปสู่ผลลัพธ์ที่โอเปอเรเตอร์สามารถอ่านได้ และย้ายรายละเอียดเชื้อสายไปยังจุดสิ้นสุด โดยจะรักษาลำดับส่วนนี้ไว้:

```text
RandomDayGuard <route title>
Generated: <timestamp>

Summary
<one plain-language route summary>

What Guard observed
- ...

What it means
- ...

What remains unknown
- ...

Recommended next step
...

Evidence boundary
- ...

Rating explanation
- ...

Technical record
- Route: <route>
- Version: <version>
- Cycle: boot=<boot> epoch=<epoch> poll=<poll>
- Source freshness: <status>
- Route result: <full|limited_expected_empty|missing>
- Coverage: <status>

Translation notes
- ...

Source references
- ...
```

การแปลใช้เฉพาะฟิลด์รายงานที่มีโครงสร้างและการแมปพจนานุกรมที่ได้รับอนุมัติเท่านั้น ไม่สามารถเพิ่มผู้เล่น กรณี การส่งมอบ สาเหตุ ความเป็นเจ้าของ เจตนา หรือการมีสิทธิ์บังคับใช้ที่ขาดหายไปจากรายงานแบบมีโครงสร้าง รายละเอียดทางเทคนิคยังคงมีอยู่โดยไม่ต้องแทนที่ผลลัพธ์ที่อ่านได้

<a id="source-accounting-schema"></a>
## สคีมาการบัญชีแหล่งที่มา

`runtime/final_logs/source_accounting_latest.json` ใช้ `randomdayguard.source-accounting/v1` พร้อมการสร้าง reason/status, enablement/disabled เหตุผล current/historical ความแตกต่าง รายการไฟล์ที่เปลี่ยนแปลง บันทึกแหล่งที่มา usable/unavailable รายการคลาส และขีดจำกัดการอ้างสิทธิ์

แต่ละระเบียนแหล่งที่มาประกอบด้วย:

| ฟิลด์ | ประเภท | ความหมาย |
|---|---|---|
| `source_class` | string | หนึ่งในแปดคลาสด้านล่าง |
| `scope` | `current` หรือ `historical` | ความเป็นเจ้าของเวลา; ขอบเขตจะไม่ถูกรวมเข้าด้วยกันโดยไม่โต้ตอบ |
| `required` | บูลีน | ต้องใช้ `active_log` เท่านั้นเพื่อความสดใหม่ของเส้นทางรอบปัจจุบัน |
| `status` | enum | ผลลัพธ์แหล่งที่มาที่แสดงด้านล่าง |
| `terminal` | บูลีน | False only for `partial` และ `deferred`. |
| `available`, `readable` | บูลีน | True only for `available` และ `expected_empty`. |
| `file_count` | จำนวนเต็ม | Bounded accounted file/reference นับ |
| `source_references` | อาร์เรย์ | เรียงลำดับแหล่งที่มาที่ไม่ซ้ำกัน paths/references. |
| `detail` | string | ผลลัพธ์ที่มีขอบเขตหรือรายละเอียดข้อผิดพลาด |
| `does_not_prove` | string | ความพร้อมใช้งานไม่ใช่เจตนา ความเป็นเจ้าของ ความเสียหาย การทำซ้ำ หรือการพิสูจน์การบังคับใช้ |

คลาสแหล่งที่มา:

| คลาสแหล่งที่มา | ขอบเขต | ประโยชน์อะไรบ้าง | สิ่งที่พิสูจน์ไม่ได้ |
|---|---|---|---|
| `active_log` | ปัจจุบัน, จำเป็น | บันทึกเซิร์ฟเวอร์ที่ใช้งานอยู่ที่สามารถอ่านได้และสายเลือดการสำรวจใหม่ | กรอกประวัติหรือความผิดของผู้เล่น |
| `admin_ini` | ปัจจุบัน ไม่บังคับ | สถานะปัจจุบัน moderator/ban ที่ถูกต้องตามโครงสร้าง หรือการขาดหายไปที่คาดไว้ | พฤติกรรมของผู้เล่นหรือข้อมูลเมตาของเหตุผลที่ถูกต้อง |
| `recent_backup_logs` | ประวัติ | สามารถอ่านได้ rotated/backup การอ้างอิงบันทึก | สถานะปัจจุบันหรือสถานะการบูตปัจจุบัน |
| `playerdata_filenames` | บริบทปัจจุบัน | การอ้างอิงชื่อไฟล์ที่อ่านได้แบบมีขอบเขตภายใต้รูทที่บันทึกไว้ที่เลือก | ความเป็นเจ้าของไฟล์ การแสดงตนสด ข้อมูลประจำตัว เนื้อหาหรือการประพฤติมิชอบ |
| `existing_cases` | ประวัติ | กรณีที่มีชื่อที่เก็บรักษาไว้ files/index บันทึกที่บันทึกไว้ก่อนเอาท์พุตปัจจุบัน | กิจกรรมปัจจุบันหรือความถูกต้องของข้อสรุปเก่า |
| `existing_reports` | ประวัติ | ที่เก็บรักษา final/forensic/warning การอ้างอิงรายงาน | แหล่งข้อมูลที่เชื่อถือได้ การทดแทน |
| `existing_evidence` | ประวัติ | การอ้างอิงหลักฐานที่เก็บไว้ | ความสมบูรณ์ของเหตุการณ์ที่เซิร์ฟเวอร์ไม่เคยเปิดเผย |
| `world_save_scan` | ประวัติ | ขอบเขตที่สมบูรณ์ บางส่วน เลื่อนออกไป หรือไม่พร้อมใช้งาน scan/checkpoint สถานะ | การกระทำหรือการเป็นเจ้าของของผู้เล่นคนใดคนหนึ่ง |

ค่าสถานะแหล่งที่มา:

| สถานะ | เทอร์มินัล | ความหมายและการดำเนินการของตัวดำเนินการ |
|---|---:|---|
| `available` | ใช่ | มีแหล่งข้อมูลที่เป็นประโยชน์ที่อ่านได้อยู่แล้ว ตรวจสอบข้อมูลอ้างอิง |
| `expected_empty` | ใช่ | แหล่งทางเลือกได้รับการตรวจสอบและถูกต้องตามกฎหมาย absent/empty อย่าประดิษฐ์ข้อมูล |
| `partial` | no | งานมีขอบเขตหรือขีดจำกัดสินค้าคงคลังไม่สมบูรณ์ อนุญาตให้ดำเนินการต่อ |
| `deferred` | no | งานอยู่ระหว่างการพิจารณาโดยเจตนา; รอผู้ปฏิบัติงานที่เป็นเจ้าของ |
| `unavailable` | ใช่ | Source/path/tool ขาดหายไปหรือใช้ไม่ได้ ซ่อมแซมเฉพาะในกรณีที่จำเป็นตามเส้นทาง |
| `malformed` | ใช่ | เนื้อหาไม่ผ่านการตรวจสอบโครงสร้าง เก็บรักษาและซ่อมแซมรูปแบบ |
| `permission_denied` | ใช่ | การเข้าถึงถูกปฏิเสธอย่างชัดเจน คืนค่าการเข้าถึงการอ่านที่มีสิทธิ์น้อยที่สุด |
| `error` | ใช่ | ขอบเขตระดับแหล่งที่มา probe/read ล้มเหลวโดยไม่คาดคิด ตรวจสอบ `detail` โดยไม่เปิดเผยความลับ |

ระดับบนสุด `coverage_status` ถูกต้องทุกประการ `complete`, `complete_with_gaps`, `partial` หรือ `unavailable` ระดับแหล่งที่มาที่จำเป็น `error`, `malformed` หรือ `permission_denied` สะสมถึงระดับบนสุด `unavailable`; ระดับแหล่งที่มา `deferred` สะสมถึงระดับบนสุด `partial` การปิดใช้งานการบัญชีต้นทางยังคงเขียนสถานะไม่พร้อมใช้งานและบังคับให้ทุกเส้นทางไปยัง `missing`.

<a id="historical-status-schema"></a>
## สคีมาสถานะเชิงประวัติ

`runtime/final_logs/historical_backfill_latest.json` ใช้ `randomdayguard.history/v1`: `generated_ts`, การบัญชี `status`, `resumable=true`, `changed_file_refresh=true`, `current_evidence_is_not_history=true`, อาร์เรย์การบัญชีต้นทาง, คลาสที่ไม่พร้อมใช้งาน และขอบเขต `next_action`.

`runtime/history/public_accounts.tsv` เป็นประวัติสาธารณะที่คงทนด้วยส่วนหัวนี้:

```text
account_id	ban_id	display_name	identity_confidence	status	score	first_seen	last_seen	source_references
```

แถวจะถูกจัดเรียงตาม ID บัญชี ฟิลด์คือ single-line/tab-safe และการอ้างอิงคือ sorted/unique ไฟล์นี้รักษาบริบททางประวัติศาสตร์ในการรีสตาร์ทแบบเงียบ มันไม่เคยเปลี่ยนประวัติศาสตร์ให้เป็นปัจจุบัน

<a id="route-proof-schema"></a>
## สคีมาการพิสูจน์เส้นทาง

`runtime/final_logs/route_proof.json` ใช้ `randomdayguard.route-proof/v1` และบันทึกการประทับเวลาการสร้างระดับบนสุด เวอร์ชัน การบูต ยุค การสำรวจ ความใหม่ของแหล่งที่มา ความสมบูรณ์ของวงจรปัจจุบัน สถานะที่อนุญาต และ `routes` อาร์เรย์

แต่ละรายการเส้นทางประกอบด้วย route/status, version/boot/epoch/poll, ออบเจ็กต์ความสดของแหล่งที่มา, ความสมบูรณ์ของวงจรปัจจุบัน, เส้นทางเอาต์พุต และการอ้างอิงแหล่งที่มา บันทึกเส้นทางที่ปิดใช้งาน `status="missing"` และ `reason="route_disabled"`. หากการเขียนการพิสูจน์เส้นทางล้มเหลว ทุกเส้นทางจะถูกเขียนใหม่เป็น incomplete/missing ก่อนที่จะยอมรับผู้สมัครการแจ้งเตือน

<a id="notification-schemas"></a>
## สคีมาการแจ้งเตือน

โหมดสาธารณะที่เป็นตัวเลือกคือกล่องขาออกของไฟล์ในเครื่องเท่านั้น

`runtime/notifications/pending/<route>_latest.json` ใช้ `randomdayguard.notification/v1` พร้อมการประทับเวลาที่สร้างขึ้น version/boot/epoch/ poll/source ความสดใหม่ เส้นทาง `completed_output`, สถานะการพิสูจน์เส้นทาง, เส้นทางรายงานที่มีโครงสร้างและแปลแล้ว, การอ้างอิงแหล่งที่มา, `delivery_backend="none"` และ `delivery_attempted=false`. การใช้เอาต์พุตที่มีสิทธิ์ `status="ready_for_local_consumer"`, `delivery_eligible=true` และ `delivery_allowed=true`. กำหนดค่า แต่ missing/ineligible ยังคงเขียนซองจดหมายการตรวจสอบด้วย `status="suppressed_current_cycle"` ทั้งสองค่าสถานะการจัดส่งเป็นเท็จ และ `suppression_reason="route_or_completion_policy_blocked"`. ดังนั้นการมีไฟล์อยู่ภายใต้ `pending/` ไม่ได้หมายถึงอยู่ในคิวหรือมีสิทธิ์

`runtime/notifications/notification_status.json` ใช้ `randomdayguard.notification-status/v1` มีเชื้อสายเดียวกัน `generic_local_outbox_only=true`, `delivery_attempted=false` และต่อเส้นทาง `queued`/`outcome` แถว `full` มีสิทธิ์; คาดว่าว่างเปล่าจะมีสิทธิ์เฉพาะเมื่อ `include_expected_empty=true`; `missing` ไม่มีสิทธิ์ ในความล้มเหลวในการเขียนเพื่อพิสูจน์เส้นทาง ผลลัพธ์ของสถานะคือ `route_proof_write_failed`; ซองจดหมายการตรวจสอบที่ถูกระงับอาจยังคงเขียนได้ แต่จะไม่ได้รับการยอมรับเอาท์พุต

ZIP ของแพ็คเกจมีเพียงค่าว่าง `.gitkeep` ตัวยึดตำแหน่งภายใต้ `runtime/`; ใดๆevidence/output ไบต์ในแพ็คเกจที่วางจำหน่ายไม่ผ่านการตรวจสอบ

## เมทริกซ์ความล้มเหลวและการกู้คืน

| ล้มเหลว | สถานะที่จำเป็น | การกู้คืนอย่างปลอดภัย | การอนุมานไม่ถูกต้อง |
|---|---|---|---|
| เชื้อสายปัจจุบัน absent/stale | ทุกเส้นทาง `missing`. | กู้คืน active-log/current-poll พิสูจน์และสร้างใหม่ | ไฟล์เส้นทางเก่ายังไม่เสร็จสมบูรณ์ในปัจจุบัน |
| แหล่งทางเลือกที่คาดว่าจะว่างเปล่า | แหล่งที่มา `expected_empty`; เส้นทางที่มีสิทธิ์อาจเป็นได้`limited_expected_empty`. | ไม่มีการซ่อมแซมเว้นแต่ว่าแหล่งที่มาควรมีอยู่ | ไม่มีข้อมูลว่างและไม่ได้พิสูจน์ว่าไม่มีข้อมูลในอดีต |
| การสแกนไม่สมบูรณ์ | แหล่งที่มา `partial` หรือ `deferred`. | อนุญาตให้ดำเนินการต่อแบบมีขอบเขต; รักษานโยบายเส้นทางปัจจุบันให้ชัดเจน | บางส่วนไม่เสียหาย |
| แหล่งข้อมูลที่ต้องการไม่พร้อมใช้งาน | `coverage_status=unavailable`; เส้นทางขึ้นอยู่กับ`missing`. | เลือกการซ่อมแซมแล้ว Saved/log เข้าถึง | แหล่งที่มาที่ดีอื่นๆ ไม่สามารถแทนที่แหล่งที่มาที่ต้องการได้ |
| ข้อผิดพลาดของโพรบแหล่งที่มาที่จำเป็น | สถานะแหล่งที่มา `error` มีขอบเขต `detail`; `coverage_status=unavailable`; เส้นทางขึ้นอยู่กับ`missing`. | ซ่อมแซมชื่อ source/probe และสร้างวงจรใหม่ | ข้อผิดพลาดของแหล่งที่มาไม่ใช่ค่าความครอบคลุมระดับบนสุดอันดับที่ห้า |
| การเขียนรายงานที่จับคู่ล้มเหลว | `coverage_status=unavailable`; เส้นทางมาบรรจบกันที่`missing`. | ซ่อมแซมระบบไฟล์และเขียนสมาชิกทั้งคู่ใหม่พร้อมการพิสูจน์ | ไฟล์พี่น้องหนึ่งไฟล์ไม่สมบูรณ์ และความล้มเหลวในการเขียนไม่ใช่ระดับบนสุด `error`. |
| การเขียนการพิสูจน์เส้นทางล้มเหลว | ทุกเส้นทางที่เขียนใหม่หายไป ไม่มีกล่องขาออกที่มีสิทธิ์ เส้นทางที่กำหนดค่าอาจได้รับซองการตรวจสอบที่ถูกระงับ | ซ่อมแซมการเขียนที่พิสูจน์เส้นทางและสร้างเอาต์พุตรอบเดียวกันใหม่ | รายงานที่ดูถูกต้อง JSON หรือซองจดหมายที่ถูกระงับไม่ใช่การพิสูจน์เส้นทาง |
| การเขียนการแจ้งเตือนล้มเหลว | ผลลัพธ์ `local_outbox_write_failed`. | ซ่อมแซมรูทเอาต์พุตในเครื่อง สร้างใหม่จากรายงานที่เสร็จสมบูรณ์ | ไม่มีการจัดส่งภายนอกเกิดขึ้น |
| Admin.ini ธุรกรรมล้มเหลว | การบังคับใช้ถูกบล็อกด้วย backup/write/readback/rollback หลักฐานที่อ้างอิง | กู้คืนข้อมูลสำรองที่ตรวจสอบแล้ว; ยังคงเป็นบทวิจารณ์เท่านั้น | เกณฑ์หรือรายงานไม่สามารถยืนยันการข้ามการกู้คืนได้ |
