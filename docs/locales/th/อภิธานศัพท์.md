# อภิธานศัพท์

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [GLOSSARY.md](../../GLOSSARY.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


| คำศัพท์ | ความหมายธรรมดา | ทางเทคนิคที่แน่นอน ความหมาย |
|---|---|---|
| บันทึกที่ใช้งานอยู่ | บันทึกเซิร์ฟเวอร์ปัจจุบันที่ใช้สำหรับหลักฐานใหม่ | แหล่งที่มา `active_log` จำเป็น; ความสามารถในการอ่านบวกกับเชื้อสายปัจจุบันเป็นสิ่งจำเป็นสำหรับการทำให้เส้นทางเสร็จสมบูรณ์ |
| Boot ID | กระบวนการเฝ้าระวังเริ่มต้นขึ้น | ตัวระบุรันไทม์ปัจจุบันใช้เพื่อปฏิเสธการบูตก่อนหน้า errors/reports. |
| Epoch ID | หนึ่งช่วงความต่อเนื่องของเซิร์ฟเวอร์ | ตัวระบุซึ่งครอบคลุมรันไทม์ปกติจนกว่าตรรกะความต่อเนื่องจะเริ่มต้นยุคอื่น |
| รหัสการสำรวจความคิดเห็น | โอกาสในการสำรวจแบบมีขอบเขตหนึ่งรายการ | ฟิลด์วงจรโมโนโทนิกเชิงบวก zero/missing ไม่สามารถดำเนินการเส้นทางให้เสร็จสิ้นได้ |
| ความใหม่ของแหล่งที่มา | ไม่ว่าแหล่งที่มาปัจจุบันและเชื้อสายของการสำรวจความคิดเห็นจะเห็นด้วยหรือไม่ | `fresh_current_poll` หรือ `stale_or_unproven` พร้อมการประทับเวลาและสถานะบันทึกที่ใช้งานอยู่ |
| การบัญชีต้นทาง | รายการหลักฐานที่มีอยู่และขีดจำกัด | `randomdayguard.source-accounting/v1` พร้อมคลาสแหล่งที่มาแปดคลาสและ current/historical ขอบเขต |
| `available` | พบแหล่งที่มาและอ่านได้ | สถานะแหล่งที่มาของเทอร์มินัลที่มี `available=true`, `readable=true`. |
| `expected_empty` | แหล่งข้อมูลทางเลือกได้รับการตรวจสอบและถูกต้องตามกฎหมาย absent/empty. | สถานะแหล่งที่มาของเทอร์มินัลที่อ่านได้; ไม่เคยสร้างหัวเรื่อง |
| `partial` | งานที่มีขอบเขตมีประโยชน์แต่ได้ผลลัพธ์ที่ไม่สมบูรณ์ | สถานะ Nonterminal source/accounting; ดำเนินการต่อโดยผู้ปฏิบัติงานที่เป็นเจ้าของ |
| `deferred` | งานอยู่ระหว่างการพิจารณาโดยเจตนา | สถานะแหล่งที่มาที่ไม่ใช่เทอร์มินัล; ไม่ใช่ข้อผิดพลาดหรือความสมบูรณ์ |
| `unavailable` | ไม่สามารถใช้แหล่งที่มาได้ในขณะนี้ | ช่องว่างของเทอร์มินัล; ช่องว่างของแหล่งที่มาที่จำเป็นทำให้การบัญชีใช้งานไม่ได้ |
| `malformed` | มีแหล่งที่มาแต่โครงสร้างไม่ถูกต้อง | ช่องว่างของเทอร์มินัลรักษารายละเอียดการตรวจสอบและการปิดการเขียนที่ขึ้นต่อกัน |
| `permission_denied` | ระบบปฏิบัติการถูกปฏิเสธการเข้าถึงอย่างชัดเจน | ช่องว่างของเทอร์มินัลแตกต่างจาก missing/unavailable. |
| `error` | ขอบเขตแบบมีขอบเขต การดำเนินการล้มเหลวโดยไม่คาดคิด | เทอร์มินัลล้มเหลวซึ่งต้องการการกู้คืนที่ระบุชื่อ ไม่มีรายละเอียดที่เป็นความลับอยู่ในรายงานสาธารณะ |
| `complete` | แหล่งที่มาที่บัญชีทั้งหมดเป็นเทอร์มินัลโดยไม่มีช่องว่าง | สถานะการบัญชีแหล่งที่มาระดับบนสุด |
| `complete_with_gaps` | หลักฐานปัจจุบันที่จำเป็นใช้งานได้ ช่องว่างเทอร์มินัลเพิ่มเติมยังคงอยู่ | สถานะการบัญชีระดับบนสุด; เส้นทางยังคงใช้ข้อกำหนดของตนเอง |
| `full` | เส้นทางที่เสร็จสมบูรณ์โดยมีสัญญาไม่ว่างเปล่าที่จำเป็น | แจงนับการพิสูจน์เส้นทางพร้อมเอาต์พุตรอบปัจจุบันที่เสร็จสมบูรณ์ |
| `limited_expected_empty` | เส้นทางเสร็จสมบูรณ์และไม่พบสิทธิ์ subject/failure. | แจงนับการพิสูจน์เส้นทางด้วย `completed=true`, `expected_empty=true`. |
| `missing` | หลักฐานการเสร็จสิ้นเส้นทางขาดหายไปหรือล้มเหลว | แจงนับการพิสูจน์เส้นทางด้วย `completed=false`; ไม่เคยมีสิทธิ์ได้รับกล่องจดหมายออก |
| รายงานที่มีโครงสร้าง | เอาต์พุตเส้นทางที่เครื่องอ่านได้ | `<route>_latest.json` โดยใช้ `randomdayguard.report/v1`. |
| รายงานที่แปล | การเรนเดอร์เส้นทางเดียวกันที่มนุษย์สามารถอ่านได้ | `<route>_latest.txt` พร้อมลำดับการอ้างอิงแบบสังเกตถึงแหล่งที่มาแบบคงที่ |
| หลักฐานเส้นทาง | บัญชีแยกประเภทการเสร็จสิ้นข้ามเส้นทาง | `route_proof.json` การเชื่อมโยง version/boot/epoch/poll/freshness/output เส้นทาง |
| หลักฐานปัจจุบัน | การสังเกตที่เป็นของวงจรที่ใช้งานอยู่ | ขอบเขต `current`; ไม่ได้สร้างขึ้นใหม่จากเก่าfilenames/reports. |
| หลักฐานทางประวัติศาสตร์ | เก็บรักษาบริบทจากรอบก่อนหน้าหรือการสแกนช้า | ขอบเขต `historical`; อาจแจ้งการตรวจสอบแต่ไม่สามารถเรียกร้องสถานะปัจจุบันได้ |
| รีวิวเท่านั้น | สร้างหลักฐานการตรวจสอบโดยไม่มี Admin.ini จริง | ค่าเริ่มต้น `review_only_mode=true`, `auto_ban=false`, `write_admin_ini=false`. |
| การตรวจสอบความปลอดภัยของรายการห้าม | หนึ่งคำถามที่ Guard ต้องตอบก่อนที่จะมีการเปลี่ยนแปลง `Admin.ini`. | จะต้องยืนยันบัญชีและคะแนน ไม่รวมบัญชีที่เชื่อถือได้และรายการที่ซ้ำกัน ตรวจสอบการสำรองข้อมูล ตรวจจับการเปลี่ยนแปลงภายนอก บันทึกการอัปเดตที่ต้องการ และตรวจสอบหรือกู้คืนไฟล์ทั้งหมดอย่างปลอดภัย |
| กล่องขาออกในเครื่อง | แฮนด์ออฟการแจ้งเตือนที่เป็นกลางโดยผู้ให้บริการทางเลือก | JSON ไฟล์ใดด้วย `delivery_backend="none"` และ `delivery_attempted=false`. |
| พื้นฐาน | ภาพรวมบริบทของไฟล์ที่บันทึกไว้ที่ขอบเขตสมบูรณ์แล้ว | Manifest/object/world สถานะนำมาใช้ซ้ำเมื่อเข้ากันได้และใหม่เพียงพอเท่านั้น |
| จุดตรวจ | กลับสู่ตำแหน่งเดิมสำหรับงานสแกนที่ไม่สมบูรณ์ | `scan_checkpoint.json`; การลบไม่ใช่การกู้คืนเริ่มต้น |
| ดัชนีที่สร้างใหม่ได้ | สรุปที่สามารถสร้างใหม่ได้ | Daily/weekly/forensic/final ตรวจสอบผลลัพธ์; หลักฐานแหล่งที่มายังคงเชื่อถือได้ |
| ขอบเขตหลักฐาน | จำกัดสิ่งที่แหล่งข้อมูลสามารถรองรับได้ | ชัดเจน `does_not_prove`, ไม่ทราบ, ความเข้มงวดของข้อมูลประจำตัว และกฎขอบเขต |
