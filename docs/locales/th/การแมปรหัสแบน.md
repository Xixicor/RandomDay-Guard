# การแมปรหัสแบน

> **แหล่งที่มาของภาษาอังกฤษตามรูปแบบบัญญัติ:** [BAN_ID_MAPPING.md](../../BAN_ID_MAPPING.md). เอกสารที่แปลเป็นภาษาท้องถิ่นนี้จะรักษาคำสั่ง เส้นทาง คีย์ ค่าสถานะ แฮช และชื่อไฟล์ที่แน่นอน หากถ้อยคำทางเทคนิคแตกต่างออกไป ให้ใช้ต้นฉบับภาษาอังกฤษ


ใช้หน้านี้เมื่อแปลงชื่อผู้เล่นเป็น ปลอดภัย `Admin.ini` บรรทัดแบน

<a id="core-rule"></a>
## กฎหลัก

ชื่อที่แสดงไม่ใช่รหัสการแบน

`Admin.ini` ใช้:

```ini
BannedPlayer=<raw numeric player ID>
```

<a id="evidence-hierarchy"></a>
## ลำดับชั้นของหลักฐาน

| อันดับ | แหล่งที่มา | ใช้ |
|---:|---|---|
| 1 | บันทึกเซิร์ฟเวอร์ `Login request` | การแมปชื่อกับ ID ที่ดีที่สุด |
| 2 | `Player_<ID>.sav` | ยืนยัน ID ที่มีอยู่ |
| 3 | ที่มีอยู่ `Admin.ini` | ที่มีอยู่ bans/moderators |
| 4 | ภายนอก การแจ้งเตือนหรือกิจกรรมแผงโฮสต์ | Time/name บริบทเท่านั้น ไม่ใช่การพิสูจน์ ID |
| 5 | UE4SS focus/player บรรทัด | Presence/context เท่านั้น |
| 6 | วงจรการใช้งานของระบบหรือบันทึกคอนเทนเนอร์ | บริบทวงจรการใช้งานของโฮสต์เท่านั้น ไม่ใช่การพิสูจน์ ID |

<a id="extract-the-clean-id"></a>
## แยก clean ID

ตัวอย่างดิบ:

```text
ConnectID=2535422284688820_+_|0002d07b...
```

Clean `Admin.ini` value:

```ini
BannedPlayer=2535422284688820
```

อย่าวาง `_+_|...`.

<a id="verify-with-playerdata"></a>
## ตรวจสอบด้วย PlayerData

ตรวจสอบ:

```text
Saved/SaveGames/Server/Worlds/<WorldName>/PlayerData/Player_<ID>.sav
```

ความหมาย:

```text
The ID exists in the world save.
```

ข้อจำกัด:

```text
PlayerData may not prove the display name unless another source maps it.
```

<a id="when-not-to-ban"></a>
## เมื่อใดที่จะไม่แบน

อย่ากำหนด ID การแบนเมื่อ:

```text
the name only appears in an external notification
the name only appears in hosting-panel activity
UE4SS shows a name but no ConnectID
only system lifecycle or container logs exist
the ID is trusted or moderator
```
