# Կարգավիճակի և սխալի հղում

> **Կանոնական անգլերեն աղբյուր:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). Այս տեղայնացված փաստաթուղթը պահպանում է ճշգրիտ հրամաններ, ուղիներ, բանալիներ, կարգավիճակի արժեքներ, հեշեր և ֆայլերի անուններ: Եթե ​​տեխնիկական ձևակերպումը տարբերվում է, օգտագործեք անգլերեն աղբյուրը:


Օգտագործեք այս հղումը, երբ ախտանիշը դասակարգվի [Խնդիրների վերացում](%D4%BD%D5%86%D4%B4%D4%BB%D5%90%D5%86%D4%B5%D5%90%D4%BB_%D5%8E%D4%B5%D5%90%D4%B1%D5%91%D5%88%D5%92%D5%84.md): Կարդացեք կառուցված կարգավիճակի ֆայլը, որն անվանվել է սխալով: Հստակ ծածկագրերը ներկայացնում են անվտանգության և կյանքի ցիկլի հստակ վիճակներ. մի փլուզեք դրանք որպես ընդհանուր «Guard-ի ձախողում» արդյունք:

<a id="route-and-source-states"></a>
## Երթուղու և աղբյուրի վիճակները

| Արժեք | Իմաստը | Օպերատորի պատասխան |
|---|---|---|
| `full` | Երթուղու պայմանագիրն ավարտված է ընթացիկ ցիկլի աղբյուրի ապացույցով: | Կարդացեք երթուղու ապացույցների սահմանը; վերանորոգում չի ենթադրվում: |
| `limited_expected_empty` | Երթուղին ավարտված է և բացակայող գործունեությունը օրինական է այս ցիկլի համար: | Սինթետիկ չկա player/case իրադարձություն: |
| `missing` | Պահանջվող ելքը, տոհմային դաշտը կամ աղբյուրի ապացույցը բացակայում է: | Ստուգեք երթուղու պատճառը և անվանված աղբյուրի կարգավիճակը: |
| `available` | Անվանված աղբյուրը ընթեռնելի և օգտագործելի էր: | Գործողություն չկա: |
| `expected_empty` | Աղբյուրը ստուգված է և օրինականորեն տողեր չուներ: | Ոչ մի գործողություն, քանի դեռ գործունեությունը անկախ չի սպասվում: |
| `partial` / `complete_with_gaps` | Գոյություն ունեն օգտագործելի ապացույցներ, սակայն անվանված աղբյուրի դասերը թերի են: | Եզրակացությունները սահմանափակեք հավաքագրված ապացույցներով: |
| `deferred` | Սահմանափակ աշխատանքը նախատեսված է ավելի ուշ աշխատողի համար: | Հաստատեք առաջընթացը նախքան կազմաձևումը փոխելը: |
| `unavailable` | Շրջակա միջավայրը չի տրամադրել աղբյուրը: | Գրանցեք սահմանաչափը; ուղղել միայն ապացուցված ճանապարհը կամ թույլտվության խնդիրը: |
| `malformed` | Աղբյուրը ընթեռնելի էր, բայց չհաջողվեց կառուցվածքային վավերացում: | Պահպանեք այն և ուղղեք աղբյուրը; մի գուշակեք: |
| `permission_denied` | Աղբյուրը գոյություն ունի, բայց հնարավոր չէ կարդալ: | Տրամադրեք միայն պահանջվող նեղ թույլտվությունը: |
| `error` | Հավաքումը ձախողվեց գրանցված պատճառով: | Պահպանեք սխալը և ախտորոշեք այդ փուլը: |

<a id="playerdata-and-inventory-codes"></a>
## PlayerData և գույքագրման կոդեր

| Կոդ | Իմաստը | Ապահով պատասխան |
|---|---|---|
| `saved_root_unavailable` | Ոչ մի հաստատված Պահված արմատ հասանելի չի եղել հանրային խողովակաշարի համար: | Ճիշտ `SavedRoot.txt` և նորից ստուգեք ուղու զոնդը: |
| `unsafe_playerdata_root` | PlayerData հայտնաբերումը լուծվել է սահմանափակված Պահված արմատից դուրս: | Ուղղեք ուղին; երբեք մի թուլացրեք սահմանը: |
| `playerdata_discovery_not_run` | Սահմանափակ հայտնաբերման աշխատողը դեռ չի գործարկվել: | Ստուգեք ժամանակացույցի և աշխատողի առաջընթացը: |
| `playerdata_discovery_read_failed:*` | Հայտնաբերման ելքը հնարավոր չէ կարդալ: | Պահպանեք վերջածանցի մանրամասները և ստուգեք սահմանափակված գույքագրման հրամանը: |
| `inventory_command_open_failed` | Գույքագրման գործընթացը չհաջողվեց սկսել: | Հաստատեք, որ գործարկման ժամանակը ապահովում է կազմաձևված հրամանի կամուրջը: |
| `inventory_command_read_failed` | Գույքագրման ելքը չհաջողվեց կարդալիս: | Պահպանել մասնակի ելքը և կրկնել միայն այն բանից հետո, երբ հիմնական սխալն ուղղվել է: |
| `inventory_command_close_failed` | Գույքագրումն ավարտված է առանց վստահելի փակման արդյունքի: | Աղբյուրը համարեք որպես թերի: |
| `identity_ledger_row_limit_exceeded` | Երկարատև ինքնության մուտքագրումը գերազանցել է հանրային անվտանգության սահմանը: | Արխիվացնել և վերանայել մատյանը; լուռ մի կտրեք այն որպես ամբողջական ապացույց: |

<a id="adminini-enforcement-codes"></a>
## Admin.ini հարկադիր կոդեր

Այս բաժնի բոլոր կոդերը փակված են: Նրանք չեն թույլատրում ձեռքով արգելել իրենց կողմից:

| Կոդ | Իմաստը | Ապահով պատասխան |
|---|---|---|
| `admin_ini_write_disabled` / `admin_ini_disabled` | Հանրային անվտանգ գրելու դարպասներն անջատված են: | Սպասվում է միայն վերանայման գործողության մեջ: |
| `admin_ini_backup_disabled` / `backup_safety_gate_disabled` | Պահուստավորման պահանջվող քաղաքականությունը ակտիվ չէ: | Գրումներն անջատված պահեք: |
| `enforcement_disabled` / `ban_on_threshold_disabled` / `auto_ban_disabled` | Մեկ բացահայտ կիրառման դարպաս անջատված է: | Սպասվում է միայն հանրային վերանայման լռելյայններում; մի վերաիմաստավորեք այն որպես գրելու ձախողում: |
| `review_only_mode_enabled` | Միայն վերանայման ռեժիմը միտումնավոր արգելափակում է մուտացիան: | Դիտեք միայն ապացույցները: |
| `duplicate_prevention_disabled` | Կրկնօրինակ պաշտպանությունն անջատված է: | Գրումն անջատված պահեք, մինչև անվտանգության դարպասը վերականգնվի: |
| `readback_safety_gate_disabled` / `rollback_safety_gate_disabled` | Հետգրելու հաստատումը կամ հետադարձ պաշտպանությունն անջատված է: | Գրումները պահել անջատված; երբեք մի շրջանցեք այս դարպասները: |
| `clean_id_safety_gate_disabled` / `account_specific_evidence_gate_disabled` | Մաքուր ինքնության կամ հաշվի հատուկ ապացույցների կիրառումն անջատված է: | Վերականգնեք դարպասը նախքան ցանկացած կիրառման փորձարկում: |
| `moderator_preservation_disabled` / `existing_ban_preservation_disabled` | Պաշտպանված հաշվի կամ գոյություն ունեցող արգելքի պահպանումն անջատված է: | Գրումներն անջատված պահեք: |
| `clean_numeric_identity_required` | Առաջարկվող ID-ն ամբողջական ընդունված կապի ձևը կամ մաքուր թվային ID-ն չէ: | Ստացեք հաստատված քարտեզագրում; երբեք մի կրճատեք կամայական նախածանցը: |
| `identity_strength_below_minimum` | Ինքնության վկայությունն ավելի թույլ է, քան կազմաձևված շեմը: | Դիտեք միայն ապացույցները: |
| `playerdata_verification_required` | Կազմաձևման համար պահանջվում է PlayerData հաստատում, և հաշիվն այն չունի: | Պահպանեք թեկնածուի վերանայումը միայն; Ֆայլի անունից մի եզրակացրեք սեփականության իրավունքը: |
| `trusted_or_moderator_identity` | Հաշիվը պաշտպանված է վստահելի կամ մոդերատորի կողմից: | Չի թույլատրվում գրել: |
| `admin_ini_path_invalid` / `admin_ini_path_outside_saved_root` | Թիրախային ուղին անվավեր է կամ դուրս է գալիս Պահված արմատից: | Ճիշտ կոնֆիգուրացիա; երբեք մի շրջանցեք ճանապարհի պահակին: |
| `admin_ini_unavailable` | Ընթեռնելի կազմաձևված չէ Admin.ini գտնվել է Պահված արմատի ներսում: | Ուղղեք սահմանափակված ուղին կամ անջատեք կիրառումը: |
| `admin_ini_read_failed` | Հեղինակավոր բայթերը հնարավոր չէ կարդալ: | Կանգնեք մուտացիայից առաջ: |
| `admin_ini_parse_failed` | Admin.ini վավերացումը ձախողվեց առանց ավելի կոնկրետ կառուցվածքային կոդի: | Պահպանեք ֆայլը և ստուգեք դրա բաժինն ու գծի կառուցվածքը: |
| `admin_ini_contains_nul` | Ֆայլը պարունակում է NUL բայթ և չի ընդունվում որպես տեքստ: | Պահպանեք ֆայլը և վերանորոգեք այն Պահակից դուրս: |
| `admin_ini_duplicate_banned_players_section` | Մեկից ավելի `[BannedPlayers]` բաժինը գոյություն ունի: | Միավորեք բաժինները ձեռքով, երբ դադարեցված է: |
| `admin_ini_banned_player_outside_section` | Արգելքի տող հայտնվում է դրսում `[BannedPlayers]`. | Ձեռքով շտկեք դասավորությունը: |
| `admin_ini_invalid_banned_player_line` | Արգելափակման տողը հենց այնպես մաքուր աջակցվող ID տող չէ: | Ուղղեք սխալ ձևավորված տողը: |
| `admin_ini_backup_failed` | Եզակի կրկնօրինակը նույնական բայթ չի գրել և կարդալ: | Ոչ մի մուտացիա չի թույլատրվում: |
| `admin_ini_external_change_detected` | Մեկ այլ գրող փոխեց ֆայլը Գվարդիայի լուսանկարից հետո: | Պահպանեք արտաքին բայթերը և նորից փորձեք միայն գրողներին համակարգելուց հետո: |
| `atomic_rename_unavailable` | Ատոմային փոխարինում է պահանջվել, սակայն Լուան չի տրամադրել `os.rename`. | Ոչ մի գրություն վստահելի չէ. օգտագործեք աջակցվող գործարկման ժամանակ կամ անջատեք կիրառումը: |
| `admin_ini_write_failed` | Վերահսկվող փոխարինումը չի ավարտվել: | Ստուգեք գրանցված փոխարինման սխալը և կրկնօրինակումը: |
| `post_write_verification_failed` | Արտադրական բայթերը չեն հավասարվել թեկնածուին: | Ստուգեք `rollback_success` և `rollback_refused_external_change` ցանկացած գործողությունից առաջ: |

<a id="startup-scheduler-and-backlog-states"></a>
## Գործարկման, ժամանակացույցի և հետաձգման վիճակներ

Այս արժեքները կյանքի ցիկլի ապացույց են, այլ ոչ թե երթուղու ապացույց: Կարդացեք դրանք ընթացիկ հարցման, հաշվետվության աշխատողի և երթուղու պաշտպանված ֆայլերով:

| Արժեք | Իմաստը | Ապահով պատասխան |
|---|---|---|
| `not_started` | Անվանված գործարկման կամ ժամանակացույցի փուլը չի ​​սկսվել: | Գործարկման ժամանակ սպասեք փաստաթղթավորված ընդմիջմանը; այնուհետև ստուգեք առաջին անփոփոխ փուլը: |
| `main_lua_loaded` / `starting` | Կանոնական բեռնիչը գործարկվեց, և Guard-ը գործարկվեց: | Շարունակել հետագա փուլերին; միայն սա պատրաստակամություն չէ: |
| `saved_root_found` / `log_tail_initialized` / `epoch_started` | Հիմնական աղբյուրի և շարունակականության սկզբնավորումն առաջադեմ է: | Ոչ մի գործողություն, եթե հաջորդ փուլը չդադարի առաջընթացը: |
| `admin_state_written` / `playerdata_index_written` | Նախնական սահմանափակված ինդեքսներն արտահանվել են: | Ոչ մի գործողություն; ժամանակացույցի հանձնումը դեռ պետք է հետևի: |
| `watchdog_started` | Զեկույցի և հարցումների դիտորդը գրանցվել է: | Հաջորդում հաստատեք ժամանակացույցը և հարցումների առաջընթացը: |
| `ready_degraded` / `scan_running` | Պահապանն աշխատում է, մինչ սահմանափակված պատմական սկանավորումը մնում է առկախ: | Զգույշ, ոչ թե ձախողում; ստուգեք առաջընթացի հաշվիչներն առաջ: |
| `ready` | Մեկնարկը և ընթացիկ սահմանափակված սկանավորումը պատրաստ են: | Առանձին ստուգեք երթուղու ապացույցը: |
| `scan_failed` / `error` | Գործարկումը կամ սկանավորումն ավարտվել է գրանցված սխալով: | Պահպանեք նշված սխալի կամ կարգավիճակի ֆայլը և ախտորոշեք այդ փուլը: |
| `running` | Ժամանակացույցին են պատկանում հարցումների ապագա հնարավորությունները: | Հաստատեք `poll_id` և `poll_completed_count` կանխավճար: |
| `manual_only` | Օղակի պլանավորումն անհասանելի էր; միայն բացահայտ աշխատանքը կարող է գործարկվել: | Անտեսված գործողությունը համարեք անհասանելի: |
| `stopped` | Ժամանակացույցի գործողությունն ավարտվեց: | Վերագործարկելուց առաջ ստուգեք նախորդ կանգառի և սխալի ապացույցները: |
| `active_log_caught_up` | Չկարդացված ակտիվ գրանցամատյան չի մնացել: | Պատմական սկանավորումը կարող է շարունակվել: |
| `active_log_unavailable_nonblocking` | Ակտիվ գրանցամատյանը բացակայում էր, բայց գործարկումը չարգելափակվեց: | Գրանցեք աղբյուրի սահմանաչափը և հաստատեք այլ աղբյուրներ: |
| `active_log_read_failed` | Ակտիվ մատյան գոյություն ուներ, բայց հնարավոր չէր կարդալ: | Պահպանեք սխալը և ուղղեք միայն ապացուցված ուղին կամ թույլտվության խնդիրը: |
| `budget_exhausted` / `active_log_has_unread_bytes` | Սահմանափակ պոչի անցաթուղթը կանգ է առել, քանի դեռ մնացել է հետընթաց: | Հաստատեք հետագա հարցումները, որոնք նվազեցնում են չկարդացվածների քանակը: |
| `offset_commit_failed_after_events_applied` | Միջոցառումները մշակվել են, սակայն երկարաժամկետ գրանցամատյանում օֆսեթների կայունությունը ձախողվել է: | Կատարումը հետաձգվում է; վերանորոգեք օֆսեթ պահեստը նախքան այլ ցիկլի վրա հիմնվելը: |

<a id="scheduler-report-and-notification-codes"></a>
## Ժամանակացույցի, զեկույցի և ծանուցման կոդեր

| Կոդ կամ կարգավիճակ | Իմաստը | Ապահով պատասխան |
|---|---|---|
| `poll already in flight` | Երկրորդ հետադարձ զանգ եկավ, մինչ ընթացիկ հարցումը պատկանում էր կյանքի ցիկլին: | Հաստատեք առկա հարցումների առաջխաղացումները; մի ավելացրեք այլ օղակի սեփականատեր: |
| `no_log_files_found` | Կազմաձևված ակտիվ կամ պահուստային մատյան չի հայտնաբերվել: | Հաստատեք Պահված արմատի և աղբյուրի կազմաձևումը: |
| `current_poll_error` | Ընթացիկ ցիկլը գրանցեց հարցման աղբյուրի ձախողում: | Կարդացեք `runtime/current/poll_error.json`. |
| `cadence_deferred` | Ավարտման դիսպետչերը դեռ չի ավարտվել: | Սպասվում է մինչև հաջորդ սահմանափակ հնարավորությունը: |
| `reports_disabled` | Հանրային հաշվետվությունների ստեղծումն անջատված է: | Միացնել միայն այն դեպքում, եթե նախատեսված են հաշվետվություններ: |
| `local_outbox_write_failed` | Թարգմանված տեղական ծրար հնարավոր չէ գրել: | Վերականգնել գործարկման ժամանակի ելքային գրացուցակը; սա ծանուցման տեղափոխման սխալ չէ: |
| `source_accounting_disabled` | Երթուղու ապացույցը չի կարող պահանջել ամբողջական աղբյուրի ծածկույթ: | Միացնել սկզբնաղբյուրի հաշվառումը կամ բացահայտորեն ընդունել բացակայող ապացույցները: |
| `route_disabled` | Երթուղին միտումնավոր անջատված է: | Այդ երթուղու առաքում չի սպասվում: |
| `poll_owner_between_polls` | Հաշվետվության աշխատողը հերթագրված է հարցումների միջև ժամանակացույցի պատկանող բացը գտնելու համար: | Սպասվում է միայն այն ժամանակ, երբ ժամանակի դրոշմակնիքներն ու կուրսորները շարունակվում են առաջադիմել: |
| `unsafe_shell_path` | Սահմանափակ գույքագրման կամ կեղևի ուղին ձախողվեց հարթակի անվտանգ վավերացումը: | Ուղղեք ուղին; երբեք մի թուլացրեք մեջբերումը կամ ուղու վավերացումը: |
