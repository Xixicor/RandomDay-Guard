# RandomDayGuard փաստաթղթեր

> **Կանոնական անգլերեն աղբյուր:** [README.md](../../README.md). Այս տեղայնացված փաստաթուղթը պահպանում է ճշգրիտ հրամաններ, ուղիներ, բանալիներ, կարգավիճակի արժեքներ, հեշեր և ֆայլերի անուններ: Եթե ​​տեխնիկական ձևակերպումը տարբերվում է, օգտագործեք անգլերեն աղբյուրը:


RandomDayGuard կարդում է գրառումները Abiotic Factor-ի հատուկ սերվերից և դրանք վերածում առանձին զեկույցների սերվերի առողջության, ամենօրյա պատմության, նվագարկչի նիստերի, վերանայման դեպքերի և Պահակների ձախողումների համար:
