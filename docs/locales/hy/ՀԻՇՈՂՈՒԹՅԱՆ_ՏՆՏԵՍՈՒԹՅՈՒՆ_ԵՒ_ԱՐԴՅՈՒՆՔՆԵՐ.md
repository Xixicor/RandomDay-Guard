<a id="memory-economy-and-output-files"></a>
# Հիշողության խնայողություն և ելքային ֆայլեր

> **Կանոնական անգլերեն աղբյուր:** [MEMORY_ECONOMY_AND_OUTPUTS.md](../../MEMORY_ECONOMY_AND_OUTPUTS.md). Այս տեղայնացված փաստաթուղթը պահպանում է ճշգրիտ հրամաններ, ուղիներ, բանալիներ, կարգավիճակի արժեքներ, հեշեր և ֆայլերի անուններ: Եթե ​​տեխնիկական ձևակերպումը տարբերվում է, օգտագործեք անգլերեն աղբյուրը:


Այս էջը բացատրում է, թե որ ֆայլերն են աճում, որ ֆայլերը վերագրվում են և ինչ վերբեռնել արագ վերանայման համար:

<a id="fast-answer"></a>
## Արագ պատասխան

| Հարց | Բացել |
|---|---|
| Պահապանը ողջ է՞: | `runtime/current/poll_status.json` |
| Ո՞վ է տեսել: | `runtime/account_evidence.json` |
| Ի՞նչ եղավ նիստերի հետ: | `runtime/evidence/session_events.jsonl` |
| Ի՞նչ տեղի ունեցավ այսօր: | `runtime/forensic_days/YYYY-MM-DD/` |
| Ի՞նչ է պարզ լեզվով ամփոփագիրը: | `runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt` |
| Ի՞նչ է սկանավորման առաջընթացը: | `runtime/scan_progress.json` |
| Ո՞րն է համաշխարհային համատեքստը: | `runtime/world_state/current/world_state_latest.json` |
| Ի՞նչ արգելքներ են գրվել: | `runtime/enforced_bans.jsonl` |

<a id="output-model"></a>
## Ելքային մոդել

| Տեսակ | Վարք | Օրինակներ |
|---|---|---|
| Ընթացիկ նկարներ | Վերագրված է | `runtime/current/*.json` |
| Իրադարձությունների մատյաններ | Միայն հավելված | `runtime/evidence/*.jsonl` |
| Աղյուսակներ | Թարմացվել կամ ավելացվել է | `*.tsv` |
| Հիմնական գծեր | Ավարտելուց հետո նորից օգտագործվեց | `runtime/baselines/*` |
| Ամենօրյա հավաքագրումներ | Թարմացվել է տեղում | `runtime/forensic_days/YYYY-MM-DD/*` |
| Վերջնական մատյաններ | Պարզ լեզվով ամենօրյա ամփոփում | `runtime/final_logs/YYYY-MM-DD/*` |

<a id="current-snapshots"></a>
## Ընթացիկ նկարներ

Սրանք մնում են փոքր և պատասխանում են «ինչն է հիմա ճիշտ»:

```text
runtime/current/poll_status.json
runtime/current/session_state.json
runtime/current/active_accounts.json
runtime/current/forensic_today.json
runtime/current/forensic_today.md
runtime/current/forensic_today.txt
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/world_state/current/world_state_latest.json
```

<a id="player-summaries"></a>
## Խաղացողի ամփոփագրեր

Սրանք առաջին ֆայլերն են, որոնք ստուգվում են հաշվի ստուգման համար:

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

Նրանք ամփոփում են.

```text
account_id
ban_id
name
identity_confidence
first_seen
last_seen
join_count
leave_count
status
score
```

<a id="event-logs"></a>
## Իրադարձությունների մատյաններ

Սրանք պահպանում են ժամանակացույցը:

```text
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/warning_events.jsonl
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/evidence/live_defense_events.jsonl
```

<a id="daily-forensic-rollups"></a>
## Ամենօրյա դատաբժշկական հավաքներ

Սրանք արագ վերբեռնման փաթեթներն են:

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

Վերբեռնեք այդ թղթապանակներից մեկը, երբ ցանկանում եք ժամանակաշրջանի արագ վերլուծություն:

<a id="scan-and-baseline-files"></a>
## Սկանավորեք և ելակետային ֆայլերը

Օգտագործեք դրանք՝ հասկանալու համար, թե արդյոք համաշխարհային համատեքստը մասնակի է, թե ամբողջական:

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/scan_complete.json
runtime/object_registry_partial.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
```

<a id="enforcement-files"></a>
## Կատարման ֆայլեր

Օգտագործեք դրանք միայն այն դեպքում, երբ կիրառումը միացված է:

```text
runtime/enforced.txt
runtime/enforced_bans.jsonl
runtime/ban_queue.json
runtime/evidence/enforced_bans.jsonl
```

`Admin.ini` պետք է ստանա միայն՝

```ini
BannedPlayer=<ID>
```

