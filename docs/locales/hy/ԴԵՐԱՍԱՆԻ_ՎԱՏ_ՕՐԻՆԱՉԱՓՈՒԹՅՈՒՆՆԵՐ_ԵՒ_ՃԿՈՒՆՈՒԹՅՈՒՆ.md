# Վատ դերասանների օրինաչափություններ և ճկունություն

> **Կանոնական անգլերեն աղբյուր:** [BAD_ACTOR_PATTERNS_AND_RESILIENCE.md](../../BAD_ACTOR_PATTERNS_AND_RESILIENCE.md). Այս տեղայնացված փաստաթուղթը պահպանում է ճշգրիտ հրամաններ, ուղիներ, բանալիներ, կարգավիճակի արժեքներ, հեշեր և ֆայլերի անուններ: Եթե ​​տեխնիկական ձևակերպումը տարբերվում է, օգտագործեք անգլերեն աղբյուրը:


Օգտագործեք այս էջը, որպեսզի հասկանաք, թե ինչպես է պահակը օգնում վերանայել վթարի չարաշահումը, շահագործման հարակից վարքագիծը և վերականգնման պլանավորումը:

<a id="what-the-guard-can-help-with"></a>
## Ինչով կարող է օգնել պահակը

| Նախշը | Ինչ ստուգել |
|---|---|
| Վթարի հետ կապված եկամուտներ | Նույն հաշիվն ակտիվ է մինչև խափանումները և վերադարձվում է վերագործարկումից հետո |
| Արագ վերամիացման զոնդավորում | Կրկնված join/leave կամ timeout/reconnect հանգույցներ |
| Բազմահաշվի կլաստերներ | Միացեք ալիքներին, ընդհանուր նախազգուշացման պատուհաններին, ընդհանուր ձախողման պատուհաններին |
| Նախազգուշական պայթյունի սթրես | Կրկնված ActorChannelFailure կամ պահպանելու նախազգուշացման պատուհաններ |
| Սահմաններից դուրս համատեքստ | PlayerData/map/world համատեքստ, երբ ընթեռնելի է |
| Պահել հպման համընկնումը | Աշխարհի պահպանում համընկնող համատեքստի քարտեզագրված աշխատաշրջաններ |
| Ինքնության շփոթություն | Անուններ, որոնք կարիք ունեն ConnectID քարտեզագրման |

<a id="why-it-avoids-memory-access"></a>
## Ինչու է այն խուսափում հիշողության հասանելիությունից

RandomDayGuard աշխատում է սերվերին պատկանող ֆայլերից.

```text
Saved/Logs/*.log
Admin.ini
World saves
PlayerData
Backups
runtime evidence
```

Դա այն դարձնում է ավելի քիչ կախված հաճախորդի կողմից հիշողության վիճակից և ավելի քիչ փխրուն խաղի թարմացումներում:

Առևտուր.

```text
It cannot prove hidden live actions unless the server writes evidence.
```

<a id="crash-correlated-returners"></a>
## Վթարի հետ կապված վերադարձողներ

Նախշը`

```text
Account joins.
Server crashes or restarts.
Same account reconnects quickly.
Pattern repeats.
```

Օգտակար ֆայլեր.

```text
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/account_evidence.json
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="rapid-reconnect-probers"></a>
## Արագ վերամիացման հետախուզիչներ

Նախշը`

```text
join -> leave -> join -> leave -> join
```

Օգտակար ֆայլեր.

```text
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/account_evidence.json
runtime/forensic_days/YYYY-MM-DD/players.tsv
```

<a id="multi-account-clusters"></a>
## Բազմահաշվի կլաստերներ

Նախշը`

```text
Several accounts join in the same window.
Warnings or crashes follow.
Some accounts rotate or reconnect after restart.
```

Օգտակար ֆայլեր.

```text
runtime/raid_cases/
runtime/forensic_days/YYYY-MM-DD/raid_cases.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

Կանոն՝

```text
A cluster is not a mass-ban list.
Each account still needs its own evidence.
```

<a id="sticky-backup-recommendation"></a>
## Կպչուն պահուստավորման առաջարկություն

Ստեղծեք կպչուն կրկնօրինակ`

```text
first full baseline completes
object_registry.json exists
file_manifest.tsv exists
world_state_latest.json has scan_complete=true
Admin.ini is verified
trusted IDs are configured
```

Պահուստավորում՝

```text
RandomDayGuard/config.lua
RandomDayGuard/SavedRoot.txt
RandomDayGuard/runtime/baselines/
RandomDayGuard/runtime/object_registry.json
RandomDayGuard/runtime/world_state/current/world_state_latest.json
Saved/SaveGames/Server/Admin.ini
```

<a id="recovery-model"></a>
## Վերականգնման մոդել

```text
Clean install
-> verify live defense
-> complete first baseline
-> create sticky backup
-> run server normally
-> use daily rollups for review
-> restore sticky backup if needed
```
