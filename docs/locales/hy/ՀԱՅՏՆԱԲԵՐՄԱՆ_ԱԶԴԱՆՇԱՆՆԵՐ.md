# Հայտնաբերման ազդանշաններ

> **Կանոնական անգլերեն աղբյուր:** [DETECTION_SIGNALS.md](../../DETECTION_SIGNALS.md). Այս տեղայնացված փաստաթուղթը պահպանում է ճշգրիտ հրամաններ, ուղիներ, բանալիներ, կարգավիճակի արժեքներ, հեշեր և ֆայլերի անուններ: Եթե ​​տեխնիկական ձևակերպումը տարբերվում է, օգտագործեք անգլերեն աղբյուրը:


Ազդանշանները ստուգման մուտքեր են, ոչ թե ավտոմատ մեղադրանքներ:

<a id="signal-table"></a>
## Ազդանշանների աղյուսակ

| Ազդանշան | Իմաստը | Ավելի ուժեղ, երբ... | Ինքնին բավարար չէ |
|---|---|---|---|
| Մուտքի ինքնությունը | Քարտեզների անունից հաշվի ID | ConnectID-ն առկա է | Արգելել |
| Մաքուր արձակուրդ | Սեսիայի սովորական փակում | Միացեք և թողեք համընկնում | կասկած |
| Արագ վերամիացում | Churn/probing համատեքստ | Արագ կրկնվում է | Արգելել |
| Անմաքուր անջատում | Աշխատաշրջանը մաքուր չի փակվել | Կրկնում կամ համընկնում է խափանումները | Արգելել |
| Խափանումների համընկնումը | Հաշիվն ակտիվ է խափանման մոտ | Նույն հաշիվը կրկնվում է | Արգելել |
| Վթարից հետո վերադարձ | Հաշիվը վերադառնում է վերագործարկումից հետո | Կրկնվում է դարաշրջաններում | Արգելել մեկ իրադարձությամբ |
| Զգուշացման պայթյուն | Սերվերի նախազգուշացման պատուհան | Համընկնում է քարտեզագրված աշխատաշրջանները | Արգելել մեկ պայթյունով |
| Դերասանի պահպանում հպում | Աշխարհի պահպանման համատեքստ | Համակցված է նիստերի հետ | Ապացույց use/theft |
| Օբյեկտի դելտա | World/class փոփոխություն | Համակցված է նիստերի հետ | Արգելել միայն հաշվումը |
| Raid case | Բազմահաշիվների կլաստեր | Կենտրոնական հաշիվը կրկնվում է | Զանգվածային արգելել բոլոր հաշիվները |

<a id="login-identity"></a>
## Մուտքի ինքնությունը

Լավագույն աղբյուրը՝

```text
Login request
Name=
ConnectID=
UniqueId=
```

Օգտագործեք այն քարտեզագրելու համար.

```text
display/log name -> account_id -> ban_id
```

<a id="rapid-reconnect"></a>
## Արագ վերամիացում

Նախշը`

```text
join -> leave -> join -> leave -> join
```

Օգտագործեք վերանայման համար, երբ կրկնվում է:

Անվտանգություն.

```text
churn_alone_never_bans = true
```

<a id="crash-overlap-and-post-crash-return"></a>
## Խափանումների համընկնումը և վթարից հետո վերադարձը

Նախշը`

```text
account active before crash
server restarts
same account returns quickly
```

Օգտագործեք վերանայման համար, երբ կրկնվում է դարաշրջաններում:

Անվտանգություն.

```text
single_crash_never_bans = true
```

<a id="warning-bursts"></a>
## Զգուշացումները պայթում են

Օրինակներ՝

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

Օգտագործեք որպես համատեքստ, քանի դեռ չեք կապվել քարտեզագրված աշխատաշրջանների և շեմերի հետ:

<a id="actor-save-touch"></a>
## Դերասանի պահպանում հպում

Իմաստը՝

```text
The server evidence referenced a class or actor.
```

Չի նշանակում.

```text
A player opened it.
A player stole from it.
A player duplicated through it.
A player damaged it.
```

<a id="raid-cases"></a>
## Ռեյդի դեպքեր

Հարձակման դեպքը խմբավորում է հաշիվները ըստ ժամանակացույցի և ընդհանուր պատուհանների:

Կանոն՝

```text
Do not auto-ban every account in a raid case.
Each account needs account-specific evidence.
```
