# Բառարան

> **Կանոնական անգլերեն աղբյուր:** [GLOSSARY.md](../../GLOSSARY.md). Այս տեղայնացված փաստաթուղթը պահպանում է ճշգրիտ հրամաններ, ուղիներ, բանալիներ, կարգավիճակի արժեքներ, հեշեր և ֆայլերի անուններ: Եթե ​​տեխնիկական ձևակերպումը տարբերվում է, օգտագործեք անգլերեն աղբյուրը:


| Ժամկետ | Պարզ իմաստ | Ճշգրիտ տեխնիկական նշանակություն |
|---|---|---|
| Ակտիվ մատյան | Սերվերի ընթացիկ գրանցամատյանը օգտագործվում է թարմ ապացույցների համար: | Պահանջվում է `active_log` աղբյուր; Երթուղին ավարտելու համար անհրաժեշտ է ընթերցելիություն և ընթացիկ տող: |
| Boot ID | Մեկ հսկիչ գործընթաց մեկնարկեց: | Ընթացիկ գործարկման ժամանակի նույնացուցիչն օգտագործվում է նախորդ բեռնումը մերժելու համար errors/reports. |
| Դարաշրջանի ID | Մեկ սերվերի շարունակականության ընդմիջում: | Նույնականացուցիչը ընդգրկում է սովորական գործարկման ժամանակը, մինչև շարունակականության տրամաբանությունը սկսի մեկ այլ դարաշրջան: |
| Հարցման ID | Հարցման մեկ սահմանափակ հնարավորություն: | Դրական միատոն ցիկլի դաշտ; zero/missing չի կարող ավարտել երթուղին: |
| Աղբյուրի թարմություն | Արդյոք ներկայիս աղբյուրը և հարցման տոհմը համաձայն են: | `fresh_current_poll` կամ `stale_or_unproven` ժամանակի դրոշմակնիքներով և ակտիվ գրանցման կարգավիճակով: |
| Աղբյուրի հաշվառում | Ապացույցների առկայության և սահմանափակումների գույքագրում: | `randomdayguard.source-accounting/v1` ութ աղբյուր դասերով և current/historical շրջանակը: |
| `available` | Գտնվել և կարդացվել է աղբյուր: | Տերմինալի աղբյուրի կարգավիճակը `available=true`, `readable=true`. |
| `expected_empty` | Ստուգվել է կամընտիր աղբյուր և օրինական absent/empty. | Տերմինալի ընթեռնելի աղբյուրի կարգավիճակը; երբեք չի արտադրում առարկա: |
| `partial` | Սահմանափակ աշխատանքը օգտակար, բայց թերի արդյունքներ ունի: | Ոչ տերմինալ source/accounting կարգավիճակը; վերսկսել սեփականատեր աշխատողին: |
| `deferred` | Աշխատանքը միտումնավոր առկախ է: | Աղբյուրի ոչ տերմինալ կարգավիճակը; սխալ կամ ավարտ չէ: |
| `unavailable` | Աղբյուրը ներկայումս չի կարող օգտագործվել: | Տերմինալ բացը; Պահանջվող աղբյուրի բացը հաշվառումն անհասանելի է դարձնում: |
| `malformed` | Աղբյուրը գոյություն ունի, բայց կառուցվածքային առումով անվավեր է: | Տերմինալ բացը պահպանում է վավերացման մանրամասները և փակում կախված գրությունները: |
| `permission_denied` | ՕՀ-ն բացահայտորեն մերժել է մուտքը: | Տերմինալի բացը տարբերվում է missing/unavailable. |
| `error` | Կողպված գործողությունն անսպասելիորեն ձախողվեց: | Տերմինալի ձախողում, որը պահանջում է անվանված վերականգնում; Հանրային հաշվետվություններում ոչ մի գաղտնի մանրամասն չի պատկանում: |
| `complete` | Հաշվարկված բոլոր աղբյուրները տերմինալային են, առանց բացթողումների: | Աղբյուրի վերին մակարդակի հաշվառման կարգավիճակը: |
| `complete_with_gaps` | Պահանջվող ընթացիկ ապացույցներն աշխատում են; կամընտիր տերմինալների բացերը մնում են: | Առաջին մակարդակի հաշվապահական հաշվառման կարգավիճակ; երթուղիները շարունակում են կիրառել իրենց սեփական պահանջները: |
| `full` | Երթուղին ավարտված է իր պահանջվող ոչ դատարկ պայմանագրով: | Երթուղու ապացուցված թվով ընթացիկ ցիկլի ավարտված ելքերով: |
| `limited_expected_empty` | Մի երթուղի ավարտված է և չի համապատասխանում subject/failure. | Երթուղիների ապացույցների թիվը `completed=true`, `expected_empty=true`. |
| `missing` | Երթուղու ավարտի ապացույցը բացակայում է կամ ձախողվել է: | Երթուղիների ապացույցների թիվը `completed=false`; Երբեք չի համապատասխանում ելքային արկղին: |
| Կառուցվածքային հաշվետվություն | Մեքենայով ընթեռնելի երթուղի: | `<route>_latest.json` օգտագործելով `randomdayguard.report/v1`. |
| Թարգմանված զեկույց | Միևնույն երթուղու ընթեռնելի արտապատկերում: | `<route>_latest.txt` ֆիքսված Observed-to-Source-references հերթականությամբ: |
| Երթուղու ապացույց | Միջերթուղիների ավարտման մատյան: | `route_proof.json` պարտադիր version/boot/epoch/poll/freshness/output ուղիներ: |
| Ընթացիկ ապացույց | Ակտիվ ցիկլին պատկանող դիտարկում: | Ծավալը `current`; չի վերակառուցվել հին filenames/reports. |
| Պատմական ապացույց | Պահպանված համատեքստը նախկին ցիկլերից կամ դանդաղ սկանավորումից: | Ծավալը `historical`; կարող է տեղեկացնել վերանայման մասին, բայց չի կարող պահանջել ներկայիս ներկայությունը: |
| Միայն վերանայման համար | Առանց Admin.ini գրում է: | Լռելյայն `review_only_mode=true`, `auto_ban=false`, `write_admin_ini=false`. |
| Անվտանգության արգելքի ստուգում | Մեկ հարց, որը Պահակը պետք է պատասխանի, նախքան այն փոխվի `Admin.ini`. | Այն պետք է հաստատի հաշիվը և միավորը, բացառի վստահելի հաշիվներն ու կրկնօրինակները, ստուգի կրկնօրինակը, հայտնաբերի արտաքին փոփոխությունները, պահպանի նախատեսված թարմացումը և ստուգի կամ ապահով կերպով վերականգնի ամբողջական ֆայլը: |
| Տեղական ելքային արկղ | Չեզոք մատակարարի կողմից ծանուցման կամընտիր փոխանցում: | JSON ֆայլեր `delivery_backend="none"` և `delivery_attempted=false`. |
| Հիմնական գիծ | Ավարտված է սահմանափակված Պահված ֆայլի համատեքստի պատկերը: | Manifest/object/world վիճակն օգտագործվում է միայն այն դեպքում, երբ համատեղելի է և բավական թարմ: |
| Ստուգակետ | Վերսկսեք դիրքը թերի սկանավորման աշխատանքի համար: | `scan_checkpoint.json`; ջնջումը կանխադրված վերականգնումը չէ: |
| Վերականգնվող ինդեքս | Ամփոփում, որը կարող է վերականգնվել: | Daily/weekly/forensic/final վերանայման արդյունք; աղբյուրի ապացույցները մնում են հեղինակավոր: |
| Ապացույցների սահման | Սահմանափակեք այն, ինչ աղբյուրը կարող է աջակցել: | Բացահայտ `does_not_prove`, անհայտներ, ինքնության ուժ և շրջանակի կանոններ: |

Սխեմաների կանոնական սահմանումները գտնվում են [`OUTPUT_SCHEMA_REFERENCE.md`](%D4%B5%D4%BC%D5%94%D4%BB_%D5%8D%D4%BD%D4%B5%D5%84%D4%B1%D5%85%D4%BB_%D5%80%D5%82%D5%88%D5%92%D5%84.md); կազմաձևման պայմանները [`CONFIG_FIELD_CATALOG.md`](%D4%BF%D4%B1%D5%90%D4%B3%D4%B1%D5%8E%D5%88%D5%90%D4%B5%D4%BC_%D4%B4%D4%B1%D5%87%D5%8F%D4%B1%D5%85%D4%BB%D5%86_%D4%BF%D4%B1%D5%8F%D4%B1%D4%BC%D5%88%D4%B3.md).
