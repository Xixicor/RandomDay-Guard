# Կազմաձևման պրոֆիլներ

> **Կանոնական անգլերեն աղբյուր:** [CONFIG_PROFILES.md](../../CONFIG_PROFILES.md). Այս տեղայնացված փաստաթուղթը պահպանում է ճշգրիտ հրամաններ, ուղիներ, բանալիներ, կարգավիճակի արժեքներ, հեշեր և ֆայլերի անուններ: Եթե ​​տեխնիկական ձևակերպումը տարբերվում է, օգտագործեք անգլերեն աղբյուրը:


Օգտագործեք այս ուղեցույցը՝ գործնական կազմաձևման պրոֆիլ ընտրելու և կիրառելու համար: Կարգավորման խմբերի փոխազդեցության բացատրության համար կարդացեք [`CONFIG_REFERENCE.md`](%D4%BF%D4%B1%D4%B6%D5%84%D4%B1%D5%81%D4%B5%D5%92%D5%84%D4%B1%D5%86_%D5%80%D5%82%D5%88%D5%92%D5%84.md): Հստակ դաշտերի, կանխադրվածների, տեսակների և անփոփոխների համար օգտագործեք ստեղծված [`CONFIG_FIELD_CATALOG.md`](%D4%BF%D4%B1%D5%90%D4%B3%D4%B1%D5%8E%D5%88%D5%90%D4%B5%D4%BC_%D4%B4%D4%B1%D5%87%D5%8F%D4%B1%D5%85%D4%BB%D5%86_%D4%BF%D4%B1%D5%8F%D4%B1%D4%BC%D5%88%D4%B3.md).

Ստորև ներկայացված Lua-ի յուրաքանչյուր բլոկ վերին մակարդակի գրառումների մի շարք է, որը կարող է փոխարինել առաքվածի ներսում համապատասխան գրառումները `return { ... }` աղյուսակ:

<a id="profile-chooser"></a>
## Պրոֆիլների ընտրիչ

| Իրավիճակը | Օգտագործեք այս պրոֆիլը |
|---|---|
| Առաջին տեղադրումը | Անվտանգ առաջին տեղադրում |
| Սերվերն անկայուն է և հաճախ խափանում է | Ընթացիկ ապացույցներ առանց դանդաղ սկանավորման |
| Դուք ցանկանում եք object/world համատեքստ | Ամբողջական բազային |
| Դուք ցանկանում եք վերանայել հին տեղեկամատյանները | Դատական ​​լրացում |
| Դուք առաջարկություններ եք ուզում, բայց ոչ գրություններ | Կատարման փորձարկում |
| Դուք պատրաստ եք թույլ տալ պահակին գրել արգելքներ | Կարգավորումը միացված է |
| Սկավառակը սահմանափակ է | Սկավառակի ցածր աճ |
| Դուք լրացրել եք մաքուր ելակետ | Կպչուն պահուստավորման կարգավորում |

<a id="safe-first-install"></a>
## Անվտանգ առաջին տեղադրում

Առաջինը սա օգտագործեք ուղիղ սերվերում:

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

log_tail = {
    enabled = true,
    start_at_end_on_first_run = true,
    tail_backup_logs = false,
},

scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

Ինչ է սա անում՝

```text
Tracks live sessions.
Starts the baseline scan.
Does not edit Admin.ini.
Avoids treating old backup logs as fresh live events.
```

<a id="current-evidence-without-slow-scan"></a>
## Ընթացիկ ապացույցներ առանց դանդաղ սկանավորման

Օգտագործեք սա, եթե սերվերն անկայուն է, և ձեզ անհրաժեշտ է crash/reconnect ապացույց՝ ծանր սկանավորումից առաջ:

```lua
log_tail = {
    enabled = true,
},

scanning = {
    full_scan_on_start = false,
},

enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

Ինչ է սա անում՝

```text
Tracks logins, joins, leaves, reconnects, crashes, and unclean sessions.
Delays heavy world scanning.
```

<a id="full-baseline"></a>
## Ամբողջական բազային

Օգտագործեք սա այն բանից հետո, երբ սերվերը կարողանա բավականաչափ երկար մնալ սկանավորման համար:

```lua
scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},
```

Ինչ է սա անում՝

```text
Builds object registry.
Writes world-state context.
Creates file manifest.
Enables changed-file refresh later.
```

<a id="forensic-backfill"></a>
## Դատական ​​լրացում

Օգտագործեք սա միայն այն ժամանակ, երբ դիտավորյալ վերանայում եք պատմական մատյանները:

```lua
log_tail = {
    start_at_end_on_first_run = false,
    tail_backup_logs = true,
    backfill_backup_logs_on_start = true,
},
```

Այն օգտագործելուց առաջ՝

```text
Back up runtime/log_offsets.tsv.
Expect old events to be reprocessed.
Return to live settings when finished.
```

<a id="enforcement-testing"></a>
## Կատարման փորձարկում

Օգտագործեք սա մինչև փաստացի Admin.ini գրություն:

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},
```

Ինչ ստուգել.

```text
runtime/account_evidence.json
runtime/warnings/
runtime/forensic_days/YYYY-MM-DD/ban_recommendations.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="enforcement-enabled"></a>
## Կարգավորումը միացված է

Օգտագործեք սա միայն այն բանից հետո, երբ ստուգման արդյունքը ճիշտ է:

```lua
enforcement = {
    review_only_mode = false,
    auto_ban = true,
    write_admin_ini = true,
    require_clean_ban_id = true,
    preserve_existing_bans = true,
    preserve_moderators = true,
},
```

Միացնելուց առաջ՝

```text
Trusted IDs are configured.
Moderator IDs are preserved.
Admin.ini backups work.
Ban recommendations are understandable.
Thresholds are accepted by the server owner.
```

<a id="low-disk-growth"></a>
## Սկավառակի ցածր աճ

Օգտագործեք սա, երբ գործարկման ժամանակի ֆայլերը չափազանց արագ են աճում:

```lua
logging = {
    low_importance_mode = "aggregate",
    write_low_importance_raw_events = false,
},

retention = {
    detailed_retention_days = 7,
    rotate_jsonl_when_bytes_exceed = 5242880,
    max_raw_events_lines = 20000,
    compact_json_outputs = true,
},
```

<a id="sticky-backup-setup"></a>
## Կպչուն պահուստավորման կարգավորում

Օգտագործեք առաջին ավարտված ելակետից հետո:

Ստուգեք, որ դրանք գոյություն ունեն.

```text
runtime/scan_complete.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
runtime/world_state/current/world_state_latest.json
```

Այնուհետև պահուստավորեք դրանք `config.lua`, `SavedRoot.txt` և `Admin.ini`.
