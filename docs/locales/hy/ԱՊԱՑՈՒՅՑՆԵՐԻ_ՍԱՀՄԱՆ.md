# Ապացույցների սահման

> **Կանոնական անգլերեն աղբյուր:** [EVIDENCE_BOUNDARY.md](../../EVIDENCE_BOUNDARY.md). Այս տեղայնացված փաստաթուղթը պահպանում է ճշգրիտ հրամաններ, ուղիներ, բանալիներ, կարգավիճակի արժեքներ, հեշեր և ֆայլերի անուններ: Եթե ​​տեխնիկական ձևակերպումը տարբերվում է, օգտագործեք անգլերեն աղբյուրը:


Օգտագործեք այս էջը՝ որոշելու համար, թե ինչ RandomDayGuard-ը կարող է զեկուցել և այն, ինչ դեռևս պահանջում է մարդկային վերանայում:

<a id="core-rule"></a>
## Հիմնական կանոն

RandomDayGuard գրանցում է սահմանափակված դիտարկումները սերվերին պատկանող ֆայլերից: Այն պետք է բացահայտի աղբյուրը, շրջանակը, հավաքագրման վիճակը և սահմանները յուրաքանչյուր նյութական եզրակացության համար:

Կառուցվածքային ապացույցները հեղինակավոր են: Թարգմանված զեկույցը բացատրում է ապացույցները. այն չի կարող ավելացնել փաստեր, որոնք բացակայում են կառուցվածքային գրառումից:

<a id="evidence-source-classes"></a>
## Ապացույցների աղբյուրների դասեր

| Աղբյուրի դաս | Տիպիկ օգտագործում | Ինքնին չի ապացուցվում |
|---|---|---|
| `admin_ini` | Գոյություն ունեցող վարչակազմի վիճակը և ստուգված write/readback համատեքստ | Ով է միջադեպի պատճառ դարձել |
| `active_log` | Ընթացիկ server/session իրադարձություններ, որոնք տեսանելի են ակտիվ մատյանում | Մտադրություն, սեփականություն կամ ուղղակի վնաս |
| `recent_backup_logs` | Պատմական մատյան համատեքստ | Ընթացիկ իրադարձություն է տեղի ունեցել |
| `playerdata_filenames` | Հաստատում, որ մաքուր հաշվի նույնացուցիչ գոյություն ունի | Բացահայտված նույնացուցիչից դուրս վարքագիծ, մեղք կամ ինքնության սեփականություն |
| `existing_cases` | Նախնական վերանայման համատեքստ | Որ նախորդ մեկնաբանությունը մնում է ճիշտ |
| `existing_reports` | Ավելի վաղ ամփոփումներ և որոշումներ | Ընթացիկ ճշմարտությունն առանց ընթացիկ հաստատման |
| `existing_evidence` | Պատմական կառուցվածքային ապացույցներ | Ընթացիկ գործունեությունը |
| սահմանափակված աշխարհը պահպանելու սկանավորում | Դանդաղ world/class համատեքստ | Խաղացողի գործողություն, սեփականություն, գողություն, կրկնօրինակում կամ վնաս |

Յուրաքանչյուր աղբյուր գրանցում է availability/readability, ֆայլերի քանակ, աղբյուրի հղումներ, ընթացիկ կամ պատմական շրջանակ և բացահայտ `does_not_prove` հայտարարություն:

<a id="source-states"></a>
## Աղբյուրի վիճակները

| Պետություն | Օպերատորի նշանակությունը |
|---|---|
| `available` | Աղբյուրը ընթեռնելի էր, և ապացույցներ հավաքվեցին: |
| `expected_empty` | Աղբյուրը ընթեռնելի էր և օրինականորեն չուներ համապատասխան գրառում: |
| `partial` | Որոշ ապացույցներ են հավաքվել. ծածկույթը թերի է: |
| `deferred` | Սահմանափակ աշխատանքը միտումնավոր հետաձգվել է: |
| `unavailable` | Աղբյուրը չկա այս միջավայրում: |
| `malformed` | Աղբյուրը գոյություն ունի, բայց չի կարող ապահով վերլուծվել: |
| `permission_denied` | Դիտորդը չունի կարդալու թույլտվություն: |
| `error` | Հավաքումը ձախողվեց մեկ այլ գրանցված պատճառով: |

Սպասվող դատարկությունը վավեր դիտարկում է: Այն երբեք չպետք է վերածվի հորինված խաղացողի, դեպքի, միջադեպի կամ մեղադրանքի:

<a id="current-versus-historical-evidence"></a>
## Ընթացիկ ընդդեմ պատմական ապացույցների

Ներկայիս ապացույցները պատկանում են ակտիվ հավաքագրման պատուհանին կամ սերվերի դարաշրջանին: Պատմական ապացույցները գալիս են նախկին մատյաններից, դեպքերից, հաշվետվություններից, ապացույցների գրառումներից, կրկնօրինակներից կամ ելակետերից:

Պատմական ապացույցները կարող են ապահովել համատեքստ: Այն չի կարող լուռ լրացնել ընթացիկ-ապացույցների բացը: Հաշվետվությունները պետք է պիտակավորեն երկու շրջանակները և առանձին նշեն դրանց աղբյուրները:

<a id="corroboration-rule"></a>
## Հաստատման կանոն

Սրանք օգտակար ենթատեքստ են, բայց ինքնին ուղղակի ապացույց չեն.

- ցուցադրել անուններ կամ անունների նմանություն;
- ժամանակի համընկնում;
- անջատել կամ նորից միացնել խափանումը;
- մեկ վթար կամ նախազգուշական պայթյուն;
- դասի, ուղու, դերակատարի, քարտեզի կամ օբյեկտների քանակի նշաններ;
- անդամակցություն ավտոմատ խմբավորված գործի մեջ;
- նախկին հաղորդումներ առանց ընթացիկ աղբյուրի հաստատման:

Մի՛ պնդեք մեղքի, դիտավորության, խաբեության, սեփականության իրավունքի, գողության, կրկնօրինակման, ուղղակի վնասի, կոնտեյների ուղղակի օգտագործում, ուղղակի գույքագրման գործողություն, ճշգրիտ ուղիղ կոորդինատներ, կենդանի պինգ կամ հիշողության մակարդակի վարքագիծ՝ առանց փաստի ուղղակի բացահայտման:

<a id="truthful-report-language"></a>
## Զեկույցի ճշմարիտ լեզու

Օգտագործեք՝

```text
Observed: the account was active in the recorded crash window.
Interpretation: repeated overlap warrants operator review.
Unknown: the cause of the crash.
Does not prove: that the account caused the crash.
Next action: compare the cited current session and lifecycle records.
```

Խուսափեք՝

```text
The player crashed the server.
The player stole or duplicated items.
The world token proves who used the object.
```

<a id="report-reading-order"></a>
## Հաղորդել ընթերցման կարգի մասին

Յուրաքանչյուր հրապարակային զեկույց պետք է բացատրի.

1. Պարզ իմաստ:
2. Ինչու է դա կարևոր:
3. Տեխնիկական ապացույցներ և աղբյուրի հղումներ:
4. Հաջորդ գործողությունը:
5. Սահմանափակումները, անհայտները և պահանջները ապացուցված չեն:
