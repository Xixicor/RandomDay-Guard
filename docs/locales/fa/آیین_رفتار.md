# آیین رفتار

> **منبع انگلیسی متعارف:** [CODE_OF_CONDUCT.md](../../../CODE_OF_CONDUCT.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید. این ترجمه اطلاعاتی است. متن قانونی انگلیسی کنترل می کند.


مباحثات را فنی، خاص و مبتنی بر شواهد نگه دارید. داده‌های پخش‌کننده خصوصی، اعتبار سرور، یا گزارش‌های رویدادهای زنده را در مسائل عمومی پست نکنید.
