# RandomDayGuard مستندات

> **منبع انگلیسی متعارف:** [README.md](../../README.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


RandomDayGuard سوابق را از سرور اختصاصی Abiotic Factor می‌خواند و آنها را به گزارش‌های جداگانه برای سلامت سرور، تاریخچه روزانه، جلسات پخش‌کننده، موارد بررسی و خرابی‌های گارد تبدیل می‌کند.
