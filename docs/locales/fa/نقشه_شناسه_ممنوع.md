# نقشه شناسه ممنوع

> **منبع انگلیسی متعارف:** [BAN_ID_MAPPING.md](../../BAN_ID_MAPPING.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


هنگام تبدیل نام بازیکن به گاوصندوق از این صفحه استفاده کنید `Admin.ini` خط ممنوعیت.

<a id="core-rule"></a>
## قانون اصلی

نام نمایشی یک شناسه ممنوعیت نیست.

`Admin.ini` از این موارد استفاده می کند:

```ini
BannedPlayer=<raw numeric player ID>
```

<a id="evidence-hierarchy"></a>
## سلسله مراتب شواهد

| رتبه | منبع | استفاده از |
|---:|---|---|
| 1 | گزارش سرور `Login request` | بهترین نقشه برداری از نام به شناسه |
| 2 | `Player_<ID>.sav` | تأیید می کند شناسه وجود دارد |
| 3 | موجود `Admin.ini` | موجود bans/moderators |
| 4 | اعلان خارجی یا فعالیت پنل میزبانی | Time/name. مدرک شناسایی نیست |
| 5 | UE4SS focus/player خطوط | Presence/context |
| 6 | گزارش‌های چرخه حیات سیستم یا کانتینر | فقط زمینه چرخه حیات میزبان. مدرک شناسایی نیست |

<a id="extract-the-clean-id"></a>
## شناسه تمیز را استخراج کنید

مثال خام:

```text
ConnectID=2535422284688820_+_|0002d07b...
```

پاک کردن `Admin.ini` مقدار:

```ini
BannedPlayer=2535422284688820
```

پست نکنید `_+_|...`.

<a id="verify-with-playerdata"></a>
## تأیید با PlayerData

بررسی کنید:

```text
Saved/SaveGames/Server/Worlds/<WorldName>/PlayerData/Player_<ID>.sav
```

معنی:

```text
The ID exists in the world save.
```

محدودیت:

```text
PlayerData may not prove the display name unless another source maps it.
```

<a id="when-not-to-ban"></a>
## چه زمانی ممنوع نیست

هنگامی که:

```text
the name only appears in an external notification
the name only appears in hosting-panel activity
UE4SS shows a name but no ConnectID
only system lifecycle or container logs exist
the ID is trusted or moderator
```
