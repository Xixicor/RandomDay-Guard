# FAQ

> **منبع انگلیسی متعارف:** [FAQ.md](../../FAQ.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


<a id="is-randomdayguard-the-randomday-mod"></a>
## است RandomDayGuard RandomDay مد؟

خیر. RandomDay مود تجربه سرور را تغییر می دهد. RandomDayGuard لایه شواهد سرور را تماشا می کند.

<a id="does-live-defense-work-before-the-scan-completes"></a>
## آیا دفاع زنده قبل از تکمیل اسکن کار می کند؟

بله. دفاع زنده از گزارش‌ها و رویدادهای جلسه استفاده می‌کند. اسکن خط پایه بعداً زمینه را بهبود می بخشد.

<a id="why-can-the-first-scan-take-a-long-time"></a>
## چرا اولین اسکن زمان زیادی می برد؟

اولین ساخت اسکن world/object زمینه، مانیفست فایل و داده های پایه قابل استفاده مجدد.

<a id="what-do-i-check-first-after-startup"></a>
## چه چیزی را ابتدا پس از راه اندازی بررسی کنم؟

```text
runtime/current/poll_status.json
```

به دنبال:

```text
scheduler_status=running
poll_id increasing
poll_in_flight=false
```

<a id="where-are-player-summaries"></a>
## خلاصه‌های پخش‌کننده کجا هستند؟

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

<a id="where-is-the-daily-quick-review-package"></a>
## بسته بررسی سریع روزانه کجاست؟

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

<a id="which-file-should-i-upload-for-fastest-review"></a>
## کدام فایل را برای بررسی سریعتر باید آپلود کنم؟

```text
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="can-it-write-bans-automatically"></a>
## آیا می تواند به طور خودکار ممنوعیت ها را بنویسد؟

فقط در صورتی که صریحاً فعال باشد.

پیش‌فرض:

```lua
review_only_mode = true
auto_ban = false
write_admin_ini = false
```

<a id="what-does-adminini-receive"></a>
## چه کاری انجام می دهد Admin.ini دریافت کنید؟

فقط:

```ini
BannedPlayer=<ID>
```

بدون نام، نظر، دلیل یا پسوند.

<a id="is-a-display-name-enough-to-ban"></a>
## آیا نام نمایشی برای ممنوع کردن کافی است؟

خیر. از گزارش سرور `Login request` با `ConnectID` یا مدرک سرور معادل.

<a id="can-one-crash-ban-someone"></a>
## آیا یک تصادف می تواند کسی را ممنوع کند؟

به‌طور پیش‌فرض خیر.

<a id="can-object-count-alone-ban-someone"></a>
## آیا شیء شمارش به تنهایی می تواند کسی را ممنوع کند؟

به‌طور پیش‌فرض خیر.

<a id="should-savedroottxt-point-to-the-world-folder"></a>
## باید SavedRoot.txt به پوشه جهان اشاره می کند؟

خیر. آن را روی `AbioticFactor/Saved`.

<a id="what-if-the-world-folder-changes"></a>
## اگر پوشه جهان تغییر کند چه؟

آن را به عنوان یک تغییر هویت پایه در نظر بگیرید. خط پایه قدیمی را حفظ کنید و یک پایه جدید بسازید.
