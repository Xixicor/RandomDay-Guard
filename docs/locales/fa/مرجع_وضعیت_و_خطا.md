# مرجع وضعیت و خطا

> **منبع انگلیسی متعارف:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


از این مرجع پس از طبقه بندی یک علامت در [عیب یابی](%D8%B9%DB%8C%D8%A8_%DB%8C%D8%A7%D8%A8%DB%8C.md). فایل وضعیت ساختار یافته را که با خطا نامگذاری شده است بخوانید. کدهای متمایز بیانگر وضعیت ایمنی و چرخه حیات متمایز هستند. آنها را در یک نتیجه کلی "Guard شکست خورد" جمع نکنید.

<a id="route-and-source-states"></a>
## حالت مسیر و منبع

| مقدار | معنا | پاسخ اپراتور |
|---|---|---|
| `full` | قرارداد مسیر با اثبات منبع چرخه جاری تکمیل شد. | مرز شواهد مسیر را بخوانید. هیچ تعمیری وجود ندارد. |
| `limited_expected_empty` | مسیر کامل شد و فعالیت از دست رفته برای این چرخه قانونی است. | بدون مصنوعی player/case باید ایجاد شود. |
| `missing` | خروجی، فیلد اصل و نسب، یا اثبات منبع مورد نیاز وجود ندارد. | دلیل مسیر و وضعیت منبع نامگذاری شده را بررسی کنید. |
| `available` | منبع نامگذاری شده قابل خواندن و قابل استفاده بود. | بدون اقدام. |
| `expected_empty` | منبع بررسی شد و به طور قانونی هیچ ردیفی نداشت. | هیچ اقدامی وجود ندارد، مگر اینکه فعالیت مستقل مورد انتظار باشد. |
| `partial` / `complete_with_gaps` | شواهد قابل استفاده وجود دارد، اما کلاس‌های منبع نام‌گذاری شده ناقص هستند. | نتیجه گیری را به شواهد جمع آوری شده محدود کنید. |
| `deferred` | کار محدود برای فرصت کارگر بعدی برنامه ریزی شده است. | پیشرفت پیشرفت را قبل از تغییر پیکربندی تأیید کنید. |
| `unavailable` | محیط منبع را ارائه نکرده است. | ثبت حد. فقط یک مسیر اثبات شده یا مشکل مجوز را تصحیح کنید. |
| `malformed` | منبع قابل خواندن بود اما اعتبار سنجی ساختاری ناموفق بود. | آن را حفظ کنید و منبع را اصلاح کنید. حدس نزنید. |
| `permission_denied` | منبع وجود دارد اما قابل خواندن نیست. | فقط مجوز خواندن محدود مورد نیاز را اعطا کنید. |
| `error` | مجموعه به دلیل ثبت شده انجام نشد. | خطا را حفظ کنید و آن مرحله را تشخیص دهید. |

<a id="playerdata-and-inventory-codes"></a>
## PlayerData و کدهای موجودی

| کد | معنا | پاسخ ایمن |
|---|---|---|
| `saved_root_unavailable` | هیچ ریشه تایید شده ذخیره شده ای برای خط لوله عمومی موجود نیست. | درست `SavedRoot.txt` و کاوشگر مسیر را دوباره بررسی کنید. |
| `unsafe_playerdata_root` | PlayerData کشف خارج از ریشه ذخیره شده محدود حل شد. | مسیر را تصحیح کنید. هرگز مرز را تضعیف نکنید. |
| `playerdata_discovery_not_run` | کارگر کشف محدود هنوز اجرا نشده است. | بررسی زمانبندی و پیشرفت کارگر. |
| `playerdata_discovery_read_failed:*` | خروجی Discovery خوانده نشد. | جزئیات پسوند را حفظ کنید و دستور موجودی محدود شده را تأیید کنید. |
| `inventory_command_open_failed` | فرایند موجودی شروع نشد. | تأیید کنید که زمان اجرا پل فرمان پیکربندی شده را فراهم می کند. |
| `inventory_command_read_failed` | خروجی موجودی در حین خواندن ناموفق بود. | خروجی جزئی را حفظ کنید و تنها پس از رفع خطای اصلی مجدداً اجرا کنید. |
| `inventory_command_close_failed` | موجودی بدون نتیجه نزدیک قابل اعتماد تکمیل شد. | منبع را ناقص در نظر بگیرید. |
| `identity_ledger_row_limit_exceeded` | ورودی هویت بادوام از محدوده ایمنی عمومی آن فراتر رفت. | بایگانی و بررسی دفتر کل. بی سر و صدا آن را به اثبات کامل کوتاه نکنید. |

<a id="adminini-enforcement-codes"></a>
## Admin.ini کدهای اجرایی

همه کدهای موجود در این بخش با شکست بسته شده اند. آنها به تنهایی اجازه ممنوعیت دستی را نمی دهند.

| کد | معنا | پاسخ ایمن |
|---|---|---|
| `admin_ini_write_disabled` / `admin_ini_disabled` | دریچه های نوشتن ایمن عمومی خاموش هستند. | در عملیات فقط بازبینی مورد انتظار است. |
| `admin_ini_backup_disabled` / `backup_safety_gate_disabled` | خط مشی پشتیبان مورد نیاز فعال نیست. | نوشتن را غیرفعال نگه دارید. |
| `enforcement_disabled` / `ban_on_threshold_disabled` / `auto_ban_disabled` | یک دروازه اجرایی صریح خاموش است. | در پیش‌فرض‌های فقط بازبینی عمومی مورد انتظار است. آن را دوباره به عنوان یک شکست نوشتن تفسیر نکنید. |
| `review_only_mode_enabled` | حالت فقط مرور عمداً جهش را مسدود می‌کند. | فقط شواهد را مرور کنید. |
| `duplicate_prevention_disabled` | محافظت تکراری غیرفعال شد. | نوشتن را غیرفعال نگه دارید تا زمانی که گیت ایمنی بازیابی شود. |
| `readback_safety_gate_disabled` / `rollback_safety_gate_disabled` | تأیید پس از نوشتن یا محافظت برگشتی غیرفعال شد. | نوشتن را غیرفعال نگه دارید. هرگز از این دروازه ها عبور نکنید. |
| `clean_id_safety_gate_disabled` / `account_specific_evidence_gate_disabled` | اجرای شواهد مربوط به هویت یا حساب پاک غیرفعال شد. | قبل از هر آزمایش اجرایی، گیت را بازیابی کنید. |
| `moderator_preservation_disabled` / `existing_ban_preservation_disabled` | حفاظت از حساب محافظت شده یا ممنوعیت موجود غیرفعال شد. | نوشتن را غیرفعال نگه دارید. |
| `clean_numeric_identity_required` | شناسه پیشنهادی فرم اتصال پذیرفته شده کامل یا شناسه عددی تمیز نیست. | دریافت یک نقشه تایید شده. هرگز یک پیشوند دلخواه را کوتاه نکنید. |
| `identity_strength_below_minimum` | شواهد هویت ضعیف تر از آستانه پیکربندی شده است. | فقط شواهد را مرور کنید. |
| `playerdata_verification_required` | پیکربندی نیاز به PlayerData و حساب آن را ندارد. | نامزد را فقط برای بازبینی نگه دارید. مالکیت را از نام فایل استنباط نکنید. |
| `trusted_or_moderator_identity` | حساب توسط دولت معتمد یا ناظر محافظت می‌شود. | نوشتن مجاز نیست. |
| `admin_ini_path_invalid` / `admin_ini_path_outside_saved_root` | مسیر هدف نامعتبر است یا از ریشه ذخیره شده خارج می شود. | پیکربندی صحیح. هرگز محافظ مسیر را دور نزنید. |
| `admin_ini_unavailable` | قابل خواندن پیکربندی نشده است Admin.ini در ریشه ذخیره شده یافت شد. | مسیر محدود شده را تصحیح کنید یا اجرا را غیرفعال نگه دارید. |
| `admin_ini_read_failed` | بایت های معتبر خوانده نشد. | قبل از جهش متوقف شوید. |
| `admin_ini_parse_failed` | Admin.ini اعتبارسنجی بدون کد ساختاری خاص تر انجام نشد. | فایل را حفظ کنید و ساختار بخش و خط آن را بررسی کنید. |
| `admin_ini_contains_nul` | فایل حاوی NUL بایت است و به عنوان متن پذیرفته نمی شود. | فایل را حفظ کنید و در خارج از گارد تعمیر کنید. |
| `admin_ini_duplicate_banned_players_section` | بیش از یک `[BannedPlayers]` وجود دارد. | در حالت توقف، بخش ها را به صورت دستی ادغام کنید. |
| `admin_ini_banned_player_outside_section` | یک ردیف ممنوعیت در خارج از `[BannedPlayers]`. | طرح بندی را به صورت دستی تصحیح کنید. |
| `admin_ini_invalid_banned_player_line` | خط ممنوعیت دقیقاً یک ردیف شناسه پشتیبانی شده تمیز نیست. | خط بد شکل را تصحیح کنید. |
| `admin_ini_backup_failed` | پشتیبان‌گیری منحصربه‌فرد، بایت‌ها را یکسان نوشته و خوانده نشده است. | هیچ جهشی مجاز نیست. |
| `admin_ini_external_change_detected` | نویسنده دیگری پس از عکس فوری گارد، فایل را تغییر داد. | بایت‌های خارجی را حفظ کنید و فقط پس از هماهنگ کردن نویسنده‌ها دوباره امتحان کنید. |
| `atomic_rename_unavailable` | جایگزینی اتمی درخواست شد اما لوا ارائه نکرد `os.rename`. | هیچ نوشته ای قابل اعتماد نیست. از یک زمان اجرا پشتیبانی شده استفاده کنید یا اجرا را غیرفعال نگه دارید. |
| `admin_ini_write_failed` | جایگزینی کنترل شده کامل نشد. | خطای جایگزینی ضبط شده و نسخه پشتیبان را بررسی کنید. |
| `post_write_verification_failed` | بایت های تولید با نامزد برابر نبود. | بررسی کنید `rollback_success` و `rollback_refused_external_change` قبل از هر اقدامی. |

<a id="startup-scheduler-and-backlog-states"></a>
## وضعیت‌های راه‌اندازی، زمان‌بندی، و بک لاگ

این مقادیر شواهد چرخه حیات هستند، نه اثبات مسیر. آن‌ها را با فایل‌های نظرسنجی، گزارش کارگر و مسیریاب فعلی بخوانید.

| مقدار | معنا | پاسخ ایمن |
|---|---|---|
| `not_started` | مرحله راه اندازی یا زمانبندی نامگذاری شده شروع نشده است. | در حین راه‌اندازی، منتظر فاصله مستند باشید. سپس اولین فاز بدون تغییر را بررسی کنید. |
| `main_lua_loaded` / `starting` | لودر متعارف اجرا شد و گارد وارد راه اندازی شد. | ادامه به مراحل بعدی. این به تنهایی آمادگی نیست. |
| `saved_root_found` / `log_tail_initialized` / `epoch_started` | راه‌اندازی منبع اصلی و تداوم پیشرفته است. | هیچ اقدامی وجود ندارد، مگر اینکه مرحله بعدی از پیشروی متوقف شود. |
| `admin_state_written` / `playerdata_index_written` | شاخص‌های محدود اولیه صادر شدند. | بدون اقدام. تحویل زمان‌بندی همچنان باید دنبال شود. |
| `watchdog_started` | سازمان نظارت بر گزارش و نظرسنجی ثبت شد. | در مرحله بعد، زمانبندی و پیشرفت نظرسنجی را تأیید کنید. |
| `ready_degraded` / `scan_running` | گارد در حال اجرا است در حالی که اسکن تاریخی محدود در حالت تعلیق باقی مانده است. | احتیاط، نه شکست. پیشروی شمارنده های پیشرفت را تأیید کنید. |
| `ready` | راه‌اندازی و اسکن محدود فعلی به حالت آماده است. | مثال مسیر را جداگانه بررسی کنید. |
| `scan_failed` / `error` | راه اندازی یا اسکن با یک خطای ثبت شده خاتمه یافت. | خطا یا فایل وضعیت نامگذاری شده را حفظ کنید و آن مرحله را تشخیص دهید. |
| `running` | زمان‌بند صاحب فرصت‌های نظرسنجی آینده است. | تأیید `poll_id` و `poll_completed_count` پیشرفت. |
| `manual_only` | زمان‌بندی حلقه در دسترس نبود. فقط کار صریح می تواند اجرا شود. | عملیات بدون مراقبت را غیرقابل دسترس تلقی کنید. |
| `stopped` | عملیات زمانبندی به پایان رسید. | قبل از راه اندازی مجدد، شواهد توقف و خطای قبلی را بررسی کنید. |
| `active_log_caught_up` | هیچ بک لاگ فعال خوانده نشده ای باقی نمانده است. | اسکن تاریخی ممکن است ادامه یابد. |
| `active_log_unavailable_nonblocking` | گزارش فعال وجود نداشت، اما راه‌اندازی مسدود نشد. | محدودیت منبع را ضبط کنید و منابع دیگر را تأیید کنید. |
| `active_log_read_failed` |  گزارش فعال وجود داشت اما قابل خواندن نبود. | خطا را حفظ کنید و فقط مسیر اثبات شده یا مشکل مجوز را اصلاح کنید. |
| `budget_exhausted` / `active_log_has_unread_bytes` | مجوز دم محدود شده با باقیمانده باقی مانده متوقف شد. | تأیید نظرسنجی های بعدی تعداد خوانده نشده را کاهش می دهد. |
| `offset_commit_failed_after_events_applied` | رویدادها پردازش شدند اما تداوم آفست گزارش بادوام انجام نشد. | اجرا به تعویق افتاد. قبل از تکیه بر چرخه دیگری، ذخیره سازی افست را تعمیر کنید. |

<a id="scheduler-report-and-notification-codes"></a>
## کدهای برنامه‌ریزی، گزارش و اعلان

| کد یا وضعیت | معنا | پاسخ ایمن |
|---|---|---|
| `poll already in flight` | در حالی که نظرسنجی فعلی متعلق به چرخه حیات بود، دومین تماس برگشتی دریافت شد. | پیشرفت های نظرسنجی موجود را تأیید کنید. مالک حلقه دیگری اضافه نکنید. |
| `no_log_files_found` | هیچ گزارش فعال یا پشتیبان پیکربندی شده ای پیدا نشد. | پیکربندی ریشه و منبع ذخیره شده را تأیید کنید. |
| `current_poll_error` | چرخه فعلی یک خطای منبع نظرسنجی را ثبت کرد. | خواندن `runtime/current/poll_error.json`. |
| `cadence_deferred` | تکمیل دیسپچر هنوز به پایان نرسیده است. | تا فرصت محدود بعدی مورد انتظار است. |
| `reports_disabled` | تولید گزارش عمومی غیرفعال است. | فقط در صورتی فعال شود که گزارش‌ها در نظر گرفته شده باشند. |
| `local_outbox_write_failed` | یک پاکت محلی ترجمه شده نمی تواند نوشته شود. | دایرکتوری خروجی زمان اجرا را تعمیر کنید. این یک خطای انتقال اعلان نیست. |
| `source_accounting_disabled` |  اثبات مسیر نمی تواند پوشش کامل منبع را ادعا کند. | حسابداری منبع را فعال کنید یا صریحاً شواهد موجود را بپذیرید. |
| `route_disabled` | مسیر عمداً غیرفعال شده است. | انتظار تحویل برای آن مسیر وجود ندارد. |
| `poll_owner_between_polls` | کارگر گزارش برای شکاف متعلق به زمان‌بندی بین نظرسنجی‌ها در صف قرار می‌گیرد. | فقط تا زمانی که مُهرهای زمانی و مکان‌نماها همچنان به پیش می‌روند، انتظار می‌رود. |
| `unsafe_shell_path` | یک موجودی محدود یا مسیر پوسته در اعتبار سنجی ایمن پلت فرم ناموفق بود. | مسیر را تصحیح کنید. هرگز نقل قول یا اعتبار سنجی مسیر را ضعیف نکنید. |
