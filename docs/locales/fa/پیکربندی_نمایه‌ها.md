# نمایه های پیکربندی

> **منبع انگلیسی متعارف:** [CONFIG_PROFILES.md](../../CONFIG_PROFILES.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


از این راهنمای نحوه انتخاب و اعمال نمایه پیکربندی عملی استفاده کنید. برای توضیح نحوه تعامل گروه های تنظیم، [`CONFIG_REFERENCE.md`](%D9%85%D8%B1%D8%AC%D8%B9_%D9%BE%DB%8C%DA%A9%D8%B1%D8%A8%D9%86%D8%AF%DB%8C.md). برای فیلدهای دقیق، پیش‌فرض‌ها، انواع و متغیرها، از [`CONFIG_FIELD_CATALOG.md`](%DA%A9%D8%A7%D9%86%D9%81%DB%8C%DA%AF_%DA%A9%D8%A7%D8%AA%D8%A7%D9%84%D9%88%DA%AF_%D9%81%DB%8C%D9%84%D8%AF.md).

هر بلوک Lua در زیر مجموعه‌ای از ورودی‌های سطح بالا است که می‌تواند جایگزین ورودی‌های منطبق در داخل کالای ارسالی شود `return { ... }` جدول.

<a id="profile-chooser"></a>
## انتخابگر نمایه

| وضعیت | از این نمایه استفاده کنید |
|---|---|
| ابتدا نصب | ابتدا نصب ایمن |
| سرور ناپایدار است و اغلب خراب می شود | شواهد فعلی بدون اسکن آهسته |
| می خواهید object/world زمینه | خط مبنا کامل |
| می‌خواهید گزارش‌های قدیمی را مرور کنید | پشت‌پوش پزشکی قانونی |
| توصیه می‌خواهید اما نوشتن ندارید | تست اجرایی |
| شما آماده هستید که به نگهبان اجازه دهید ممنوعیت‌ها را بنویسد | اجرا فعال شد |
| دیسک محدود است | رشد کم دیسک |
| شما یک خط پایه تمیز را تکمیل کردید | تنظیم پشتیبان چسبنده |

<a id="safe-first-install"></a>
## ابتدا نصب ایمن

ابتدا از این در سرور زنده استفاده کنید.

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

log_tail = {
    enabled = true,
    start_at_end_on_first_run = true,
    tail_backup_logs = false,
},

scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

این چه کاری انجام می دهد:

```text
Tracks live sessions.
Starts the baseline scan.
Does not edit Admin.ini.
Avoids treating old backup logs as fresh live events.
```

<a id="current-evidence-without-slow-scan"></a>
## شواهد فعلی بدون اسکن آهسته

اگر سرور ناپایدار است و به crash/reconnect شواهد قبل از اسکن سنگین.

```lua
log_tail = {
    enabled = true,
},

scanning = {
    full_scan_on_start = false,
},

enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

این چه کاری انجام می دهد:

```text
Tracks logins, joins, leaves, reconnects, crashes, and unclean sessions.
Delays heavy world scanning.
```

<a id="full-baseline"></a>
## خط مبنا کامل

بعد از اینکه سرور به اندازه کافی بیدار ماند و اسکن کرد، از این استفاده کنید.

```lua
scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},
```

این چه کاری انجام می دهد:

```text
Builds object registry.
Writes world-state context.
Creates file manifest.
Enables changed-file refresh later.
```

<a id="forensic-backfill"></a>
## پشت‌پوش پزشکی قانونی

از این فقط هنگام مرور عمدی گزارش‌های تاریخی استفاده کنید.

```lua
log_tail = {
    start_at_end_on_first_run = false,
    tail_backup_logs = true,
    backfill_backup_logs_on_start = true,
},
```

قبل از استفاده از آن:

```text
Back up runtime/log_offsets.tsv.
Expect old events to be reprocessed.
Return to live settings when finished.
```

<a id="enforcement-testing"></a>
## تست اجرایی

از این قبل از Admin.ini نوشتن.

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},
```

چه باید بررسی شود:

```text
runtime/account_evidence.json
runtime/warnings/
runtime/forensic_days/YYYY-MM-DD/ban_recommendations.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="enforcement-enabled"></a>
## اجرا فعال شد

این را فقط پس از درست بودن خروجی بررسی استفاده کنید.

```lua
enforcement = {
    review_only_mode = false,
    auto_ban = true,
    write_admin_ini = true,
    require_clean_ban_id = true,
    preserve_existing_bans = true,
    preserve_moderators = true,
},
```

قبل از فعال کردن:

```text
Trusted IDs are configured.
Moderator IDs are preserved.
Admin.ini backups work.
Ban recommendations are understandable.
Thresholds are accepted by the server owner.
```

<a id="low-disk-growth"></a>
## رشد کم دیسک

وقتی فایل‌های زمان اجرا خیلی سریع رشد می‌کنند از این استفاده کنید.

```lua
logging = {
    low_importance_mode = "aggregate",
    write_low_importance_raw_events = false,
},

retention = {
    detailed_retention_days = 7,
    rotate_jsonl_when_bytes_exceed = 5242880,
    max_raw_events_lines = 20000,
    compact_json_outputs = true,
},
```

<a id="sticky-backup-setup"></a>
## تنظیم پشتیبان چسبنده

پس از اولین خط پایه تکمیل شده استفاده کنید.

وجود این موارد را بررسی کنید:

```text
runtime/scan_complete.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
runtime/world_state/current/world_state_latest.json
```

سپس با `config.lua`, `SavedRoot.txt` و `Admin.ini`.
