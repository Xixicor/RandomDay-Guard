# واژه نامه

> **منبع انگلیسی متعارف:** [GLOSSARY.md](../../GLOSSARY.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


| مدت | معنی ساده | معنای فنی دقیق |
|---|---|---|
| گزارش فعال | گزارش سرور فعلی برای شواهد جدید استفاده می‌شود. | الزامی `active_log`; خوانایی به همراه اصل و نسب فعلی برای تکمیل مسیر مورد نیاز است. |
| شناسه بوت | فرآیند یک نگهبان شروع می شود. | شناسه زمان اجرا فعلی برای رد بوت قبلی errors/reports. |
| شناسه دوره | فاصله تداوم یک سرور. | شناسه زمان اجرای عادی را در بر می گیرد تا زمانی که منطق تداوم یک دوره دیگر را شروع کند. |
| شناسه نظرسنجی | یک فرصت نظرسنجی محدود. | فیلد چرخه یکنواخت مثبت؛ zero/missing نمی تواند یک مسیر را تکمیل کند. |
| تازه منبع | آیا منبع فعلی و اصل و نسب نظرسنجی موافق هستند. | `fresh_current_poll` یا `stale_or_unproven` با مُهر زمان و وضعیت ثبت فعال. |
| حسابداری منبع | موجودی از در دسترس بودن و محدودیت های شواهد. | `randomdayguard.source-accounting/v1` با هشت کلاس منبع و current/historical. |
| `available` | یک منبع پیدا شد و خوانده شد. | وضعیت منبع ترمینال با `available=true`, `readable=true`. |
| `expected_empty` | یک منبع اختیاری بررسی شد و به طور قانونی absent/empty. | وضعیت منبع قابل خواندن ترمینال. هرگز سوژه ای تولید نمی کند. |
| `partial` | کار محدود نتایج مفید اما ناقصی دارد. | غیر ترمینال source/accounting; کارگر مالک را از سر بگیرید. |
| `deferred` | کار عمداً در انتظار است. | وضعیت منبع غیر پایانی. یک خطا یا تکمیل نیست. |
| `unavailable` | در حال حاضر نمی توان از منبع استفاده کرد. | شکاف پایانه; شکاف منبع مورد نیاز حسابداری را از دسترس خارج می کند. |
| `malformed` | یک منبع وجود دارد اما از نظر ساختاری نامعتبر است. | شکاف پایانه حفظ جزئیات اعتبارسنجی و بستن نوشته‌های وابسته. |
| `permission_denied` | سیستم عامل به صراحت دسترسی را رد کرد. | شکاف پایانه متمایز از missing/unavailable. |
| `error` | عملیات محدود به طور غیرمنتظره ای شکست خورد. | خرابی ترمینال که نیاز به بازیابی نامگذاری شده دارد. هیچ جزئیات محرمانه ای در گزارش های عمومی تعلق ندارد. |
| `complete` | همه منابع حساب شده ترمینال بدون شکاف هستند. | وضعیت حسابداری منبع سطح بالا. |
| `complete_with_gaps` | شواهد مورد نیاز فعلی کار می کند. شکاف های پایانه اختیاری باقی می ماند. | وضعیت حسابداری سطح بالا؛ مسیرها همچنان الزامات خود را اعمال می کنند. |
| `full` | مسیری که با قرارداد غیر خالی مورد نیاز آن تکمیل شد. | Enum اثبات مسیر با خروجی‌های کامل چرخه جریان. |
| `limited_expected_empty` | یک مسیر تکمیل شد و هیچ واجد شرایطی یافت نشد subject/failure. | Enum اثبات مسیر با `completed=true`, `expected_empty=true`. |
| `missing` | اثبات تکمیل مسیر وجود ندارد یا ناموفق است. | Enum اثبات مسیر با `completed=false`; هرگز برای صندوق خروجی واجد شرایط نیست. |
| گزارش ساختاریافته | خروجی مسیر قابل خواندن توسط ماشین. | `<route>_latest.json` با استفاده از `randomdayguard.report/v1`. |
| گزارش ترجمه شده | پردازش قابل خواندن توسط انسان از همان مسیر. | `<route>_latest.txt` با ترتیب ارجاعات مشاهده شده به منبع ثابت. |
| مثال مسیر | دفتر کل تکمیل مسیرهای متقابل. | `route_proof.json` الزام آور version/boot/epoch/poll/freshness/output مسیرها. |
| شواهد فعلی | مشاهده متعلق به چرخه فعال است. | محدوده `current`; از filenames/reports. |
| شواهد تاریخی | زمینه را از چرخه های قبلی یا اسکن آهسته حفظ کرده است. | محدوده `historical`; ممکن است به بررسی اطلاع دهد اما نمی تواند ادعای حضور فعلی را داشته باشد. |
| فقط برای بازبینی | شواهد بررسی بدون Admin.ini می نویسد. | پیش‌فرض `review_only_mode=true`, `auto_ban=false`, `write_admin_ini=false`. |
| بررسی ایمنی فهرست ممنوع | یک سوال پیش از تغییر، گارد باید به آن پاسخ دهد `Admin.ini`. | باید حساب و امتیاز را تأیید کند، حساب‌های قابل اعتماد و موارد تکراری را حذف کند، یک نسخه پشتیبان را تأیید کند، تغییرات خارجی را شناسایی کند، به‌روزرسانی مورد نظر را ذخیره کند، و فایل کامل را تأیید یا با خیال راحت بازیابی کند. |
| صندوق خروجی محلی | انتقال اعلان اختیاری خنثی از ارائه دهنده. | JSON با `delivery_backend="none"` و `delivery_attempted=false`. |
| خط پایه | عکس فوری زمینه فایل ذخیره شده محدود شده کامل شد. | Manifest/object/world فقط زمانی استفاده مجدد می شود که سازگار و تازه باشد. |
| نقطه بازرسی | موقعیت را برای کار اسکن ناقص از سر بگیرید. | `scan_checkpoint.json`; حذف بازیابی پیش فرض نیست. |
| شاخص قابل بازسازی | خلاصه ای که می توان آن را بازسازی کرد. | Daily/weekly/forensic/final خروجی بررسی. شواهد منبع همچنان معتبر است. |
| مرز شواهد | محدودیتی را که منبع می تواند پشتیبانی کند محدود کنید. | صریح `does_not_prove`، مجهولات، قوت هویت، و قوانین محدوده. |
