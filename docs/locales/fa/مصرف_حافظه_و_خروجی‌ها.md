<a id="memory-economy-and-output-files"></a>
# مصرف حافظه و فایل‌های خروجی

> **منبع انگلیسی متعارف:** [MEMORY_ECONOMY_AND_OUTPUTS.md](../../MEMORY_ECONOMY_AND_OUTPUTS.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


این صفحه توضیح می‌دهد که کدام فایل‌ها رشد می‌کنند، کدام فایل‌ها بازنویسی می‌شوند، و چه چیزی برای بررسی سریع آپلود شود.

<a id="fast-answer"></a>
## پاسخ سریع

| سوال | باز کردن |
|---|---|
| آیا نگهبان زنده است؟ | `runtime/current/poll_status.json` |
| چه کسی دیده شد؟ | `runtime/account_evidence.json` |
| چه اتفاقی برای جلسات افتاد؟ | `runtime/evidence/session_events.jsonl` |
| امروز چه اتفاقی افتاد؟ | `runtime/forensic_days/YYYY-MM-DD/` |
| خلاصه به زبان ساده چیست؟ | `runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt` |
| پیشرفت اسکن چیست؟ | `runtime/scan_progress.json` |
| زمینه جهان چیست؟ | `runtime/world_state/current/world_state_latest.json` |
| چه ممنوعیت هایی نوشته شد؟ | `runtime/enforced_bans.jsonl` |

<a id="output-model"></a>
## مدل خروجی

| تایپ | رفتار | نمونه‌ها |
|---|---|---|
| عکس‌های فوری فعلی | بازنویسی شده | `runtime/current/*.json` |
| گزارش‌های رویداد | فقط الحاق | `runtime/evidence/*.jsonl` |
| جدول | به‌روزرسانی یا اضافه شد | `*.tsv` |
| خطوط پایه | پس از تکمیل مجدداً استفاده شد | `runtime/baselines/*` |
| مجموعه‌های روزانه | درجا به روز شد | `runtime/forensic_days/YYYY-MM-DD/*` |
| گزارش‌های گزارش نهایی | خلاصه روزانه به زبان ساده | `runtime/final_logs/YYYY-MM-DD/*` |

<a id="current-snapshots"></a>
## عکس‌های فوری فعلی

این‌ها کوچک می‌مانند و پاسخ می‌دهند «الان چه چیزی درست است».

```text
runtime/current/poll_status.json
runtime/current/session_state.json
runtime/current/active_accounts.json
runtime/current/forensic_today.json
runtime/current/forensic_today.md
runtime/current/forensic_today.txt
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/world_state/current/world_state_latest.json
```

<a id="player-summaries"></a>
## خلاصه های پخش کننده

اینها اولین فایلهایی هستند که برای بررسی حساب بررسی می شوند.

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

آنها خلاصه می کنند:

```text
account_id
ban_id
name
identity_confidence
first_seen
last_seen
join_count
leave_count
status
score
```

<a id="event-logs"></a>
## گزارش‌های رویداد

اینها خط زمانی را حفظ می کنند.

```text
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/warning_events.jsonl
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/evidence/live_defense_events.jsonl
```

<a id="daily-forensic-rollups"></a>
## مجموعه های پزشکی قانونی روزانه

اینها بسته های آپلود سریع هستند.

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

هنگامی که می‌خواهید تجزیه و تحلیل دوره سریع داشته باشید، یکی از آن پوشه‌ها را آپلود کنید.

<a id="scan-and-baseline-files"></a>
## اسکن و فایل های پایه

از اینها برای درک اینکه آیا بافت جهان جزئی است یا کامل استفاده کنید.

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/scan_complete.json
runtime/object_registry_partial.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
```

<a id="enforcement-files"></a>
## فایل های اجرایی

از اینها فقط زمانی استفاده کنید که اجرا فعال باشد.

```text
runtime/enforced.txt
runtime/enforced_bans.jsonl
runtime/ban_queue.json
runtime/evidence/enforced_bans.jsonl
```

`Admin.ini` فقط باید دریافت کند:

```ini
BannedPlayer=<ID>
```

## چه چیزی با پیوستن بازیکن به‌روزرسانی می‌شود

به روز رسانی های مورد انتظار:

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/current/session_state.json
runtime/forensic_days/YYYY-MM-DD/players.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

## وقتی سرور از کار می افتد یا راه اندازی مجدد می شود چه چیزی به روز می شود

به روز رسانی های مورد انتظار:

```text
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/account_evidence.json
runtime/forensic_days/YYYY-MM-DD/crash_reconnects.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="what-updates-when-the-scan-progresses"></a>
## وقتی اسکن پیشرفت می کند چه چیزی به روز می شود

به روز رسانی های مورد انتظار:

```text

runtime/scan_checkpoint.json
runtime/object_registry_partial.json
runtime/world_state/current/world_state_latest.json
runtime/forensic_days/YYYY-MM-DD/forensic_day_summary.json
```

<a id="what-to-upload-for-quick-analysis"></a>
## چه چیزی برای تجزیه و تحلیل سریع آپلود شود

بهترین بسته:

```text
runtime/final_logs/YYYY-MM-DD/
```

```text

```

بسته شواهد کامل:

```text

runtime/evidence/session_events.jsonl
runtime/server_lifecycle_events.jsonl
runtime/warning_events.jsonl
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```
