# سیگنال های تشخیص

> **منبع انگلیسی متعارف:** [DETECTION_SIGNALS.md](../../DETECTION_SIGNALS.md). این اسناد بومی سازی شده دستورات، مسیرها، کلیدها، مقادیر وضعیت، هش ها و نام فایل ها را دقیق حفظ می کند. اگر عبارت فنی متفاوت است، از منبع انگلیسی استفاده کنید.


سیگنال‌ها ورودی بازبینی هستند، نه اتهامات خودکار.

<a id="signal-table"></a>
## جدول سیگنال

| سیگنال | معنا | قوی تر وقتی... | به خودی خود کافی نیست |
|---|---|---|---|
| هویت ورود | شناسه نام به حساب نقشه‌ها | ConnectID موجود است | ممنوع کردن |
| مرخصی پاک | بسته شدن عادی جلسه | پیوستن و ترک مسابقه | مشکوک |
| اتصال مجدد سریع | Churn/probing زمینه | به سرعت تکرار می شود | ممنوع کردن |
| قطع ناپاک | جلسه کاملاً بسته نشد | تکرار یا همپوشانی خرابی ها | ممنوع کردن |
| همپوشانی خرابی | حساب در نزدیکی خرابی فعال است | همان حساب تکرار می شود | ممنوع کردن |
| بازگشت پس از خرابی | حساب پس از راه اندازی مجدد برمی گردد | در طول دوره‌ها تکرار می‌شود | ممنوع کردن توسط یک رویداد |
| هشدار انفجاری | پنجره هشدار سرور | جلسات نگاشت شده همپوشانی دارد | توسط یک انفجار ممنوع |
| لمس ذخیره بازیگر | زمینه ذخیره جهانی | با جلسات مرتبط است | اثبات use/theft |
| دلتای شی | World/class تغییر | با جلسات مرتبط است | منع از شمارش به تنهایی |
| قاب حمله | خوشه چند حساب | تکرار حساب مرکزی | ممنوع انبوه همه حساب ها |

<a id="login-identity"></a>
## هویت ورود

بهترین منبع:

```text
Login request
Name=
ConnectID=
UniqueId=
```

از آن برای نقشه برداری استفاده کنید:

```text
display/log name -> account_id -> ban_id
```

<a id="rapid-reconnect"></a>
## اتصال مجدد سریع

الگو:

```text
join -> leave -> join -> leave -> join
```

در صورت تکرار برای بازبینی استفاده کنید.

ایمنی:

```text
churn_alone_never_bans = true
```

<a id="crash-overlap-and-post-crash-return"></a>
## همپوشانی خرابی و بازگشت پس از خرابی

الگو:

```text
account active before crash
server restarts
same account returns quickly
```

برای مرور زمانی که در هر دوره تکرار می شود استفاده کنید.

ایمنی:

```text
single_crash_never_bans = true
```

<a id="warning-bursts"></a>
## هشدار انفجاری

مثال:

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

از آن به عنوان زمینه استفاده کنید تا زمانی که به جلسات و آستانه های نگاشت شده پیوند داده شود.

<a id="actor-save-touch"></a>
## لمس ذخیره بازیگر

معنی:

```text
The server evidence referenced a class or actor.
```

به این معنی نیست:

```text
A player opened it.
A player stole from it.
A player duplicated through it.
A player damaged it.
```

<a id="raid-cases"></a>
## موارد حمله

یک مورد حمله حساب ها را بر اساس زمان بندی و پنجره های مشترک گروه بندی می کند.

قانون:

```text
Do not auto-ban every account in a raid case.
Each account needs account-specific evidence.
```
