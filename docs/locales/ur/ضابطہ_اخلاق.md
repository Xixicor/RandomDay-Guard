# ضابطہ اخلاق

> **کیننیکل انگریزی ماخذ:** [CODE_OF_CONDUCT.md](../../../CODE_OF_CONDUCT.md). یہ مقامی دستاویزات درست کمانڈز، پاتھز، کیز، اسٹیٹس ویلیوز، ہیشز اور فائل کے ناموں کو محفوظ رکھتی ہیں۔ اگر تکنیکی الفاظ میں فرق ہے تو انگریزی ماخذ استعمال کریں۔ یہ ترجمہ معلوماتی ہے؛ انگریزی قانونی ٹیکسٹ کنٹرولز۔


بات چیت کو تکنیکی، مخصوص اور ثبوت پر مبنی رکھیں۔ پبلک ایشوز میں پرائیویٹ پلیئر ڈیٹا، سرور کی اسناد، یا لائیو ایونٹ لاگ پوسٹ نہ کریں۔
