# FAQ

> **کیننیکل انگریزی ماخذ:** [FAQ.md](../../FAQ.md). یہ مقامی دستاویزات درست کمانڈز، پاتھز، کیز، اسٹیٹس ویلیوز، ہیشز اور فائل کے ناموں کو محفوظ رکھتی ہیں۔ اگر تکنیکی الفاظ میں فرق ہے تو انگریزی ماخذ استعمال کریں۔


<a id="is-randomdayguard-the-randomday-mod"></a>
## ہے RandomDayGuard the RandomDay موڈ؟

نہیں RandomDay موڈ سرور کے تجربے کو تبدیل کرتا ہے۔ RandomDayGuard سرور ثبوت پرت کو دیکھتا ہے۔

<a id="does-live-defense-work-before-the-scan-completes"></a>
## کیا اسکین مکمل ہونے سے پہلے لائیو ڈیفنس کام کرتا ہے؟

ہاں۔ لائیو ڈیفنس لاگز اور سیشن ایونٹس کا استعمال کرتا ہے۔ بیس لائن اسکین بعد میں سیاق و سباق کو بہتر بناتا ہے۔

<a id="why-can-the-first-scan-take-a-long-time"></a>
## پہلے اسکین میں زیادہ وقت کیوں لگ سکتا ہے؟

پہلا اسکین بنتا ہے world/object سیاق و سباق، فائل مینی فیسٹس، اور دوبارہ قابل استعمال بیس لائن ڈیٹا۔

<a id="what-do-i-check-first-after-startup"></a>
## اسٹارٹ اپ کے بعد میں سب سے پہلے کیا چیک کروں؟

```text
runtime/current/poll_status.json
```

تلاش کریں:

```text
scheduler_status=running
poll_id increasing
poll_in_flight=false
```

<a id="where-are-player-summaries"></a>
## کھلاڑی کے خلاصے کہاں ہیں؟

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

<a id="where-is-the-daily-quick-review-package"></a>
## روزانہ کوئیک ریویو پیکج کہاں ہے؟

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

<a id="which-file-should-i-upload-for-fastest-review"></a>
## تیز ترین جائزے کے لیے مجھے کون سی فائل اپ لوڈ کرنی چاہیے؟

```text
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="can-it-write-bans-automatically"></a>
## کیا یہ خود بخود پابندیاں لکھ سکتا ہے؟

صرف اس صورت میں جب واضح طور پر فعال ہو۔

ڈیفالٹ:

```lua
review_only_mode = true
auto_ban = false
write_admin_ini = false
```

<a id="what-does-adminini-receive"></a>
## کیا کرتا ہے Admin.ini وصول کریں؟

صرف:

```ini
BannedPlayer=<ID>
```

کوئی نام، تبصرے، وجوہات، یا لاحقہ نہیں۔

<a id="is-a-display-name-enough-to-ban"></a>
## کیا ایک ڈسپلے نام پابندی کے لیے کافی ہے؟

نہیں سرور لاگ استعمال کریں `Login request` کے ساتھ `ConnectID` یا مساوی سرور کا ثبوت۔

<a id="can-one-crash-ban-someone"></a>
## کیا ایک کریش کسی پر پابندی لگا سکتا ہے؟

بذریعہ ڈیفالٹ نہیں۔

<a id="can-object-count-alone-ban-someone"></a>
## کیا آبجیکٹ شمار اکیلے کسی پر پابندی لگا سکتا ہے؟

بذریعہ ڈیفالٹ نہیں۔

<a id="should-savedroottxt-point-to-the-world-folder"></a>
## چاہیے SavedRoot.txt عالمی فولڈر کی طرف اشارہ کریں؟

نہیں اس کی طرف اشارہ کریں `AbioticFactor/Saved`.

<a id="what-if-the-world-folder-changes"></a>
## کیا ہوگا اگر عالمی فولڈر بدل جائے؟

اسے بنیادی شناخت کی تبدیلی کے طور پر سمجھیں۔ پرانی بیس لائن کو محفوظ کریں اور ایک نئی بنائیں۔
