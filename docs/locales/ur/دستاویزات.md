# RandomDayGuard دستاویزات

> **کیننیکل انگریزی ماخذ:** [README.md](../../README.md). یہ مقامی دستاویزات درست کمانڈز، پاتھز، کیز، اسٹیٹس ویلیوز، ہیشز اور فائل کے ناموں کو محفوظ رکھتی ہیں۔ اگر تکنیکی الفاظ میں فرق ہے تو انگریزی ماخذ استعمال کریں۔


RandomDayGuard ابیوٹک فیکٹر کے لیے وقف کردہ سرور سے ریکارڈز پڑھتا ہے اور انہیں سرور کی صحت، روزانہ کی تاریخ، کھلاڑیوں کے سیشنز، جائزہ لینے کے کیسز، اور گارڈ کی ناکامیوں کے لیے الگ الگ رپورٹس میں تبدیل کرتا ہے۔
