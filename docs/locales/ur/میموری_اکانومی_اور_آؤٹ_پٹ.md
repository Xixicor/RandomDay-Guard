# میموری اکانومی اور آؤٹ پٹ فائلز

> **کیننیکل انگریزی ماخذ:** [MEMORY_ECONOMY_AND_OUTPUTS.md](../../MEMORY_ECONOMY_AND_OUTPUTS.md). یہ مقامی دستاویزات درست کمانڈز، پاتھز، کیز، اسٹیٹس ویلیوز، ہیشز اور فائل کے ناموں کو محفوظ رکھتی ہیں۔ اگر تکنیکی الفاظ میں فرق ہے تو انگریزی ماخذ استعمال کریں۔


یہ صفحہ بتاتا ہے کہ کون سی فائلیں بڑھتی ہیں، کون سی فائلز کو اوور رائٹ کیا جاتا ہے، اور فوری جائزہ کے لیے کیا اپ لوڈ کرنا ہے۔

<a id="fast-answer"></a>
## تیز جواب

| سوال | کھولیں |
|---|---|
| کیا گارڈ زندہ ہے؟ | `runtime/current/poll_status.json` |
| کس کو دیکھا گیا؟ | `runtime/account_evidence.json` |
| سیشنز کا کیا ہوا؟ | `runtime/evidence/session_events.jsonl` |
| آج کیا ہوا؟ | `runtime/forensic_days/YYYY-MM-DD/` |
| سادہ زبان کا خلاصہ کیا ہے؟ | `runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt` |
| اسکین کی پیشرفت کیا ہے؟ | `runtime/scan_progress.json` |
| عالمی سیاق و سباق کیا ہے؟ | `runtime/world_state/current/world_state_latest.json` |
| کونسی پابندیاں لکھی گئی تھیں؟ | `runtime/enforced_bans.jsonl` |

<a id="output-model"></a>
## آؤٹ پٹ ماڈل

| قسم | رویہ | مثالیں |
|---|---|---|
| موجودہ سنیپ شاٹس | اوور رائٹ | `runtime/current/*.json` |
| ایونٹ لاگز | صرف ضمیمہ | `runtime/evidence/*.jsonl` |
| ٹیبلز | اپ ڈیٹ یا منسلک | `*.tsv` |
| بیس لائنز | مکمل ہونے کے بعد دوبارہ استعمال کیا جاتا ہے | `runtime/baselines/*` |
| روزانہ رول اپس | جگہ پر اپ ڈیٹ کیا گیا | `runtime/forensic_days/YYYY-MM-DD/*` |
| حتمی لاگز | سادہ زبان کا روزانہ کا خلاصہ | `runtime/final_logs/YYYY-MM-DD/*` |

<a id="current-snapshots"></a>
## موجودہ سنیپ شاٹس

یہ چھوٹے رہتے ہیں اور جواب دیتے ہیں "اب کیا سچ ہے۔"

```text
runtime/current/poll_status.json
runtime/current/session_state.json
runtime/current/active_accounts.json
runtime/current/forensic_today.json
runtime/current/forensic_today.md
runtime/current/forensic_today.txt
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/world_state/current/world_state_latest.json
```

<a id="player-summaries"></a>
## کھلاڑی کے خلاصے

یہ اکاؤنٹ کے جائزے کے لیے چیک کرنے والی پہلی فائلیں ہیں۔

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

وہ خلاصہ کرتے ہیں:

```text
account_id
ban_id
name
identity_confidence
first_seen
last_seen
join_count
leave_count
status
score
```

## ایونٹ لاگز

```text
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/warning_events.jsonl
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/evidence/live_defense_events.jsonl
```

<a id="daily-forensic-rollups"></a>
## روزانہ فرانزک رول اپس

یہ فوری اپ لوڈ پیکجز ہیں۔

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

جب آپ فوری پیریڈ تجزیہ چاہتے ہیں تو ان فولڈرز میں سے ایک اپ لوڈ کریں۔

<a id="scan-and-baseline-files"></a>
## اسکین اور بیس لائن فائلیں

یہ سمجھنے کے لیے استعمال کریں کہ عالمی سیاق و سباق جزوی ہے یا مکمل۔

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/scan_complete.json
runtime/object_registry_partial.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
```

<a id="enforcement-files"></a>
## انفورسمنٹ فائلز

ان کو صرف اس وقت استعمال کریں جب نفاذ فعال ہو۔

```text
runtime/enforced.txt
runtime/enforced_bans.jsonl
runtime/ban_queue.json
runtime/evidence/enforced_bans.jsonl
```

`Admin.ini` صرف موصول ہونا چاہئے:

```ini
BannedPlayer=<ID>
```
