# آؤٹ پٹ اور اسٹیٹ اسکیما حوالہ

> **کیننیکل انگریزی ماخذ:** [OUTPUT_SCHEMA_REFERENCE.md](../../OUTPUT_SCHEMA_REFERENCE.md). یہ مقامی دستاویزات درست کمانڈز، پاتھز، کیز، اسٹیٹس ویلیوز، ہیشز اور فائل کے ناموں کو محفوظ رکھتی ہیں۔ اگر تکنیکی الفاظ میں فرق ہے تو انگریزی ماخذ استعمال کریں۔


یہ آپریٹر کا سامنا کرنے والی فائلوں کے لیے کینونیکل معاہدہ ہے۔ یہ اکیلے ہی درست آؤٹ پٹ پاتھ، فیلڈ کے نام، اجازت شدہ اقدار، نسب کی ضروریات اور روٹ اسکیموں کا مالک ہے۔ طریقہ کار کے رہنما ان حقائق کی دوبارہ وضاحت کرنے کے بجائے یہاں لنک کرتے ہیں۔

رن ٹائم ثبوت مستند ہے؛ فائل کا نام، شیڈولر دل کی دھڑکن، ترجمہ شدہ رپورٹ، یا مقامی آؤٹ باکس آبجیکٹ اس کے اپنے شعبوں اور نسب سے زیادہ ثابت نہیں ہوتا ہے۔

<a id="public-report-routes"></a>
## عوامی رپورٹ کے راستے

رپورٹ ورکر `runtime/final_logs/`:

| راستہ | معاہدہ | `full` ضرورت | متوقع خالی معنی |
|---|---|---|---|
| `server_status` | موجودہ شیڈولر، ایکٹیو لاگ، اسکین زیر التواء، اور سورس کوریج کی حالت۔ | موجودہ boot/epoch/poll نسب، تازہ فعال لاگ، accounting/history لکھتا ہے، اور JSON/TXT جوڑا۔ | بصورت دیگر صحت مند کرنٹ سائیکل کے لیے استعمال نہیں کیا جاتا ہے۔ لاپتہ نسب ہے `missing`. |
| `daily_rollup` | موجودہ day/window سرور، پلیئرز، کیسز، اسکین اور کوریج میں تسلسل۔ | روٹ کے لیے تاریخی اکاؤنٹنگ ٹرمینل کافی ہے اور کرنٹ سائیکل پروف مکمل ہے۔ | کوئی کھلاڑی برقرار نہیں رکھا گیا اور نہ ہی کوئی جائزہ کیس۔ |
| `player_activity` | موجودہ اور تاریخی کو الگ کریں player/account مشاہدات۔ | موجودہ سائیکل پروف جمع ایک یا زیادہ current/historical قطاریں۔ | باؤنڈڈ ان پٹس میں کوئی اہل کھلاڑی کی قطاریں نہیں ہیں۔ کوئی مصنوعی مضمون نہیں۔ |
| `case_review` | نام رکھے ہوئے کیسز اور موجودہ review/BAN-ELIGIBLE امیدوار۔ | موجودہ سائیکل ثبوت کے علاوہ ماخذ حوالہ جات کے ساتھ ایک یا زیادہ نامزد کیسز۔ | کوئی نامزد کیس جائزے کے معیار پر پورا نہیں اترتا؛ کوئی مصنوعی کیس نہیں۔ |
| `critical_guard` | موجودہ بوٹ شیڈیولر، اسٹارٹ اپ، پول، یا ثبوت کی سالمیت کی ناکامی۔ | موجودہ سائیکل ثبوت کے علاوہ موجودہ اہم ناکامی۔ | کوئی موجودہ اہم ناکامی نہیں؛ پرانی متن کی غلطیاں اس راستے کی مالک نہیں ہیں۔ |

ہر فعال راستہ لکھتا ہے `<route>_latest.json` اور `<route>_latest.txt`۔ `runtime/final_logs/route_proof.json` ایک ہی ورژن، بوٹ، epoch، پول، اور ماخذ تازہ کاری کو ریکارڈ کرتا ہے۔

<a id="report-json-schema"></a>
## رپورٹ JSON اسکیما

تمام راستہ JSON استعمال کرتا ہے `schema="randomdayguard.report/v1"`.

| فیلڈ | قسم | معنی اور متغیر |
|---|---|---|
| `schema` | string | بالکل `randomdayguard.report/v1`. |
| `generated_ts`, `report_date` | string | جنریشن ٹائم اسٹیمپ اور رپورٹنگ کی تاریخ۔ |
| `version` | string | Runtime/package اس سائیکل کے لیے شناخت۔ |
| `boot_id`, `epoch_id` | string | موجودہ عمل بوٹ اور سرور کے تسلسل کا دور۔ تکمیل کے لیے دونوں درکار ہیں۔ |
| `poll_id` | انٹیجر | مثبت موجودہ پول شناخت کنندہ۔ Zero/missing راستہ مکمل نہیں کر سکتا۔ |
| `source_freshness` | آبجیکٹ | `status`, `checked_ts`، ایکٹیو لاگ اسٹیٹس، آخری پول ٹائم اسٹیمپ، اور آخری مکمل پول ٹائم اسٹیمپ۔ |
| `current_cycle_proof_complete` | بولین | صرف اس وقت درست ہے جب نسب اور تازہ active-log/current-poll ثبوت متفق ہیں۔ |
| `route` | enum | اوپر کے پانچ راستوں میں سے ایک۔ |
| `route_proof_status` | enum | `full`, `limited_expected_empty`، یا `missing`. |
| `coverage_status` | enum | بالکل `complete`, `complete_with_gaps`, `partial`، یا `unavailable`. |
| `completed`, `expected_empty` | بولین | `completed` صرف `missing`; `expected_empty` صرف `limited_expected_empty`. |
| `observed` | سٹرنگز کی صف | کنکریٹ کو برقرار رکھا گیا facts/counts/statuses. |
| `interpretation` | سٹرنگز کی صف | محتاط معنی ثبوت کے مطابق کیلیبریٹڈ۔ |
| `unknown` | سٹرنگز کی صف | لاپتہ شناخت، تاریخ، ماخذ، یا سیاق و سباق۔ |
| `does_not_prove` | سٹرنگز کی صف | نتائج جن کی شواہد تائید نہیں کر سکتے۔ |
| `next_action` | string | محفوظ پابند آپریٹر کارروائی۔ |
| `source_references` | سٹرنگز کی صف | منفرد ترتیب دیا گیا runtime/Saved حوالہ جات۔ |
| `enforcement_authority` | بولین | ہمیشہ غلط۔ رپورٹ کبھی بھی تحریر کی اجازت نہیں دیتی۔ |
| `output_paths` | دو تاریں | JSON اور TXT جوڑا لکھنے سے پہلے جوڑے گئے راستے۔ |

`coverage_status` صرف اعلی سطحی اکاؤنٹنگ ہے۔ ماخذ ریکارڈز الگ سے `available`, `expected_empty`, `partial`, `deferred`, `unavailable`, `malformed`, `permission_denied`، اور `error`۔ روٹ پروف الگ سے `full`, `limited_expected_empty`، اور `missing`؛ اقدار کبھی بھی ان حدود کو پار نہیں کرتیں۔

روٹ ایکسٹینشنز:

- `server_status`: `scheduler_status`, `active_log_status`، اور `server_metrics`۔ میٹرکس موجودہ دور کی شروعات، تازہ ترین مکمل پول ٹائم اسٹیمپ اور ID، فعال کھلاڑیوں کی گنتی، active/backup-log شمار، اسکین pending/progress اقدار، اور configured/usable/unavailable سورس گروپ اکاؤنٹنگ۔ جب کوئی ذریعہ ان حقائق کو ظاہر نہیں کرتا ہے تو وہ اپ ٹائم، دوبارہ شروع کی گنتی، بیک اپ ٹائم اسٹیمپ، یا بند ہونے کا دورانیہ ایجاد نہیں کرتے ہیں۔
- `player_activity`: `player_activity_present`, `movement`, `same_day_sessions`, `current_player_count`, `current_evidence_player_count`, `historical_player_count`, `historical_session_count`, `current_players`, `historical_players`، اور مطابقت کی صف `players`۔ ہر ایک ہی دن کا سیشن اپنا سیشن ID، اکاؤنٹ ID، ڈسپلے کا نام رکھتا ہے جب معلوم ہو، join/leave ٹائم اسٹیمپ، کلین ایگزٹ اور لائف سائیکل فلیگ، اور ماخذ حوالہ جات۔ شناخت کو برقرار رکھا اور PlayerData موجودگی سیاق و سباق میں رہتی ہے، آج کی سرگرمی کا ثبوت نہیں۔
- `case_review`: `cases`, `review_subjects`, `current_case_count`، اور `retained_case_count`۔ موجودہ جائزہ کا مضمون اس کا case/account ID، معلوم ہونے پر ڈسپلے نام، حیثیت، سکور، شناخت کا اعتماد، first/last مشاہدہ، انتباہی شمار، وجوہات، موجودہ لائیو پرچم، اور ماخذ حوالہ جات۔ برقرار رکھے گئے کیسز خود سے کوئی موجودہ موضوع نہیں بناتے ہیں۔
- `critical_guard`: `critical_failure_present` اور `current_boot_error_only=true`.
- `daily_rollup`: `daily_maturity`, `once_per_day_continuity`, `dedupe_window`، اور `daily_metrics`۔ میٹرکس رپورٹ کی تاریخ، فعال کھلاڑی، ایک ہی دن کی سرگرمی والے اکاؤنٹس، جوائن، چھوڑے، صاف اور ناپاک اخراج، لائف سائیکل ریٹرن، موجودہ نامزد جائزہ مضامین، برقرار رکھے گئے کیسز، current/retained شناختی شمار، اور ماخذ گروپ کوریج۔

<a id="translated-txt-schema"></a>
## ترجمہ شدہ TXT اسکیما

جوڑا ٹیکسٹ فائل آپریٹر کے پڑھنے کے قابل نتیجہ کے ساتھ لیڈ کرتی ہے اور سلسلہ نسب کی تفصیلات کو آخر تک لے جاتی ہے۔ یہ اس قطعی سیکشن آرڈر کو محفوظ رکھتا ہے:

```text
RandomDayGuard <route title>
Generated: <timestamp>

Summary
<one plain-language route summary>

What Guard observed
- ...

What it means
- ...

What remains unknown
- ...

Recommended next step
...

Evidence boundary
- ...

Rating explanation
- ...

Technical record
- Route: <route>
- Version: <version>
- Cycle: boot=<boot> epoch=<epoch> poll=<poll>
- Source freshness: <status>
- Route result: <full|limited_expected_empty|missing>
- Coverage: <status>

Translation notes
- ...

Source references
- ...
```

ترجمہ صرف ساختی رپورٹ فیلڈز اور منظور شدہ لغت میپنگز کا استعمال کرتا ہے۔ یہ تشکیل شدہ رپورٹ میں کھلاڑیوں، معاملات، ترسیل، وجہ، ملکیت، ارادے، یا نفاذ کی اہلیت کو شامل نہیں کر سکتا۔ تکنیکی تفصیلات پڑھنے کے قابل نتیجہ کو ہٹائے بغیر دستیاب رہتی ہیں۔

<a id="source-accounting-schema"></a>
## ذریعہ اکاؤنٹنگ اسکیما

`runtime/final_logs/source_accounting_latest.json` استعمال کرتا ہے `randomdayguard.source-accounting/v1` جنریشن کے ساتھ reason/status, enablement/disabled وجہ، current/historical امتیاز، تبدیل شدہ فائل مینی فیسٹ، سورس ریکارڈز، usable/unavailable کلاس کی فہرستیں، اور دعوی کی حد۔

ہر سورس ریکارڈ پر مشتمل ہے:

| فیلڈ | قسم | مطلب |
|---|---|---|
| `source_class` | string | ذیل میں آٹھ کلاسوں میں سے ایک۔ |
| `scope` | `current` یا `historical` | وقت کی ملکیت؛ دائرہ کار کبھی بھی خاموشی سے ضم نہیں ہوتے ہیں۔ |
| `required` | بولین | صرف `active_log` موجودہ سائیکل روٹ کی تازگی کے لیے درکار ہے۔ |
| `status` | enum | ذیل میں درج ماخذ نتیجہ۔ |
| `terminal` | بولین | صرف `partial` اور `deferred`. |
| `available`, `readable` | بولین | صرف `available` اور `expected_empty`. |
| `file_count` | انٹیجر | باؤنڈڈ اکاؤنٹڈ file/reference شمار۔ |
| `source_references` | صف | منفرد ذریعہ ترتیب دیا گیا paths/references. |
| `detail` | string | باؤنڈڈ نتیجہ یا خرابی کی تفصیل۔ |
| `does_not_prove` | string | دستیابیت ارادہ، ملکیت، نقصان، نقل، یا نفاذ کا ثبوت نہیں ہے۔ |

ماخذ کی کلاسز:

| ماخذ کی کلاس | اسکوپ | یہ کیا تعاون کرتا ہے | یہ کیا ثابت نہیں کرسکتا |
|---|---|---|---|
| `active_log` | موجودہ، مطلوبہ | پڑھنے کے قابل فعال سرور لاگ اور تازہ رائے شماری کا سلسلہ۔ | مکمل سرگزشت یا کھلاڑی کا قصور۔ |
| `admin_ini` | موجودہ، اختیاری | ساختی طور پر درست موجودہ moderator/ban حالت، یا متوقع غیر موجودگی۔ | کھلاڑی کا برتاؤ یا درست وجہ میٹا ڈیٹا۔ |
| `recent_backup_logs` | تاریخی | پڑھنے کے قابل rotated/backup لاگ حوالہ جات۔ | موجودہ موجودگی یا موجودہ بوٹ حالت۔ |
| `playerdata_filenames` | موجودہ سیاق و سباق | منتخب محفوظ شدہ روٹ کے تحت پڑھنے کے قابل فائل نام کے حوالہ جات۔ | فائل کی ملکیت، لائیو موجودگی، شناختی مواد، یا بدتمیزی۔ |
| `existing_cases` | تاریخی | نامزد کیس کو برقرار رکھا گیا files/index موجودہ آؤٹ پٹ سے پہلے کیپچر کیے گئے ریکارڈز۔ | موجودہ سرگرمی یا پرانے نتائج کی درستگی۔ |
| `existing_reports` | تاریخی |  برقرار رکھا گیا final/forensic/warning رپورٹ کے حوالے۔ | مستند ماخذ کی تبدیلی۔ |
| `existing_evidence` | تاریخی | ثبوت کے حوالہ جات کو برقرار رکھا گیا ہے۔ | واقعات کی مکملیت جو سرور نے کبھی ظاہر نہیں کی۔ |
| `world_save_scan` | تاریخی | مکمل، جزوی، موخر، یا غیر دستیاب باؤنڈڈ scan/checkpoint حالت۔ | ایک مخصوص کھلاڑی کی کارروائی یا ملکیت۔ |

ماخذ کی حیثیت کی قدریں:

| اسٹیٹس | ٹرمینل | آپریٹر کا مطلب اور عمل |
|---|---:|---|
| `available` | ہاں | پڑھنے کے قابل مفید ذریعہ موجود ہے؛ اس کے حوالہ جات کا جائزہ لیں۔ |
| `expected_empty` | ہاں | اختیاری ماخذ کو چیک کیا گیا اور جائز طور پر absent/empty۔ ڈیٹا ایجاد نہ کریں۔ |
| `partial` | نہیں | باؤنڈڈ کام یا انوینٹری کی حد نامکمل ہے؛ دوبارہ شروع کرنے کی اجازت دیں۔ |
| `deferred` | نہیں | کام جان بوجھ کر زیر التواء ہے؛ مالک کارکن کا انتظار کریں۔ |
| `unavailable` | ہاں | Source/path/tool غیر حاضر یا ناقابل استعمال ہے۔ مرمت صرف اس صورت میں کریں جب راستے کی ضرورت ہو۔ |
| `malformed` | ہاں | مواد کی ساخت کی توثیق ناکام ہوگئی۔ اسے محفوظ کریں اور فارمیٹ کی مرمت کریں۔ |
| `permission_denied` | ہاں | رسائی کو واضح طور پر مسترد کر دیا گیا تھا۔ کم سے کم استحقاق پڑھنے کی رسائی کو بحال کریں۔ |
| `error` | ہاں | سورس لیول باؤنڈڈ probe/read غیر متوقع طور پر ناکام ہوگیا؛ معائنہ کریں `detail` راز فاش کیے بغیر۔ |

اوپر کی سطح `coverage_status` بالکل `complete`, `complete_with_gaps`, `partial`، یا `unavailable`۔ ایک مطلوبہ ماخذ کی سطح `error`, `malformed`، یا `permission_denied` ٹاپ لیول تک رول کرتا ہے `unavailable`؛ ماخذ کی سطح `deferred` ٹاپ لیول تک رول کرتا ہے `partial`۔ ماخذ اکاؤنٹنگ کو غیر فعال کرنا اب بھی ایک غیر دستیاب حیثیت لکھتا ہے اور ہر راستے کو `missing`.

<a id="historical-status-schema"></a>
## تاریخی حیثیت کا اسکیما

`runtime/final_logs/historical_backfill_latest.json` استعمال کرتا ہے `randomdayguard.history/v1`: `generated_ts`، اکاؤنٹنگ `status`, `resumable=true`, `changed_file_refresh=true`, `current_evidence_is_not_history=true`، ماخذ اکاؤنٹنگ صف، غیر دستیاب کلاسز، اور ایک پابند `next_action`.

`runtime/history/public_accounts.tsv` اس ہیڈر کے ساتھ پائیدار عوامی تاریخ ہے:

```text
account_id	ban_id	display_name	identity_confidence	status	score	first_seen	last_seen	source_references
```

قطاریں اکاؤنٹ ID کے لحاظ سے ترتیب دی جاتی ہیں، فیلڈز ہیں single-line/tab-safe، اور حوالہ جات ہیں sorted/unique۔ یہ فائل خاموشی سے دوبارہ شروع ہونے کے دوران تاریخی سیاق و سباق کو محفوظ رکھتی ہے۔ یہ کبھی بھی تاریخ کو موجودہ موجودگی میں تبدیل نہیں کرتا۔

<a id="route-proof-schema"></a>
## روٹ پروف اسکیما

`runtime/final_logs/route_proof.json` استعمال کرتا ہے `randomdayguard.route-proof/v1` اور اعلی درجے کی جنریشن ٹائم اسٹیمپ، ورژن، بوٹ، عہد، پول، ماخذ کی تازگی، موجودہ دور کی تکمیل، اجازت شدہ اسٹیٹس، اور ایک `routes` صف۔

ہر راستے کے اندراج پر مشتمل ہے route/status, version/boot/epoch/poll، ماخذ تازگی آبجیکٹ، کرنٹ سائیکل مکمل، آؤٹ پٹ پاتھ، اور ماخذ حوالہ جات۔ ایک غیر فعال راستے کا ریکارڈ `status="missing"` اور `reason="route_disabled"`۔ اگر روٹ پروف تحریر ناکام ہوجاتی ہے، تو ہر روٹ کو incomplete/missing اس سے پہلے کہ کسی بھی اطلاع کے امیدوار کو قبول کیا جائے۔

<a id="notification-schemas"></a>
## اطلاعاتی اسکیمے

اختیاری عوامی وضع صرف مقامی فائل آؤٹ باکس ہے۔

`runtime/notifications/pending/<route>_latest.json` استعمال کرتا ہے `randomdayguard.notification/v1` تیار کردہ ٹائم اسٹیمپ کے ساتھ، version/boot/epoch/ poll/source تازگی، راستہ، `completed_output`، روٹ پروف اسٹیٹس، تشکیل شدہ اور ترجمہ شدہ رپورٹ کے راستے، ماخذ کے حوالہ جات، `delivery_backend="none"`، اور `delivery_attempted=false`۔ اہل آؤٹ پٹ استعمال کرتا ہے `status="ready_for_local_consumer"`, `delivery_eligible=true`، اور `delivery_allowed=true`۔ ایک کنفیگرڈ لیکن missing/ineligible راستہ اب بھی `status="suppressed_current_cycle"`، دونوں ڈیلیوری جھنڈے غلط ہیں، اور `suppression_reason="route_or_completion_policy_blocked"`۔ لہذا `pending/` کا بذات خود مطلب قطار یا اہل نہیں ہے۔

`runtime/notifications/notification_status.json` استعمال کرتا ہے `randomdayguard.notification-status/v1` ایک ہی نسب کے ساتھ، `generic_local_outbox_only=true`, `delivery_attempted=false`، اور فی روٹ `queued`/`outcome` قطاریں۔ `full` اہل ہے؛ متوقع خالی صرف اس وقت اہل ہے جب `include_expected_empty=true`; `missing` کبھی بھی اہل نہیں ہے۔ روٹ پروف تحریری ناکامی پر اسٹیٹس کا نتیجہ ہے `route_proof_write_failed`؛ ایک دبایا ہوا آڈٹ لفافہ اب بھی لکھا جا سکتا ہے، لیکن یہ آؤٹ پٹ قبول نہیں کیا جاتا ہے۔

| ناکامی | مطلوبہ حالت | محفوظ بازیافت | غلط تخمینہ |
