# ڈیٹیکشن سگنلز

> **کیننیکل انگریزی ماخذ:** [DETECTION_SIGNALS.md](../../DETECTION_SIGNALS.md). یہ مقامی دستاویزات درست کمانڈز، پاتھز، کیز، اسٹیٹس ویلیوز، ہیشز اور فائل کے ناموں کو محفوظ رکھتی ہیں۔ اگر تکنیکی الفاظ میں فرق ہے تو انگریزی ماخذ استعمال کریں۔


سگنل جائزے کے ان پٹ ہیں، خودکار الزامات نہیں۔

<a id="signal-table"></a>
## سگنل ٹیبل

| سگنل | مطلب | مضبوط جب... | خود ہی کافی نہیں ہے |
|---|---|---|---|
| لاگ ان شناخت | اکاؤنٹ ID پر نقشے کا نام | ConnectID موجود ہے | پابندی |
| صاف چھٹی | عام سیشن کی بندش | شامل ہوں اور میچ چھوڑیں | شک |
| تیزی سے دوبارہ جڑیں | Churn/probing سیاق و سباق | تیزی سے دہرایا جاتا ہے | پابندی |
| غیر صاف رابطہ منقطع | سیشن صاف طور پر بند نہیں ہوا | کریشوں کو دہرایا جاتا ہے یا اوورلیپ کرتا ہے | پابندی |
| کریش اوورلیپ | کریش کے قریب اکاؤنٹ فعال | ایک ہی اکاؤنٹ دہرایا جاتا ہے | پابندی |
| کریش کے بعد کی واپسی | ری اسٹارٹ ہونے کے بعد اکاؤنٹ واپس آتا ہے | ہر دور میں دہرایا جاتا ہے | ایک ایونٹ پر پابندی |
| انتباہ برسٹ | سرور وارننگ ونڈو | اوورلیپ میپ شدہ سیشنز | ایک بارسٹ پر پابندی |
| ایکٹر سیو ٹچ | عالمی محفوظ سیاق و سباق | سیشنز کے ساتھ تعلق ہے | کا ثبوت use/theft |
| آبجیکٹ ڈیلٹا | World/class تبدیلی | سیشنز کے ساتھ تعلق ہے | صرف گنتی پر پابندی |
| چھاپہ کیس | ملٹی اکاؤنٹ کلسٹر | مرکزی اکاؤنٹ دہرایا جاتا ہے | تمام اکاؤنٹس پر بڑے پیمانے پر پابندی |

<a id="login-identity"></a>
## لاگ ان شناخت

بہترین ذریعہ:

```text
Login request
Name=
ConnectID=
UniqueId=
```

اسے نقشہ بنانے کے لیے استعمال کریں:

```text
display/log name -> account_id -> ban_id
```

<a id="rapid-reconnect"></a>
## تیزی سے دوبارہ جڑیں

پیٹرن:

```text
join -> leave -> join -> leave -> join
```

دہرائے جانے پر جائزے کے لیے استعمال کریں۔

حفاظت:

```text
churn_alone_never_bans = true
```

<a id="crash-overlap-and-post-crash-return"></a>
## کریش اوورلیپ اور کریش کے بعد کی واپسی

پیٹرن:

```text
account active before crash
server restarts
same account returns quickly
```

دہرائے جانے پر جائزے کے لیے استعمال کریں۔

حفاظت:

```text
single_crash_never_bans = true
```

<a id="warning-bursts"></a>
## انتباہی برسٹ

مثالیں:

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

سیاق و سباق کے بطور استعمال کریں جب تک کہ میپ شدہ سیشنز اور حد سے منسلک نہ ہوں۔

<a id="actor-save-touch"></a>
## ایکٹر سیو ٹچ

مطلب:

```text
The server evidence referenced a class or actor.
```

مطلب نہیں:

```text
A player opened it.
A player stole from it.
A player duplicated through it.
A player damaged it.
```

<a id="raid-cases"></a>
## چھاپے کے کیسز

ایک چھاپہ کیس اکاؤنٹس کو ٹائمنگ اور مشترکہ ونڈوز کے مطابق گروپ کرتا ہے۔

قاعدہ:

```text
Do not auto-ban every account in a raid case.
Each account needs account-specific evidence.
```
