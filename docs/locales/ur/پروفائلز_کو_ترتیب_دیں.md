# کنفیگریشن پروفائلز

> **کیننیکل انگریزی ماخذ:** [CONFIG_PROFILES.md](../../CONFIG_PROFILES.md). یہ مقامی دستاویزات درست کمانڈز، پاتھز، کیز، اسٹیٹس ویلیوز، ہیشز اور فائل کے ناموں کو محفوظ رکھتی ہیں۔ اگر تکنیکی الفاظ میں فرق ہے تو انگریزی ماخذ استعمال کریں۔


ایک عملی کنفیگریشن پروفائل کو منتخب کرنے اور لاگو کرنے کے لیے اس گائیڈ کو استعمال کریں۔ اس بات کی وضاحت کے لیے کہ سیٹنگ گروپس کیسے باہم تعامل کرتے ہیں، [`CONFIG_REFERENCE.md`](%D8%AA%D8%B9%D9%85%DB%8C%D8%B1%D8%A7%D8%AA%DB%8C_%D8%AD%D9%88%D8%A7%D9%84%DB%81.md)۔ قطعی فیلڈز، ڈیفالٹس، اقسام، اور انویریئنٹس کے لیے، تیار کردہ استعمال کریں [`CONFIG_FIELD_CATALOG.md`](%DA%A9%D9%86%D9%81%DB%8C%DA%AF_%D9%81%DB%8C%D9%84%DA%88_%DA%A9%DB%8C%D9%B9%D9%84%D8%A7%DA%AF.md).

نیچے ہر Lua بلاک اعلی درجے کے اندراجات کا ایک مجموعہ ہے جو بھیجے گئے اندراجات کی جگہ لے سکتا ہے `return { ... }` ٹیبل۔

<a id="profile-chooser"></a>
## پروفائل کا انتخاب کنندہ

| صورتحال | یہ پروفائل استعمال کریں |
|---|---|
| پہلی انسٹال | محفوظ پہلے انسٹال |
| سرور غیر مستحکم ہے اور اکثر کریش ہوتا ہے | موجودہ ثبوت بغیر سست اسکین کے |
| آپ چاہتے ہیں object/world سیاق و سباق | مکمل بیس لائن |
| آپ پرانے لاگز کا جائزہ لینا چاہتے ہیں | فارنزک بیک فل |
| آپ سفارشات چاہتے ہیں لیکن کوئی تحریر نہیں | انفورسمنٹ ٹیسٹنگ |
| آپ گارڈ کو لکھنے پر پابندی لگانے کے لیے تیار ہیں | انفورسمنٹ فعال ہے |
| ڈسک محدود ہے | کم ڈسک کی نمو |
| آپ نے کلین بیس لائن مکمل کی | چسپاں بیک اپ سیٹ اپ |

<a id="safe-first-install"></a>
## محفوظ پہلے انسٹال

اسے پہلے لائیو سرور پر استعمال کریں۔

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

log_tail = {
    enabled = true,
    start_at_end_on_first_run = true,
    tail_backup_logs = false,
},

scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

یہ کیا کرتا ہے:

```text
Tracks live sessions.
Starts the baseline scan.
Does not edit Admin.ini.
Avoids treating old backup logs as fresh live events.
```

<a id="current-evidence-without-slow-scan"></a>
## موجودہ ثبوت بغیر سست اسکین کے

اس کا استعمال کریں اگر سرور غیر مستحکم ہے اور آپ کو ضرورت ہے crash/reconnect بھاری اسکین سے پہلے ثبوت۔

```lua
log_tail = {
    enabled = true,
},

scanning = {
    full_scan_on_start = false,
},

enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

یہ کیا کرتا ہے:

```text
Tracks logins, joins, leaves, reconnects, crashes, and unclean sessions.
Delays heavy world scanning.
```

<a id="full-baseline"></a>
## مکمل بیس لائن

اس کا استعمال اس وقت کریں جب سرور اسکین کرنے کے لیے کافی دیر تک برقرار رہ سکے۔

```lua
scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},
```

یہ کیا کرتا ہے:

```text
Builds object registry.
Writes world-state context.
Creates file manifest.
Enables changed-file refresh later.
```

<a id="forensic-backfill"></a>
## فارنزک بیک فل

اس کا استعمال صرف اس وقت کریں جب جان بوجھ کر تاریخی نوشتہ جات کا جائزہ لیا جائے۔

```lua
log_tail = {
    start_at_end_on_first_run = false,
    tail_backup_logs = true,
    backfill_backup_logs_on_start = true,
},
```

اسے استعمال کرنے سے پہلے:

```text
Back up runtime/log_offsets.tsv.
Expect old events to be reprocessed.
Return to live settings when finished.
```

<a id="enforcement-testing"></a>
## انفورسمنٹ ٹیسٹنگ

اسے اصل سے پہلے استعمال کریں Admin.ini تحریر۔

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},
```

کیا معائنہ کرنا ہے:

```text
runtime/account_evidence.json
runtime/warnings/
runtime/forensic_days/YYYY-MM-DD/ban_recommendations.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="enforcement-enabled"></a>
## انفورسمنٹ فعال ہے

جائزہ آؤٹ پٹ درست ہونے کے بعد ہی اسے استعمال کریں۔

```lua
enforcement = {
    review_only_mode = false,
    auto_ban = true,
    write_admin_ini = true,
    require_clean_ban_id = true,
    preserve_existing_bans = true,
    preserve_moderators = true,
},
```

فعال کرنے سے پہلے:

```text
Trusted IDs are configured.
Moderator IDs are preserved.
Admin.ini backups work.
Ban recommendations are understandable.
Thresholds are accepted by the server owner.
```

<a id="low-disk-growth"></a>
## کم ڈسک کی نمو

اس کا استعمال اس وقت کریں جب رن ٹائم فائلیں بہت تیزی سے بڑھ رہی ہوں۔

```lua
logging = {
    low_importance_mode = "aggregate",
    write_low_importance_raw_events = false,
},

retention = {
    detailed_retention_days = 7,
    rotate_jsonl_when_bytes_exceed = 5242880,
    max_raw_events_lines = 20000,
    compact_json_outputs = true,
},
```

<a id="sticky-backup-setup"></a>
## چسپاں بیک اپ سیٹ اپ

پہلی مکمل بیس لائن کے بعد استعمال کریں۔

چیک کریں کہ یہ موجود ہیں:

```text
runtime/scan_complete.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
runtime/world_state/current/world_state_latest.json
```

پھر ان کے ساتھ بیک اپ لیں `config.lua`, `SavedRoot.txt`، اور `Admin.ini`.
