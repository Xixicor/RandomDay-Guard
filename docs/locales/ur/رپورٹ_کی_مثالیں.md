# پانچ گارڈ رپورٹس کی مثالیں

> **کیننیکل انگریزی ماخذ:** [REPORT_EXAMPLES.md](../../REPORT_EXAMPLES.md). یہ مقامی دستاویزات درست کمانڈز، پاتھز، کیز، اسٹیٹس ویلیوز، ہیشز اور فائل کے ناموں کو محفوظ رکھتی ہیں۔ اگر تکنیکی الفاظ میں فرق ہے تو انگریزی ماخذ استعمال کریں۔


یہ مثالیں ریلیز کے ساتھ شامل نمونے کے ڈیٹا سے تیار کی گئی ہیں۔ نام اور اکاؤنٹ نمبر ایجاد کیے گئے ہیں۔ وہ جانچ شدہ رپورٹ کے فیلڈز، حسابات اور راستے کی حدود دکھاتے ہیں۔ ایک حقیقی رپورٹ انہیں اس سرور سے جمع کی گئی معلومات سے بدل دیتی ہے اور کہتی ہے کہ جب کوئی حقیقت دستیاب نہیں تھی۔

ہر رپورٹ میں ایک کام ہوتا ہے۔ سرور کی صحت پلیئر کی تاریخ کو نہیں دہراتی، روزانہ جائزہ ہر چند منٹوں میں نہیں بھیجا جاتا، اور خاموش پلیئر یا کیس روٹس کو فلر پیغامات موصول نہیں ہوتے۔ ایک موجودہ رپورٹ تیار ہو سکتی ہے جب باؤنڈڈ تاریخی اسکین ابھی بھی جاری ہے۔ اس صورت میں رپورٹ پرانی تاریخ کو مکمل کے طور پر پیش کرنے کے بجائے خلا کا نام دیتی ہے۔

## جب کوئی راستہ خاموش ہو

ایک پرسکون راستہ Discord کو فلر بھیجے بغیر براہ راست نتیجہ ریکارڈ کرتا ہے:

> **چیک کیا گیا؛ اس رپورٹ کے لیے کچھ نہیں۔** مطلوبہ ریکارڈز دستیاب تھے اور اس رپورٹ ونڈو کے دوران کوئی مماثل کھلاڑی کی سرگرمی، کیس، یا گارڈ کی ناکامی واقع نہیں ہوئی۔

یہ ایک مکمل خالی نتیجہ ہے۔ یہ ایک گمشدہ رپورٹ سے مختلف ہے، جہاں مطلوبہ ماخذ کو چیک نہیں کیا جا سکا یا پڑھنے کے قابل آؤٹ پٹ نہیں بنایا جا سکا۔

ہر پڑھنے کے قابل رپورٹ اسی راستے پر چلتی ہے:

```text
collected evidence -> normalized values -> dictionary mapping -> route calculations -> readable report -> Discord notification
```
