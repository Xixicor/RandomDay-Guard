#  لغت

> **کیننیکل انگریزی ماخذ:** [GLOSSARY.md](../../GLOSSARY.md). یہ مقامی دستاویزات درست کمانڈز، پاتھز، کیز، اسٹیٹس ویلیوز، ہیشز اور فائل کے ناموں کو محفوظ رکھتی ہیں۔ اگر تکنیکی الفاظ میں فرق ہے تو انگریزی ماخذ استعمال کریں۔


| اصطلاح | سادہ معنی | بالکل تکنیکی معنی |
|---|---|---|
| ایکٹو لاگ | تازہ ثبوت کے لیے موجودہ سرور لاگ استعمال کیا جاتا ہے۔ | ضرورت ہے `active_log` ذریعہ؛ روٹ کی تکمیل کے لیے پڑھنے کی اہلیت کے علاوہ موجودہ نسب کی ضرورت ہے۔ |
| بوٹ ID | ایک واچ ڈاگ عمل شروع۔ | موجودہ رن ٹائم شناخت کنندہ پیشگی بوٹ کو مسترد کرنے کے لیے استعمال کیا جاتا ہے errors/reports. |
| Epoch ID | ایک سرور تسلسل کا وقفہ۔ | شناخت کنندہ عام رن ٹائم پر پھیلا ہوا ہے جب تک کہ تسلسل منطق ایک اور دور شروع نہ کرے۔ |
| پول ID | ایک پابند پول کا موقع۔ | مثبت مونوٹونک سائیکل فیلڈ؛ zero/missing راستہ مکمل نہیں کر سکتا۔ |
| ذریعہ تازگی | کیا موجودہ ماخذ اور رائے شماری کا سلسلہ متفق ہے۔ | `fresh_current_poll` یا `stale_or_unproven` ٹائم اسٹیمپ اور ایکٹیو لاگ اسٹیٹس کے ساتھ۔ |
| ذریعہ اکاؤنٹنگ | ثبوت کی دستیابی اور حدود کی انوینٹری۔ | `randomdayguard.source-accounting/v1` آٹھ سورس کلاسز کے ساتھ اور current/historical دائرہ کار۔ |
| `available` | ایک ذریعہ ملا اور پڑھا گیا۔ | کے ساتھ ٹرمینل سورس اسٹیٹس `available=true`, `readable=true`. |
| `expected_empty` | ایک اختیاری ماخذ کو چیک کیا گیا اور جائز طریقے سے absent/empty. | ٹرمینل پڑھنے کے قابل ذریعہ کی حیثیت؛ کبھی بھی موضوع تیار نہیں کرتا۔ |
| `partial` | باؤنڈڈ کام کے مفید لیکن نامکمل نتائج ہوتے ہیں۔ | نانٹرمینل source/accounting اسٹیٹس؛ مالک کارکن کو دوبارہ شروع کریں۔ |
| `deferred` | کام جان بوجھ کر زیر التواء ہے۔ | نانٹرمینل سورس اسٹیٹس؛ غلطی یا تکمیل نہیں ہے۔ |
| `unavailable` | ذریعہ فی الحال استعمال نہیں کیا جا سکتا۔ | ٹرمینل گیپ؛ مطلوبہ ماخذ کا فرق اکاؤنٹنگ کو دستیاب نہیں بناتا ہے۔ |
| `malformed` | ایک ذریعہ موجود ہے لیکن ساختی طور پر غلط ہے۔ | ٹرمینل گیپ کی توثیق کی تفصیل کو محفوظ کرنا اور منحصر تحریروں کو بند کرنا۔ |
| `permission_denied` | OS نے واضح طور پر رسائی کو مسترد کردیا۔ | ٹرمینل گیپ missing/unavailable. |
| `error` | ایک باؤنڈڈ آپریشن غیر متوقع طور پر ناکام ہوگیا۔ | ٹرمینل کی ناکامی جس میں نام کی وصولی کی ضرورت ہوتی ہے؛ عوامی رپورٹس میں کوئی خفیہ تفصیل نہیں ہے۔ |
| `complete` | تمام حسابی ذرائع ٹرمینل ہیں بغیر کسی فرق کے۔ | اعلی سطحی ماخذ اکاؤنٹنگ کی حیثیت۔ |
| `complete_with_gaps` | موجودہ ثبوت کام کرتا ہے؛ اختیاری ٹرمینل گیپس باقی ہیں۔ | اعلی سطحی اکاؤنٹنگ کی حیثیت؛ راستے اب بھی اپنی ضروریات کا اطلاق کرتے ہیں۔ |
| `full` | ایک راستہ اس کے مطلوبہ غیر خالی معاہدے کے ساتھ مکمل ہوا۔ | مکمل کرنٹ سائیکل آؤٹ پٹس کے ساتھ روٹ پروف اینم۔ |
| `limited_expected_empty` | ایک راستہ مکمل ہوا اور کوئی اہل نہیں ملا subject/failure. | روٹ پروف اینوم کے ساتھ `completed=true`, `expected_empty=true`. |
| `missing` | روٹ کی تکمیل کا ثبوت غائب یا ناکام ہے۔ | روٹ پروف اینوم کے ساتھ `completed=false`؛ آؤٹ باکس کے لیے کبھی اہل نہیں۔ |
| سٹرکچرڈ رپورٹ | مشین سے پڑھنے کے قابل روٹ آؤٹ پٹ۔ | `<route>_latest.json` استعمال کر رہا ہے `randomdayguard.report/v1`. |
| ترجمہ شدہ رپورٹ | اسی راستے کی انسانی پڑھنے کے قابل رینڈرنگ۔ | `<route>_latest.txt` فکسڈ آبزروڈ ٹو سورس ریفرینس آرڈر کے ساتھ۔ |
| روٹ پروف | کراس روٹ تکمیلی لیجر۔ | `route_proof.json` بائنڈنگ version/boot/epoch/poll/freshness/output راستے۔ |
| موجودہ ثبوت | مشاہدہ فعال سائیکل کی ملکیت ہے۔ | اسکوپ `current`؛ پرانے سے دوبارہ تعمیر نہیں کیا گیا filenames/reports. |
| تاریخی ثبوت | پہلے چکروں یا سست اسکین سے سیاق و سباق کو برقرار رکھا۔ | اسکوپ `historical`؛ جائزہ کو مطلع کر سکتا ہے لیکن موجودہ موجودگی کا دعوی نہیں کر سکتا۔ |
| صرف جائزہ | بغیر جائزہ ثبوت پیش کریں Admin.ini لکھتا ہے۔ | ڈیفالٹ `review_only_mode=true`, `auto_ban=false`, `write_admin_ini=false`. |
| پابندی کی فہرست سیفٹی چیک | ایک سوال گارڈ کو جواب دینا چاہیے اس سے پہلے کہ وہ تبدیل ہو جائے `Admin.ini`. | اس کے لیے اکاؤنٹ اور سکور کی تصدیق، قابل اعتماد اکاؤنٹس اور ڈپلیکیٹس کو خارج کرنا، بیک اپ کی توثیق کرنا، بیرونی تبدیلیوں کا پتہ لگانا، مطلوبہ اپ ڈیٹ کو محفوظ کرنا، اور مکمل فائل کی تصدیق یا محفوظ طریقے سے بحال کرنا ضروری ہے۔ |
| مقامی آؤٹ باکس | اختیاری فراہم کنندہ غیر جانبدار اطلاع ہینڈ آف۔ | JSON فائلیں `delivery_backend="none"` اور `delivery_attempted=false`. |
| بیس لائن | مکمل شدہ باؤنڈڈ محفوظ شدہ فائل سیاق و سباق کا اسنیپ شاٹ۔ | Manifest/object/world حالت صرف اس صورت میں دوبارہ استعمال کی جاتی ہے جب ہم آہنگ اور کافی تازہ ہو۔ |
| چیک پوائنٹ | نامکمل اسکین کام کے لیے پوزیشن دوبارہ شروع کریں۔ | `scan_checkpoint.json`؛ حذف کرنا ڈیفالٹ ریکوری نہیں ہے۔ |
| دوبارہ قابل تعمیر انڈیکس | خلاصہ جسے دوبارہ تخلیق کیا جاسکتا ہے۔ | Daily/weekly/forensic/final جائزہ آؤٹ پٹ؛ ماخذ ثبوت مستند رہتا ہے۔ |
| ثبوت کی حد | اس بات کی حد جو کوئی ذریعہ سپورٹ کرسکتا ہے۔ | واضح `does_not_prove`، نامعلوم، شناخت کی طاقت، اور دائرہ کار کے اصول۔ |
