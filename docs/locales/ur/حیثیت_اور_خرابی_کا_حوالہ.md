# حیثیت اور غلطی کا حوالہ

> **کیننیکل انگریزی ماخذ:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). یہ مقامی دستاویزات درست کمانڈز، پاتھز، کیز، اسٹیٹس ویلیوز، ہیشز اور فائل کے ناموں کو محفوظ رکھتی ہیں۔ اگر تکنیکی الفاظ میں فرق ہے تو انگریزی ماخذ استعمال کریں۔


اس حوالہ کو استعمال کریں جب کسی علامت کی درجہ بندی ہو جائے [ٹربل شوٹنگ](%D9%B9%D8%B1%D8%A8%D9%84_%D8%B4%D9%88%D9%B9%D9%86%DA%AF.md)۔ ایرر کے نام سے سٹرکچرڈ اسٹیٹس فائل کو پڑھیں۔ الگ الگ کوڈز مختلف حفاظتی اور لائف سائیکل ریاستوں کی نمائندگی کرتے ہیں۔ انہیں عام "گارڈ فیل" نتیجہ میں نہ سمیٹیں۔

<a id="route-and-source-states"></a>
## روٹ اور سورس اسٹیٹس

| ویلیو | مطلب | آپریٹر کا جواب |
|---|---|---|
| `full` | روٹ کا معاہدہ کرنٹ سائیکل سورس پروف کے ساتھ مکمل ہوا۔ | روٹ کے ثبوت کی حد پڑھیں؛ کوئی مرمت مضمر نہیں ہے۔ |
| `limited_expected_empty` | روٹ مکمل ہوگیا اور گمشدہ سرگرمی اس سائیکل کے لیے جائز ہے۔ | کوئی مصنوعی نہیں player/case ایونٹ بنایا جانا چاہیے۔ |
| `missing` | ایک مطلوبہ آؤٹ پٹ، نسب کی فیلڈ، یا سورس پروف غائب ہے۔ | روٹ کی وجہ اور نام کے ذریعہ کی حیثیت کا معائنہ کریں۔ |
| `available` | نام کا ذریعہ پڑھنے کے قابل اور قابل استعمال تھا۔ | کوئی کارروائی نہیں۔ |
| `expected_empty` | ذریعہ چیک کیا گیا تھا اور قانونی طور پر اس میں کوئی قطار نہیں تھی۔ | کوئی کارروائی نہیں جب تک کہ سرگرمی آزادانہ طور پر متوقع نہ ہو۔ |
| `partial` / `complete_with_gaps` | قابل استعمال شواہد موجود ہیں، لیکن نامزد کردہ سورس کلاسز نامکمل ہیں۔ | نتائج کو جمع کردہ شواہد تک محدود رکھیں۔ |
| `deferred` | باؤنڈڈ کام بعد میں کارکن کے موقع کے لیے مقرر کیا گیا ہے۔ | کنفیگریشن کو تبدیل کرنے سے پہلے پیشرفت کی تصدیق کریں۔ |
| `unavailable` | ماحول نے ذریعہ فراہم نہیں کیا۔ | حد ریکارڈ کریں؛ صرف ایک ثابت شدہ راستہ یا اجازت کا مسئلہ درست کریں۔ |
| `malformed` | ذریعہ پڑھنے کے قابل تھا لیکن ساختی توثیق میں ناکام رہا۔ | اسے محفوظ کریں اور ماخذ کو درست کریں؛ اندازہ نہ لگائیں۔ |
| `permission_denied` | ذریعہ موجود ہے لیکن پڑھا نہیں جا سکتا۔ | صرف محدود مطلوبہ پڑھنے کی اجازت دیں۔ |
| `error` | ریکارڈ کی گئی وجہ سے جمع کرنا ناکام ہوگیا۔ | خرابی کو محفوظ رکھیں اور اس مرحلے کی تشخیص کریں۔ |

<a id="playerdata-and-inventory-codes"></a>
## PlayerData اور انوینٹری کوڈز

| کوڈ | مطلب | محفوظ جواب |
|---|---|---|
| `saved_root_unavailable` | عوامی پائپ لائن کے لیے کوئی تصدیق شدہ محفوظ شدہ روٹ دستیاب نہیں تھا۔ | درست `SavedRoot.txt` اور پاتھ پروب کو دوبارہ چیک کریں۔ |
| `unsafe_playerdata_root` | PlayerData دریافت باؤنڈڈ محفوظ شدہ جڑ سے باہر حل ہوگئی۔ | راستہ درست کریں؛ حد کو کبھی کمزور مت کرو۔ |
| `playerdata_discovery_not_run` | باؤنڈڈ ڈسکوری ورکر ابھی تک نہیں چلا ہے۔ | شیڈیولر اور کارکن کی پیشرفت چیک کریں۔ |
| `playerdata_discovery_read_failed:*` | Discovery output کو پڑھا نہیں جا سکا۔ | لاحقہ تفصیل کو محفوظ کریں اور باؤنڈڈ انوینٹری کمانڈ کی تصدیق کریں۔ |
| `inventory_command_open_failed` | انوینٹری کا عمل شروع نہیں کیا جا سکا۔ | تصدیق کریں کہ رن ٹائم ترتیب شدہ کمانڈ برج فراہم کرتا ہے۔ |
| `inventory_command_read_failed` | پڑھنے کے دوران انوینٹری آؤٹ پٹ ناکام ہوگیا۔ | جزوی آؤٹ پٹ کو محفوظ کریں اور بنیادی خامی ٹھیک ہونے کے بعد ہی دوبارہ چلائیں۔ |
| `inventory_command_close_failed` | بغیر قابل اعتماد قریبی نتیجہ کے مکمل انوینٹری۔ | ماخذ کو نامکمل سمجھیں۔ |
| `identity_ledger_row_limit_exceeded` | پائیدار شناختی ان پٹ اپنی عوامی حفاظت کی حد سے تجاوز کر گیا ہے۔ | لیجر کو محفوظ کریں اور اس کا جائزہ لیں؛ خاموشی سے اسے مکمل ثبوت میں نہ تراشیں۔ |

<a id="adminini-enforcement-codes"></a>
## Admin.ini نفاذ کوڈز

اس سیکشن کے تمام کوڈز ناکام بند ہیں۔ وہ خود سے دستی پابندی کی اجازت نہیں دیتے۔

| کوڈ | مطلب | محفوظ جواب |
|---|---|---|
| `admin_ini_write_disabled` / `admin_ini_disabled` | عوامی محفوظ تحریری دروازے بند ہیں۔ | صرف جائزہ آپریشن میں متوقع۔ |
| `admin_ini_backup_disabled` / `backup_safety_gate_disabled` | مطلوبہ بیک اپ پالیسی فعال نہیں ہے۔ | لکھنے کو غیر فعال رکھیں۔ |
| `enforcement_disabled` / `ban_on_threshold_disabled` / `auto_ban_disabled` | انفورسمنٹ کا ایک واضح گیٹ بند ہے۔ | صرف عوامی جائزہ ڈیفالٹس میں متوقع؛ اسے لکھنے کی ناکامی کے طور پر دوبارہ تعبیر نہ کریں۔ |
| `review_only_mode_enabled` | صرف جائزہ موڈ جان بوجھ کر اتپریورتن کو روکتا ہے۔ | صرف ثبوت کا جائزہ لیں۔ |
| `duplicate_prevention_disabled` | ڈپلیکیٹ تحفظ کو غیر فعال کر دیا گیا تھا۔ | سیفٹی گیٹ بحال ہونے تک تحریروں کو غیر فعال رکھیں۔ |
| `readback_safety_gate_disabled` / `rollback_safety_gate_disabled` | بعد کی تحریری توثیق یا رول بیک تحفظ کو غیر فعال کر دیا گیا تھا۔ | لکھنے کو غیر فعال رکھیں؛ ان دروازوں کو کبھی نظرانداز نہ کریں۔ |
| `clean_id_safety_gate_disabled` / `account_specific_evidence_gate_disabled` | صاف شناخت یا اکاؤنٹ کے مخصوص ثبوت کے نفاذ کو غیر فعال کر دیا گیا تھا۔ | کسی بھی نفاذ کے ٹیسٹ سے پہلے گیٹ کو بحال کریں۔ |
| `moderator_preservation_disabled` / `existing_ban_preservation_disabled` | محفوظ اکاؤنٹ یا موجودہ پابندی کے تحفظ کو غیر فعال کردیا گیا تھا۔ | لکھنے کو غیر فعال رکھیں۔ |
| `clean_numeric_identity_required` | مجوزہ ID مکمل قبول شدہ کنکشن فارم یا کلین عددی ID نہیں ہے۔ | تصدیق شدہ میپنگ حاصل کریں؛ صوابدیدی سابقہ ​​کو کبھی نہ چھوٹا کریں۔ |
| `identity_strength_below_minimum` | شناختی ثبوت کنفیگر کردہ حد سے کمزور ہے۔ | صرف ثبوت کا جائزہ لیں۔ |
| `playerdata_verification_required` | کنفیگریشن کی ضرورت ہے PlayerData تصدیق اور اکاؤنٹ میں نہیں ہے۔ | امیدوار کو صرف جائزے کے لیے رکھیں؛ فائل نام سے ملکیت کا اندازہ نہ لگائیں۔ |
| `trusted_or_moderator_identity` | اکاؤنٹ بھروسہ مند یا ماڈریٹر اسٹیٹ کے ذریعہ محفوظ ہے۔ | لکھنے کی اجازت نہیں ہے۔ |
| `admin_ini_path_invalid` / `admin_ini_path_outside_saved_root` | ہدف کا راستہ غلط ہے یا محفوظ شدہ جڑ سے بچ جاتا ہے۔ | درست ترتیب؛ راستے کے محافظ کو کبھی بھی نظرانداز نہ کریں۔ |
| `admin_ini_unavailable` | کوئی پڑھنے کے قابل کنفیگر نہیں ہے Admin.ini محفوظ شدہ جڑ کے اندر پایا گیا۔ | باؤنڈڈ راستے کو درست کریں یا نفاذ کو غیر فعال رکھیں۔ |
| `admin_ini_read_failed` | مستند بائٹس کو پڑھا نہیں جا سکا۔ | میوٹیشن سے پہلے رک جائیں۔ |
| `admin_ini_parse_failed` | Admin.ini زیادہ مخصوص ساختی کوڈ کے بغیر توثیق ناکام ہوگئی۔ | فائل کو محفوظ کریں اور اس کے سیکشن اور لائن کی ساخت کا معائنہ کریں۔ |
| `admin_ini_contains_nul` | فائل پر مشتمل ہے NUL بائٹس اور متن کے طور پر قبول نہیں کیا جاتا ہے۔ | فائل کو محفوظ کریں اور اسے گارڈ کے باہر مرمت کریں۔ |
| `admin_ini_duplicate_banned_players_section` | ایک سے زیادہ `[BannedPlayers]` سیکشن موجود ہے۔ | روکتے وقت سیکشنز کو دستی طور پر ضم کریں۔ |
| `admin_ini_banned_player_outside_section` | باہر ایک پابندی کی قطار ظاہر ہوتی ہے `[BannedPlayers]`. | لے آؤٹ کو دستی طور پر درست کریں۔ |
| `admin_ini_invalid_banned_player_line` | پابندی کی لائن قطعی طور پر کلین سپورٹ شدہ ID قطار نہیں ہے۔ | خراب لائن کو درست کریں۔ |
| `admin_ini_backup_failed` | منفرد بیک اپ نے بائٹ یکساں طور پر نہیں لکھا اور نہ ہی پڑھا۔ | کسی تبدیلی کی اجازت نہیں ہے۔ |
| `admin_ini_external_change_detected` | ایک اور مصنف نے گارڈ کے اسنیپ شاٹ کے بعد فائل کو تبدیل کیا۔ | بیرونی بائٹس کو محفوظ کریں اور مصنفین کو مربوط کرنے کے بعد ہی دوبارہ کوشش کریں۔ |
| `atomic_rename_unavailable` | جوہری متبادل کی درخواست کی گئی تھی لیکن Lua نے فراہم نہیں کیا `os.rename`. | کوئی تحریر قابل اعتبار نہیں ہے؛ تعاون یافتہ رن ٹائم استعمال کریں یا نفاذ کو غیر فعال رکھیں۔ |
| `admin_ini_write_failed` | کنٹرول شدہ تبدیلی مکمل نہیں ہوئی۔ | ریکارڈ کی گئی تبدیلی کی خرابی اور بیک اپ کا معائنہ کریں۔ |
| `post_write_verification_failed` | پروڈکشن بائٹس امیدوار کے برابر نہیں تھے۔ | چیک کریں `rollback_success` اور `rollback_refused_external_change` کسی بھی کارروائی سے پہلے۔ |

<a id="startup-scheduler-and-backlog-states"></a>
## اسٹارٹ اپ، شیڈولر، اور بیک لاگ اسٹیٹس

یہ اقدار لائف سائیکل ثبوت ہیں، روٹ پروف نہیں۔ انہیں موجودہ پول، رپورٹ ورکر، اور روٹ پروف فائلوں کے ساتھ پڑھیں۔

| ویلیو | مطلب | محفوظ جواب |
|---|---|---|
| `not_started` | نام کا آغاز یا شیڈولر مرحلہ شروع نہیں ہوا ہے۔ | لانچ کے دوران، دستاویزی وقفہ کا انتظار کریں؛ اس کے بعد پہلے غیر تبدیل شدہ مرحلے کا معائنہ کریں۔ |
| `main_lua_loaded` / `starting` | کیننیکل لوڈر بھاگ گیا اور گارڈ اسٹارٹ اپ میں داخل ہوا۔ | بعد کے مراحل تک جاری رکھیں؛ یہ اکیلے تیاری نہیں ہے۔ |
| `saved_root_found` / `log_tail_initialized` / `epoch_started` | بنیادی ماخذ اور تسلسل کی ابتداء ایڈوانس۔ | کوئی کارروائی نہیں جب تک کہ اگلا مرحلہ آگے بڑھنا بند نہ کر دے۔ |
| `admin_state_written` / `playerdata_index_written` | ابتدائی پابند اشاریہ جات برآمد کیے گئے تھے۔ | کوئی کارروائی نہیں؛ شیڈولر ہینڈ آف کو ابھی بھی فالو کرنا چاہیے۔ |
| `watchdog_started` | رپورٹ اور پول واچ ڈاگ رجسٹرڈ تھا۔ | شیڈیولر کی تصدیق کریں اور اگلی پول کی پیشرفت۔ |
| `ready_degraded` / `scan_running` | گارڈ چل رہا ہے جب کہ پابند تاریخی اسکین زیر التواء ہے۔ | احتیاط، ناکامی نہیں؛ پیش رفت کاؤنٹرز کی پیشگی تصدیق کریں۔ |
| `ready` | اسٹارٹ اپ اور موجودہ باؤنڈڈ اسکین تیار حالت میں پہنچ گیا۔ | روٹ پروف کو الگ سے چیک کریں۔ |
| `scan_failed` / `error` | ایک ریکارڈ شدہ خرابی کے ساتھ اسٹارٹ اپ یا اسکین ختم ہوگیا۔ | نام کی غلطی یا اسٹیٹس فائل کو محفوظ کریں اور اس مرحلے کی تشخیص کریں۔ |
| `running` | شیڈیولر مستقبل کے پول کے مواقع کا مالک ہے۔ | تصدیق کریں `poll_id` اور `poll_completed_count` پیشگی۔ |
| `manual_only` | لوپ شیڈولنگ دستیاب نہیں تھی؛ صرف واضح کام چل سکتا ہے۔ | غیر حاضر آپریشن کو غیر دستیاب سمجھیں۔ |
| `stopped` | شیڈیولر آپریشن ختم ہوگیا۔ | دوبارہ شروع کرنے سے پہلے پچھلے سٹاپ اور غلطی کے ثبوت کا معائنہ کریں۔ |
| `active_log_caught_up` | کوئی بغیر پڑھا ہوا ایکٹیو لاگ بیک لاگ باقی نہیں ہے۔ | تاریخی اسکین آگے بڑھ سکتا ہے۔ |
| `active_log_unavailable_nonblocking` | ایکٹو لاگ غائب تھا، لیکن اسٹارٹ اپ غیر مسدود رہا۔ | ماخذ کی حد کو ریکارڈ کریں اور دوسرے ذرائع کی تصدیق کریں۔ |
| `active_log_read_failed` | فعال لاگ موجود تھا لیکن پڑھا نہیں جا سکا۔ | خرابی کو محفوظ رکھیں اور صرف ثابت شدہ راستہ یا اجازت کے مسئلے کو درست کریں۔ |
| `budget_exhausted` / `active_log_has_unread_bytes` | باؤنڈڈ ٹیل پاس باقی رہ جانے کے ساتھ رک گیا۔ | تصدیق کریں کہ بعد میں ہونے والے پولز بغیر پڑھے ہوئے گنتی کو کم کرتے ہیں۔ |
| `offset_commit_failed_after_events_applied` | ایونٹس پر کارروائی کی گئی لیکن پائیدار لاگ آفسیٹ تسلسل ناکام رہا۔ | انفورسمنٹ موخر کر دی گئی ہے۔ دوسرے سائیکل پر انحصار کرنے سے پہلے آفسیٹ اسٹوریج کی مرمت کریں۔ |

<a id="scheduler-report-and-notification-codes"></a>
## شیڈیولر، رپورٹ، اور اطلاعی کوڈز

| کوڈ یا اسٹیٹس | مطلب | محفوظ جواب |
|---|---|---|
| `poll already in flight` | ایک دوسرا کال بیک آیا جب کہ موجودہ پول لائف سائیکل کی ملکیت ہے۔ | موجودہ پول ایڈوانسز کی تصدیق کریں؛ دوسرے لوپ مالک کو شامل نہ کریں۔ |
| `no_log_files_found` | کوئی ترتیب شدہ فعال یا بیک اپ لاگ دریافت نہیں ہوا۔ | محفوظ کردہ روٹ اور سورس کنفیگریشن کی تصدیق کریں۔ |
| `current_poll_error` | موجودہ سائیکل نے پول سورس کی ناکامی کو ریکارڈ کیا ہے۔ | پڑھیں `runtime/current/poll_error.json`. |
| `cadence_deferred` | کمپلیشن ڈسپیچر ابھی باقی نہیں ہے۔ | اگلے پابند موقع تک متوقع۔ |
| `reports_disabled` | عوامی رپورٹ تیار کرنا غیر فعال ہے۔ | صرف اس صورت میں فعال کریں جب رپورٹس کا ارادہ ہو۔ |
| `local_outbox_write_failed` | ایک ترجمہ شدہ مقامی لفافہ لکھا نہیں جا سکا۔ | رن ٹائم آؤٹ پٹ ڈائرکٹری کی مرمت کریں؛ یہ اطلاعی نقل و حمل کی خرابی نہیں ہے۔ |
| `source_accounting_disabled` | روٹ پروف مکمل سورس کوریج کا دعوی نہیں کرسکتا۔ | ذریعہ اکاؤنٹنگ کو فعال کریں یا غائب ثبوت کو واضح طور پر قبول کریں۔ |
| `route_disabled` | راستے کو جان بوجھ کر غیر فعال کیا گیا ہے۔ | اس راستے کے لیے کوئی ترسیل متوقع نہیں ہے۔ |
| `poll_owner_between_polls` | رپورٹ ورکر پولز کے درمیان شیڈولر کی ملکیت والے فرق کے لیے قطار میں کھڑا ہے۔ | متوقع صرف اس وقت جب ٹائم اسٹیمپ اور کرسر آگے بڑھتے رہیں۔ |
| `unsafe_shell_path` | ایک پابند انوینٹری یا شیل پاتھ پلیٹ فارم سے محفوظ توثیق میں ناکام ہوگیا۔ | راستہ درست کریں؛ کوٹنگ یا راستے کی توثیق کو کبھی کمزور نہ کریں۔ |
