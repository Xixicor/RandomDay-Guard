# 安装RandomDayGuard

> **规范的英文来源:** [INSTALL.md](../../../INSTALL.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


本指南安装 `v0.4.12-alpha`在已使用的 Abiotic Factor 专用服务器上UE4SS。该模组不与任何托管公司或控制面板绑定。

<a id="before-you-begin"></a>
## 开始之前

您需要：

- 有权停止和启动专用服务器；
- 服务器的UE4SS `Mods`文件夹；
- 当前RandomDayGuard文件夹的副本（如果您要更新）；
- 更改 mod 之前通常保护的服务器数据的备份。

**Mods 文件夹** 是 `ue4ss/Mods/`专用服务器安装内的目录。 RandomDayGuard 直接属于该文件夹。

<a id="new-installation"></a>
## 新安装

1. 停止专用服务器。
2. 将 RandomDayGuard ZIP 解压到一个新的空文件夹中。
3. 将解压的`RandomDayGuard` 文件夹放入服务器的 UE4SS `Mods` 文件夹。结果应该是一个 `Mods/RandomDayGuard/` 文件夹中，而不是嵌套在其中的第二个 RandomDayGuard 文件夹中
4. 打开UE4SS `mods.txt` 并启用：

   ```text
   RandomDayGuard : 1
   ```

5. 正常启动服务器。
6. 等待UE4SS 游戏服务器启动完成，然后按照[阅读第一份报告](%E4%BB%8E%E8%BF%99%E9%87%8C%E5%BC%80%E5%A7%8B.md).

不要在正在运行的安装上复制新版本。保留备份，直到更新的安装生成当前服务器状态报告。

<a id="update-an-existing-installation"></a>
## 更新现有安装

1. 停止服务器。
2. 将完整安装的RandomDayGuard文件夹复制到安全的备份位置。
3. 将旧程序文件夹移出UE4SS `Mods`，而不是在其上覆盖新版本。
4. 将新的 RandomDayGuard 文件夹复制到 `Mods`.
5. 仅恢复您检查过的本地配置和保存的证据。如果配置指南列出了新字段，请将它们合并到审阅的副本中，而不是盲目替换所有设置。
6. 确认`RandomDayGuard : 1`保持启用状态。
7. 启动服务器并读取当前服务器状态报告。

此清理文件夹更新还会删除旧版本中的过时文件，而无需要求操作员检查程序

<a id="help-guard-find-the-server-records"></a>
## 帮助 Guard 查找服务器记录

Guard 通常会自动查找 Abiotic Factor `Saved` 目录。如果不能，请将 `Saved` 目录的完整路径放入 RandomDayGuard 文件夹内的 `SavedRoot.txt` 内 RandomDayGuard 文件夹。指向`Saved`，而不是指向其下方的单个世界。

第一个服务器状态报告说明是否找到记录位置以及哪些源组可用。使用[故障排除](%E6%95%85%E9%9A%9C%E6%8E%92%E9%99%A4.md) 当无法读取位置时。

<a id="first-run-behavior"></a>
## 首次运行行为

默认安装会监视可用记录并写入报告。它不会改变`Admin.ini`或添加禁令。这样，您可以在决定是否启用任何可选操作之前确认收集、翻译和报告质量。

[阅读第一份报告](%E4%BB%8E%E8%BF%99%E9%87%8C%E5%BC%80%E5%A7%8B.md)

<a id="disable-or-remove-randomdayguard"></a>
## 禁用或删除RandomDayGuard

1. 停止服务器。
2. 复制完整内容RandomDayGuard 文件夹到安全存档。
3. 要禁用该模块，请设置 `RandomDayGuard : 0` 位于 UE4SS `mods.txt`.
4. 要删除它，请移动完整的RandomDayGuard 文件夹位于 `Mods`确认存档后即可打开。
5. 启动服务器并确认 Guard 不再启动。

禁用或删除 Guard 会停止未来的收集。它不会删除游戏数据、删除存档报告或撤销单独的操作员操作。

<a id="roll-back-an-update"></a>
## 回滚更新

如果新安装无法加载或无法生成当前报告：

1. 停止服务器。
2. 将不成功的安装移到一边，而不删除其记录。
3. 恢复完整的更新前RandomDayGuard 文件夹。
4. 从同一备份中恢复已审核的配置和保存的证据。
5. 确认模组已启用并启动服务器。
6. 在进行其他更改之前阅读恢复的服务器状态报告。
