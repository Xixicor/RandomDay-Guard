<a id="detection-signals"></a>
# 检测信号

> **规范的英文来源:** [DETECTION_SIGNALS.md](../../DETECTION_SIGNALS.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


信号是审核输入，而不是自动指控。

<a id="signal-table"></a>
## 信号表

| 信号 | 含义 | 当...时更强 | 本身不够 |
|---|---|---|---|
| 登录身份 | 将名称映射到帐户 ID | ConnectID 存在 | 禁令 |
| 干净离开 | 正常会话关闭 | 加入并离开比赛 | 怀疑 |
| 快速重新连接 | Churn/probing上下文 | 快速重复 | 禁令 |
| 不干净的断开连接 | 会话未完全关闭 | 重复或重叠崩溃 | 禁令 |
| 崩溃重叠 | 崩溃附近的帐户处于活动状态 | 同一帐户重复 | 禁令 |
| 崩溃后返回 | 帐户重新启动后返回 | 跨纪元重复 | 被一个事件禁止 |
| 突发警告 | 服务器警告窗口 | 重叠映射会话 | 一次突发禁止 |
| 演员保存触摸 | 世界保存上下文 | 与会话关联 | 证据use/theft |
| 对象增量 | World/class更改 | 与会话关联 | 单独禁止计数 |
| 袭击案例 | 多帐户集群 | 中央帐户重复 | 大规模禁止所有帐户 |

<a id="login-identity"></a>
## 登录身份

最佳来源：

```text
Login request
Name=
ConnectID=
UniqueId=
```

用它来映射：

```text
display/log name -> account_id -> ban_id
```

<a id="rapid-reconnect"></a>
## 快速重新连接

模式：

```text
join -> leave -> join -> leave -> join
```

重复时用于审核。

安全性：

```text
churn_alone_never_bans = true
```

<a id="crash-overlap-and-post-crash-return"></a>
## 崩溃重叠和崩溃后返回

模式：

```text
account active before crash
server restarts
same account returns quickly
```

跨时期重复时用于审核。

安全性：

```text
single_crash_never_bans = true
```

<a id="warning-bursts"></a>
## 突发警告

示例：

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

在链接到映射的会话和阈值之前用作上下文。

<a id="actor-save-touch"></a>
## 演员保存触摸

含义：

```text
The server evidence referenced a class or actor.
```

不意味着：

```text
A player opened it.
A player stole from it.
A player duplicated through it.
A player damaged it.
```

<a id="raid-cases"></a>
## 袭击案例

突袭案例按时间和共享窗口对帐户进行分组。

规则：

```text
Do not auto-ban every account in a raid case.
Each account needs account-specific evidence.
```
