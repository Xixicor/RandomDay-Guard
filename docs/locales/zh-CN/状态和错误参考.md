# 状态和错误参考

> **规范的英文来源:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


在 [故障排除](%E6%95%85%E9%9A%9C%E6%8E%92%E9%99%A4.md) 中对症状进行分类后使用此参考。 Read the structured status file named by the error. Distinct codes represent distinct safety and lifecycle states;不要将它们折叠成通用的“Guard 失败”结果。

<a id="route-and-source-states"></a>
## 路由和源状态

| 值 | 含义 | 操作员响应 |
|---|---|---|
| `full` | 使用当前周期源证明完成的路线合同。 | 读取路线的证据边界；不暗示修复。 |
| `limited_expected_empty` | 已完成的路线和缺少的活动对于本周期是合法的。 | 不应创建合成player/case事件。 |
| `missing` | 缺少必需的输出、沿袭字段或源证明。 | 检查路由原因和命名源状态。 |
| `available` | 命名源可读且可用。 | 否操作。 |
| `expected_empty` | 源已检查并且合法地没有行。 | 除非活动是独立预期的，否则不采取任何操作。 |
| `partial` / `complete_with_gaps` | 存在可用的证据，但指定的源类不完整。 | 将结论限制在收集的证据中。 |
| `deferred` | 为稍后的工作人员安排有限的工作 | 更改配置之前确认进度。 |
| `unavailable` | 环境未提供源。 | 记录限制；仅更正经过验证的路径或权限问题。 |
| `malformed` | 源代码可读，但结构验证失败。 | 保留它并修复源代码；不要猜测。 |
| `permission_denied` | 来源存在，但无法读取。 | 仅授予所需的有限读取权限。 |
| `error` | 由于记录的原因，收集失败。 | 保留错误并诊断该阶段。 |

<a id="playerdata-and-inventory-codes"></a>
## PlayerData和库存代码

| 代码 | 含义 | 安全响应 |
|---|---|---|
| `saved_root_unavailable` | 没有经过验证的已保存根可用于公共管道。 | 更正`SavedRoot.txt`并重新检查路径探测。 |
| `unsafe_playerdata_root` | PlayerData在外部解决的发现有限的已保存根目录。 | 更正路径；永远不会削弱边界。 |
| `playerdata_discovery_not_run` | 有界发现工作线程尚未运行。 | 检查调度程序和工作线程进度。 |
| `playerdata_discovery_read_failed:*` | 无法读取发现输出。 | 保留后缀详细信息并验证有界清单命令。 |
| `inventory_command_open_failed` | 无法执行清单过程已启动。 | 验证运行时提供配置的命令桥。 |
| `inventory_command_read_failed` | 读取期间清单输出失败。 | 保留部分输出并仅在修复基础错误后重新运行。 |
| `inventory_command_close_failed` | 清单已完成，但没有可靠的关闭结果。 | 将源视为不完整。 |
| `identity_ledger_row_limit_exceeded` | 持久身份输入超出了其公共安全范围。 | 归档并审查账本；不要默默地将其截断为完整的证明。 |

<a id="adminini-enforcement-codes"></a>
## Admin.ini强制代码

本节中的所有代码都是失败关闭的。他们自己不授权手动禁止。

| 代码 | 含义 | 安全响应 |
|---|---|---|
| `admin_ini_write_disabled` / `admin_ini_disabled` | 公共安全写入门已关闭。 | 预期仅用于审核操作。 |
| `admin_ini_backup_disabled` / `backup_safety_gate_disabled` | 所需的备份策略未激活。 | 保持写入禁用。 |
| `enforcement_disabled` / `ban_on_threshold_disabled` / `auto_ban_disabled` | 一个明确的强制门是关闭。 | 预计仅公开审核默认值；不要将其重新解释为写入失败。 |
| `review_only_mode_enabled` | 仅审核模式有意阻止突变。 | 仅审核证据。 |
| `duplicate_prevention_disabled` | 重复保护已禁用。 | 在安全门恢复之前保持写入禁用状态。 |
| `readback_safety_gate_disabled` / `rollback_safety_gate_disabled` | 写入后验证或回滚保护已禁用。 | 保留禁止写入；切勿绕过这些大门。 |
| `clean_id_safety_gate_disabled` / `account_specific_evidence_gate_disabled` | 清洁身份或特定于帐户的证据强制执行已禁用。 | 在任何执行测试之前恢复大门。 |
| `moderator_preservation_disabled` / `existing_ban_preservation_disabled` | 受保护帐户或现有禁令保留已禁用。 | 保持写入禁用。 |
| `clean_numeric_identity_required` | 建议的 ID 不是完整接受的连接表单或干净的数字 ID。 | 获取经过验证的映射；切勿截断任意前缀。 |
| `identity_strength_below_minimum` | 身份证据弱于配置的阈值。 | 仅审核证据。 |
| `playerdata_verification_required` | 配置需要 PlayerData 确认，但帐户没有该配置。 | 仅让候选者进行审核；请勿从文件名推断所有权。 |
| `trusted_or_moderator_identity` | 帐户受受信任或主持人状态保护。 | 不允许写入。 |
| `admin_ini_path_invalid` / `admin_ini_path_outside_saved_root` | 目标路径无效或转义保存的根目录。 | 正确配置；切勿绕过路径防护。 |
| `admin_ini_unavailable` | 在已保存的根中找不到可读配置Admin.ini。 | 更正有界路径或保持强制禁用。 |
| `admin_ini_read_failed` | 无法读取权威字节。 | 在突变之前停止。 |
| `admin_ini_parse_failed` | Admin.ini 如果没有更具体的结构代码，验证失败。 | 保留文件并检查其部分和行结构。 |
| `admin_ini_contains_nul` | 该文件包含 NUL 字节，不被接受为文本。 | 保留文件并在 Guard 之外修复它。 |
| `admin_ini_duplicate_banned_players_section` | 存在多个 `[BannedPlayers]` 部分。 | 手动合并部分已停止。 |
| `admin_ini_banned_player_outside_section` | 禁止行出现在外部`[BannedPlayers]`. | 手动更正布局。 |
| `admin_ini_invalid_banned_player_line` | 禁止行并不完全是干净的受支持 ID 行。 | 更正格式错误的行。 |
| `admin_ini_backup_failed` | 唯一备份未以相同的字节方式写入和读回。 | 不允许更改。 |
| `admin_ini_external_change_detected` | 另一个写入器在 Guard 快照后更改了文件。 | 保留外部字节并仅在协调写入器后重试。 |
| `atomic_rename_unavailable` | 已请求原子替换，但 Lua 未提供`os.rename`. | 不信任写入；使用支持的运行时或保持强制禁用。 |
| `admin_ini_write_failed` | 受控替换未完成。 | 检查记录的替换错误和备份。 |
| `post_write_verification_failed` | 生产字节与候选字节不相等。 | 在执行任何操作之前检查`rollback_success` 和 `rollback_refused_external_change`。 |

<a id="startup-scheduler-and-backlog-states"></a>
## 启动、调度程序和积压状态

这些值是生命周期证据，而不是路由证明。使用当前轮询、报告工作人员和防路由文件读取它们。

| 值 | 含义 | 安全响应 |
|---|---|---|
| `not_started` | 指定的启动或调度程序阶段尚未开始。 | 在启动期间，等待记录的时间间隔；然后检查第一个未更改的阶段。 |
| `main_lua_loaded` / `starting` | 规范加载程序运行并且 Guard 进入启动状态。 | 继续后面的阶段；仅此一点还没有准备好。 |
| `saved_root_found` / `log_tail_initialized` / `epoch_started` | 核心源代码和连续性初始化已高级。 | 除非下一阶段停止推进，否则不采取任何行动。 |
| `admin_state_written` / `playerdata_index_written` | 初始有界索引已导出。 | 不采取任何行动；调度程序切换仍必须遵循。 |
| `watchdog_started` | 报告和轮询看门狗已注册。 | 下一步确​​认调度程序和轮询进度。 |
| `ready_degraded` / `scan_running` | 防护正在运行，而有界历史扫描仍处于待处理状态。 | 注意，不是失败；验证进度计数器是否提前。 |
| `ready` | 启动和当前有界扫描已达到就绪状态。 | 单独检查路由证明。 |
| `scan_failed` / `error` | 启动或扫描因记录的错误而终止。 | 保留指定的错误或状态文件并诊断该阶段。 |
| `running` | 调度程序拥有未来投票机会。 | 确认`poll_id` 和 `poll_completed_count`提前。 |
| `manual_only` | 循环调度不可用；仅显式工作可以运行。 | 将无人值守操作视为不可用。 |
| `stopped` | 调度程序操作已结束。 | 在重新启动之前检查先前的停止和错误证据。 |
| `active_log_caught_up` | 没有未读的活动日志积压。 | 历史扫描可能会发生继续。 |
| `active_log_unavailable_nonblocking` | 活动日志不存在，但启动仍然是非阻塞的。 | 记录源限制并验证其他源。 |
| `active_log_read_failed` | 活动日志存在，但无法读取。 | 保留错误并仅更正已证明的路径或权限问题。 |
| `budget_exhausted` / `active_log_has_unread_bytes` | 有界尾部传递已停止，且仍有积压。 | 确认稍后的民意调查减少了未读的日志计数。 |
| `offset_commit_failed_after_events_applied` | 事件已处理，但持久日志偏移量持久性失败。 | 强制执行已推迟；在依赖另一个周期之前修复偏移存储。 |

<a id="scheduler-report-and-notification-codes"></a>
## 调度程序、报告和通知代码

| 代码或状态 | 含义 | 安全响应 |
|---|---|---|
| `poll already in flight` | 当前轮询拥有生命周期时第二个回调到达。 | 确认现有轮询进展；请勿添加其他循环所有者。 |
| `no_log_files_found` | 未发现配置的活动或备份日志。 | 验证保存的根和源配置。 |
| `current_poll_error` | 当前循环记录了轮询源失败。 | 读取`runtime/current/poll_error.json`. |
| `cadence_deferred` | 完成调度程序尚未到期。 | 预计到下一个有限机会为止。 |
| `reports_disabled` | 公共报告生成已禁用。 | 仅在需要报告时才启用。 |
| `local_outbox_write_failed` | 无法写入已翻译的本地信封。 | 修复运行时输出目录；这不是通知传输错误。 |
| `source_accounting_disabled` | 路由证明无法声明完整的源覆盖范围。 | 启用源核算或显式接受缺失的证明。 |
| `route_disabled` | 该路由被故意禁用。 | 预计该路线不会进行传送。 |
| `poll_owner_between_polls` | 报表工作人员已在轮询之间的调度程序拥有的间隙内排队。 | 仅当时间戳和游标继续前进时才预期。 |
| `unsafe_shell_path` | 有界清单或 shell 路径未通过平台安全验证。 | 更正路径；切勿削弱报价或路径验证。 |
