# 操作手册

> **规范的英文来源:** [OPERATIONS_PLAYBOOK.md](../../OPERATIONS_PLAYBOOK.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


这是 RandomDayGuard。你不需要知道JSON、Git、校验和或命令行工具来检查健康的服务器。

<a id="daily-operator-flow"></a>
## 每日操作流程

1. 打开`runtime/final_logs/server_status_latest.txt`。它告诉您 Guard 是否正在监视当前服务器的运行、最后一个周期何时完成、连接了多少玩家以及源或扫描是否不完整。
2. 打开`runtime/final_logs/daily_rollup_latest.txt`每天一次。它汇总当天的会话、退出、指定案例工作、身份清单和源覆盖范围，而无需重复每个单独的记录。
3. 打开`runtime/final_logs/player_activity_latest.txt`仅当服务器在白天有加入、离开或活动会话时。
4. 打开`runtime/final_logs/case_review_latest.txt`仅当它指定当前主题时。该报告提供帐户、审核状态、分数、身份来源以及接下来要打开的记录。
5. 打开`runtime/final_logs/critical_guard_latest.txt`仅当 Guard 报告其自身启动、监控周期或报告写入失败时。

如果路由没有任何内容可报告，Guard 会记录预期为空的结果。这是一份完整的检查，而不是一份缺失的报告。

<a id="what-to-read-inside-a-report"></a>
## 报告中要读的内容

按顺序阅读这些部分：

1. **Summary** - what this report covers.
2. **What Guard observed** - actual timestamps, counts, accounts, sessions, or status values collected for this route.
3. **What it means** - the plain-language interpretation of those records.
4. **What remains unknown** - a source or scan limit that affects the result.
5. **Recommended next step** - whether to monitor, review a named subject, or repair Guard.
6. **证据边界** - the limit of the report's scope.

技术记录和来源参考显示在末尾，供需要检查确切结构化证据的读者使用。

<a id="when-a-report-is-missing"></a>
## 当报告丢失时

打开`runtime/final_logs/route_proof.json`仅当可读报告不存在或表明其当前证据丢失时。每条路线都有以下结果之一：

| 结果 | 含义 |
|---|---|
| `full` | Guard 使用当前路线拥有的证据完成了路线。 |
| `limited_expected_empty` | Guard 完成了路线，但没有发现合格事件，或记录了指定的成熟度限制。 |
| `missing` | 所需的来源、沿袭检查或配对报告写入未完成。 |

对于丢失的路线，请遵循指定的来源或在报告中写入错误。首先请勿更改不相关的路由或通知设置。

<a id="after-a-crash-or-restart"></a>
## 崩溃或重新启动后

1. 读取服务器状态以获取新的服务器运行时间戳和最新完成的监控周期。
2. 读取 Critical Guard 来了解当前启动或轮询失败。
3. 仅在生命周期后加入、离开或返回的当天会话读取玩家活动更改。
4. 更改配置之前保留引用的源记录。

<a id="before-enabling-optional-adminini-writes"></a>
## 在启用可选Admin.ini写入

默认包监视和报告而不更改`Admin.ini`.高级操作员可以在针对文件副本进行测试后启用可选的强制路径​​。然后，Guard 需要一个干净的数字帐户 ID，保护受信任的帐户，创建并验证备份，拒绝并发更改，读回保存的文件，并在验证失败时恢复备份。 See [`ADMIN_INI_ENFORCEMENT.md`](%E7%AE%A1%E7%90%86%E5%91%98%E5%88%9D%E5%A7%8B%E5%8C%96%E6%89%A7%E8%A1%8C.md) for the complete setup and test procedure.
