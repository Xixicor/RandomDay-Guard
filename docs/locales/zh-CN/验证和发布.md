<a id="validation-and-release"></a>
# 验证和发布

> **规范的英文来源:** [VALIDATION_AND_RELEASE.md](../../VALIDATION_AND_RELEASE.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


此页面适用于贡献者和版本维护者。服务器操作员不需要运行这些命令来安装RandomDayGuard.

<a id="user-visible-proof"></a>
## 用户可见的证明

当新操作员可以安装该版本、找到第一个服务器状态报告、区分五个报告路由并遵循工作示例中的一个明确操作时，该版本是可以理解的。读取器任务不得需要 Git、PowerShell、Python 或校验和知识。

<a id="contributor-checks"></a>
## 贡献者检查

```powershell
python -B tools/validate_repo.py
python -B tools/test_public_pipeline.py
python -B -m unittest discover tests
```

何时`luac`可用：

```powershell
luac -p RandomDayGuard/Scripts/main.lua
luac -p RandomDayGuard/Scripts/public_pipeline.lua
```

Lua 固定装置测试涵盖加载器、调度程序、报告路由和可选Admin.ini写入事务。强制固定装置仅使用临时文件并验证身份、可信帐户拒绝、阈值、备份、并发更改拒绝、读回和回滚。

<a id="package-proof"></a>
## 包证明

```powershell
python -B tools/build_release_zip.py --check
git diff --check
```

- 所有版本标记都匹配。 `VERSION`.
- 只有当前版本存在于`releases/`.
- ZIP 包含规范`RandomDayGuard/Scripts/main.lua` 路径，并且没有小写大小写变体加载程序。
- 运行时输出、私有配置、凭证、本地路径、缓存和测试工件均被排除。
- 公共配置仍仅供审查，禁用强制执行。
- 五个工作报告示例与路由所有权和发布测试装置保持一致。
- ZIP 字节是确定性的且匹配`CHECKSUMS.sha256`.
- 所有本地文档链接和 27 个语言环境条目页面进行验证。

<a id="avoid-validation-environment-pitfalls"></a>
## 避免验证环境陷阱

- 连续运行存储库写入检查以避免临时文件争用。
- 在 Windows 上，检查重复加载程序时检查存档成员名称或枚举路径拼写，而不是不区分大小写的文件查找。
- 缺少`luac`命令或Lua运行时是不可用的功能，而不是通过语法或运行时测试。
- 固定装置仅证明其建模输入。它不能证明实时服务器生成了当前报告。
- 记录命令超时和部分输出，而不是假设完成。

<a id="repair-failed-repository-validation"></a>
## 修复失败的存储库验证

从第一个报告的路径或合约开始。更正该项目，重新运行窄测试，然后重新运行完整的矩阵。不要通过删除需要的测试来隐藏缺失的功能。

<a id="known-limits-and-release-decision"></a>
## 已知限制和发布决策

本地检查证明源、夹具、包和文档合同。特定的服务器安装、长期运行的稳定性窗口或客户端显示需要单独的集成结果。在做出匹配声明之前，记录该结果及其构建、配置、持续时间和观察到的输出。
