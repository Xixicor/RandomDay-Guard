# 术语表

> **规范的英文来源:** [GLOSSARY.md](../../GLOSSARY.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


| 术语 | 简单含义 | 准确技术含义 |
|---|---|---|
| 活动日志 | 用于新证据的当前服务器日志。 | 必需`active_log`来源；路由完成需要可读性和当前沿袭。 |
| 启动 ID | 启动一个看门狗进程。 | 用于拒绝先前启动的当前运行时标识符errors/reports. |
| Epoch ID | 一个服务器连续性间隔。 | 跨越正常运行时间的标识符，直到连续性逻辑开始另一个纪元。 |
| 轮询 ID | 一个有界轮询机会。 | 正单调循环字段； zero/missing无法完成路线。 |
| 源新鲜度 | 当前源和轮询沿袭是否一致。 | `fresh_current_poll` 或 `stale_or_unproven`带有时间戳和活动日志状态。 |
| 源记帐 | 证据可用性和限制清单。 | `randomdayguard.source-accounting/v1`有八个源类别和current/historical范围。 |
| `available` | 已找到并读取源。 | 终端源状态，`available=true`, `readable=true`. |
| `expected_empty` | 已检查可选源且合法absent/empty. | 终端可读源状态；永远不会制造主题。 |
| `partial` | 有界工作有有用但不完整的结果。 | 非终结source/accounting状态；恢复所属工作人员。 |
| `deferred` | 工作有意待定。 | 非终端源状态；不是错误或完成。 |
| `unavailable` | 当前无法使用源。 | 终端间隙；必需的源间隙导致记帐不可用。 |
| `malformed` | 源存在，但结构无效。 | 保留验证详细信息并关闭相关写入的终端间隙。 |
| `permission_denied` | 操作系统明确拒绝访问。 | 终端间隙不同于missing/unavailable. |
| `error` | 有界操作失败出乎意料。 | 终端故障需要指定的恢复；公开报告中没有秘密细节。 |
| `complete` | 所有核算来源都是终端，没有间隙。 | 顶级来源核算状态。 |
| `complete_with_gaps` | 所需的当前证据有效；可选的终端间隙仍然存在。 | 顶级会计状态；路线仍然适用自己的要求。 |
| `full` | 一条路线以其所需的非空合同完成。 | 具有完整当前周期输出的路由证明枚举。 |
| `limited_expected_empty` | 路线已完成，但未发现符合条件的subject/failure. | 路由证明枚举 `completed=true`, `expected_empty=true`. |
| `missing` | 路由完成证明缺失或失败。 | 路由证明枚举 `completed=false`;永远没有资格进入发件箱。 |
| 结构化报告 | 机器可读的路由输出。 | `<route>_latest.json` 使用 `randomdayguard.report/v1`. |
| 翻译后的报告 | 同一路线的人类可读渲染。 | `<route>_latest.txt` 具有固定的 Observed-to-Source-references 顺序。 |
| 路由证明 | 跨路线完成账本。 | `route_proof.json` 绑定 version/boot/epoch/poll/freshness/output 路径。 |
| 当前证据 | 活动周期拥有的观察。 | 范围`current`;不是从旧的重建filenames/reports. |
| 历史证据 | 保留早期周期或慢速扫描的上下文。 | 范围`historical`;可以通知审核，但不能声称当前存在。 |
| 仅供审核 | 无需提供审核证据Admin.ini写入。 | 默认`review_only_mode=true`, `auto_ban=false`, `write_admin_ini=false`. |
| 禁止列表安全检查 | Guard 在更改之前必须回答一个问题`Admin.ini`. | 它必须确认帐户和分数、排除可信帐户和重复帐户、验证备份、检测外部更改、保存预期更新以及验证或安全恢复完整的文件。 |
| 本地发件箱 | 可选的提供商中立通知移交。 | JSON 包含 `delivery_backend="none"` 和 `delivery_attempted=false`. |
| 基线 | 完整的有界保存文件上下文快照的 JSON 文件。 | Manifest/object/world仅在兼容且足够新鲜时重用状态。 |
| 检查点 | 恢复未完成扫描工作的位置。 | `scan_checkpoint.json`；删除不是默认恢复。 |
| 可重建索引 | 可以重新生成的摘要。 | Daily/weekly/forensic/final查看输出；源证据仍然具有权威性。 |
| 证据边界 | 限制源可以支持的内容。 | 显式`does_not_prove`、未知数、身份强度和范围规则。 |

Canonical definitions for schemas are in [`OUTPUT_SCHEMA_REFERENCE.md`](%E8%BE%93%E5%87%BA%E6%9E%B6%E6%9E%84%E5%8F%82%E8%80%83.md); configuration terms are in [`CONFIG_FIELD_CATALOG.md`](%E9%85%8D%E7%BD%AE%E5%AD%97%E6%AE%B5%E7%9B%AE%E5%BD%95.md).
