# RandomDayGuard文档

> **规范的英文来源:** [README.md](../../README.md). 此本地化文档保留了准确的命令、路径、键、状态值、哈希值和文件名。如果技术措辞不同，请使用英文来源。


RandomDayGuard从非生物因子专用服务器读取记录，并将其转换为服务器运行状况、每日历史记录、玩家会话、审核案例和 Guard 故障的单独报告。
