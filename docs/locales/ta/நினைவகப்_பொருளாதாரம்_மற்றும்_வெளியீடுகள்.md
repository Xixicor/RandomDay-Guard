# நினைவக சிக்கனம் மற்றும் வெளியீட்டு கோப்புகள்

> **நியாய ஆங்கில மூல:** [MEMORY_ECONOMY_AND_OUTPUTS.md](../../MEMORY_ECONOMY_AND_OUTPUTS.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


எந்தக் கோப்புகள் வளர்கின்றன, எந்தக் கோப்புகள் மேலெழுதப்படுகின்றன மற்றும் விரைவான மதிப்பாய்விற்கு எதைப் பதிவேற்ற வேண்டும் என்பதை இந்தப் பக்கம் விளக்குகிறது.

<a id="fast-answer"></a>
## வேகமான பதில்

| கேள்வி | திறந்த |
|---|---|
| காவலர் உயிருடன் இருக்கிறாரா? | `runtime/current/poll_status.json` |
| யார் பார்த்தார்கள்? | `runtime/account_evidence.json` |
| அமர்வுகளுக்கு என்ன ஆனது? | `runtime/evidence/session_events.jsonl` |
| இன்று என்ன நடந்தது? | `runtime/forensic_days/YYYY-MM-DD/` |
| வெற்று மொழி சுருக்கம் என்ன? | `runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt` |
| ஸ்கேன் முன்னேற்றம் என்றால் என்ன? | `runtime/scan_progress.json` |
| உலக சூழல் என்றால் என்ன? | `runtime/world_state/current/world_state_latest.json` |
| என்ன தடைகள் எழுதப்பட்டன? | `runtime/enforced_bans.jsonl` |

<a id="output-model"></a>
## வெளியீட்டு மாதிரி

| வகை | நடத்தை | எடுத்துக்காட்டுகள் |
|---|---|---|
| தற்போதைய ஸ்னாப்ஷாட்கள் | மேலெழுதப்பட்டது | `runtime/current/*.json` |
| நிகழ்வு பதிவுகள் | இணைக்க மட்டும் | `runtime/evidence/*.jsonl` |
| அட்டவணைகள் | புதுப்பிக்கப்பட்டது அல்லது இணைக்கப்பட்டது | `*.tsv` |
| அடிப்படைகள் | முடிந்த பிறகு மீண்டும் பயன்படுத்தப்பட்டது | `runtime/baselines/*` |
| தினசரி ரோல்அப்கள் | இடத்தில் புதுப்பிக்கப்பட்டது | `runtime/forensic_days/YYYY-MM-DD/*` |
| இறுதி பதிவுகள் | எளிமையான மொழி தினசரி சுருக்கம் | `runtime/final_logs/YYYY-MM-DD/*` |

<a id="current-snapshots"></a>
## தற்போதைய ஸ்னாப்ஷாட்கள்

இவை சிறியதாக இருக்கும் மற்றும் "இப்போது என்ன உண்மை" என்று பதிலளிக்கும்.

```text
runtime/current/poll_status.json
runtime/current/session_state.json
runtime/current/active_accounts.json
runtime/current/forensic_today.json
runtime/current/forensic_today.md
runtime/current/forensic_today.txt
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/world_state/current/world_state_latest.json
```

<a id="player-summaries"></a>
## பிளேயர் சுருக்கங்கள்

கணக்கு மதிப்பாய்வைச் சரிபார்க்கும் முதல் கோப்புகள் இவை.

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

அவை சுருக்கமாக:

```text
account_id
ban_id
name
identity_confidence
first_seen
last_seen
join_count
leave_count
status
score
```

<a id="event-logs"></a>
## நிகழ்வு பதிவுகள்

இவை காலவரிசையைப் பாதுகாக்கின்றன.

```text
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/warning_events.jsonl
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/evidence/live_defense_events.jsonl
```

<a id="daily-forensic-rollups"></a>
## தினசரி தடயவியல் ரோல்அப்கள்

இவை விரைவான பதிவேற்ற தொகுப்புகள்.

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

விரைவான காலப் பகுப்பாய்வை நீங்கள் விரும்பினால் அந்தக் கோப்புறைகளில் ஒன்றைப் பதிவேற்றவும்.

<a id="scan-and-baseline-files"></a>
## ஸ்கேன் மற்றும் அடிப்படை கோப்புகள்

உலக சூழல் பகுதியா அல்லது முழுமையானதா என்பதைப் புரிந்துகொள்ள இவற்றைப் பயன்படுத்தவும்.

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/scan_complete.json
runtime/object_registry_partial.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
```

<a id="enforcement-files"></a>
## அமலாக்கக் கோப்புகள்

செயல்படுத்துதல் இயக்கப்பட்டிருக்கும் போது மட்டுமே இவற்றைப் பயன்படுத்தவும்.

```text
runtime/enforced.txt
runtime/enforced_bans.jsonl
runtime/ban_queue.json
runtime/evidence/enforced_bans.jsonl
```

`Admin.ini` மட்டுமே பெற வேண்டும்:

```ini
BannedPlayer=<ID>
```
