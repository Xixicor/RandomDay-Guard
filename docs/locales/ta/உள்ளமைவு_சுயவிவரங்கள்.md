# உள்ளமைவு சுயவிவரங்கள்

> **நியாய ஆங்கில மூல:** [CONFIG_PROFILES.md](../../CONFIG_PROFILES.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


நடைமுறை உள்ளமைவு சுயவிவரத்தைத் தேர்ந்தெடுத்துப் பயன்படுத்த, இந்த வழிமுறையைப் பயன்படுத்தவும். குழுக்களை எவ்வாறு அமைப்பது என்பது பற்றிய விளக்கத்திற்கு, [`CONFIG_REFERENCE.md`](%E0%AE%95%E0%AE%9F%E0%AF%8D%E0%AE%9F%E0%AE%AE%E0%AF%88%E0%AE%B5%E0%AF%81_%E0%AE%95%E0%AF%81%E0%AE%B1%E0%AE%BF%E0%AE%AA%E0%AF%8D%E0%AE%AA%E0%AF%81.md). சரியான புலங்கள், இயல்புநிலைகள், வகைகள் மற்றும் மாறுபாடுகளுக்கு, உருவாக்கப்பட்ட [`CONFIG_FIELD_CATALOG.md`](%E0%AE%95%E0%AE%9F%E0%AF%8D%E0%AE%9F%E0%AE%AE%E0%AF%88%E0%AE%AA%E0%AF%8D%E0%AE%AA%E0%AF%81_%E0%AE%AA%E0%AF%81%E0%AE%B2_%E0%AE%AA%E0%AE%9F%E0%AF%8D%E0%AE%9F%E0%AE%BF%E0%AE%AF%E0%AE%B2%E0%AF%8D.md).

கீழே உள்ள ஒவ்வொரு லுவா தொகுதியும், அனுப்பப்பட்டவற்றிற்குள் பொருந்தும் உள்ளீடுகளை மாற்றக்கூடிய உயர்மட்ட உள்ளீடுகளின் தொகுப்பாகும் `return { ... }` அட்டவணை.

<a id="profile-chooser"></a>
## சுயவிவரத் தேர்வி

| சூழ்நிலை | இந்தச் சுயவிவரத்தைப் பயன்படுத்தவும் |
|---|---|
| முதல் நிறுவல் | பாதுகாப்பான முதல் நிறுவல் |
| சேவையகம் நிலையற்றது மற்றும் அடிக்கடி செயலிழக்கிறது | மெதுவான ஸ்கேன் இல்லாத தற்போதைய ஆதாரம் |
| உங்களுக்கு வேண்டும் object/world சூழல் | முழு அடிப்படை |
| நீங்கள் பழைய பதிவுகளை மதிப்பாய்வு செய்ய விரும்புகிறீர்கள் | தடயவியல் பின் நிரப்புதல் |
| உங்களுக்கு பரிந்துரைகள் தேவை, ஆனால் எழுதுவது இல்லை | அமலாக்க சோதனை |
| பாதுகாவலர் தடைகளை எழுத அனுமதிக்க நீங்கள் தயாராக உள்ளீர்கள் | அமலாக்கம் இயக்கப்பட்டது |
| வட்டு வரையறுக்கப்பட்டுள்ளது | குறைந்த வட்டு வளர்ச்சி |
| ஒரு சுத்தமான அடிப்படையை முடித்துவிட்டீர்கள் | ஸ்டிக்கி காப்பு அமைப்பு |

<a id="safe-first-install"></a>
## பாதுகாப்பான முதல் நிறுவல்

இதை முதலில் லைவ் சர்வரில் பயன்படுத்தவும்.

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

log_tail = {
    enabled = true,
    start_at_end_on_first_run = true,
    tail_backup_logs = false,
},

scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

இது என்ன செய்கிறது:

```text
Tracks live sessions.
Starts the baseline scan.
Does not edit Admin.ini.
Avoids treating old backup logs as fresh live events.
```

<a id="current-evidence-without-slow-scan"></a>
## மெதுவான ஸ்கேன் இல்லாத தற்போதைய ஆதாரம்

சேவையகம் நிலையற்றதாக இருந்தால் இதைப் பயன்படுத்தவும், உங்களுக்குத் தேவை crash/reconnect கனமான ஸ்கேன்க்கு முன் சான்று.

```lua
log_tail = {
    enabled = true,
},

scanning = {
    full_scan_on_start = false,
},

enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

இது என்ன செய்கிறது:

```text
Tracks logins, joins, leaves, reconnects, crashes, and unclean sessions.
Delays heavy world scanning.
```

<a id="full-baseline"></a>
## முழு அடிப்படை

ஸ்கேன் செய்வதற்கு சேவையகம் நீண்ட நேரம் செயல்பட்ட பிறகு இதைப் பயன்படுத்தவும்.

```lua
scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},
```

இது என்ன செய்கிறது:

```text
Builds object registry.
Writes world-state context.
Creates file manifest.
Enables changed-file refresh later.
```

<a id="forensic-backfill"></a>
## தடயவியல் பின் நிரப்புதல்

வரலாற்றுப் பதிவுகளை வேண்டுமென்றே மதிப்பாய்வு செய்யும் போது மட்டும் இதைப் பயன்படுத்தவும்.

```lua
log_tail = {
    start_at_end_on_first_run = false,
    tail_backup_logs = true,
    backfill_backup_logs_on_start = true,
},
```

பயன்படுத்தும் முன்:

```text
Back up runtime/log_offsets.tsv.
Expect old events to be reprocessed.
Return to live settings when finished.
```

<a id="enforcement-testing"></a>
## அமலாக்க சோதனை

உண்மைக்கு முன் இதைப் பயன்படுத்தவும் Admin.ini எழுத்து.

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},
```

என்ன ஆய்வு செய்ய வேண்டும்:

```text
runtime/account_evidence.json
runtime/warnings/
runtime/forensic_days/YYYY-MM-DD/ban_recommendations.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="enforcement-enabled"></a>
## அமலாக்கம் இயக்கப்பட்டது

மதிப்பாய்வு வெளியீடு சரியாக இருந்தால் மட்டுமே இதைப் பயன்படுத்தவும்.

```lua
enforcement = {
    review_only_mode = false,
    auto_ban = true,
    write_admin_ini = true,
    require_clean_ban_id = true,
    preserve_existing_bans = true,
    preserve_moderators = true,
},
```

இயக்குவதற்கு முன்:

```text
Trusted IDs are configured.
Moderator IDs are preserved.
Admin.ini backups work.
Ban recommendations are understandable.
Thresholds are accepted by the server owner.
```

<a id="low-disk-growth"></a>
## குறைந்த வட்டு வளர்ச்சி

இயக்க நேரக் கோப்புகள் மிக விரைவாக வளரும்போது இதைப் பயன்படுத்தவும்.

```lua
logging = {
    low_importance_mode = "aggregate",
    write_low_importance_raw_events = false,
},

retention = {
    detailed_retention_days = 7,
    rotate_jsonl_when_bytes_exceed = 5242880,
    max_raw_events_lines = 20000,
    compact_json_outputs = true,
},
```

<a id="sticky-backup-setup"></a>
## ஸ்டிக்கி காப்பு அமைப்பு

முதலில் பூர்த்தி செய்யப்பட்ட அடிப்படைக்கு பிறகு பயன்படுத்தவும்.

இவை உள்ளதா எனச் சரிபார்க்கவும்:

```text
runtime/scan_complete.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
runtime/world_state/current/world_state_latest.json
```

பின்னர் அவற்றை `config.lua`, `SavedRoot.txt`, மற்றும் `Admin.ini`.
