# வேலை செய்யப்பட்ட செயல்பாட்டு எடுத்துக்காட்டுகள்

> **நியாய ஆங்கில மூல:** [EXAMPLE_RUNS.md](../../EXAMPLE_RUNS.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


எதிர்பார்க்கப்பட்ட நிலை மாற்றங்களை விளக்க இந்த எடுத்துக்காட்டுகள் கண்டுபிடிக்கப்பட்ட மதிப்புகளைப் பயன்படுத்துகின்றன; அவை நேரடி இணக்கத்தன்மை அல்லது பிளேயர் சான்றுகள் அல்ல.

<a id="successful-current-cycle"></a>
## வெற்றிகரமான தற்போதைய சுழற்சி

உள்ளீடுகள்: படிக்கக்கூடிய செயலில் உள்ள பதிவு, version/boot/epoch, `poll_id=41`, தற்போதைய வாக்கெடுப்பு முடிந்தது, எழுதக்கூடியது accounting/history/report வேர்கள், மெதுவான ஸ்கேன் கொள்கையைத் தடுப்பது இல்லை.

எதிர்பார்க்கப்பட்டது:

```text
server_status = full
player_activity = full or limited_expected_empty
case_review = full or limited_expected_empty
daily_rollup = full or limited_expected_empty
critical_guard = full or limited_expected_empty
```

ஒவ்வொரு இயக்கப்பட்ட வழியிலும் உள்ளது JSON/TXT வெளியீடு மற்றும் `route_proof.json`. பாதை நிலை அதன் சொந்த பாடங்களைப் பொறுத்தது, பொதுவான வெற்றிச் செய்தியில் அல்ல.

<a id="expected-empty-player-and-case-routes"></a>
## எதிர்பார்க்கப்படும்-வெற்று பிளேயர் மற்றும் கேஸ் வழிகள்

உள்ளீடுகள்: தற்போதைய சுழற்சி ஆதாரம் முடிந்தது; தற்போதைய அல்லது தக்கவைக்கப்பட்ட வீரர் வரிசைகள் இல்லை; தக்கவைக்கப்பட்ட வழக்கு மற்றும் தற்போதைய REVIEW/BAN-ELIGIBLE கணக்கு.

எதிர்பார்க்கப்பட்டது:

```text
player_activity.route_proof_status = limited_expected_empty
player_activity.expected_empty = true
player_activity.players = []

case_review.route_proof_status = limited_expected_empty
case_review.expected_empty = true
case_review.cases = []
```

தகுதியான வரம்புக்குட்பட்ட பொருள் எதுவும் காணப்படவில்லை என்று மொழிபெயர்க்கப்பட்ட அறிக்கைகள் கூறுகின்றன. யாரும் இதுவரை இணைக்கப்படவில்லை அல்லது எந்த சூழலையும் காணவில்லை என்பதை இது நிரூபிக்கவில்லை என்றும் அவர்கள் கூறுகிறார்கள். ஒதுக்கிடமில்லை player/case உருவாக்கப்பட்டது.

<a id="partial-bounded-scan"></a>
## பகுதி எல்லை ஸ்கேன்

உள்ளீடுகள்: புதிய மின்னோட்டம் log/poll; `scan_checkpoint.json` அல்லது `scan_progress.json` உள்ளது; ஸ்கேன் முழுமையடையவில்லை; இயல்புநிலை `slow_world_scan_blocks_current_reports=false`.

எதிர்பார்க்கப்பட்டது:

```text
world_save_scan.status = partial
source accounting = partial
server_status may still be full for fresh current state
historical routes name the scan limitation
```

அமைவு `slow_world_scan_blocks_current_reports=true` தற்போதைய அறிக்கைகளைத் தடுக்க, விருப்பமான மெதுவான மூலத்தை இயக்குபவர் விரும்பினால் மட்டுமே. மீட்பு என்பது ஸ்கேன் பணியாளரை மீண்டும் தொடங்க அனுமதிப்பதே தவிர, சோதனைச் சாவடியை நீக்குவதற்காக அல்ல.

<a id="missing-current-cycle-proof"></a>
## தற்போதைய சுழற்சி ஆதாரம் இல்லை

உள்ளீடுகள்: செயலில் உள்ள பதிவு கிடைக்கவில்லை, `poll_id=0`, அல்லது boot/epoch/last-poll பரம்பரை இல்லை.

எதிர்பார்க்கப்பட்டது:

```text
current_cycle_proof_complete = false
all route proof statuses = missing
each configured route envelope status = suppressed_current_cycle
delivery_eligible = false
delivery_attempted = false
```

அடக்கப்பட்ட உறை ஒரு தணிக்கைப் பதிவாகும், வரிசைப்படுத்தப்பட்ட டெலிவரி அல்ல. பழைய இறுதிப் பதிவுகள் வரலாற்றுப் பதிவுகள் மட்டுமே. முதலில் விடுபட்டதை lineage/source புலம் மற்றும் புதிய சுழற்சியை உருவாக்கவும்.

<a id="malformed-optional-adminini-source"></a>
## தவறான விருப்பத்தேர்வு Admin.ini ஆதாரம்

உள்ளீடுகள்: `Admin.ini` உள்ளது ஆனால் சுத்தமான கட்டமைப்பு சரிபார்ப்பில் தோல்வியுற்றது.

எதிர்பார்க்கப்பட்டது:

```text
admin_ini.status = malformed
source reference preserved
write/enforcement path closed
```

கோப்பைப் பாதுகாத்து, மதிப்பாய்வு செய்யப்பட்ட சுத்தமான வடிவமைப்பை மீட்டெடுக்கவும். இயக்க நேர ஆதாரத்தில் விளக்க உரையை வைத்திருங்கள்; ஒவ்வொன்றும் `Admin.ini` தடை நுழைவு மட்டுமே உள்ளது `BannedPlayer=<ID>`.

<a id="required-active-log-probe-error"></a>
## தேவையான Active-log probe பிழை

உள்ளீடுகள்: சுத்திகரிக்கப்பட்ட வாசிப்புப் பிழையால் கட்டுப்படுத்தப்பட்ட தேவையான செயலில்-பதிவு ஆய்வு தோல்வியடைகிறது.

எதிர்பார்க்கப்பட்டது:

```text
source_accounting.sources[active_log].status = error
source_accounting.sources[active_log].detail = "bounded active-log probe failed: <sanitized reason>"
coverage_status = unavailable
all route proof statuses = missing
```

`error` அதன் வரம்புக்குட்பட்ட விவரத்துடன் மூல வரிசையில் உள்ளது. உயர்மட்ட அறிக்கை `unavailable`, மற்றும் பாதை ஆதாரம் உள்ளது `missing` ஒரு புதிய தற்போதைய சுழற்சி தேவையான மூலத்தை நிரூபிக்கும் வரை.

<a id="incompatible-or-stale-baseline"></a>
## பொருத்தமற்ற அல்லது பழமையான அடிப்படை

உள்ளீடுகள்: மாற்றப்பட்டது package/source அடையாளம் அல்லது stale/incompatible அடிப்படை மேனிஃபெஸ்ட்.

எதிர்பார்க்கப்பட்டது: சரிபார்ப்பு அல்லது இயக்க நேர நிலை இணக்கமின்மையை பதிவு செய்கிறது; ஸ்கேன் நிலை முடிக்கப்பட்ட மறுபயன்பாட்டைக் கோரவில்லை. முன் சான்றுகளை பாதுகாத்து, ஒரு வெளிப்படையான அடிப்படை மறுகட்டமைப்பைத் தொடங்கவும், மேலும் புதிய முனைய ஆதாரத்திற்காக காத்திருக்கவும். பதிவுசெய்யப்பட்ட காரணமின்றி கட்டாயமாக மீண்டும் கட்டுவது இயல்புநிலை மீட்டெடுப்பு அல்ல.

<a id="paired-report-write-failure"></a>
## இணைக்கப்பட்ட அறிக்கை எழுதுவதில் தோல்வி

உள்ளீடுகள்: JSON எழுதுவது வெற்றியளிக்கிறது ஆனால் TXT எழுதுதல் தோல்வி, அல்லது தலைகீழ்.

எதிர்பார்க்கப்பட்டது:

```text
route_proof_status = missing
completed = false
coverage_status = unavailable
output_write_detail = "paired JSON/TXT write failed: <sanitized reason>"
next_action = repair both route output writes
```

எழுத்தாளர் பெஸ்ட்-எஃபர்ட் தோல்வியை சந்திக்க இரு உடன்பிறப்புகளையும் மீண்டும் எழுதுகிறார். ஒரு வெற்றிகரமான உடன்பிறந்தவர் வெற்றிக் கோரிக்கையாக இருக்க முடியாது. வரம்புக்குட்பட்ட எழுதும் விவரம் ஐந்தாவது உயர்மட்ட கவரேஜ் மதிப்பை உருவாக்காது.

<a id="route-proof-write-failure"></a>
## பாதை-சான்று எழுதுவதில் தோல்வி

உள்ளீடுகள்: பாதை ஜோடிகள் எழுதப்பட்டன ஆனால் `route_proof.json`ஐ மாற்ற முடியாது.

எதிர்பார்க்கப்பட்டது: அனைத்து அறிக்கைகளும் மீண்டும் எழுதப்பட்டன `missing`, அனைத்து அறிவிப்பு விளைவுகளும் `route_proof_write_failed`, மற்றும் எந்த உறையும் ஏற்கப்படவில்லை. உள்ளமைக்கப்பட்ட பாதையில் `suppressed_current_cycle` தணிக்கை உறை தவறானது. வெளியீட்டு மூலத்தை சரிசெய்து அதே தற்போதைய சுழற்சியை மீண்டும் உருவாக்கவும்.

<a id="review-only-enforcement-example"></a>
## மதிப்பாய்வு மட்டும் அமலாக்க உதாரணம்

கட்டமைப்பு:

```lua
review_only_mode = true
auto_ban = false
write_admin_ini = false
```

எதிர்பார்க்கப்பட்டது: மதிப்பெண்கள், வழக்குகள் மற்றும் பரிந்துரைகள் எழுதப்படலாம்; `Admin.ini` மாறாமல் உள்ளது. இது பொது இயல்புநிலை.

<a id="approved-write-success-example"></a>
## அங்கீகரிக்கப்பட்ட எழுதப்பட்ட வெற்றி உதாரணம்

தனியாக அங்கீகரிக்கப்பட்ட சோதனை மட்டுமே மூன்று எழுதும் சுவிட்சுகளையும் அமைக்கலாம். இது சுத்தமான எண் அடையாளத்தையும் நிரூபிக்க வேண்டும், trust/moderator விலக்கு, வரம்பு தகுதி, செல்லுபடியாகும் Admin.ini path/parse, காப்புப் பிரதி வெற்றி, எழுதுதல் வெற்றி, வாசிப்பு சமத்துவம் மற்றும் கணக்கு சார்ந்த சான்றுகள்.

எதிர்பார்க்கப்பட்டது:

```text
runtime/backups/Admin_<timestamp>_<source-fingerprint>_<clean-ID>.ini
Admin.ini contains one clean BannedPlayer=<ID>
runtime/enforced_bans.jsonl and evidence mirror record success
```

வெற்றிகரமான உதாரணம் பிற கணக்குகளுக்கான தானியங்கு அமலாக்கத்தை இயக்காது.

<a id="writereadback-failure-with-rollback"></a>
## Write/readback திரும்பப் பெறுவதில் தோல்வி

உள்ளீடுகள்: ஒவ்வொரு முன் எழுதும் வாயிலும் கடந்து சென்றது; மாற்று எழுதுதல் அல்லது திரும்பப் பெறுதல் தோல்வி; `rollback_on_readback_failure=true` மற்றும் சரிபார்க்கப்பட்ட காப்புப்பிரதி கிடைக்கிறது.

எதிர்பார்க்கப்பட்டது: தோல்வி சான்றுகள் நிலை மற்றும் `rollback_success`; அசல் Admin.ini பைட்டுகள் மீட்டமைக்கப்பட்டன மற்றும் கணக்கு வெற்றிகரமாக செயல்படுத்தப்பட்டதாக தெரிவிக்கப்படவில்லை. திரும்பப் பெறுதல் தோல்வியுற்றால், எழுதுவதை நிறுத்தி, இரண்டையும் பாதுகாக்கவும் files/evidence, மற்றும் காப்புப்பிரதியிலிருந்து கைமுறையாக மீட்டெடுக்கவும்.

<a id="local-outbox-example"></a>
## உள்ளூர் அவுட்பாக்ஸ் உதாரணம்

உள்ளீடுகள்: `local_file_outbox` பயன்முறை, வழி இயக்கப்பட்டது, முடிக்கப்பட்ட வழி ஆதாரம் மற்றும் `full` அல்லது வெளிப்படையாக அனுமதிக்கப்பட்ட எதிர்பார்க்கப்படுகிறது-வெறுமை.

எதிர்பார்க்கப்படும் உறை:

```text
schema = randomdayguard.notification/v1
completed_output = true
status = ready_for_local_consumer
delivery_eligible = true
delivery_backend = none
delivery_attempted = false
```

க்கு missing/ineligible வெளியீடு, அதே பாதையில் `status=suppressed_current_cycle`, `completed_output=false`, மற்றும் `delivery_eligible=false`. எந்த கோப்பும் உள்ளூர் எழுத்தை மட்டுமே நிரூபிக்கும். வழங்குநர், போக்குவரத்து, விநியோகம் அல்லது வாசிப்பு ரசீது தொகுக்கப்படவில்லை அல்லது ஊகிக்கப்படவில்லை.
