# பங்களிப்பு

> **நியாய ஆங்கில மூல:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


RandomDayGuard பாகுபடுத்திகள், ஆவணப்படுத்தல், சோதனைகள் மற்றும் பொது-பாதுகாப்பான சரிபார்ப்பு ஆகியவற்றில் கவனம் செலுத்தும், மீண்டும் உருவாக்கக்கூடிய மேம்பாடுகளை ஏற்றுக்கொள்கிறது. ஒவ்வொரு மாற்றத்தையும் பொதுத் திட்ட ஒப்பந்தத்திற்குக் கட்டுப்பட்டு, மறுஆய்வு-முதல் நடத்தையைப் பாதுகாக்கவும்: காவலர் வெளியேற வேண்டும் `Admin.ini` தேவையான பாதுகாப்புச் சரிபார்ப்பை உறுதிப்படுத்த முடியாதபோது மாறாது.

<a id="prepare-a-safe-workspace"></a>
## பாதுகாப்பான பணியிடத்தைத் தயாரிக்கவும்

1. தொகுப்பை முறுக்கு அல்லது குளோன் செய்து, மையப்படுத்தப்பட்ட கிளையை உருவாக்கவும்.
2. ஆதரிக்கப்படும் Python 3 மொழிபெயர்ப்பாளரை நிறுவவும். Lua so `luac -p` தொடரியல் சரிபார்க்க முடியும்.
3. ஐப் படிக்கவும் [ஆவண முகப்பு](%E0%AE%86%E0%AE%B5%E0%AE%A3%E0%AE%AE%E0%AF%8D.md), [கட்டமைப்பு](%E0%AE%95%E0%AE%9F%E0%AF%8D%E0%AE%9F%E0%AE%BF%E0%AE%9F%E0%AE%95%E0%AF%8D%E0%AE%95%E0%AE%B2%E0%AF%88.md), மற்றும் [சான்று எல்லை](%E0%AE%9A%E0%AE%BE%E0%AE%A9%E0%AF%8D%E0%AE%B1%E0%AF%81_%E0%AE%8E%E0%AE%B2%E0%AF%8D%E0%AE%B2%E0%AF%88.md).
4. ஆய்வு செய் `git status`ஐத் திருத்துவதற்கு முன் மற்றும் தொடர்பில்லாத வேலையைப் பாதுகாக்கவும்.
5. செயற்கை அல்லது சுத்திகரிக்கப்பட்ட சாதனங்களை மட்டும் பயன்படுத்தவும்.

தனிப்பட்ட சர்வர் பதிவுகள், சேமிக்கப்பட்ட கோப்புறைகள், பிளேயர் அடையாளங்காட்டிகள், `Admin.ini`, தனிப்பட்ட அறிவிப்பு இறுதிப்புள்ளிகள், நற்சான்றிதழ்கள், தனிப்பட்ட பாதைகள், இயக்க நேர வெளியீடு அல்லது நகலெடுக்கப்பட்ட நேரடி சான்றுகள்.

<a id="make-a-focused-change"></a>
## ஒருமுகப்படுத்தப்பட்ட மாற்றத்தை உருவாக்கவும்

- ஏற்கனவே பெயரிடுதல், வடிவமைத்தல், பாதுகாப்பு சோதனைகள் மற்றும் தொகுதி உரிமையைப் பின்பற்றவும்.
- ஒவ்வொரு நடைமுறைக்கும் அல்லது சரியான உண்மைக்கும் ஒரு நியமன ஆவண உரிமையாளரை வைத்திருங்கள்.
- நடத்தை அல்லது பொது வெளியீடு மாறும்போது பயனர் ஆவணங்கள் மற்றும் எடுத்துக்காட்டுகளைப் புதுப்பிக்கவும்.
- நடைமுறையில் பிழைத்திருத்தத்திற்கான பின்னடைவு சோதனையைச் சேர்க்கவும்.
- கணக்கு உறுதிப்படுத்தல், நம்பகமான கணக்குப் பாதுகாப்பு, காப்புப் பிரதிச் சரிபார்ப்பு, வெளிப்புற மாற்றத்தைக் கண்டறிதல், சேமிக்கப்பட்ட கோப்பு ஒப்பீடு, மீட்டெடுப்பு அல்லது மதிப்பாய்வு மட்டும் இயல்புநிலை ஆகியவற்றைச் சோதனையில் தேர்ச்சி பெறச் செய்ய வேண்டாம்.

<a id="run-the-relevant-checks"></a>
## தொடர்புடைய காசோலைகளை இயக்கவும்

ஆவணங்கள் மட்டுமே மாற்றங்களுக்கு, இயக்கவும்:

```powershell
python -B tools\generate_documentation_audit.py --check
python -B -m unittest discover tests -p "test_documentation*.py"
git diff --check
```

மூலம், உள்ளமைவு, பேக்கேஜிங் அல்லது சோதனை மாற்றங்களுக்கு, [சரிபார்ப்பு மற்றும் வெளியீட்டு மதிப்பாய்வு](%E0%AE%9A%E0%AE%B0%E0%AE%BF%E0%AE%AA%E0%AE%BE%E0%AE%B0%E0%AF%8D%E0%AE%AA%E0%AF%8D%E0%AE%AA%E0%AF%81_%E0%AE%AE%E0%AE%B1%E0%AF%8D%E0%AE%B1%E0%AF%81%E0%AE%AE%E0%AF%8D_%E0%AE%B5%E0%AF%86%E0%AE%B3%E0%AE%BF%E0%AE%AF%E0%AF%80%E0%AE%9F%E0%AF%81.md), Lua தொடரியல் சோதனைகள், களஞ்சிய சரிபார்ப்பு, பொது-பைப்லைன் சோதனைகள் மற்றும் முழு அலகு-சோதனை தொகுப்பு உட்பட. தவிர்க்கப்பட்ட அல்லது கிடைக்காத ஒவ்வொரு காசோலையையும் புகாரளிக்கவும்; கடந்துவிட்டதாக விவரிக்க வேண்டாம்.

<a id="submit-the-change-for-review"></a>
## மாற்றத்தை மதிப்பாய்வுக்கு சமர்ப்பிக்கவும்

முழுமையான வேறுபாட்டை மதிப்பாய்வு செய்த பின்னரே ஃபோகஸ்டு புல் கோரிக்கையைத் திறக்கவும். அடங்கும்:

- சிக்கல் மற்றும் நோக்கம் கொண்ட நடத்தை;
- சரியான கோப்புகள் மற்றும் பொது ஒப்பந்தங்கள் மாற்றப்பட்டன;
- கட்டளைகள் இயங்குகின்றன மற்றும் அவற்றின் முடிவுகள்;
- தனியுரிமை, இணக்கத்தன்மை மற்றும் அமலாக்க தாக்கம்; மற்றும்
- மீதமுள்ள வரம்புகள் அல்லது பின்தொடர்தல் வேலை.

உருவாக்கப்பட்ட இயக்க நேரச் சான்றுகளைச் சேர்க்க வேண்டாம் அல்லது காப்பகங்களை வெளியிட வேண்டாம். மூன்றாம் தரப்பு தளத்தில் வெளியீடு, வரிசைப்படுத்தல், லைவ்-சர்வர் சோதனை, அமலாக்க நடவடிக்கை அல்லது வெளியீட்டை பங்களிப்பு அங்கீகரிக்காது.

பாதிப்புகளை [தனிப்பட்ட பாதுகாப்பு வழி](%E0%AE%AA%E0%AE%BE%E0%AE%A4%E0%AF%81%E0%AE%95%E0%AE%BE%E0%AE%AA%E0%AF%8D%E0%AE%AA%E0%AF%81.md), பொதுச் சிக்கல் அல்லது சாதாரண இழுப்புக் கோரிக்கை அல்ல.
