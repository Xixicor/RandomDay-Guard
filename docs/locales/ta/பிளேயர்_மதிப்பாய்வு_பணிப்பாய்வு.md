# பிளேயர் மதிப்பாய்வு பணிப்பாய்வு

> **நியாய ஆங்கில மூல:** [PLAYER_REVIEW_WORKFLOW.md](../../PLAYER_REVIEW_WORKFLOW.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


ஒரு பிளேயர், கணக்கு அல்லது கேஸுக்கு இந்தப் பக்கத்தைப் பயன்படுத்தவும். மறுஆய்வு முடிவுதான் நோக்கம், தானியங்கு குற்றச்சாட்டு அல்ல.

<a id="quick-path"></a>
## விரைவு பாதை

1. திற `runtime/final_logs/player_activity_latest.json`.
2. வழியின் நிலையை `runtime/final_logs/route_proof.json`.
3. எந்த அவதானிப்புகள் தற்போதையவை மற்றும் எவை வரலாற்று ரீதியானவை என்பதைக் கண்டறியவும்.
4. மேற்கோள் காட்டப்பட்ட அடையாளம் மற்றும் அமர்வு மூலக் குறிப்புகளைச் சரிபார்க்கவும்.
5. மதிப்பாய்வு `case_review_latest.json` தொடர்புடைய வழக்கு இருக்கும் போது.
6. தெரியாதவற்றைப் பதிவுசெய்தல் மற்றும் `does_not_prove` ஒரு செயலைத் தேர்ந்தெடுப்பதற்கு முன்.
7. தனியான அமலாக்க வாயில்கள் நிரூபிக்கப்படும் வரை அமலாக்கத்தை முடக்கி விடவும்.

<a id="1-confirm-route-proof"></a>
## 1. பாதை ஆதாரத்தை உறுதிப்படுத்தவும்

பிளேயர் வழியை இவ்வாறு விளக்கவும்:

| நிலை | செயல் |
|---|---|
| `full` | மூல வரம்புகளை மதிப்பாய்வு செய்யும் போது தொடரவும். |
| `limited_expected_empty` | உண்மையில் உள்ள பாடங்களுடன் மட்டும் தொடரவும்; காணாமல் போன பிளேயர் அல்லது கேஸைக் கண்டுபிடிக்க வேண்டாம். |
| `missing` | பிளேயர் முடிவை நிறுத்தி, வழியை சரிசெய்யவும். |

ஆரோக்கியமான திட்டமிடுபவர் பாதை ஆதாரத்தை மாற்றாது.

<a id="2-establish-identity"></a>
## 2. அடையாளத்தை நிறுவவும்

சர்வர்-வெளிப்படுத்தப்பட்ட அடையாளச் சான்றுகள் மற்றும் கிடைக்கும் இடங்களில், PlayerData கோப்பு பெயர்கள். மூல ஆதாரக் குறிப்பை வைத்திருங்கள்.

இதிலிருந்து செயல்படுத்த வேண்டாம்:

- ஒரு காட்சி பெயர் மட்டும்;
- ஒரு அறிவிப்பு அல்லது ஹோஸ்டிங் பேனலில் காணப்பட்ட பெயர்;
- நேர ஒற்றுமை;
- மேப் செய்யப்படாத அல்லது பலவீனமான நம்பிக்கை அடையாளம்;
- தற்போதைய உறுதிப்படுத்தல் இல்லாத ஒரு வரலாற்று அறிக்கை.

<a id="3-separate-current-from-historical"></a>
## 3. வரலாற்றிலிருந்து மின்னோட்டத்தைப் பிரிக்கவும்

தற்போதைய சான்றுகள் செயலில் உள்ள அறிக்கையிடல் சாளரம் அல்லது சர்வர் சகாப்தத்தை விவரிக்கிறது. வரலாற்றுச் சான்றுகள் ஒரு வடிவத்தை விளக்கலாம், ஆனால் அது தற்போதைய சாளரத்தில் உள்ள இடைவெளிகளை அமைதியாக நிரப்ப முடியாது.

இரண்டு நோக்கங்களையும் தனித்தனியாகப் பதிவுசெய்க:

```text
Current observations:
Current source references:
Historical context:
Historical source references:
```

<a id="4-review-observations-and-interpretation"></a>
## 4. அவதானிப்புகள் மற்றும் விளக்கங்களை மதிப்பாய்வு செய்யவும்

இந்த அறிக்கைப் பிரிவுகளைத் தெளிவாகப் படிக்கவும்:

```text
observed
interpretation
unknown
does_not_prove
next_action
source_references
```

எந்தவொரு பொருள் முடிவிற்கும் மேற்கோள் காட்டப்பட்ட கட்டமைக்கப்பட்ட ஆதாரத்தை மீண்டும் திறக்கவும். ஒரு மொழிபெயர்ப்பு என்பது வழிசெலுத்தல் மற்றும் விளக்கம், புதிய ஆதாரம் அல்ல.

<a id="5-calibrate-the-decision"></a>
## 5. முடிவை அளவீடு செய்யவும்

| முடிவு | எப்போது பயன்படுத்தவும் |
|---|---|
| `INFO` | சாதாரண அல்லது குறைந்த சூழல் அவதானிப்பு. |
| `WATCH` | கண்காணிக்க வேண்டிய பலவீனமான அல்லது முழுமையற்ற சமிக்ஞை. |
| `REVIEW` | தொடர்புடைய சான்றுகளுக்கு நிர்வாகி தீர்ப்பு தேவை. |
| `BAN-ELIGIBLE` | சுத்தமான அடையாளம் மற்றும் உள்ளமைக்கப்பட்ட சான்று வரம்புகள் பூர்த்தி செய்யப்படுகின்றன; எழுத்து வாயில்கள் இன்னும் பொருந்தும். |
| `AUTO-BANNED` | அமலாக்கம் வெளிப்படையாக இயக்கப்பட்டது மற்றும் காப்புப்பிரதி, எழுதுதல், வாசிப்பு மற்றும் தணிக்கை அனைத்தும் வெற்றியடைந்தன. |

எந்த முடிவு லேபிளும் குற்றத்தையோ நோக்கத்தையோ நிரூபிக்கவில்லை.

<a id="6-apply-the-evidence-boundary"></a>
## 6. ஆதார எல்லையைப் பயன்படுத்தவும்

சிதைவுகள், மீண்டும் இணைதல், எச்சரிக்கைகள், object/class டோக்கன்கள் மற்றும் கேஸ் குழுவாக்கம் மதிப்பாய்வை ஆதரிக்கும். தனியாக, அவர்கள் ஏமாற்றுதல், திருட்டு, நகல், உரிமை, நேரடி சேதம் அல்லது சம்பவ காரணத்தை நிரூபிக்கவில்லை.

அடையாளம், பாகுபடுத்துதல், காப்புப்பிரதி, எழுதுதல், மறுபரிசீலனை செய்தல் அல்லது திரும்பப்பெறுதல் பலவீனமாக இருந்தால் அல்லது தோல்வியடைந்தால், அமலாக்கம் மூடப்பட வேண்டும்.
