# நிறுவு RandomDayGuard

> **நியாய ஆங்கில மூல:** [INSTALL.md](../../../INSTALL.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


இந்த வழிகாட்டி நிறுவுகிறது `v0.4.12-alpha` ஏற்கனவே பயன்படுத்தும் Abiotic Factor அர்ப்பணிக்கப்பட்ட சர்வரில் UE4SS. மோட் ஒரு ஹோஸ்டிங் நிறுவனம் அல்லது கட்டுப்பாட்டுப் பலகத்துடன் இணைக்கப்படவில்லை.

<a id="before-you-begin"></a>
## தொடங்கும் முன்

உங்களுக்குத் தேவை:

- பிரத்யேக சேவையகத்தை நிறுத்தி தொடங்குவதற்கான அணுகல்;
- சேவையகத்தின் UE4SS `Mods` கோப்புறை;
- தற்போதைய நகல் RandomDayGuard கோப்புறை;
- மோட்டை மாற்றும் முன் நீங்கள் வழக்கமாகப் பாதுகாக்கும் சர்வர் தரவின் காப்புப்பிரதி.

தி **Mods கோப்புறை** என்பது `ue4ss/Mods/` டெடிகேட்டட்-சர்வர் நிறுவலின் உள்ளே அடைவு. RandomDayGuard நேரடியாக அந்தக் கோப்புறைக்குள் உள்ளது.

<a id="new-installation"></a>
## புதிய நிறுவல்

1. பிரத்யேக சேவையகத்தை நிறுத்தவும்.
2. இதை பிரித்தெடுக்கவும் RandomDayGuard ZIP ஒரு புதிய வெற்று கோப்புறையில்.
3. பிரித்தெடுத்ததை நகலெடுக்கவும் `RandomDayGuard` கோப்புறை UE4SS `Mods` கோப்புறை. முடிவு ஒன்று `Mods/RandomDayGuard/` கோப்புறை, ஒரு நொடி அல்ல RandomDayGuard கோப்புறை அதன் உள்ளே உள்ளது.
4. திற UE4SS `mods.txt` மற்றும் இயக்கு:

   ```text
   RandomDayGuard : 1
   ```

5. சேவையகத்தை சாதாரணமாகத் தொடங்கவும்.
6. காத்திருங்கள் UE4SS மற்றும் கேம் சர்வர் தொடங்கி முடிக்க, பின் [முதல் அறிக்கையைப் படிக்கவும்](%E0%AE%87%E0%AE%99%E0%AF%8D%E0%AE%95%E0%AF%87_%E0%AE%A4%E0%AF%8A%E0%AE%9F%E0%AE%99%E0%AF%8D%E0%AE%95%E0%AF%81.md).

இயங்கும் நிறுவலில் புதிய வெளியீட்டை நகலெடுக்க வேண்டாம். புதுப்பிக்கப்பட்ட நிறுவல் தற்போதைய சர்வர்-நிலை அறிக்கையை உருவாக்கும் வரை காப்புப்பிரதியை வைத்திருக்கவும்.

<a id="update-an-existing-installation"></a>
## ஏற்கனவே உள்ள நிறுவலைப் புதுப்பிக்கவும்

1. சேவையகத்தை நிறுத்து.
2. நிறுவப்பட்டதை முழுமையாக நகலெடுக்கவும் RandomDayGuard பாதுகாப்பான காப்புப்பிரதி இருப்பிடத்திற்கு கோப்புறை.
3. பழைய நிரல் கோப்புறையை UE4SS `Mods` புதிய வெளியீட்டை அதன் மேல் அடுக்குவதற்குப் பதிலாக.
4. புதியதை நகலெடு RandomDayGuard கோப்புறையில் `Mods`.
5. உங்கள் மதிப்பாய்வு செய்யப்பட்ட உள்ளூர் உள்ளமைவு மற்றும் சேமிக்கப்பட்ட ஆதாரங்களை மட்டும் மீட்டெடுக்கவும். உள்ளமைவு வழிகாட்டி புதிய புலங்களை பட்டியலிட்டால், அனைத்து அமைப்புகளையும் கண்மூடித்தனமாக மாற்றுவதற்குப் பதிலாக மதிப்பாய்வு செய்யப்பட்ட நகலில் அவற்றை இணைக்கவும்.
6. உறுதிப்படுத்து `RandomDayGuard : 1` இயக்கத்தில் உள்ளது.
7. சேவையகத்தைத் தொடங்கி, தற்போதைய சர்வர்-நிலை அறிக்கையைப் படிக்கவும்.

இந்த சுத்தமான-கோப்புறை புதுப்பிப்பு, நிரல் கோப்புப் பெயர்களை ஆய்வு செய்யும்படி ஆபரேட்டரிடம் கேட்காமலேயே பழைய வெளியீடுகளிலிருந்து வழக்கற்றுப் போன கோப்புகளை நீக்குகிறது.

<a id="help-guard-find-the-server-records"></a>
## சர்வர் பதிவுகளைக் கண்டறிய காவலருக்கு உதவுங்கள்

பாதுகாவலர் பொதுவாக அபியோடிக் காரணியைக் கண்டுபிடிப்பார் `Saved` அடைவு தானாகவே. முடியாவிட்டால், அதற்கான முழு பாதையையும் `Saved` கோப்பகம் `SavedRoot.txt` உள்ளே RandomDayGuard கோப்புறை. சுட்டி `Saved`, அதற்கு கீழே உள்ள ஒரு தனி உலகத்திற்கு அல்ல.

பதிவு இருப்பிடம் கண்டுபிடிக்கப்பட்டதா மற்றும் எந்த மூலக் குழுக்கள் உள்ளன என்பதை முதல் சேவையக நிலை அறிக்கை கூறுகிறது. [சரிசெய்தல்](%E0%AE%9A%E0%AE%B0%E0%AE%BF%E0%AE%9A%E0%AF%86%E0%AE%AF%E0%AF%8D%E0%AE%A4%E0%AE%B2%E0%AF%8D.md) இருப்பிடத்தைப் படிக்க முடியாதபோது.

<a id="first-run-behavior"></a>
## முதல்-ஓட்ட நடத்தை

இயல்புநிலை நிறுவல் கிடைக்கக்கூடிய பதிவுகளைப் பார்த்து அறிக்கைகளை எழுதுகிறது. இது மாறாது `Admin.ini` அல்லது தடையைச் சேர்க்கவும். எந்தவொரு விருப்பமான செயலையும் இயக்க வேண்டுமா என்பதைத் தீர்மானிக்கும் முன், சேகரிப்பு, மொழிபெயர்ப்பு மற்றும் அறிக்கையின் தரத்தை உறுதிப்படுத்த இது உங்களை அனுமதிக்கிறது.

[முதல் அறிக்கையைப் படிக்கவும்](%E0%AE%87%E0%AE%99%E0%AF%8D%E0%AE%95%E0%AF%87_%E0%AE%A4%E0%AF%8A%E0%AE%9F%E0%AE%99%E0%AF%8D%E0%AE%95%E0%AF%81.md)

<a id="disable-or-remove-randomdayguard"></a>
## முடக்கு அல்லது அகற்று RandomDayGuard

1. சேவையகத்தை நிறுத்து.
2. முழுமையை நகலெடு RandomDayGuard கோப்புறை.
3. மோட்டை முடக்க, அமைக்கவும் `RandomDayGuard : 0` in UE4SS `mods.txt`.
4. அதை அகற்ற, முழுமையை நகர்த்தவும் RandomDayGuard கோப்புறை வெளியே `Mods` உறுதிப்படுத்திய பிறகு காப்பகத்தைத் திறக்க முடியும்.
5. சேவையகத்தைத் தொடங்கி, காவலர் இனி தொடங்காது என்பதை உறுதிப்படுத்தவும்.

காவலரை முடக்குவது அல்லது அகற்றுவது எதிர்கால சேகரிப்பை நிறுத்துகிறது. இது கேம் தரவை நீக்காது, காப்பகப்படுத்தப்பட்ட அறிக்கைகளை அழிக்காது அல்லது தனி ஆபரேட்டர் செயலை மாற்றாது.

<a id="roll-back-an-update"></a>
## ஒரு புதுப்பிப்பை திரும்பப் பெறவும்

புதிய நிறுவல் ஏற்றப்படாவிட்டால் அல்லது தற்போதைய அறிக்கையை உருவாக்க முடியாவிட்டால்:

1. சேவையகத்தை நிறுத்து.
2. தோல்வியடைந்த நிறுவலை அதன் பதிவுகளை நீக்காமல் ஒதுக்கி நகர்த்தவும்.
3. முழு முன் புதுப்பிப்பை மீட்டெடுக்கவும் RandomDayGuard கோப்புறை.
4. அதே காப்புப்பிரதியிலிருந்து மதிப்பாய்வு செய்யப்பட்ட உள்ளமைவு மற்றும் சேமிக்கப்பட்ட ஆதாரத்தை மீட்டெடுக்கவும்.
5. மோட் இயக்கப்பட்டிருப்பதை உறுதிசெய்து, சேவையகத்தைத் தொடங்கவும்.
6. மற்றொரு மாற்றத்தைச் செய்வதற்கு முன், மீட்டமைக்கப்பட்ட சர்வர்-நிலை அறிக்கையைப் படிக்கவும்.
