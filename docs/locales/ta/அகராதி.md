# அகராதி

> **நியாய ஆங்கில மூல:** [GLOSSARY.md](../../GLOSSARY.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


| காலம் | தெளிவான பொருள் | சரியான தொழில்நுட்ப பொருள் |
|---|---|---|
| செயலில் உள்ள பதிவு | புதிய ஆதாரங்களுக்காகப் பயன்படுத்தப்படும் தற்போதைய சர்வர் பதிவு. | தேவை `active_log` ஆதாரம்; வழியை முடிக்க, வாசிப்புத்திறன் மற்றும் தற்போதைய வரிசை தேவை. |
| துவக்க ஐடி | ஒரு கண்காணிப்புச் செயல்முறை தொடக்கம். | தற்போதைய இயக்க நேர அடையாளங்காட்டி முன் துவக்கத்தை நிராகரிக்கப் பயன்படுகிறது errors/reports. |
| Epoch ID | ஒரு சர்வர் தொடர்ச்சி இடைவெளி. | தொடர்ச்சியான தர்க்கம் மற்றொரு சகாப்தத்தைத் தொடங்கும் வரை அடையாளங்காட்டி இயல்பான இயக்க நேரத்தைக் கொண்டிருக்கும். |
| வாக்கெடுப்பு ஐடி | ஒரு வரம்பிற்குட்பட்ட வாக்கெடுப்பு வாய்ப்பு. | நேர்மறை மோனோடோனிக் சுழற்சி புலம்; zero/missing வழியை முடிக்க முடியாது. |
| மூல புத்துணர்ச்சி | தற்போதைய மூலமும் வாக்கெடுப்பு பரம்பரையும் ஒப்புக்கொள்கிறதா. | `fresh_current_poll` அல்லது `stale_or_unproven` நேர முத்திரைகள் மற்றும் செயலில் பதிவு நிலை. |
| மூலக் கணக்கியல் | ஆதாரம் கிடைக்கும் மற்றும் வரம்புகளின் இருப்பு. | `randomdayguard.source-accounting/v1` எட்டு மூல வகுப்புகள் மற்றும் current/historical நோக்கம். |
| `available` | ஒரு ஆதாரம் கண்டறியப்பட்டு படிக்கப்பட்டது. | டெர்மினல் மூல நிலை `available=true`, `readable=true`. |
| `expected_empty` | ஒரு விருப்பமான ஆதாரம் சரிபார்க்கப்பட்டது மற்றும் சட்டப்பூர்வமாக absent/empty. | டெர்மினல் படிக்கக்கூடிய மூல நிலை; ஒரு விஷயத்தை ஒருபோதும் தயாரிப்பதில்லை. |
| `partial` | வரம்புக்குட்பட்ட வேலை பயனுள்ள ஆனால் முழுமையற்ற முடிவுகளைக் கொண்டுள்ளது. | அல்லாதது source/accounting நிலை; சொந்த தொழிலாளியை மீண்டும் தொடங்கவும். |
| `deferred` | வேலை வேண்டுமென்றே நிலுவையில் உள்ளது. | அல்லாத மூல நிலை; பிழை அல்லது நிறைவு அல்ல. |
| `unavailable` | மூலத்தை தற்போது பயன்படுத்த முடியாது. | டெர்மினல் இடைவெளி; தேவையான மூல இடைவெளி கணக்கியல் கிடைக்காமல் செய்கிறது. |
| `malformed` | ஒரு ஆதாரம் உள்ளது ஆனால் கட்டமைப்பு ரீதியாக தவறானது. | டெர்மினல் இடைவெளி சரிபார்ப்பு விவரங்களைப் பாதுகாக்கிறது மற்றும் சார்பு எழுதுதல்களை மூடுகிறது. |
| `permission_denied` | OS வெளிப்படையாக அணுகலை நிராகரித்தது. | டெர்மினல் இடைவெளி missing/unavailable. |
| `error` | ஒரு வரம்புக்குட்பட்ட செயல்பாடு எதிர்பாராத விதமாக தோல்வியடைந்தது. | பெயரிடப்பட்ட மீட்பு தேவைப்படும் டெர்மினல் தோல்வி; பொது அறிக்கைகளில் எந்த ரகசிய விவரமும் இல்லை. |
| `complete` | அனைத்து கணக்கு மூலங்களும் இடைவெளி இல்லாமல் முனையத்தில் உள்ளன. | உயர்நிலை மூல கணக்கியல் நிலை. |
| `complete_with_gaps` | தேவையான தற்போதைய சான்றுகள் செயல்படுகின்றன; விருப்ப முனைய இடைவெளிகள் உள்ளன. | உயர்நிலை கணக்கியல் நிலை; பாதைகள் இன்னும் அவற்றின் சொந்த தேவைகளைப் பயன்படுத்துகின்றன. |
| `full` | ஒரு பாதை அதன் தேவையான காலியாக இல்லாத ஒப்பந்தத்துடன் நிறைவுற்றது. | முடிக்கப்பட்ட தற்போதைய சுழற்சி வெளியீடுகளுடன் ரூட் ஆதாரம் enum. |
| `limited_expected_empty` | ஒரு பாதை நிறைவுற்றது மற்றும் எந்த தகுதியும் இல்லை subject/failure. | Route proof enum with `completed=true`, `expected_empty=true`. |
| `missing` | பாதை முடித்ததற்கான ஆதாரம் இல்லை அல்லது தோல்வியுற்றது. | Route proof enum with `completed=false`; அவுட்பாக்ஸுக்கு ஒருபோதும் தகுதி இல்லை. |
| கட்டமைக்கப்பட்ட அறிக்கை | இயந்திரம் படிக்கக்கூடிய வழி வெளியீடு. | `<route>_latest.json`ஐப் பயன்படுத்தி `randomdayguard.report/v1`. |
| மொழிபெயர்க்கப்பட்ட அறிக்கை | அதே பாதையின் மனிதனால் படிக்கக்கூடிய ரெண்டரிங். | `<route>_latest.txt` நிலையான Observed-to-Source-references வரிசையுடன். |
| வழி ஆதாரம் | குறுக்கு வழி நிறைவு லெட்ஜர். | `route_proof.json` பிணைப்பு version/boot/epoch/poll/freshness/output பாதைகள். |
| தற்போதைய சான்றுகள் | கண்காணிப்பு செயலில் உள்ள சுழற்சிக்கு சொந்தமானது. | நோக்கம் `current`; பழைய filenames/reports. |
| வரலாற்று சான்றுகள் | முந்தைய சுழற்சிகள் அல்லது மெதுவான ஸ்கேன் ஆகியவற்றிலிருந்து தக்கவைக்கப்பட்ட சூழல். | நோக்கம் `historical`; மதிப்பாய்வைத் தெரிவிக்கலாம் ஆனால் தற்போதைய இருப்பைக் கோர முடியாது. |
| மதிப்பாய்வு மட்டும் | Admin.ini எழுதுகிறது. | இயல்புநிலை `review_only_mode=true`, `auto_ban=false`, `write_admin_ini=false`. |
| தடை பட்டியல் பாதுகாப்பு சோதனை | ஒரு கேள்வியை மாற்றும் முன் காவலர் பதிலளிக்க வேண்டும் `Admin.ini`. | இது கணக்கையும் மதிப்பெண்ணையும் உறுதிப்படுத்த வேண்டும், நம்பகமான கணக்குகள் மற்றும் நகல்களை விலக்க வேண்டும், காப்புப்பிரதியைச் சரிபார்க்க வேண்டும், வெளிப்புற மாற்றங்களைக் கண்டறிய வேண்டும், உத்தேசித்துள்ள புதுப்பிப்பைச் சேமிக்க வேண்டும், மேலும் முழுமையான கோப்பைச் சரிபார்க்க வேண்டும் அல்லது பாதுகாப்பாக மீட்டெடுக்க வேண்டும். |
| உள்ளூர் அவுட்பாக்ஸ் | விருப்ப வழங்குநர்-நடுநிலை அறிவிப்பு கையேடு. | JSON உடன் `delivery_backend="none"` மற்றும் `delivery_attempted=false`. |
| அடிப்படை | நிறைவுசெய்யப்பட்ட வரம்பிடப்பட்ட சேமிக்கப்பட்ட கோப்பு சூழல் ஸ்னாப்ஷாட். | Manifest/object/world இணக்கமான மற்றும் போதுமான அளவு புதியதாக இருக்கும்போது மட்டுமே நிலை மீண்டும் பயன்படுத்தப்படும். |
| செக்பாயிண்ட் | முழுமையற்ற ஸ்கேன் பணிக்கான நிலையை மீண்டும் தொடங்கவும். | `scan_checkpoint.json`; நீக்குதல் இயல்பு மீட்பு அல்ல. |
| மீண்டும் கட்டக்கூடிய அட்டவணை | மீண்டும் உருவாக்கக்கூடிய சுருக்கம். | Daily/weekly/forensic/final மதிப்பாய்வு வெளியீடு; ஆதார ஆதாரம் அதிகாரப்பூர்வமாக உள்ளது. |
| சான்று எல்லை | ஆதாரம் எதை ஆதரிக்கும் என்பதைக் கட்டுப்படுத்தவும். | வெளிப்படையானது `does_not_prove`, தெரியாதவை, அடையாள வலிமை மற்றும் நோக்கம் விதிகள். |
