# தமிழில் RandomDayGuard வழிகாட்டி

**v0.4.12-alpha**

RandomDayGuard, Abiotic Factor தனிச் சேவையகத்தின் வரம்பிடப்பட்ட ஆதாரங்களை
நிர்வாகி எளிதாகப் படிக்கக்கூடிய அறிக்கைகளாக மாற்றுகிறது. சேவையக நிலை,
தினசரி தொகுப்பு, வீரர் செயல்பாடு, வழக்கு ஆய்வு மற்றும் முக்கியப் பிழைகள்
தனித்தனி வழிகளில் வைக்கப்படுகின்றன.

## நிறுவல்

[நிறுவல் வழிகாட்டியை](../../../INSTALL.md) பின்பற்றவும். கோப்புறை
`ue4ss/Mods/RandomDayGuard` ஆக இருக்க வேண்டும்; `mods.txt` கோப்பில்
`RandomDayGuard : 1` இருக்க வேண்டும். உள்ளமைந்த நிறுவல்களையும் இரட்டை `Scripts`
கோப்புறைகளையும் தவிர்க்கவும்.

## முதல் அறிக்கையைச் சரிபார்த்தல்

முதலில் `runtime/current/startup_status.json`, பின்னர்
`runtime/final_logs/latest_dossier.json`, இறுதியாக
`runtime/final_logs/route_proof.json` ஆகியவற்றைப் பார்க்கவும். ஒவ்வொரு வழியும்
`full`, `limited_expected_empty` அல்லது `missing` எனக் காட்ட வேண்டும். அறிக்கையும்
அது சுட்டும் மூலமும் ஒரே சுழற்சியைச் சேர்ந்திருக்க வேண்டும்.

## அமைப்பும் செயல்பாடும்

பொது இயல்புநிலைகள் `review_only_mode = true`, `auto_ban = false`, மற்றும்
`write_admin_ini = false`. [தொடக்கம்](../../START_HERE.md),
[செயல்பாடுகள்](../../OPERATIONS_PLAYBOOK.md), [அமைப்பு](../../CONFIG_PROFILES.md),
மற்றும் [சிக்கல் தீர்வு](../../TROUBLESHOOTING.md) ஆகியவற்றைப் படிக்கவும்.

உண்மையான கோப்புகளுடன் துல்லியமாகப் பொருந்த கட்டளைகள், பாதைகள், விசைகள் மற்றும்
நிலை மதிப்புகள் ஆங்கிலத்திலேயே இருக்கும்.

## ஆல்பா வெளியீடும் இரண்டு ஆதார வழிகளும்

இது ஓர் ஆல்பா வெளியீடு. ஆவணப்படுத்தப்பட்ட சேகரிப்பு, அறிக்கை மற்றும் மீட்பு வழிகள் சோதிக்கப்பட்டுள்ளன; இணக்கத்தன்மை, வரலாற்று உள்ளடக்கம் மற்றும் அறிக்கைத் தரம் தொடர்ந்து மேம்படுத்தப்படுகின்றன.

தற்போதைய வழி செயலில் உள்ள log, தற்போதைய தொடக்கம் மற்றும் scheduler நிலை, தற்போதைய session-களைப் பயன்படுத்துவதால் தற்போதைய அறிக்கைகளை உடனே எழுதும். வரலாற்று வழி சேமிக்கப்பட்ட logs, PlayerData பெயர்கள், பழைய ஆதாரங்கள் மற்றும் cases-ஐ வரம்புள்ள படிகளில் பார்க்கும்.

`runtime/current/report_worker_status.json`

பல சுழற்சிகளில் `runtime/current/report_worker_status.json` உள்ள `scan_cursor`, `last_progress_ts` மதிப்புகளை ஒப்பிடுங்கள். அவை முன்னேறினால் scan இயங்குகிறது. தற்போதைய அறிக்கைகள் முன்னேறியும் அவை மாறாவிட்டால் வரலாற்று scan நின்றுள்ளது; தற்போதைய உண்மைகள் பயன்படும், ஆனால் பழைய வரலாறு தேவைப்படும் முடிவுகள் வரம்புடையவை.
