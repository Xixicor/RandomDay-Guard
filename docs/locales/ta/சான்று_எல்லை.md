# சான்று எல்லை

> **நியாய ஆங்கில மூல:** [EVIDENCE_BOUNDARY.md](../../EVIDENCE_BOUNDARY.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


என்ன என்பதைத் தீர்மானிக்க இந்தப் பக்கத்தைப் பயன்படுத்தவும் RandomDayGuard இன்னும் மனித மதிப்பாய்வு தேவை என்பதை தெரிவிக்கலாம்.

<a id="core-rule"></a>
## முக்கிய விதி

RandomDayGuard சேவையகத்திற்குச் சொந்தமான கோப்புகளிலிருந்து வரம்புக்குட்பட்ட அவதானிப்புகளைப் பதிவுசெய்கிறது. இது ஒவ்வொரு பொருளின் முடிவுக்கான ஆதாரம், நோக்கம், சேகரிப்பு நிலை மற்றும் வரம்புகளை அடையாளம் காண வேண்டும்.

கட்டமைக்கப்பட்ட சான்றுகள் அதிகாரப்பூர்வமானது. மொழிபெயர்க்கப்பட்ட அறிக்கை ஆதாரத்தை விளக்குகிறது; கட்டமைக்கப்பட்ட பதிவில் இல்லாத உண்மைகளைச் சேர்க்க முடியாது.

<a id="evidence-source-classes"></a>
## சான்று ஆதார வகுப்புகள்

| மூல வகுப்பு | வழக்கமான பயன்பாடு | தன்னை நிரூபிக்கவில்லை |
|---|---|---|
| `admin_ini` | தற்போதுள்ள நிர்வாக நிலை மற்றும் தணிக்கை செய்யப்பட்டது write/readback சூழல் | ஒரு சம்பவத்தை ஏற்படுத்தியவர் |
| `active_log` | தற்போதைய server/session நிகழ்வுகள் செயலில் உள்ள பதிவில் தெரியும் | நோக்கம், உரிமை அல்லது நேரடி சேதம் |
| `recent_backup_logs` | வரலாற்று பதிவு சூழல் | தற்போதைய நிகழ்வு நிகழ்ந்தது |
| `playerdata_filenames` | சுத்தமான கணக்கு அடையாளங்காட்டி இருப்பதை உறுதிப்படுத்துதல் | வெளிப்படுத்தப்பட்ட அடையாளங்காட்டியைத் தாண்டிய நடத்தை, குற்ற உணர்வு அல்லது அடையாள உரிமை |
| `existing_cases` | முந்தைய மதிப்பாய்வு சூழல் | முன் விளக்கம் சரியாக இருக்கும் |
| `existing_reports` | முந்தைய சுருக்கங்கள் மற்றும் முடிவுகள் | தற்போதைய உறுதிப்படுத்தல் இல்லாத தற்போதைய உண்மை |
| `existing_evidence` | வரலாற்று கட்டமைக்கப்பட்ட சான்றுகள் | தற்போதைய செயல்பாடு |
| வரையறுக்கப்பட்ட உலக சேமிப்பு ஸ்கேன் | மெதுவானது world/class சூழல் | பிளேயர் நடவடிக்கை, உரிமை, திருட்டு, நகல் அல்லது சேதம் |

ஒவ்வொரு மூல பதிவுகளும் availability/readability, கோப்பு எண்ணிக்கை, மூலக் குறிப்புகள், தற்போதைய அல்லது வரலாற்று நோக்கம் மற்றும் வெளிப்படையான `does_not_prove` அறிக்கை.

<a id="source-states"></a>
## ஆதார நிலைகள்

| நிலை | ஆபரேட்டர் பொருள் |
|---|---|
| `available` | ஆதாரம் படிக்கக்கூடியதாக இருந்தது மற்றும் ஆதாரம் சேகரிக்கப்பட்டது. |
| `expected_empty` | மூலத்தைப் படிக்கக்கூடியதாக இருந்தது மற்றும் சட்டப்பூர்வமாக எந்தப் பதிவும் இல்லை. |
| `partial` | சில ஆதாரங்கள் சேகரிக்கப்பட்டன; கவரேஜ் முழுமையடையவில்லை. |
| `deferred` | வரம்புக்குட்பட்ட வேலை வேண்டுமென்றே ஒத்திவைக்கப்பட்டது. |
| `unavailable` | இந்த சூழலில் ஆதாரம் இல்லை. |
| `malformed` | ஆதாரம் உள்ளது ஆனால் பாதுகாப்பாக பாகுபடுத்த முடியாது. |
| `permission_denied` | வாட்ச்டாக் படிக்க அனுமதி இல்லை. |
| `error` | மற்றொரு பதிவு செய்யப்பட்ட காரணத்திற்காக சேகரிப்பு தோல்வியடைந்தது. |

எதிர்பார்க்கப்படும் காலியானது சரியான கவனிப்பு. இது ஒருபோதும் புனையப்பட்ட பிளேயர், வழக்கு, சம்பவம் அல்லது குற்றச்சாட்டாக மாற்றப்படக்கூடாது.

<a id="current-versus-historical-evidence"></a>
## தற்போதைய மற்றும் வரலாற்று சான்றுகள்

தற்போதைய சான்றுகள் செயலில் உள்ள சேகரிப்பு சாளரம் அல்லது சர்வர் சகாப்தத்திற்கு சொந்தமானது. வரலாற்றுச் சான்றுகள் முந்தைய பதிவுகள், வழக்குகள், அறிக்கைகள், ஆதாரப் பதிவுகள், காப்புப் பிரதிகள் அல்லது அடிப்படைக் குறிப்புகளிலிருந்து வருகிறது.

வரலாற்று சான்றுகள் சூழலை வழங்கலாம். தற்போதைய ஆதார இடைவெளியை அமைதியாக நிரப்ப முடியாது. அறிக்கைகள் இரண்டு நோக்கங்களையும் லேபிளிட வேண்டும் மற்றும் அவற்றின் ஆதாரங்களை தனித்தனியாக மேற்கோள் காட்ட வேண்டும்.

<a id="corroboration-rule"></a>
## உறுதிப்படுத்தல் விதி

இவை பயனுள்ள சூழல், ஆனால் அவை நேரடியாக ஆதாரம் இல்லை:

- காட்சி பெயர்கள் அல்லது பெயர் ஒற்றுமை;
- நேர தற்செயல்;
- துண்டிக்கவும் அல்லது மீண்டும் இணைக்கவும்;
- ஒரு விபத்து அல்லது எச்சரிக்கை வெடிப்பு;
- வகுப்பு, பாதை, நடிகர், வரைபடம் அல்லது பொருள் எண்ணிக்கை டோக்கன்கள்;
- தானாக குழுவாக்கப்பட்ட வழக்கில் உறுப்பினர்;
- தற்போதைய ஆதார உறுதிப்படுத்தல் இல்லாத முந்தைய அறிக்கைகள்.

உண்மையை நேரடியாக அம்பலப்படுத்தும் ஆதாரம் இல்லாமல் குற்றம், நோக்கம், ஏமாற்றுதல், உரிமை, திருட்டு, நகல், நேரடி சேதம், நேரடி கொள்கலன் பயன்பாடு, நேரடி சரக்கு நடவடிக்கை, சரியான நேரடி ஒருங்கிணைப்புகள், நேரடி பிங் அல்லது நினைவக நிலை நடத்தை ஆகியவற்றைக் கோர வேண்டாம்.

<a id="truthful-report-language"></a>
## உண்மையான அறிக்கை மொழி

பயன்படுத்தவும்:

```text
Observed: the account was active in the recorded crash window.
Interpretation: repeated overlap warrants operator review.
Unknown: the cause of the crash.
Does not prove: that the account caused the crash.
Next action: compare the cited current session and lifecycle records.
```

தவிர்:

```text
The player crashed the server.
The player stole or duplicated items.
The world token proves who used the object.
```

<a id="report-reading-order"></a>
## வாசிப்பு வரிசையைப் புகாரளிக்கவும்

பொதுவை எதிர்கொள்ளும் ஒவ்வொரு அறிக்கையும் விளக்க வேண்டும்:

1. தெளிவான பொருள்.
2. அது ஏன் முக்கியமானது.
3. தொழில்நுட்ப ஆதாரம் மற்றும் ஆதாரக் குறிப்புகள்.
4. அடுத்த செயல்.
5. வரம்புகள், தெரியாதவை மற்றும் உரிமைகோரல்கள் நிரூபிக்கப்படவில்லை.
