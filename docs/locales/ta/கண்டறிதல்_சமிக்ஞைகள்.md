# கண்டறிதல் சமிக்ஞைகள்

> **நியாய ஆங்கில மூல:** [DETECTION_SIGNALS.md](../../DETECTION_SIGNALS.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


சிக்னல்கள் மதிப்பாய்வு உள்ளீடுகள், தானியங்கு குற்றச்சாட்டுகள் அல்ல.

<a id="signal-table"></a>
## சிக்னல் அட்டவணை

| சிக்னல் | பொருள் | எப்போது வலிமையானது... | தேவையே போதுமானதாக இல்லை |
|---|---|---|---|
| உள்நுழைவு அடையாளம் | கணக்கு ஐடிக்கு வரைபடத்தின் பெயர் | ConnectID உள்ளது | தடை |
| சுத்தமான விடுப்பு | சாதாரண அமர்வு மூடல் | சேர்ந்து போட்டியிலிருந்து வெளியேறவும் | சந்தேகம் |
| விரைவான மறுஇணைப்பு | Churn/probing சூழல் | விரைவாக மீண்டும் நிகழும் | தடை |
| அசுத்தமான துண்டிப்பு | அமர்வு சுத்தமாக மூடப்படவில்லை | சிதறல்களைத் திரும்பத் திரும்ப அல்லது ஒன்றுடன் ஒன்று சேர்க்கிறது | தடை |
| விபத்து ஒன்றுடன் ஒன்று | விபத்திற்கு அருகில் கணக்கு செயலில் உள்ளது | ஒரே கணக்கு மீண்டும் நிகழ்கிறது | தடை |
| விபத்திற்குப் பிந்தைய வருவாய் | மறுதொடக்கம் செய்த பிறகு கணக்கு திரும்பும் | சகாப்தங்கள் முழுவதும் மீண்டும் நிகழும் | ஒரு நிகழ்வின் மூலம் தடை |
| எச்சரிக்கை வெடிப்பு | சேவையக எச்சரிக்கை சாளரம் | மேப் செய்யப்பட்ட அமர்வுகளை மேலெழுதுகிறது | ஒரே பர்ஸ்ட் மூலம் தடை |
| நடிகர் சேவ் டச் | உலக சேமிப்பு சூழல் | அமர்வுகளுடன் தொடர்புடையது | சான்று use/theft |
| பொருள் டெல்டா | World/class மாற்றம் | அமர்வுகளுடன் தொடர்புடையது | கணக்கிலிருந்து மட்டும் தடை |
| ரெய்டு வழக்கு | பல கணக்கு கிளஸ்டர் | மத்திய கணக்கு மீண்டும் வருகிறது | அனைத்து கணக்குகளையும் பெருமளவில் தடை செய்யுங்கள் |

<a id="login-identity"></a>
## உள்நுழைவு அடையாளம்

சிறந்த ஆதாரம்:

```text
Login request
Name=
ConnectID=
UniqueId=
```

வரைபடத்திற்கு இதைப் பயன்படுத்தவும்:

```text
display/log name -> account_id -> ban_id
```

<a id="rapid-reconnect"></a>
## விரைவான மறுஇணைப்பு

முறை:

```text
join -> leave -> join -> leave -> join
```

மீண்டும் திரும்பும்போது மதிப்பாய்வுக்கு பயன்படுத்தவும்.

பாதுகாப்பு:

```text
churn_alone_never_bans = true
```

<a id="crash-overlap-and-post-crash-return"></a>
## விபத்து ஒன்றுடன் ஒன்று மற்றும் பிந்தைய செயலிழப்பு திரும்பும்

முறை:

```text
account active before crash
server restarts
same account returns quickly
```

சகாப்தங்கள் முழுவதும் மீண்டும் மீண்டும் வரும்போது மதிப்பாய்வுக்கு பயன்படுத்தவும்.

பாதுகாப்பு:

```text
single_crash_never_bans = true
```

<a id="warning-bursts"></a>
## எச்சரிக்கை வெடிப்புகள்

எடுத்துக்காட்டுகள்:

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

மேப் செய்யப்பட்ட அமர்வுகள் மற்றும் வரம்புகளுடன் இணைக்கப்படும் வரை சூழலாகப் பயன்படுத்தவும்.

<a id="actor-save-touch"></a>
## நடிகர் சேவ் டச்

பொருள்:

```text
The server evidence referenced a class or actor.
```

அர்த்தம் இல்லை:

```text
A player opened it.
A player stole from it.
A player duplicated through it.
A player damaged it.
```

<a id="raid-cases"></a>
## ரெய்டு வழக்குகள்

ஒரு ரெய்டு வழக்கு நேரம் மற்றும் பகிரப்பட்ட சாளரங்களின் அடிப்படையில் கணக்குகளைக் குழுவாக்குகிறது.

விதி:

```text
Do not auto-ban every account in a raid case.
Each account needs account-specific evidence.
```
