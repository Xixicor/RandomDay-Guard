# சரிபார்ப்பு மற்றும் வெளியீடு

> **நியாய ஆங்கில மூல:** [VALIDATION_AND_RELEASE.md](../../VALIDATION_AND_RELEASE.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


இந்தப் பக்கம் பங்களிப்பாளர்கள் மற்றும் வெளியீடு பராமரிப்பாளர்களுக்கானது. சர்வர் ஆபரேட்டர்கள் RandomDayGuard.

<a id="user-visible-proof"></a>
## பயனர் காணக்கூடிய ஆதாரம்

ஒரு புதிய ஆபரேட்டர் அதை நிறுவி, முதல் சர்வர்-நிலை அறிக்கையைக் கண்டறிந்து, ஐந்து அறிக்கை வழிகளை வேறுபடுத்தி, வேலை செய்த எடுத்துக்காட்டில் இருந்து ஒரு தெளிவான செயலைப் பின்பற்றினால், வெளியீட்டைப் புரிந்துகொள்ள முடியும். வாசகர் பணிகளுக்கு Git, PowerShell, பைதான் அல்லது செக்சம் அறிவு.

<a id="contributor-checks"></a>
## பங்களிப்பாளர் சோதனைகள்

```powershell
python -B tools/validate_repo.py
python -B tools/test_public_pipeline.py
python -B -m unittest discover tests
```

எப்போது `luac` கிடைக்கிறது:

```powershell
luac -p RandomDayGuard/Scripts/main.lua
luac -p RandomDayGuard/Scripts/public_pipeline.lua
```

Lua fixture சோதனைகள் ஏற்றி, திட்டமிடுபவர், அறிக்கை வழிகள் மற்றும் விருப்பத்தேர்வை உள்ளடக்கியது Admin.ini பரிவர்த்தனை எழுதவும். அமலாக்க சாதனங்கள் தற்காலிக கோப்புகளை மட்டுமே பயன்படுத்துகின்றன மற்றும் அடையாளம், நம்பகமான-கணக்கு நிராகரிப்பு, வரம்புகள், காப்புப்பிரதி, ஒரே நேரத்தில்-மாற்ற மறுப்பு, ரீட்பேக் மற்றும் திரும்பப் பெறுதல் ஆகியவற்றைச் சரிபார்க்கின்றன.

<a id="package-proof"></a>
## பேக்கேஜ் ஆதாரம்

```powershell
python -B tools/build_release_zip.py --check
git diff --check
```

- அனைத்து பதிப்பு குறிப்பான்களும் பொருந்தும் `VERSION`.
- தற்போதைய பதிப்பு மட்டுமே `releases/`.
- தி ZIP `RandomDayGuard/Scripts/main.lua` பாதை மற்றும் சிறிய எழுத்து மாறுபாடு ஏற்றி இல்லை.
- இயக்க நேர வெளியீடு, தனிப்பட்ட உள்ளமைவு, நற்சான்றிதழ்கள், உள்ளூர் பாதைகள், தற்காலிக சேமிப்புகள் மற்றும் சோதனை கலைப்பொருட்கள் ஆகியவை விலக்கப்பட்டுள்ளன.
- பொது உள்ளமைவு, அமலாக்கம் முடக்கப்பட்ட நிலையில் மதிப்பாய்வு மட்டுமே.
- ஐந்து வேலை அறிக்கை எடுத்துக்காட்டுகள் வழி உரிமை மற்றும் வெளியீட்டு சோதனை பொருத்தத்துடன் ஒத்துப்போகின்றன.
- ZIP பைட்டுகள் உறுதியானவை மற்றும் பொருந்துகின்றன `CHECKSUMS.sha256`.
- அனைத்து உள்ளூர் ஆவண இணைப்புகளும் 27 மொழி நுழைவு பக்கங்களும் சரிபார்க்கப்படுகின்றன.

<a id="avoid-validation-environment-pitfalls"></a>
## சரிபார்ப்பு சூழல் ஆபத்துகளைத் தவிர்க்கவும்

- தற்காலிக-கோப்பு சர்ச்சையைத் தவிர்க்க களஞ்சிய-எழுத்துச் சரிபார்ப்புகளைத் தொடராக இயக்கவும்.
- விண்டோஸில், நகல் ஏற்றிகளைச் சரிபார்க்கும்போது, ​​கேஸ்-இன்சென்சிட்டிவ் கோப்புத் தேடலுக்குப் பதிலாக, காப்பகப்படுத்தப்பட்ட உறுப்பினர் பெயர்கள் அல்லது எண்ணப்பட்ட பாதை எழுத்துப்பிழைகளை ஆய்வு செய்யவும்.
- ஒரு விடுபட்டது `luac` கட்டளை அல்லது Lua இயக்க நேரம் என்பது கிடைக்காத திறனாகும், இது தொடரியல் அல்லது இயக்க நேர சோதனை அல்ல.
- ஒரு பொருத்தம் அதன் மாதிரி உள்ளீடுகளை மட்டுமே நிரூபிக்கிறது. நேரடி சேவையகம் தற்போதைய அறிக்கையை உருவாக்கியது என்பதை இது நிரூபிக்கவில்லை.
- கட்டளை நேரம் முடிந்துவிட்டதாகக் கருதுவதற்குப் பதிலாக, பகுதியளவு வெளியீட்டைப் பதிவுசெய்யவும்.

<a id="repair-failed-repository-validation"></a>
## தோல்வியடைந்த களஞ்சிய சரிபார்ப்பைப் பழுதுபார்த்தல்

முதலில் அறிவிக்கப்பட்ட பாதை அல்லது ஒப்பந்தத்துடன் தொடங்கவும். அந்த உருப்படியை சரிசெய்து, குறுகிய சோதனையை மீண்டும் இயக்கவும், பின்னர் முழுமையான மேட்ரிக்ஸை மீண்டும் இயக்கவும். தேவைப்படும் சோதனையை அகற்றுவதன் மூலம் விடுபட்ட திறனை மறைக்க வேண்டாம்.

<a id="known-limits-and-release-decision"></a>
## தெரிந்த வரம்புகள் மற்றும் வெளியீட்டு முடிவு

உள்ளூர் காசோலைகள் ஆதாரம், சாதனம், தொகுப்பு மற்றும் ஆவண ஒப்பந்தங்களை நிரூபிக்கின்றன. ஒரு குறிப்பிட்ட சேவையக நிறுவல், நீண்டகால நிலைப்புத்தன்மை சாளரம் அல்லது கிளையன்ட் காட்சிக்கு ஒரு தனி ஒருங்கிணைப்பு முடிவு தேவைப்படுகிறது. பொருந்தக்கூடிய உரிமைகோரலைச் செய்வதற்கு முன், அதன் உருவாக்கம், உள்ளமைவு, கால அளவு மற்றும் கவனிக்கப்பட்ட வெளியீடு ஆகியவற்றுடன் அந்த முடிவைப் பதிவுசெய்க.
