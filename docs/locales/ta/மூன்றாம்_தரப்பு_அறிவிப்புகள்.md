# மூன்றாம் தரப்பு அறிவிப்புகள்

> **நியாய ஆங்கில மூல:** [THIRD_PARTY_NOTICES.md](../../../THIRD_PARTY_NOTICES.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும். இந்த மொழிபெயர்ப்பு தகவல் சார்ந்தது; ஆங்கில சட்ட உரை கட்டுப்பாடுகள்.


RandomDayGuard மூன்றாம் தரப்பு மோட்கள் அல்லது கேம் சொத்துக்களை தொகுப்பதில்லை. இது இயங்கும் Abiotic Factor சேவையகத்தால் உருவாக்கப்பட்ட சேவையகத்திற்குச் சொந்தமான சேமிக்கப்பட்ட கோப்புறை கோப்புகளைப் படிக்கிறது.
