# ஐடி மேப்பிங்கைத் தடைசெய்

> **நியாய ஆங்கில மூல:** [BAN_ID_MAPPING.md](../../BAN_ID_MAPPING.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


பிளேயர் பெயரை பாதுகாப்பானதாக மாற்றும் போது இந்தப் பக்கத்தைப் பயன்படுத்தவும் `Admin.ini` தடை வரி.

<a id="core-rule"></a>
## முக்கிய விதி

காட்சிப் பெயர் தடை ஐடி அல்ல.

`Admin.ini` பயன்படுத்துகிறது:

```ini
BannedPlayer=<raw numeric player ID>
```

<a id="evidence-hierarchy"></a>
## சான்று படிநிலை

| தரவரிசை | ஆதாரம் | பயன்படுத்து |
|---:|---|---|
| 1 | சர்வர் பதிவு `Login request` | பெஸ்ட்-டு-ஐடி மேப்பிங் |
| 2 | `Player_<ID>.sav` | ஐடி இருப்பதை உறுதிப்படுத்துகிறது |
| 3 | தற்போது உள்ளது `Admin.ini` | தற்போது உள்ளது bans/moderators |
| 4 | வெளிப்புற அறிவிப்பு அல்லது ஹோஸ்டிங்-பேனல் செயல்பாடு | Time/name சூழல் மட்டும்; அடையாளச் சான்று அல்ல |
| 5 | UE4SS focus/player வரிகள் | Presence/context மட்டும் |
| 6 | கணினி வாழ்க்கைச் சுழற்சி அல்லது கொள்கலன் பதிவுகள் | ஹோஸ்ட் வாழ்க்கைச் சுழற்சி சூழல் மட்டும்; அடையாளச் சான்று அல்ல |

<a id="extract-the-clean-id"></a>
## சுத்தமான ஐடியைப் பிரித்தெடுக்கவும்

மூல உதாரணம்:

```text
ConnectID=2535422284688820_+_|0002d07b...
```

சுத்தம் `Admin.ini` மதிப்பு:

```ini
BannedPlayer=2535422284688820
```

ஒட்ட வேண்டாம் `_+_|...`.

<a id="verify-with-playerdata"></a>
## உடன் சரிபார்க்கவும் PlayerData

இதைச் சரிபார்க்கவும்:

```text
Saved/SaveGames/Server/Worlds/<WorldName>/PlayerData/Player_<ID>.sav
```

பொருள்:

```text
The ID exists in the world save.
```

வரம்பு:

```text
PlayerData may not prove the display name unless another source maps it.
```

<a id="when-not-to-ban"></a>
## எப்போது தடை செய்யக்கூடாது

எப்போது தடை ஐடியை ஒதுக்க வேண்டாம்:

```text
the name only appears in an external notification
the name only appears in hosting-panel activity
UE4SS shows a name but no ConnectID
only system lifecycle or container logs exist
the ID is trusted or moderator
```
