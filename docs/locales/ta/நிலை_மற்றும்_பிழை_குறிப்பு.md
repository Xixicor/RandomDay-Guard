# நிலை மற்றும் பிழை குறிப்பு

> **நியாய ஆங்கில மூல:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


ஒரு அறிகுறி வகைப்படுத்தப்பட்ட பிறகு இந்த குறிப்பைப் பயன்படுத்தவும் [சரிசெய்தல்](%E0%AE%9A%E0%AE%B0%E0%AE%BF%E0%AE%9A%E0%AF%86%E0%AE%AF%E0%AF%8D%E0%AE%A4%E0%AE%B2%E0%AF%8D.md). பிழையால் பெயரிடப்பட்ட கட்டமைக்கப்பட்ட நிலைக் கோப்பைப் படிக்கவும். தனித்துவமான குறியீடுகள் தனித்துவமான பாதுகாப்பு மற்றும் வாழ்க்கைச் சுழற்சி நிலைகளைக் குறிக்கின்றன; அவற்றை ஒரு பொதுவான "காவலர் தோல்வியடைந்தார்" என்ற முடிவாகச் சுருக்க வேண்டாம்.

## பாதை மற்றும் மூல நிலைகள்

| மதிப்பு | பொருள் | ஆபரேட்டர் பதில் |
|---|---|---|
| `full` | நடப்பு-சுழற்சி ஆதார ஆதாரத்துடன் பாதை ஒப்பந்தம் முடிக்கப்பட்டது. | வழியின் ஆதார எல்லையைப் படிக்கவும்; பழுது இல்லை. |
| `limited_expected_empty` | வழி முடிக்கப்பட்டது மற்றும் விடுபட்ட செயல்பாடு இந்த சுழற்சிக்கு முறையானது. | செயற்கை இல்லை player/case நிகழ்வு உருவாக்கப்பட வேண்டும். |
| `missing` | தேவையான வெளியீடு, பரம்பரை புலம் அல்லது ஆதார ஆதாரம் இல்லை. | வழியின் காரணத்தையும் பெயரிடப்பட்ட மூல நிலையையும் ஆய்வு செய்யவும். |
| `available` | பெயரிடப்பட்ட மூலமானது படிக்கக்கூடியதாகவும் பயன்படுத்தக்கூடியதாகவும் இருந்தது. | செயல் இல்லை. |
| `expected_empty` | மூலம் சரிபார்க்கப்பட்டது மற்றும் சட்டப்பூர்வமாக வரிசைகள் இல்லை. | செயல்பாடு சுயாதீனமாக எதிர்பார்க்கப்படும் வரை எந்த நடவடிக்கையும் இல்லை. |
| `partial` / `complete_with_gaps` | பயன்படுத்தக்கூடிய சான்றுகள் உள்ளன, ஆனால் பெயரிடப்பட்ட மூல வகுப்புகள் முழுமையடையாது. | முடிவுகளை சேகரிக்கப்பட்ட சான்றுகளுக்கு வரம்பிடவும். |
| `deferred` | பணியிடப்பட்ட வேலை, பின்னர் பணிபுரியும் வாய்ப்பிற்காக திட்டமிடப்பட்டுள்ளது. | உள்ளமைவை மாற்றும் முன் முன்னேற்ற முன்னேற்றங்களை உறுதிப்படுத்தவும். |
| `unavailable` | சூழல் மூலத்தை வழங்கவில்லை. | வரம்பைப் பதிவு செய்யவும்; நிரூபிக்கப்பட்ட பாதை அல்லது அனுமதி சிக்கலை மட்டும் சரிசெய்யவும். |
| `malformed` | மூலம் படிக்கக்கூடியதாக இருந்தது, ஆனால் கட்டமைப்பு சரிபார்ப்பில் தோல்வியடைந்தது. | அதை பாதுகாத்து, மூலத்தை சரிசெய்யவும்; யூகிக்க வேண்டாம். |
| `permission_denied` | ஆதாரம் உள்ளது ஆனால் படிக்க முடியவில்லை. | தேவையான குறுகிய வாசிப்பு அனுமதியை மட்டும் வழங்கவும். |
| `error` | பதிவு செய்யப்பட்ட காரணத்திற்காக சேகரிப்பு தோல்வியடைந்தது. | பிழையைப் பாதுகாத்து, அந்த நிலையைக் கண்டறியவும். |

## PlayerData மற்றும் சரக்கு குறியீடுகள்

| குறியீடு | பொருள் | பாதுகாப்பான பதில் |
|---|---|---|
| `saved_root_unavailable` | பொது பைப்லைனில் சரிபார்க்கப்பட்ட சேமிக்கப்பட்ட ரூட் எதுவும் கிடைக்கவில்லை. | சரியானது `SavedRoot.txt` மற்றும் பாதை ஆய்வை மீண்டும் சரிபார்க்கவும். |
| `unsafe_playerdata_root` | PlayerData கண்டறிதல் கட்டுப்படுத்தப்பட்ட சேமிக்கப்பட்ட மூலத்திற்கு வெளியே தீர்க்கப்பட்டது. | பாதையை சரிசெய்யவும்; எல்லையை ஒருபோதும் பலவீனப்படுத்த வேண்டாம். |
| `playerdata_discovery_not_run` | கட்டுப்படுத்தப்பட்ட கண்டுபிடிப்பு பணியாளர் இன்னும் இயங்கவில்லை. | திட்டமிடுபவர் மற்றும் பணியாளரின் முன்னேற்றத்தைச் சரிபார்க்கவும். |
| `playerdata_discovery_read_failed:*` | கண்டுபிடிப்பு வெளியீட்டைப் படிக்க முடியவில்லை. | பின்னொட்டு விவரங்களைப் பாதுகாத்து வரம்பிற்குட்பட்ட சரக்கு கட்டளையைச் சரிபார்க்கவும். |
| `inventory_command_open_failed` | இருப்பு செயல்முறையைத் தொடங்க முடியவில்லை. | உள்ளமைக்கப்பட்ட கட்டளைப் பிரிட்ஜை வழங்கும் இயக்க நேரத்தைச் சரிபார்க்கவும். |
| `inventory_command_read_failed` | படிக்கும்போது சரக்கு வெளியீடு தோல்வியடைந்தது. | பகுதி வெளியீட்டைப் பாதுகாத்து, அடிப்படைப் பிழை சரி செய்யப்பட்ட பின்னரே மீண்டும் இயக்கவும். |
| `inventory_command_close_failed` | நம்பகமான நெருங்கிய முடிவு இல்லாமல் சரக்கு முடிந்தது. | மூலத்தை முழுமையடையாததாகக் கருதவும். |
| `identity_ledger_row_limit_exceeded` | நீடித்த அடையாள உள்ளீடு அதன் பொது பாதுகாப்பு வரம்பை மீறியது. | பேட்ஜரைக் காப்பகப்படுத்தி மதிப்பாய்வு செய்யவும்; அமைதியாக அதை முழு ஆதாரமாக துண்டிக்க வேண்டாம். |

## Admin.ini அமலாக்கக் குறியீடுகள்

இந்தப் பிரிவில் உள்ள அனைத்து குறியீடுகளும் தோல்வியடைந்துவிட்டன. அவர்கள் தாங்களாகவே கைமுறையான தடையை அங்கீகரிக்கவில்லை.

| குறியீடு | பொருள் | பாதுகாப்பான பதில் |
|---|---|---|
| `admin_ini_write_disabled` / `admin_ini_disabled` | பொது-பாதுகாப்பான எழுத்து வாயில்கள் முடக்கப்பட்டுள்ளன. | மதிப்பாய்வு-மட்டும் செயல்பாட்டில் எதிர்பார்க்கப்படுகிறது. |
| `admin_ini_backup_disabled` / `backup_safety_gate_disabled` | தேவையான காப்புப்பிரதி கொள்கை செயலில் இல்லை. | எழுதுவதை முடக்கி வைக்கவும். |
| `enforcement_disabled` / `ban_on_threshold_disabled` / `auto_ban_disabled` | ஒரு வெளிப்படையான அமலாக்க வாயில் முடக்கப்பட்டுள்ளது. | பொது மதிப்பாய்வு மட்டும் இயல்புநிலைகளில் எதிர்பார்க்கப்படுகிறது; அதை ஒரு எழுத்து தோல்வி என மறுவிளக்கம் செய்ய வேண்டாம். |
| `review_only_mode_enabled` | மதிப்பாய்வு மட்டும் பயன்முறை வேண்டுமென்றே பிறழ்வைத் தடுக்கிறது. | ஆதாரங்களை மட்டும் மதிப்பாய்வு செய்யவும். |
| `duplicate_prevention_disabled` | நகல் பாதுகாப்பு முடக்கப்பட்டது. | பாதுகாப்பு வாயிலை மீட்டெடுக்கும் வரை எழுதுதல்களை முடக்கி வைக்கவும். |
| `readback_safety_gate_disabled` / `rollback_safety_gate_disabled` | எழுதலுக்குப் பின் சரிபார்ப்பு அல்லது திரும்பப்பெறும் பாதுகாப்பு முடக்கப்பட்டது. | எழுத்துகளை முடக்கி வைத்திருங்கள்; இந்த வாயில்களை ஒருபோதும் கடந்து செல்ல வேண்டாம். |
| `clean_id_safety_gate_disabled` / `account_specific_evidence_gate_disabled` | சுத்தமான அடையாளம் அல்லது கணக்கு சார்ந்த சான்றுகள் அமலாக்கம் முடக்கப்பட்டது. | எந்தவொரு அமலாக்க சோதனைக்கும் முன் வாயிலை மீட்டெடுக்கவும். |
| `moderator_preservation_disabled` / `existing_ban_preservation_disabled` | பாதுகாக்கப்பட்ட கணக்கு அல்லது ஏற்கனவே உள்ள தடை பாதுகாப்பு முடக்கப்பட்டது. | எழுதுவதை முடக்கி வைக்கவும். |
| `clean_numeric_identity_required` | உத்தேச ஐடியானது முழுமையாக ஏற்றுக்கொள்ளப்பட்ட இணைப்பு படிவம் அல்லது சுத்தமான எண் ஐடி அல்ல. | சரிபார்க்கப்பட்ட மேப்பிங்கைப் பெறவும்; தன்னிச்சையான முன்னொட்டை ஒருபோதும் துண்டிக்க வேண்டாம். |
| `identity_strength_below_minimum` | உள்ளமைக்கப்பட்ட வரம்பை விட அடையாளச் சான்று பலவீனமாக உள்ளது. | ஆதாரங்களை மட்டும் மதிப்பாய்வு செய்யவும். |
| `playerdata_verification_required` | உள்ளமைவு தேவை PlayerData உறுதிப்படுத்தல் மற்றும் கணக்கில் அது இல்லை. | வேட்பாளரை மதிப்பாய்வு செய்ய மட்டும் வைத்திருங்கள்; கோப்பு பெயரிலிருந்து உரிமையை ஊகிக்க வேண்டாம். |
| `trusted_or_moderator_identity` | கணக்கு நம்பகமான அல்லது மதிப்பீட்டாளர் நிலை மூலம் பாதுகாக்கப்படுகிறது. | எழுதுவதற்கு அனுமதி இல்லை. |
| `admin_ini_path_invalid` / `admin_ini_path_outside_saved_root` | இலக்கு பாதை தவறானது அல்லது சேமித்த மூலத்திலிருந்து தப்பிக்கும். | சரியான உள்ளமைவு; பாதை காவலரை ஒருபோதும் கடந்து செல்ல வேண்டாம். |
| `admin_ini_unavailable` | படிக்கக்கூடிய வகையில் உள்ளமைக்கப்படவில்லை Admin.ini கண்டறியப்பட்டது. | வரையறுக்கப்பட்ட பாதையை சரிசெய்யவும் அல்லது அமலாக்கத்தை முடக்கவும். |
| `admin_ini_read_failed` | அதிகாரப்பூர்வ பைட்டுகளைப் படிக்க முடியவில்லை. | மாற்றத்திற்கு முன் நிறுத்தவும். |
| `admin_ini_parse_failed` | Admin.ini இன்னும் குறிப்பிட்ட கட்டமைப்பு குறியீடு இல்லாமல் சரிபார்ப்பு தோல்வியடைந்தது. | கோப்பைப் பாதுகாத்து அதன் பிரிவு மற்றும் வரி அமைப்பை ஆய்வு செய்யவும். |

## தொடக்கம், திட்டமிடல் மற்றும் பின்னிணைப்பு நிலைகள்

இந்த மதிப்புகள் வாழ்க்கைச் சுழற்சி சான்றுகள், பாதை ஆதாரம் அல்ல. நடப்பு வாக்கெடுப்பு, அறிக்கை-பணியாளர் மற்றும் வழித்தடக் கோப்புகளுடன் அவற்றைப் படிக்கவும்.

- [சரிபார்ப்பு மற்றும் வெளியீட்டு மதிப்பாய்வு](%E0%AE%9A%E0%AE%B0%E0%AE%BF%E0%AE%AA%E0%AE%BE%E0%AE%B0%E0%AF%8D%E0%AE%AA%E0%AF%8D%E0%AE%AA%E0%AF%81_%E0%AE%AE%E0%AE%B1%E0%AF%8D%E0%AE%B1%E0%AF%81%E0%AE%AE%E0%AF%8D_%E0%AE%B5%E0%AF%86%E0%AE%B3%E0%AE%BF%E0%AE%AF%E0%AF%80%E0%AE%9F%E0%AF%81.md) பொருத்துதல் மற்றும் தொகுப்பு தோல்விகளுக்கு.
