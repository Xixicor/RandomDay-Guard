# FAQ

> **நியாய ஆங்கில மூல:** [FAQ.md](../../FAQ.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


<a id="is-randomdayguard-the-randomday-mod"></a>
## ஆகும் RandomDayGuard the RandomDay Mod?

இல்லை. RandomDay மோட் சர்வர் அனுபவத்தை மாற்றுகிறது. RandomDayGuard சர்வர் சான்று அடுக்கைப் பார்க்கிறது.

<a id="does-live-defense-work-before-the-scan-completes"></a>
## ஸ்கேன் முடிவதற்குள் நேரடி பாதுகாப்பு வேலை செய்யுமா?

ஆம். நேரடி பாதுகாப்பு பதிவுகள் மற்றும் அமர்வு நிகழ்வுகளைப் பயன்படுத்துகிறது. அடிப்படை ஸ்கேன் பின்னர் சூழலை மேம்படுத்துகிறது.

<a id="why-can-the-first-scan-take-a-long-time"></a>
## முதல் ஸ்கேன் ஏன் நீண்ட நேரம் எடுக்கலாம்?

முதல் ஸ்கேன் உருவாக்கம் world/object சூழல், கோப்பு வெளிப்பாடுகள் மற்றும் மீண்டும் பயன்படுத்தக்கூடிய அடிப்படை தரவு.

<a id="what-do-i-check-first-after-startup"></a>
## தொடங்கிய பிறகு முதலில் எதைச் சரிபார்க்க வேண்டும்?

```text
runtime/current/poll_status.json
```

இதைத் தேடு:

```text
scheduler_status=running
poll_id increasing
poll_in_flight=false
```

<a id="where-are-player-summaries"></a>
## பிளேயர் சுருக்கங்கள் எங்கே?

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

<a id="where-is-the-daily-quick-review-package"></a>
## தினசரி விரைவான மதிப்பாய்வு தொகுப்பு எங்கே?

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

<a id="which-file-should-i-upload-for-fastest-review"></a>
## வேகமான மதிப்பாய்வுக்கு எந்தக் கோப்பைப் பதிவேற்ற வேண்டும்?

```text
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="can-it-write-bans-automatically"></a>
## அது தானாகவே தடைகளை எழுத முடியுமா?

வெளிப்படையாக இயக்கப்பட்டிருந்தால் மட்டுமே.

இயல்புநிலை:

```lua
review_only_mode = true
auto_ban = false
write_admin_ini = false
```

<a id="what-does-adminini-receive"></a>
## என்ன செய்கிறது Admin.ini பெறவா?

மட்டும்:

```ini
BannedPlayer=<ID>
```

பெயர்கள், கருத்துகள், காரணங்கள் அல்லது பின்னொட்டுகள் இல்லை.

<a id="is-a-display-name-enough-to-ban"></a>
## தடை செய்ய காட்சி பெயர் போதுமா?

இல்லை. சர்வர் பதிவைப் பயன்படுத்தவும் `Login request` உடன் `ConnectID` அல்லது அதற்கு சமமான சர்வர் சான்று.

<a id="can-one-crash-ban-someone"></a>
## ஒரு செயலிழப்பு ஒருவரைத் தடை செய்ய முடியுமா?

இயல்புநிலையாக இல்லை.

<a id="can-object-count-alone-ban-someone"></a>
## பொருளை மட்டும் எண்ணி யாரையாவது தடை செய்ய முடியுமா?

இயல்புநிலையாக இல்லை.

<a id="should-savedroottxt-point-to-the-world-folder"></a>
## வேண்டும் SavedRoot.txt உலகக் கோப்புறையை சுட்டிக்காட்டவா?

இல்லை. அதை `AbioticFactor/Saved`.

<a id="what-if-the-world-folder-changes"></a>
## உலக கோப்புறை மாறினால் என்ன செய்வது?

அதை அடிப்படை அடையாள மாற்றமாக கருதவும். பழைய பேஸ்லைனைப் பாதுகாத்து புதிய ஒன்றை உருவாக்கவும்.
