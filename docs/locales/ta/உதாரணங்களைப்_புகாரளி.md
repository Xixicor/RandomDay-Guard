# ஐந்து காவலர் அறிக்கைகளின் எடுத்துக்காட்டுகள்

> **நியாய ஆங்கில மூல:** [REPORT_EXAMPLES.md](../../REPORT_EXAMPLES.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


இந்த எடுத்துக்காட்டுகள் வெளியீட்டில் சேர்க்கப்பட்ட மாதிரித் தரவிலிருந்து உருவாக்கப்பட்டன; பெயர்கள் மற்றும் கணக்கு எண்கள் கண்டுபிடிக்கப்பட்டுள்ளன. அவை சோதனை செய்யப்பட்ட அறிக்கை புலங்கள், கணக்கீடுகள் மற்றும் பாதை எல்லைகளைக் காட்டுகின்றன. உண்மையான அறிக்கையானது, அந்தச் சேவையகத்திலிருந்து சேகரிக்கப்பட்ட தகவலுடன் அவற்றை மாற்றியமைத்து, ஒரு உண்மை கிடைக்கவில்லை என்று கூறுகிறது.

ஒவ்வொரு அறிக்கைக்கும் ஒரு வேலை உள்ளது. சேவையக ஆரோக்கியம் பிளேயர் வரலாற்றை மீண்டும் செய்யாது, தினசரி மதிப்பாய்வு ஒவ்வொரு சில நிமிடங்களுக்கும் அனுப்பப்படாது, அமைதியான பிளேயர் அல்லது கேஸ் வழிகள் நிரப்பு செய்திகளைப் பெறாது. வரம்பிற்குட்பட்ட வரலாற்று ஸ்கேன் இன்னும் முன்னேறும் போது தற்போதைய அறிக்கை தயாராக இருக்கலாம்; அப்படியானால், அறிக்கையானது பழைய வரலாற்றை முழுமையானதாகக் காட்டுவதற்குப் பதிலாக இடைவெளியைக் குறிப்பிடுகிறது.

> **முக்கியமான காவலர்: அறிக்கை எழுதுவது நிறுத்தப்பட்டது**  **தொடங்கப்பட்டது:** 21:14  **பாதிக்கப்பட்ட செயல்பாடு:** பிளேயர் அறிக்கை எழுத்தாளர் **தாக்கம்:** புதிய பிளேயர் சுருக்கங்களை முடிக்க முடியாது.  **சேவையகம்:** ஆன்லைனில் உள்ளது.  **கண்காணிப்பு:** சான்று சேகரிப்பு தொடர்கிறது, ஆனால் படிக்கக்கூடிய அறிக்கைகள் தாமதமாகின்றன.  **கடைசி வெற்றிகரமான அறிக்கை:** 21:09  **தோல்வி:** அறிக்கை வெளியீட்டைச் சேமிக்க முடியவில்லை.  **சாத்தியமான காரணம்:** சேருமிடம் கிடைக்கவில்லை அல்லது எழுதுவதை நிராகரித்தது.  **செயல்:** காவலர் இயக்க நேர வெளியீட்டு இருப்பிடத்தைச் சரிபார்க்கவும். கண்காணிப்பு நிறுத்தப்படும் வரை கேம் சர்வரை மறுதொடக்கம் செய்ய வேண்டாம்.

சிக்கல் தீர்ந்தால், அதே பாதை மீட்டெடுப்பை பதிவு செய்யும்:

> **முக்கிய காவலர் தீர்க்கப்பட்டார்: அறிக்கை எழுதுதல் மீட்டமைக்கப்பட்டது**  **மீண்டும் தொடங்கப்பட்டது:** 21:22  **குறுக்கீடு:** 8 நிமிடங்கள் **முடிவு:** தடங்கலின் போது சேகரிக்கப்பட்ட சான்றுகள் பாதுகாக்கப்பட்டு, தாமதமான அறிக்கைகள் முடிக்கப்பட்டன.

முக்கிய காவலர் தோல்வி மட்டுமே. வழக்கமான நிலை, தினசரி வரலாறு, பிளேயர் செயல்பாடு மற்றும் சாதாரண எதிர்பார்க்கப்படும்-வெற்று முடிவுகள் அவற்றின் சொந்த அறிக்கைகளில் இருக்கும்.

## ஒரு பாதை அமைதியாக இருக்கும்போது

அமைதியான பாதையானது டிஸ்கார்டிற்கு நிரப்பியை அனுப்பாமல் நேரடி முடிவைப் பதிவுசெய்கிறது:

> **சரிபார்க்கப்பட்டது; இந்த அறிக்கைக்கு எதுவும் இல்லை.** தேவையான பதிவுகள் கிடைக்கப்பெற்றன, மேலும் இந்த அறிக்கை சாளரத்தின் போது பொருந்தக்கூடிய பிளேயர் செயல்பாடு, கேஸ் அல்லது காவலர் தோல்வி எதுவும் ஏற்படவில்லை.

இது ஒரு முழுமையான வெற்று முடிவு. இது விடுபட்ட அறிக்கையிலிருந்து வேறுபட்டது, அங்கு தேவையான மூலத்தைச் சரிபார்க்க முடியவில்லை அல்லது படிக்கக்கூடிய வெளியீட்டை உருவாக்க முடியவில்லை.

ஒவ்வொரு படிக்கக்கூடிய அறிக்கையும் ஒரே பாதையைப் பின்பற்றுகிறது:

```text
collected evidence -> normalized values -> dictionary mapping -> route calculations -> readable report -> Discord notification
```
