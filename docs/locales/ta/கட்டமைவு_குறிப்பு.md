# உள்ளமைவு கருத்துக்கள்

> **நியாய ஆங்கில மூல:** [CONFIG_REFERENCE.md](../../CONFIG_REFERENCE.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


இந்த விளக்கம், ஒவ்வொரு பெரிய உள்ளமைவுப் பகுதியும் எதைக் கட்டுப்படுத்துகிறது, அது இயங்கும் போது, ​​அது எவ்வாறு ஆதாரங்கள் மற்றும் பாதுகாப்பு வாயில்களுடன் தொடர்பு கொள்கிறது என்பதை விவரிக்கிறது. இது சரியான புல பட்டியல் அல்லது சுயவிவர நடைமுறைகளை சொந்தமாக்கவில்லை.

பணி சார்ந்த முன்னமைவுகள் மற்றும் பாதுகாப்பான மாற்ற படிகளுக்கு, பயன்படுத்தவும் [`CONFIG_PROFILES.md`](%E0%AE%89%E0%AE%B3%E0%AF%8D%E0%AE%B3%E0%AE%AE%E0%AF%88%E0%AE%B5%E0%AF%81_%E0%AE%9A%E0%AF%81%E0%AE%AF%E0%AE%B5%E0%AE%BF%E0%AE%B5%E0%AE%B0%E0%AE%99%E0%AF%8D%E0%AE%95%E0%AE%B3%E0%AF%8D.md). ஒவ்வொரு சரியான மூலப் புலத்திற்கும், இயல்புநிலை, வகை, மாறாத, வெளியீட்டு விளைவு மற்றும் மீட்பு விதி, உருவாக்கப்பட்ட [`CONFIG_FIELD_CATALOG.md`](%E0%AE%95%E0%AE%9F%E0%AF%8D%E0%AE%9F%E0%AE%AE%E0%AF%88%E0%AE%AA%E0%AF%8D%E0%AE%AA%E0%AF%81_%E0%AE%AA%E0%AF%81%E0%AE%B2_%E0%AE%AA%E0%AE%9F%E0%AF%8D%E0%AE%9F%E0%AE%BF%E0%AE%AF%E0%AE%B2%E0%AF%8D.md); அனுப்பப்பட்ட ஒவ்வொரு `config.lua` இலை புலம்.

<a id="top-level-safety"></a>
## உயர்நிலை பாதுகாப்பு

| விருப்பம் | இயல்புநிலை | பொருள் |
|---|---:|---|
| `enabled` | `true` | பாதுகாவலுக்கான முதன்மை சுவிட்ச் |
| `enforcement.review_only_mode` | `true` | Record/recommend மட்டும் |
| `enforcement.auto_ban` | `false` | இயல்புநிலையாக தானாகவே தடை செய்ய வேண்டாம் |
| `enforcement.write_admin_ini` | `false` | எழுத வேண்டாம் Admin.ini இயல்பாக |

சேவையக உரிமையாளர் வெளியீட்டை மதிப்பாய்வு செய்யும் வரை இவற்றைப் பாதுகாப்பாக வைத்திருங்கள்.

<a id="saved"></a>
## `saved`

பாதுகாவலர் எவ்வாறு சேவையகத்தைக் கண்டுபிடிப்பார் என்பதைக் கட்டுப்படுத்துகிறது `Saved/` கோப்புறை மற்றும் எந்த கோப்பு குடும்பங்களை ஸ்கேன் செய்யலாம்.

எப்போது பயன்படுத்தவும்:

```text
Saved root auto-detection fails.
World folder changed.
Provider or container path is unusual.
```

சரிபார்:

```text
runtime/saved_path_probe.json
RandomDayGuard/SavedRoot.txt
```

விதி:

```text
SavedRoot.txt -> AbioticFactor/Saved
not -> Worlds/<WorldName>
```

<a id="log_tail"></a>
## `log_tail`

நேரடி பதிவு வாசிப்பைக் கட்டுப்படுத்துகிறது.

பயனுள்ள விருப்பங்கள்:

| விருப்பம் | பாதுகாப்பான மதிப்பு | ஏன் |
|---|---|---|
| `enabled` | `true` | நேரடி பாதுகாப்புக்கு தேவை |
| `start_at_end_on_first_run` | `true` | பழைய பதிவுகளை நேரலை நிகழ்வுகளாகத் தவிர்க்கிறது |
| `tail_backup_logs` | `false` | காப்புப் பதிவுகள் வரலாறு, நேரலை அல்ல |
| `max_lines_per_poll` | கட்டுப்படுத்தப்பட்டது | வாக்கெடுப்பு வளையத்தை பதிலளிக்கக்கூடியதாக வைத்திருக்கிறது |

சரிபார்:

```text
runtime/log_offsets.tsv
runtime/evidence/session_events.jsonl
runtime/current/poll_status.json
```

<a id="runtime"></a>
## `runtime`

வாக்கெடுப்பு மற்றும் பட்ஜெட்களைக் கட்டுப்படுத்துகிறது.

முக்கிய சுகாதார விதி:

```text
poll_id increases
poll_in_flight returns false
poll_scheduled is true
```

சரிபார்:

```text
runtime/current/poll_status.json
```

என்றால் `poll_id` நிறுத்தங்கள், லூப்பை ஏதோ தடுக்கிறது.

<a id="source_accounting"></a>
## `source_accounting`

வெளிப்படையான சான்று-மூலக் கவரேஜ் மற்றும் நோக்கத்தைக் கட்டுப்படுத்துகிறது.

| விசை | இயல்புநிலை | பொருள் |
|---|---:|---|
| `enabled` | `true` | பொது வழி அறிக்கைகளுக்கான மூலக் கணக்கை எழுதுகிறது. |
| `require_terminal_status` | `true` | ஒவ்வொரு மூலமும் வெளிப்படையான முனையம் அல்லது முழுமையற்ற நிலையை வெளிப்படுத்த வேண்டும். |
| `distinguish_current_from_historical` | `true` | தற்போதைய மற்றும் வரலாற்று ஆதாரங்களை தனித்தனியாக வைத்திருக்கிறது. |
| `slow_world_scan_blocks_current_reports` | `false` | கட்டுப்படுத்தப்பட்ட உலக ஸ்கேனிங் ஒத்திவைக்கப்பட்டது அல்லது பகுதியளவு என்று தற்போதைய அறிக்கைகளை அனுமதிக்கிறது. |
| `changed_file_manifest` | அடிப்படை மேனிஃபெஸ்ட் பாதை | வரம்பிற்குப் பயன்படுத்தப்படும் குறிப்பு historical/world கணக்கியல். |

மூல நிலைகள் `available`, `expected_empty`, `partial`, `deferred`, `unavailable`, `malformed`, `permission_denied`, அல்லது `error`.

அமைப்பு `source_accounting.enabled = false` நிலை வெளியீட்டை அமைதியாக அகற்றாது. பைப்லைன் இன்னும் `runtime/final_logs/source_accounting_latest.json` உடன் `enabled=false`, `status="unavailable"`, மற்றும் `disabled_reason="source_accounting_disabled"`. இது கிடைக்காத கணக்கியலுடன் வரலாற்று-நிலைப் பதிவையும் எழுதுகிறது. மூலக் கணக்கியல் அறிக்கை ஒப்பந்தத்தின் ஒரு பகுதியாக இருப்பதால், ஒவ்வொரு வழியும் `missing`; கணக்கியல் முடக்கப்பட்டிருக்கும் போது எந்த வழியும் முடிந்ததாக கருதப்படவில்லை.

<a id="reports"></a>
## `reports`

பொதுவான உள்ளூர் அறிக்கையிடல் பைப்லைனைக் கட்டுப்படுத்துகிறது.

இயல்புநிலைகள் ஐந்து வழிகளையும் இயக்கி `runtime/final_logs`:

```text
server_status
daily_rollup
player_activity
case_review
critical_guard
```

ஒவ்வொரு வழியும் கட்டமைக்கப்பட்ட மற்றும் மொழிபெயர்க்கப்பட்ட வெளியீட்டையும் `route_proof.json`. வழியை முடக்குவது `missing` அது முடிந்தது என்று பாசாங்கு செய்வதை விட ஆதாரம்.

<a id="notification"></a>
## `notification`

விருப்பப் பொது உள்ளூர் கோப்பு அவுட்பாக்ஸ். இது இயல்பாகவே முடக்கப்பட்டுள்ளது மற்றும் வெளிப்புற வழங்குநருக்கு எதையும் அனுப்பாது.

இயல்புநிலைகள்:

```lua
notification = {
    enabled = false,
    mode = "local_file_outbox",
    include_expected_empty = false,
},
```

ஒவ்வொரு அறிவிப்பு வழியும் இயல்பாகவே முடக்கப்பட்டுள்ளது. வேண்டுமென்றே இயக்கப்பட்டால், `route_proof.json` எழுதப்பட்டுள்ளது. உள்ளூர் சான்றுகள் மற்றும் அறிக்கைகள் அதிகாரப்பூர்வமாக இருக்கும். வழங்குநர்-குறிப்பிட்ட டெலிவரி, டெலிவரி முடிவுப் புள்ளிகள், நற்சான்றிதழ்கள் மற்றும் பாலங்கள் ஆகியவை பொது சுயாதீன கண்காணிப்பு ஒப்பந்தத்தின் பகுதியாக இல்லை.

<a id="scanning"></a>
## `scanning`

அடிப்படை ஸ்கேன், சோதனைச் சாவடி மற்றும் மாற்றப்பட்ட கோப்பு புதுப்பிப்பைக் கட்டுப்படுத்துகிறது.

எப்போது பயன்படுத்தவும்:

```text
building first world baseline
resuming after crash
refreshing changed files later
```

சரிபார்:

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/scan_complete.json
runtime/baselines/file_manifest.tsv
```

முக்கியமான அமைப்புகள்:

```lua
scanning = {
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
    changed_file_detection = true,
},
```

<a id="forensic_rollup"></a>
## `forensic_rollup`

விரைவான தினசரி பதிவேற்ற தொகுப்பு மற்றும் இறுதி எளிய மொழி பதிவுகளை கட்டுப்படுத்துகிறது.

வெளியீடுகள்:

```text
runtime/current/forensic_today.json
runtime/current/forensic_today.md
runtime/current/forensic_today.txt
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

எப்போது பயன்படுத்தவும்:

```text
You want one daily folder that summarizes what happened.
You want a plain-language TXT to upload for quick analysis.
```

சரிபார்:

```text
runtime/forensic_days/YYYY-MM-DD/forensic_day_summary.json
runtime/forensic_days/YYYY-MM-DD/players.tsv
runtime/forensic_days/YYYY-MM-DD/ban_recommendations.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

விதி:

```text
Daily summaries are rebuildable indexes.
Source evidence remains authoritative.
```

<a id="logging"></a>
## `logging`

நிகழ்வின் அளவு மற்றும் குறைந்த முக்கியத்துவம் வாய்ந்த ஒருங்கிணைப்பைக் கட்டுப்படுத்துகிறது.

எப்போது பயன்படுத்தவும்:

```text
actor-touch events are noisy
raw event files grow too quickly
```

பாதுகாப்பான முறை:

```lua
logging = {
    low_importance_mode = "aggregate",
    write_low_importance_raw_events = false,
},
```

<a id="retention"></a>
## `retention`

கோப்புகள் எவ்வளவு நேரம் மற்றும் எப்போது சேமிக்கப்படுகின்றன என்பதைக் கட்டுப்படுத்துகிறது JSONL பதிவுகள் சுழலும்.

எப்போது பயன்படுத்தவும்:

```text
disk usage grows too fast
you need more audit history
you need shorter live-history windows
```

முக்கிய விருப்பங்கள்:

```text
detailed_retention_days
rotate_jsonl_when_bytes_exceed
max_raw_events_lines
keep_enforced_forever
keep_evidence_forever
```

## `warning_bursts`

எச்சரிக்கை சாளரத்தைக் கண்டறிவதைக் கட்டுப்படுத்துகிறது.

எடுத்துக்காட்டுகள்:

```text
ActorChannelFailure

Warnings are context until correlated with mapped sessions and thresholds.
```

<a id="crash_correlation"></a>
## `crash_correlation`

கட்டுப்பாடுகள் மீண்டும் மீண்டும் crash/reconnect மதிப்பாய்வு.

பாதுகாப்பான இயல்புநிலைகள்:

```lua
crash_correlation = {
    single_crash_never_bans = true,
    require_same_account = true,
},
```

பயனுள்ள கவுண்டர்கள்:

```text
server_crash_overlap_count
post_crash_reconnect_count
unclean_disconnect_count
```

<a id="join_leave"></a>
## `join_leave`

கட்டுப்பாடு மற்றும் சேர-அலை கண்காணிப்பு.

பாதுகாப்பான இயல்புநிலை:

```lua
join_leave = {
    churn_alone_never_bans = true,
},
```

இதற்குப் பயன்படுத்தவும்:

```text
rapid reconnect loops
join waves
short-session patterns
```

<a id="raid_detection"></a>
## `raid_detection`

தொடர்புடைய சாளரங்களில் செயல்படும் குழுக் கணக்குகள்.

விதி:

```text
A raid case groups accounts for review.
It does not make every account guilty.
```

ஒவ்வொரு செயல்படுத்தப்பட்ட கணக்கிற்கும் இன்னும் கணக்கு சார்ந்த சான்றுகள் தேவை.

runtime/object_registry_partial.json
runtime/object_registry.json

Object/class context is not a ban reason by itself.

<a id="world_state"></a>
## `world_state`

கட்டுப்பாடுகள் boot/current/session உலக-நிலை ஸ்னாப்ஷாட்கள்.

வெளியீடுகள்:

```text
runtime/world_state/current/world_state_latest.json
runtime/world_state/sessions/<date>/<session_id>_<account_id>/
```

அமர்வு மதிப்பாய்வு மற்றும் உலக சூழலுக்கு பயன்படுத்தவும்.

<a id="enforcement"></a>
## `enforcement`

பரிந்துரைகள் மற்றும் உண்மையானவற்றைக் கட்டுப்படுத்துகிறது Admin.ini எழுதுகிறது.

பாதுகாவலர் தடையைச் சேர்க்கும் முன், கீழே உள்ள ஒவ்வொரு அறிக்கையும் உண்மையாக இருக்க வேண்டும்:

```text
review_only_mode == false
auto_ban == true
write_admin_ini == true
ban_id is clean numeric
account identity is mapped
not trusted
not moderator
threshold is met
```

ஒரு அறிக்கை தவறானது அல்லது சரிபார்க்க முடியாவிட்டால், காவலர் வெளியேறுவார் `Admin.ini` மாறாமல் காரணத்தை பதிவு செய்கிறது.

<a id="admin_ini"></a>
## `admin_ini`

பாதுகாப்பான கோப்பு எழுதுதல்களைக் கட்டுப்படுத்துகிறது.

விதிகள்:

```text
Back up before writing.
Preserve existing bans.
Preserve moderators.
Write clean BannedPlayer=<ID> only.
```

<a id="restart_request"></a>
## `restart_request`

மற்றொரு ஆபரேட்டருக்குச் சொந்தமான செயல்முறை ஆய்வு செய்யக்கூடிய விருப்ப உள்ளூர் மார்க்கர் கோப்புகளைக் கட்டுப்படுத்துகிறது. இது சேவையகத்தை மறுதொடக்கம் செய்யவோ அல்லது அழிக்கவோ இல்லை.

இயல்புநிலைகள்:

```lua
restart_request = {
    enabled = false,
    restart_marker_file = "runtime/request_restart.flag",
    restart_reason_file = "runtime/restart_reason.json",
},
```

வெளியீடுகள்:

```text
runtime/request_restart.flag
runtime/restart_reason.json
```

ஹோஸ்டிங் பேனல், வழங்குநர் பிரிட்ஜ் அல்லது மறுதொடக்கம் ஆட்டோமேஷன் தொகுக்கப்படவில்லை. மார்க்கர் உருவாக்கத்தை இயக்குவது, வெளிப்புறச் செயல்முறையானது கோரிக்கையைப் பயன்படுத்தியது அல்லது சேவையகத்தை மறுதொடக்கம் செய்தது என்பதை நிரூபிக்காது.
