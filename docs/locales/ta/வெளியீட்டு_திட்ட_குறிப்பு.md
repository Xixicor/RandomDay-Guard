# வெளியீடு மற்றும் நிலை திட்ட குறிப்பு

> **நியாய ஆங்கில மூல:** [OUTPUT_SCHEMA_REFERENCE.md](../../OUTPUT_SCHEMA_REFERENCE.md). இந்த உள்ளூர்மயமாக்கப்பட்ட ஆவணம் சரியான கட்டளைகள், பாதைகள், விசைகள், நிலை மதிப்புகள், ஹாஷ்கள் மற்றும் கோப்பு பெயர்களைப் பாதுகாக்கிறது. தொழில்நுட்ப வார்த்தைகள் வேறுபட்டால், ஆங்கில மூலத்தைப் பயன்படுத்தவும்.


இது உருவாக்கப்படும் ஆபரேட்டர் எதிர்கொள்ளும் கோப்புகளுக்கான நியமன ஒப்பந்தமாகும். இது மட்டுமே சரியான வெளியீட்டுப் பாதைகள், புலப் பெயர்கள், அனுமதிக்கப்பட்ட மதிப்புகள், பரம்பரைத் தேவைகள் மற்றும் வழித் திட்டங்கள் ஆகியவற்றைக் கொண்டுள்ளது. நடைமுறை வழிகாட்டிகள் அந்த உண்மைகளை மறுவரையறை செய்வதற்குப் பதிலாக இங்கே இணைக்கின்றன.

இயக்க நேர ஆதாரம் அதிகாரப்பூர்வமானது; கோப்புப்பெயர், திட்டமிடுபவர் இதயத் துடிப்பு, மொழிபெயர்க்கப்பட்ட அறிக்கை அல்லது உள்ளூர் அவுட்பாக்ஸ் பொருள் அதன் சொந்த புலங்கள் மற்றும் பரம்பரையை விட அதிகமாக நிரூபிக்கவில்லை.

<a id="public-report-routes"></a>
## பொது அறிக்கை வழிகள்

அறிக்கை பணியாளருக்கு `runtime/final_logs/`:

| வழி | ஒப்பந்தம் | `full` தேவை | எதிர்பார்க்கப்படும்-வெற்று பொருள் |
|---|---|---|---|
| `server_status` | தற்போதைய திட்டமிடல், செயலில்-பதிவு, ஸ்கேன்-நிலுவையில் உள்ளது மற்றும் மூல-கவரேஜ் நிலை. | தற்போதைய boot/epoch/poll பரம்பரை, புதிய செயலில் உள்ள பதிவு, accounting/history எழுதுகிறது, மற்றும் JSON/TXT ஜோடி. | இல்லையெனில் ஆரோக்கியமான மின்னோட்டம் சுழற்சிக்காகப் பயன்படுத்தப்படவில்லை; விடுபட்ட பரம்பரை `missing`. |
| `daily_rollup` | தற்போதைய day/window சர்வர், பிளேயர்கள், கேஸ்கள், ஸ்கேன் மற்றும் கவரேஜ் முழுவதும் தொடர்ச்சி. | வரலாற்று கணக்கியல் முனையம், பாதை மற்றும் தற்போதைய சுழற்சிக்கான ஆதாரம் நிறைவடைவதற்கு போதுமானது. | தங்கும் வீரர்கள் இல்லை மற்றும் மறுஆய்வு வழக்குகள் இல்லை. |
| `player_activity` | தனி நடப்பு மற்றும் வரலாற்று player/account அவதானிப்புகள். | தற்போதைய சுழற்சி ஆதாரம் மற்றும் ஒன்று அல்லது அதற்கு மேற்பட்டவை current/historical வரிசைகள். | கட்டுப்பட்ட உள்ளீடுகளில் தகுதியான பிளேயர் வரிசைகள் இல்லை; செயற்கை பொருள் இல்லை. |
| `case_review` | பெயரிடப்பட்ட தக்க வழக்குகள் மற்றும் நடப்பு review/BAN-ELIGIBLE வேட்பாளர்கள். | தற்போதைய சுழற்சி ஆதாரம் மற்றும் ஆதாரக் குறிப்புகளுடன் ஒன்று அல்லது அதற்கு மேற்பட்ட பெயரிடப்பட்ட வழக்குகள். | பெயரிடப்பட்ட வழக்கு எதுவும் மறுஆய்வு அளவுகோலைப் பூர்த்தி செய்தது; செயற்கை வழக்கு இல்லை. |
| `critical_guard` | தற்போதைய துவக்க திட்டமிடல், தொடக்கம், கருத்துக்கணிப்பு அல்லது சான்று-ஒருமைப்பாடு தோல்வி. | தற்போதைய சுழற்சி ஆதாரம் மற்றும் தற்போதைய முக்கியமான தோல்வி. | தற்போதைய முக்கியமான தோல்வி இல்லை; பழைய உரை பிழைகள் இந்த வழியை சொந்தமாக்கவில்லை. |

இயக்கப்பட்ட ஒவ்வொரு வழியும் எழுதும் `<route>_latest.json` மற்றும் `<route>_latest.txt`. `runtime/final_logs/route_proof.json` அதே பதிப்பு, துவக்கம், சகாப்தம், வாக்கெடுப்பு மற்றும் மூல புத்துணர்ச்சியை பதிவு செய்கிறது.

<a id="report-json-schema"></a>
## அறிக்கை JSON ஸ்கீமா

எல்லா வழியும் JSON பயன்படுத்துகிறது `schema="randomdayguard.report/v1"`.

| புலம் | வகை | பொருள் மற்றும் மாறாத |
|---|---|---|
| `schema` | சரம் | சரியாக `randomdayguard.report/v1`. |
| `generated_ts`, `report_date` | சரம் | தலைமுறை நேர முத்திரை மற்றும் அறிக்கை தேதி. |
| `version` | சரம் | Runtime/package அடையாளம். |
| `boot_id`, `epoch_id` | சரம் | தற்போதைய செயல்முறை துவக்கம் மற்றும் சர்வர் தொடர்ச்சி சகாப்தம். முடிக்க இரண்டும் தேவை. |
| `poll_id` | முழு எண் | நேர்மறை நடப்பு வாக்கெடுப்பு அடையாளங்காட்டி. Zero/missing வழியை முடிக்க முடியாது. |
| `source_freshness` | பொருள் | `status`, `checked_ts`, செயலில்-பதிவு நிலை, கடைசி வாக்கெடுப்பு நேர முத்திரை மற்றும் கடைசியாக நிறைவு செய்யப்பட்ட வாக்கெடுப்பு நேரமுத்திரை. |
| `current_cycle_proof_complete` | பூலியன் | பரம்பரை மற்றும் புதியதாக இருக்கும்போது மட்டுமே உண்மை active-log/current-poll சான்றுகள் ஒப்புக்கொள்கின்றன. |
| `route` | enum | மேலே உள்ள ஐந்து வழிகளில் ஒன்று. |
| `route_proof_status` | enum | `full`, `limited_expected_empty`, அல்லது `missing`. |
| `coverage_status` | enum | சரியாக `complete`, `complete_with_gaps`, `partial`, அல்லது `unavailable`. |
| `completed`, `expected_empty` | பூலியன் | `completed` என்பது `missing`; `expected_empty` என்பது `limited_expected_empty`. |
| `observed` | சரங்களின் வரிசை | கான்கிரீட் தக்கவைக்கப்பட்டது facts/counts/statuses. |
| `interpretation` | சரங்களின் வரிசை | எச்சரிக்கையான அர்த்தம் ஆதாரத்திற்கு அளவீடு செய்யப்பட்டது. |
| `unknown` | சரங்களின் வரிசை | அடையாளம், வரலாறு, ஆதாரம் அல்லது சூழல் காணவில்லை. |
| `does_not_prove` | சரங்களின் வரிசை | ஆதாரங்களால் ஆதரிக்க முடியாத முடிவுகள். |
| `next_action` | சரம் | பாதுகாப்பான வரம்புக்குட்பட்ட ஆபரேட்டர் செயல். |
| `source_references` | சரங்களின் வரிசை | தனித்துவம் என வரிசைப்படுத்தப்பட்டது runtime/Saved குறிப்புகள். |
| `enforcement_authority` | பூலியன் | எப்போதும் தவறானது. ஒரு அறிக்கை எழுதுவதை ஒருபோதும் அங்கீகரிக்காது. |
| `output_paths` | இரண்டு சரங்கள் | JSON மற்றும் TXT ஜோடி எழுதுவதற்கு முன் சேர்க்கப்படும் பாதைகள். |

`coverage_status` என்பது உயர்மட்ட கணக்கியல் மட்டுமே. ஆதார பதிவுகள் தனித்தனியாக சொந்தம் `available`, `expected_empty`, `partial`, `deferred`, `unavailable`, `malformed`, `permission_denied`, மற்றும் `error`. பாதை ஆதாரம் தனித்தனியாக `full`, `limited_expected_empty`, மற்றும் `missing`; மதிப்புகள் இந்த எல்லைகளை கடக்காது.

பாதை நீட்டிப்புகள்:

- `server_status`: `scheduler_status`, `active_log_status`, மற்றும் `server_metrics`. அளவீடுகள் தற்போதைய சகாப்தத்தின் தொடக்கம், சமீபத்திய முடிக்கப்பட்ட வாக்கெடுப்பு நேர முத்திரை மற்றும் ஐடி, செயலில் உள்ள பிளேயர் எண்ணிக்கை, active/backup-log எண்ணிக்கைகள், ஸ்கேன் pending/progress மதிப்புகள் மற்றும் configured/usable/unavailable source-group accounting. எந்த ஆதாரமும் அந்த உண்மைகளை அம்பலப்படுத்தாத போது, ​​அவை இயக்க நேரம், மறுதொடக்கம் எண்ணிக்கை, காப்பு நேர முத்திரைகள் அல்லது செயலிழக்கும் காலம் ஆகியவற்றைக் கண்டுபிடிப்பதில்லை.
- `player_activity`: `player_activity_present`, `movement`, `same_day_sessions`, `current_player_count`, `current_evidence_player_count`, `historical_player_count`, `historical_session_count`, `current_players`, `historical_players`, மற்றும் பொருந்தக்கூடிய வரிசை `players`. ஒவ்வொரு அதே நாள் அமர்வும் அதன் அமர்வு ஐடி, கணக்கு ஐடி, காட்சிப் பெயர் தெரிந்தால், join/leave நேர முத்திரைகள், க்ளீன்-எக்ஸிட் மற்றும் லைஃப்சைக்கிள் கொடிகள் மற்றும் மூல குறிப்புகள். தக்கவைக்கப்பட்ட அடையாளம் மற்றும் PlayerData இருப்பு சூழலில் உள்ளது, இன்று செயல்பாட்டிற்கான ஆதாரம் அல்ல.
- `case_review`: `cases`, `review_subjects`, `current_case_count`, மற்றும் `retained_case_count`. தற்போதைய மதிப்பாய்வு பொருள் அதன் case/account ஐடி, தெரியும் போது காட்சி பெயர், நிலை, மதிப்பெண், அடையாள நம்பிக்கை, first/last கவனிப்பு, எச்சரிக்கை எண்ணிக்கைகள், காரணங்கள், தற்போதைய-நேரடி கொடி மற்றும் மூல குறிப்புகள். தக்கவைக்கப்பட்ட வழக்குகள் தானாக நடப்பு விஷயத்தை உருவாக்காது.
- `critical_guard`: `critical_failure_present` மற்றும் `current_boot_error_only=true`.
- `daily_rollup`: `daily_maturity`, `once_per_day_continuity`, `dedupe_window`, மற்றும் `daily_metrics`. அளவீடுகள் அறிக்கை தேதி, செயலில் உள்ள வீரர்கள், ஒரே நாளில் செயல்படும் கணக்குகள், சேருதல், வெளியேறுதல், சுத்தமான மற்றும் அசுத்தமான வெளியேறுதல், வாழ்க்கைச் சுழற்சி வருமானம், தற்போதைய பெயரிடப்பட்ட மதிப்பாய்வு பாடங்கள், தக்கவைக்கப்பட்ட வழக்குகள், current/retained அடையாள எண்ணிக்கைகள் மற்றும் மூல-குழு கவரேஜ்.

<a id="translated-txt-schema"></a>
## மொழிபெயர்க்கப்பட்டது TXT ஸ்கீமா

இணைக்கப்பட்ட உரைக் கோப்பு ஆபரேட்டர்-படிக்கக்கூடிய முடிவைக் கொண்டு செல்கிறது மற்றும் பரம்பரை விவரங்களை இறுதிவரை நகர்த்துகிறது. இது இந்த சரியான பிரிவு வரிசையை பாதுகாக்கிறது:

```text
RandomDayGuard <route title>
Generated: <timestamp>

Summary
<one plain-language route summary>

What Guard observed
- ...

What it means
- ...

What remains unknown
- ...

Recommended next step
...

Evidence boundary
- ...

Rating explanation
- ...

Technical record
- Route: <route>
- Version: <version>
- Cycle: boot=<boot> epoch=<epoch> poll=<poll>
- Source freshness: <status>
- Route result: <full|limited_expected_empty|missing>
- Coverage: <status>

Translation notes
- ...

Source references
- ...
```

மொழிபெயர்ப்பு கட்டமைக்கப்பட்ட அறிக்கைப் புலங்களையும் அங்கீகரிக்கப்பட்ட அகராதி மேப்பிங்குகளையும் மட்டுமே பயன்படுத்துகிறது. கட்டமைக்கப்பட்ட அறிக்கையில் இல்லாத வீரர்கள், வழக்குகள், டெலிவரி, காரணம், உரிமை, நோக்கம் அல்லது அமலாக்கத் தகுதி ஆகியவற்றைச் சேர்க்க முடியாது. படிக்கக்கூடிய முடிவை இடமாற்றம் செய்யாமல் தொழில்நுட்ப விவரங்கள் கிடைக்கும்.

## வழிச் சான்று திட்டம்

`runtime/final_logs/route_proof.json` பயன்படுத்துகிறது `randomdayguard.route-proof/v1` மற்றும் உயர்நிலை தலைமுறை நேர முத்திரை, பதிப்பு, துவக்கம், சகாப்தம், கருத்துக்கணிப்பு, மூல புத்துணர்ச்சி, தற்போதைய சுழற்சி முழுமை, அனுமதிக்கப்பட்ட நிலைகள் மற்றும் ஒரு `routes` அணிவரிசை.

ஒவ்வொரு வழி நுழைவிலும் route/status, version/boot/epoch/poll, source-freshness object, current-cycle completeness, output paths மற்றும் source references. முடக்கப்பட்ட பாதை பதிவுகள் `status="missing"` மற்றும் `reason="route_disabled"`. ரூட்-ப்ரூஃப் எழுதுவதில் தோல்வி ஏற்பட்டால், ஒவ்வொரு வழியும் incomplete/missing எந்த அறிவிப்பு வேட்பாளரையும் ஏற்கும் முன்.

<a id="notification-schemas"></a>
## அறிவிப்பு திட்டங்கள்

விருப்ப பொது பயன்முறையானது லோக்கல்-ஃபைல் அவுட்பாக்ஸ் மட்டுமே.

`runtime/notifications/pending/<route>_latest.json` பயன்படுத்துகிறது `randomdayguard.notification/v1` உருவாக்கப்பட்ட நேர முத்திரையுடன், version/boot/epoch/ poll/source புத்துணர்ச்சி, பாதை, `completed_output`, பாதை-ஆதார நிலை, கட்டமைக்கப்பட்ட மற்றும் மொழிபெயர்க்கப்பட்ட அறிக்கை பாதைகள், மூல குறிப்புகள், `delivery_backend="none"`, மற்றும் `delivery_attempted=false`. தகுதியான வெளியீடு பயன்பாடுகள் `status="ready_for_local_consumer"`, `delivery_eligible=true`, மற்றும் `delivery_allowed=true`. ஒரு கட்டமைக்கப்பட்ட ஆனால் missing/ineligible பாதை இன்னும் ஒரு தணிக்கை உறையை `status="suppressed_current_cycle"`, டெலிவரி கொடிகள் இரண்டும் தவறானவை மற்றும் `suppression_reason="route_or_completion_policy_blocked"`. எனவே `pending/` என்பது வரிசைப்படுத்தப்பட்ட அல்லது தகுதியானதைக் குறிக்காது.

`runtime/notifications/notification_status.json` பயன்படுத்துகிறது `randomdayguard.notification-status/v1` அதே பரம்பரையுடன், `generic_local_outbox_only=true`, `delivery_attempted=false`, மற்றும் per-route `queued`/`outcome` வரிசைகள். `full` தகுதியானது; எதிர்பார்க்கப்படும்-வெறுமை `include_expected_empty=true`; `missing` ஒருபோதும் தகுதி பெறாது. ரூட்-ப்ரூஃப் எழுதும் தோல்வியின் நிலை விளைவு `route_proof_write_failed`; ஒரு அடக்கப்பட்ட தணிக்கை உறை இன்னும் எழுதப்பட்டிருக்கலாம், ஆனால் அது வெளியீடாக ஏற்றுக்கொள்ளப்படவில்லை.

## தோல்வி மற்றும் மீட்பு அணி

| தோல்வி | தேவையான நிலை | பாதுகாப்பான மீட்பு | தவறான அனுமானம் |
|---|---|---|---|
| தற்போதைய பரம்பரை absent/stale | எல்லா வழிகளும் `missing`. | மீட்டமை active-log/current-poll ஆதாரம் மற்றும் மறுஉருவாக்கம். | பழைய வழி கோப்புகள் தற்போது முடிக்கப்படவில்லை. |
| விருப்ப ஆதாரம் காலியாக இருக்கும் என எதிர்பார்க்கப்படுகிறது | ஆதாரம் `expected_empty`; தகுதியான பாதை `limited_expected_empty`. | ஆதாரம் இல்லாதவரை பழுதுபார்க்க முடியாது. | காலியானது கிடைக்கவில்லை மற்றும் வரலாற்று இல்லாமையை நிரூபிக்கவில்லை. |
| ஸ்கேன் முழுமையடையவில்லை | ஆதாரம் `partial` அல்லது `deferred`. | வரையறுக்கப்பட்ட விண்ணப்பத்தை அனுமதி; தற்போதைய வழிக் கொள்கையை வெளிப்படையாக வைத்திருங்கள். | பகுதி என்பது ஊழல் அல்ல. |
| தேவையான ஆதாரம் கிடைக்கவில்லை | `coverage_status=unavailable`; சார்பு வழிகள் `missing`. | தேர்ந்தெடுக்கப்பட்ட பழுதுபார்ப்பு Saved/log அணுகல். | பிற ஆரோக்கியமான ஆதாரங்கள் தேவையான மூலத்தை மாற்றாது. |
| தேவையான மூல ஆய்வு பிழைகள் | மூல நிலை `error` வரம்புடன் `detail`; `coverage_status=unavailable`; சார்பு வழிகள் `missing`. | பெயரிடப்பட்டதை பழுதுபார்க்கவும் source/probe மற்றும் ஒரு புதிய சுழற்சியை உருவாக்கவும். | மூலப் பிழை என்பது ஐந்தாவது உயர்மட்ட கவரேஜ் மதிப்பு அல்ல. |
| இணைக்கப்பட்ட அறிக்கை எழுதுவதில் தோல்வி | `coverage_status=unavailable`; பாதை `missing`. | கோப்பு அமைப்பைச் சரிசெய்து, இரு ஜோடி உறுப்பினர்களையும் சேர்த்து ஆதாரத்தையும் மீண்டும் எழுதவும். | ஒரு உடன்பிறப்பு கோப்பு நிறைவுபெறவில்லை, எழுதுவதில் தோல்வி உயர்நிலை அல்ல `error`. |
