<a id="v0412-alpha"></a>
## v0.4.12-alpha

- تمت إضافة مجموعة بيانات الخادم المقيدة مع تغطية المصدر الواضحة وعدم اليقين.
- تمت إضافة حالة الخادم القابلة للقراءة، والمجموع اليومي، ونشاط اللاعب، ومراجعة الحالة، وتقارير الحراسة المهمة مع ملكية المسار الصارمة.
- تمت إضافة فصل هوية اللاعب الحالي والتاريخي، وملخصات الجلسة، ومراجع الأدلة، وحالات التقرير الفارغة المتوقعة.
- تمت الإضافة بشكل اختياري. Admin.ini التنفيذ مع حماية الحساب الموثوق به، والعتبات، والنسخ الاحتياطي، واكتشاف التغيير المتزامن، والقراءة، والتراجع.
-  تمت إضافة تكوين عام محمول، وتجاوز الجذر المحفوظ الدقيق، والمخرجات الكاملة ومراجع الأخطاء، وأمثلة للتقرير العملي.
- تمت إضافة مكتبة دليل كاملة باللغة الإنجليزية و27 صفحة إدخال مترجمة.
- تم التحقق من صحة حزمة الإصدار كتخطيط حتمي ومتعارف عليه UE4SS بدون تكوين خاص أو بيانات اعتماد التسليم أو بيانات وقت التشغيل.
