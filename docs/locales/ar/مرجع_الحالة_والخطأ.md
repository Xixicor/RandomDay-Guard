# مرجع الحالة والخطأ

> **المصدر الإنجليزي الأساسي:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). تحتفظ هذه الوثائق المترجمة بالأوامر والمسارات والمفاتيح وقيم الحالة والتجزئة وأسماء الملفات بشكل دقيق. إذا اختلفت الصياغة الفنية، استخدم المصدر باللغة الإنجليزية.


استخدم هذا المرجع بعد تصنيف أحد الأعراض في [استكشاف الأخطاء وإصلاحها](%D8%A7%D8%B3%D8%AA%D9%83%D8%B4%D8%A7%D9%81_%D8%A7%D9%84%D8%A3%D8%AE%D8%B7%D8%A7%D8%A1_%D9%88%D8%A5%D8%B5%D9%84%D8%A7%D8%AD%D9%87%D8%A7.md). اقرأ ملف الحالة المنظم المسمى بالخطأ. تمثل الرموز المميزة حالات السلامة ودورة الحياة المميزة؛ لا تقم بتجميعها في نتيجة عامة "فشل الحراسة".

<a id="route-and-source-states"></a>
## حالات المسار والمصدر

| القيمة | المعنى | استجابة المشغل |
|---|---|---|
| `full` | تم إكمال عقد المسار مع إثبات مصدر الدورة الحالية. | اقرأ حدود دليل المسار؛ لا يوجد إصلاح ضمني. |
| `limited_expected_empty` | اكتمل المسار وأصبح النشاط المفقود مشروعًا لهذه الدورة. | لا ينبغي إنشاء أي حدث player/case اصطناعي. |
| `missing` | لا يوجد مخرجات مطلوبة، أو حقل النسب، أو دليل المصدر غائب. | افحص سبب المسار وحالة المصدر المسمى. |
| `available` | كان المصدر المحدد قابلاً للقراءة والاستخدام. | لا يوجد إجراء. |
| `expected_empty` | تم التحقق من المصدر ولم يكن به أي صفوف بشكل قانوني. | لا يوجد أي إجراء ما لم يكن النشاط متوقعًا بشكل مستقل. |
| `partial` / `complete_with_gaps` | يوجد دليل قابل للاستخدام، لكن فئات المصدر المسماة غير مكتملة. | اقتصر الاستنتاجات على الأدلة التي تم جمعها. |
| `deferred` | تتم جدولة العمل المحدود لفرصة عامل لاحقة. | تأكد من تقدم التقدم قبل تغيير التكوين. |
| `unavailable` | لم توفر البيئة المصدر. | سجل الحد؛ تصحيح فقط المسار الذي تم إثباته أو مشكلة الإذن. |
| `malformed` | كان المصدر قابلاً للقراءة ولكن فشل التحقق من الصحة الهيكلية. | احفظه وأصلح المصدر؛ لا تخمن. |
| `permission_denied` | المصدر موجود ولكن لا يمكن قراءته. | امنح فقط إذن القراءة الضيق المطلوب. |
| `error` | فشلت عملية التجميع للسبب المسجل. | احفظ الخطأ وقم بتشخيص تلك المرحلة. |

<a id="playerdata-and-inventory-codes"></a>
## PlayerData ورموز المخزون

| الكود | المعنى | الاستجابة الآمنة |
|---|---|---|
| `saved_root_unavailable` | لم يكن هناك جذر محفوظ تم التحقق منه متاحًا لخط الأنابيب العام. | صحيح `SavedRoot.txt` وأعد فحص مسبار المسار. |
| `unsafe_playerdata_root` | PlayerData تم حل الاكتشاف خارج النطاق المحفوظ المحدود. الجذر. | تصحيح المسار؛ لا تضعف الحدود أبدًا. |
| `playerdata_discovery_not_run` | لم يتم تشغيل عامل الاكتشاف المحدود بعد. | تحقق من تقدم المجدول والعامل. |
| `playerdata_discovery_read_failed:*` | تعذرت قراءة مخرجات الاكتشاف. | احتفظ بتفاصيل اللاحقة وتحقق من المخزون المحدود. الأمر. |
| `inventory_command_open_failed` | تعذر بدء عملية الجرد. | تحقق من أن وقت التشغيل يوفر جسر الأوامر الذي تم تكوينه. |
| `inventory_command_read_failed` | فشل إخراج المخزون أثناء القراءة. | احتفظ بالمخرجات الجزئية وأعد التشغيل فقط بعد إصلاح الخطأ الأساسي. |
| `inventory_command_close_failed` | اكتمل المخزون بدون نتيجة قريبة جديرة بالثقة. | تعامل مع المصدر على أنه غير مكتمل. |
| `identity_ledger_row_limit_exceeded` | تجاوز إدخال الهوية الدائمة حدود السلامة العامة. | أرشف دفتر الأستاذ ومراجعته؛ لا تقم باقتطاعها بصمت إلى دليل كامل. |

<a id="adminini-enforcement-codes"></a>
## Admin.ini رموز التنفيذ

جميع الرموز الموجودة في هذا القسم غير قابلة للفشل. إنهم لا يسمحون بالحظر اليدوي من تلقاء أنفسهم.

| الكود | المعنى | الاستجابة الآمنة |
|---|---|---|
| `admin_ini_write_disabled` / `admin_ini_disabled` | بوابات الكتابة الآمنة العامة معطلة. | متوقع في عملية المراجعة فقط. |
| `admin_ini_backup_disabled` / `backup_safety_gate_disabled` | سياسة النسخ الاحتياطي المطلوبة غير نشطة. | الإبقاء على تعطيل الكتابة. |
| `enforcement_disabled` / `ban_on_threshold_disabled` / `auto_ban_disabled` | تم إيقاف بوابة تنفيذ صريحة واحدة. | متوقع في الإعدادات الافتراضية للمراجعة العامة فقط؛ لا تعيد تفسير ذلك على أنه فشل في الكتابة. |
| `review_only_mode_enabled` | يمنع وضع المراجعة فقط الطفرة عمدًا. | مراجعة الأدلة فقط. |
| `duplicate_prevention_disabled` | تم تعطيل الحماية المكررة. | احتفظ بتعطيل الكتابة حتى تتم استعادة بوابة الأمان. |
| `readback_safety_gate_disabled` / `rollback_safety_gate_disabled` | التحقق بعد الكتابة أو تم تعطيل الحماية من التراجع. | استمر في تعطيل الكتابة؛ لا تتجاوز هذه البوابات أبدًا. |
| `clean_id_safety_gate_disabled` / `account_specific_evidence_gate_disabled` | تم تعطيل فرض الهوية النظيفة أو الأدلة الخاصة بالحساب. | قم باستعادة البوابة قبل أي اختبار تنفيذ. |
| `moderator_preservation_disabled` / `existing_ban_preservation_disabled` | تم تعطيل الحساب المحمي أو الاحتفاظ بالحظر الحالي. | الإبقاء على تعطيل الكتابة. |
| `clean_numeric_identity_required` | المعرف المقترح ليس نموذج الاتصال المقبول الكامل أو المعرف الرقمي النظيف. | الحصول على رسم خرائط تم التحقق منه؛ لا تقم مطلقًا باقتطاع بادئة عشوائية. |
| `identity_strength_below_minimum` | دليل الهوية أضعف من الحد الذي تم تكوينه. | مراجعة الأدلة فقط. |
| `playerdata_verification_required` | يتطلب التكوين تأكيدًا PlayerData ولا يحتوي الحساب عليه. | احتفظ بمراجعة المرشح فقط؛ لا تستنتج الملكية من اسم ملف. |
| `trusted_or_moderator_identity` | الحساب محمي بواسطة حالة موثوق بها أو وسيط. | غير مسموح بالكتابة. |
| `admin_ini_path_invalid` / `admin_ini_path_outside_saved_root` | المسار الهدف غير صالح أو يفلت من الجذر المحفوظ. | التكوين الصحيح؛ لا تتجاوز أبدًا حارس المسار. |
| `admin_ini_unavailable` | لم يتم العثور على تكوين قابل للقراءة Admin.ini داخل الجذر المحفوظ. | قم بتصحيح المسار المحدود أو اترك التنفيذ معطلاً. |
| `admin_ini_read_failed` | تعذرت قراءة البايتات الموثوقة. | توقف قبل التغيير. |
| `admin_ini_parse_failed` | Admin.ini فشل التحقق من الصحة بدون تعليمات برمجية هيكلية أكثر تحديدًا. | احتفظ بالملف وافحص بنية القسم والخط. |
| `admin_ini_contains_nul` | يحتوي الملف على NUL بايت ولا يتم قبوله كنص. | احفظ الملف وأصلحه خارج Guard. |
| `admin_ini_duplicate_banned_players_section` | يوجد أكثر من قسم `[BannedPlayers]`. | دمج الأقسام يدويًا أثناء التوقف. |
| `admin_ini_banned_player_outside_section` | يظهر صف الحظر بالخارج `[BannedPlayers]`. | قم بتصحيح التخطيط يدويًا. |
| `admin_ini_invalid_banned_player_line` | خط الحظر ليس بالضبط صف معرف نظيف مدعوم. | قم بتصحيح الخط التالف. |
| `admin_ini_backup_failed` | لم تقم النسخة الاحتياطية الفريدة بكتابة وقراءة البايت بشكل متطابق. | غير مسموح بإجراء أي تغيير. |
| `admin_ini_external_change_detected` | قام كاتب آخر بتغيير الملف بعد الحرس لقطة. | احتفظ بالبايتات الخارجية وأعد المحاولة فقط بعد تنسيق الكتاب. |
| `atomic_rename_unavailable` | تم طلب الاستبدال الذري ولكن Lua لم تقدم `os.rename`. | لم يتم الوثوق بالكتابة؛ استخدم وقت تشغيل مدعومًا أو استمر في تعطيل التنفيذ. |
| `admin_ini_write_failed` | لم يكتمل الاستبدال المتحكم فيه. | افحص خطأ الاستبدال المسجل والنسخ الاحتياطي. |
| `post_write_verification_failed` | لم تساوي بايتات الإنتاج المرشح. | تحقق من `rollback_success` و `rollback_refused_external_change` قبل أي إجراء. |

<a id="startup-scheduler-and-backlog-states"></a>
## حالات بدء التشغيل والمجدولة والتراكم

هذه القيم هي دليل على دورة الحياة، وليست دليلاً على المسار. اقرأها باستخدام ملفات الاستقصاء الحالية وعامل التقرير وملفات دليل التوجيه.

| القيمة | المعنى | الاستجابة الآمنة |
|---|---|---|
| `not_started` | لم تبدأ مرحلة بدء التشغيل أو الجدولة المحددة. | أثناء التشغيل، انتظر الفاصل الزمني الموثق؛ بعد ذلك، قم بفحص المرحلة الأولى التي لم تتغير. |
| `main_lua_loaded` / `starting` | تم تشغيل المُحمل الأساسي ودخل Guard في بدء التشغيل. | تابع إلى المراحل اللاحقة؛ هذا وحده ليس جاهزًا. |
| `saved_root_found` / `log_tail_initialized` / `epoch_started` | المصدر الأساسي وتهيئة الاستمرارية متقدمة. | لا يوجد إجراء ما لم تتوقف المرحلة التالية عن التقدم. |
| `admin_state_written` / `playerdata_index_written` | تم تصدير الفهارس المحدودة الأولية. | لا يوجد إجراء؛ يجب أن تستمر عملية تسليم المجدول. |
| `watchdog_started` | تم تسجيل التقرير ومراقبة الاستطلاع. | تأكد من تقدم المجدول والاستقصاء بعد ذلك. |
| `ready_degraded` / `scan_running` | يتم تشغيل الحراسة بينما يظل الفحص التاريخي المحدود معلقًا. | الحذر، وليس الفشل؛ تحقق من تقدم عدادات التقدم. |
| `ready` | وصل بدء التشغيل والفحص المحدد الحالي إلى حالة الاستعداد. | تحقق من دليل المسار بشكل منفصل. |
| `scan_failed` / `error` | تم إنهاء بدء التشغيل أو الفحص مع وجود خطأ مسجل. | احتفظ بالخطأ المسمى أو ملف الحالة وقم بتشخيص تلك المرحلة. |
| `running` |  يمتلك المجدول فرص الاستطلاع المستقبلية. | تأكيد `poll_id` و `poll_completed_count` مقدمًا. |
| `manual_only` | لم تكن جدولة الحلقات متاحة؛ يمكن تشغيل العمل الصريح فقط. | تعامل مع العملية غير المراقبة على أنها غير متاحة. |
| `stopped` | انتهت عملية الجدولة. | افحص دليل التوقف والخطأ السابق قبل إعادة التشغيل. |
| `active_log_caught_up` | لم يتبق أي تراكم للسجل النشط غير المقروء. | قد يستمر الفحص التاريخي. |
| `active_log_unavailable_nonblocking` | السجل النشط كان غائبًا، لكن بدء التشغيل ظل غير محظور. | سجل حد المصدر وتحقق من المصادر الأخرى. |
| `active_log_read_failed` | السجل النشط موجود ولكن لا يمكن قراءته. | احتفظ بالخطأ وصحح فقط المسار الذي تم إثباته أو مشكلة الإذن. |
| `budget_exhausted` / `active_log_has_unread_bytes` | توقف التمرير الخلفي المحدود مع بقاء الأعمال المتراكمة. | تأكد من أن الاستطلاعات اللاحقة تقلل عدد غير المقروء. |
| `offset_commit_failed_after_events_applied` | تمت معالجة الأحداث ولكن فشل استمرار إزاحة السجل الدائم. | تم تأجيل الإنفاذ؛ قم بإصلاح تخزين الأوفست قبل الاعتماد على دورة أخرى. |

<a id="scheduler-report-and-notification-codes"></a>
## أكواد المجدول والتقرير والإشعارات

| الكود أو الحالة | المعنى | الاستجابة الآمنة |
|---|---|---|
| `poll already in flight` | وصل رد اتصال ثانٍ بينما كان الاستقصاء الحالي يمتلك دورة الحياة. | تأكد من تقدم الاستقصاء الحالي؛ لا تقم بإضافة مالك حلقة آخر. |
| `no_log_files_found` | لم يتم اكتشاف أي سجل نشط أو احتياطي تم تكوينه. | تحقق من تكوين الجذر المحفوظ والمصدر. |
| `current_poll_error` | سجلت الدورة الحالية فشل استقصاء المصدر. | اقرأ `runtime/current/poll_error.json`. |
| `cadence_deferred` | مرسل الإكمال ليس مستحقًا بعد. | متوقع حتى الفرصة المحدودة التالية. |
| `reports_disabled` | تم تعطيل إنشاء التقرير العام. | تمكين فقط إذا كانت التقارير مقصودة. |
| `local_outbox_write_failed` | تعذرت كتابة مظروف محلي مترجم. | أصلح دليل إخراج وقت التشغيل؛ وهذا ليس خطأ في نقل الإشعارات. |
| `source_accounting_disabled` | لا يمكن لدليل المسار المطالبة بتغطية المصدر الكاملة. | قم بتمكين حساب المصدر أو قبول الدليل المفقود بشكل صريح. |
| `route_disabled` | تم تعطيل المسار عمدًا. | لا يتوقع تسليم هذا المسار. |
| `poll_owner_between_polls` | يتم وضع عامل التقرير في قائمة الانتظار للفجوة المملوكة للمجدول بين الاستطلاعات. | متوقع فقط أثناء استمرار تقدم الطوابع الزمنية والمؤشرات. |
| `unsafe_shell_path` | فشل المخزون المحدود أو مسار الصدفة في التحقق الآمن من النظام الأساسي. | قم بتصحيح المسار؛ لا تضعف أبدًا عملية الاقتباس أو التحقق من صحة المسار. |
