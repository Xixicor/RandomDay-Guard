# ملفات تعريف التكوين

> **المصدر الإنجليزي الأساسي:** [CONFIG_PROFILES.md](../../CONFIG_PROFILES.md). تحتفظ هذه الوثائق المترجمة بالأوامر والمسارات والمفاتيح وقيم الحالة والتجزئة وأسماء الملفات بشكل دقيق. إذا اختلفت الصياغة الفنية، استخدم المصدر باللغة الإنجليزية.


استخدم دليل الإرشادات هذا لاختيار ملف تعريف تكوين عملي وتطبيقه. للحصول على شرح لكيفية تفاعل مجموعات الإعدادات، اقرأ [`CONFIG_REFERENCE.md`](%D9%85%D8%B1%D8%AC%D8%B9_%D8%A7%D9%84%D8%AA%D9%83%D9%88%D9%8A%D9%86.md). بالنسبة للحقول والافتراضيات والأنواع والمتغيرات الدقيقة، استخدم [`CONFIG_FIELD_CATALOG.md`](%D9%83%D8%AA%D8%A7%D9%84%D9%88%D8%AC_%D8%AD%D9%82%D9%88%D9%84_%D8%A7%D9%84%D8%AA%D9%83%D9%88%D9%8A%D9%86.md).

كل كتلة Lua أدناه عبارة عن مجموعة من إدخالات المستوى الأعلى التي يمكن أن تحل محل الإدخالات المطابقة داخل `return { ... }` الذي تم شحنه.

<a id="profile-chooser"></a>
## منتقي الملف الشخصي

| الموقف | استخدم ملف التعريف هذا |
|---|---|
| التثبيت الأول | التثبيت الأول الآمن |
| الخادم غير مستقر ويتعطل كثيرًا | الأدلة الحالية دون فحص بطيء |
| تريد object/world السياق | كامل خط الأساس |
| تريد مراجعة السجلات القديمة | ردم الطب الشرعي |
| تريد توصيات ولكن بدون كتابة | اختبار الإنفاذ |
| أنت على استعداد للسماح للحارس بكتابة أوامر الحظر | التنفيذ ممكّن |
| القرص محدود | نمو القرص منخفض |
| لقد أكملت خط أساس نظيف | إعداد النسخ الاحتياطي الثابت |

<a id="safe-first-install"></a>
## التثبيت الأول الآمن

استخدم هذا أولاً على خادم مباشر.

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

log_tail = {
    enabled = true,
    start_at_end_on_first_run = true,
    tail_backup_logs = false,
},

scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

ما يفعله هذا:

```text
Tracks live sessions.
Starts the baseline scan.
Does not edit Admin.ini.
Avoids treating old backup logs as fresh live events.
```

<a id="current-evidence-without-slow-scan"></a>
## الأدلة الحالية دون فحص بطيء

استخدم هذا إذا كان الخادم غير مستقر وتحتاج إلى crash/reconnect دليل قبل الفحص المكثف.

```lua
log_tail = {
    enabled = true,
},

scanning = {
    full_scan_on_start = false,
},

enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

ما يفعله هذا:

```text
Tracks logins, joins, leaves, reconnects, crashes, and unclean sessions.
Delays heavy world scanning.
```

<a id="full-baseline"></a>
## كامل خط الأساس

استخدم هذا بعد أن يظل الخادم نشطًا لفترة كافية لإجراء الفحص.

```lua
scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},
```

ما يفعله هذا:

```text
Builds object registry.
Writes world-state context.
Creates file manifest.
Enables changed-file refresh later.
```

<a id="forensic-backfill"></a>
## ردم الطب الشرعي

استخدم هذا فقط عند مراجعة السجلات التاريخية عمدًا.

```lua
log_tail = {
    start_at_end_on_first_run = false,
    tail_backup_logs = true,
    backfill_backup_logs_on_start = true,
},
```

قبل استخدامه:

```text
Back up runtime/log_offsets.tsv.
Expect old events to be reprocessed.
Return to live settings when finished.
```

<a id="enforcement-testing"></a>
## اختبار الإنفاذ

استخدم هذا قبل الكتابة الفعلية Admin.ini.

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},
```

ما يجب فحصه:

```text
runtime/account_evidence.json
runtime/warnings/
runtime/forensic_days/YYYY-MM-DD/ban_recommendations.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="enforcement-enabled"></a>
## التنفيذ ممكّن

استخدم هذا فقط بعد أن تكون نتائج المراجعة صحيحة.

```lua
enforcement = {
    review_only_mode = false,
    auto_ban = true,
    write_admin_ini = true,
    require_clean_ban_id = true,
    preserve_existing_bans = true,
    preserve_moderators = true,
},
```

قبل التمكين:

```text
Trusted IDs are configured.
Moderator IDs are preserved.
Admin.ini backups work.
Ban recommendations are understandable.
Thresholds are accepted by the server owner.
```

<a id="low-disk-growth"></a>
## نمو القرص منخفض

استخدم هذا عندما تنمو ملفات وقت التشغيل بسرعة كبيرة جدًا.

```lua
logging = {
    low_importance_mode = "aggregate",
    write_low_importance_raw_events = false,
},

retention = {
    detailed_retention_days = 7,
    rotate_jsonl_when_bytes_exceed = 5242880,
    max_raw_events_lines = 20000,
    compact_json_outputs = true,
},
```

<a id="sticky-backup-setup"></a>
## إعداد النسخ الاحتياطي الثابت

استخدمه بعد أول خط أساس مكتمل.

تحقق من وجودها:

```text
runtime/scan_complete.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
runtime/world_state/current/world_state_latest.json
```

ثم قم بعمل نسخة احتياطية منها باستخدام `config.lua`, `SavedRoot.txt` الحالي و`Admin.ini`.
