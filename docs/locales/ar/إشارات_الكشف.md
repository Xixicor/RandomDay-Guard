# إشارات الكشف

> **المصدر الإنجليزي الأساسي:** [DETECTION_SIGNALS.md](../../DETECTION_SIGNALS.md). تحتفظ هذه الوثائق المترجمة بالأوامر والمسارات والمفاتيح وقيم الحالة والتجزئة وأسماء الملفات بشكل دقيق. إذا اختلفت الصياغة الفنية، استخدم المصدر باللغة الإنجليزية.


الإشارات هي مدخلات مراجعة، وليست اتهامات تلقائية.

<a id="signal-table"></a>
## جدول الإشارات

| الإشارة | المعنى | أقوى عندما... | غير كافية في حد ذاتها |
|---|---|---|---|
| هوية تسجيل الدخول | تعيين الاسم لمعرف الحساب | معرف الاتصال موجود | الحظر |
| المغادرة النظيفة | إغلاق عادي للجلسة | الانضمام وترك المباراة | الاشتباه |
| إعادة الاتصال السريع | Churn/probing السياق | يتكرر بسرعة | الحظر |
| قطع الاتصال غير النظيف | لم يتم إغلاق الجلسة بشكل سليم | التكرار أو التداخل في الأعطال | الحظر |
| تداخل الأعطال | الحساب نشط على وشك التعطل | يتكرر نفس الحساب | الحظر |
| الإرجاع بعد التعطل | إرجاع الحساب بعد إعادة التشغيل | يتكرر عبر العصور | الحظر بواسطة حدث واحد |
| دفعة تحذيرية | نافذة تحذير الخادم | تتداخل الجلسات المعينة | الحظر بواسطة دفعة واحدة |
| الممثل حفظ اللمس | حفظ السياق العالمي | يرتبط بالجلسات | إثبات use/theft |
| تغيير دلتا الكائن | World/class | يرتبط بالجلسات | الحظر من العد وحده |
| Raid الحالة | مجموعة الحسابات المتعددة | يتكرر الحساب المركزي | الحظر الشامل لجميع الحسابات |

<a id="login-identity"></a>
## هوية تسجيل الدخول

أفضل مصدر:

```text
Login request
Name=
ConnectID=
UniqueId=
```

استخدمها للتخطيط:

```text
display/log name -> account_id -> ban_id
```

<a id="rapid-reconnect"></a>
## إعادة الاتصال السريع

النمط:

```text
join -> leave -> join -> leave -> join
```

استخدمها للمراجعة عند التكرار.

السلامة:

```text
churn_alone_never_bans = true
```

<a id="crash-overlap-and-post-crash-return"></a>
## تداخل الأعطال وعودة ما بعد الحادث

النمط:

```text
account active before crash
server restarts
same account returns quickly
```

استخدم للمراجعة عند تكرارها عبر العصور.

السلامة:

```text
single_crash_never_bans = true
```

<a id="warning-bursts"></a>
## دفعات تحذيرية

أمثلة:

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

استخدم كسياق حتى يتم ربطه بالجلسات والحدود المعينة.

<a id="actor-save-touch"></a>
## الممثل حفظ اللمس

المعنى:

```text
The server evidence referenced a class or actor.
```

لا يعني ذلك:

```text
A player opened it.
A player stole from it.
A player duplicated through it.
A player damaged it.
```

<a id="raid-cases"></a>
## حالات الغارة

تقوم حالة الغارة بتجميع الحسابات حسب التوقيت والنوافذ المشتركة.

القاعدة:

```text
Do not auto-ban every account in a raid case.
Each account needs account-specific evidence.
```
