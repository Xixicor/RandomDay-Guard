# مرجع مخطط الإخراج والحالة

> **المصدر الإنجليزي الأساسي:** [OUTPUT_SCHEMA_REFERENCE.md](../../OUTPUT_SCHEMA_REFERENCE.md). تحتفظ هذه الوثائق المترجمة بالأوامر والمسارات والمفاتيح وقيم الحالة والتجزئة وأسماء الملفات بشكل دقيق. إذا اختلفت الصياغة الفنية، استخدم المصدر باللغة الإنجليزية.


هذا هو العقد الأساسي للملفات التي تواجه المشغل والتي تم إنشاؤها. فهو يمتلك وحده مسارات الإخراج الدقيقة وأسماء الحقول والقيم المسموح بها ومتطلبات النسب ومخططات المسار. ترتبط الأدلة الإجرائية هنا بدلاً من إعادة تعريف تلك الحقائق.

يعتبر دليل وقت التشغيل موثوقًا؛ اسم الملف أو نبضات المجدول أو التقرير المترجم أو كائن البريد الصادر المحلي لا يثبت أكثر من الحقول والنسب الخاصة به.

<a id="public-report-routes"></a>
## مسارات التقرير العام

يمتلك عامل التقرير خمسة مسارات ضمن `runtime/final_logs/`:

| المسار | العقد | `full` متطلب | المعنى الفارغ المتوقع |
|---|---|---|---|
| `server_status` | المجدول الحالي، والسجل النشط، والفحص في انتظار المراجعة، وحالة تغطية المصدر. | يستبدل boot/epoch/poll النسب، والسجل النشط الجديد، accounting/history يكتب، وزوج JSON/TXT. | غير مستخدم لدورة تيار صحية؛ النسب المفقود هو `missing`. |
| `daily_rollup` | يستبدل day/window الاستمرارية عبر الخادم واللاعبين والحالات والمسح والتغطية. | محطة المحاسبة التاريخية كافية للمسار واكتمال إثبات الدورة الحالية. | لا يوجد لاعبون محتفظون ولا حالات مراجعة. |
| `player_activity` | فصل بين الحالي والتاريخي player/account الملاحظات. | إثبات الدورة الحالية بالإضافة إلى صف واحد أو أكثر current/historical. | لا توجد صفوف لاعب مؤهلة في المدخلات المحدودة؛ لا يوجد موضوع اصطناعي. |
| `case_review` | الحالات المُحتفظ بها المُسماة والمرشحون الحاليون review/BAN-ELIGIBLE. | إثبات الدورة الحالية بالإضافة إلى حالة مسماة واحدة أو أكثر مع مراجع المصدر. | لم تستوف أي حالة مسماة معايير المراجعة؛ لا توجد حالة اصطناعية. |
| `critical_guard` | فشل جدولة التمهيد الحالي، أو بدء التشغيل، أو الاستقصاء، أو فشل تكامل الأدلة. | إثبات الدورة الحالية بالإضافة إلى الفشل الحرج الحالي. | لا يوجد فشل حرج حالي؛ أخطاء النص القديمة لا تملك هذا المسار. |

يكتب كل مسار ممكن `<route>_latest.json` و `<route>_latest.txt`. لا يكتمل الزوج حتى `runtime/final_logs/route_proof.json` يسجل نفس الإصدار والتمهيد والعصر والاستقصاء وحداثة المصدر.

<a id="report-json-schema"></a>
## تقرير JSON مخطط

تمت إضافة جميع المسارات JSON تستخدم `schema="randomdayguard.report/v1"`.

| الحقل | النوع | المعنى والثابت |
|---|---|---|
| `schema` | السلسلة | بالضبط `randomdayguard.report/v1`. |
| `generated_ts`, `report_date` | السلسلة | الطابع الزمني للإنشاء وتاريخ التقرير. |
| `version` | السلسلة | Runtime/package هوية هذه الدورة. |
| `boot_id`, `epoch_id` | السلسلة | فترة تشغيل العملية الحالية واستمرارية الخادم. كلاهما مطلوب لإكماله. |
| `poll_id` | عدد صحيح | معرف الاستطلاع الحالي الإيجابي. Zero/missing لا يمكنه إكمال المسار. |
| `source_freshness` | الكائن | `status`, `checked_ts`، وحالة السجل النشط، والطابع الزمني لآخر استطلاع، والطابع الزمني لآخر استطلاع مكتمل. |
| `current_cycle_proof_complete` | منطقي | صحيح فقط عندما يتفق النسب والأدلة الحديثة active-log/current-poll. |
| `route` | التعداد | أحد الطرق الخمسة المذكورة أعلاه. |
| `route_proof_status` | التعداد | `full`, `limited_expected_empty`، أو `missing`. |
| `coverage_status` | التعداد | بالضبط `complete`, `complete_with_gaps`, `partial`، أو `unavailable`. |
| `completed`, `expected_empty` | منطقي | `completed` خطأ فقط بالنسبة إلى `missing`; `expected_empty` صحيح فقط بالنسبة إلى `limited_expected_empty`. |
| `observed` | صفيف السلاسل | الأشياء الملموسة المحتجزة facts/counts/statuses. |
| `interpretation` | صفيف السلاسل | المعنى الحذر الذي تمت معايرته وفقًا للأدلة. |
| `unknown` | صفيف السلاسل | الهوية أو التاريخ أو المصدر أو السياق المفقود. |
| `does_not_prove` | صفيف السلاسل | الاستنتاجات التي لا يمكن للأدلة دعمها. |
| `next_action` | السلسلة | إجراء المشغل الأكثر أمانًا. |
| `source_references` | صفيف السلاسل | مرتبة مراجع runtime/Saved الفريدة. |
| `enforcement_authority` | منطقي | خطأ دائمًا. لا يسمح التقرير أبدًا بالكتابة. |
| `output_paths` | سلسلتين | JSON و TXT قبل عمليات الكتابة المقترنة. |

`coverage_status` هي محاسبة المستوى الأعلى فقط. تمتلك سجلات المصدر بشكل منفصل `available`, `expected_empty`, `partial`, `deferred`, `unavailable`, `malformed`, `permission_denied` الحالي و`error`. يمتلك دليل المسار بشكل منفصل `full`, `limited_expected_empty` الحالي و`missing`; لا تتجاوز القيم هذه الحدود أبدًا.

امتدادات المسار:

- `server_status`: `scheduler_status`, `active_log_status` الحالي و`server_metrics`. تسجل المقاييس بداية العصر الحالي، وأحدث طابع زمني ومعرف استطلاع مكتمل، وعدد اللاعبين النشطين، وأعداد active/backup-log، ومسح pending/progress القيم، وconfigured/usable/unavailable حساب مجموعة المصدر. إنهم لا يخترعون وقت التشغيل، أو إعادة التشغيل، أو الطوابع الزمنية الاحتياطية، أو مدة الانقطاع عندما لا يكشف أي مصدر عن هذه الحقائق.
- `player_activity`: `player_activity_present`, `movement`, `same_day_sessions`, `current_player_count`, `current_evidence_player_count`, `historical_player_count`, `historical_session_count`, `current_players`, `historical_players`، ومصفوفة التوافق `players`. تحتفظ كل جلسة في نفس اليوم بمعرف الجلسة، ومعرف الحساب، واسم العرض عندما يكون معروفًا، join/leave الطوابع الزمنية وعلامات الخروج النظيف ودورة الحياة ومراجع المصدر. تظل الهوية المحتفظ بها وPlayerData هي السياق، وليس دليلاً على النشاط اليوم.
- `case_review`: `cases`, `review_subjects`, `current_case_count` الحالي و`retained_case_count`. يسجل موضوع المراجعة الحالي case/account معرّفه، واسم العرض عند معرفته، والحالة، والنتيجة، وثقة الهوية، first/last الملاحظة، وأعداد التحذيرات، والأسباب، والعلامة المباشرة الحالية، ومراجع المصدر. الحالات المحتجزة لا تؤدي إلى إنشاء موضوع حالي من تلقاء نفسها.
- `critical_guard`: `critical_failure_present` و `current_boot_error_only=true`.
- `daily_rollup`: `daily_maturity`, `once_per_day_continuity`, `dedupe_window` الحالي و`daily_metrics`. تسجل المقاييس تاريخ التقرير، واللاعبين النشطين، والحسابات ذات النشاط في نفس اليوم، وعمليات الانضمام، والمغادرة، والمخارج النظيفة وغير النظيفة، وإرجاع دورة الحياة، وموضوعات المراجعة المسماة الحالية، والحالات المحتجزة، current/retained أعداد الهوية، وتغطية مجموعة المصدر.

<a id="translated-txt-schema"></a>
## مترجم TXT مخطط

يؤدي الملف النصي المقترن إلى النتيجة التي يمكن للمشغل قراءتها وينقل السلالة التفاصيل حتى النهاية. ويحافظ على ترتيب الأقسام الدقيق هذا:

```text
RandomDayGuard <route title>
Generated: <timestamp>

Summary
<one plain-language route summary>

What Guard observed
- ...

What it means
- ...

What remains unknown
- ...

Recommended next step
...

Evidence boundary
- ...

Rating explanation
- ...

Technical record
- Route: <route>
- Version: <version>
- Cycle: boot=<boot> epoch=<epoch> poll=<poll>
- Source freshness: <status>
- Route result: <full|limited_expected_empty|missing>
- Coverage: <status>

Translation notes
- ...

Source references
- ...
```

تستخدم الترجمة فقط حقول التقارير المنظمة وتعيينات القاموس المعتمدة. ولا يمكنه إضافة لاعبين أو حالات أو تسليم أو سببية أو ملكية أو نية أو أهلية تنفيذ غائبة عن التقرير المنظم. تظل التفاصيل الفنية متاحة دون إزاحة النتيجة القابلة للقراءة.

<a id="source-accounting-schema"></a>
## مخطط محاسبة المصدر

`runtime/final_logs/source_accounting_latest.json` تستخدم `randomdayguard.source-accounting/v1` مع إنشاء reason/status, enablement/disabled السبب، current/historical التمييز، بيان الملف الذي تم تغييره، سجلات المصدر، usable/unavailable قوائم الفئات، وحد المطالبة.

يحتوي كل سجل مصدر على:

| الحقل | النوع | المعنى |
|---|---|---|
| `source_class` | السلسلة | واحدة من الفئات الثمانية أدناه. |
| `scope` | `current` أو `historical` | ملكية الوقت؛ لا يتم دمج النطاقات بصمت مطلقًا. |
| `required` | منطقي | مطلوب فقط `active_log` لحداثة مسار الدورة الحالية. |
| `status` | التعداد | نتيجة المصدر مدرجة أدناه. |
| `terminal` | منطقي | خطأ فقط لـ `partial` و `deferred`. |
| `available`, `readable` | منطقي | صحيح فقط لـ `available` و `expected_empty`. |
| `file_count` | عدد صحيح | عدد الحسابات المقيدة file/reference. |
| `source_references` | مصفوفة | المصدر الفريد المصنف paths/references. |
| `detail` | السلسلة | النتيجة المقيدة أو تفاصيل الخطأ. |
| `does_not_prove` | السلسلة | التوفر ليس نية أو ملكية أو ضرر أو تكرار أو إثبات تنفيذ. |

المصدر الطبقات:

| فئة المصدر | النطاق | ما تساهم به | ما لا يمكن إثباته |
|---|---|---|---|
| `active_log` | حالي، مطلوب | سجل خادم نشط قابل للقراءة ونسب استطلاع جديدة. | التاريخ الكامل أو ذنب اللاعب. |
| `admin_ini` | حالية، اختيارية | حالة حالية moderator/ban صالحة من الناحية الهيكلية، أو غياب متوقع. | سلوك اللاعب أو بيانات وصفية لسبب وجيه. |
| `recent_backup_logs` | تاريخية | سجل rotated/backup قابل للقراءة المراجع. | التواجد الحالي أو حالة التمهيد الحالية. |
| `playerdata_filenames` | السياق الحالي | مراجع أسماء الملفات القابلة للقراءة ضمن الجذر المحفوظ المحدد. | ملكية الملف، أو التواجد المباشر، أو محتوى الهوية، أو سوء السلوك. |
| `existing_cases` | تاريخية | تم الاحتفاظ بالحالة المسماة files/index السجلات التي تم التقاطها قبل المخرجات الحالية. | النشاط الحالي أو صحة الاستنتاجات القديمة. |
| `existing_reports` | تاريخية | تم الاحتفاظ final/forensic/warning بمراجع التقارير. | استبدال المصدر الرسمي. |
| `existing_evidence` | تاريخية | الأدلة المحفوظة المراجع. | اكتمال الأحداث التي لم يكشف عنها الخادم مطلقًا. |
| `world_save_scan` | تاريخية | حالة كاملة أو جزئية أو مؤجلة أو غير متاحة محددة scan/checkpoint. | إجراء لاعب محدد أو ملكيته. |

قيم حالة المصدر:

| الحالة | المحطة | معنى المشغل وإجراءاته |
|---|---:|---|
| `available` | نعم | يوجد مصدر مفيد يمكن قراءته؛ قم بمراجعة مراجعها. |
| `expected_empty` | نعم | تم التحقق من المصدر الاختياري وتأكد من صحته absent/empty. لا تخترع البيانات. |
| `partial` | لا | العمل المحدود أو حد المخزون غير مكتمل؛ السماح بالاستئناف. |
| `deferred` | لا | العمل معلق عمدًا؛ انتظر العامل المالك. |
| `unavailable` | نعم | Source/path/tool غائب أو غير صالح للاستخدام؛ يتم الإصلاح فقط إذا لزم الأمر بواسطة المسار. |
| `malformed` | نعم | فشل التحقق من صحة المحتوى من الناحية الهيكلية؛ احتفظ به وأصلح التنسيق. |
| `permission_denied` | نعم | تم رفض الوصول صراحةً؛ استعادة الوصول الأقل امتيازًا للقراءة. |
| `error` | نعم | فشل مستوى المصدر المحدود probe/read بشكل غير متوقع؛ افحص `detail` دون كشف الأسرار. |

المستوى الأعلى `coverage_status` هو بالضبط `complete`, `complete_with_gaps`, `partial`، أو `unavailable`. مستوى المصدر المطلوب `error`, `malformed`، أو `permission_denied` يصل إلى المستوى الأعلى `unavailable`; مستوى المصدر `deferred` يصل إلى المستوى الأعلى `partial`. يؤدي تعطيل حساب المصدر إلى استمرار كتابة حالة عدم توفر وإجبار كل مسار على الوصول إلى `missing`.

<a id="historical-status-schema"></a>
## مخطط الحالة التاريخية

`runtime/final_logs/historical_backfill_latest.json` تستخدم `randomdayguard.history/v1`: `generated_ts`، المحاسبة `status`, `resumable=true`, `changed_file_refresh=true`, `current_evidence_is_not_history=true`، ومصفوفة المحاسبة المصدر، والفئات غير المتاحة، و`next_action`.

`runtime/history/public_accounts.tsv` هو سجل عام دائم بهذا الرأس:

```text
account_id	ban_id	display_name	identity_confidence	status	score	first_seen	last_seen	source_references
```

يتم فرز الصفوف حسب معرف الحساب، وتكون الحقول single-line/tab-safe، والمراجع هي sorted/unique. يحافظ هذا الملف على السياق التاريخي عبر عمليات إعادة التشغيل الهادئة؛ فهو لا يحول التاريخ أبدًا إلى الوجود الحالي.

<a id="route-proof-schema"></a>
## مخطط إثبات المسار

`runtime/final_logs/route_proof.json` تستخدم `randomdayguard.route-proof/v1` ويسجل الطابع الزمني للإنشاء عالي المستوى، والإصدار، والتمهيد، والعصر، والاستقصاء، ونضارة المصدر، واكتمال الدورة الحالية، والحالات المسموح بها، و`routes` المصفوفة.

يحتوي كل إدخال مسار على route/status, version/boot/epoch/poll، وكائن حداثة المصدر، واكتمال الدورة الحالية، ومسارات الإخراج، ومراجع المصدر. سجلات المسار المعطل `status="missing"` و `reason="route_disabled"`. إذا فشلت كتابة إثبات المسار، تتم إعادة كتابة كل مسار كـ incomplete/missing قبل قبول أي إشعار مرشح.

<a id="notification-schemas"></a>
## مخططات الإشعارات

الوضع العام الاختياري هو صندوق الصادر للملفات المحلية فقط.

`runtime/notifications/pending/<route>_latest.json` تستخدم `randomdayguard.notification/v1` مع الطابع الزمني الذي تم إنشاؤه، version/boot/epoch/ poll/source الحداثة، المسار، `completed_output`، حالة مقاومة المسار، مسارات التقارير المنظمة والمترجمة، مراجع المصدر، `delivery_backend="none"` الحالي و`delivery_attempted=false`. استخدامات الإخراج المؤهلة `status="ready_for_local_consumer"`, `delivery_eligible=true` الحالي و`delivery_allowed=true`. تم تكوينه ولكن missing/ineligible لا يزال المسار يكتب مظروف تدقيق باستخدام `status="suppressed_current_cycle"`، وعلامتي التسليم false، و`suppression_reason="route_or_completion_policy_blocked"`. ولذلك فإن وجود ملف ضمن `pending/` لا يعني في حد ذاته أنه في قائمة الانتظار أو مؤهل.

`runtime/notifications/notification_status.json` تستخدم `randomdayguard.notification-status/v1` بنفس السلالة، `generic_local_outbox_only=true`, `delivery_attempted=false`، وفي كل مسار `queued`/`outcome` من الصفوف. `full` مؤهل؛ المتوقع-فارغ يكون مؤهلاً فقط عندما لا يكون `include_expected_empty=true`; `missing` مؤهلاً على الإطلاق. في حالة فشل الكتابة أثناء مقاومة المسار، تكون نتيجة الحالة هي `route_proof_write_failed`؛ قد يستمر كتابة مظروف التدقيق المحظور، لكن لا يتم قبوله كمخرجات.

<a id="runtime-output-inventory"></a>
## مخزون مخرجات وقت التشغيل

يحتوي فهرس إمكانية التتبع على صف جهاز واحد لكل مسار أو فئة ملف ديناميكي. يقوم هذا المخزون القابل للقراءة بتجميع الملفات حسب غرض المشغل.

| المسار أو النمط | Producer/trigger | السياسة والحالات المفيدة | Failure/recovery |
|---|---|---|---|
| `runtime/loader_probe.txt`, `runtime/loader_probe.json` | إدخال المُحمل. | بدء التشغيل المكتوب identity/probe. | المفقود لا يثبت التحميل؛ فحص UE4SS السجلات والتمكين. |
| `runtime/config_load_error.txt` | فشل تحميل التكوين. | خطأ فقط، يحافظ على السبب المحدود. | استعادة التكوين العام الصالح وإعادة التشغيل. |
| `runtime/saved_path_probe.json` | تحليل الجذر المحفوظ. | Candidate/readability المحدودة. | المجموعة `SavedRoot.txt` أو إصلاح عام المرشح. |
| `runtime/startup_status.json`, `runtime/startup_error.txt`, `runtime/current/startup_error.json` | دورة حياة بدء التشغيل. | أحدث خطأ في بدء التشغيل والتمهيد الحالي. | يمتلك التمهيد المطابق فقط الحالة الحرجة الحالية. |
| `runtime/runtime_version.json`, `runtime/runtime_capabilities.json`, `runtime/public_pipeline_status.json` | Startup/report التكامل. | أحدث version/capability/handoff. | يمنع الإصدار أو القدرة الانجراف مطالبات الإكمال. |

<a id="failure-and-recovery-matrix"></a>
## مصفوفة الفشل والاسترداد

| الفشل | الحالة المطلوبة | الاسترداد الآمن | استدلال غير صالح |
|---|---|---|---|
| النسب الحالي absent/stale | جميع المسارات `missing`. | استعادة active-log/current-poll يتم إثباتها وإعادة إنشائها. | ملفات المسار القديمة ليست مكتملة حاليًا. |
| يتوقع أن يكون المصدر الاختياري فارغًا | المصدر `expected_empty`; قد يكون المسار المؤهل `limited_expected_empty`. | لا يمكن إصلاحه ما لم يكن المصدر موجودًا. | الفارغ ليس غير متاح ولا يثبت الغياب التاريخي. |
| المسح غير مكتمل | المصدر `partial` أو `deferred`. | السماح بالاستئناف المحدود؛ إبقاء سياسة المسار الحالية واضحة. | الجزئي ليس تلفًا. |
| المصدر المطلوب غير متاح | `coverage_status=unavailable`; المسارات التابعة `missing`. | الإصلاح المحدد Saved/log الوصول. | لا تحل المصادر السليمة الأخرى محل المصدر المطلوب. |
| أخطاء فحص المصدر المطلوبة | حالة المصدر `error` مع حدود `detail`; `coverage_status=unavailable`; المسارات التابعة `missing`. | أصلح source/probe وأنشئ دورة أحدث. | خطأ المصدر ليس قيمة خامسة لتغطية المستوى الأعلى. |
| فشلت كتابة التقرير المقترن | `coverage_status=unavailable`; يتقارب المسار إلى `missing`. | إصلاح نظام الملفات وإعادة كتابة كلا العضوين الزوجيين بالإضافة إلى إثبات. | لم يكتمل أحد الملفات الشقيقة، وفشل الكتابة ليس في المستوى الأعلى `error`. |
| فشل الكتابة المقاومة للمسار | كل مسار تمت إعادة كتابته مفقود؛ لا يوجد صندوق صادر مؤهل؛ قد تتلقى المسارات التي تم تكوينها مغلفات التدقيق المحظورة. | قم بإصلاح الكتابة المقاومة للمسار وأعد إنشاء مخرجات الدورة نفسها. | تقرير ذو مظهر صالح JSON أو المظروف المحظور ليس دليلاً على المسار. |
| فشل كتابة الإشعارات | النتيجة `local_outbox_write_failed`. | إصلاح جذر الإخراج المحلي؛ إعادة الإنشاء من التقرير المكتمل. | لم يحدث أي تسليم خارجي. |
| Admin.ini فشل المعاملة | تم حظر التنفيذ باستخدام backup/write/readback/rollback المذكورة. | استعادة النسخة الاحتياطية التي تم التحقق منها؛ تظل للمراجعة فقط. | لا يمكن أن يبرر الحد أو التقرير تجاوز الاسترداد. |
