# FAQ

> **المصدر الإنجليزي الأساسي:** [FAQ.md](../../FAQ.md). تحتفظ هذه الوثائق المترجمة بالأوامر والمسارات والمفاتيح وقيم الحالة والتجزئة وأسماء الملفات بشكل دقيق. إذا اختلفت الصياغة الفنية، استخدم المصدر باللغة الإنجليزية.


<a id="is-randomdayguard-the-randomday-mod"></a>
## هل RandomDayGuard RandomDay Mod؟

لا. RandomDay يغير التعديل تجربة الخادم. RandomDayGuard يراقب طبقة أدلة الخادم.

<a id="does-live-defense-work-before-the-scan-completes"></a>
## هل يعمل الدفاع المباشر قبل اكتمال الفحص؟

نعم. يستخدم الدفاع المباشر السجلات وأحداث الجلسة. يعمل الفحص الأساسي على تحسين السياق لاحقًا.

<a id="why-can-the-first-scan-take-a-long-time"></a>
## لماذا يمكن أن يستغرق الفحص الأول وقتًا طويلاً؟

يبني الفحص الأول world/object السياق وبيانات الملف والبيانات الأساسية القابلة لإعادة الاستخدام.

<a id="what-do-i-check-first-after-startup"></a>
## ما الذي يجب أن أتحقق منه أولاً بعد بدء التشغيل؟

```text
runtime/current/poll_status.json
```

ابحث عن:

```text
scheduler_status=running
poll_id increasing
poll_in_flight=false
```

<a id="where-are-player-summaries"></a>
## أين ملخصات اللاعبين؟

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

<a id="where-is-the-daily-quick-review-package"></a>
## أين حزمة المراجعة السريعة اليومية؟

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

<a id="which-file-should-i-upload-for-fastest-review"></a>
## ما هو الملف الذي يجب أن أقوم بتحميله للمراجعة الأسرع؟

```text
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="can-it-write-bans-automatically"></a>
## هل يمكن كتابة الحظر تلقائيًا؟

فقط إذا تم تمكينه بشكل صريح.

الافتراضي:

```lua
review_only_mode = true
auto_ban = false
write_admin_ini = false
```

<a id="what-does-adminini-receive"></a>
## ما الذي يتلقاه Admin.ini؟

فقط:

```ini
BannedPlayer=<ID>
```

لا توجد أسماء أو تعليقات أو أسباب أو لاحقات.

<a id="is-a-display-name-enough-to-ban"></a>
## هل يكفي اسم العرض للحظر؟

لا. استخدم سجل الخادم `Login request` باستخدام `ConnectID` أو دليل خادم مكافئ.

<a id="can-one-crash-ban-someone"></a>
## هل يمكن لمرة واحدة حظر شخص ما؟

لا بشكل افتراضي.

<a id="can-object-count-alone-ban-someone"></a>
## هل يمكن لعدد الكائنات بمفرده أن يمنع شخصًا ما؟

لا بشكل افتراضي.

<a id="should-savedroottxt-point-to-the-world-folder"></a>
## هل يجب SavedRoot.txt الإشارة إلى المجلد العالمي؟

لا. قم بتوجيهه إلى `AbioticFactor/Saved`.

<a id="what-if-the-world-folder-changes"></a>
## ماذا لو تغير المجلد العالمي؟

تعامل معه باعتباره تغييرًا أساسيًا في الهوية. حافظ على خط الأساس القديم وابني خطًا جديدًا.
