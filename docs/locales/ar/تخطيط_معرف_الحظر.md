# تعيين معرف الحظر

> **المصدر الإنجليزي الأساسي:** [BAN_ID_MAPPING.md](../../BAN_ID_MAPPING.md). تحتفظ هذه الوثائق المترجمة بالأوامر والمسارات والمفاتيح وقيم الحالة والتجزئة وأسماء الملفات بشكل دقيق. إذا اختلفت الصياغة الفنية، استخدم المصدر باللغة الإنجليزية.


استخدم هذه الصفحة عند تحويل اسم لاعب إلى خط حظر `Admin.ini` آمن.

<a id="core-rule"></a>
## القاعدة الأساسية

اسم العرض ليس معرف حظر.

`Admin.ini` يستخدم:

```ini
BannedPlayer=<raw numeric player ID>
```

<a id="evidence-hierarchy"></a>
## التسلسل الهرمي للأدلة

| التصنيف | المصدر | الاستخدام |
|---:|---|---|
| 1 | سجل الخادم `Login request` | أفضل تعيين من الاسم إلى المعرف |
| 2 | `Player_<ID>.sav` | يؤكد المعرف موجود |
| 3 | سياق `Admin.ini` | سياق bans/moderators |
| 4 | الإخطار الخارجي أو نشاط لوحة الاستضافة | Time/name موجود فقط؛ ليس إثبات هوية |
| 5 | UE4SS focus/player الخطوط | Presence/context فقط |
| 6 | سجلات دورة حياة النظام أو الحاوية | سياق دورة حياة المضيف فقط؛ ليس دليلاً على الهوية |

<a id="extract-the-clean-id"></a>
## استخرج المعرف النظيف

مثال أولي:

```text
ConnectID=2535422284688820_+_|0002d07b...
```

نظيف `Admin.ini` القيمة:

```ini
BannedPlayer=2535422284688820
```

لا تلصق `_+_|...`.

<a id="verify-with-playerdata"></a>
## التحقق باستخدام PlayerData

تحقق من:

```text
Saved/SaveGames/Server/Worlds/<WorldName>/PlayerData/Player_<ID>.sav
```

المعنى:

```text
The ID exists in the world save.
```

الحدود:

```text
PlayerData may not prove the display name unless another source maps it.
```

<a id="when-not-to-ban"></a>
## متى لا يتم الحظر

لا تقم بتعيين معرف حظر عندما:

```text
the name only appears in an external notification
the name only appears in hosting-panel activity
UE4SS shows a name but no ConnectID
only system lifecycle or container logs exist
the ID is trusted or moderator
```
