# مفاهيم التكوين

> **المصدر الإنجليزي الأساسي:** [CONFIG_REFERENCE.md](../../CONFIG_REFERENCE.md). تحتفظ هذه الوثائق المترجمة بالأوامر والمسارات والمفاتيح وقيم الحالة والتجزئة وأسماء الملفات بشكل دقيق. إذا اختلفت الصياغة الفنية، استخدم المصدر باللغة الإنجليزية.


يصف هذا الشرح ما تتحكم فيه كل منطقة تكوين رئيسية، ومتى يتم تشغيلها، وكيفية تفاعلها مع الأدلة وبوابات الأمان. فهو لا يمتلك كتالوج الحقول أو إجراءات الملف الشخصي بالضبط.

للإعدادات المسبقة الموجهة نحو المهام وخطوات التغيير الآمن، استخدم [`CONFIG_PROFILES.md`](%D9%85%D9%84%D9%81%D8%A7%D8%AA_%D8%AA%D8%B9%D8%B1%D9%8A%D9%81_%D8%A7%D9%84%D8%AA%D9%83%D9%88%D9%8A%D9%86.md). لكل حقل مصدر محدد، افتراضي، نوع، ثابت، تأثير الإخراج، وقاعدة الاسترداد، استخدم [`CONFIG_FIELD_CATALOG.md`](%D9%83%D8%AA%D8%A7%D9%84%D9%88%D8%AC_%D8%AD%D9%82%D9%88%D9%84_%D8%A7%D9%84%D8%AA%D9%83%D9%88%D9%8A%D9%86.md) الذي تم إنشاؤه؛ يتطلب المدقق صفًا واحدًا هناك لكل `config.lua` حقل طرفي يتم شحنه.

<a id="top-level-safety"></a>
## أمان على أعلى مستوى

| الخيار | افتراضي | المعنى |
|---|---:|---|
| `enabled` | `true` | مفتاح رئيسي للحارس |
| `enforcement.review_only_mode` | `true` | Record/recommend فقط |
| `enforcement.auto_ban` | `false` | لا تحظر تلقائيًا بشكل افتراضي |
| `enforcement.write_admin_ini` | `false` | لا تكتب Admin.ini بشكل افتراضي |

احتفظ بها آمنة حتى يقوم مالك الخادم بمراجعة المخرجات.

<a id="saved"></a>
## `saved`

يتحكم في كيفية عثور الحارس على مجلد الخادم `Saved/` وعائلات الملفات التي يمكنه العثور عليها المسح الضوئي.

يستخدم عندما:

```text
Saved root auto-detection fails.
World folder changed.
Provider or container path is unusual.
```

التحقق:

```text
runtime/saved_path_probe.json
RandomDayGuard/SavedRoot.txt
```

القاعدة:

```text
SavedRoot.txt -> AbioticFactor/Saved
not -> Worlds/<WorldName>
```

<a id="log_tail"></a>
## `log_tail`

يتحكم في قراءة السجل المباشر.

خيارات مفيدة:

| الخيار | القيمة الآمنة | لماذا |
|---|---|---|
| `enabled` | `true` | مطلوب للدفاع المباشر |
| `start_at_end_on_first_run` | `true` | يتجنب السجلات القديمة كأحداث مباشرة |
| `tail_backup_logs` | `false` | السجلات الاحتياطية هي سجل، وليست حية |
| `max_lines_per_poll` | محدودة | تحافظ على استجابة حلقة الاستطلاع |

التحقق:

```text
runtime/log_offsets.tsv
runtime/evidence/session_events.jsonl
runtime/current/poll_status.json
```

<a id="runtime"></a>
## `runtime`

تتحكم في الاقتراع والميزانيات.

القاعدة الصحية الرئيسية:

```text
poll_id increases
poll_in_flight returns false
poll_scheduled is true
```

التحقق:

```text
runtime/current/poll_status.json
```

إذا `poll_id` يتوقف، هناك شيء ما يعوق الحلقة.

<a id="source_accounting"></a>
## `source_accounting`

يتحكم في تغطية مصدر الأدلة الصريحة ونطاقه.

| المفتاح | افتراضي | المعنى |
|---|---:|---|
| `enabled` | `true` | يكتب محاسبة المصدر لتقارير المسار العام. |
| `require_terminal_status` | `true` | يتطلب من كل مصدر الكشف عن محطة صريحة أو حالة غير كاملة. |
| `distinguish_current_from_historical` | `true` | يحافظ على فصل الأدلة الحالية والتاريخية. |
| `slow_world_scan_blocks_current_reports` | `false` | يسمح للتقارير الحالية بالإشارة إلى أن المسح العالمي المحدود مؤجل أو جزئي. |
| `changed_file_manifest` | مسار البيان الأساسي | المرجع المستخدم للمحاسبة historical/world المحدودة. |

حالات المصدر هي `available`, `expected_empty`, `partial`, `deferred`, `unavailable`, `malformed`, `permission_denied`، أو `error`.

الإعداد `source_accounting.enabled = false` لا يزيل مخرجات الحالة بصمت. لا يزال خط الأنابيب يكتب `runtime/final_logs/source_accounting_latest.json` باستخدام `enabled=false`, `status="unavailable"` الحالي و`disabled_reason="source_accounting_disabled"`. كما أنه يكتب سجل الحالة التاريخية مع المحاسبة غير المتاحة. نظرًا لأن محاسبة المصدر جزء من عقد التقرير، فإن كل مسار يفشل في الإغلاق على `missing`؛ لا يتم التعامل مع أي مسار على أنه مكتمل أثناء تعطيل المحاسبة.

<a id="reports"></a>
## `reports`

يتحكم في مسار إعداد التقارير المحلية العامة.

تعمل الإعدادات الافتراضية على تمكين جميع المسارات الخمسة والكتابة ضمن `runtime/final_logs`:

```text
server_status
daily_rollup
player_activity
case_review
critical_guard
```

يجب أن يكتب كل مسار مخرجات منظمة ومترجمة بالإضافة إلى إثبات في `route_proof.json`. يؤدي تعطيل المسار إلى إنتاج `missing` إثباتًا بدلاً من التظاهر بأنه مكتمل.

<a id="notification"></a>
## `notification`

صندوق الصادر للملف المحلي العام الاختياري. يتم تعطيله افتراضيًا ولا يرسل أي شيء إلى موفر خارجي.

الإعدادات الافتراضية:

```lua
notification = {
    enabled = false,
    mode = "local_file_outbox",
    include_expected_empty = false,
},
```

يتم تعطيل كل مسار إعلام بشكل افتراضي. عند تمكينه عمدًا، قد يستهلك البريد الصادر تقريرًا مترجمًا مكتملًا فقط بعد كتابة `route_proof.json`. الأدلة والتقارير المحلية لا تزال موثوقة. لا يعد التسليم ونقاط نهاية التسليم وبيانات الاعتماد والجسور الخاصة بالموفر جزءًا من عقد المراقبة العامة المستقلة.

<a id="scanning"></a>
## `scanning`

يتحكم في فحص خط الأساس وفحص البيانات وتحديث الملفات التي تم تغييرها.

يستخدم عندما:

```text
building first world baseline
resuming after crash
refreshing changed files later
```

التحقق:

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/scan_complete.json
runtime/baselines/file_manifest.tsv
```

إعدادات مهمة:

```lua
scanning = {
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
    changed_file_detection = true,
},
```

<a id="forensic_rollup"></a>
## `forensic_rollup`

يتحكم في حزمة التحميل اليومية السريعة والسجلات النهائية باللغة البسيطة.

المخرجات:

```text
runtime/current/forensic_today.json
runtime/current/forensic_today.md
runtime/current/forensic_today.txt
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

يستخدم عندما:

```text
You want one daily folder that summarizes what happened.
You want a plain-language TXT to upload for quick analysis.
```

التحقق:

```text
runtime/forensic_days/YYYY-MM-DD/forensic_day_summary.json
runtime/forensic_days/YYYY-MM-DD/players.tsv
runtime/forensic_days/YYYY-MM-DD/ban_recommendations.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

القاعدة:

```text
Daily summaries are rebuildable indexes.
Source evidence remains authoritative.
```

<a id="logging"></a>
## `logging`

يتحكم في حجم الأحداث والتجميع منخفض الأهمية.

يستخدم عندما:

```text
actor-touch events are noisy
raw event files grow too quickly
```

النمط الآمن:

```lua
logging = {
    low_importance_mode = "aggregate",
    write_low_importance_raw_events = false,
},
```

<a id="retention"></a>
## `retention`

يتحكم في مدة الاحتفاظ بالملفات ومتى يتم تدوير السجلات JSONL.

يستخدم عندما:

```text
disk usage grows too fast
you need more audit history
you need shorter live-history windows
```

خيارات مهمة:

```text
detailed_retention_days
rotate_jsonl_when_bytes_exceed
max_raw_events_lines
keep_enforced_forever
keep_evidence_forever
```

<a id="warning_bursts"></a>
## `warning_bursts`

تتحكم في اكتشاف نافذة التحذير.

أمثلة:

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

القاعدة:

```text
Warnings are context until correlated with mapped sessions and thresholds.
```

<a id="crash_correlation"></a>
## `crash_correlation`

عناصر التحكم المتكررة crash/reconnect المراجعة.

الإعدادات الافتراضية الآمنة:

```lua
crash_correlation = {
    single_crash_never_bans = true,
    require_same_account = true,
},
```

العدادات المفيدة:

```text
server_crash_overlap_count
post_crash_reconnect_count
unclean_disconnect_count
```

<a id="join_leave"></a>
## `join_leave`

يتحكم في تتبع الحركة والانضمام.

الافتراضي الآمن:

```lua
join_leave = {
    churn_alone_never_bans = true,
},
```

يستخدم من أجل:

```text
rapid reconnect loops
join waves
short-session patterns
```

<a id="raid_detection"></a>
## `raid_detection`

حسابات المجموعات النشطة في النوافذ ذات الصلة.

القاعدة:

```text
A raid case groups accounts for review.
It does not make every account guilty.
```

لا يزال كل حساب مفروض يحتاج إلى أدلة خاصة بالحساب.

<a id="object_registry"></a>
## `object_registry`

عناصر التحكم object/class استخراج الرمز المميز من الأدلة المحفوظة القابلة للقراءة.

المخرجات:

```text
runtime/object_registry_partial.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
```

القاعدة:

```text
Object/class context is not a ban reason by itself.
```

<a id="world_state"></a>
## `world_state`

عناصر التحكم boot/current/session لقطات من حالة العالم.

المخرجات:

```text
runtime/world_state/current/world_state_latest.json
runtime/world_state/sessions/<date>/<session_id>_<account_id>/
```

يستخدم لمراجعة الجلسة والسياق العالمي.

<a id="enforcement"></a>
## `enforcement`

يتحكم في التوصيات والفعلية Admin.ini الكتابة.

قبل بإمكان Guard إضافة حظر، كل عبارة أدناه يجب أن تكون صحيحة:

```text
review_only_mode == false
auto_ban == true
write_admin_ini == true
ban_id is clean numeric
account identity is mapped
not trusted
not moderator
threshold is met
```

إذا كانت إحدى العبارات خاطئة أو لا يمكن التحقق منها، يترك Guard `Admin.ini` دون تغيير ويسجل السبب.

<a id="admin_ini"></a>
## `admin_ini`

يتحكم في عمليات كتابة الملفات الآمنة.

القواعد:

```text
Back up before writing.
Preserve existing bans.
Preserve moderators.
Write clean BannedPlayer=<ID> only.
```

<a id="restart_request"></a>
## `restart_request`

يتحكم في ملفات العلامات المحلية الاختيارية التي يقوم آخر قد يتم فحص العملية المملوكة للمشغل. ولا يؤدي إلى إعادة تشغيل الخادم أو إيقافه.

الإعدادات الافتراضية:

```lua
restart_request = {
    enabled = false,
    restart_marker_file = "runtime/request_restart.flag",
    restart_reason_file = "runtime/restart_reason.json",
},
```

المخرجات:

```text
runtime/request_restart.flag
runtime/restart_reason.json
```

لا يتم تجميع أي لوحة استضافة أو جسر موفر أو إعادة تشغيل تلقائية. لا يثبت تمكين إنشاء العلامة أن عملية خارجية استهلكت الطلب أو أعادت تشغيل الخادم.
