# المسرد

> **المصدر الإنجليزي الأساسي:** [GLOSSARY.md](../../GLOSSARY.md). تحتفظ هذه الوثائق المترجمة بالأوامر والمسارات والمفاتيح وقيم الحالة والتجزئة وأسماء الملفات بشكل دقيق. إذا اختلفت الصياغة الفنية، استخدم المصدر باللغة الإنجليزية.


| المصطلح | معنى عادي | المعنى الفني الدقيق |
|---|---|---|
| السجل النشط | سجل الخادم الحالي المستخدم للأدلة الجديدة. | المصدر المطلوب `active_log`؛ هناك حاجة إلى إمكانية القراءة بالإضافة إلى السلالة الحالية لإكمال المسار. |
| معرف التمهيد | بدء عملية مراقبة واحدة. | معرف وقت التشغيل الحالي المستخدم لرفض التمهيد السابق errors/reports. |
| معرف العصر | فاصل استمرارية خادم واحد. | معرف يمتد وقت التشغيل العادي حتى يبدأ منطق الاستمرارية حقبة أخرى. |
| معرف الاستطلاع | فرصة استطلاع محدودة واحدة. | حقل دورة رتيبة إيجابية؛ zero/missing لا يمكنه إكمال المسار. |
| حداثة المصدر | ما إذا كان المصدر الحالي ونسب الاستطلاع متفقين. | `fresh_current_poll` أو `stale_or_unproven` مع الطوابع الزمنية وحالة السجل النشط. |
| محاسبة المصدر | جرد توفر الأدلة والحدود. | `randomdayguard.source-accounting/v1` مع ثمانية فئات مصدر وcurrent/historical نطاق. |
| `available` | تم العثور على مصدر وقراءته. | حالة المصدر الطرفي مع `available=true`, `readable=true`. |
| `expected_empty` | تم فحص مصدر اختياري وبشكل شرعي absent/empty. | حالة المصدر الطرفي القابل للقراءة؛ لا تصنع موضوعًا أبدًا. |
| `partial` | للعمل المحدود نتائج مفيدة ولكنها غير مكتملة. | حالة source/accounting غير طرفية؛ استئناف العامل المالك. |
| `deferred` | العمل معلق عمدًا. | حالة المصدر غير الطرفي؛ ليس خطأ أو إكمال. |
| `unavailable` | لا يمكن استخدام المصدر حاليًا. | ثغرة طرفية؛ فجوة المصدر المطلوب تجعل المحاسبة غير متاحة. |
| `malformed` | المصدر موجود ولكنه غير صالح من الناحية الهيكلية. | ثغرة طرفية تحافظ على تفاصيل التحقق من الصحة وإغلاق عمليات الكتابة التابعة. |
| `permission_denied` | رفض نظام التشغيل الوصول بشكل صريح. | ثغرة طرفية مختلفة عن missing/unavailable. |
| `error` | فشلت عملية مقيدة بشكل غير متوقع. | فشل في المحطة الطرفية يتطلب الاسترداد المحدد؛ لا توجد تفاصيل سرية تنتمي إلى التقارير العامة. |
| `complete` | جميع المصادر المحاسبية نهائية ولا يوجد بها أي فجوة. | حالة المحاسبة المصدرية ذات المستوى الأعلى. |
| `complete_with_gaps` | الأدلة الحالية المطلوبة تعمل؛ لا تزال هناك فجوات نهائية اختيارية. | الحالة المحاسبية ذات المستوى الأعلى؛ لا تزال المسارات تطبق متطلباتها الخاصة. |
| `full` | مسار مكتمل بعقده المطلوب غير الفارغ. | تعداد إثبات المسار مع مخرجات الدورة الحالية المكتملة. |
| `limited_expected_empty` | مسار مكتمل ولم يتم العثور على أي مؤهل subject/failure. | تعداد إثبات المسار مع `completed=true`, `expected_empty=true`. |
| `missing` | إثبات إكمال المسار هو غائبة أو فاشلة. | تعداد إثبات المسار مع `completed=false`; غير مؤهل أبدًا للبريد الصادر. |
| التقرير المنظم | مخرج مسار يمكن قراءته بواسطة الآلة. | `<route>_latest.json` باستخدام `randomdayguard.report/v1`. |
| تقرير مترجم | عرض قابل للقراءة بواسطة الإنسان لنفس المسار. | `<route>_latest.txt` مع ترتيب ثابت من الملاحظة إلى المصدر. |
| إثبات المسار | دفتر الأستاذ للإكمال عبر المسار. | `route_proof.json` الربط version/boot/epoch/poll/freshness/output المقصودة. |
| الأدلة الحالية | الملاحظة المملوكة للدورة النشطة. | النطاق `current`; لم يتم إعادة بنائها من القديم filenames/reports. |
| الأدلة التاريخية | السياق المحتفظ به من الدورات السابقة أو الفحص البطيء. | النطاق `historical`; قد تبلغ المراجعة ولكن لا يمكنها المطالبة بالتواجد الحالي. |
| المراجعة فقط | قدم أدلة المراجعة بدون Admin.ini الكتابة. | الافتراضي `review_only_mode=true`, `auto_ban=false`, `write_admin_ini=false`. |
| فحص سلامة قائمة الحظر | سؤال واحد يجب على الحرس الإجابة عليه قبل أن يتغير `Admin.ini`. | يجب أن يؤكد الحساب والنتيجة، ويستبعد الحسابات الموثوقة والتكرارات، ويتحقق من النسخ الاحتياطي، ويكتشف التغييرات الخارجية، ويحفظ التحديث المقصود، ويتحقق من الملف الكامل أو يستعيده بأمان. |
| صندوق الصادر المحلي | تسليم إشعار اختياري محايد للموفر. | JSON مع الملفات التي تحتوي على `delivery_backend="none"` و `delivery_attempted=false`. |
| خط الأساس | سياق الملف المحفوظ المكتمل المكتمل لقطة. | Manifest/object/world لا يتم إعادة استخدام الحالة إلا عندما تكون متوافقة وحديثة بدرجة كافية. |
| نقطة التفتيش | استأنف الموضع بسبب أعمال المسح غير المكتملة. | `scan_checkpoint.json`; الحذف ليس هو الاسترداد الافتراضي. |
| الفهرس القابل لإعادة البناء | الملخص الذي يمكن إعادة إنشائه. | Daily/weekly/forensic/final مراجعة المخرجات؛ تظل الأدلة المصدرية موثوقة. |
| حدود الأدلة | تحدد ما يمكن أن يدعمه المصدر. | القواعد الصريحة `does_not_prove` والمجهولات وقوة الهوية وقواعد النطاق. |
