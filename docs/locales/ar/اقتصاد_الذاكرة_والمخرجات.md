<a id="memory-economy-and-output-files"></a>
# اقتصاد الذاكرة وملفات الإخراج

> **المصدر الإنجليزي الأساسي:** [MEMORY_ECONOMY_AND_OUTPUTS.md](../../MEMORY_ECONOMY_AND_OUTPUTS.md). تحتفظ هذه الوثائق المترجمة بالأوامر والمسارات والمفاتيح وقيم الحالة والتجزئة وأسماء الملفات بشكل دقيق. إذا اختلفت الصياغة الفنية، استخدم المصدر باللغة الإنجليزية.


تشرح هذه الصفحة الملفات التي تنمو، والملفات التي يتم الكتابة فوقها، وما يجب تحميله للمراجعة السريعة.

<a id="fast-answer"></a>
## إجابة سريعة

| سؤال | مفتوح |
|---|---|
| هل الحارس على قيد الحياة؟ | `runtime/current/poll_status.json` |
| من تمت رؤيته؟ | `runtime/account_evidence.json` |
| ماذا حدث للجلسات؟ | `runtime/evidence/session_events.jsonl` |
| ماذا حدث اليوم؟ | `runtime/forensic_days/YYYY-MM-DD/` |
| ما هو الملخص باللغة البسيطة؟ | `runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt` |
| ما هو تقدم الفحص؟ | `runtime/scan_progress.json` |
| ما هو السياق العالمي؟ | `runtime/world_state/current/world_state_latest.json` |
| ما هي عمليات الحظر التي تمت كتابتها؟ | `runtime/enforced_bans.jsonl` |

<a id="output-model"></a>
## نموذج الإخراج

| النوع | السلوك | أمثلة |
|---|---|---|
| اللقطات الحالية | تم الكتابة فوقها | `runtime/current/*.json` |
| سجلات الأحداث | إلحاق فقط | `runtime/evidence/*.jsonl` |
| الجداول | تم تحديثها أو إلحاقها | `*.tsv` |
| خطوط الأساس | إعادة استخدامها بعد الاكتمال | `runtime/baselines/*` |
| المجموعات اليومية | تم التحديث في مكانه | `runtime/forensic_days/YYYY-MM-DD/*` |
| السجلات النهائية | ملخص يومي بلغة مبسطة | `runtime/final_logs/YYYY-MM-DD/*` |

<a id="current-snapshots"></a>
## اللقطات الحالية

تظل هذه صغيرة وتجيب على "ما هو صحيح الآن".

```text
runtime/current/poll_status.json
runtime/current/session_state.json
runtime/current/active_accounts.json
runtime/current/forensic_today.json
runtime/current/forensic_today.md
runtime/current/forensic_today.txt
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/world_state/current/world_state_latest.json
```

<a id="player-summaries"></a>
## ملخصات اللاعب

هذه هي الملفات الأولى للتحقق من الحساب المراجعة.

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

تلخص ما يلي:

```text
account_id
ban_id
name
identity_confidence
first_seen
last_seen
join_count
leave_count
status
score
```

<a id="event-logs"></a>
## سجلات الأحداث

هذه تحافظ على الجدول الزمني.

```text
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/warning_events.jsonl
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/evidence/live_defense_events.jsonl
```

<a id="daily-forensic-rollups"></a>
## مجموعات الطب الشرعي اليومية

هذه هي حزم التحميل السريع.

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

قم بتحميل أحد هذه المجلدات عندما تريد تحليلًا سريعًا للفترة.

<a id="scan-and-baseline-files"></a>
## ملفات المسح والخط الأساسي

استخدمها لفهم ما إذا كان السياق العالمي جزئيًا أم كاملاً.

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/scan_complete.json
runtime/object_registry_partial.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
```

<a id="enforcement-files"></a>
## ملفات الإنفاذ

استخدمها فقط عند تمكين التنفيذ.

```text
runtime/enforced.txt
runtime/enforced_bans.jsonl
runtime/ban_queue.json
runtime/evidence/enforced_bans.jsonl
```

`Admin.ini` يجب أن يتلقى فقط:

```ini
BannedPlayer=<ID>
```

<a id="what-to-upload-for-quick-analysis"></a>
## ما يجب تحميله للتحليل السريع

أفضل حزمة:

```text
runtime/final_logs/YYYY-MM-DD/
```

أكثر اكتمالاً الحزمة:

```text
runtime/forensic_days/YYYY-MM-DD/
```

حزمة الأدلة الكاملة:

```text

runtime/evidence/session_events.jsonl
runtime/server_lifecycle_events.jsonl
runtime/warning_events.jsonl
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```
