# გამოვლენის სიგნალები

> **კანონიკური ინგლისური წყარო:** [DETECTION_SIGNALS.md](../../DETECTION_SIGNALS.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


სიგნალები არის მიმოხილვის შეყვანა და არა ავტომატური ბრალდებები.

<a id="signal-table"></a>
## სიგნალის ცხრილი

| სიგნალი | მნიშვნელობა | უფრო ძლიერია, როცა... | არ არის საკმარისი თავისთავად |
|---|---|---|---|
| შესვლის ვინაობა | რუქების სახელი ანგარიშის ID | ConnectID არის | აკრძალვა |
| სუფთა შვებულება | სესიის ნორმალური დახურვა | შეუერთდით და დატოვეთ მატჩი | ეჭვი |
| სწრაფი ხელახალი დაკავშირება | Churn/probing კონტექსტი | სწრაფად მეორდება | აკრძალვა |
| უწმინდური გათიშვა | სესია არ დაიხურა სუფთად | იმეორებს ან გადაფარავს ავარიებს | აკრძალვა |
| ავარიული გადახურვა | ანგარიში აქტიურია ავარიის დროს | იგივე ანგარიში მეორდება | აკრძალვა |
| ავარიის შემდეგ დაბრუნება | ანგარიში ბრუნდება გადატვირთვის შემდეგ | მეორდება ეპოქაში | აკრძალვა ერთი მოვლენით |
| გაფრთხილების აფეთქება | სერვერის გამაფრთხილებელი ფანჯარა | გადაფარავს შედგენილ სესიებს | აკრძალვა ერთი შეტევით |
| მსახიობის შეხება | მსოფლიოს შენახვის კონტექსტი | კორელაციაშია სესიებთან | დადასტურება use/theft |
| ობიექტის დელტა | World/class ცვლილება | კორელაციაშია სესიებთან | მხოლოდ დათვლის აკრძალვა |
| Raid case | მრავალ ანგარიშთა კლასტერი | ცენტრალური ანგარიში მეორდება | ყველა ანგარიშის მასობრივი აკრძალვა |

<a id="login-identity"></a>
## შესვლის ვინაობა

საუკეთესო წყარო:

```text
Login request
Name=
ConnectID=
UniqueId=
```

გამოიყენეთ რუკაზე:

```text
display/log name -> account_id -> ban_id
```

<a id="rapid-reconnect"></a>
## სწრაფი ხელახალი დაკავშირება

ნიმუში:

```text
join -> leave -> join -> leave -> join
```

გამოიყენეთ განსახილველად, როდესაც განმეორდება.

უსაფრთხოება:

```text
churn_alone_never_bans = true
```

<a id="crash-overlap-and-post-crash-return"></a>
## ავარიის გადახურვა და ავარიის შემდგომ დაბრუნება

ნიმუში:

```text
account active before crash
server restarts
same account returns quickly
```

გამოიყენეთ განსახილველად, როდესაც მეორდება ეპოქაში.

უსაფრთხოება:

```text
single_crash_never_bans = true
```

<a id="warning-bursts"></a>
## გაფრთხილების აფეთქება

მაგალითები:

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

გამოიყენეთ კონტექსტად მანამ, სანამ არ დაუკავშირდებით შედგენილ სესიებსა და ზღვრებს.

<a id="actor-save-touch"></a>
## მსახიობის შეხება

მნიშვნელობა:

```text
The server evidence referenced a class or actor.
```

არ ნიშნავს:

```text
A player opened it.
A player stole from it.
A player duplicated through it.
A player damaged it.
```

<a id="raid-cases"></a>
## რეიდის შემთხვევები

რეიდის შემთხვევა აჯგუფებს ანგარიშებს დროისა და გაზიარებული ფანჯრების მიხედვით.

წესი:

```text
Do not auto-ban every account in a raid case.
Each account needs account-specific evidence.
```
