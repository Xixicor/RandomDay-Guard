# RandomDayGuard დოკუმენტაცია

> **კანონიკური ინგლისური წყარო:** [README.md](../../README.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


RandomDayGuard კითხულობს ჩანაწერებს Abiotic Factor-ის გამოყოფილი სერვერიდან და აქცევს მათ ცალკეულ ანგარიშებად სერვერის ჯანმრთელობის, ყოველდღიური ისტორიის, მოთამაშის სესიების, მიმოხილვის შემთხვევებისა და დაცვის წარუმატებლობის შესახებ.
