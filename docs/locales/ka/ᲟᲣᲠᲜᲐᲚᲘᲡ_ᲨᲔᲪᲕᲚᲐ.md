# ცვლილებების ჟურნალი

> **კანონიკური ინგლისური წყარო:** [CHANGELOG.md](../../../CHANGELOG.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


<a id="v0412-alpha"></a>
## v0.4.12-alpha

- დაემატა შეზღუდული სერვერის მონაცემთა კოლექცია აშკარა წყაროს დაფარვით და გაურკვევლობით.
- დამატებულია იკითხებადი სერვერის სტატუსი, ყოველდღიური შეკრება, მოთამაშის აქტივობა, შემთხვევის განხილვა და კრიტიკული დაცვის ანგარიშები მარშრუტის მკაცრი მფლობელობით.
- დამატებულია მოთამაშის ამჟამინდელი და ისტორიული იდენტობის გამიჯვნა, სესიების შეჯამებები, მტკიცებულებების მითითებები და მოსალოდნელი-ცარიელი ანგარიშის მდგომარეობები.
- დამატებულია სურვილისამებრ Admin.ini აღსრულება სანდო ანგარიშის დაცვით, ზღვრებით, სარეზერვო ასლებით, ერთდროული ცვლილებების გამოვლენით, წაკითხვით და უკან დაბრუნებასთან ერთად.
- დაემატა პორტატული საჯარო კონფიგურაცია, ზუსტი Saved-root გადაფარვა, სრული გამომავალი და შეცდომების მითითებები და სამუშაო ანგარიშის მაგალითები.
- დაემატა ინგლისური სახელმძღვანელოს სრული ბიბლიოთეკა და 27 ლოკალიზებული შესვლის გვერდი.
- დაადასტურა გამოშვების პაკეტი, როგორც დეტერმინისტული, კანონიკური შემთხვევა UE4SS განლაგება პირადი კონფიგურაციის, მიწოდების სერთიფიკატების ან მუშაობის დროის მონაცემების გარეშე.
