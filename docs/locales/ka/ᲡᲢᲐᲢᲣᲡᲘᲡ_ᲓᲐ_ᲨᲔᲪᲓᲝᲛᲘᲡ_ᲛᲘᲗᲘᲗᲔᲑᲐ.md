# სტატუსისა და შეცდომის მითითება

> **კანონიკური ინგლისური წყარო:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


გამოიყენეთ ეს მითითება მას შემდეგ, რაც სიმპტომი კლასიფიცირებულია [პრობლემების აღმოფხვრა](%E1%B2%9E%E1%B2%A0%E1%B2%9D%E1%B2%91%E1%B2%9A%E1%B2%94%E1%B2%9B%E1%B2%94%E1%B2%91%E1%B2%98%E1%B2%A1_%E1%B2%90%E1%B2%A6%E1%B2%9B%E1%B2%9D%E1%B2%A4%E1%B2%AE%E1%B2%95%E1%B2%A0%E1%B2%90.md). წაიკითხეთ შეცდომით დასახელებული სტრუქტურირებული სტატუსის ფაილი. განსხვავებული კოდები წარმოადგენს უსაფრთხოებისა და სიცოცხლის ციკლის განსხვავებულ მდგომარეობას; არ დაშალოთ ისინი ზოგად "გვარდიის წარუმატებლობის" შედეგში.

## გაშვების, განრიგის და ჩამორჩენილი მდგომარეობები

ეს მნიშვნელობები სიცოცხლის ციკლის მტკიცებულებაა და არა მარშრუტის მტკიცებულება. წაიკითხეთ ისინი მიმდინარე გამოკითხვის, ანგარიშის მუშაკისა და მარშრუტის მტკიცებულების ფაილებით.

| მნიშვნელობა | მნიშვნელობა | უსაფრთხო პასუხი |
|---|---|---|
| `not_started` | დასახელებული გაშვების ან განრიგის ეტაპი არ დაწყებულა. | გაშვებისას დაელოდეთ დოკუმენტურ ინტერვალს; შემდეგ შეამოწმეთ პირველი უცვლელი ეტაპი. |
| `main_lua_loaded` / `starting` | კანონიკური ჩამტვირთველი გაიქცა და მცველი შევიდა გაშვებაში. | გაგრძელება შემდეგ ეტაპებზე; მარტო ეს არ არის მზადყოფნა. |
| `saved_root_found` / `log_tail_initialized` / `epoch_started` | ძირითადი წყაროს და უწყვეტობის ინიციალიზაცია გაუმჯობესებულია. | არავითარი ქმედება, თუ შემდეგი ეტაპი არ შეწყვეტს წინსვლას. |
| `admin_state_written` / `playerdata_index_written` | საწყისი შეზღუდული ინდექსები ექსპორტირებული იყო. | მოქმედების გარეშე; განრიგის გადაცემა მაინც უნდა მოჰყვეს. |
| `watchdog_started` | ანგარიშისა და გამოკითხვის დამკვირვებელი რეგისტრირებულია. | შემდეგ დაადასტურეთ განრიგის და გამოკითხვის პროგრესი. |
| `ready_degraded` / `scan_running` | Guard მუშაობს, სანამ შეზღუდული ისტორიული სკანირება მოლოდინის რეჟიმშია. | სიფრთხილე, არა წარუმატებლობა; შეამოწმეთ პროგრესის მრიცხველების წინსვლა. |
| `ready` | გაშვება და ამჟამინდელი შემოსაზღვრული სკანირება მზადაა. | შეამოწმეთ მარშრუტის მტკიცებულება ცალკე. |
| `scan_failed` / `error` | გაშვება ან სკანირება დასრულდა ჩაწერილი შეცდომით. | შეინახეთ დასახელებული შეცდომის ან სტატუსის ფაილი და დაადგინეთ ეს ეტაპი. |
| `running` | დაგეგმავი ფლობს მომავალ გამოკითხვის შესაძლებლობებს. | დაადასტურეთ `poll_id` და `poll_completed_count` წინასწარ. |
| `manual_only` | ციკლის დაგეგმვა მიუწვდომელი იყო; შესაძლებელია მხოლოდ ექსპლიციტური სამუშაოს შესრულება. | მიმართეთ უყურადღებო ოპერაციას, როგორც მიუწვდომელს. |
| `stopped` | დაგეგმარის ოპერაცია დასრულდა. | გადატვირთვამდე შეამოწმეთ წინა გაჩერებისა და შეცდომის მტკიცებულება. |
| `active_log_caught_up` | არ დარჩა წაუკითხავი აქტიური ჟურნალის ჩამორჩენა. | ისტორიული სკანირება შეიძლება გაგრძელდეს. |
| `active_log_unavailable_nonblocking` | აქტიური ჟურნალი არ იყო, მაგრამ გაშვება დაბლოკილი დარჩა. | ჩაწერეთ წყაროს ლიმიტი და გადაამოწმეთ სხვა წყაროები. |
| `active_log_read_failed` | აქტიური ჟურნალი არსებობდა, მაგრამ მისი წაკითხვა შეუძლებელია. | შეინარჩუნეთ შეცდომა და შეასწორეთ მხოლოდ დადასტურებული გზა ან ნებართვის პრობლემა. |
| `budget_exhausted` / `active_log_has_unread_bytes` | შეზღუდული კუდის საშვი შეჩერდა დარჩენილი ნაწილის გამო. | დაადასტურეთ, რომ მოგვიანებით გამოკითხვები შეამცირებს წაკითხულთა რაოდენობას. |
| `offset_commit_failed_after_events_applied` | მოვლენები დამუშავდა, მაგრამ გრძელვადიანი ჟურნალის ოფსეტური მდგრადობა ვერ მოხერხდა. | აღსრულება გადაიდო; ოფსეტური მეხსიერების შეკეთება სხვა ციკლზე დაყრდნობამდე. |

## დაგეგმარის, მოხსენების და შეტყობინების კოდები

| კოდი ან სტატუსი | მნიშვნელობა | უსაფრთხო პასუხი |
|---|---|---|
| `poll already in flight` | მოვიდა მეორე გამოძახება, სანამ მიმდინარე გამოკითხვა ეკუთვნოდა სიცოცხლის ციკლს. | დაადასტურეთ არსებული გამოკითხვის წინსვლა; არ დაამატოთ სხვა მარყუჟის მფლობელი. |
| `no_log_files_found` | კონფიგურირებული აქტიური ან სარეზერვო ჟურნალი არ არის ნაპოვნი. | დაადასტურეთ შენახული root და წყაროს კონფიგურაცია. |
| `current_poll_error` | მიმდინარე ციკლმა დააფიქსირა გამოკითხვის წყაროს მარცხი. | წაიკითხეთ `runtime/current/poll_error.json`. |
| `cadence_deferred` | დასრულების დისპეტჩერი ჯერ არ დასრულებულა. | მოსალოდნელია შემდეგ შეზღუდულ შესაძლებლობამდე. |
| `reports_disabled` | საჯარო ანგარიშის შექმნა გამორთულია. | ჩართეთ მხოლოდ იმ შემთხვევაში, თუ ანგარიშები განკუთვნილია. |
| `local_outbox_write_failed` | თარგმნილი ლოკალური კონვერტის დაწერა ვერ მოხერხდა. | გაშვების დროის გამომავალი კატალოგის შეკეთება; ეს არ არის შეტყობინების ტრანსპორტირების შეცდომა. |
| `source_accounting_disabled` | მარშრუტის მტკიცებულება არ შეიძლება მოითხოვოს სრული წყაროს დაფარვა. | ჩართეთ წყაროს აღრიცხვა ან მკაფიოდ მიიღეთ დაკარგული მტკიცებულება. |
| `route_disabled` | მარშრუტი განზრახ გამორთულია. | ამ მარშრუტისთვის მიწოდება არ არის მოსალოდნელი. |
| `poll_owner_between_polls` | მოხსენების თანამშრომელი რიგში დგას განრიგის საკუთრებაში არსებული უფსკრული გამოკითხვებს შორის. | მოსალოდნელია მხოლოდ მანამ, სანამ დროის ანაბეჭდები და კურსორები წინ მიიწევს. |
| `unsafe_shell_path` | შეზღუდული ინვენტარი ან გარსის გზა ვერ მოხერხდა პლატფორმაზე უსაფრთხო ვალიდაცია. | შეასწორეთ ბილიკი; არასოდეს შეასუსტოთ ციტირება ან ბილიკის დადასტურება. |
