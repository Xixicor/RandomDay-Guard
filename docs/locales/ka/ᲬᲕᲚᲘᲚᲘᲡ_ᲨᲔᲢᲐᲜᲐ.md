# წვლილის შეტანა

> **კანონიკური ინგლისური წყარო:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


RandomDayGuard იღებს ფოკუსირებულ, განმეორებად გაუმჯობესებებს პარსერებში, დოკუმენტაციაში, ტესტებსა და საჯაროდ უსაფრთხო ვალიდაციაში. შეინარჩუნეთ ყველა ცვლილება საჯარო პროექტის ხელშეკრულებით და შეინარჩუნეთ პირველი განხილვის ქცევა: დაცვამ უნდა დატოვოს `Admin.ini` უცვლელია, როდესაც უსაფრთხოების საჭირო შემოწმება ვერ დადასტურდება.

<a id="prepare-a-safe-workspace"></a>
## მოამზადეთ უსაფრთხო სამუშაო ადგილი

1. გააფორმეთ ან კლონირეთ საცავი და შექმენით ფოკუსირებული ფილიალი.
2. დააინსტალირეთ მხარდაჭერილი Python 3 თარჯიმანი. დააინსტალირეთ Lua შემდგენელი, როდესაც შეცვლით Lua ასე `luac -p` შეუძლია სინტაქსის შემოწმება.
3. წაიკითხეთ [დოკუმენტაციის მთავარი](%E1%B2%93%E1%B2%9D%E1%B2%99%E1%B2%A3%E1%B2%9B%E1%B2%94%E1%B2%9C%E1%B2%A2%E1%B2%90%E1%B2%AA%E1%B2%98%E1%B2%90.md), [არქიტექტურა](%E1%B2%90%E1%B2%A0%E1%B2%A5%E1%B2%98%E1%B2%A2%E1%B2%94%E1%B2%A5%E1%B2%A2%E1%B2%A3%E1%B2%A0%E1%B2%90.md) და [მტკიცებულების საზღვარი](%E1%B2%9B%E1%B2%A2%E1%B2%99%E1%B2%98%E1%B2%AA%E1%B2%94%E1%B2%91%E1%B2%A3%E1%B2%9A%E1%B2%94%E1%B2%91%E1%B2%94%E1%B2%91%E1%B2%98%E1%B2%A1_%E1%B2%A1%E1%B2%90%E1%B2%96%E1%B2%A6%E1%B2%95%E1%B2%90%E1%B2%A0%E1%B2%98.md) იმ ტერიტორიისთვის, რომელსაც შეცვლით.
4. შეამოწმეთ `git status` რედაქტირებამდე და შეინახეთ დაუკავშირებელი სამუშაო.
5. გამოიყენეთ მხოლოდ სინთეტიკური ან გაწმენდილი მოწყობილობები.

არასოდეს გაგზავნოთ პირადი სერვერის ჟურნალები, შენახული საქაღალდეები, მოთამაშის იდენტიფიკატორები, `Admin.ini`, შეტყობინების შეტყობინების საბოლოო წერტილები, რწმუნებათა სიგელები, პირადი ბილიკები, გაშვების დროის გამომავალი ან კოპირებული ცოცხალი მტკიცებულება.

<a id="make-a-focused-change"></a>
## შეიტანეთ ორიენტირებული ცვლილება

- მიჰყევით არსებულ სახელებს, ფორმატირებას, უსაფრთხოების შემოწმებებს და მოდულის მფლობელობას.
-  შეინახეთ ერთი კანონიკური დოკუმენტაციის მფლობელი თითოეული პროცედურისთვის ან ზუსტი ფაქტისთვის.
- განაახლეთ მომხმარებლის დოკუმენტაცია და მაგალითები, როდესაც იცვლება ქცევა ან საჯარო გამომავალი.
- დაამატეთ რეგრესიის ტესტი ხარვეზის გამოსასწორებლად, როდესაც ეს პრაქტიკულია.
- არ შეასუსტოთ ანგარიშის დადასტურება, სანდო ანგარიშის დაცვა, სარეზერვო დადასტურება, გარე ცვლილებების ამოცნობა, შენახული ფაილების შედარება, აღდგენა ან მხოლოდ განხილვის ნაგულისხმევი ნაგულისხმევი ნაგულისხმევი სატესტო ჩაბარების გასაკეთებლად.

<a id="run-the-relevant-checks"></a>
## გაატარეთ შესაბამისი შემოწმებები

მხოლოდ დოკუმენტაციის ცვლილებებისთვის, გაუშვით:

```powershell
python -B tools\generate_documentation_audit.py --check
python -B -m unittest discover tests -p "test_documentation*.py"
git diff --check
```

წყაროს, კონფიგურაციის, შეფუთვის ან ტესტის ცვლილებებისთვის, ასევე გაუშვით შესაბამისი შემოწმება [ვალიდაციის და გამოშვების მიმოხილვა](%E1%B2%95%E1%B2%90%E1%B2%9A%E1%B2%98%E1%B2%93%E1%B2%90%E1%B2%AA%E1%B2%98%E1%B2%90_%E1%B2%93%E1%B2%90_%E1%B2%92%E1%B2%90%E1%B2%9B%E1%B2%9D%E1%B2%A8%E1%B2%95%E1%B2%94%E1%B2%91%E1%B2%90.md), მათ შორის Lua სინტაქსის შემოწმებები, საცავის ვალიდაცია, საჯარო მილსადენის ტესტები და სრული ერთეულის ტესტის ნაკრები. შეატყობინეთ ყოველი გამოტოვებული ან მიუწვდომელი შემოწმების შესახებ; არ აღწეროთ ის, როგორც მიღებული.

<a id="submit-the-change-for-review"></a>
## გააგზავნეთ ცვლილება განსახილველად

გახსენით ფოკუსირებული გაყვანის მოთხოვნა მხოლოდ სრული განსხვავების განხილვის შემდეგ. მოიცავს:

- პრობლემა და დაგეგმილი ქცევა;
- ზუსტი ფაილები და საჯარო კონტრაქტები შეიცვალა;
- გაშვებული ბრძანებები და მათი შედეგები;
- კონფიდენციალურობა, თავსებადობა და აღსრულებაზე გავლენა; და
- დარჩენილი შეზღუდვები ან შემდგომი სამუშაო.

არ შეიტანოთ გენერირებული გაშვების მტკიცებულებები ან გამოშვების არქივები, თუ ცვლილება ცალსახად არ მოითხოვს და ადასტურებს მათ. წვლილის ავტორიზაცია არ არის გამოშვება, განლაგება, პირდაპირი სერვერის ტესტირება, აღსრულების მოქმედება ან მესამე მხარის საიტზე გამოქვეყნება.

შეატყობინეთ დაუცველობის შესახებ [პირადი უსაფრთხოების მარშრუტი](%E1%B2%A3%E1%B2%A1%E1%B2%90%E1%B2%A4%E1%B2%A0%E1%B2%97%E1%B2%AE%E1%B2%9D%E1%B2%94%E1%B2%91%E1%B2%90.md), არ არის საჯარო საკითხი ან ჩვეულებრივი გაყვანის მოთხოვნა.
