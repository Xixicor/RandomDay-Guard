# მეხსიერების ეკონომია და გამომავალი ფაილები

> **კანონიკური ინგლისური წყარო:** [MEMORY_ECONOMY_AND_OUTPUTS.md](../../MEMORY_ECONOMY_AND_OUTPUTS.md). ეს ლოკალიზებული დოკუმენტაცია ინახავს ზუსტ ბრძანებებს, ბილიკებს, გასაღებებს, სტატუსის მნიშვნელობებს, ჰეშებსა და ფაილების სახელებს. თუ ტექნიკური ფორმულირება განსხვავდება, გამოიყენეთ ინგლისური წყარო.


ეს გვერდი განმარტავს, რომელი ფაილები იზრდება, რომელი ფაილები გადაიწერება და რა უნდა ატვირთოთ სწრაფი განხილვისთვის.

<a id="fast-answer"></a>
## სწრაფი პასუხი

| კითხვა | გახსნა |
|---|---|
| მცველი ცოცხალია? | `runtime/current/poll_status.json` |
| ვინ ნახეს? | `runtime/account_evidence.json` |
| რა დაემართა სესიებს? | `runtime/evidence/session_events.jsonl` |
| რა მოხდა დღეს? | `runtime/forensic_days/YYYY-MM-DD/` |
| რა არის უბრალო ენაზე შეჯამება? | `runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt` |
| რა არის სკანირების პროგრესი? | `runtime/scan_progress.json` |
| რა არის მსოფლიო კონტექსტი? | `runtime/world_state/current/world_state_latest.json` |
| რა აკრძალვები დაიწერა? | `runtime/enforced_bans.jsonl` |

<a id="output-model"></a>
## გამომავალი მოდელი

| ტიპი | ქცევა | მაგალითები |
|---|---|---|
| მიმდინარე კადრები | გადაწერილი | `runtime/current/*.json` |
| მოვლენის ჟურნალი | მხოლოდ დამატება | `runtime/evidence/*.jsonl` |
| ცხრილები | განახლებულია ან დამატებულია | `*.tsv` |
| ძირითადი ხაზები | ხელახლა გამოიყენება დასრულების შემდეგ | `runtime/baselines/*` |
| ყოველდღიური შეკრებები | განახლებულია ადგილზე | `runtime/forensic_days/YYYY-MM-DD/*` |
| საბოლოო ჟურნალები | დღიური რეზიუმე უბრალო ენაზე | `runtime/final_logs/YYYY-MM-DD/*` |
