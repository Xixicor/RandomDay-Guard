# RandomDayGuardドキュメント

> **正規の英語ソース:** [README.md](../../README.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


RandomDayGuard は、Abiotic Factor 専用サーバーからレコードを読み取り、サーバーの健全性、日々の履歴、プレーヤー セッション、レビュー ケース、Guard の失敗に関する個別のレポートに変換します。
