# 用語集

> **正規の英語ソース:** [GLOSSARY.md](../../GLOSSARY.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


| 用語 | 明確な意味 | 正確技術的な意味 |
|---|---|---|
| アクティブ ログ | 最新の証拠に使用される現在のサーバー ログ。 | 必須`active_log`ソース。ルートの完了には可読性と現在のリネージが必要です。 |
| ブート ID | 1 つのウォッチドッグ プロセスの開始。 | 以前のブートを拒否するために使用される現在のランタイム ID errors/reports. |
| エポック ID | 1 つのサーバーの継続性 | 継続性ロジックが別のエポックを開始するまで、通常のランタイムにわたる識別子。 |
| ポーリング ID | 1 つの制限付きポーリング機会。 | 正の単調サイクル フィールド。 zero/missingルートを完了できません。 |
| ソースの鮮度 | 現在のソースとポーリング リネージが一致するかどうか。 | `fresh_current_poll` または `stale_or_unproven`タイムスタンプとアクティブ ログ ステータス。 |
| ソース アカウンティング | 証拠の入手可能性と制限の一覧。 | `randomdayguard.source-accounting/v1` 8 つのソース クラスと current/historical スコープ。 |
| `available` | ソースが見つかり、読み取られました。 | ターミナル ソース ステータスと`available=true`, `readable=true`. |
| `expected_empty` | オプションのソースがチェックされ、正当であるabsent/empty. | 端末で読み取り可能なソースのステータス。  |
| `partial` | 制限された作業は有用ですが、不完全な結果をもたらします。 | 非ターミナルsource/accountingステータス。所有するワーカーを再開します。 |
| `deferred` | 作業は意図的に保留中です。 | 非ターミナル ソース ステータス。エラーまたは完了ではありません。 |
| `unavailable` | ソースは現在使用できません。 | 端子ギャップ。必須ソース ギャップによりアカウンティングが使用できなくなります。 |
| `malformed` | ソースは存在しますが、構造的に無効です。 | ターミナル ギャップが検証の詳細を保持し、依存する書き込みを閉じます。 |
| `permission_denied` | OS が明示的にアクセスを拒否しました。 | ターミナル ギャップとは異なります。missing/unavailable. |
| `error` | 制限された操作が失敗しました | 指定されたリカバリが必要な端末障害。公開レポートには秘密の詳細は含まれません。 |
| `complete` | すべてのアカウンティングされた情報源はギャップがなく最終的なものです。 | トップレベルの情報源アカウンティング ステータス。 |
| `complete_with_gaps` | 必要な現在の証拠が機能します。オプションのターミナル ギャップが残ります。 | トップレベルのアカウンティング ステータス。ルートには独自の要件が適用されます。 |
| `full` | 必要な空でないコントラクトを使用して完了したルート。 | 完了した現在のサイクル出力を含むルート証明列挙型。 |
| `limited_expected_empty` | ルートが完了しましたが、適格なルートが見つかりませんでしたsubject/failure. | ルート証明列挙型 `completed=true`, `expected_empty=true`. |
| `missing` | ルート完了証明が存在しないか、失敗しました。 | ルート証明列挙型 `completed=false`;送信トレイの対象にはなりません。 |
| 構造化レポート | 機械可読なルート出力。 | `<route>_latest.json` `randomdayguard.report/v1`. |
| 翻訳されたレポート | 人間が判読できる同じルートのレンダリング。 | `<route>_latest.txt` 観測対象からソース参照の順序が固定されています。 |
| ルート証明 | クロスルート完了台帳。 | `route_proof.json` バインディング version/boot/epoch/poll/freshness/output パス。 |
| 現在の証拠 | アクティブなサイクルが所有する観測。 | 範囲 `current`;古いものから再構築されていませんfilenames/reports. |
| 歴史的証拠 | 以前のサイクルまたは低速スキャンからのコンテキストが保持されます。 | 範囲 `historical`;レビューに通知することはできますが、現在の存在を主張することはできません。 |
| レビューのみ | レビュー証拠をAdmin.ini書き込みを制御します。 | デフォルト`review_only_mode=true`, `auto_ban=false`, `write_admin_ini=false`. |
| 禁止リストの安全性チェックなしで作成する | 変更される前に Guard が回答する必要がある 1 つの質問 `Admin.ini`. | アカウントとスコアを確認し、信頼できるアカウントと重複を除外し、バックアップを検証し、外部からの変更を検出し、目的の更新を保存し、完全なものを検証または安全に復元する必要があります |
| ローカル送信ボックスに収束します | オプションのプロバイダー中立の通知ハンドオフ。 | JSON ファイルの `delivery_backend="none"` と `delivery_attempted=false`. |
| ベースライン | 完了した境界付き保存ファイル コンテキスト スナップショットを含む JSON ファイル。 | Manifest/object/world状態は、互換性があり十分に新しい場合にのみ再利用されます。 |
| チェックポイント | 不完全なスキャン作業の位置を再開します。 | `scan_checkpoint.json`;削除はデフォルトのリカバリではありません。 |
| 再構築可能なインデックス | 再生成可能な概要。 | Daily/weekly/forensic/final出力を確認します。ソースの証拠は信頼性を保ちます。 |
| 証拠の境界 | ソースがサポートできる内容の制限。 | 明示的な`does_not_prove`、未知、アイデンティティの強度、範囲ルール。 |

スキーマの正規定義は [`OUTPUT_SCHEMA_REFERENCE.md`](%E5%87%BA%E5%8A%9B%E3%82%B9%E3%82%AD%E3%83%BC%E3%83%9E%E3%81%AE%E3%83%AA%E3%83%95%E3%82%A1%E3%83%AC%E3%83%B3%E3%82%B9.md) にあります。設定用語は[`CONFIG_FIELD_CATALOG.md`](%E8%A8%AD%E5%AE%9A%E3%83%95%E3%82%A3%E3%83%BC%E3%83%AB%E3%83%89_%E3%82%AB%E3%82%BF%E3%83%AD%E3%82%B0.md).
