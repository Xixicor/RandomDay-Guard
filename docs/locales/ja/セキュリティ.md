<a id="security-policy"></a>
# セキュリティ ポリシー

> **正規の英語ソース:** [SECURITY.md](../../../SECURITY.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


<a id="report-a-vulnerability-privately"></a>
## 脆弱性を報告する。非公開

使用する [GitHub非公開の脆弱性レポート](https://github.com/Xixicor/RandomDay-Guard/security/advisories/new): 機密レポートをリポジトリ所有者に送信します。そのフォームが利用できない場合は、[所有者の公開 GitHub プロファイル](https://github.com/Xixicor)は、脆弱性の詳細を含めずにプライベート連絡先チャネルをリクエストします。

エクスプロイト ステップ、認証情報、プライベート サーバー パス、プレーヤー識別子、`Admin.ini`、保存データ、Webhook URL、またはライブ証拠ファイルを含む公開問題を開かないでください。

<a id="include-useful-evidence"></a>
## 有用な証拠を含めてください

以下を提供します:

- 影響を受けるRandomDayGuard バージョンまたはコミット;
- 影響を受けるコンポーネントと予想される安全な動作、
- サニタイズされたフィクスチャを使用した最小限の再現手順、
- 観察された影響と再現可能かどうか。および
- 個人データを公開しない提案された緩和策。

実際の秘密は送信しないでください。問題の再現に必要な構造を維持しながら、プライベート パス、アカウント識別子、ホスト名、トークンを明確なプレースホルダーに置き換えます。

<a id="expect-review-first-handling"></a>
## レビュー優先の処理を期待する

レポートは、サーバーへのアクセス、ライブ ターゲットのテスト、エクスプロイトの詳細の公開、またはフェールクローズされたデフォルトの弱体化の承認ではなく、メンテナによるレビューの証拠です。所有者は範囲を検証し、プライベート レポートを通じて開示を調整します。
