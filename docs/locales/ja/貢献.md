# 貢献

> **正規の英語ソース:** [CONTRIBUTING.md](../../../CONTRIBUTING.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


RandomDayGuard は、パーサー、ドキュメント、テスト、パブリックセーフ検証に対する重点的かつ再現可能な改善を受け入れます。すべての変更を公共プロジェクト契約に限定し、レビュー優先の動作を維持します: ガードは退場する必要があります `Admin.ini`変更しないでください。

<a id="prepare-a-safe-workspace"></a>
## 安全なワークスペースを準備します。

1. リポジトリをフォークまたはクローンして、フォーカスされたブランチを作成します。
2. サポートされている Python 3 インタープリターをインストールします。 Lua を変更する場合は、`luac -p` 構文をチェックできるように、Lua コンパイラをインストールします。
3. 内容を読む [ドキュメント ホーム](%E3%83%89%E3%82%AD%E3%83%A5%E3%83%A1%E3%83%B3%E3%83%88.md), [アーキテクチャ](%E3%82%A2%E3%83%BC%E3%82%AD%E3%83%86%E3%82%AF%E3%83%81%E3%83%A3.md) と一致する必要があり、[証拠の境界](%E8%A8%BC%E6%8B%A0%E3%81%AE%E5%A2%83%E7%95%8C.md)。
4. 編集する前に検査し`git status`無関係な作業を保存してください。
5. 合成またはサニタイズされたフィクスチャのみを使用してください。

プライベートサーバーログ、保存フォルダー、プレーヤー識別子などは決して送信しないでください。`Admin.ini`、プライベート通知エンドポイント、認証情報、プライベート パス、ランタイム出力、またはコピーされたライブ証拠。

<a id="make-a-focused-change"></a>
## 焦点を絞った変更を加える

- 既存の命名、フォーマット、安全性チェック、モジュールの所有権に従ってください。
- 手順または正確な事実ごとに 1 人の正規ドキュメントの所有者を保持します。
- 動作や公開出力が変更された場合は、ユーザー ドキュメントと例を更新します。
- 実際的であれば、バグ修正のための回帰テストを追加します。
- テストに合格するために、アカウントの確認、信頼できるアカウントの保護、バックアップの検証、外部変更の検出、保存されたファイルの比較、リカバリ、またはレビューのみのデフォルトを弱めないでください。

<a id="run-the-relevant-checks"></a>
## 関連するチェックを実行します

ドキュメントのみの変更の場合は、次を実行します。

```powershell
python -B tools\generate_documentation_audit.py --check
python -B -m unittest discover tests -p "test_documentation*.py"
git diff --check
```

ソース、構成、パッケージング、またはテストの変更については、[検証とリリースのレビュー](%E6%A4%9C%E8%A8%BC%E3%81%A8%E3%83%AA%E3%83%AA%E3%83%BC%E3%82%B9.md) これには、Lua 構文チェック、リポジトリ検証、パブリック パイプライン テスト、完全な単体テスト スイートが含まれます。スキップされたチェックまたは使用できないチェックをすべて報告します。合格したとは記述しないでください。

<a id="submit-the-change-for-review"></a>
## 審査のために変更を送信します

完全な差分を確認した後でのみ、フォーカスされたプル リクエストを開きます。含める:

- 問題と意図された動作;
- 正確なファイルと公的契約が変更されました。
- コマンドの実行とその結果。
- プライバシー、互換性、施行への影響。そして
- 残りの制限またはフォローアップ作業。

変更によって明示的に要求および検証される場合を除き、生成された実行時証拠やリリース アーカイブを含めないでください。投稿によって、リリース、展開、ライブサーバー テスト、強制アクション、またはサードパーティ サイトでの公開が承認されるわけではありません。

脆弱性を報告するには[プライベート セキュリティ ルート](%E3%82%BB%E3%82%AD%E3%83%A5%E3%83%AA%E3%83%86%E3%82%A3.md)、公開問題や通常のプル リクエストではありません。
