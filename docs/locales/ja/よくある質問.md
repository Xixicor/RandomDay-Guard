# FAQ

> **正規の英語ソース:** [FAQ.md](../../FAQ.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


<a id="is-randomdayguard-the-randomday-mod"></a>
## です。RandomDayGuard RandomDay 修正はありますか?

いいえ。 RandomDay Mod はサーバー エクスペリエンスを変更します。 RandomDayGuard はサーバーの証拠レイヤーを監視します。

<a id="does-live-defense-work-before-the-scan-completes"></a>
## スキャンが完了する前にライブ防御は機能しますか?

はい。ライブ防御では、ログとセッション イベントが使用されます。ベースライン スキャンにより、後でコンテキストが改善されます。

<a id="why-can-the-first-scan-take-a-long-time"></a>
## 最初のスキャンに時間がかかるのはなぜですか?

最初のスキャンでは、world/objectコンテキスト、ファイル マニフェスト、および再利用可能なベースライン データが構築されます。

<a id="what-do-i-check-first-after-startup"></a>
## 起動後に最初に何を確認すればよいですか?

```text
runtime/current/poll_status.json
```

次の点を確認してください。

```text
scheduler_status=running
poll_id increasing
poll_in_flight=false
```

<a id="where-are-player-summaries"></a>
## プレーヤーはどこにありますか?


<a id="can-it-write-bans-automatically"></a>
## 禁止を自動的に書き込めますか?

明示的に有効になっている場合のみ。

デフォルト:

```lua
review_only_mode = true
auto_ban = false
write_admin_ini = false
```

<a id="what-does-adminini-receive"></a>
## 内容Admin.ini受け取りますか?

のみ:

```ini
BannedPlayer=<ID>
```

名前、コメント、理由、接尾辞はありません。

<a id="is-a-display-name-enough-to-ban"></a>
## 表示名だけで禁止するのに十分ですか?

いいえ。サーバー ログ`Login request` を書き込みます。また、利用できないアカウンティングを含む履歴ステータス レコードも書き込みます。ソース アカウンティングはレポート コントラクトの一部であるため、すべてのルートは `ConnectID`または同等のサーバー証拠を使用します。

<a id="can-one-crash-ban-someone"></a>
## クラッシュで誰かを禁止できますか?

デフォルトではいいえ。

<a id="can-object-count-alone-ban-someone"></a>
## オブジェクト カウントだけで誰かを禁止できますか?

デフォルトではいいえ。

<a id="should-savedroottxt-point-to-the-world-folder"></a>
## 世界を指す必要がありますSavedRoot.txtフォルダは?

いいえ。 `AbioticFactor/Saved`.

<a id="what-if-the-world-folder-changes"></a>
## ワールド フォルダが変更された場合はどうなりますか?

ベースライン ID の変更として扱います。古いベースラインを保存し、新しいベースラインを構築します。
