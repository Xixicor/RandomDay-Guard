# インストール RandomDayGuard

> **正規の英語ソース:** [INSTALL.md](../../../INSTALL.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


このガイドは`v0.4.12-alpha` すでに使用している Abiotic Factor 専用サーバー上の UE4SS。 MOD は 1 つのホスティング会社やコントロール パネルに関連付けられていません。

<a id="before-you-begin"></a>
## 始める前に

必要なもの:

- 専用サーバーを停止および起動するためのアクセス権、
- サーバーの UE4SS `Mods`フォルダー、
- 現在のファイルのコピー RandomDayGuard フォルダー。
- MOD を変更する前に通常保護するサーバー データのバックアップ。

**Mods フォルダー** は `ue4ss/Mods/` ディレクトリは、専用サーバーのインストール内にあります。 RandomDayGuard そのフォルダー内に直接属します。

<a id="new-installation"></a>
## 新規インストール

1. 専用サーバーを停止します。
2. 抽出RandomDayGuard ZIP 新しい空のフォルダーにコピーします。
3. 抽出した `RandomDayGuard` フォルダをサーバーの UE4SS `Mods` フォルダー。結果は、1 つの`Mods/RandomDayGuard/` フォルダー、2 番目のフォルダーではありません RandomDayGuard フォルダー内にネストされています。
4. 開く UE4SS `mods.txt`次の項目を有効にします。

   ```text
   RandomDayGuard : 1
   ```

5. サーバーを通常どおり起動します。
6. お待ちください UE4SS とゲームサーバーの起動が完了したら、[最初のレポートを読む](%E3%81%93%E3%81%93%E3%81%8B%E3%82%89%E9%96%8B%E5%A7%8B.md).

実行中のインストールに新しいリリースをコピーしないでください。更新されたインストールによって現在のサーバー ステータス レポートが作成されるまで、バックアップを保管してください。

<a id="update-an-existing-installation"></a>
## 既存のインストールを更新します。

1. サーバーを停止します。
2. インストールされているファイルを完全にコピーしますRandomDayGuard フォルダを安全なバックアップ場所にコピーします。
3. 古いプログラム フォルダーを UE4SS `Mods`。
4. 新しいものをコピーRandomDayGuard フォルダを `Mods`.
5. 確認したローカル構成のみを復元し、保存された証拠。構成ガイドに新しいフィールドがリストされている場合は、すべての設定をやみくもに置き換えるのではなく、確認済みのコピーにそれらをマージします。
6. 有効のままであることを確認します。`RandomDayGuard : 1`
7. サーバーを起動し、現在のサーバー ステータス レポートを読み取ります。

このクリーン フォルダー アップデートでは、オペレーターにプログラムの検査を依頼することなく、古いリリースから古いファイルも削除されます。

<a id="help-guard-find-the-server-records"></a>
## Guard によるサーバー レコードの検索を支援します。

Guard は通常、Abiotic Factor `Saved` ディレクトリを自動的に検索します。それができない場合は、RandomDayGuard フォルダ内の `Saved` ディレクトリへのフル パスを入力します。その下の 1 つの個別のワールドではなく、`SavedRoot.txt` RandomDayGuard フォルダー。 `Saved` をポイントします。

最初のサーバー ステータス レポートには、レコードの場所が見つかったかどうか、およびどのソース グループが利用可能だったかが示されます。 [トラブルシューティング](%E3%83%88%E3%83%A9%E3%83%96%E3%83%AB%E3%82%B7%E3%83%A5%E3%83%BC%E3%83%86%E3%82%A3%E3%83%B3%E3%82%B0.md) 位置を読み取れない場合。

<a id="first-run-behavior"></a>
## 初回実行時の動作

デフォルトのインストールでは、利用可能なレコードを監視し、レポートを書き込みます。 `Admin.ini` を変更したり、禁止を追加したりするものではありません。これにより、オプションのアクションを有効にするかどうかを決定する前に、収集、翻訳、レポートの品質を確認できます。

[最初のレポートを読む](%E3%81%93%E3%81%93%E3%81%8B%E3%82%89%E9%96%8B%E5%A7%8B.md)

<a id="disable-or-remove-randomdayguard"></a>
## 無効化または削除する RandomDayGuard

1. サーバーを停止します。
2. 完全にコピーする RandomDayGuard フォルダーを安全なアーカイブに保存します。
3. MOD を無効にするには、`RandomDayGuard : 0` 内 UE4SS `mods.txt`.
4. 削除するには、完全なファイルを移動してください。RandomDayGuard フォルダが `Mods` から移動します。
5. サーバーを起動し、Guard が起動しなくなったことを確認します。

Guard を無効化または削除すると、今後の収集が停止します。ゲーム データの削除、アーカイブされたレポートの消去、または別のオペレータ アクションの取り消しは行われません。

<a id="roll-back-an-update"></a>
## アップデートをロールバックする

新しいインストールが読み込まれない場合、または現在のレポートを生成できない場合:

1. サーバーを停止します。
2. 失敗したインストールをレコードを削除せずに脇に移動します。
3. アップデート前の完全な状態に戻す RandomDayGuard フォルダー。
4. 確認した設定と保存された証拠を同じバックアップから復元します。
5. MOD が有効になっていることを確認し、サーバーを起動します。
6. 別の変更を行う前に、復元されたサーバー ステータス レポートをお読みください。
