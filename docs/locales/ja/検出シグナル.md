<a id="detection-signals"></a>
# 検出シグナル

> **正規の英語ソース:** [DETECTION_SIGNALS.md](../../DETECTION_SIGNALS.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


シグナルはレビュー入力であり、自動告発ではありません。

<a id="signal-table"></a>
## シグナル テーブル

| シグナル | 意味 | 次の場合に強力になります... | 単独では不十分 |
|---|---|---|---|
| ログイン ID | 名前をアカウント ID にマッピングします | ConnectID が存在します | 禁止 |
| 完全離脱 | 通常のセッション終了 | 試合への参加と離脱 | 疑惑 |
| 迅速な再接続 | Churn/probingコンテキスト | すぐに繰り返す | 禁止 |
| 不完全な切断 | セッションが正常に終了しなかった | クラッシュが繰り返される、または重複する | 禁止 |
| クラッシュが重複する | クラッシュ寸前でアクティブなアカウント | 同じアカウントが繰り返される | 禁止 |
| クラッシュ後の復帰 | 再起動後のアカウントの復帰 | エポック間で繰り返す | 1つのイベントによる禁止 |
| 警告バースト | サーバー警告ウィンドウ | マッピングされたセッションの重複 | 1 バーストによる禁止 |
| アクター セーブ タッチ | ワールド セーブ コンテキスト | と相関セッション | use/theft |
| オブジェクト デルタ | World/class変更の証明 | と相関セッション | カウントのみからの禁止 |
| 襲撃ケース | マルチアカウント クラスタ | セントラル アカウント繰り返し | すべてのアカウントを一括禁止 |

<a id="login-identity"></a>
## ログイン ID

最適なソース:

```text
Login request
Name=
ConnectID=
UniqueId=
```

マッピングに使用します:

```text
display/log name -> account_id -> ban_id
```

<a id="rapid-reconnect"></a>
## 迅速な再接続

パターン:

```text
join -> leave -> join -> leave -> join
```

繰り返した場合のレビューに使用します。

安全性:

```text
churn_alone_never_bans = true
```

<a id="crash-overlap-and-post-crash-return"></a>
## クラッシュのオーバーラップとクラッシュ後の復帰

パターン:

```text
account active before crash
server restarts
same account returns quickly
```

複数回繰り返された場合のレビューに使用します

安全性:

```text
single_crash_never_bans = true
```

<a id="warning-bursts"></a>
## 警告バースト

例:

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

マップされたセッションとしきい値にリンクされるまでコンテキストとして使用します。

<a id="actor-save-touch"></a>
## アクター セーブ タッチ

意味:

```text
The server evidence referenced a class or actor.
```

意味はありません:

```text
A player opened it.
A player stole from it.
A player duplicated through it.
A player damaged it.
```

<a id="raid-cases"></a>
## 襲撃ケース

RAID ケースは、タイミングと共有ウィンドウによってアカウントをグループ化します。

ルール:

```text
Do not auto-ban every account in a raid case.
Each account needs account-specific evidence.
```
