# 出力および状態スキーマのリファレンス

> **正規の英語ソース:** [OUTPUT_SCHEMA_REFERENCE.md](../../OUTPUT_SCHEMA_REFERENCE.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


これは、生成されたオペレータ向けファイルの正規の規約です。これだけで、正確な出力パス、フィールド名、許可される値、系統要件、およびルート スキーマを所有します。手順ガイドは、これらの事実を再定義するのではなく、ここにリンクしています。

実行時の証拠は信頼できます。ファイル名、スケジューラのハートビート、翻訳されたレポート、またはローカルの送信トレイ オブジェクトは、それ自身のフィールドと系統以上のものではありません。

<a id="public-report-routes"></a>
## パブリック レポート ルート

レポート ワーカーは、`runtime/final_logs/`:

| ルート | 契約 | `full` 要件 | 期待される空の意味 |
|---|---|---|---|
| `server_status` | 現在のスケジューラ、アクティブ ログ、スキャン保留中、およびソース カバレッジの状態。 | アクティブ ログに表示される現在のboot/epoch/poll リネージ、最新のアクティブ ログ、accounting/history は書き込み、JSON/TXT ペア。 | その他の点では健全な現在のサイクルには使用されません。欠落しているリネージは、`missing`. |
| `daily_rollup` | アクティブ ログに表示される現在のday/windowサーバー、プレーヤー、ケース、スキャン、およびカバレッジにわたる連続性です。 | ルートと現在のサイクルの証明に十分な履歴アカウンティング ターミナルが完了しています。 | 保持されているプレーヤーやレビュー ケースはありません。 |
| `player_activity` | 現在と過去のデータを分離します。player/account  | 現在のサイクルの証明と 1 つ以上のcurrent/historical行。 | 制限付き入力に適格なプレイヤー行がありません。合成主題なし。 |
| `case_review` | 名前付きの保持ケースと現在のreview/BAN-ELIGIBLE候補。 | 現在のサイクルの証拠と、出典参照付きの 1 つ以上の名前付きケース。 | レビュー基準を満たした名前付きケースはありません。合成ケースはありません。 |
| `critical_guard` | 現在のブート スケジューラ、起動、ポーリング、または証拠の整合性の障害。 | 現在のサイクルの証明と現在の重大な障害。 | 現在の重大な障害はありません。古いテキスト エラーはこのルートを所有しません。 |

有効なルートはすべて `<route>_latest.json` と `<route>_latest.txt` を書き込みます。ペアは、`runtime/final_logs/route_proof.json`同じバージョン、ブート、エポック、ポーリング、およびソースの鮮度を記録するまで完了しません。

<a id="report-json-schema"></a>
## レポート JSON スキーマ

すべてのルート JSON は `schema="randomdayguard.report/v1"`.

| フィールド | タイプ | 意味と不変 |
|---|---|---|
| `schema` | 文字列 | 正確`randomdayguard.report/v1`. |
| `generated_ts`, `report_date` | 文字列 | 生成タイムスタンプとレポート日付。 |
| `version` | 文字列 | Runtime/packageこのサイクルの ID。 |
| `boot_id`, `epoch_id` | 文字列 | 現在のプロセス ブートとサーバー継続エポック。完了するには両方が必要です。 |
| `poll_id` | 整数 | 正の現在のポーリング識別子。 Zero/missingルートを完了できません。 |
| `source_freshness` | オブジェクト | `status`, `checked_ts`、アクティブ ログ ステータス、最後のポーリング タイムスタンプ、および最後に完了したポーリング タイムスタンプ。 |
| `current_cycle_proof_complete` | ブール値 | 系統と最新のactive-log/current-poll証拠が一致する場合にのみ真となります。 |
| `route` | 列挙型 | 5 つのルートの 1 つ |
| `route_proof_status` | 列挙型 | `full`, `limited_expected_empty`または `missing`. |
| `coverage_status` | 列挙型 | 正確`complete`, `complete_with_gaps`, `partial`または `unavailable`. |
| `completed`, `expected_empty` | ブール値 | `completed` は、`missing`; `expected_empty`は、`limited_expected_empty`. |
| `observed` | 文字列の配列の場合にのみ true です。 | コンクリートが保持されます。facts/counts/statuses. |
| `interpretation` | 文字列の配列の場合にのみ true です。 | 証拠に合わせて調整された慎重な意味です。 |
| `unknown` | 文字列の配列の場合にのみ true です。 | アイデンティティが欠落しています。  |
| `does_not_prove` | 文字列の配列の場合にのみ true です。 | 証拠がサポートできない結論。 |
| `next_action` | 文字列 | 最も安全な制限された演算子のアクション。 |
| `source_references` | 文字列の配列の場合にのみ true です。 | ソートされた一意のruntime/Saved参照。 |
| `enforcement_authority` | ブール値 | 常に false。レポートは書き込みを許可しません。 |
| `output_paths` | 2 つの文字列 | JSON と TXT パスはペア書き込みの前に追加されます。 |

`coverage_status`はトップレベルのアカウンティングのみです。ソースレコードは別途所有`available`, `expected_empty`, `partial`, `deferred`, `unavailable`, `malformed`, `permission_denied` と一致する必要があり、`error`。ルート証明は別途所有`full`, `limited_expected_empty` と一致する必要があり、`missing`;値がこれらの境界を越えることはありません。

ルート拡張:

- `server_status`: `scheduler_status`, `active_log_status` と一致する必要があり、`server_metrics`。メトリクスには、現在のエポックの開始、最後に完了したポーリングのタイムスタンプと ID、アクティブ プレーヤーの数が記録されます。active/backup-log カウント、スキャン pending/progress 値、および configured/usable/unavailable ソースグループのアカウンティング。ソースがこれらの事実を公開していない場合、稼働時間、再起動回数、バックアップのタイムスタンプ、または停止期間をでっち上げることはありません。
- `player_activity`: `player_activity_present`, `movement`, `same_day_sessions`, `current_player_count`, `current_evidence_player_count`, `historical_player_count`, `historical_session_count`, `current_players`, `historical_players` および互換性配列 `players`。同じ日の各セッションでは、セッション ID、アカウント ID、表示名がわかっている場合は保持されます。join/leave タイムスタンプ、クリーン終了およびライフサイクル フラグ、およびソース参照。保持された ID と PlayerData プレゼンスはコンテキストのままであり、今日の活動の証拠ではありません。
- `case_review`: `cases`, `review_subjects`, `current_case_count` と一致する必要があり、`retained_case_count`。現在のレビュー対象者はその case/account ID、既知の場合の表示名、ステータス、スコア、アイデンティティの信頼度、first/last 観察、警告数、理由、現在有効なフラグ、ソース参照。保持されたケースは、それ自体で現在の件名を作成しません。
- `critical_guard`: `critical_failure_present` と `current_boot_error_only=true`.
- `daily_rollup`: `daily_maturity`, `once_per_day_continuity`, `dedupe_window` と一致する必要があり、`daily_metrics`。メトリクスには、レポートの日付、アクティブなプレーヤー、同日アクティビティのあるアカウント、参加、脱退、クリーンな終了とクリーンでない終了、ライフサイクル リターン、現在の名前付きレビュー対象、保持されたケースが記録されます。current/retained ID 数とソースグループの範囲。

<a id="translated-txt-schema"></a>
## 翻訳済み TXT スキーマ

ペアになったテキスト ファイルは、オペレータが読み取り可能な結果を​​先頭に置き、系統の詳細を最後に移動します。このセクションの順序は正確に保持されます。

```text
RandomDayGuard <route title>
Generated: <timestamp>

Summary
<one plain-language route summary>

What Guard observed
- ...

What it means
- ...

What remains unknown
- ...

Recommended next step
...

Evidence boundary
- ...

Rating explanation
- ...

Technical record
- Route: <route>
- Version: <version>
- Cycle: boot=<boot> epoch=<epoch> poll=<poll>
- Source freshness: <status>
- Route result: <full|limited_expected_empty|missing>
- Coverage: <status>

Translation notes
- ...

Source references
- ...
```

翻訳では、構造化レポート フィールドと承認された辞書マッピングのみが使用されます。構造化レポートにないプレーヤー、ケース、配信、因果関係、所有権、意図、または執行資格を追加することはできません。技術的な詳細は、読み取り可能な結果を​​置き換えることなく引き続き利用できます。

<a id="source-accounting-schema"></a>
## ソース会計スキーマ

`runtime/final_logs/source_accounting_latest.json` は `randomdayguard.source-accounting/v1` 世代付き reason/status, enablement/disabled 理由、current/historical 区別、変更されたファイルのマニフェスト、ソース レコード、usable/unavailable クラス リストと請求限度額。

各ソース レコードには以下が含まれます。

| フィールド | タイプ | 意味 |
|---|---|---|
| `source_class` | 文字列 | 以下の 8 つのクラスのいずれか。 |
| `scope` | `current` または `historical` | 時間の所有権。スコープがサイレントにマージされることはありません。 |
| `required` | ブール値 | 現在のサイクル ルートの鮮度に必要なのは`active_log`のみです。 |
| `status` | 列挙型 | ソース結果は以下にリストされています。 |
| `terminal` | ブール値 | `partial` と `deferred`. |
| `available`, `readable` | ブール値 | 場合のみ False `available` と `expected_empty`. |
| `file_count` | 整数 | 制限付きアカウントの場合のみ True file/referenceカウント。 |
| `source_references` | 配列 | ソートされた一意のソース paths/references. |
| `detail` | 文字列 | 制限された結果またはエラーの詳細。 |
| `does_not_prove` | 文字列 | 可用性は、意図、所有権、損傷、複製、強制の証拠ではありません。 |

ソース クラス:

| ソース クラス | 範囲 | 貢献するもの | 証明できないもの |
|---|---|---|---|
| `active_log` | 最新、必須 | 読み取り可能なアクティブなサーバー ログと最新の投票リネージ。 | 完全な履歴またはプレイヤーの責任。 |
| `admin_ini` | 現在の、オプション | 構造的に有効な現在のmoderator/ban状態、または予想される不在。 | プレーヤーの動作または正当な理由のメタデータ。 |
| `recent_backup_logs` | 履歴 | 読み取り可能なrotated/backupログ参照。 | 現在の存在または現在のブート状態。 |
| `playerdata_filenames` | 現在のコンテキスト | 選択した保存済みルートの下の境界付き読み取り可能なファイル名参照。 | ファイル所有権、ライブプレゼンス、ID コンテンツ、または不正行為。 |
| `existing_cases` | 履歴 | 現在の出力前に取得された名前付きケースの保持files/index記録。 | 現在のアクティビティまたは古い結論の正しさ。 |
| `existing_reports` | 履歴 | 保持final/forensic/warningレポート参照。 | 信頼できるソースの置き換え。 |
| `existing_evidence` | 履歴 | 保持されている証拠の参照。 | サーバーが公開しなかったイベントの完全性。 |
| `world_save_scan` | 履歴 | 完全、部分的、延期、または利用できない制限されたscan/checkpoint状態。 | 特定のプレイヤーのアクションまたは |

ソース ステータス値:

| ステータス | ターミナル | 演算子の意味とアクション |
|---|---:|---|
| `available` | はい | 読み取り可能な有用なソースが存在します。参照を確認してください。 |
| `expected_empty` | はい | オプションのソースがチェックされ、正当であることが確認されました。absent/emptyデータを発明しないでください。 |
| `partial` | いいえ | 制限された作業または在庫制限が不完全です。再開を許可します。 |
| `deferred` | いいえ | 作業は意図的に保留中です。所有するワーカーを待ちます。 |
| `unavailable` | はい | Source/path/tool が存在しないか使用できません。ルートで必要な場合にのみ修復してください。 |
| `malformed` | はい | コンテンツの構造検証に失敗しました。それを保存してフォーマットを修復します。 |
| `permission_denied` | はい | アクセスは明示的に拒否されました。最小特権の読み取りアクセスを復元します。 |
| `error` | はい | ソースレベルの制限付きprobe/readが予期せず失敗しました。 `detail` は秘密を公開せずに検査します。 |

トップレベル `coverage_status` は正確に `complete`, `complete_with_gaps`, `partial`または `unavailable` です。必須のソースレベル `error`, `malformed`または `permission_denied` は、トップレベル `unavailable` にロールアップされます。ソースレベル `deferred` は、トップレベル `partial`。ソース アカウンティングを無効にしても、使用不可ステータスが書き込まれ、すべてのルートが`missing`.

<a id="historical-status-schema"></a>
## 履歴ステータス スキーマ

`runtime/final_logs/historical_backfill_latest.json` は `randomdayguard.history/v1`: `generated_ts`、アカウンティング `status`, `resumable=true`, `changed_file_refresh=true`, `current_evidence_is_not_history=true`、ソース アカウンティング配列、使用不可クラス、および制限された`next_action`.

`runtime/history/public_accounts.tsv`は、次のヘッダーを持つ永続的な公開履歴になります。

```text
account_id	ban_id	display_name	identity_confidence	status	score	first_seen	last_seen	source_references
```

行はアカウント ID によって並べ替えられ、フィールドはsingle-line/tab-safe、参照はsorted/uniqueです。このファイルは、静かな再起動後も履歴コンテキストを保持します。歴史を現在の存在に変えることは決してありません。

<a id="route-proof-schema"></a>
## ルート証明スキーマ

`runtime/final_logs/route_proof.json` は `randomdayguard.route-proof/v1`と、トップレベルの生成タイムスタンプ、バージョン、ブート、エポック、ポーリング、ソースの鮮度、現在のサイクルの完全性、許可されたステータス、`routes`配列が記録されます。

各ルート エントリには、route/status, version/boot/epoch/poll、ソース鮮度オブジェクト、電流サイクルの完全性、出力パス、ソース参照。無効化されたルートレコードは `status="missing"` と `reason="route_disabled"` となります。ルートプルーフ書き込みが失敗した場合、通知候補が受け入れられる前に、すべてのルートがincomplete/missingとして書き換えられます。

<a id="notification-schemas"></a>
## 通知スキーマ

オプションのパブリック モードは、ローカル ファイル送信ボックスのみです。

`runtime/notifications/pending/<route>_latest.json` は `randomdayguard.notification/v1`生成されたタイムスタンプ、version/boot/epoch/ poll/source鮮度、ルート、 `completed_output`、ルートプルーフ ステータス、構造化および翻訳されたレポート パス、ソース参照、`delivery_backend="none"` と一致する必要があり、`delivery_attempted=false`。対象となる出力には `status="ready_for_local_consumer"`, `delivery_eligible=true` と一致する必要があり、`delivery_allowed=true` が使用されます。設定されていても missing/ineligible ルートは、`status="suppressed_current_cycle"` の両方の配信フラグが false で、`suppression_reason="route_or_completion_policy_blocked"` の監査エンベロープを書き込みます。したがって、 `pending/` にファイルが存在すること自体は、キューに入れられているか適格であることを意味しません。

`runtime/notifications/notification_status.json` は `randomdayguard.notification-status/v1` 同じ系統、 `generic_local_outbox_only=true`, `delivery_attempted=false` およびルートごとの `queued`/`outcome` 行を持ちます。 `full` が対象です。 Expected-empty は、`include_expected_empty=true`; `missing` が決して適格でない場合にのみ適格です。ルートプルーフ書き込み失敗の場合、ステータス結果は `route_proof_write_failed` になります。抑制された監査エンベロープは引き続き書き込まれる可能性がありますが、出力は受け入れられません。

<a id="runtime-output-inventory"></a>
## ランタイム出力インベントリ

トレーサビリティ インデックスには、パスまたは動的ファイル クラスごとに 1 つのマシン行があります。この読み取り可能なインベントリは、オペレータの目的別にファイルをグループ化します。

| パスまたはパターン | Producer/trigger | ポリシーと有用な状態 | Failure/recovery |
|---|---|---|---|
| `runtime/loader_probe.txt`, `runtime/loader_probe.json` | ローダー エントリ。 | 上書きされた起動 identity/probe. | 紛失しても負荷が証明されるわけではありません。 UE4SS ログと有効化を検査します。 |
| `runtime/config_load_error.txt` | 設定の読み込みエラー。 | エラーのみ、制限された理由を保持します。 | 有効なパブリック設定を復元して再起動します。 |
| `runtime/saved_path_probe.json` | 保存されたルート解決。 | Candidate/readabilityアカウンティングに使用される参照。 | オペレータがオプションの低速ソースで現在のレポートをブロックしたい場合にのみ`SavedRoot.txt`または汎用候補を修復します。 |
| `runtime/startup_status.json`, `runtime/startup_error.txt`, `runtime/current/startup_error.json` | 起動ライフサイクル。 | 最新の起動エラーと現在のブート エラー。 | 一致するブートのみが現在のクリティカル ステータスを所有します。 |
| `runtime/runtime_version.json`, `runtime/runtime_capabilities.json`, `runtime/public_pipeline_status.json` | Startup/report統合。 | 最新version/capability/handoff状態。 | バージョンまたは機能のドリフトは、完了の要求をブロックします。 |
| `runtime/poll_status.json`, `runtime/current/poll_status.json`, `runtime/poll_error.txt`, `runtime/current/poll_error.json` | ポーリングfinalizer/error. | 最新poll/scheduler/in-flight状態と現在のブート エラー。 | 制限付きコールバックを修復し、より新しい完了したポーリングを要求します。 |
| `runtime/logs/current.jsonl`, `runtime/raw_events.jsonl` | イベント ロガー。 | 制限付き append/rotation. | 前のバイトを保持します。修理disk/retentionギャップに依存する前に。 |
| `runtime/log_offsets.tsv`, `runtime/log_registry.json` | ログtail/registry. | 最新のオフセットと正規のログ ID。 | 慎重に再構築してください。バックアップ ログは履歴のまま残ります。 |
| `runtime/log_continuity_events.jsonl`, `runtime/evidence/log_continuity_events.jsonl`, `runtime/server_lifecycle_events.jsonl`, `runtime/evidence/lifecycle_events.jsonl` | Continuity/lifecycleノーマライザー。 | 追加専用コンテキスト。 | 欠落しているコンテキストは証明できないgraceful/crash状態。 |
| `runtime/current_server_epoch.json`, `runtime/server_epochs.jsonl`, `runtime/epochs/**` | エポック所有者。 | 現在および保持されているサーバー エポック。 | 次の後に新しいエポックを開始します。修理;古い履歴は書き換えないでください。 |
| `runtime/session_events.tsv`, `runtime/evidence/session_events.jsonl`, `runtime/sessions/**` | セッション所有者。 | Current/historicalセッション イベントとスナップショット。 | マップされていない行は不明のままです。 ID の発明はありません。 |
| `runtime/account_evidence.tsv`, `runtime/account_evidence.json`, `runtime/history/public_accounts.tsv` | Account/session集計およびレポート モジュール。 | 現在のスナップショットと永続的な履歴。 | スコープを分離し、推測ではなく証拠から復元します。 |
| `runtime/current/session_state.json`, `runtime/current/active_accounts.json`, `runtime/current/spatial_context.json`, `runtime/current/actor_touch_rollup.json` | Poll/current-stateライター。 | 現在のスナップショットを上書きします。 | Stale/missing は不明です。空ではありません。 |

<a id="failure-and-recovery-matrix"></a>
## 障害と回復のマトリックス

| 障害 | 必要な状態 | 安全な回復 | 無効な推論 |
|---|---|---|---|
| 現在の系統 absent/stale | すべてのルート `missing`. | active-log/current-poll証明して再生成します。 | 古いルート ファイルは現在完成していません。 |
| オプションのソースは空であることが期待されます | ソース `expected_empty`;対象となるルートは、`limited_expected_empty`. | ソースが存在する必要がない限り修復できません。 | 空は利用できないわけではなく、履歴が存在しないことを証明しません。 |
| スキャンが不完全 | ソース `partial` または `deferred`. | 制限付き再開を許可します。現在のルート ポリシーを明示的に保ちます。 | 部分は破損していません。 |
| 必要なソースが利用できません | `coverage_status=unavailable`;依存ルート`missing`. | 選択したSaved/logアクセスを修復します。 | 他の正常なソースは必要なソースを置き換えません。 |
| 必要なソースのプローブ エラー | ソースのステータス `error` 制限付き`detail`; `coverage_status=unavailable`;依存ルート`missing`. | 名前付きsource/probeを修復し、新しいサイクルを生成します。 | ソース エラーは 5 番目のトップレベル カバレッジ値ではありません。 |
| ペア レポートの書き込みは失敗します。 | `coverage_status=unavailable`;ルートは、`missing`. | ファイル システムを修復し、両方のペア メンバーとプルーフを再書き込みします。 | 1 つの兄弟ファイルが完了しておらず、書き込み失敗がトップレベルではない`error`. |
| ルートプルーフ書き込み失敗 | 再書き込みされたすべてのルートが欠落しています。対象となる送信トレイがありません。設定されたルートは抑制された監査エンベロープを受け取る可能性があります。 | ルートプルーフ書き込みを修復し、同じサイクル出力を再生成します。 | 有効なレポート JSON または抑制されたエンベロープはルート証明ではありません。 |
| 通知の書き込みが失敗する | 結果 `local_outbox_write_failed`. | 修復ローカル出力ルート。完了したレポートから再生成します。 | 外部配信は行われませんでした。 |
| Admin.iniトランザクションが失敗しました。 | 適用は、backup/write/readback/rollback証拠を検査します。 | 検証済みのバックアップの復元でブロックされました。  | しきい値やレポートによって回復のバイパスを正当化することはできません。 |

参照[`EVIDENCE_BOUNDARY.md`](%E8%A8%BC%E6%8B%A0%E3%81%AE%E5%A2%83%E7%95%8C.md), [`ARCHITECTURE.md`](%E3%82%A2%E3%83%BC%E3%82%AD%E3%83%86%E3%82%AF%E3%83%81%E3%83%A3.md) と一致する必要があり、[`SOURCE_MODULE_REFERENCE.md`](%E3%82%BD%E3%83%BC%E3%82%B9_%E3%83%A2%E3%82%B8%E3%83%A5%E3%83%BC%E3%83%AB_%E3%83%AA%E3%83%95%E3%82%A1%E3%83%AC%E3%83%B3%E3%82%B9.md).
