# ステータスとエラーのリファレンス

> **正規の英語ソース:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). このローカライズされたドキュメントには、正確なコマンド、パス、キー、ステータス値、ハッシュ、ファイル名が保存されています。技術的な表現が異なる場合は、英語のソースを使用してください。


で症状が分類された後、このリファレンスを使用してください。[トラブルシューティング](%E3%83%88%E3%83%A9%E3%83%96%E3%83%AB%E3%82%B7%E3%83%A5%E3%83%BC%E3%83%86%E3%82%A3%E3%83%B3%E3%82%B0.md)エラーによって指定された構造化ステータス ファイルを読み取ります。個別のコードは、個別の安全性とライフサイクル状態を表します。それらを一般的な「ガード失敗」の結果にまとめないでください。

<a id="route-and-source-states"></a>
## ルートとソースの状態

| 値 | 意味 | オペレーターの応答 |
|---|---|---|
| `full` | 現在のサイクルのソース証明でルート契約が完了しました。 | ルートの証拠の境界を読み取ります。修復は暗示されません。 |
| `limited_expected_empty` | ルートは完了し、欠落しているアクティビティはこのサイクルでは正当です。 | 合成イベントは作成されませんplayer/case。 |
| `missing` | 必要な出力、系統フィールド、またはソース証明がありません。 | ルートの理由と名前付きソースのステータスを検査してください。 |
| `available` | 名前付きソースは読み取り可能であり、使用可能でした。 | いいえアクション。 |
| `expected_empty` | ソースはチェックされ、正当に行がありませんでした。 | アクティビティが独自に予期されない限り、アクションはありません。 |
| `partial` / `complete_with_gaps` | 使用可能な証拠は存在しますが、名前付きソース クラスが不完全です。 | 収集された証拠に結論を限定します。 |
| `deferred` | 制限された作業は後のワーカーにスケジュールされます。  | 設定を変更する前に、進捗状況を確認してください。 |
| `unavailable` | 環境がソースを提供しませんでした。 | 制限を記録します。証明されたパスまたは権限の問題のみを修正してください。 |
| `malformed` | ソースは読み取り可能でしたが、構造検証に失敗しました。 | ソースを保存して修正します。推測しないでください。 |
| `permission_denied` | ソースは存在しますが、読み取れませんでした。 | 必要な一部の読み取り権限のみを付与します。 |
| `error` | 記録された理由により収集に失敗しました。 | エラーを保存し、その段階を診断します。 |

<a id="playerdata-and-inventory-codes"></a>
## PlayerData と在庫コード

| コード | 意味 | 安全な応答 |
|---|---|---|
| `saved_root_unavailable` | パブリック パイプラインで使用できる検証済みの保存済みルートがありませんでした。 | 修正し`SavedRoot.txt`、パス プローブを再確認します。 |
| `unsafe_playerdata_root` | PlayerData 検出は、境界のある保存されたルートの外側で解決されました。 | パスを修正してください。境界を弱めないでください。 |
| `playerdata_discovery_not_run` | 制限付きディスカバリ ワーカーはまだ実行されていません。 | スケジューラとワーカーの進行状況を確認してください。 |
| `playerdata_discovery_read_failed:*` | ディスカバリ出力を読み取れませんでした。 | サフィックスの詳細を保存し、制限付きインベントリ コマンドを確認してください。 |
| `inventory_command_open_failed` | インベントリ プロセスを実行できませんでした。  | ランタイムが構成されたコマンド ブリッジを提供していることを確認します。 |
| `inventory_command_read_failed` | 読み取り中にインベントリ出力が失敗しました。 | 部分的な出力を保持し、根本的なエラーが修正された後にのみ再実行します。 |
| `inventory_command_close_failed` | 信頼できるクローズ結果が得られずにインベントリが完了しました。 | ソースを次のように扱います。不完全。 |
| `identity_ledger_row_limit_exceeded` | 永続的な ID 入力が公安の限界を超えました。 | 台帳をアーカイブして確認します。完全な証明に黙って切り詰めないでください。 |

<a id="adminini-enforcement-codes"></a>
## Admin.ini施行コード

このセクションのコードはすべてフェールクローズされます。手動禁止を単独で許可するものではありません。

| コード | 意味 | 安全な応答 |
|---|---|---|
| `admin_ini_write_disabled` / `admin_ini_disabled` | 公衆に安全な書き込みゲートがオフになっています。 | レビューのみの操作で期待されます。 |
| `admin_ini_backup_disabled` / `backup_safety_gate_disabled` | 必要なバックアップ ポリシーがアクティブではありません。 | 書き込みを無効にしてください。 |
| `enforcement_disabled` / `ban_on_threshold_disabled` / `auto_ban_disabled` | 明示的な強制ゲートの 1 つは、オフ。 | パブリック レビューのみのデフォルトで期待されます。これを書き込み失敗として再解釈しないでください。 |
| `review_only_mode_enabled` | レビュー専用モードは、突然変異を意図的にブロックします。 | 証拠のみを確認します。 |
| `duplicate_prevention_disabled` | 重複保護が無効になりました。 | セーフティ ゲートが復元されるまで書き込みを無効のままにしておきます。 |
| `readback_safety_gate_disabled` / `rollback_safety_gate_disabled` | 書き込み後の検証またはロールバック保護が無効になりました。 | 保持書き込みが無効になります。これらのゲートは決してバイパスしないでください。 |
| `clean_id_safety_gate_disabled` / `account_specific_evidence_gate_disabled` | クリーンな ID またはアカウント固有の証拠の強制が無効になりました。 | 強制テストの前にゲートを復元してください。 |
| `moderator_preservation_disabled` / `existing_ban_preservation_disabled` | 保護されたアカウントまたは既存の禁止の保存が無効になりました。 | 書き込みを無効にしてください。 |
| `clean_numeric_identity_required` | 提案された ID は、完全に受け入れられた接続フォームまたはクリーンな数値 ID ではありません。 | 検証済みのマッピングを取得します。任意のプレフィックスを決して切り詰めないでください。 |
| `identity_strength_below_minimum` | 身元の証拠が設定されたしきい値よりも弱いです。 | 証拠のみを確認します。 |
| `playerdata_verification_required` | 設定には次のものが必要ですPlayerData 確認しましたが、アカウントにそれがありません。 | 候補者をレビュー専用にしておきます。ファイル名から所有権を推測しないでください。 |
| `trusted_or_moderator_identity` | アカウントは信頼済みまたはモデレータの状態によって保護されています。 | 書き込みは許可されません。 |
| `admin_ini_path_invalid` / `admin_ini_path_outside_saved_root` | ターゲット パスが無効であるか、保存されたルートをエスケープしています。 | 正しい設定。パス ガードをバイパスしないでください。 |
| `admin_ini_unavailable` | 読み取り可能な設定がありませんAdmin.iniが、保存されたルート内に見つかりませんでした。 | 境界パスを修正するか、強制を無効のままにしてください。 |
| `admin_ini_read_failed` | 権限のあるバイトを読み取ることができませんでした。 | 変更の前に停止してください。 |
| `admin_ini_parse_failed` | Admin.ini より具体的な構造コードがないと検証に失敗しました。 | ファイルを保存し、そのセクションと行の構造を検査します。 |
| `admin_ini_contains_nul` | ファイルには次の内容が含まれていますNUL バイトであり、テキストとして受け入れられません。 | ファイルを保存し、Guard の外で修復します。 |
| `admin_ini_duplicate_banned_players_section` | 複数の`[BannedPlayers]`セクションが存在します。 | セクションを手動でマージします。停止しました。 |
| `admin_ini_banned_player_outside_section` | 禁止行が外側に表示されます。`[BannedPlayers]`. | レイアウトを手動で修正してください。 |
| `admin_ini_invalid_banned_player_line` | 禁止行は、正確にはサポートされている ID 行ではありません。 | 不正な行を修正してください。 |
| `admin_ini_backup_failed` | 一意のバックアップはバイト同一に書き込みおよび読み取りを行っていません。 | 変更は許可されません。 |
| `admin_ini_external_change_detected` | 別のライターが Guard のスナップショット後にファイルを変更しました。 | 外部バイトを保存し、ライターを調整した後でのみ再試行してください。 |
| `atomic_rename_unavailable` | アトミック置換が要求されましたが、Lua が提供しませんでした。`os.rename`. | 書き込みは信頼されません。サポートされているランタイムを使用するか、強制を無効のままにしてください。 |
| `admin_ini_write_failed` | 制御された置換は完了しませんでした。 | 記録された置換エラーとバックアップを検査します。 |
| `post_write_verification_failed` | 実稼働バイト数が候補と一致しませんでした。 | アクションの前に `rollback_success` と `rollback_refused_external_change` を確認してください。 |

<a id="startup-scheduler-and-backlog-states"></a>
## スタートアップ、スケジューラー、バックログの状態

これらの値はライフサイクルの証拠であり、ルートの証明ではありません。現在のポーリング、レポートワーカー、およびルートプルーフ ファイルを使用してそれらを読み取ります。

| 値 | 意味 | 安全な応答 |
|---|---|---|
| `not_started` | 指定されたスタートアップ ステージまたはスケジューラー ステージはまだ開始されていません。 | 起動中は、記載されている間隔が経過するまで待ちます。その後、最初の変更されていないフェーズを検査します。 |
| `main_lua_loaded` / `starting` | 正規ローダーが実行され、Guard が起動に入りました。 | 後のフェーズに進みます。これだけでは準備完了とは言えません。 |
| `saved_root_found` / `log_tail_initialized` / `epoch_started` | コア ソースと継続性の初期化が進みました。 | 次のフェーズの進行が停止しない限り、アクションはありません。 |
| `admin_state_written` / `playerdata_index_written` | 初期の制限付きインデックスはエクスポートされました。 | アクションはありません。スケジューラのハンドオフは引き続き続行する必要があります。 |
| `watchdog_started` | レポートとポーリングのウォッチドッグが登録されました。 | 次にスケジューラとポーリングの進行状況を確認します。 |
| `ready_degraded` / `scan_running` | 制限付き履歴スキャンが保留中の間、Guard は実行されています。 | 失敗ではなく注意してください。進行状況カウンタが進んでいることを確認します。 |
| `ready` | 起動し、現在のバインド スキャンが準備完了状態に達しました。 | ルート証明を個別に確認します。 |
| `scan_failed` / `error` | 起動またはスキャンは、記録されたエラーで終了しました。 | 指定されたエラー ファイルまたはステータス ファイルを保存し、その段階を診断します。 |
| `running` | スケジューラは、将来のポーリングの機会。 | 有効のままであることを確認します。`poll_id` と `poll_completed_count`前進。 |
| `manual_only` | ループ スケジュールは利用できませんでした。明示的な作業のみを実行できます。 | 無人操作は利用できないものとして扱います。 |
| `stopped` | スケジューラ操作は終了しました。 | 再起動前に、前の停止とエラーの証拠を検査します。 |
| `active_log_caught_up` | 未読のアクティブ ログ バックログは残りません。 | 履歴スキャンは可能です。続行します。 |
| `active_log_unavailable_nonblocking` | アクティブなログは存在しませんでしたが、起動はノンブロッキングのままでした。 | ソース制限を記録し、他のソースを確認します。 |
| `active_log_read_failed` | アクティブなログは存在しましたが、読み取ることができませんでした。 | エラーを保持し、証明されたパスまたは権限の問題のみを修正します。 |
| `budget_exhausted` / `active_log_has_unread_bytes` | バックログが残ったまま境界付き末尾パスが停止しました。 | 後でポーリングして未読数が減少していることを確認します。 |
| `offset_commit_failed_after_events_applied` | イベントは処理されましたが、永続的なログ オフセットの永続化に失敗しました。 | 適用は延期されます。別のサイクルに依存する前にオフセット ストレージを修復します。 |

<a id="scheduler-report-and-notification-codes"></a>
## スケジューラ、レポート、および通知コード

| コードまたはステータス | 意味 | 安全な応答 |
|---|---|---|
| `poll already in flight` | 現在のポーリングがライフサイクルを所有している間に 2 番目のコールバックが到着しました。 | 既存のポーリングが進んでいることを確認します。別のループ所有者を追加しないでください。 |
| `no_log_files_found` | 設定されたアクティブ ログまたはバックアップ ログが検出されませんでした。 | 保存されたルートとソースの設定を確認してください。 |
| `current_poll_error` | 現在のサイクルでポーリング ソースの失敗が記録されました。 | 読み取り `runtime/current/poll_error.json`. |
| `cadence_deferred` | 完了ディスパッチャの期限はまだありません。 | 次の限定された機会まで期待されます。 |
| `reports_disabled` | パブリック レポートの生成は無効になっています。 | レポートが目的の場合にのみ有効にします。 |
| `local_outbox_write_failed` | 翻訳されたローカル エンベロープを書き込むことができませんでした。 | ランタイム出力ディレクトリを修復します。これは通知トランスポート エラーではありません。 |
| `source_accounting_disabled` | ルート証明では完全なソース カバレッジを主張できません。 | ソース アカウンティングを有効にするか、欠落している証明を明示的に受け入れてください。 |
| `route_disabled` | ルートは意図的に無効になっています。 | そのルートでは配信は期待されません。 |
| `poll_owner_between_polls` | レポート ワーカーは、スケジューラが所有するポーリング間のギャップのためにキューに入れられます。 | タイムスタンプとカーソルが進み続ける間のみ期待されます。 |
| `unsafe_shell_path` | 制限されたインベントリまたはシェル パスがプラットフォーム セーフ検証に失敗しました。 | パスを修正してください。引用やパスの検証を決して弱めないでください。 |
