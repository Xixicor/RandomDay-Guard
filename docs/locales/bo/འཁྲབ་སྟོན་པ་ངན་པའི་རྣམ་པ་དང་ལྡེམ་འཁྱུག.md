# འཁྲབ་སྟོན་པ་ངན་པའི་རྣམ་པ་དང་ལྡེམ་འཁྱུག

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [BAD_ACTOR_PATTERNS_AND_RESILIENCE.md](../../BAD_ACTOR_PATTERNS_AND_RESILIENCE.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


ཤོག་ངོས་འདི་བེད་སྤྱད་ནས་སྲུང་མ་དེས་རྐྱེན་ངན་ལོག་སྤྱོད་དང་།

<a id="what-the-guard-can-help-with"></a>
## སྒོ་སྲུང་བ་དེས་ག་རེ་རོགས་རམ་བྱེད་ཐུབ་པ

| བཀོད་རིས། | ག་རེ་བརྟག་དཔྱད་བྱེད་དགོས་སམ། |
|---|---|
| བརྡབ་སྐྱོན་དང་འབྲེལ་བའི་ཕྱིར་ལོག | རྩིས་ཁྲ་གཅིག་པ་དེ་བརྡབ་སྐྱོན་བྱུང་བའི་སྔོན་ལ་ཤུགས་ལྡན་ཡིན་པ་དང་བསྐྱར་དུ་འགོ་འཛུགས་རྗེས་ཕྱིར་ལོག་བྱེད་ཀྱི་ཡོད། |
| མགྱོགས་མྱུར་བསྐྱར་སྦྲེལ་ཞིབ་འཇུག | བསྐྱར་ཟློས་བྱས།join/leave ཡང་ན་ timeout/reconnect བསྐྱར་འཁོར་ |
| སྣ་མང་རྩིས་ཁྲའི་ཕྲེང་བ། | མཉམ་སྦྲེལ་རླབས་དང་། མཉམ་སྤྱོད་ཉེན་བརྡའི་སྒེའུ་ཁུང་། མཉམ་སྤྱོད་འཐུས་ཤོར་སྒེའུ་ཁུང་། |
| ཉེན་བརྡའི་འབར་གས་གནོན་ཤུགས། | བསྐྱར་ཟློས་བྱས།ActorChannelFailure ཡང་ན་ཉར་ཚགས་ཉེན་བརྡའི་སྒེའུ་ཁུང་ |
| ཚད་ལས་ཕྱི་རོལ་གྱི་སྐབས་དོན། | PlayerData/map/world སྐབས་དོན་ཀློག་ཐུབ་པའི་སྐབས་ |
| ཉར་ཚགས་-རེག་བྱ་བརྗེ་རེས་ | འཛམ་གླིང་ཉར་ཚགས་སྐབས་དོན་བརྗེ་སྒྱུར་ས་ཁྲ་བཟོས་པའི་དུས་ཚོད་ |
| ངོས་འཛིན་མགོ་རྙོག | མཐུད་སྣེ་ཨང་རྟགས་ས་ཁྲ་བཟོ་དགོས་པའི་མིང་། |

<a id="why-it-avoids-memory-access"></a>
## དེས་དྲན་ཚད་འཛུལ་སྤྱོད་སྤོང་བའི་རྒྱུ་མཚན།

RandomDayGuard སར་བར་གྱི་བདག་དབང་ཡོད་པའི་ཡིག་ཆ་ལས་ལས་ཀ་བྱེད།

```text
Saved/Logs/*.log
Admin.ini
World saves
PlayerData
Backups
runtime evidence
```

དེས་ཚོང་ཤག་ཕྱོགས་ཀྱི་དྲན་ཤེས་གནས་སྟངས་ལ་རག་ལུས་མེད་པ་དང་རྩེད་མོའི་དུས་བསྟུན་གྱི་སྐབས་སུ་སྙིང་རྗེ་པོ་མེད་པ་བཟོས།

བརྗེ་རེས།

```text
It cannot prove hidden live actions unless the server writes evidence.
```

<a id="crash-correlated-returners"></a>
## བརྡབ་སྐྱོན་དང་འབྲེལ་བའི་ཕྱིར་ལོག་པ་

བཀོད་རིས་:

```text
Account joins.
Server crashes or restarts.
Same account reconnects quickly.
Pattern repeats.
```

ཕན་ཐོགས་པའི་ཡིག་ཆ།

```text
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/account_evidence.json
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="rapid-reconnect-probers"></a>
## མགྱོགས་མྱུར་བསྐྱར་མཐུད་འཚོལ་ཞིབ་འཕྲུལ་ཆས་

བཀོད་རིས་:

```text
join -> leave -> join -> leave -> join
```

ཕན་ཐོགས་པའི་ཡིག་ཆ།

```text
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/account_evidence.json
runtime/forensic_days/YYYY-MM-DD/players.tsv
```

<a id="multi-account-clusters"></a>
## སྣ་མང་རྩིས་ཁྲའི་ཕྲེང་བ།

བཀོད་རིས་:

```text
Several accounts join in the same window.
Warnings or crashes follow.
Some accounts rotate or reconnect after restart.
```

ཕན་ཐོགས་པའི་ཡིག་ཆ།

```text
runtime/raid_cases/
runtime/forensic_days/YYYY-MM-DD/raid_cases.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

ཁྲིམས་ལུགས།

```text
A cluster is not a mass-ban list.
Each account still needs its own evidence.
```

<a id="sticky-backup-recommendation"></a>
## སྦྱར་བའི་རྒྱབ་ལྗོངས་འོས་སྦྱོར།

རྗེས་སུ་སྦྱར་བའི་རྒྱབ་ལྗོངས་གསར་བཟོ།:

```text
first full baseline completes
object_registry.json exists
file_manifest.tsv exists
world_state_latest.json has scan_complete=true
Admin.ini is verified
trusted IDs are configured
```

རྒྱབ་སྣོན།

```text
RandomDayGuard/config.lua
RandomDayGuard/SavedRoot.txt
RandomDayGuard/runtime/baselines/
RandomDayGuard/runtime/object_registry.json
RandomDayGuard/runtime/world_state/current/world_state_latest.json
Saved/SaveGames/Server/Admin.ini
```

<a id="recovery-model"></a>
## སླར་གསོའི་དཔེ་གཞི།

```text
Clean install
-> verify live defense
-> complete first baseline
-> create sticky backup
-> run server normally
-> use daily rollups for review
-> restore sticky backup if needed
```
