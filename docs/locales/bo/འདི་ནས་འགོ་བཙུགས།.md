# འདི་ནས་འགོ་བཙུགས། སྲུང་སྐྱོབ་སྙན་ཞུ་དང་པོ་ཀློག

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [START_HERE.md](../../START_HERE.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


ལམ་སྟོན་འདི་RandomDayGuard སྒྲིག་འཇུག་དང་ནུས་ལྡན་བཟོས་ཡོད། དེས་བཀོལ་སྤྱོད་པ་གསར་པར་ཐོན་ཁུངས་ཨང་རྟགས་དང་། ཐུམ་སྒྲིལ་ནང་ཁུལ། ཡང་ན་འཕྲུལ་ཆས་ཁོ་ནའི་གནས་ཚུལ་ཡིག་ཆ་ཞིབ་བཤེར་བྱེད་དགོས་པའི་བཀའ་མ་བཏང་བར་ཕན་ཐོགས་པའི་གྲུབ་འབྲས་གཅིག་ཁུངས་སྐྱེལ་བྱེད།

## སར་བར་འགོ་འཛུགས་རྗེས་ག་རེ་འབྱུང་གི་རེད།

སྲུང་སྐྱོབ་པས་རྩེད་མོའི་སར་བར་སྒུག་པ་དང་UE4SS མངོན་འཆར་བྱེད་པར་སར་བར་གྱི་ཡོད་པའི་དྲན་ཐོ་འཚོལ་བ་དང་ མཐའ་མཚམས་རྒྱབ་ལྗོངས་བརྟག་དཔྱད་འགོ་འཛུགས། ལོ་རྒྱུས་རྙིང་པ་དེ་ད་དུང་དཀར་ཆག་བཟོ་བཞིན་པའི་སྐབས་སུ་ད་ལྟའི་སར་བར་གྱི་འཕྲོད་བསྟེན་སྙན་ཞུ་བྱེད་ཐུབ།

སྙན་ཞུ་དང་པོ་དེ་ **སར་བར་གྱི་གནས་ཚུལ་**. དེས་ད་ལྟ་སྲུང་སྐྱོབ་པས་ལྟ་རྟོག་འཁོར་ཡུན་མཇུག་སྒྲིལ་བཞིན་ཡོད་མེད་དང་། གལ་ཏེ་དུས་ཚོད་མཚོན་རྟགས་དེ་ཡོད་ན། ད་ལྟའི་ཞབས་ཞུ་འཕྲུལ་ཆས་བཀོལ་སྤྱོད་བྱེད་འགོ་ཚུགས་སྐབས།active/rotated དྲན་ཐོ་དང་པར་བཤུས་ཁྱབ་ཁོངས་ཡོད་མེད་དང་། རྩེད་མོ་བ་ག་ཚོད་མཐུད་ཡོད་དམ། ཐོན་ཁུངས་སྡེ་ཚན་གང་ཞིག་མེད་པ། དེ་བཞིན་བཀོལ་སྤྱོད་པའི་བྱ་སྤྱོད་དགོས་མིན་བཅས་ཡིན།

རྒྱབ་ལྗོངས་བརྟག་དཔྱད་དེ་ད་དུང་འཕེལ་རྒྱས་འགྲོ་བཞིན་པ་དེ་ནི་ལོ་རྒྱུས་ཀྱི་ཁྱབ་ཁོངས་ལ་ཚད་བཀག་བྱེད་པ་ལས་རང་འགུལ་གྱིས་འགོ་འཛུགས་འཐུས་ཤོར་མིན། གྷར་ཌི་ཡིས་པར་བཤུས་འོད་རྟགས་དང་། ཡིག་ཆ་མཇུག་སྒྲིལ་བ། ཡིག་ཆ་རྙེད་པ། དེ་བཞིན་མཐའ་མའི་འཕེལ་རྒྱས་དུས་ཚོད་བཅས་ཐོ་འགོད་བྱེད། གལ་ཏེ་རིན་ཐང་དེ་དག་བསྐྱར་ལོག་ལྟ་རྟོག་འཁོར་རིམ་ནང་འགྱུར་བ་འགྲོ་རྒྱུ་མཚམས་འཇོག་ན། ལོ་རྒྱུས་རྙིང་པ་མ་ཚང་བའི་རྐྱེན་གྱིས་ད་ལྟའི་དྲན་ཐོ་དང་ལས་རིམ་གྱི་གྲུབ་འབྲས་དེ་དག་མེད་པར་མ་བཟོ།

## ཁུ་སིམ་མེར་སྙན་ཞུ་རྟོགས།

རྩེད་མོ་བའི་བྱེད་སྒོ་དང་། གནས་ཚུལ་བསྐྱར་ཞིབ། དེ་བཞིན་གལ་ཆེའི་སྲུང་སྐྱོབ་བཅས་ནི་བྱུང་རིམ་ལ་བརྟེན་ནས་ཡིན། ཞི་འཇམ་གྱི་སར་བར་གྱིས་རྒྱུ་ལམ་བཀང་ཆེད་དུ་སྒྲུང་གཏམ་གྱི་གླུ་གཞས་གཏོང་མཁན་དང་། གྱོད་གཞི། ཡང་ན་འཐུས་ཤོར་བཟོ་མི་རུང་། ཀློག་ཐུབ་པའི་གྲུབ་འབྲས་ཀྱིས་ཐོན་ཁུངས་དེ་ཞིབ་བཤེར་བྱས་པ་དང་སྙན་ཞུ་དེའི་ནང་གང་ཡང་མི་ཚུད་ཅེས་བརྗོད་སྲིད།

ཉིན་རེའི་བསྡུ་རུབ་མི་འདྲ་བ་རེད། དེས་སྙན་ཞུའི་ཚེས་གྲངས་རེ་ལ་ཉིན་གཅིག་གི་ཚོགས་འདུ་དང་། ད་ལྟའི་བསྐྱར་ཞིབ་ཀྱི་སློབ་ཚན།identity/case སྐབས་དོན་དང་། ཡོད་པའི་སར་བར་གྱི་ཐོ་འགོད་ནང་མེད་པའི་དངོས་དོན་དེ་ཚོ་ཚོད་དཔག་བྱེད་པའི་ཚབ་ཏུ་མ་ཤེས་པར་ལུས་ཡོད།

## སྤྱིར་བཏང་གི་རྩེད་མོ་བའི་དུས་ཚོད་གཅིག་ཚོད་ལྟ་བྱེད་པ།

3. གླུ་གཞས་གཏོང་མཁན་གྱི་བྱ་འགུལ་ཁ་ཕྱེ།
4. དེས་སྲུང་སྐྱོབ་པ་ལ་ཡོད་པའི་རྩིས་ཁྲའམ་བཀྲམ་སྟོན་མིང་དང་། མཉམ་ཞུགས་དང་ཐོན་པའི་དུས་ཚོད། ལས་རིམ་གཙང་མ་ཡང་ན་མ་ཚང་བའི་གྲུབ་འབྲས། ཡོད་པའི་སྐབས་སྔོན་གྱི་ལོ་རྒྱུས། དེ་བཞིན་བྱ་སྤྱོད་རྗེས་མ་གཅིག

ལས་རིམ་སྙན་ཞུའི་ནང་དོ་སྣང་བྱས་པའི་གཞི་གྲངས་ཚུད་དགོས། ཡིག་ཆའི་མིང་ཐོ་གཞུང་ཡང་ན་ཐོ་འགོད་ཡོད་པའི་སྤྱིར་བཏང་གི་གསལ་བསྒྲགས་ཀྱིས་ཚབ་བྱེད་མི་རུང་།
