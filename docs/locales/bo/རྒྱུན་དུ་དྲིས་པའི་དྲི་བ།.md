# FAQ

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [FAQ.md](../../FAQ.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


<a id="is-randomdayguard-the-randomday-mod"></a>
## ནི་RandomDayGuard དེ་ RandomDay མོད?

མིན།RandomDay མོ་ཌི་ཡིས་སར་བར་གྱི་ཉམས་མྱོང་བསྒྱུར་བཅོས་བྱེད། RandomDayGuard སར་བར་གྱི་མངོན་གསལ་བང་རིམ་ལ་ལྟ་ཞིབ་བྱེད།

<a id="does-live-defense-work-before-the-scan-completes"></a>
## བཤེར་འཇལ་མ་ཚར་གོང་ལ་གསོན་པོའི་འགོག་སྲུང་ལས་ཀ་བྱེད་ཀྱི་ཡོད་དམ།

རེད། ཐད་གཏོང་འགོག་སྲུང་གིས་དྲན་ཐོ་དང་དུས་ཚོད་ཀྱི་བྱུང་རིམ་བེད་སྤྱོད་བྱེད་ཀྱི་ཡོད། གཞི་གྲངས་བརྟག་དཔྱད་དེས་རྗེས་སུ་སྐབས་དོན་ལེགས་བཅོས་བྱེད།

<a id="why-can-the-first-scan-take-a-long-time"></a>
## ཅིའི་ཕྱིར་ཐོག་མའི་པར་བཤུས་ལ་དུས་ཡུན་རིང་པོ་འགོར་སྲིད་དམ།

ཐོག་མའི་བཤེར་འཇལ་བཟོ་སྐྲུན་ world/object སྐབས་དོན། ཡིག་ཆའི་མངོན་ཚུལ། དེ་བཞིན་བསྐྱར་དུ་བེད་སྤྱོད་གཏོང་ཐུབ་པའི་གཞི་གྲངས་གཞི་གྲངས།

<a id="what-do-i-check-first-after-startup"></a>
## འགོ་འཛུགས་བྱས་རྗེས་ཐོག་མར་ག་རེ་བརྟག་དཔྱད་བྱེད་དགོས་སམ།

```text
runtime/current/poll_status.json
```

འཚོལ་ཞིབ།

```text
scheduler_status=running
poll_id increasing
poll_in_flight=false
```

<a id="where-are-player-summaries"></a>
## རྩེད་མོ་བའི་སྙིང་བསྡུས་གང་དུ་ཡོད་དམ།

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

<a id="where-is-the-daily-quick-review-package"></a>
## ཉིན་རེའི་མགྱོགས་མྱུར་བསྐྱར་ཞིབ་ཀྱི་ཐུམ་བུ་གང་དུ་ཡོད་དམ།

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

<a id="which-file-should-i-upload-for-fastest-review"></a>
## བསྐྱར་ཞིབ་མགྱོགས་ཤོས་ཆེད་དུ་ཡིག་ཆ་གང་ཞིག་ཡར་བསྐུར་དགོས་སམ།

```text
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="can-it-write-bans-automatically"></a>
## དེས་རང་འགུལ་གྱིས་བཀག་སྡོམ་འབྲི་ཐུབ་བམ།

གསལ་པོར་ལྕོགས་ཅན་བཟོས་ན་རྐྱངམ་གཅིག

སྔོན་སྒྲིག:

```lua
review_only_mode = true
auto_ban = false
write_admin_ini = false
```

<a id="what-does-adminini-receive"></a>
## ག་རེ་བྱེད།Admin.ini ཐོབ་བམ།

ཁོ་ན:

```ini
BannedPlayer=<ID>
```

མིང་དང་དཔྱད་བརྗོད་དང་རྒྱུ་མཚན་དང་རྗེས་འཇུག་མེད།

<a id="is-a-display-name-enough-to-ban"></a>
## འགྲེམས་སྟོན་མིང་གཅིག་གིས་བཀག་འགོག་བྱེད་པར་འདང་ངེས་རེད་དམ།

མིན། སར་བར་གྱི་དྲན་ཐོ་བེད་སྤྱོད་བྱེད།`Login request` དང་མཉམ་དུ་ `ConnectID` ཡང་ན་དེ་དང་འདྲ་མཉམ་གྱི་སར་བར་གྱི་བདེན་དཔང་།

## བརྡབ་སྐྱོན་གཅིག་གིས་མི་གཞན་ལ་བཀག་འགོག་བྱེད་ཐུབ་བམ།

## བྱ་ཚིག་མ་འོངས་པ་སྟོན་པའི་ཚིག་གྲོགསSavedRoot.txt འཛམ་གླིང་སྣོད་ལ་སྟོན་དགོས་སམ།
