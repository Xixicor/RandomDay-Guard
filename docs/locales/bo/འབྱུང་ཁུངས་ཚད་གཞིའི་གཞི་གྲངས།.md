# འབྱུང་ཁུངས་ཚད་གཞིའི་གཞི་གྲངས།

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [SOURCE_MODULE_REFERENCE.md](../../SOURCE_MODULE_REFERENCE.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


ཤོག་ངོས་འདིས་འགྲེམ་སྤེལ་ཆོག་པའི་ཐོ་གཞུང་གིས་ངོས་ལེན་བྱས་པའི་འབྱུང་ཁུངས་དང་། རིམ་སྒྲིག། གཞི་གྲངས། མཐུན་སྒྲིལ། འཕྲུལ་ཆས་ཟུར་ཐོ་ནི་[`TRACEABILITY_INDEX.json`](../../TRACEABILITY_INDEX.json); ཤོག་ངོས་འདི་ནི་ཀློག་ཐུབ་པའི་ཁྲིམས་ལུགས་ཀྱི་འགྲེལ་བཤད་ཡིན། བཟོས་པའི་འཕྲུལ་ཆས་གྲལ་ཐིག་རེ་རེ་ལ་མིང་མི་འདྲ་བ་path/class, དམིགས་ཡུལ། ཐོན་ཁུངས་བཀག་སྡོམ་བདག་དབང་། སྤྱི་དམངས་སྒྲིག་སྟངས། ཟུར་ཕོག་། བཀོལ་སྤྱོད་པས་མཐོང་བའི་གནས་སྟངས། འཐུས་ཤོར། སླར་གསོ། དང་ཁྲིམས་མཐུན་ཡིག་ཆ།

## ཐུམ་སྒྲིལ་གྱི་བཀོད་སྒྲིག

བཟོ་མཁན་གྱིས་རྩ་བའི་ཁྲིམས་མཐུན་ཡིག་ཆ་གསུམ་ཁོ་ན་ཁས་ལེན་བྱེད་ཀྱི་ཡོད།`RandomDayGuard/` གོང་དུ་འགྲོ་ལམ་དང་། གཡོག་བཀོལ་དུས་ཚོད་ཀྱི་ས་གནས་འཛིན་མཁན་སྟོང་པ་ འདིས་ཚོགས་མི་རྣམས་ལ་བའིཊ་རེ་རེར་བཀོད་སྒྲིག་བྱེད། ZIP མེ་ཊ་ཌེ་ཊ། ཁྲིམས་མཐུན་གྱི་མངོན་འཆར་ཐེངས་གཅིག་བསྡུ་སྒྲིག་བྱེད། ཚོགས་མི་རེ་རེ་ལ་སྒེར་གྱི་རྒྱུ་ཆ་འཚོལ་ཞིབ་བྱེད། SHA-256 འཐུས་མི་རེ་རེའི་ཆེད་དུ་མིང་དང་བཱའིཊི་ནང་དོན་བསྡུ་རུབ་གཅིག་ལ་སྦྲེལ་ནས་ཐེངས་གཉིས་བཟོ་སྐྲུན་བྱེད། བརྟག་དཔྱད་ཀྱིས་གནས་ཚུལ་གྱི་གདོང་ཐུག་རེ་རེ་ཁས་མི་ལེན་པར་སྤྱིར་བཏང་གི་འཐེན་བཤེར་གྱིས་ཡིག་མཛོད་ཀྱི་ཐོ་འགོད་རེ་ལ་དངོས་གཟུགས་ཡིག་ཆ་གཅིག་ཐོན་སྐྱེད་བྱེད་པར་ཁུངས་སྐྱེལ་བྱེད།
