# བརྟག་དཔྱད་བརྡ་རྟགས།

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [DETECTION_SIGNALS.md](../../DETECTION_SIGNALS.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


བརྡ་རྟགས་ནི་བསྐྱར་ཞིབ་ཀྱི་ནང་འཇུག་ཡིན་པ་ལས་རང་འགུལ་གྱི་སྐྱོན་བརྗོད་མིན།

<a id="login-identity"></a>
## ནང་འཇུག་ངོ་རྟགས།

ཐོན་ཁུངས་ཡག་ཤོས།

```text
Login request
Name=
ConnectID=
UniqueId=
```

ས་ཁྲ་བཟོ་བར་བེད་སྤྱོད་བྱོས།

```text
display/log name -> account_id -> ban_id
```

<a id="rapid-reconnect"></a>
## མགྱོགས་མྱུར་བསྐྱར་མཐུད་

བཀོད་རིས་:

```text
join -> leave -> join -> leave -> join
```

བསྐྱར་ཟློས་བྱེད་སྐབས་བསྐྱར་ཞིབ་ཆེད་དུ་བེད་སྤྱོད་བྱེད།

བདེ་འཇགས:

```text
churn_alone_never_bans = true
```

<a id="crash-overlap-and-post-crash-return"></a>
## བརྡབ་སྐྱོན་བརྗེ་རེས་དང་བརྡབ་སྐྱོན་རྗེས་ཀྱི་ཕྱིར་ལོག

བཀོད་རིས་:

```text
account active before crash
server restarts
same account returns quickly
```

དུས་རབས་བར་དུ་བསྐྱར་ཟློས་བྱེད་སྐབས་བསྐྱར་ཞིབ་ཆེད་དུ་བེད་སྤྱོད་བྱེད།

བདེ་འཇགས:

```text
single_crash_never_bans = true
```

<a id="warning-bursts"></a>
## ཉེན་བརྡའི་འབར་གས་

དཔེར་ན།

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

ས་ཁྲ་བཟོས་པའི་ལས་རིམ་དང་ཚད་གཞི་ལ་འབྲེལ་མཐུད་མ་བྱེད་བར་དུ་སྐབས་དོན་ལྟར་བེད་སྤྱོད་བྱེད།

<a id="actor-save-touch"></a>
## འཁྲབ་སྟོན་པ་ཉར་ཚགས་ཀྱི་རེག་ཐུག

ནང་དོན:

```text
The server evidence referenced a class or actor.
```

དོན་དག་མིན།

```text
A player opened it.
A player stole from it.
A player duplicated through it.
A player damaged it.
```

<a id="raid-cases"></a>
## བཙན་འཛུལ་གྱོད་གཞི་

བཙན་འཛུལ་གྱོད་གཞི་ཞིག་གིས་དུས་ཚོད་དང་མཉམ་སྤྱོད་སྒེའུ་ཁུངས་ལྟར་རྩིས་ཁྲ་སྡེ་ཚན་བཟོས།

ཁྲིམས་ལུགས།

```text
Do not auto-ban every account in a raid case.
Each account needs account-specific evidence.
```
