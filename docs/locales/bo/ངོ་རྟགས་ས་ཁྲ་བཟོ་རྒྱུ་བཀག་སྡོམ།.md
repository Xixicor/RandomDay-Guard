# IDས་ཁྲ་བཟོ་རྒྱུ་བཀག་སྡོམ།

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [BAN_ID_MAPPING.md](../../BAN_ID_MAPPING.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


རྩེད་ཆས་ཀྱི་མིང་ཉེན་མེད་དུ་བསྒྱུར་དུས་ཤོག་ངོས་འདི་བེད་སྤྱོད་བྱེད། `Admin.ini` བཀག་སྡོམ་གྲལ་རིམ།

<a id="core-rule"></a>
## ལྟེ་བའི་ཁྲིམས་ལུགས།

མངོན་པའི་མིང་ནི་བཀག་སྡོམ་ཨང་རྟགས་མིན།

`Admin.ini` བེད་སྤྱོད།

```ini
BannedPlayer=<raw numeric player ID>
```

<a id="evidence-hierarchy"></a>
## བདེན་དཔང་རིམ་པ་

| རིམ་པ་ | འབྱུང་ཁུངས | བེད་སྤྱོད། |
|---:|---|---|
| 1 | ཞབས་ཞུའི་དྲན་ཐོ། `Login request` | མིང་ནས་IDས་ཁྲ་བཟོ་སྟངས་ཡག་ཤོས། |
| 2 | `Player_<ID>.sav` | IDཡོད་པར་གཏན་འཁེལ་བྱེད། |
| 3 | ད་ཡོད་ཀྱི`Admin.ini` | ད་ཡོད་ཀྱིbans/moderators |
| 4 | ཕྱི་ཕྱོགས་ཀྱི་བརྡ་ཐོའམ་གཙོ་གཉེར་སྒྲོམ་གྱི་བྱ་འགུལ། | Time/name སྐབས་དོན་ཁོ་ན་དང་། ID དཔང་ཡིག་མིན། |
| 5 | UE4SS focus/player གྲལ་ཐིག་ | Presence/context ཁོ་ན |
| 6 | མ་ལག་གི་ཚེ་སྲོག་འཁོར་རིམ་ཡང་ན་སྣོད་ཀྱི་དྲན་ཐོ། | གཙོ་བོའི་མི་ཚེ་འཁོར་རིམ་གྱི་སྐབས་དོན་ཁོ་ན། ID དཔང་ཡིག་མིན། |

<a id="extract-the-clean-id"></a>
## IDགཙང་མ་ཕྱིར་འདོན་བྱེད།

དཔེར་ན།

```text
ConnectID=2535422284688820_+_|0002d07b...
```

གཙང་བཟོ།`Admin.ini` རིན་ཐང་:

```ini
BannedPlayer=2535422284688820
```

སྦྱར་མི་རུང་།`_+_|...`.

<a id="verify-with-playerdata"></a>
##  PlayerData

ལ་ཞིབ་བཤེར་བྱེད་དགོས།

```text
Saved/SaveGames/Server/Worlds/<WorldName>/PlayerData/Player_<ID>.sav
```

ནང་དོན:

```text
The ID exists in the world save.
```

ཚད་གཞི།

```text
PlayerData may not prove the display name unless another source maps it.
```

<a id="when-not-to-ban"></a>
## ག་དུས་བཀག་འགོག་མི་བྱེད་པ

བཀག་སྡོམ་ཨང་རྟགས་མ་སྤྲོད་པའི་སྐབས་:

```text
the name only appears in an external notification
the name only appears in hosting-panel activity
UE4SS shows a name but no ConnectID
only system lifecycle or container logs exist
the ID is trusted or moderator
```
