# ལས་ཀ་བྱས་པའི་བཀོལ་སྤྱོད་དཔེ་མཚོན་

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [EXAMPLE_RUNS.md](../../EXAMPLE_RUNS.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


དཔེ་འདི་དག་གིས་རེ་བ་བྱེད་པའི་གནས་སྟངས་བརྗེ་སྒྱུར་འགྲེལ་བཤད་བྱེད་པར་གསར་གཏོད་བྱས་པའི་རིན་ཐང་བེད་སྤྱོད་བྱེད། དེ་དག་ནི་ཐད་གཏོང་མཐུན་སྒྲིལ་དང་རྩེད་མོ་བའི་དཔང་རྟགས་མིན།

<a id="successful-current-cycle"></a>
## མིག་སྔའི་འཁོར་ཡུན་ལེགས་འགྲུབ་བྱུང་བ།

ནང་འཇུག་: ཀློག་ཐུབ་པའི་ཤུགས་ལྡན་དྲན་ཐོ། version/boot/epoch, `poll_id=41`, ད་ལྟའི་འོས་བསྡུ་མཇུག་སྒྲིལ། འབྲི་ཆོག accounting/history/report རྩ་བ། དལ་བུས་བཤེར་འཇལ་སྲིད་ཇུས་བཀག་འགོག་མེད།

རེ་སྒུག:

```text
server_status = full
player_activity = full or limited_expected_empty
case_review = full or limited_expected_empty
daily_rollup = full or limited_expected_empty
critical_guard = full or limited_expected_empty
```

ལྕོགས་ཅན་བཟོས་པའི་ལམ་ཐིག་རེ་རེ་ལ་JSON/TXT ཐོན་འབྲས་དང་ `route_proof.json`. ལམ་ཐིག་གནས་ཚུལ་དེ་རང་ཉིད་ཀྱི་བརྗོད་གཞི་ལ་རག་སླེབས་པ་ལས་སྤྱིར་བཏང་གི་གྲུབ་འབྲས་བརྡ་འཕྲིན་ལ་རག་སླེབས་ཀྱི་མེད།

<a id="expected-empty-player-and-case-routes"></a>
## རེ་བ་-སྟོང་པའི་སྒྲ་སྒམ་དང་གྱོད་གཞིའི་ལམ་ཐིག

ནང་འཇུག་: ད་ལྟའི་འཁོར་རིམ་གྱི་བདེན་དཔང་མཇུག་སྒྲིལ་ཡོད། ད་ལྟའི་ཡང་ན་བཀག་སྡོམ་བྱས་པའི་རྩེད་མོ་བའི་གྲལ་རིམ་མེད། བཀག་སྡོམ་བྱས་པའི་གནད་དོན་མེད་པ་དང་ད་ལྟའི་གནས་ཚུལ་མེད་པ།REVIEW/BAN-ELIGIBLEརྩིས་ཐོ།

རེ་སྒུག:

```text
player_activity.route_proof_status = limited_expected_empty
player_activity.expected_empty = true
player_activity.players = []

case_review.route_proof_status = limited_expected_empty
case_review.expected_empty = true
case_review.cases = []
```

སྐད་སྒྱུར་བྱས་པའི་སྙན་ཞུའི་ནང་འོས་འཚམ་གྱི་ཚད་གཞི་ཅན་གྱི་སློབ་ཚན་གང་ཡང་མཐོང་མ་བྱུང་ཟེར། ཁོང་ཚོས་འདིས་མི་སུ་ཞིག་ཡང་འབྲེལ་བ་མེད་པ་དང་ཡང་ན་སྐབས་དོན་གང་ཡང་མེད་པ་ཁུངས་སྐྱེལ་བྱེད་ཀྱི་མེད་ཅེས་བརྗོད་ཀྱི་ཡོད། ས་གནས་འཛིན་མཁན་མེད་པplayer/case གསར་འཛུགས་བྱས་ཡོད།

<a id="partial-bounded-scan"></a>
## ཆ་ཤས་མཚམས་ཐིག་ཅན་གྱི་བཤེར་འཇལ་

ནང་འཇུག་: གློག་རྒྱུན་གསར་པ། log/poll; `scan_checkpoint.json` ཡང་ན་ `scan_progress.json` ཡོད། བཤེར་འཇལ་ཆ་ཚང་མེད་པ་རེད། སྔོན་སྒྲིག `slow_world_scan_blocks_current_reports=false`.

རེ་སྒུག:

```text
world_save_scan.status = partial
source accounting = partial
server_status may still be full for fresh current state
historical routes name the scan limitation
```

གཞི་སྒྲིག་`slow_world_scan_blocks_current_reports=true` བཀོལ་སྤྱོད་པས་འདམ་ཀའི་དལ་བའི་འབྱུང་ཁུངས་དེ་ད་ལྟའི་སྙན་ཞུ་བཀག་འགོག་བྱེད་དགོས་པའི་སྐབས་རྐྱངམ་གཅིག་རེད། སླར་གསོ་བྱེད་པ་ནི་བཤེར་འཇལ་ལས་བྱེད་པ་དེ་བསྐྱར་དུ་འགོ་འཛུགས་ཆོག་པ་ལས་བརྟག་དཔྱད་ས་ཚིགས་སུབ་པ་མ་རེད།

<a id="missing-current-cycle-proof"></a>
## ད་ལྟའི་འཁོར་རིམ་གྱི་བདེན་དཔང་བརླག་སོང་།

ནང་འཇུག་: ཤུགས་ལྡན་གྱི་དྲན་ཐོ་མེད་པ། `poll_id=0`, ཡང་ན་ boot/epoch/last-poll རིགས་རྒྱུད་བརླག་སོང་།

རེ་སྒུག:

```text
current_cycle_proof_complete = false
all route proof statuses = missing
each configured route envelope status = suppressed_current_cycle
delivery_eligible = false
delivery_attempted = false
```

མནན་པའི་ཡིག་སྐོགས་དེ་རྩིས་ཞིབ་དྲན་ཐོ་ཡིན་པ་ལས་བང་སྒྲིག་པའི་སྐྱེལ་འདྲེན་མིན། མཐའ་མའི་དྲན་ཐོ་རྙིང་པ་དེ་ལོ་རྒྱུས་ཁོ་ན་ལྷག་ཡོད། ཐོག་མར་བརླགས་པ་རྣམས་ཉམས་གསོ་བྱོས།lineage/source ཡིག་དུམ་དང་འཁོར་ཡུན་གསར་པ་ཞིག་བསྐྲུན་དགོས།

<a id="malformed-optional-adminini-source"></a>
## གདམ་གའི་བཟོ་ལྟ་ནོར་བ།Admin.ini འབྱུང་ཁུངས།

ནང་འཇུག་: `Admin.ini` ཡོད་ཀྱང་སྒྲིག་བཀོད་གཙང་མའི་བདེན་དཔང་བྱེད་མི་ཐུབ།

རེ་སྒུག:

```text
admin_ini.status = malformed
source reference preserved
write/enforcement path closed
```

ཡིག་ཆ་ཉར་ཚགས་བྱས་ནས་བསྐྱར་ཞིབ་བྱས་པའི་རྣམ་གཞག་གཙང་མ་ཞིག་སླར་གསོ་བྱེད། འགྲེལ་བཤད་ཀྱི་ཡིག་ཆ་དེ་རྒྱུག་དུས་ཀྱི་དཔང་རྟགས་ནང་ཉར་དགོས། རེ་རེ`Admin.ini`འཛུལ་ཞུགས་བཀག་སྡོམ་ཁོ་ན་ལྷག་ཡོད།`BannedPlayer=<ID>`.

<a id="required-active-log-probe-error"></a>
## དགོས་མཁོའི་ཤུགས་ལྡན་དྲན་ཐོའི་འཚོལ་ཞིབ་ནོར་འཁྲུལ།

ནང་འཇུག་: མཐའ་མཚམས་དགོས་མཁོའི་ཤུགས་ལྡན་དྲན་ཐོ་འཚོལ་ཞིབ་དེ་གཙང་མ་བཟོས་པའི་ཀློག་ནོར་འཁྲུལ་གྱིས་འཐུས་ཤོར་བྱུང་ཡོད།

རེ་སྒུག:

```text
source_accounting.sources[active_log].status = error
source_accounting.sources[active_log].detail = "bounded active-log probe failed: <sanitized reason>"
coverage_status = unavailable
all route proof statuses = missing
```

`error` འབྱུང་ཁུངས་གྲལ་ཐིག་སྟེང་དུ་དེའི་མཚམས་ཐིག་ཞིབ་ཕྲ་དང་མཉམ་དུ་ལུས་ཡོད། གོང་རིམ་སྙན་ཞུའི་ནང་`unavailable`, དང་ལམ་ཐིག་བདེན་དཔང་ལྷག་ཡོད། `missing` ད་ལྟའི་འཁོར་ཡུན་གསར་བ་ཞིག་གིས་དགོས་ངེས་ཀྱི་འབྱུང་ཁུངས་ཁུངས་སྐྱེལ་མ་བྱེད་བར།

<a id="incompatible-or-stale-baseline"></a>
## མི་མཐུན་པའམ་རྙིང་པའི་གཞི་གྲངས

ནང་འཇུག་: བསྒྱུར་ཡོད། package/sourceངོ་རྟགས་སམ་stale/incompatible གཞི་གྲངས་གསལ་བསྒྲགས།

རེ་བ་: བདེན་དཔང་ཡང་ན་རྒྱུག་དུས་གནས་ཚུལ་གྱིས་མི་མཐུན་པ་ཐོ་འགོད་བྱེད། བཤེར་འཇལ་གནས་སྟངས་ཀྱིས་བསྐྱར་དུ་བེད་སྤྱོད་གཏོང་ཚར་བའི་ཐོབ་ཐང་རྩོད་ལེན་བྱེད་ཀྱི་མེད། སྔོན་གྱི་དཔང་རྟགས་ཉར་ཚགས་བྱས་ནས་གཞི་རྩའི་བསྐྱར་སྐྲུན་གསལ་པོ་འགོ་འཛུགས་པ་དང་མཐའ་མའི་དཔང་རྟགས་གསར་པ་སྒུག་དགོས། ཐོ་འགོད་བྱས་པའི་རྒྱུ་མཚན་མེད་པར་བཙན་ཤེད་ཀྱིས་བསྐྱར་བཟོ་བྱེད་པ་དེ་སྔོན་སྒྲིག་སླར་གསོ་མིན།

<a id="paired-report-write-failure"></a>
## ཆ་སྒྲིག་སྙན་ཞུ་འབྲི་བའི་འཐུས་ཤོར།

ནང་འཇུག་: JSON འབྲི་ལམ་འགྲུབ་ཡོད་ཀྱང་ TXT བྲིས་མ་ཐུབ་པའམ་ཡང་ན་ལྡོག་ཕྱོགས་ཡིན།

རེ་སྒུག:

```text
route_proof_status = missing
completed = false
coverage_status = unavailable
output_write_detail = "paired JSON/TXT write failed: <sanitized reason>"
```
