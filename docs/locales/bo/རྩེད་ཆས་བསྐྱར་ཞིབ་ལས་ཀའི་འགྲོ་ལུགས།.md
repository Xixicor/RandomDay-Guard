# རྩེད་མོ་བའི་བསྐྱར་ཞིབ་ལས་ཀའི་འགྲོ་ལུགས།

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [PLAYER_REVIEW_WORKFLOW.md](../../PLAYER_REVIEW_WORKFLOW.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


ཤོག་ངོས་འདི་རྩེད་ཆས་གཅིག་དང་རྩིས་ཁྲ་གཅིག་ཡང་ན་གྱོད་གཞིའི་ཆེད་དུ་བེད་སྤྱོད་བྱེད། དམིགས་ཡུལ་ནི་བསྐྱར་བཟོ་ཐུབ་པའི་བསྐྱར་ཞིབ་ཐག་གཅོད་ཅིག་ཡིན་པ་ལས་རང་འགུལ་གྱིས་སྐྱོན་བརྗོད་བྱེད་པ་མ་རེད།

## མྱུར་ལམ་

1. ཁ་ཕྱེ།`runtime/final_logs/player_activity_latest.json`.
2. `runtime/final_logs/route_proof.json`.
3. དོ་སྣང་གང་ཞིག་ད་ལྟའི་དུས་དང་གང་ཞིག་ལོ་རྒྱུས་ཀྱི་ཡིན་པ་ངོས་འཛིན།
4. ལུང་འདྲེན་བྱས་པའི་ངོ་བོ་དང་ལས་རིམ་འབྱུང་ཁུངས་གཞི་གྲངས་ལ་ཞིབ་བཤེར་བྱེད།
5. བསྐྱར་ཞིབ`case_review_latest.json` འབྲེལ་ཡོད་གནས་ཚུལ་ཡོད་པའི་སྐབས།
6. མ་ཤེས་པ་ཐོ་འགོད་དང་།`does_not_prove` བྱ་བ་འདེམས་པའི་སྔོན་ལ།
7. ལག་བསྟར་སྒོ་ཕྱེ་སོ་སོར་ཁུངས་སྐྱེལ་མ་བྱས་ན་ལག་བསྟར་བྱེད་ནུས་མེད་པར་བཞག

## 1. ལམ་ཐིག་བདེན་དཔང་གཏན་འཁེལ་

རྩེད་ཆས་འགྲོ་ལམ་འདི་ལྟར་དོན་འགྲེལ།

| གོ་གནས | བྱ་སྤྱོད། |
|---|---|
| `full` | མུ་མཐུད། ད་དུང་ཐོན་ཁུངས་ཚད་གཞི་བསྐྱར་ཞིབ་བྱེད་བཞིན་ཡོད། |
| `limited_expected_empty` | དངོས་གནས་ཡོད་པའི་བརྗོད་གཞི་ཁོ་ན་མུ་མཐུད་དུ་བྱེད། བརླག་པའི་རྩེད་མོ་བའམ་ཡང་ན་གྱོད་གཞི་གསར་གཏོད་མ་བྱེད། |
| `missing` | རྩེད་མོ་བའི་ཐག་གཅོད་བཀག་ནས་ལམ་ཐིག་ལ་དཀའ་ངལ་སེལ་དགོས། |

བདེ་ཐང་གི་དུས་ཚོད་བཀོད་སྒྲིག་བྱེད་མཁན་གྱིས་ལམ་ཐིག་བདེན་དཔང་ཚབ་བྱེད་མི་ཐུབ།

<a id="2-establish-identity"></a>
## 2. ངོ་བོ་འཛུགས་པ

རྩིས་ཁྲའི་ངོས་འཛིན་བྱེད་མཁན་གཙང་མ་ཞིག་ལ་དགའ་པོ་བྱེད་པ་དང་དེ་ནི་ཞབས་ཞུ་འཕྲུལ་ཆས་ཀྱིས་གསལ་སྟོན་བྱས་པའི་ངོས་འཛིན་དཔང་རྟགས་དང་།PlayerDataཡིག་ཆའི་མིང་། ཐོན་ཁུངས་གཞི་གྲངས་ངོ་མ་དེ་ཉར་དགོས།

ནས་བཙན་ཤེད་མི་བྱེད།

- མངོན་པའི་མིང་གཅིག་པུ།
- བརྡ་ཐོའམ་གཙོ་གཉེར་སྒྲོམ་ནང་མཐོང་བའི་མིང་།
- དུས་ཚོད་འདྲ་མཚུངས།
- ས་ཁྲ་བཟོས་མེད་པའམ་ཡང་ན་ཡིད་ཆེས་ཞན་པའི་ངོ་བོ།
- ད་ལྟའི་བདེན་དཔང་མེད་པའི་ལོ་རྒྱུས་སྙན་ཞུ།

<a id="3-separate-current-from-historical"></a>
## 3. ད་ལྟའི་ལོ་རྒྱུས་དང་ལོ་རྒྱུས་

ད་ལྟའི་དཔང་རྟགས་ཀྱིས་སྙན་ཞུའི་སྒེའུ་ཁུངས་ཤུགས་ལྡན་ཡང་ན་སར་བར་གྱི་དུས་རབས་བརྗོད་ཀྱི་ཡོད། ལོ་རྒྱུས་ཀྱི་དཔང་རྟགས་ཀྱིས་བཀོད་རིས་ཤིག་འགྲེལ་བཤད་རྒྱག་ཐུབ་ཀྱི་ཡོད་ཀྱང་། དེས་ད་ལྟའི་སྒེའུ་ཁུང་ནང་དུ་སྟོང་ཆ་ཁུ་སིམ་ངང་བཀང་མི་ཐུབ།

<a id="5-calibrate-the-decision"></a>
## 5. ཐག་གཅོད་ཚད་གཞི་བཟོ

| གཏན་དུ་འཁེལ་བ | ག་དུས་སྤྱོད། |
|---|---|
| `INFO` | སྤྱིར་བཏང་ངམ་ཡང་ན་སྐབས་དོན་དམའ་བའི་དོ་སྣང་། |
| `WATCH` | ལྟ་རྟོག་བྱེད་རིན་ཡོད་པའི་བརྡ་རྟགས་ཞན་པའམ་ཡང་ན་མ་ཚང་བ། |
| `REVIEW` | འབྲེལ་ཡོད་ཀྱི་དཔང་རྟགས་ལ་འཛིན་སྐྱོང་པའི་ཐག་གཅོད་དགོས། |
| `BAN-ELIGIBLE` | ངོས་འཛིན་གཙང་མ་དང་སྒྲིག་བཀོད་བྱས་པའི་མངོན་གསལ་གྱི་ཚད་གཞི་ཚང་ཡོད། འབྲི་སྒོ་ད་དུང་ཡང་བཀོལ་སྤྱོད་བྱེད་ཀྱི་ཡོད། |
| `AUTO-BANNED` | ལག་བསྟར་བྱེད་པ་དེ་གསལ་པོར་ལྕོགས་ཅན་བཟོས་པ་དང་རྒྱབ་ལྗོངས་དང་། འབྲི་བ། ཕྱིར་ཀློག རྩིས་ཞིབ་བཅས་ཚང་མ་ལེགས་འགྲུབ་བྱུང་ཡོད། |

ཐག་གཅོད་ཀྱི་མིང་བྱང་གང་གིས་ཀྱང་ཉེས་འཛུགས་དང་དམིགས་ཡུལ་ཁུངས་སྐྱེལ་བྱེད་ཀྱི་མེད།

<a id="6-apply-the-evidence-boundary"></a>
## 6. དཔང་རྟགས་ཀྱི་ས་མཚམས་སྤྱད་པ

བརྡབ་སྐྱོན་བྱུང་། བསྐྱར་དུ་མཐུད། ཉེན་བརྡ། object/class རྟགས་མཚན་དང་གནད་དོན་སྡེ་ཚན་གྱིས་བསྐྱར་ཞིབ་ལ་རྒྱབ་སྐྱོར་བྱེད་ཐུབ། གཅིག་པོས་ཁོ་ཚོས་མགོ་སྐོར་དང་། རྐུན། འདྲ་བཤུས། བདག་དབང་། ཐད་ཀར་གྱི་གནོད་སྐྱོན། ཡང་ན་དོན་རྐྱེན་གྱི་རྒྱུ་རྐྱེན་བཅས་ཁུངས་སྐྱེལ་བྱེད་ཀྱི་མེད།

གལ་ཏེ་ངོས་འཛིན་དང་། དབྱེ་ཞིབ། རྒྱབ་སྐྱོར། འབྲི་བ། ཕྱིར་ཀློག ཡང་ན་ཕྱིར་འཐེན་བྱེད་པ་དེ་ཞན་པོའམ་ཡང་ན་འཐུས་ཤོར་བྱུང་ན། ལག་བསྟར་བྱེད་པར་འཐུས་ཤོར་ཁ་བརྒྱབ་དགོས།
