# ཁྲིམས་ལུགས་ཉིན་རེའི་བསྡོམས་རྩིས་

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [FORENSIC_DAILY_ROLLUPS.md](../../FORENSIC_DAILY_ROLLUPS.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


ཉིན་རེའི་བསྡོམས་རྩིས་ནི་བསྐྱར་བཟོ་བྱེད་ཐུབ་པའི་ཟུར་ཐོ་ཞིག་ཡིན། ཐོན་ཁུངས་དཔང་རྟགས་དེ་དབང་ཆ་ལྡན་ཡོད། ཉིན་རེའི་སྣོད་ཐོ་དང་མཐའ་མའི་དྲན་ཐོ་ནི་རྒྱུག་དུས་ཀྱི་དཔང་རྟགས་ལས་བྱུང་བའི་བསྐྱར་ཞིབ་མགྱོགས་མྱུར་གྱི་ཐུམ་སྒྲིལ་ཡིན།

མགྱོགས་མྱུར་དབྱེ་ཞིབ་ཀྱི་ཆེད་དུ་སྣོད་ཐོ་གཅིག་ཡར་བསྐུར་དགོས་དུས་ཤོག་ངོས་འདི་བེད་སྤྱོད་བྱོས།

<a id="what-it-is"></a>
## དེ་ག་རེ་རེད་
ཉིན་རེའི་བསྡུ་རུབ་ནི་ཉིན་གཅིག་གི་ཆེད་དུ་བསྐྱར་བཟོ་བྱེད་ཐུབ་པའི་དཔང་རྟགས་ཀྱི་སྙིང་བསྡུས་ཤིག་རེད།

འདིས་དཔང་རྟགས་རྙིང་པའི་ཚབ་བྱེད་མི་ཐུབ།

```text
Source evidence = truth
Daily rollup = fast index
Final log = plain-language summary
```
