# རིམ་སྒྲིག་གསལ་སྡུད།

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [CONFIG_PROFILES.md](../../CONFIG_PROFILES.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


ལག་ལེན་གྱི་རིམ་སྒྲིག་གསལ་སྡུད་འདེམས་སྒྲུག་དང་འཇུག་སྤྱོད་བྱེད་པར་བྱེད་ཐབས་ལམ་སྟོན་འདི་བེད་སྤྱོད་བྱེད། སྒྲིག་སྟངས་སྡེ་ཚན་ཕན་ཚུན་འབྲེལ་བ་བྱེད་སྟངས་ཀྱི་འགྲེལ་བཤད་ལ་ [`CONFIG_REFERENCE.md`](%E0%BD%A2%E0%BD%B2%E0%BD%98%E0%BC%8B%E0%BD%A6%E0%BE%92%E0%BE%B2%E0%BD%B2%E0%BD%82%E0%BC%8B%E0%BD%82%E0%BD%9E%E0%BD%B2%E0%BC%8B%E0%BD%82%E0%BE%B2%E0%BD%84%E0%BD%A6%E0%BC%8D.md). ཡིག་དུམ་ཏག་ཏག་དང་སྔོན་སྒྲིག རིགས་དང་འགྱུར་ལྡོག་མེད་པའི་ཆེད་དུ་བཟོ་བསྐྲུན་བྱས་པའི་ [`CONFIG_FIELD_CATALOG.md`](%E0%BD%A2%E0%BD%B2%E0%BD%98%E0%BC%8B%E0%BD%A6%E0%BE%92%E0%BE%B2%E0%BD%B2%E0%BD%82%E0%BC%8B%E0%BD%A6%E0%BC%8B%E0%BD%81%E0%BD%BC%E0%BD%84%E0%BD%A6%E0%BC%8B%E0%BD%90%E0%BD%BC%E0%BC%8B%E0%BD%82%E0%BD%9E%E0%BD%B4%E0%BD%84%E0%BC%8B.md).

གཤམ་གྱི་ལུའུ་ཡི་སྡེབ་ཚན་རེ་རེ་ནི་སྐྱེལ་འདྲེན་བྱས་པའི་ནང་དུ་མཐུན་པའི་ཐོ་འགོད་ཀྱི་ཚབ་བྱེད་ཐུབ་པའི་མཐོ་རིམ་ཐོ་འགོད་ཀྱི་ཆ་ཚང་ཞིག་ཡིན།`return { ... }` རེའུ་མིག

<a id="profile-chooser"></a>
## གསལ་སྡུད་འདེམས་མཁན།

| གནས་བབ | གསལ་སྡུད་འདི་བེད་སྤྱོད་བྱོས། |
|---|---|
| ཐོག་མར་སྒྲིག་འཛུགས། | ཉེན་མེད་ཐོག་མར་སྒྲིག་འཇུག་ |
| སར་བར་བརྟན་པོ་མེད་པས་རྒྱུན་དུ་བརྡབ་སྐྱོན་ཤོར་གྱི་ཡོད། | མིག་སྔའི་བདེན་དཔང་དལ་བའི་བཤེར་འཕེན་མེད་པའི་དཔང་རྟགས། |
| ཁྱེད་ལ་དགོས་པ།object/world སྐབས་དོན། | གཞི་གྲངས་ཆ་ཚང་ |
| ཁྱེད་ཀྱིས་དྲན་ཐོ་རྙིང་པར་བསྐྱར་ཞིབ་བྱེད་དགོས་སམ། | ཁྲིམས་ལུགས་ཀྱི་ཕྱིར་བཀང་ |
| ཁྱེད་ལ་འོས་སྦྱོར་དགོས་ཀྱང་བྲིས་མི་འདུག | ལག་བསྟར་ཚོད་ལྟ |
| ཁྱོད་ཀྱིས་སྲུང་མ་ལ་བཀག་སྡོམ་འབྲི་བཅུག་པར་གྲ་སྒྲིག་ཡིན། | ལག་བསྟར་བྱེད་ནུས་ལྡན་འདུག |
| ཌིཀསི་ཚད་བཀག་ཡོད། | སྲབ་སྡེར་འཕར་ཚད་དམའ་བ། |
| ཁྱེད་ཀྱིས་གཞི་གྲངས་གཙང་མ་ཞིག་བསྒྲུབས་པ་ | སྦྱར་བའི་རྒྱབ་ལྗོངས་སྒྲིག་བཀོད། |

<a id="safe-first-install"></a>
## ཉེན་མེད་ཐོག་མར་སྒྲིག་འཇུག་

ཐོག་མར་ཐད་གཏོང་སར་བར་ཐོག་འདི་བེད་སྤྱོད་བྱོས།

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

log_tail = {
    enabled = true,
    start_at_end_on_first_run = true,
    tail_backup_logs = false,
},

scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

འདིས་ཅི་ཞིག་བྱེད།

```text
Tracks live sessions.
Starts the baseline scan.
Does not edit Admin.ini.
Avoids treating old backup logs as fresh live events.
```

<a id="current-evidence-without-slow-scan"></a>
## མིག་སྔའི་བདེན་དཔང་དལ་བའི་བཤེར་འཕེན་མེད་པའི་དཔང་རྟགས།

གལ་ཏེ་སར་བར་གཏན་འཇགས་མིན་པ་དང་ཁྱེད་ལ་དགོས་ན་crash/reconnect བརྟག་དཔྱད་ལྗིད་པོ་མ་བྱས་སྔོན་གྱི་དཔང་རྟགས།

```lua
log_tail = {
    enabled = true,
},

scanning = {
    full_scan_on_start = false,
},

enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

འདིས་ཅི་ཞིག་བྱེད།

```text
Tracks logins, joins, leaves, reconnects, crashes, and unclean sessions.
Delays heavy world scanning.
```

<a id="full-baseline"></a>
## གཞི་གྲངས་ཆ་ཚང་

སར་བར་གྱིས་བཤེར་འཚོལ་བྱེད་པར་ཡུན་རིང་བསྡད་ཐུབ་པའི་རྗེས་སུ་འདི་བེད་སྤྱོད་བྱེད་དགོས།

```lua
scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},
```

འདིས་ཅི་ཞིག་བྱེད།

```text
Builds object registry.
Writes world-state context.
Creates file manifest.
Enables changed-file refresh later.
```

<a id="forensic-backfill"></a>
## ཁྲིམས་ལུགས་ཀྱི་ཕྱིར་བཀང་

འདི་ལོ་རྒྱུས་དྲན་ཐོ་ལ་བསམ་བཞིན་དུ་བསྐྱར་ཞིབ་བྱེད་སྐབས་རྐྱངམ་གཅིག་བེད་སྤྱོད་བྱེད་དགོས།

```lua
log_tail = {
    start_at_end_on_first_run = false,
    tail_backup_logs = true,
    backfill_backup_logs_on_start = true,
},
```

བེད་སྤྱོད་མ་བཏང་སྔོན་:

```text
Back up runtime/log_offsets.tsv.
Expect old events to be reprocessed.
Return to live settings when finished.
```

<a id="enforcement-testing"></a>
## ལག་བསྟར་ཚོད་ལྟ

དངོས་ཡོད་ཀྱི་སྔོན་ལ་འདི་བེད་སྤྱོད་བྱོས།Admin.ini འབྲི་བ།

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},
```

ག་རེ་ཞིབ་བཤེར་བྱེད་དགོས་སམ།

```text
runtime/account_evidence.json
runtime/warnings/
runtime/forensic_days/YYYY-MM-DD/ban_recommendations.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="enforcement-enabled"></a>
## ལག་བསྟར་བྱེད་ནུས་ལྡན་འདུག

བསྐྱར་ཞིབ་ཀྱི་ཐོན་འབྲས་ཡང་དག་བྱུང་རྗེས་ད་གཟོད་འདི་བེད་སྤྱོད་བྱེད།

```lua
enforcement = {
    review_only_mode = false,
    auto_ban = true,
    write_admin_ini = true,
    require_clean_ban_id = true,
    preserve_existing_bans = true,
    preserve_moderators = true,
},
```

ལྕོགས་ཅན་མ་བཟོས་སྔོན་:

```text
Trusted IDs are configured.
Moderator IDs are preserved.
Admin.ini backups work.
Ban recommendations are understandable.
Thresholds are accepted by the server owner.
```

<a id="low-disk-growth"></a>
## སྲབ་སྡེར་འཕར་ཚད་དམའ་བ།

རྒྱུག་དུས་ཡིག་ཆ་འཕེལ་རྒྱས་མགྱོགས་དྲགས་པའི་སྐབས་འདི་བེད་སྤྱོད་བྱེད།

```lua
logging = {
    low_importance_mode = "aggregate",
    write_low_importance_raw_events = false,
},

retention = {
    detailed_retention_days = 7,
    rotate_jsonl_when_bytes_exceed = 5242880,
    max_raw_events_lines = 20000,
    compact_json_outputs = true,
},
```

<a id="sticky-backup-setup"></a>
## སྦྱར་བའི་རྒྱབ་ལྗོངས་སྒྲིག་བཀོད།

ཐོག་མར་གྲུབ་པའི་གཞི་གྲངས་རྗེས་སུ་བེད་སྤྱོད་བྱེད།

འདི་དག་ཡོད་མེད་བརྟག་དཔྱད་བྱོས།

```text
runtime/scan_complete.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
runtime/world_state/current/world_state_latest.json
```

དེ་རྗེས་ `config.lua`, `SavedRoot.txt`, དང་ `Admin.ini`.
