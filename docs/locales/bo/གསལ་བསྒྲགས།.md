# གསལ་བསྒྲགས།

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [NOTICE.md](../../../NOTICE.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས། སྐད་སྒྱུར་འདི་ཆ་འཕྲིན་ཡིན། དབྱིན་ཡིག་གི་ཁྲིམས་ལུགས་ཡིག་ཆ་དེས་ཚོད་འཛིན་བྱེད་ཀྱི་ཡོད།
