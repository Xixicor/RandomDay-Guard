# སྒྲིག་བཀོད་ཀྱི་བསམ་གཞིག

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [CONFIG_REFERENCE.md](../../CONFIG_REFERENCE.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


འགྲེལ་བཤད་འདིས་སྒྲིག་བཀོད་ས་ཁོངས་གཙོ་བོ་རེ་རེས་གང་ཚོད་འཛིན་བྱེད་ཀྱི་ཡོད་མེད་དང་། དེ་ག་དུས་གཡོག་བཀོལ་བྱེད་ཀྱི་ཡོད་མེད་དང་། དེ་ལ་ས་ཁོངས་ཐོ་གཞུང་ཡང་ན་གསལ་སྡུད་བྱ་ཐབས་གཏན་འཁེལ་གྱི་བདག་དབང་མེད།

ལས་འགན་ལ་དམིགས་པའི་སྔོན་སྒྲིག་དང་ཉེན་མེད་བརྗེ་སྒྱུར་གྱི་གོམ་པ་ལ་[`CONFIG_PROFILES.md`](%E0%BD%A2%E0%BD%B2%E0%BD%98%E0%BC%8B%E0%BD%A6%E0%BE%92%E0%BE%B2%E0%BD%B2%E0%BD%82%E0%BC%8B%E0%BD%82%E0%BD%A6%E0%BD%A3%E0%BC%8B%E0%BD%A6%E0%BE%A1%E0%BD%B4%E0%BD%91%E0%BC%8D.md). ཐོན་ཁུངས་ས་ཁོངས་གཏན་འཁེལ་རེ་རེའི་ཆེད་དུ་སྔོན་སྒྲིག་དང་རིགས་དང་འགྱུར་ལྡོག་མེད་པ་དང་ཐོན་འབྲས་ཕན་ནུས་དང་སླར་གསོའི་ཁྲིམས་ལུགས་རེ་རེའི་ཆེད་དུ་བཟོས་པའི་ [`CONFIG_FIELD_CATALOG.md`](%E0%BD%A2%E0%BD%B2%E0%BD%98%E0%BC%8B%E0%BD%A6%E0%BE%92%E0%BE%B2%E0%BD%B2%E0%BD%82%E0%BC%8B%E0%BD%A6%E0%BC%8B%E0%BD%81%E0%BD%BC%E0%BD%84%E0%BD%A6%E0%BC%8B%E0%BD%90%E0%BD%BC%E0%BC%8B%E0%BD%82%E0%BD%9E%E0%BD%B4%E0%BD%84%E0%BC%8B.md); བདེན་དཔང་བྱེད་མཁན་ལ་སྐྱེལ་འདྲེན་རེ་རེར་གྲལ་རིམ་གཅིག་དགོས། `config.lua` ལོ་མའི་ས་ཁོངས།

|---|---:|---|
| `enabled` | `true` | སྲུང་སྐྱོབ་ཀྱི་ཆེད་དུ་གཙོ་བོའི་བརྗེ་སྒྱུར་ |

| `enforcement.write_admin_ini` | `false` | འབྲི་མི་རུང་Admin.ini སྔོན་སྒྲིག་ལྟར་ |

<a id="saved"></a>
## `saved`

སྲུང་དམག་གིས་སར་བར་ཇི་ལྟར་འཚོལ་མིན་ཚོད་འཛིན་བྱེད།`Saved/` སྣོད་ཐོ་དང་དེས་ཡིག་ཆའི་རིགས་གང་ཞིག་བཤེར་འཇལ་བྱེད་ཐུབ།

ག་དུས་སྤྱོད་དགོས།

```text
Saved root auto-detection fails.
World folder changed.
Provider or container path is unusual.
```

ཞིབ་བཤེར།

```text
runtime/saved_path_probe.json
RandomDayGuard/SavedRoot.txt
```

ཁྲིམས་ལུགས།

```text
SavedRoot.txt -> AbioticFactor/Saved
not -> Worlds/<WorldName>
```

<a id="log_tail"></a>
## `log_tail`

ཐད་གཏོང་དྲན་ཐོ་ཀློག་སྟངས་ཚོད་འཛིན་བྱེད།

ཕན་ཐོགས་པའི་གདམ་ཁ།

| གདམ་ག | བདེ་འཇགས་རིན་ཐང་། | ཅིའི་ཕྱིར་ |
|---|---|---|
| `enabled` | `true` | གསོན་འགོག་སྲུང་སྐྱོབ་ལ་མཁོ། |
| `start_at_end_on_first_run` | `true` | དྲན་ཐོ་རྙིང་པ་དེ་ཐད་གཏོང་བྱུང་རིམ་ལྟར་སྤང་དགོས། |
| `tail_backup_logs` | `false` | རྒྱབ་ལྗོངས་དྲན་ཐོ་ནི་ལོ་རྒྱུས་ཡིན་པ་ལས་ཐད་གཏོང་མིན། |
| `max_lines_per_poll` | ཚད་ལྡན་ | འོས་བསྡུའི་བསྐྱར་འཁོར་ལན་འདེབས་ཐུབ་པ་བཟོས། |

ཞིབ་བཤེར།

```text
runtime/log_offsets.tsv
runtime/evidence/session_events.jsonl
runtime/current/poll_status.json
```

<a id="runtime"></a>
## `runtime`

འོས་བསྡུ་དང་སྔོན་རྩིས་ཚོད་འཛིན་བྱེད།

འཕྲོད་བསྟེན་ཁྲིམས་གཞི་གཙོ་བོ།

```text
poll_id increases
poll_in_flight returns false
poll_scheduled is true
```

ཞིབ་བཤེར།

```text
runtime/current/poll_status.json
```

གལ་ཏེ`poll_id` བཀག་ན་གང་ཞིག་གིས་བསྐྱར་ལོག་བཀག་ཡོད།

<a id="source_accounting"></a>
## `source_accounting`

མངོན་གསལ་དཔང་རྟགས་ཐོན་ཁུངས་ཁྱབ་ཁོངས་དང་ཁྱབ་ཁོངས་ཚོད་འཛིན་བྱེད།

| ལྡེ་མིག | སྔོན་སྒྲིག | ནང་དོན |
|---|---:|---|
| `enabled` | `true` | སྤྱི་སྤྱོད་ལམ་ཐིག་སྙན་ཞུའི་འབྱུང་ཁུངས་རྩིས་ཁྲ་འབྲི་བ། |
| `require_terminal_status` | `true` | ཐོན་ཁུངས་རེ་རེ་ལ་གསལ་པོའི་མཐའ་མཚམས་ཡང་ན་མ་ཚང་བའི་གནས་སྟངས་གསལ་སྟོན་བྱེད་དགོས། |
| `distinguish_current_from_historical` | `true` | ད་ལྟའི་དང་ལོ་རྒྱུས་ཀྱི་བདེན་དཔང་གཉིས་སོ་སོར་བཞག་ཡོད། |
| `slow_world_scan_blocks_current_reports` | `false` | མིག་སྔའི་སྙན་ཞུ་ལ་མཚམས་ཐིག་ཅན་གྱི་འཛམ་གླིང་བཤེར་འཚོལ་ཕྱིར་འགྱངས་བྱས་པའམ་ཡང་ན་ཆ་ཤས་ཡིན་པ་བརྗོད་དུ་འཇུག་ཐུབ། |
| `changed_file_manifest` | གཞི་གྲངས་གསལ་སྟོན་ལམ་ཐིག | མཐའ་མཚམས་ལ་སྤྱོད་པའི་གཞི་གྲངས་historical/worldརྩིས་ཁྲ། |

འབྱུང་ཁུངས་གནས་སྟངས་ནི།`available`, `expected_empty`, `partial`, `deferred`, `unavailable`, `malformed`, `permission_denied`, ཡང་ན་ `error`.

སྒྲིག་སྟངས`source_accounting.enabled = false` གིས་གནས་སྟངས་ཐོན་འབྲས་ཁུ་སིམ་ངང་མེད་པར་མི་བཟོ། མདོང་ལམ་གྱིས་ད་དུང་`runtime/final_logs/source_accounting_latest.json` དང་མཉམ་དུ་ `enabled=false`, `status="unavailable"`, དང་ `disabled_reason="source_accounting_disabled"`. དེས་རྩིས་ཁྲ་མེད་པའི་ལོ་རྒྱུས་གནས་བབ་ཀྱི་ཐོ་འགོད་ཡང་བྲིས་ཡོད། འབྱུང་ཁུངས་རྩིས་ཁྲ་དེ་སྙན་ཞུའི་གན་རྒྱའི་ཆ་ཤས་ཤིག་ཡིན་པས་ལམ་ཐིག་ཚང་མ་`missing`; རྩིས་ཁྲ་ལྕོགས་མིན་བཟོས་པའི་སྐབས་ལམ་ཐིག་གང་ཡང་མཇུག་སྒྲིལ་བར་བརྩི་མི་ཐུབ།

<a id="reports"></a>
## `reports`

སྤྱིར་བཏང་གི་ས་གནས་སྙན་ཞུའི་མདོང་ལམ་ཚོད་འཛིན་བྱེད།

སྔོན་སྒྲིག་གིས་ལམ་ཐིག་ལྔ་པོ་ཚང་མ་ལྕོགས་ཅན་བཟོས་པ་དང་ `runtime/final_logs`:

```text
server_status
daily_rollup
player_activity
case_review
critical_guard
```

ལམ་ཐིག་རེ་རེར་སྒྲིག་བཀོད་དང་སྐད་སྒྱུར་བྱས་པའི་ཐོན་འབྲས་དང་བདེན་དཔང་`route_proof.json`. ལམ་ཐིག་ཅིག་ལྕོགས་མེད་བཟོས་ན་ `missing` བདེན་དཔང་བྱེད་པ་ལས་དེ་མཇུག་སྒྲིལ་ཡོད་པའི་ཁ་གཡར་མི་དགོས།

<a id="notification"></a>
## `notification`

འདམ་ཀའི་སྤྱིར་བཏང་གི་ས་གནས་ཡིག་ཆའི་ཕྱིར་སྒྲོམ། དེ་སྔོན་སྒྲིག་ལྟར་ལྕོགས་མིན་བཟོས་པ་དང་ཕྱི་རོལ་གྱི་མཁོ་སྤྲོད་བྱེད་མཁན་ལ་གང་ཡང་བཏང་མི་ཐུབ།

སྔོན་སྒྲིག:

```lua
notification = {
    enabled = false,
    mode = "local_file_outbox",
    include_expected_empty = false,
},
```

བརྡ་ཐོའི་འགྲོ་ལམ་ཚང་མ་སྔོན་སྒྲིག་ལྟར་ལྕོགས་མིན་བཟོས་ཡོད། བསམ་བཞིན་དུ་ལྕོགས་ཅན་བཟོས་སྐབས་ཕྱིར་སྒམ་གྱིས་`route_proof.json` བྲིས་ཡོད། ས་གནས་ཀྱི་དཔང་རྟགས་དང་སྙན་ཞུའི་དབང་ཆ་སྔར་བཞིན་གནས་ཡོད། མཁོ་སྤྲོད་བྱེད་མཁན་གྱི་དམིགས་བསལ་གྱི་སྐྱེལ་འདྲེན་དང་། སྐྱེལ་འདྲེན་གྱི་མཐའ་མཚམས། ཡིག་ཆ། ཟམ་པ་བཅས་ནི་སྤྱི་པའི་རང་དབང་ལྟ་རྟོག་བྱེད་མཁན་གྱི་གན་རྒྱའི་ཆ་ཤས་ཤིག་མ་རེད།

## `restart_request`

བཀོལ་སྤྱོད་པ་གཞན་གྱིས་བདག་གཉེར་བྱེད་པའི་བྱ་རིམ་གྱིས་ཞིབ་བཤེར་བྱེད་སྲིད་པའི་འདམ་ཀའི་ས་གནས་ཀྱི་མཚོན་རྟགས་ཡིག་ཆ་ཚོད་འཛིན་བྱེད། དེས་སར་བར་ཡང་བསྐྱར་འགོ་འཛུགས་མི་ཐུབ་པའམ་ཡང་ན་གསོད་མི་ཐུབ།

སྔོན་སྒྲིག:

```lua
restart_request = {
    enabled = false,
    restart_marker_file = "runtime/request_restart.flag",
    restart_reason_file = "runtime/restart_reason.json",
},
```

ཐོན་འབྲས།

```text
runtime/request_restart.flag
runtime/restart_reason.json
```

མགྲོན་ཁང་གི་སྒྲོམ་གཞི་དང་། མཁོ་སྤྲོད་བྱེད་མཁན་གྱི་ཟམ་པ། ཡང་ན་བསྐྱར་འགོ་འཛུགས་རང་འགུལ་ཅན་བཅས་སྒྲིག་སྦྱོར་བྱས་མེད། རྟགས་བཀོད་པ་གསར་བཟོ་བྱེད་པ་དེས་ཕྱི་རོལ་གྱི་བྱ་རིམ་གྱིས་རེ་འདུན་དེ་བེད་སྤྱོད་བཏང་བའམ་ཡང་ན་སར་བར་བསྐྱར་དུ་འགོ་འཛུགས་བྱས་པ་ཁུངས་སྐྱེལ་བྱེད་ཀྱི་མེད།
