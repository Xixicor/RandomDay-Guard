## ལྟེ་བའི་ཁྲིམས་ལུགས།

RandomDayGuard གིས་སར་བར་གྱི་བདག་དབང་ཡོད་པའི་ཡིག་ཆ་ནས་ཚད་གཞི་ཅན་གྱི་དོ་སྣང་ཐོ་འགོད་བྱེད། དེས་དངོས་པོའི་མཇུག་སྡོམ་རེ་རེའི་འབྱུང་ཁུངས་དང་། ཁྱབ་ཁོངས། བསྡུ་སྒྲིག་གནས་སྟངས། ཚད་གཞི་བཅས་ངོས་འཛིན་བྱེད་དགོས།

སྒྲིག་བཀོད་ཀྱི་དཔང་རྟགས་ནི་དབང་ཆ་ཡོད། སྐད་སྒྱུར་བྱས་པའི་སྙན་ཐོ་ཞིག་གིས་མངོན་གསལ་འགྲེལ་བཤད་རྒྱག་པ་དང་། དེས་སྒྲིག་བཀོད་བྱས་པའི་ཐོ་འགོད་ནང་མེད་པའི་དོན་དངོས་ཁ་སྣོན་བྱེད་མི་ཐུབ།

<a id="current-versus-historical-evidence"></a>
## ད་ལྟའི་དང་ལོ་རྒྱུས་ཀྱི་དཔང་རྟགས།

ད་ལྟའི་སྒྲུབ་བྱེད་དེ་བསྡུ་སྒྲིག་སྒེའུ་ཁུང་ཡང་ན་སར་བར་གྱི་དུས་རབས་ལ་གཏོགས་ཡོད། ལོ་རྒྱུས་ཀྱི་དཔང་རྟགས་དེ་སྔོན་གྱི་དྲན་ཐོ་དང་། གྱོད་གཞི། སྙན་ཞུ། དཔང་རྟགས་ཀྱི་ཐོ་འགོད། རྒྱབ་སྐྱོར། ཡང་ན་གཞི་གྲངས་བཅས་ནས་ཡོང་བ་རེད།

ལོ་རྒྱུས་ཀྱི་དཔང་རྟགས་ཀྱིས་སྐབས་དོན་མཁོ་སྤྲོད་བྱེད་ཐུབ། ད་ལྟའི་དཔང་རྟགས་ཀྱི་སྟོང་ཆ་དེ་ཁུ་སིམ་མེར་བསྒྲུབ་མི་ཐུབ། སྙན་ཞུའི་ནང་ཁྱབ་ཁོངས་གཉིས་ཀར་མཚོན་རྟགས་བཀོད་དགོས་པ་དང་དེ་དག་གི་ཐོན་ཁུངས་སོ་སོར་བཀོད་དགོས།

<a id="corroboration-rule"></a>
## བདེན་དཔང་ཁྲིམས་ལུགས།

འདི་དག་ཕན་ཐོགས་ཅན་གྱི་སྐབས་དོན་ཡིན་མོད། འོན་ཀྱང་དེ་དག་རང་ཉིད་ཀྱིས་ཐད་ཀར་སྒྲུབ་བྱེད་མིན།

- མངོན་པའི་མིང་ངམ་མིང་འདྲ་མཚུངས་;
- དུས་ཚོད་ཀྱི་དུས་མཚུངས་དང་།
- ཆད་པའམ་ཡང་ན་བསྐྱར་དུ་སྦྲེལ་བའི་ཆར་ན;
- བརྡབ་སྐྱོན་གཅིག ཡང་ན་ཉེན་བརྡའི་འབར་གས་;
- རིགས་དང་། ལམ་ཐིག། འཁྲབ་སྟོན་པ། ས་ཁྲ། ཡང་ན་དངོས་པོ་གྲངས་འབོར་གྱི་རྟགས་མཚན།
- རང་འགུལ་གྱིས་སྡེབ་སྒྲིག་བྱས་པའི་གནད་དོན་ནང་གི་ཚོགས་མི།
- ད་ལྟའི་འབྱུང་ཁུངས་གཏན་འཁེལ་མེད་པའི་སྔོན་གྱི་སྙན་ཞུ།

ཉེས་འཛུགས་དང་། དམིགས་ཡུལ། མགོ་སྐོར་གཏོང་བ། བདག་དབང་། རྐུན་མ། འདྲ་བཤུས། ཐད་ཀར་གྱི་གནོད་སྐྱོན། ཐད་ཀར་གྱི་སྣོད་ཆས་བེད་སྤྱོད། ཐད་ཀར་གྱི་ཐོ་གཞུང་བྱ་སྤྱོད།
