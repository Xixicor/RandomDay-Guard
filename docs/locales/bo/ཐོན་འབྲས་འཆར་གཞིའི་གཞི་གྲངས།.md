# ཐོན་འབྲས་དང་གནས་སྟངས་འཆར་གཞིའི་གཞི་གྲངས།

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [OUTPUT_SCHEMA_REFERENCE.md](../../OUTPUT_SCHEMA_REFERENCE.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


འདི་ནི་བཀོལ་སྤྱོད་ལ་ཁ་གཏད་པའི་ཡིག་ཆའི་ཆེད་དུ་བཟོས་པའི་ཁྲིམས་མཐུན་གན་རྒྱ་ཡིན། དེ་གཅིག་པུར་ཐོན་འབྲས་ལམ་ཐིག་ངེས་ཅན་དང་། ས་སྒོའི་མིང་། ཆོག་མཆན་ཐོབ་པའི་རིན་ཐང་། རིགས་རྒྱུད་ཀྱི་དགོས་མཁོ། ལམ་ཐིག་འཆར་གཞི་བཅས་ཡོད། བྱ་ཐབས་ལམ་སྟོན་འདིར་འབྲེལ་མཐུད་བྱས་ནས་དོན་དངོས་དེ་དག་ལ་བསྐྱར་དུ་ངེས་ཚིག་བཀོད་དགོས།

རྒྱུག་དུས་ཀྱི་སྒྲུབ་བྱེད་དེ་དབང་ཆ་ལྡན་པ་ཡིན། ཡིག་ཆའི་མིང་དང་། དུས་ཚོད་གཏན་འཁེལ་བྱེད་མཁན་གྱི་སྙིང་རྩ། སྐད་སྒྱུར་བྱས་པའི་སྙན་ཞུ། ཡང་ན་ས་གནས་ཀྱི་ཕྱིར་སྒྲོམ་དངོས་པོ་དེས་རང་ཉིད་ཀྱི་ས་ཁོངས་དང་རིགས་རྒྱུད་ལས་མང་བ་ཁུངས་སྐྱེལ་མི་བྱེད།
