# དྲན་ཤེས་དཔལ་འབྱོར་དང་ཐོན་འབྲས་ཡིག་ཆ།

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [MEMORY_ECONOMY_AND_OUTPUTS.md](../../MEMORY_ECONOMY_AND_OUTPUTS.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


ཤོག་ངོས་འདིས་ཡིག་ཆ་གང་འཚར་ལོངས་བྱུང་བ་དང་། ཡིག་ཆ་གང་ཞིག་བརྗེ་སྒྱུར་བྱས་པ། མགྱོགས་མྱུར་བསྐྱར་ཞིབ་ཆེད་དུ་གང་ཞིག་ཡར་བསྐུར་དགོས་མིན་འགྲེལ་བཤད་བྱས་ཡོད།

| སུ་མཐོང་སོང་ངམ། | `runtime/account_evidence.json` |

| དེ་རིང་ག་རེ་བྱུང་སོང་ངམ། | `runtime/forensic_days/YYYY-MM-DD/` |
| དྭངས་གསལ་གྱི་ཕྱོགས་བསྡུས་དེ་གང་ཡིན་ནམ། | `runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt` |
| བཤེར་འཇལ་འཕེལ་རིམ་ཟེར་བ་གང་ཡིན་ནམ། | `runtime/scan_progress.json` |
| འཛམ་གླིང་སྐབས་དོན་གང་ཡིན་ནམ། | `runtime/world_state/current/world_state_latest.json` |
| བཀག་སྡོམ་གང་ཞིག་བྲིས་ཡོད་དམ། | `runtime/enforced_bans.jsonl` |

<a id="output-model"></a>
## ཐོན་འབྲས་དཔེ་གཟུགས།

| དབྱེ་བ་ | བྱ་སྤྱོད | དཔེར་བརྗོད། |
|---|---|---|
| ད་ལྟའི་པར་རིས། | བསྐྱར་བྲིས་བྱས་ཡོད། | `runtime/current/*.json` |
| བྱུང་རིམ་དྲན་ཐོ། | ཟུར་སྣོན་ཁོ་ན | `runtime/evidence/*.jsonl` |
| རེའུ་མིག | གསར་བཅོས་བྱས་པའམ་ཡང་ན་ཁ་སྣོན་བྱས་པ། | `*.tsv` |
| གཞི་གྲངས། | མཇུག་སྒྲིལ་རྗེས་ཡང་བསྐྱར་བེད་སྤྱོད་བྱས། | `runtime/baselines/*` |
| ཉིན་རེའི་བསྡུ་སྒྲིག | ས་གནས་སུ་གསར་བཅོས་བྱས། | `runtime/forensic_days/YYYY-MM-DD/*` |
| མཐའ་མའི་དྲན་ཐོ། | སྐད་ཡིག་གསལ་བའི་ཉིན་རེའི་ཕྱོགས་བསྡུས། | `runtime/final_logs/YYYY-MM-DD/*` |
