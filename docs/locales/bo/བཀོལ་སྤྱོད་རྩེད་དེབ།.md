<a id="what-to-read-inside-a-report"></a>
## སྙན་ཐོའི་ནང་དུ་ཅི་ཞིག་ཀློག་དགོས་སམ།

ཚན་པ་འདི་དག་གོ་རིམ་ལྟར་ཀློག་དགོས།

1. **ཕྱོགས་བསྡུས།** - སྙན་ཞུ་འདིས་གང་ཁྱབ་ཡོད།
2. **སྲུང་དམག་གིས་ག་རེ་དོ་སྣང་བྱས།** - ལམ་ཐིག་འདིའི་ཆེད་དུ་བསྡུ་རུབ་བྱས་པའི་དུས་ཚོད་ཀྱི་རྟགས་མཚན་ངོ་མ། གྲངས་འབོར། རྩིས་ཁྲ། ལས་རིམ་ཡང་ན་གནས་ཚུལ་གྱི་རིན་ཐང་།
3. **དེའི་གོ་དོན་གང་ཡིན།** - ཐོ་འགོད་དེ་དག་གི་སྐད་ཡིག་གཙང་མའི་དོན་འགྲེལ།
4. **གང་ཞིག་མ་ཤེས་པར་ལྷག་ཡོད།** - གྲུབ་འབྲས་ལ་ཤུགས་རྐྱེན་ཐེབས་པའི་འབྱུང་ཁུངས་ཡང་ན་བཤེར་འཚོལ་ཚད་གཞི།
5. **འོས་སྦྱོར་བྱས་པའི་གོམ་སྟབས་རྗེས་མ** - མིང་བཏགས་པའི་བརྗོད་གཞི་ལ་ལྟ་རྟོག་བྱེད་དགོས་སམ། བསྐྱར་ཞིབ་བྱེད་དགོས་སམ། ཡང་ན་སྲུང་སྐྱོབ་པ་ཉམས་གསོ་བྱེད་དགོས་སམ།
6. **བདེན་དཔང་མཐའ་མཚམས།** - སྙན་ཞུའི་ཁྱབ་ཁོངས་ཀྱི་ཚད་གཞི།

ལག་རྩལ་གྱི་ཐོ་འགོད་དང་ཐོན་ཁུངས་གཞི་གྲངས་དེ་མཇུག་ཏུ་འཆར་གྱི་ཡོད།

## སྙན་ཞུ་ཞིག་བརླག་པའི་སྐབས།

|---|---|
| `full` | སྲུང་དམག་གིས་ད་ལྟའི་ལམ་ཐིག་བདག་དབང་ཡོད་པའི་དཔང་རྟགས་དང་མཉམ་དུ་ལམ་ཐིག་མཇུག་སྒྲིལ་ཡོད། |
| `limited_expected_empty` | སྲུང་སྐྱོབ་པ་ལམ་ཐིག་དེ་མཇུག་སྒྲིལ་ནས་ཆ་རྐྱེན་ཚང་བའི་བྱུང་རིམ་གང་ཡང་མཐོང་མ་བྱུང་། ཡང་ན་མིང་བཏགས་པའི་དུས་ཚོད་ཚད་གཞི་ཐོ་འགོད་བྱས། |
| `missing` | དགོས་མཁོའི་འབྱུང་ཁུངས་དང་། རིགས་རྒྱུད་ཞིབ་བཤེར། ཡང་ན་ཆ་སྒྲིག་སྙན་ཞུ་འབྲི་བ་མཇུག་སྒྲིལ་མེད། |

## བརྡབ་སྐྱོན་བྱུང་བའམ་བསྐྱར་དུ་འགོ་འཛུགས་བྱས་རྗེས།

1. སར་བར་གསར་པ་གཡོག་པའི་དུས་ཚོད་མཚོན་རྟགས་དང་མཐའ་མའི་མཇུག་སྒྲིལ་བའི་ལྟ་རྟོག་འཁོར་རིམ་གྱི་སར་བར་གནས་ཚུལ་ཀློག
2. ད་ལྟའི་འགོ་འཛུགས་ཡང་ན་འོས་བསྡུའི་འཐུས་ཤོར་གྱི་གལ་ཆེའི་སྲུང་སྐྱོབ་ཀློག
3. མི་ཚེའི་འཁོར་རིམ་བསྒྱུར་བཅོས་བྱས་རྗེས་ཉིན་གཅིག་གི་ལས་རིམ་མཉམ་ཞུགས་བྱས་པའམ་ཡང་ན་ཕྱིར་ལོག་བྱས་པའམ་ཡང་ན་ཕྱིར་ལོག་བྱུང་བ་ཡིན་ན་རྐྱངམ་གཅིག་རྩེད་མོ་བའི་བྱེད་སྒོ་ཀློག་དགོས།
4. སྒྲིག་བཀོད་བསྒྱུར་བཅོས་མ་བྱས་གོང་ལུང་འདྲེན་བྱས་པའི་འབྱུང་ཁུངས་དྲན་ཐོ་ཉར་ཚགས་བྱོས།

## གདམ་ཀ་ནུས་ལྡན་མ་བཟོས་གོང་Admin.ini བྲིས།

སྔོན་སྒྲིག་ཐུམ་སྒྲིལ་གྱིས་འགྱུར་བ་མེད་པར་ལྟ་ཞིབ་དང་སྙན་ཞུ་བྱེད། `Admin.ini`. ཡར་ཐོན་ཅན་གྱི་བཀོལ་སྤྱོད་པ་ཚོས་ཡིག་ཆའི་འདྲ་བཤུས་ལ་ཚོད་ལྟ་བྱས་རྗེས་འདེམས་གཞིའི་ལག་བསྟར་ལམ་དེ་ལྕོགས་ཅན་བཟོ་ཐུབ། དེ་ནས་སྲུང་སྐྱོབ་པ་ལ་ཨང་གྲངས་ཀྱི་རྩིས་ཁྲའི་IDགཙང་མ་དགོས་པ་དང་། ཡིད་ཆེས་བྱེད་ཐུབ་པའི་རྩིས་ཁྲ་སྲུང་སྐྱོབ་བྱེད་པ། རྒྱབ་ཐག་གསར་འཛུགས་དང་བདེན་དཔང་བྱེད་པ། དུས་མཉམ་གྱི་བསྒྱུར་བཅོས་ཁས་མི་ལེན། [`ADMIN_INI_ENFORCEMENT.md`](%E0%BD%A0%E0%BD%9B%E0%BD%B2%E0%BD%93%E0%BC%8B%E0%BD%A6%E0%BE%90%E0%BE%B1%E0%BD%BC%E0%BD%84%E0%BC%8B%E0%BD%A8%E0%BD%B2%E0%BC%8B%E0%BD%93%E0%BD%B2%E0%BC%8B%E0%BD%A3%E0%BD%82%E0%BC%8B%E0%BD%96%E0%BD%A6%E0%BE%9F%E0%BD%A2%E0%BC%8D.md) སྒྲིག་བཀོད་དང་ཚོད་ལྟའི་གོ་རིམ་ཆ་ཚང་ཆེད་དུ།
