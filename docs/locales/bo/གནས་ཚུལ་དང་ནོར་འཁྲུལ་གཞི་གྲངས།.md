# གནས་ཚུལ་དང་ནོར་འཁྲུལ་དཔྱད་གཞི།

> **དབྱིན་ཇིའི་ཁྲིམས་མཐུན་གྱི་འབྱུང་ཁུངས།:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). ས་གནས་ཀྱི་ཡིག་ཆ་འདིས་གཏན་འཁེལ་གྱི་བཀའ་ཚིག་དང་འགྲོ་ལམ་དང་ལྡེ་མིག་དང་གནས་ཚད་ཀྱི་རིན་ཐང་དང་ཧ་ཤི་དང་ཡིག་ཆའི་མིང་རྣམས་ཉར་ཚགས་བྱེད། གལ་ཏེ་ལག་རྩལ་གྱི་ཚིག་སྦྱོར་མི་འདྲ་ན་དབྱིན་ཡིག་གི་ཐོན་ཁུངས་བེད་སྤྱོད་བྱེད་དགོས།


རྟགས་འདི་[སྐྱོན་སེལ་ཐབས།](%E0%BD%A6%E0%BE%90%E0%BE%B1%E0%BD%BC%E0%BD%93%E0%BC%8B%E0%BD%A6%E0%BD%BA%E0%BD%A3%E0%BC%8B%E0%BD%90%E0%BD%96%E0%BD%A6%E0%BC%8D.md). ནོར་འཁྲུལ་གྱིས་མིང་བཏགས་པའི་སྒྲིག་བཀོད་གནས་ཚུལ་ཡིག་ཆ་ཀློག མཚོན་རྟགས་མི་འདྲ་བ་དེས་བདེ་འཇགས་དང་འཚོ་བའི་འཁོར་རིམ་གྱི་གནས་སྟངས་མི་འདྲ་བ་མཚོན་གྱི་ཡོད། དེ་དག་སྤྱིར་བཏང་གི་"སྲུང་སྐྱོབ་འཐུས་ཤོར་"གྲུབ་འབྲས་ལ་མ་བསྒྲིགས།
