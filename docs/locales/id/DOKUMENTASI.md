# RandomDayGuard dokumentasi

> **Sumber kanonis bahasa Inggris:** [README.md](../../README.md). Dokumentasi yang dilokalkan ini mempertahankan perintah, jalur, kunci, nilai status, hash, dan nama file yang tepat. Jika kata-kata teknisnya berbeda, gunakan sumber bahasa Inggris.


RandomDayGuard membaca catatan dari server khusus Abiotic Factor dan mengubahnya menjadi laporan terpisah untuk kesehatan server, riwayat harian, sesi pemain, kasus peninjauan, dan kegagalan Penjaga.
