<a id="memory-economy-and-output-files"></a>
# 메모리 절약 및 출력 파일

> **표준 영어 소스:** [MEMORY_ECONOMY_AND_OUTPUTS.md](../../MEMORY_ECONOMY_AND_OUTPUTS.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


이 페이지에서는 어떤 파일이 커지는지, 어떤 파일을 덮어쓰는지, 빠른 검토를 위해 업로드할 항목에 대해 설명합니다.

<a id="fast-answer"></a>
## 빠른 답변

| 질문 | 공개 |
|---|---|
| 경비원은 살아 있나요? | `runtime/current/poll_status.json` |
| 누가 목격되었나요? | `runtime/account_evidence.json` |
| 세션에 무슨 일이 일어났나요? | `runtime/evidence/session_events.jsonl` |
| 오늘 무슨 일이 있었나요? | `runtime/forensic_days/YYYY-MM-DD/` |
| 평문 요약은 무엇인가요? | `runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt` |
| 스캔 진행 상황은 무엇입니까? | `runtime/scan_progress.json` |
| 세계 상황은 무엇입니까? | `runtime/world_state/current/world_state_latest.json` |
| 어떤 금지 사항이 기록되었습니까? | `runtime/enforced_bans.jsonl` |

<a id="output-model"></a>
## 출력 모델

| 유형 | 행동 | 예 |
|---|---|---|
| 현재 스냅샷 | 덮어쓰기 | `runtime/current/*.json` |
| 이벤트 로그 | 추가 전용 | `runtime/evidence/*.jsonl` |
| 테이블 | 업데이트 또는 추가됨 | `*.tsv` |
| 기준 | 다음 이후 재사용 완료 | `runtime/baselines/*` |
| 일일 롤업 | 현재 업데이트됨 | `runtime/forensic_days/YYYY-MM-DD/*` |
| 최종 로그 | 일반 언어 일일 요약 | `runtime/final_logs/YYYY-MM-DD/*` |

<a id="current-snapshots"></a>
## 현재 스냅샷

이 파일은 작게 유지되며 "현재 사실이 무엇인지"에 답합니다.

```text
runtime/current/poll_status.json
runtime/current/session_state.json
runtime/current/active_accounts.json
runtime/current/forensic_today.json
runtime/current/forensic_today.md
runtime/current/forensic_today.txt
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/world_state/current/world_state_latest.json
```

<a id="player-summaries"></a>
## 플레이어 요약

이 파일은 계정 검토를 위해 확인할 첫 번째 파일입니다.

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

요약:

```text
account_id
ban_id
name
identity_confidence
first_seen
last_seen
join_count
leave_count
status
score
```

<a id="event-logs"></a>
## 이벤트 로그

이 파일은 타임라인.

```text
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/warning_events.jsonl
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/evidence/live_defense_events.jsonl
```

<a id="daily-forensic-rollups"></a>
## 일일 포렌식 롤업

빠른 업로드 패키지입니다.

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

빠른 기간 분석을 원할 때 해당 폴더 중 하나를 업로드하세요.

<a id="scan-and-baseline-files"></a>
## 스캔 및 기준 파일

이를 사용하여 세계 맥락이 부분적인지 아니면 완전한지 이해하세요.

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/scan_complete.json
runtime/object_registry_partial.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
```

<a id="enforcement-files"></a>
## 적용 파일

적용이 활성화된 경우에만 이 파일을 사용하세요.

```text
runtime/enforced.txt
runtime/enforced_bans.jsonl
runtime/ban_queue.json
runtime/evidence/enforced_bans.jsonl
```

`Admin.ini`다음만 수신해야 합니다:

```ini
BannedPlayer=<ID>
```

<a id="what-updates-when-a-player-joins"></a>
## 플레이어가 참가할 때 업데이트되는 내용

예상 업데이트:

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/current/session_state.json
runtime/forensic_days/YYYY-MM-DD/players.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="what-updates-when-the-server-crashes-or-restarts"></a>
## 서버가 충돌하거나 다시 시작될 때 업데이트되는 내용

예상 업데이트:

```text
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/account_evidence.json
runtime/forensic_days/YYYY-MM-DD/crash_reconnects.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

## 스캔이 진행되면 업데이트되는 항목

## 빠른 분석을 위해 업로드할 항목
