# 용어집

> **표준 영어 소스:** [GLOSSARY.md](../../GLOSSARY.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


| 용어 | 일반적인 의미 | 정확함 기술적 의미 |
|---|---|---|
| 활성 로그 | 새로운 증거에 사용되는 현재 서버 로그. | 필수 `active_log` 소스; 경로 완료를 위해서는 가독성과 현재 계보가 필요합니다. |
| 부팅 ID | 1개의 감시 프로세스 시작. | 이전 부팅을 거부하는 데 사용되는 현재 런타임 식별자 errors/reports. |
| Epoch ID | 1개의 서버 연속성 간격. | 연속성 논리가 다른 시대를 시작할 때까지 일반 런타임에 걸쳐 있는 식별자. |
| Poll ID | 한 개의 제한된 폴 기회. | 양의 단조 주기 필드, zero/missing 경로를 완료할 수 없습니다. |
| 소스 최신성 | 현재 소스와 설문 조사 계보가 일치하는지 여부. | `fresh_current_poll` 또는 `stale_or_unproven` 타임스탬프 및 활성 로그 상태 |
| 소스 회계 | 증거 가용성 및 한계 목록. | `randomdayguard.source-accounting/v1` 8개의 소스 클래스 및 current/historical 범위. |
| `available` | 소스를 찾아서 읽었습니다. | `available=true`, `readable=true`. |
| `expected_empty` | 선택적 소스를 확인하고 적법하게 absent/empty. | 터미널에서 읽을 수 있는 소스 상태; 결코 주제를 만들지 않습니다. |
| `partial` | 제한된 작업에는 유용하지만 불완전한 결과가 있습니다. | 비터미널 source/accounting 상태; 소유한 작업자를 재개하세요. |
| `deferred` | 작업이 의도적으로 보류 중입니다. | 비터미널 소스 상태. 오류나 완료가 아닙니다. |
| `unavailable` | 현재 소스를 사용할 수 없습니다. | 단자 간격; 필수 소스 간격으로 인해 계정을 사용할 수 없습니다. |
| `malformed` | 소스가 존재하지만 구조적으로 유효하지 않습니다. | 터미널 간격이 유효성 검사 세부 정보를 보존하고 종속 쓰기를 닫습니다. |
| `permission_denied` | OS가 명시적으로 액세스를 거부했습니다. | missing/unavailable. |
| `error` | 제한된 작업이 실패했습니다. 예기치 않게 발생했습니다. | 명명된 복구가 필요한 터미널 오류입니다. 공개 보고서에는 비밀 세부정보가 포함되지 않습니다. |
| `complete` | 모든 계정 소스는 공백 없이 최종 상태입니다. | 최상위 소스 계정 상태. |
| `complete_with_gaps` | 필요한 현재 증거가 작동합니다. 선택적 단말기 공백이 남아 있습니다. | 최상위 회계 상태; 경로에는 여전히 자체 요구사항이 적용됩니다. |
| `full` | 비어 있지 않은 필수 계약으로 완료된 경로. | 현재 주기 출력이 완료된 경로 증명 열거형 |
| `limited_expected_empty` | 완료된 경로가 있으나 적격한 경로가 발견되지 않음 subject/failure. | 경로 증명 열거형`completed=true`, `expected_empty=true`. |
| `missing` | 경로 완료 증명이 없거나 실패했습니다. | 경로 증명 열거형`completed=false`; 보낼 편지함을 사용할 수 없습니다. |
| 구조화된 보고서 | 기계가 읽을 수 있는 경로 출력. | `<route>_latest.json` 사용 `randomdayguard.report/v1`. |
| 번역된 보고서 | 사람이 읽을 수 있는 동일한 경로 렌더링 | `<route>_latest.txt` 관찰된 소스 참조 순서가 고정되어 있습니다. |
| 경로 증명 | 교차 경로 완료 원장. | `route_proof.json` 바인딩 version/boot/epoch/poll/freshness/output 경로. |
| 현재 증거 | 활성 주기가 소유한 관측치. | 범위 `current`; 오래된 것에서 재구성되지 않았습니다 filenames/reports. |
| 역사적 증거 | 이전 주기 또는 느린 스캔의 컨텍스트를 유지합니다. | 범위 `historical`; 검토 결과를 알릴 수는 있지만 현재 존재한다고 주장할 수는 없습니다. |
| 검토 전용 | 기본값 없이 검토 증거 생성Admin.ini 쓰기를 제어합니다. | 기본값 `review_only_mode=true`, `auto_ban=false`, `write_admin_ini=false`. |
| 금지 목록 안전 확인 | Guard가 변경되기 전에 한 가지 질문에 답해야 합니다. `Admin.ini`. | 계정과 점수를 확인하고, 신뢰할 수 있는 계정과 중복 항목을 제외하고, 백업을 확인하고, 외부 변경 사항을 감지하고, 의도한 업데이트를 저장하고, 전체 내용을 확인하거나 안전하게 복원해야 합니다. 파일. |
| 로컬 보낼 편지함 | 제공자 중립적 알림 전달 옵션. | JSON `delivery_backend="none"` 및 `delivery_attempted=false`. |
| 기준 | 제한된 저장된 파일 컨텍스트 스냅샷이 포함된 JSON 파일. | Manifest/object/world 호환 가능하고 충분히 새로운 경우에만 상태가 재사용됩니다. |
| 체크포인트 | 불완전한 스캔 작업에 대한 위치를 재개합니다. | `scan_checkpoint.json`; 삭제는 기본 복구가 아닙니다. |
| 재구축 가능한 인덱스 | 재생성할 수 있는 요약. | Daily/weekly/forensic/final 검토 출력; 소스 증거는 여전히 신뢰할 수 있습니다. |
| 증거 경계 | 소스가 지원할 수 있는 항목에 대한 제한. | 명시적 `does_not_prove`, 알 수 없는 항목, ID 강도 및 범위 규칙. |

스키마에 대한 정식 정의는 [`OUTPUT_SCHEMA_REFERENCE.md`](%EC%B6%9C%EB%A0%A5_%EC%8A%A4%ED%82%A4%EB%A7%88_%EC%B0%B8%EC%A1%B0.md)에 있습니다. 구성 용어는 [`CONFIG_FIELD_CATALOG.md`](%EA%B5%AC%EC%84%B1_%ED%95%84%EB%93%9C_%EC%B9%B4%ED%83%88%EB%A1%9C%EA%B7%B8.md).
