# 5가지 Guard 보고서의 예

> **표준 영어 소스:** [REPORT_EXAMPLES.md](../../REPORT_EXAMPLES.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


이 예제는 릴리스에 포함된 샘플 데이터에서 생성되었습니다. 이름과 계좌번호가 만들어졌습니다. 테스트된 보고서 필드, 계산 및 경로 경계가 표시됩니다. 실제 보고서는 이를 해당 서버에서 수집된 정보로 대체하고 언제 사실을 사용할 수 없는지 알려줍니다.

각 보고서에는 하나의 작업이 있습니다. 서버 상태는 플레이어 기록을 반복하지 않으며 일일 리뷰는 몇 분마다 전송되지 않으며 조용한 플레이어 또는 케이스 경로는 필러 메시지를 받지 않습니다. 제한된 기록 스캔이 계속 진행되는 동안 현재 보고서가 준비될 수 있습니다. 이 경우 보고서는 이전 기록을 완료된 것으로 표시하는 대신 간격의 이름을 지정합니다.

<a id="when-a-route-is-quiet"></a>
## 경로가 조용할 때

고요 경로는 Discord에 필러를 보내지 않고 직접적인 결과를 기록합니다:

> **확인; 이 보고서에는 아무것도 없습니다.** 필수 기록이 사용 가능했으며 이 보고서 기간 동안 일치하는 플레이어 활동, 사례 또는 가드 실패가 발생하지 않았습니다.

완전히 비어 있는 결과입니다. 필요한 소스를 확인할 수 없거나 읽을 수 있는 출력을 생성할 수 없는 누락된 보고서와는 다릅니다.

읽을 수 있는 모든 보고서는 동일한 경로를 따릅니다.

```text
collected evidence -> normalized values -> dictionary mapping -> route calculations -> readable report -> Discord notification
```
