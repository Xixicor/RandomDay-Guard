# 설치 RandomDayGuard

> **표준 영어 소스:** [INSTALL.md](../../../INSTALL.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


이 가이드는 설치합니다. `v0.4.12-alpha`를 떠나야 합니다. 모드는 하나의 호스팅 회사나 제어판에 연결되어 있지 않습니다.UE4SS를 사용하고 있는 Abiotic Factor 전용 서버에

<a id="before-you-begin"></a>
## 시작하기 전에

필요 사항:

- 전용 서버를 중지하고 시작할 수 있는 액세스 권한,
- 업데이트하는 경우 서버의 UE4SS `Mods` 폴더,
- 현재 RandomDayGuard 폴더 사본;
- 모드를 변경하기 전에 일반적으로 보호하는 서버 데이터의 백업.

**Mods 폴더**은 `ue4ss/Mods/` 전용 서버 설치 내부 디렉토리. RandomDayGuard은 해당 폴더 내부에 직접 속합니다.

<a id="new-installation"></a>
## 새 설치

1. 전용 서버를 중지합니다.
2. RandomDayGuard ZIP를 새로운 빈 폴더에 추출합니다.
3. 추출된 `RandomDayGuard` 폴더는 내부에 중첩된 두 번째 UE4SS `Mods` 폴더. 결과는 하나의 `Mods/RandomDayGuard/` 폴더에 들어갑니다. RandomDayGuard 폴더가 아니라 서버의
4. 열기UE4SS `mods.txt` 다음을 활성화하고:

   ```text
   RandomDayGuard : 1
   ```

5. 정상적으로 서버를 시작합니다.
6. 기다린 후 UE4SS 및 게임 서버 시작을 완료한 후 [첫 번째 보고서 읽기](%EC%97%AC%EA%B8%B0%EC%84%9C_%EC%8B%9C%EC%9E%91.md).

실행 중인 설치 위에 새 릴리스를 복사하지 마세요. 업데이트된 설치에서 현재 서버 상태 보고서가 생성될 때까지 백업을 유지하세요.

<a id="update-an-existing-installation"></a>
## 기존 설치를 업데이트하세요

1. 서버를 중지하세요.
2. 완전히 설치된 RandomDayGuard 폴더를 안전한 백업 위치로 복사하세요.
3. 이전 프로그램 폴더를 UE4SS `Mods`
4. 새 RandomDayGuard 폴더를 `Mods`.
5. 검토한 로컬 구성만 복원하고 저장해 두세요. 증거. 구성 가이드에 새 필드가 나열되어 있으면 모든 설정을 맹목적으로 바꾸는 대신 검토된 복사본에 병합하세요.
6. 확인 `RandomDayGuard : 1`활성화된 상태로 유지됩니다.
7. 서버를 시작하고 현재 서버 상태 보고서를 읽습니다.

이 클린 폴더 업데이트는 운영자에게 프로그램 검사를 요청하지 않고도 이전 릴리스에서 사용되지 않는 파일을 제거합니다. filenames.

<a id="help-guard-find-the-server-records"></a>
## Guard가 서버 기록을 찾도록 도와주세요

Guard는 일반적으로 Abiotic Factor `Saved` 디렉터리를 자동으로 찾습니다. 그럴 수 없는 경우 RandomDayGuard 폴더 내부의 `Saved` 디렉터리의 전체 경로를 입력하세요. 아래에 있는 하나의 개별 세계가 아닌 `SavedRoot.txt` RandomDayGuard 폴더. `Saved`를 가리킵니다.

첫 번째 서버 상태 보고서에는 레코드 위치가 발견되었는지 여부와 사용 가능한 소스 그룹이 나와 있습니다. [문제 해결](%EB%AC%B8%EC%A0%9C_%ED%95%B4%EA%B2%B0.md) 위치를 읽을 수 없는 경우

<a id="disable-or-remove-randomdayguard"></a>
## 비활성화 또는 제거 RandomDayGuard

1. 서버를 중지하세요.
2. 전체 복사 RandomDayGuard 폴더를 안전한 아카이브로 이동하세요.
3. 모드를 비활성화하려면 `RandomDayGuard : 0` UE4SS `mods.txt`.
4. 제거하려면 전체를 이동하세요. RandomDayGuard 폴더 `Mods` 밖으로 이동하세요.
5. 서버를 시작하고 Guard가 더 이상 시작되지 않는지 확인하세요.

Guard를 비활성화하거나 제거하면 향후 수집이 중지됩니다. 게임 데이터를 삭제하거나 보관된 보고서를 지우거나 별도의 운영자 작업을 취소하지 않습니다.

<a id="roll-back-an-update"></a>
## 업데이트 롤백

새 설치가 로드되지 않거나 현재 보고서를 생성할 수 없는 경우:

1. 서버를 중지하세요.
2. 기록을 삭제하지 않고 실패한 설치를 옆으로 옮기십시오.
3. 전체 사전 업데이트 복원 RandomDayGuard 폴더.
4. 검토된 구성과 저장된 증거를 동일한 백업에서 복원하세요.
5. 모드가 활성화되었는지 확인하고 서버를 시작하세요.
6. 다른 변경을 하기 전에 복원된 서버 상태 보고서를 읽어보세요.
