<a id="detection-signals"></a>
# 탐지 신호

> **표준 영어 소스:** [DETECTION_SIGNALS.md](../../DETECTION_SIGNALS.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


신호는 자동 고발이 아닌 검토 입력입니다.

<a id="signal-table"></a>
## 신호 테이블

| 신호 | 의미 | 강한 경우... | 그 자체만으로는 충분하지 않음 |
|---|---|---|---|
| 로그인 ID | 이름을 계정 ID에 매핑 | ConnectID가 존재함 | 차단 |
| 클린 탈퇴 | 정상 세션 종료 | 참여 및 탈퇴 매치 | 의심 |
| 빠른 재접속 | Churn/probing컨텍스트 | 빠른 반복 | 차단 |
| 깨끗하지 않은 연결 해제 | 세션이 완전히 종료되지 않았습니다 | 충돌이 반복되거나 겹칩니다. | 차단 |
| 충돌이 겹칩니다 | 충돌에 가까운 계정 활성 | 동일한 계정이 반복됩니다 | 차단 |
| 충돌 후 반환 | 다시 시작 후 계정 반환 | 세대에 걸쳐 반복 | 한 이벤트에 의한 금지 |
| 경고 버스트 | 서버 경고 창 | 매핑된 세션 중복 | 한 버스트로 금지 |
| 배우 저장 터치 | 세계 저장 컨텍스트 | 상관 관계 세션 | use/theft |
| 객체 델타 | World/class 변경 증명 | 상관 관계 세션 | 개수만으로 금지 |
| Rad 케이스 | 다중 계정 클러스터 | 중앙 계정 반복 | 모든 계정 대량 금지 |

<a id="login-identity"></a>
## 로그인 ID

최상의 소스:

```text
Login request
Name=
ConnectID=
UniqueId=
```

매핑에 사용:

```text
display/log name -> account_id -> ban_id
```

<a id="rapid-reconnect"></a>
## 빠른 재접속

패턴:

```text
join -> leave -> join -> leave -> join
```

반복 시 검토에 사용.

안전:

```text
churn_alone_never_bans = true
```

<a id="crash-overlap-and-post-crash-return"></a>
## 충돌 중복 및 충돌 후 반환

패턴:

```text
account active before crash
server restarts
same account returns quickly
```

반복 시 검토에 사용 epochs.

안전:

```text
single_crash_never_bans = true
```

<a id="warning-bursts"></a>
## 경고 폭주

예:

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

매핑된 세션 및 임계값에 연결될 때까지 컨텍스트로 사용합니다.

<a id="actor-save-touch"></a>
## 배우 저장 터치

의미:

```text
The server evidence referenced a class or actor.
```

의미 없음:

```text
A player opened it.
A player stole from it.
A player duplicated through it.
A player damaged it.
```

<a id="raid-cases"></a>
## 급습 사례

단속 사건은 시기와 공유 창에 따라 계정을 그룹화합니다.

규칙:

```text
Do not auto-ban every account in a raid case.
Each account needs account-specific evidence.
```
