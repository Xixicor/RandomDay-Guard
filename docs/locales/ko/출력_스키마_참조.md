# 출력 및 상태 스키마 참조

> **표준 영어 소스:** [OUTPUT_SCHEMA_REFERENCE.md](../../OUTPUT_SCHEMA_REFERENCE.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


이는 생성된 운영자용 파일에 대한 정식 계약입니다. 이는 단독으로 정확한 출력 경로, 필드 이름, 허용된 값, 계보 요구 사항 및 경로 스키마를 소유합니다. 절차 가이드는 이러한 사실을 재정의하는 대신 여기에 연결됩니다.

런타임 증거는 권위가 있습니다. 파일 이름, 스케줄러 하트비트, 번역된 보고서 또는 로컬 보낼 편지함 개체는 자체 필드 및 계보 이상의 것을 증명하지 않습니다.

<a id="public-report-routes"></a>
## 공개 보고서 경로

보고서 작업자는 `runtime/final_logs/`:

| 경로 | 계약 | `full` 아래에 5개의 경로를 소유합니다. 요구 사항 | 예상 비어 있음 의미 |
|---|---|---|---|
| `server_status` | 현재 스케줄러, 활성 로그, 스캔 보류 및 소스 적용 범위 상태. | 현재 boot/epoch/poll 계보, 새로운 활성 로그, accounting/history 쓰기 및 JSON/TXT 쌍. | 정상적인 현재 주기에는 사용되지 않습니다. 누락된 계보는 `missing`. |
| `daily_rollup` | 현재 day/window 서버, 플레이어, 케이스, 스캔 및 적용 범위 전반에 걸친 연속성입니다. | 경로에 충분한 과거 회계 터미널 및 현재 주기 증명이 완료되었습니다. | 유지된 플레이어가 없고 케이스 검토가 없습니다. |
| `player_activity` | 현재 및 과거 분리 player/account 관찰. | 현재 주기 증명과 하나 이상의 current/historical 행. | 제한된 입력에는 적합한 플레이어 행이 없습니다. 합성 주제가 없습니다. |
| `case_review` | 명명된 보유 사례 및 현재 review/BAN-ELIGIBLE 후보. | 현재 주기 증명과 소스 참조가 포함된 하나 이상의 명명된 사례. | 검토 기준을 충족하는 명명된 사례가 없습니다. 합성 사례 없음. |
| `critical_guard` | 현재 부팅 스케줄러, 시작, 폴링 또는 증거 무결성 실패. | 현재 주기 증명과 현재 심각한 오류. | 현재 심각한 오류 없음; 오래된 텍스트 오류는 이 경로를 소유하지 않습니다. |

활성화된 모든 경로는 `<route>_latest.json` 및 `<route>_latest.txt`를 씁니다. `runtime/final_logs/route_proof.json`동일한 버전, 부팅, 에포크, 폴링 및 소스 최신성을 기록할 때까지 쌍은 완료되지 않습니다.

<a id="report-json-schema"></a>
## 신고 JSON 스키마

전체 경로 JSON는 `schema="randomdayguard.report/v1"`.

| 필드 | 유형 | 의미 및 불변 |
|---|---|---|
| `schema` | 문자열 | 정확히 `randomdayguard.report/v1`. |
| `generated_ts`, `report_date` | 문자열 | 생성 타임스탬프 및 보고 날짜. |
| `version` | 문자열 | Runtime/package 이 주기의 ID. |
| `boot_id`, `epoch_id` | 문자열 | 현재 프로세스 부팅 및 서버 연속성 시대. 완료하려면 둘 다 필요합니다. |
| `poll_id` | 정수 | 현재 긍정적인 설문 조사 식별자입니다. Zero/missing 경로를 완료할 수 없습니다. |
| `source_freshness` | 객체 | `status`, `checked_ts`, 활성 로그 상태, 마지막 폴링 타임스탬프 및 마지막 완료된 폴링 타임스탬프. |
| `current_cycle_proof_complete` | 부울 | 계보와 새로운 active-log/current-poll 증거가 일치하는 경우에만 참입니다. |
| `route` | enum | 5개 경로 중 하나 위. |
| `route_proof_status` | enum | `full`, `limited_expected_empty` 또는 `missing`. |
| `coverage_status` | enum | 정확히 `complete`, `complete_with_gaps`, `partial` 또는 `unavailable`. |
| `completed`, `expected_empty` | 부울 | `completed`는 `missing`; `expected_empty`에 대해서만 거짓입니다. `limited_expected_empty`. |
| `observed` | 문자열 배열 | 구체적으로 유지됩니다. facts/counts/statuses. |
| `interpretation` | 문자열 배열 | 증거에 맞게 조정된 신중한 의미입니다. |
| `unknown` | 문자열 배열 | 신원이 누락되었습니다. 역사, 출처 또는 맥락. |
| `does_not_prove` | 문자열 배열 | 증거가 뒷받침할 수 없는 결론. |
| `next_action` | 문자열 | 가장 안전한 경계 연산자 작업. |
| `source_references` | 문자열 배열 | 고유한 runtime/Saved 참조를 정렬합니다. |
| `enforcement_authority` | 부울 | 항상 거짓입니다. 보고서는 쓰기를 승인하지 않습니다. |
| `output_paths` | 두 개의 문자열 | JSON 및 TXT 쌍으로 쓰기 전에 경로가 추가되었습니다. |

`coverage_status`는 최상위 수준 회계에만 해당됩니다. 소스 레코드는 별도로 소유합니다 `available`, `expected_empty`, `partial`, `deferred`, `unavailable`, `malformed`, `permission_denied` 및 `error`. 경로 증명은 `full`, `limited_expected_empty` 및 `missing`를 별도로 소유합니다. 값은 이 경계를 넘지 않습니다.

경로 확장:

- `server_status`: `scheduler_status`, `active_log_status` 및 `server_metrics`. 측정항목은 현재 에포크 시작, 최근 완료된 폴링 타임스탬프 및 ID, 활성 플레이어 수, active/backup-log 수, 스캔 pending/progress 값 및 configured/usable/unavailable 소스 그룹 계정을 기록합니다. 가동 시간, 재시작 횟수, 백업 타임스탬프, 가동 중단 기간 등의 사실을 공개하는 소스가 없을 때 이를 고안하지 않습니다.
- `player_activity`: `player_activity_present`, `movement`, `same_day_sessions`, `current_player_count`, `current_evidence_player_count`, `historical_player_count`, `historical_session_count`, `current_players`, `historical_players` 및 호환성 배열 `players`. 각 당일 세션은 세션 ID, 계정 ID, 표시 이름(알려진 경우), join/leave 타임스탬프, 정리 종료 및 수명 주기 플래그, 소스 참조. 신원은 유지되며 PlayerData 현재 활동에 대한 증거가 아니라 현재 상태가 컨텍스트로 유지됩니다.
- `case_review`: `cases`, `review_subjects`, `current_case_count` 및 `retained_case_count`. 현재 검토 대상은 해당 case/account ID, 알려진 경우 표시 이름, 상태, 점수, 신원 신뢰도, first/last 관찰, 경고 횟수, 이유, 현재 실시간 플래그 및 소스 참조를 기록합니다. 보관된 사례는 자체적으로 현재 주제를 생성하지 않습니다.
- `critical_guard`: `critical_failure_present` 및 `current_boot_error_only=true`.
- `daily_rollup`: `daily_maturity`, `once_per_day_continuity`, `dedupe_window` 및 `daily_metrics`. 측정항목은 보고 날짜, 활성 플레이어, 당일 활동이 있는 계정, 가입, 탈퇴, 정리 및 비정리 종료, 수명 주기 반환, 현재 명명된 검토 주제, 보관된 사례, current/retained ID 수 및 소스 그룹 적용 범위를 기록합니다.

<a id="translated-txt-schema"></a>
## 번역됨 TXT 스키마

쌍으로 구성된 텍스트 파일은 운영자가 읽을 수 있는 결과와 연결되며 계보 세부 정보를 끝. 정확한 섹션 순서가 유지됩니다.

```text
RandomDayGuard <route title>
Generated: <timestamp>

Summary
<one plain-language route summary>

What Guard observed
- ...

What it means
- ...

What remains unknown
- ...

Recommended next step
...

Evidence boundary
- ...

Rating explanation
- ...

Technical record
- Route: <route>
- Version: <version>
- Cycle: boot=<boot> epoch=<epoch> poll=<poll>
- Source freshness: <status>
- Route result: <full|limited_expected_empty|missing>
- Coverage: <status>

Translation notes
- ...

Source references
- ...
```

번역에서는 구조화된 보고서 필드와 승인된 사전 매핑만 사용합니다. 구조화된 보고서에 없는 플레이어, 사례, 전달, 원인, 소유권, 의도 또는 집행 자격을 추가할 수 없습니다. 읽을 수 있는 결과를 대체하지 않고도 기술적 세부 사항을 계속 사용할 수 있습니다.

<a id="source-accounting-schema"></a>
## 소스 회계 스키마

`runtime/final_logs/source_accounting_latest.json`는 `randomdayguard.source-accounting/v1` 생성 reason/status, enablement/disabled 이유, current/historical 구별, 변경된 파일 매니페스트, 소스 기록, usable/unavailable 클래스 목록 및 청구 한도.

각 소스 레코드에는 다음이 포함됩니다.

| 필드 | 유형 | 의미 |
|---|---|---|
| `source_class` | 문자열 | 아래 8개 클래스 중 하나. |
| `scope` | `current` 또는 `historical` | 시간 소유권, 범위는 자동으로 병합되지 않습니다. |
| `required` | 부울 | 현재 주기 경로를 새로 고치려면 `active_log`만 필요합니다. |
| `status` | enum | 아래에 나열된 소스 결과. |
| `terminal` | 부울 | False only for `partial` 및 `deferred`. |
| `available`, `readable` | 부울 | True only for `available` 및 `expected_empty`. |
| `file_count` | 정수 | Bounded accounted file/reference 개수. |
| `source_references` | 배열 | 정렬된 고유 소스 paths/references. |
| `detail` | 문자열 | 제한된 결과 또는 오류 세부정보. |
| `does_not_prove` | 문자열 | 가용성은 의도, 소유권, 손상, 복제 또는 시행 증거가 아닙니다. |

소스 클래스:

| 소스 클래스 | 범위 | 기여하는 것 | 증명할 수 없는 것 |
|---|---|---|---|
| `active_log` | 현재, 필수 | 읽을 수 있는 활성 서버 로그 및 새로운 폴링 계보. | 전체 기록 또는 플레이어 과실. |
| `admin_ini` | 현재, 선택 사항 | 구조적으로 유효한 현재 moderator/ban 상태 또는 예상되는 부재. | 플레이어 행동 또는 유효한 이유 메타데이터. |
| `recent_backup_logs` | 기록 | 읽기 가능 rotated/backup 로그 참조. | 현재 존재 또는 현재 부팅 상태. |
| `playerdata_filenames` | 현재 컨텍스트 | 선택한 저장된 루트 아래에 제한적으로 읽을 수 있는 파일 이름 참조. | 파일 소유권, 실제 존재, 신원 내용 또는 위법 행위. |
| `existing_cases` | 기록 | 보존된 명명된 사례 files/index 현재 출력 전에 캡처된 기록. | 현재 활동 또는 이전 결론의 정확성. |
| `existing_reports` | 기록 | 보유된 final/forensic/warning 보고서 참조. | 신뢰할 수 있는 소스 교체. |
| `existing_evidence` | 기록 | 보존된 증거 참조. | 서버가 노출하지 않은 이벤트의 완전성. |
| `world_save_scan` | 기록 | 제한된 전체, 부분, 연기 또는 사용할 수 없는 scan/checkpoint 상태. | 특정 플레이어의 작업 또는 소유권. |

소스 상태 값:

| 상태 | 터미널 | 연산자의 의미 및 작업 |
|---|---:|---|
| `available` | 예 | 읽을 수 있는 유용한 소스가 존재합니다. 참조 내용을 검토하세요. |
| `expected_empty` | 예 | 선택적 소스가 확인되었으며 합법적으로 사용되었습니다 absent/empty. 데이터를 만들어내지 마세요. |
| `partial` | 아니요 | 제한된 작업 또는 재고 제한이 불완전합니다. 재개를 허용합니다. |
| `deferred` | 아니요 | 작업이 의도적으로 보류 중입니다. 소유 작업자를 기다리세요. |
| `unavailable` | 예 | Source/path/tool가 없거나 사용할 수 없습니다. 경로에 필요한 경우에만 수리하세요. |
| `malformed` | 예 | 콘텐츠가 구조적 검증에 실패했습니다. 이를 보존하고 형식을 복구하세요. |
| `permission_denied` | 예 | 액세스가 명시적으로 거부되었습니다. 최소 권한 읽기 액세스를 복원합니다. |
| `error` | 예 | 소스 수준 제한 probe/read 예기치 않게 실패했습니다. 비밀을 노출하지 않고 `detail` 검사하세요. |

최상위 `coverage_status`는 정확히 `complete`, `complete_with_gaps`, `partial` 또는 `unavailable`입니다. 필수 소스 수준 `error`, `malformed` 또는 `permission_denied`는 최상위 수준으로 롤업됩니다 `unavailable`; 소스 수준 `deferred`는 최상위 수준으로 롤업됩니다 `partial`. 소스 계정을 비활성화해도 여전히 사용할 수 없는 상태가 기록되고 모든 경로가 `missing`.

<a id="historical-status-schema"></a>
## 기록 상태 스키마

`runtime/final_logs/historical_backfill_latest.json`는 `randomdayguard.history/v1`: `generated_ts`, 계정 `status`, `resumable=true`, `changed_file_refresh=true`, `current_evidence_is_not_history=true`, 소스 계정 배열, 사용할 수 없는 클래스 및 제한된 `next_action`.

`runtime/history/public_accounts.tsv`에 강제로 적용됩니다. 이 헤더가 있는 지속 가능한 공개 기록입니다.

```text
account_id	ban_id	display_name	identity_confidence	status	score	first_seen	last_seen	source_references
```

행은 계정 ID별로 정렬되고, 필드는 single-line/tab-safe, 참조는 sorted/unique입니다. 이 파일은 자동 재시작 시 기록 컨텍스트를 보존합니다. 기록을 현재 상태로 변환하지 않습니다.

<a id="route-proof-schema"></a>
## 경로 증명 스키마

`runtime/final_logs/route_proof.json`는 `randomdayguard.route-proof/v1` 그리고 최상위 생성 타임스탬프, 버전, 부팅, 에포크, 폴링, 소스 신선도, 현재 주기 완전성, 허용된 상태 및 `routes` 배열을 기록합니다.

각 경로 항목에는 route/status, version/boot/epoch/poll, source-freshness 개체, 현재 주기가 포함됩니다. 완전성, 출력 경로 및 소스 참조. 비활성화된 경로는 `status="missing"` 및 `reason="route_disabled"`를 기록합니다. 경로 증명 쓰기에 실패하면 알림 후보가 수락되기 전에 모든 경로가 incomplete/missing로 다시 작성됩니다.

<a id="notification-schemas"></a>
## 알림 스키마

선택적 공개 모드는 로컬 파일 발신함 전용입니다.

`runtime/notifications/pending/<route>_latest.json`는 `randomdayguard.notification/v1` 타임스탬프가 생성된 version/boot/epoch/ poll/source 신선도, 경로, `completed_output`, 경로 방지 상태, 구조화되고 번역된 보고서 경로, 소스 참조, `delivery_backend="none"` 및 `delivery_attempted=false`. 적합한 출력은 `status="ready_for_local_consumer"`, `delivery_eligible=true` 및 `delivery_allowed=true`을 사용합니다. 구성되었지만 missing/ineligible 경로는 여전히 `status="suppressed_current_cycle"`, 두 전달 플래그 모두 false 및 `suppression_reason="route_or_completion_policy_blocked"`를 사용하여 감사 봉투를 작성합니다. 따라서 `pending/` 아래에 파일이 존재한다고 해서 그 자체로 대기 중이거나 적격하다는 의미는 아닙니다.

`runtime/notifications/notification_status.json`는 `randomdayguard.notification-status/v1` 동일한 계보, `generic_local_outbox_only=true`, `delivery_attempted=false` 및 경로별 `queued`/`outcome` 행이 있습니다. `full` 자격이 있습니다. 예상 비어 있음은 `include_expected_empty=true`; `missing`가 적합하지 않은 경우에만 적합합니다. 경로 방지 쓰기 실패 시 상태 결과는 `route_proof_write_failed`입니다. 억제된 감사 봉투는 여전히 기록될 수 있지만 허용되는 출력은 아닙니다.

<a id="failure-and-recovery-matrix"></a>
## 실패 및 복구 매트릭스

| 실패 | 필수 상태 | 안전 복구 | 잘못된 추론 |
|---|---|---|---|
| 현재 계보 absent/stale | 모든 경로 `missing`. | active-log/current-poll 증명하고 재생성하세요. | 이전 경로 파일이 현재 완성되지 않았습니다. |
| 선택 소스가 비어 있을 것으로 예상됩니다. | 소스 `expected_empty`; 적격 경로는 `limited_expected_empty`. | 소스가 존재하지 않는 한 수리할 수 없습니다. | 비어 있음을 사용할 수 없으며 과거 부재를 증명하지 않습니다. |
| 스캔이 완료되지 않았습니다. | 소스 `partial` 또는 `deferred`. | 제한된 재개를 허용합니다. 현재 경로 정책을 명시적으로 유지합니다. | 부분은 손상되지 않습니다. |
| 필수 소스를 사용할 수 없습니다. | `coverage_status=unavailable`; 종속 경로 `missing`. | 선택한 Saved/log 액세스를 복구합니다. | 다른 정상 소스는 필수 소스를 대체하지 않습니다. |
| 필수 소스 프로브 오류 | 소스 상태 `error` 경계가 있는 `detail`; `coverage_status=unavailable`; 종속 경로 `missing`. | 명명된 source/probe를 복구하고 새로운 주기를 생성하세요. | 소스 오류는 다섯 번째 최상위 범위 값이 아닙니다. |
| 페어링된 보고서 쓰기 실패 | `coverage_status=unavailable`; 경로는 `missing`. | 파일 시스템을 복구하고 두 쌍 멤버와 증명을 모두 다시 작성합니다. | 한 형제 파일이 완료되지 않았고 쓰기 실패가 최상위 수준이 아닙니다. `error`. |
| 경로 증명 쓰기 실패 | 재작성된 모든 경로가 누락되었습니다. 적격한 보낼 편지함이 없습니다. 구성된 경로는 억제된 감사 봉투를 받을 수 있습니다. | 경로 증명 쓰기를 복구하고 동일한 주기 출력을 다시 생성합니다. | 유효해 보이는 보고서 JSON 또는 표시되지 않는 봉투는 경로 증명이 아닙니다. |
| 알림 쓰기 실패 | 결과 `local_outbox_write_failed`. | 수리 로컬 출력 루트; 완료된 보고서에서 다시 생성합니다. | 외부 전송이 발생하지 않았습니다. |
| Admin.ini 거래 실패 | backup/write/readback/rollback 증거를 검사합니다. | 확인된 백업 복원으로 시행이 차단되었습니다. 검토 전용으로 유지됩니다. | 임계값이나 보고서는 복구 우회를 정당화할 수 없습니다. |
