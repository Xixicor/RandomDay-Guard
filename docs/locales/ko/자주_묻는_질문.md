# FAQ

> **표준 영어 소스:** [FAQ.md](../../FAQ.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


<a id="is-randomdayguard-the-randomday-mod"></a>
## 입니다 RandomDayGuard RandomDay 모드?

아니요. RandomDay Mod는 서버 경험을 변경합니다. RandomDayGuard 서버 증거 레이어를 감시합니다.

<a id="does-live-defense-work-before-the-scan-completes"></a>
## 스캔이 완료되기 전에 실시간 방어가 작동합니까?

예. 실시간 방어는 로그와 세션 이벤트를 사용합니다. 기준 스캔은 나중에 상황을 개선합니다.

<a id="why-can-the-first-scan-take-a-long-time"></a>
## 첫 번째 스캔에 시간이 오래 걸릴 수 있는 이유는 무엇입니까?

첫 번째 스캔에서는 world/object 컨텍스트, 파일 매니페스트 및 재사용 가능한 기준 데이터가 구축됩니다.

<a id="what-do-i-check-first-after-startup"></a>
## 시작 후 먼저 무엇을 확인해야 합니까?

```text
runtime/current/poll_status.json
```

찾아보세요:

```text
scheduler_status=running
poll_id increasing
poll_in_flight=false
```

<a id="where-are-player-summaries"></a>
## 플레이어 위치 요약?

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

<a id="where-is-the-daily-quick-review-package"></a>
## 일일 빠른 검토 패키지는 어디에 있나요?

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

<a id="which-file-should-i-upload-for-fastest-review"></a>
## 가장 빠른 검토를 위해 어떤 파일을 업로드해야 하나요?

```text
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="can-it-write-bans-automatically"></a>
## 자동으로 차단을 작성할 수 있나요?

명시적으로 활성화된 경우에만.

기본값:

```lua
review_only_mode = true
auto_ban = false
write_admin_ini = false
```

<a id="what-does-adminini-receive"></a>
## 무엇을 업로드하나요? Admin.ini 수신하시겠습니까?

한정:

```ini
BannedPlayer=<ID>
```

이름, 설명, 이유 또는 접미사 없음.

<a id="is-a-display-name-enough-to-ban"></a>
## 표시 이름만으로도 금지할 수 있습니까?

아니요. 서버 로그 `Login request`를 씁니다. 또한 사용할 수 없는 회계로 과거 상태 레코드를 기록합니다. 소스 계정은 보고서 계약의 일부이므로 모든 경로는 `ConnectID` 또는 이에 상응하는 서버 증거를 사용하세요.

<a id="can-one-crash-ban-someone"></a>
## 한 번의 크래시로 누군가를 차단할 수 있나요?

기본적으로는 아니요.

<a id="can-object-count-alone-ban-someone"></a>
## 객체 개수만으로 누군가를 차단할 수 있나요?

기본적으로는 아니요.

<a id="should-savedroottxt-point-to-the-world-folder"></a>
## SavedRoot.txt세계를 가리켜야 합니다. 폴더?

아니요. `AbioticFactor/Saved`.

<a id="what-if-the-world-folder-changes"></a>
## 월드 폴더가 변경되면 어떻게 되나요?

이를 기본 ID 변경으로 간주하세요. 이전 기준을 유지하고 새 기준을 구축하세요.
