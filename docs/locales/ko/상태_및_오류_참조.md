# 상태 및 오류 참조

> **표준 영어 소스:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). 이 현지화된 문서는 정확한 명령, 경로, 키, 상태 값, 해시 및 파일 이름을 보존합니다. 기술적인 표현이 다를 경우 영어 소스를 사용하세요.


[문제 해결](%EB%AC%B8%EC%A0%9C_%ED%95%B4%EA%B2%B0.md)에서 증상을 분류한 후 이 참조를 사용하세요. 오류로 명명된 구조화된 상태 파일을 읽습니다. 고유한 코드는 고유한 안전 및 수명주기 상태를 나타냅니다. 일반적인 "Guard 실패" 결과로 축소하지 마십시오.

<a id="route-and-source-states"></a>
## 경로 및 소스 상태

| 값 | 의미 | 운영자 응답 |
|---|---|---|
| `full` | 현재 주기 소스 증명으로 경로 계약이 완료되었습니다. | 경로의 증거 경계를 읽습니다. 수리가 암시되지 않습니다. |
| `limited_expected_empty` | 경로가 완료되었으며 누락된 활동이 이 주기에 적합합니다. | 합성 player/case 이벤트를 생성해서는 안 됩니다. |
| `missing` | 필수 출력, 계보 필드 또는 소스 증명이 없습니다. | 경로 이유와 명명된 소스 상태를 검사하세요. |
| `available` |  명명된 소스를 읽고 사용할 수 있었습니다. | 아니요 작업. |
| `expected_empty` | 소스가 확인되었으며 합법적으로 행이 없습니다. | 활동이 독립적으로 예상되지 않는 한 아무런 조치도 취하지 않습니다. |
| `partial` / `complete_with_gaps` | 사용 가능한 증거가 있지만 명명된 소스 클래스가 불완전합니다. | 수집된 증거로 결론을 제한하십시오. |
| `deferred` | 제한된 작업은 이후 작업자에게 예약되어 있습니다. 기회. | 구성을 변경하기 전에 진행 상황을 확인하세요. |
| `unavailable` | 환경이 소스를 제공하지 않았습니다. | 한계를 기록하세요. 입증된 경로 또는 권한 문제만 수정하세요. |
| `malformed` | 소스를 읽을 수는 있지만 구조적 검증에 실패했습니다. | 소스를 보존하고 소스를 수정하세요. 추측하지 마세요. |
| `permission_denied` | 소스가 존재하지만 읽을 수 없습니다. | 필요한 제한된 읽기 권한만 부여하세요. |
| `error` | 기록된 이유로 수집에 실패했습니다. | 오류를 보존하고 해당 단계를 진단하세요. |

| `unsafe_playerdata_root` | PlayerData 검색은 외부에서 해결됩니다. 제한된 저장된 루트. | 경로를 수정하세요. 경계를 약화시키지 마세요. |
| `playerdata_discovery_not_run` | 제한된 검색 작업자가 아직 실행되지 않았습니다. | 스케줄러 및 작업자 진행 상황을 확인하세요. |
| `playerdata_discovery_read_failed:*` | 검색 출력을 읽을 수 없습니다. | 접미사 세부정보를 보존하고 제한된 인벤토리 명령을 확인하세요. |
| `inventory_command_open_failed` | 인벤토리 프로세스를 실행할 수 없습니다. 시작되었습니다. | 런타임이 구성된 명령 브리지를 제공하는지 확인하세요. |
| `inventory_command_read_failed` | 읽는 동안 인벤토리 출력이 실패했습니다. | 부분 출력을 보존하고 기본 오류가 수정된 후에만 다시 실행하세요. |
| `inventory_command_close_failed` | 신뢰할 수 있는 종료 결과 없이 인벤토리가 완료되었습니다. | 소스를 다음과 같이 처리하세요. 불완전합니다. |
| `identity_ledger_row_limit_exceeded` | 지속적인 신원 입력이 공공 안전 한계를 초과했습니다. | 원장을 보관하고 검토하세요. 전체 증거로 자동으로 자르지 마십시오. |

## Admin.ini 시행 코드

이 섹션의 모든 코드는 페일클로즈됩니다. 자체적으로는 수동 금지를 승인하지 않습니다.

| 코드 | 의미 | 안전한 응답 |
|---|---|---|
| `admin_ini_write_disabled` / `admin_ini_disabled` | 공개 안전 쓰기 게이트가 꺼져 있습니다. | 검토 전용 작업에서 예상됩니다. |
| `admin_ini_backup_disabled` / `backup_safety_gate_disabled` | 필수 백업 정책이 활성화되지 않습니다. | 쓰기를 비활성화합니다. |
| `enforcement_disabled` / `ban_on_threshold_disabled` / `auto_ban_disabled` | 한 개의 명시적인 시행 게이트는 꺼짐. | 공개 검토 전용 기본값으로 예상됩니다. 쓰기 실패로 재해석하지 마세요. |
| `review_only_mode_enabled` | 검토 전용 모드는 의도적으로 변형을 차단합니다. | 증거만 검토합니다. |
| `duplicate_prevention_disabled` | 중복 보호가 비활성화되었습니다. | 안전 게이트가 복원될 때까지 쓰기를 비활성화된 상태로 유지합니다. |
| `readback_safety_gate_disabled` / `rollback_safety_gate_disabled` | 쓰기 후 확인 또는 롤백 보호가 비활성화되었습니다. | 쓰기를 비활성화합니다. 이 게이트를 우회하지 마십시오. |
| `clean_id_safety_gate_disabled` / `account_specific_evidence_gate_disabled` | 신원 정리 또는 계정별 증거 시행이 비활성화되었습니다. | 강제 테스트 전에 게이트를 복원하십시오. |
| `moderator_preservation_disabled` / `existing_ban_preservation_disabled` | 보호된 계정 또는 기존 금지 보존이 비활성화되었습니다. | 쓰기를 비활성화합니다. |
| `clean_numeric_identity_required` | 제안된 ID는 허용되는 완전한 연결 양식 또는 깨끗한 숫자 ID가 아닙니다. | 확인된 매핑을 얻습니다. 임의의 접두사를 자르지 마십시오. |
| `identity_strength_below_minimum` | 신원 증거가 구성된 임계값보다 약합니다. | 증거만 검토합니다. |
| `playerdata_verification_required` | 구성에는 PlayerData 확인이 필요하며 계정에 해당 확인이 필요합니다. | 후보자를 검토 전용으로 유지하세요. 파일 이름에서 소유권을 추론하지 마세요. |
| `trusted_or_moderator_identity` | 계정은 신뢰할 수 있는 상태 또는 중재자 상태로 보호됩니다. | 쓰기가 허용되지 않습니다. |
| `admin_ini_path_invalid` / `admin_ini_path_outside_saved_root` | 대상 경로가 잘못되었거나 저장된 루트를 이스케이프합니다. | 올바른 구성입니다. 절대 경로 가드를 우회하지 마세요. |
| `admin_ini_unavailable` | 읽을 수 있는 구성이 없습니다. Admin.ini가 저장된 루트 내부에서 발견되었습니다. | 제한된 경로를 수정하거나 적용을 비활성화하세요. |
| `admin_ini_read_failed` | 신뢰할 수 있는 바이트를 읽을 수 없습니다. | 변이 전에 중지하세요. |
| `admin_ini_parse_failed` | Admin.ini 더 구체적인 구조 코드가 없으면 유효성 검사가 실패했습니다. | 파일을 보존하고 해당 섹션과 줄 구조를 검사하십시오. |
| `admin_ini_contains_nul` | 파일에 NUL 바이트가 포함되어 있으며 텍스트로 허용되지 않습니다. | 파일을 보존하고 Guard 외부에서 복구하십시오. |
| `admin_ini_duplicate_banned_players_section` | 두 개 이상의 `[BannedPlayers]` 섹션이 존재합니다. | 섹션을 수동으로 병합하세요 중지된 동안. |
| `admin_ini_banned_player_outside_section` | 금지 행이 외부에 나타납니다.`[BannedPlayers]`. | 레이아웃을 수동으로 수정하세요. |
| `admin_ini_invalid_banned_player_line` | 금지 라인은 정확하게 지원되는 ID 행이 아닙니다. | 잘못된 라인을 수정하세요. |
| `admin_ini_backup_failed` | 고유 백업이 바이트 동일하게 쓰고 읽지 않았습니다. | 변경은 허용되지 않습니다. |
| `admin_ini_external_change_detected` | 다른 작성자가 Guard의 스냅샷 이후에 파일을 변경했습니다. | 외부 바이트를 보존하고 작성자를 조정한 후에만 다시 시도하십시오. |
| `atomic_rename_unavailable` | 원자 교체가 요청되었지만 Lua는 제공하지 않았습니다. `os.rename`. | 쓰기를 신뢰할 수 없습니다. 지원되는 런타임을 사용하거나 시행을 비활성화 상태로 유지하세요. |

| `post_write_verification_failed` | 생산 바이트가 후보와 동일하지 않습니다. | 어떤 조치를 취하기 전에 `rollback_success` 및 `rollback_refused_external_change`를 확인하세요. |

<a id="startup-scheduler-and-backlog-states"></a>
## 시작, 스케줄러 및 백로그 상태

이러한 값은 경로 증명이 아닌 수명 주기 증거입니다. 현재 설문조사, 보고서 작업자 및 경로 증명 파일을 사용하여 읽어보세요.

| 값 | 의미 | 안전한 응답 |
|---|---|---|
| `not_started` | 지정된 시작 또는 스케줄러 단계가 시작되지 않았습니다. | 실행 중에는 문서화된 간격을 기다립니다. 그 후에 변경되지 않은 첫 번째 단계를 검사하세요. |
| `main_lua_loaded` / `starting` | 표준 로더가 실행되고 Guard가 시작에 들어갔습니다. | 나중 단계를 계속하세요. 이것만으로는 준비가 되지 않았습니다. |
| `saved_root_found` / `log_tail_initialized` / `epoch_started` | 핵심 소스 및 연속성 초기화가 진행되었습니다. | 다음 단계의 진행이 중단되지 않는 한 아무런 조치도 취하지 않습니다. |
| `admin_state_written` / `playerdata_index_written` | 초기 경계 인덱스를 내보냈습니다. | 조치가 없습니다. 스케줄러 핸드오프는 여전히 따라야 합니다. |
| `watchdog_started` | 보고 및 폴링 감시가 등록되었습니다. | 다음으로 스케줄러 및 폴링 진행을 확인하세요. |
| `ready_degraded` / `scan_running` | 제한된 기록 스캔이 보류 중인 동안 가드가 실행 중입니다. | 실패가 아니라 주의하세요. 진행률 카운터가 진행되는지 확인하세요. |
| `ready` | 시작 및 현재 제한된 스캔이 준비 상태에 도달했습니다. | 경로 증명을 별도로 확인하세요. |
| `scan_failed` / `error` | 기록된 오류로 인해 시작 또는 스캔이 종료되었습니다. | 명명된 오류 또는 상태 파일을 보존하고 해당 단계를 진단하세요. |
| `running` | 스케줄러 향후 설문조사 기회를 소유하고 있습니다. | 확인 `poll_id` 및 `poll_completed_count` 진행하세요. |
| `manual_only` | 루프 예약을 사용할 수 없습니다. 명시적인 작업만 실행할 수 있습니다. | 무인 작업을 사용할 수 없는 것으로 처리합니다. |
| `stopped` | 스케줄러 작업이 종료되었습니다. | 다시 시작하기 전에 이전 중지 및 오류 증거를 검사합니다. |
| `active_log_caught_up` | 읽지 않은 활성 로그 백로그가 남지 않습니다. | 기록 검색이 진행하세요. |
| `active_log_unavailable_nonblocking` | 활성 로그는 없지만 시작은 비차단 상태로 유지됩니다. | 소스 제한을 기록하고 다른 소스를 확인하세요. |
| `active_log_read_failed` | 활성 로그가 존재했지만 읽을 수 없었습니다. | 오류를 보존하고 입증된 경로나 권한 문제만 수정하세요. |
| `budget_exhausted` / `active_log_has_unread_bytes` | 백로그가 남아서 제한된 테일 패스가 중지되었습니다. | 나중에 폴링을 확인하면 읽지 않은 로그가 줄어듭니다. 개수. |
| `offset_commit_failed_after_events_applied` | 이벤트가 처리되었지만 내구성 있는 로그 오프셋 지속성에 실패했습니다. | 시행이 연기되었습니다. 다른 주기에 의존하기 전에 오프셋 저장소를 복구하십시오. |

<a id="scheduler-report-and-notification-codes"></a>
## 스케줄러, 보고서 및 알림 코드

| 코드 또는 상태 | 의미 | 안전한 응답 |

| `no_log_files_found` | 구성된 활성 또는 백업 로그가 발견되지 않았습니다. | 저장된 루트 및 소스 구성을 확인하십시오. |
| `current_poll_error` | 현재 주기에서 폴링 소스 실패를 기록했습니다. | 읽기 `runtime/current/poll_error.json`. |
| `cadence_deferred` | 완료 디스패처가 아직 만료되지 않았습니다. | 다음 제한된 기회까지 예상됩니다. |
| `reports_disabled` | 공개 보고서 생성이 비활성화됩니다. | 보고서가 의도된 경우에만 활성화하십시오. |
| `local_outbox_write_failed` | 번역된 로컬 봉투를 쓸 수 없습니다. | 런타임 출력 디렉터리를 복구하세요. 이는 알림 전송 오류가 아닙니다. |

| `poll_owner_between_polls` | 폴링 사이의 스케줄러 소유 간격 때문에 보고서 작업자가 대기열에 있습니다. | 타임스탬프와 커서가 계속 진행되는 동안에만 예상됩니다. |
| `unsafe_shell_path` | 제한된 인벤토리 또는 셸 경로가 플랫폼 안전 검증에 실패했습니다. | 수정하세요. 경로; 인용 또는 경로 검증을 약화시키지 마십시오. |
