# কনফিগারেশন প্রোফাইল

> **ক্যাননিকাল ইংরেজি উৎস:** [CONFIG_PROFILES.md](../../CONFIG_PROFILES.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন।


একটি ব্যবহারিক কনফিগারেশন প্রোফাইল চয়ন এবং প্রয়োগ করতে এই কীভাবে-প্রদর্শনটি ব্যবহার করুন৷ সেটিং গোষ্ঠীগুলি কীভাবে ইন্টারঅ্যাক্ট করে তার ব্যাখ্যার জন্য, পড়ুন [`CONFIG_REFERENCE.md`](%E0%A6%95%E0%A6%A8%E0%A6%AB%E0%A6%BF%E0%A6%97_%E0%A6%B0%E0%A7%87%E0%A6%AB%E0%A6%BE%E0%A6%B0%E0%A7%87%E0%A6%A8%E0%A7%8D%E0%A6%B8.md)। সঠিক ক্ষেত্র, ডিফল্ট, প্রকার এবং পরিবর্তনের জন্য, তৈরি করা ব্যবহার করুন [`CONFIG_FIELD_CATALOG.md`](%E0%A6%95%E0%A6%A8%E0%A6%AB%E0%A6%BF%E0%A6%97_%E0%A6%AB%E0%A6%BF%E0%A6%B2%E0%A7%8D%E0%A6%A1_%E0%A6%95%E0%A7%8D%E0%A6%AF%E0%A6%BE%E0%A6%9F%E0%A6%BE%E0%A6%B2%E0%A6%97.md).

নিচের প্রতিটি লুয়া ব্লক শীর্ষ-স্তরের এন্ট্রিগুলির একটি সেট যা শিপডের ভিতরে মিলে যাওয়া এন্ট্রিগুলিকে প্রতিস্থাপন করতে পারে `return { ... }` টেবিল।

<a id="profile-chooser"></a>
## প্রোফাইল চয়নকারী

| পরিস্থিতি | এই প্রোফাইলটি ব্যবহার করুন |
|---|---|
| প্রথম ইনস্টল | নিরাপদ প্রথম ইনস্টল |
| সার্ভার অস্থির এবং প্রায়ই ক্র্যাশ হয় | ধীর স্ক্যান ছাড়াই বর্তমান প্রমাণ |
| আপনি চান object/world প্রসঙ্গ | সম্পূর্ণ বেসলাইন |
| আপনি পুরানো লগগুলি পর্যালোচনা করতে চান | ফরেন্সিক ব্যাকফিল |
| আপনি সুপারিশ চান কিন্তু কোন লেখা নেই | এনফোর্সমেন্ট টেস্টিং |
| আপনি গার্ডকে নিষেধাজ্ঞা লিখতে দিতে প্রস্তুত | এনফোর্সমেন্ট সক্ষম |
| ডিস্ক সীমিত | নিম্ন ডিস্ক বৃদ্ধি |
| আপনি একটি পরিষ্কার বেসলাইন সম্পূর্ণ করেছেন | স্টিকি ব্যাকআপ সেটআপ |

<a id="safe-first-install"></a>
## নিরাপদ প্রথম ইনস্টল

এটি প্রথমে একটি লাইভ সার্ভারে ব্যবহার করুন৷

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

log_tail = {
    enabled = true,
    start_at_end_on_first_run = true,
    tail_backup_logs = false,
},

scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

এটি কী করে:

```text
Tracks live sessions.
Starts the baseline scan.
Does not edit Admin.ini.
Avoids treating old backup logs as fresh live events.
```

<a id="current-evidence-without-slow-scan"></a>
## ধীর স্ক্যান ছাড়াই বর্তমান প্রমাণ

সার্ভারটি অস্থির হলে এটি ব্যবহার করুন এবং আপনার প্রয়োজন crash/reconnect একটি ভারী স্ক্যান করার আগে প্রমাণ।

```lua
log_tail = {
    enabled = true,
},

scanning = {
    full_scan_on_start = false,
},

enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

এটি কী করে:

```text
Tracks logins, joins, leaves, reconnects, crashes, and unclean sessions.
Delays heavy world scanning.
```

<a id="full-baseline"></a>
## সম্পূর্ণ বেসলাইন

সার্ভারটি স্ক্যান করার জন্য যথেষ্ট সময় ধরে থাকার পরে এটি ব্যবহার করুন৷

```lua
scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},
```

এটি কী করে:

```text
Builds object registry.
Writes world-state context.
Creates file manifest.
Enables changed-file refresh later.
```

<a id="forensic-backfill"></a>
## ফরেন্সিক ব্যাকফিল

ইচ্ছাকৃতভাবে ঐতিহাসিক লগ পর্যালোচনা করার সময় এটি ব্যবহার করুন৷

```lua
log_tail = {
    start_at_end_on_first_run = false,
    tail_backup_logs = true,
    backfill_backup_logs_on_start = true,
},
```

এটি ব্যবহার করার আগে:

```text
Back up runtime/log_offsets.tsv.
Expect old events to be reprocessed.
Return to live settings when finished.
```

<a id="enforcement-testing"></a>
## এনফোর্সমেন্ট টেস্টিং

আসলের আগে এটি ব্যবহার করুন Admin.ini লেখা।

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},
```

কি পরিদর্শন করবেন:

```text
runtime/account_evidence.json
runtime/warnings/
runtime/forensic_days/YYYY-MM-DD/ban_recommendations.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="enforcement-enabled"></a>
## এনফোর্সমেন্ট সক্ষম

রিভিউ আউটপুট সঠিক হওয়ার পরেই এটি ব্যবহার করুন৷

```lua
enforcement = {
    review_only_mode = false,
    auto_ban = true,
    write_admin_ini = true,
    require_clean_ban_id = true,
    preserve_existing_bans = true,
    preserve_moderators = true,
},
```

সক্রিয় করার আগে:

```text
Trusted IDs are configured.
Moderator IDs are preserved.
Admin.ini backups work.
Ban recommendations are understandable.
Thresholds are accepted by the server owner.
```

<a id="low-disk-growth"></a>
## নিম্ন ডিস্ক বৃদ্ধি

রানটাইম ফাইলগুলি খুব দ্রুত বৃদ্ধি পেলে এটি ব্যবহার করুন৷

```lua
logging = {
    low_importance_mode = "aggregate",
    write_low_importance_raw_events = false,
},

retention = {
    detailed_retention_days = 7,
    rotate_jsonl_when_bytes_exceed = 5242880,
    max_raw_events_lines = 20000,
    compact_json_outputs = true,
},
```

<a id="sticky-backup-setup"></a>
## স্টিকি ব্যাকআপ সেটআপ

প্রথম সম্পূর্ণ বেসলাইনের পরে ব্যবহার করুন৷

এগুলি বিদ্যমান কিনা তা পরীক্ষা করুন:

```text
runtime/scan_complete.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
runtime/world_state/current/world_state_latest.json
```

তারপর তাদের সাথে ব্যাক আপ নিন `config.lua`, `SavedRoot.txt` এবং `Admin.ini`.
