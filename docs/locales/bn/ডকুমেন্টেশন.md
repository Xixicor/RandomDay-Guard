# RandomDayGuard ডকুমেন্টেশন

> **ক্যাননিকাল ইংরেজি উৎস:** [README.md](../../README.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন।


RandomDayGuard একটি অ্যাবায়োটিক ফ্যাক্টর ডেডিকেটেড সার্ভার থেকে রেকর্ড পড়ে এবং সার্ভারের স্বাস্থ্য, দৈনিক ইতিহাস, প্লেয়ার সেশন, রিভিউ কেস এবং গার্ড ব্যর্থতার জন্য আলাদা রিপোর্টে পরিণত করে৷
