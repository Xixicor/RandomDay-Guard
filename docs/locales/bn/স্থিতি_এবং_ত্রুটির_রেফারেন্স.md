# স্থিতি এবং ত্রুটির রেফারেন্স

> **ক্যাননিকাল ইংরেজি উৎস:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন।


একটি লক্ষণ শ্রেণীবদ্ধ করার পরে এই রেফারেন্সটি ব্যবহার করুন [সমস্যা নিবারণ](%E0%A6%B8%E0%A6%AE%E0%A6%B8%E0%A7%8D%E0%A6%AF%E0%A6%BE_%E0%A6%A8%E0%A6%BF%E0%A6%AC%E0%A6%BE%E0%A6%B0%E0%A6%A3.md)। ত্রুটি দ্বারা নামকৃত কাঠামোগত অবস্থা ফাইল পড়ুন. স্বতন্ত্র কোডগুলি স্বতন্ত্র নিরাপত্তা এবং জীবনচক্র অবস্থার প্রতিনিধিত্ব করে; এগুলিকে একটি সাধারণ "গার্ড ব্যর্থ" ফলাফলে ভেঙ্গে ফেলবেন না৷

<a id="route-and-source-states"></a>
## রুট এবং উৎসের অবস্থা

| মান | অর্থ | অপারেটরের প্রতিক্রিয়া |
|---|---|---|
| `full` | কারেন্ট-সাইকেল সোর্স প্রুফ সহ রুট চুক্তি সম্পন্ন হয়েছে৷ | রুটের প্রমাণ সীমানা পড়ুন; কোনো মেরামত উহ্য নয়৷ |
| `limited_expected_empty` | রুটটি সম্পূর্ণ হয়েছে এবং অনুপস্থিত কার্যকলাপ এই চক্রের জন্য বৈধ৷ | কোন সিন্থেটিক নেই player/case ইভেন্ট তৈরি করা উচিত৷ |
| `missing` | একটি প্রয়োজনীয় আউটপুট, বংশ ক্ষেত্র বা উৎস প্রমাণ অনুপস্থিত৷ | রুটের কারণ এবং নামযুক্ত উৎসের স্থিতি পরিদর্শন করুন৷ |
| `available` | নামকৃত উৎসটি পাঠযোগ্য এবং ব্যবহারযোগ্য ছিল। | কোন কাজ নেই। |
| `expected_empty` | উৎসটি পরীক্ষা করা হয়েছে এবং বৈধভাবে কোনো সারি নেই। | স্বাধীনভাবে প্রত্যাশিত কার্যকলাপ না হলে কোনো কাজ নেই৷ |
| `partial` / `complete_with_gaps` | ব্যবহারযোগ্য প্রমাণ বিদ্যমান, কিন্তু নাম দেওয়া উৎস ক্লাসগুলি অসম্পূর্ণ৷ | সংগৃহীত প্রমাণের মধ্যে সীমিত সিদ্ধান্ত। |
| `deferred` | বাউন্ডেড কাজ পরবর্তী কর্মীদের সুযোগের জন্য নির্ধারিত হয়েছে৷ | কনফিগারেশন পরিবর্তন করার আগে অগ্রগতি নিশ্চিত করুন। |
| `unavailable` | পরিবেশ উৎস প্রদান করেনি। | সীমা রেকর্ড করুন; শুধুমাত্র একটি প্রমাণিত পথ বা অনুমতি সমস্যা সংশোধন করুন। |
| `malformed` | উৎসটি পাঠযোগ্য ছিল কিন্তু কাঠামোগত বৈধতা ব্যর্থ হয়েছে৷ | এটি সংরক্ষণ করুন এবং উৎস ঠিক করুন; অনুমান করবেন না। |
| `permission_denied` | উৎসটি বিদ্যমান কিন্তু পড়া যাবে না। | শুধুমাত্র সংকীর্ণ প্রয়োজনীয় পড়ার অনুমতি দিন৷ |
| `error` | লিপিবদ্ধ কারণে সংগ্রহ ব্যর্থ হয়েছে৷ | ত্রুটিটি সংরক্ষণ করুন এবং সেই পর্যায়টি নির্ণয় করুন৷ |

<a id="playerdata-and-inventory-codes"></a>
## PlayerData এবং ইনভেন্টরি কোড

| কোড | অর্থ | নিরাপদ প্রতিক্রিয়া |
|---|---|---|
| `saved_root_unavailable` | পাবলিক পাইপলাইনে কোনো যাচাইকৃত সংরক্ষিত রুট উপলব্ধ ছিল না। | সঠিক `SavedRoot.txt` এবং পাথ প্রোব পুনরায় পরীক্ষা করুন। |
| `unsafe_playerdata_root` | PlayerData আবদ্ধ সংরক্ষিত রুটের বাইরে আবিষ্কারের সমাধান হয়েছে। | পাথ ঠিক করুন; কখনই সীমারেখা দুর্বল করবেন না। |
| `playerdata_discovery_not_run` | বাউন্ডেড ডিসকভারি ওয়ার্কার এখনও দৌড়েনি৷ | শিডিউলার এবং কর্মীদের অগ্রগতি পরীক্ষা করুন৷ |
| `playerdata_discovery_read_failed:*` | ডিসকভারি আউটপুট পড়া যাবে না। | প্রত্যয় বিবরণ সংরক্ষণ করুন এবং আবদ্ধ ইনভেন্টরি কমান্ড যাচাই করুন৷ |
| `inventory_command_open_failed` | ইনভেন্টরি প্রক্রিয়া শুরু করা যায়নি৷ | রানটাইম কনফিগার করা কমান্ড ব্রিজ প্রদান করে তা যাচাই করুন। |
| `inventory_command_read_failed` | ইনভেন্টরি আউটপুট পড়ার সময় ব্যর্থ হয়েছে৷ | আংশিক আউটপুট সংরক্ষণ করুন এবং অন্তর্নিহিত ত্রুটি ঠিক হওয়ার পরেই পুনরায় চালান৷ |
| `inventory_command_close_failed` | বিশ্বস্ত ফলাফল ছাড়াই ইনভেন্টরি সম্পূর্ণ হয়েছে৷ | উৎসটিকে অসম্পূর্ণ হিসাবে বিবেচনা করুন৷ |
| `identity_ledger_row_limit_exceeded` | টেকসই পরিচয় ইনপুট তার জননিরাপত্তা সীমা অতিক্রম করেছে৷ | খাতা সংরক্ষণাগার এবং পর্যালোচনা; নীরবে এটিকে পূর্ণ প্রমাণে ছেঁটে ফেলবেন না। |

<a id="adminini-enforcement-codes"></a>
## Admin.ini এনফোর্সমেন্ট কোড

এই বিভাগের সমস্ত কোড ব্যর্থ-বন্ধ। তারা নিজেরাই ম্যানুয়াল নিষেধাজ্ঞা অনুমোদন করে না।

| কোড | অর্থ | নিরাপদ প্রতিক্রিয়া |
|---|---|---|
| `admin_ini_write_disabled` / `admin_ini_disabled` | পাবলিক-সেফ রাইটের গেট বন্ধ। | শুধুমাত্র পর্যালোচনায় প্রত্যাশিত৷ |
| `admin_ini_backup_disabled` / `backup_safety_gate_disabled` | প্রয়োজনীয় ব্যাকআপ নীতি সক্রিয় নয়৷ | লেখা অক্ষম রাখুন। |
| `enforcement_disabled` / `ban_on_threshold_disabled` / `auto_ban_disabled` | একটি স্পষ্ট এনফোর্সমেন্ট গেট বন্ধ। | পাবলিক রিভিউ-কেবল ডিফল্টে প্রত্যাশিত; এটিকে লেখার ব্যর্থতা হিসাবে পুনরায় ব্যাখ্যা করবেন না। |
| `review_only_mode_enabled` | শুধুমাত্র পর্যালোচনা মোড ইচ্ছাকৃতভাবে মিউটেশন ব্লক করে। | শুধুমাত্র প্রমাণ পর্যালোচনা করুন৷ |
| `duplicate_prevention_disabled` | ডুপ্লিকেট সুরক্ষা নিষ্ক্রিয় করা হয়েছে৷ | সেফটি গেট পুনরুদ্ধার না হওয়া পর্যন্ত লেখাগুলি অক্ষম রাখুন৷ |
| `readback_safety_gate_disabled` / `rollback_safety_gate_disabled` | লেখার পরে যাচাইকরণ বা রোলব্যাক সুরক্ষা অক্ষম করা হয়েছে৷ | লেখা অক্ষম রাখুন; কখনই এই গেটগুলিকে বাইপাস করবেন না৷ |
| `clean_id_safety_gate_disabled` / `account_specific_evidence_gate_disabled` | পরিষ্কার পরিচয় বা অ্যাকাউন্ট-নির্দিষ্ট প্রমাণ প্রয়োগ অক্ষম করা হয়েছে৷ | কোনও প্রয়োগ পরীক্ষার আগে গেটটি পুনরুদ্ধার করুন৷ |
| `moderator_preservation_disabled` / `existing_ban_preservation_disabled` | সুরক্ষিত-অ্যাকাউন্ট বা বিদ্যমান-নিষিদ্ধ সংরক্ষণ অক্ষম করা হয়েছে৷ | লেখা অক্ষম রাখুন। |
| `clean_numeric_identity_required` | প্রস্তাবিত ID সম্পূর্ণ গৃহীত সংযোগ ফর্ম বা পরিষ্কার সংখ্যাসূচক ID নয়৷ | একটি যাচাইকৃত ম্যাপিং পান; একটি নির্বিচারে উপসর্গ ছেঁটে না. |
| `identity_strength_below_minimum` | পরিচয় প্রমাণ কনফিগার করা থ্রেশহোল্ডের চেয়ে দুর্বল৷ | শুধুমাত্র প্রমাণ পর্যালোচনা করুন৷ |
| `playerdata_verification_required` | কনফিগারেশন প্রয়োজন PlayerData নিশ্চিতকরণ এবং অ্যাকাউন্টে এটি নেই। | প্রার্থীকে শুধুমাত্র-রিভিউ রাখুন; একটি ফাইলের নাম থেকে মালিকানা অনুমান করবেন না৷ |
| `trusted_or_moderator_identity` | অ্যাকাউন্টটি বিশ্বস্ত বা মডারেটর স্টেট দ্বারা সুরক্ষিত৷ | কোন লেখার অনুমতি নেই৷ |
| `admin_ini_path_invalid` / `admin_ini_path_outside_saved_root` | লক্ষ্য পথটি অবৈধ বা সংরক্ষিত রুট থেকে বেরিয়ে গেছে। | সঠিক কনফিগারেশন; পাথ গার্ডকে কখনই বাইপাস করবেন না। |
| `admin_ini_unavailable` | পঠনযোগ্য কনফিগার করা নেই Admin.ini সংরক্ষিত রুটের ভিতরে পাওয়া গেছে। | বাউন্ডেড পাথ ঠিক করুন বা এনফোর্সমেন্ট অক্ষম রাখুন। |
| `admin_ini_read_failed` | অনুমোদিত বাইট পড়া যাবে না। | মিউটেশনের আগে থামুন। |
| `admin_ini_parse_failed` | Admin.ini আরও নির্দিষ্ট কাঠামোগত কোড ছাড়াই বৈধতা ব্যর্থ হয়েছে৷ | ফাইল সংরক্ষণ করুন এবং এর বিভাগ এবং লাইন গঠন পরিদর্শন করুন৷ |
| `admin_ini_contains_nul` | ফাইলটিতে রয়েছে NUL বাইট এবং পাঠ্য হিসাবে গ্রহণ করা হয় না। | ফাইল সংরক্ষণ করুন এবং গার্ডের বাইরে মেরামত করুন৷ |
| `admin_ini_duplicate_banned_players_section` | একের বেশি `[BannedPlayers]` বিভাগ বিদ্যমান৷ | বন্ধ করার সময় ম্যানুয়ালি বিভাগগুলি মার্জ করুন৷ |
| `admin_ini_banned_player_outside_section` | একটি নিষেধাজ্ঞার সারি বাইরে উপস্থিত হয় `[BannedPlayers]`. | লেআউটটি ম্যানুয়ালি সংশোধন করুন৷ |
| `admin_ini_invalid_banned_player_line` | একটি নিষেধাজ্ঞা লাইন ঠিক একটি পরিষ্কার সমর্থিত আইডি সারি নয়৷ | বিকৃত লাইন সংশোধন করুন। |
| `admin_ini_backup_failed` | অনন্য ব্যাকআপটি বাইট-সদৃশভাবে লেখা বা পড়া হয়নি৷ | কোন মিউটেশন অনুমোদিত নয়৷ |
| `admin_ini_external_change_detected` | অন্য একজন লেখক গার্ডের স্ন্যাপশটের পরে ফাইলটি পরিবর্তন করেছেন৷ | বাহ্যিক বাইটগুলি সংরক্ষণ করুন এবং লেখকদের সমন্বয় করার পরেই পুনরায় চেষ্টা করুন৷ |
| `atomic_rename_unavailable` | পারমাণবিক প্রতিস্থাপনের অনুরোধ করা হয়েছিল কিন্তু লুয়া প্রদান করেনি `os.rename`. | কোন লেখাই বিশ্বস্ত নয়; একটি সমর্থিত রানটাইম ব্যবহার করুন বা এনফোর্সমেন্ট অক্ষম রাখুন৷ |
| `admin_ini_write_failed` | নিয়ন্ত্রিত প্রতিস্থাপন সম্পূর্ণ হয়নি৷ | রেকর্ড করা প্রতিস্থাপন ত্রুটি এবং ব্যাকআপ পরিদর্শন করুন৷ |
| `post_write_verification_failed` | উৎপাদন বাইট প্রার্থীর সমান ছিল না। | চেক করুন `rollback_success` এবং `rollback_refused_external_change` কোনো কাজ করার আগে। |

## স্টার্টআপ, সময়সূচী, এবং ব্যাকলগ অবস্থা

এই মানগুলি জীবনচক্রের প্রমাণ, রুট প্রমাণ নয়৷ বর্তমান পোল, রিপোর্ট-কর্মী, এবং রুট-প্রুফ ফাইলগুলির সাথে সেগুলি পড়ুন৷

| মান | অর্থ | নিরাপদ প্রতিক্রিয়া |
|---|---|---|
| `not_started` | নামিত স্টার্টআপ বা সময়সূচী পর্যায় শুরু হয়নি৷ | লঞ্চের সময়, নথিভুক্ত ব্যবধানের জন্য অপেক্ষা করুন; পরে প্রথম অপরিবর্তিত পর্যায় পরিদর্শন করুন৷ |
| `main_lua_loaded` / `starting` | কনোনিকাল লোডার দৌড়ে গিয়ে গার্ড স্টার্টআপে প্রবেশ করেছে। | পরবর্তী ধাপে চালিয়ে যান; এটি একা প্রস্তুতি নয়৷ |
| `saved_root_found` / `log_tail_initialized` / `epoch_started` | কোর সোর্স এবং কন্টিনিউটি ইনিশিয়ালাইজেশন উন্নত। | পরবর্তী পর্যায়টি অগ্রসর হওয়া বন্ধ না করলে কোনো কাজ নেই। |
| `admin_state_written` / `playerdata_index_written` | প্রাথমিক আবদ্ধ সূচীগুলি রপ্তানি করা হয়েছিল৷ | কোন কাজ নেই; শিডিউলার হ্যান্ডঅফ এখনও অনুসরণ করতে হবে। |
| `watchdog_started` | রিপোর্ট এবং পোল ওয়াচডগ নিবন্ধিত হয়েছে৷ | নিশ্চিত করুন সময়সূচী এবং পরবর্তী ভোটের অগ্রগতি৷ |
| `ready_degraded` / `scan_running` | বাউন্ডেড ঐতিহাসিক স্ক্যান মুলতুবি থাকা অবস্থায় গার্ড চলছে। | সতর্কতা, ব্যর্থতা নয়; অগ্রগতি কাউন্টার অগ্রিম যাচাই করুন। |
| `ready` | স্টার্টআপ এবং বর্তমান আবদ্ধ স্ক্যান প্রস্তুত অবস্থায় পৌঁছেছে৷ | আলাদাভাবে রুট প্রুফ চেক করুন। |
| `scan_failed` / `error` | একটি রেকর্ড করা ত্রুটির সাথে স্টার্টআপ বা স্ক্যান বন্ধ করা হয়েছে৷ | নামিত ত্রুটি বা স্থিতি ফাইল সংরক্ষণ করুন এবং সেই পর্যায়টি নির্ণয় করুন৷ |
| `running` | শিডিউলকারী ভবিষ্যতের ভোটের সুযোগের মালিক৷ | নিশ্চিত করুন `poll_id` এবং `poll_completed_count` অগ্রিম। |
| `manual_only` | লুপ সময়সূচী অনুপলব্ধ ছিল; শুধুমাত্র স্পষ্ট কাজ চলতে পারে। | অন্যাটেন্ডেড অপারেশনকে অনুপলব্ধ হিসাবে বিবেচনা করুন৷ |
| `stopped` | শিডিউলার অপারেশন শেষ হয়েছে৷ | পুনরায় শুরু করার আগে পূর্ববর্তী স্টপ এবং ত্রুটি প্রমাণ পরিদর্শন করুন৷ |
| `active_log_caught_up` | কোন অপঠিত সক্রিয়-লগ ব্যাকলগ অবশিষ্ট নেই৷ | ঐতিহাসিক স্ক্যান করা যেতে পারে৷ |
| `active_log_unavailable_nonblocking` | সক্রিয় লগটি অনুপস্থিত ছিল, কিন্তু স্টার্টআপটি অবরুদ্ধ নয়। | উৎস সীমা রেকর্ড করুন এবং অন্যান্য উত্স যাচাই করুন৷ |
| `active_log_read_failed` | সক্রিয় লগ বিদ্যমান ছিল কিন্তু পড়া যাবে না৷ | ত্রুটি সংরক্ষণ করুন এবং শুধুমাত্র প্রমাণিত পাথ বা অনুমতি সমস্যা সংশোধন করুন। |
| `budget_exhausted` / `active_log_has_unread_bytes` | বাউন্ডেড টেইল পাসটি ব্যাকলগ বাকি থাকা অবস্থায় বন্ধ হয়ে গেছে। | নিশ্চিত করুন পরবর্তী পোল অপঠিত গণনা হ্রাস করে৷ |
| `offset_commit_failed_after_events_applied` | ইভেন্টগুলি প্রক্রিয়া করা হয়েছিল কিন্তু টেকসই লগ অফসেট স্থিরতা ব্যর্থ হয়েছে৷ | এনফোর্সমেন্ট পিছিয়ে গেছে; অন্য চক্রের উপর নির্ভর করার আগে অফসেট স্টোরেজ মেরামত করুন। |

<a id="scheduler-report-and-notification-codes"></a>
## শিডিউলার, রিপোর্ট, এবং বিজ্ঞপ্তি কোড

| কোড বা স্থিতি | অর্থ | নিরাপদ প্রতিক্রিয়া |
|---|---|---|
| `poll already in flight` | বর্তমান পোল জীবনচক্রের মালিক হওয়ার সময় একটি দ্বিতীয় কলব্যাক এসেছে৷ | বিদ্যমান পোল অগ্রগতি নিশ্চিত করুন; অন্য লুপের মালিক যোগ করবেন না৷ |
| `no_log_files_found` | কোন কনফিগার করা সক্রিয় বা ব্যাকআপ লগ আবিষ্কৃত হয়নি৷ | সংরক্ষিত রুট এবং উৎস কনফিগারেশন যাচাই করুন। |
| `current_poll_error` | বর্তমান চক্র একটি পোল-উৎস ব্যর্থতা রেকর্ড করেছে৷ | পড়ুন `runtime/current/poll_error.json`. |
| `cadence_deferred` | সমাপ্তির প্রেরক এখনও শেষ হয়নি৷ | পরবর্তী সীমাবদ্ধ সুযোগ পর্যন্ত প্রত্যাশিত৷ |
| `reports_disabled` | পাবলিক রিপোর্ট তৈরি করা অক্ষম৷ | প্রতিবেদন উদ্দেশ্য হলেই সক্ষম করুন৷ |
| `local_outbox_write_failed` | একটি অনুবাদ করা স্থানীয় খাম লেখা যাবে না৷ | রানটাইম আউটপুট ডিরেক্টরি মেরামত করুন; এটি একটি বিজ্ঞপ্তি পরিবহন ত্রুটি নয়৷ |
| `source_accounting_disabled` | রুট প্রমাণ সম্পূর্ণ উৎস কভারেজ দাবি করতে পারে না৷ | উৎস অ্যাকাউন্টিং সক্ষম করুন বা অনুপস্থিত প্রমাণ স্পষ্টভাবে স্বীকার করুন৷ |
| `route_disabled` | রুটটি ইচ্ছাকৃতভাবে অক্ষম করা হয়েছে৷ | সেই রুটের জন্য কোনো ডেলিভারি প্রত্যাশিত নয়৷ |
| `poll_owner_between_polls` | পোলগুলির মধ্যে শিডিউলারের মালিকানাধীন ব্যবধানের জন্য রিপোর্ট কর্মী সারিবদ্ধ। | টাইমস্ট্যাম্প এবং কার্সারগুলি অগ্রসর হওয়ার সময় শুধুমাত্র প্রত্যাশিত৷ |
| `unsafe_shell_path` | একটি আবদ্ধ ইনভেন্টরি বা শেল পাথ প্ল্যাটফর্ম-নিরাপদ বৈধতা ব্যর্থ হয়েছে৷ | পাথ ঠিক করুন; উদ্ধৃতি বা পথের বৈধতাকে কখনই দুর্বল করবেন না। |
