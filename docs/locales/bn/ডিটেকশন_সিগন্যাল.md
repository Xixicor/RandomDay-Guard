# শনাক্তকরণ সংকেত

> **ক্যাননিকাল ইংরেজি উৎস:** [DETECTION_SIGNALS.md](../../DETECTION_SIGNALS.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন।


সংকেত হল পর্যালোচনা ইনপুট, স্বয়ংক্রিয় অভিযোগ নয়৷

<a id="signal-table"></a>
## সিগন্যাল টেবিল

| সংকেত | অর্থ | শক্তিশালী যখন... | নিজে থেকে যথেষ্ট নয় |
|---|---|---|---|
| লগইন পরিচয় | অ্যাকাউন্ট আইডিতে মানচিত্রের নাম | কানেক্টআইডি উপস্থিত আছে | নিষিদ্ধ |
| পরিষ্কার ছুটি | সাধারণ সেশন বন্ধ | যোগ দিন এবং ম্যাচ ছেড়ে দিন | সন্দেহ |
| দ্রুত পুনরায় সংযোগ | Churn/probing প্রসঙ্গ | দ্রুত পুনরাবৃত্তি হয় | নিষিদ্ধ |
| অপরিচ্ছন্ন সংযোগ বিচ্ছিন্ন | সেশনটি পরিষ্কারভাবে বন্ধ হয়নি | ক্র্যাশের পুনরাবৃত্তি বা ওভারল্যাপ | নিষিদ্ধ |
| ক্র্যাশ ওভারল্যাপ | ক্র্যাশের কাছাকাছি অ্যাকাউন্ট সক্রিয় | একই অ্যাকাউন্টের পুনরাবৃত্তি | নিষিদ্ধ |
| ক্র্যাশ-পরবর্তী রিটার্ন | অ্যাকাউন্ট রিস্টার্ট করার পরে ফেরত আসে | যুগ জুড়ে পুনরাবৃত্তি হয় | একটি ইভেন্ট দ্বারা নিষিদ্ধ করুন |
| সতর্কতা বিস্ফোরণ | সার্ভার সতর্কতা উইন্ডো | ওভারল্যাপ ম্যাপ করা সেশন | একবার ব্যান করুন |
| অভিনেতা সেভ টাচ | বিশ্ব-সংরক্ষণ প্রসঙ্গ | সেশনের সাথে সম্পর্কযুক্ত | এর প্রমাণ use/theft |
| অবজেক্ট ডেল্টা | World/class পরিবর্তন | সেশনের সাথে সম্পর্কযুক্ত | একা গণনা থেকে নিষিদ্ধ |
| রেড কেস | মাল্টি-অ্যাকাউন্ট ক্লাস্টার | কেন্দ্রীয় অ্যাকাউন্টের পুনরাবৃত্তি | সমস্ত অ্যাকাউন্ট ব্যাপকভাবে নিষিদ্ধ করুন |

<a id="login-identity"></a>
## লগইন পরিচয়

সেরা উৎস:

```text
Login request
Name=
ConnectID=
UniqueId=
```

এটি ম্যাপ করতে ব্যবহার করুন:

```text
display/log name -> account_id -> ban_id
```

<a id="rapid-reconnect"></a>
## দ্রুত পুনরায় সংযোগ

প্যাটার্ন:

```text
join -> leave -> join -> leave -> join
```

পুনরাবৃত্ত হলে পর্যালোচনার জন্য ব্যবহার করুন।

নিরাপত্তা:

```text
churn_alone_never_bans = true
```

<a id="crash-overlap-and-post-crash-return"></a>
## ক্র্যাশ ওভারল্যাপ এবং ক্র্যাশ পরবর্তী রিটার্ন

প্যাটার্ন:

```text
account active before crash
server restarts
same account returns quickly
```

পর্যালোচনার জন্য ব্যবহার করুন যখন যুগ জুড়ে পুনরাবৃত্তি হয়।

নিরাপত্তা:

```text
single_crash_never_bans = true
```

<a id="warning-bursts"></a>
## সতর্কতা বিস্ফোরণ

উদাহরণ:

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

ম্যাপ করা সেশন এবং থ্রেশহোল্ডের সাথে লিঙ্ক না হওয়া পর্যন্ত প্রসঙ্গ হিসাবে ব্যবহার করুন।

<a id="actor-save-touch"></a>
## অভিনেতা সেভ টাচ

অর্থ:

```text
The server evidence referenced a class or actor.
```

অর্থ নয়:

```text
A player opened it.
A player stole from it.
A player duplicated through it.
A player damaged it.
```

<a id="raid-cases"></a>
## রেড কেস

একটি রেইড কেস টাইমিং এবং শেয়ার করা উইন্ডোর ভিত্তিতে অ্যাকাউন্টগুলিকে গ্রুপ করে৷

নিয়ম:

```text
Do not auto-ban every account in a raid case.
Each account needs account-specific evidence.
```
