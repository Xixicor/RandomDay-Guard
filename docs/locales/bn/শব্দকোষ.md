# শব্দকোষ

> **ক্যাননিকাল ইংরেজি উৎস:** [GLOSSARY.md](../../GLOSSARY.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন।


| টার্ম | সরল অর্থ | সঠিক প্রযুক্তিগত অর্থ |
|---|---|---|
| সক্রিয় লগ | নতুন প্রমাণের জন্য ব্যবহৃত বর্তমান সার্ভার লগ৷ | প্রয়োজনীয় `active_log` উৎস; রুট সম্পূর্ণ করার জন্য পঠনযোগ্যতা এবং বর্তমান বংশের প্রয়োজন। |
| বুট আইডি | একটি ওয়াচডগ প্রক্রিয়া শুরু৷ | বর্তমান রানটাইম শনাক্তকারী পূর্বের বুট প্রত্যাখ্যান করতে ব্যবহৃত হয় errors/reports. |
| Epoch ID | একটি সার্ভারের ধারাবাহিকতা ব্যবধান। | শনাক্তকারী স্বাভাবিক রানটাইমকে বিস্তৃত করে যতক্ষণ না ধারাবাহিকতা লজিক আরেকটি যুগ শুরু করে। |
| পোল আইডি | এক সীমাবদ্ধ ভোটের সুযোগ। | ইতিবাচক একঘেয়ে চক্র ক্ষেত্র; zero/missing একটি রুট সম্পূর্ণ করতে পারে না৷ |
| উৎস সতেজতা | বর্তমান উৎস এবং পোল বংশ সম্মত কিনা। | `fresh_current_poll` বা `stale_or_unproven` টাইমস্ট্যাম্প এবং সক্রিয়-লগ স্ট্যাটাস সহ। |
| উৎস অ্যাকাউন্টিং | প্রমাণের প্রাপ্যতা এবং সীমার তালিকা। | `randomdayguard.source-accounting/v1` আটটি উৎস ক্লাস এবং current/historical সুযোগ। |
| `available` | একটি উৎস পাওয়া গেছে এবং পড়া হয়েছে। | এর সাথে টার্মিনাল সোর্স স্ট্যাটাস `available=true`, `readable=true`. |
| `expected_empty` | একটি ঐচ্ছিক উৎস যাচাই করা হয়েছে এবং বৈধভাবে absent/empty. | টার্মিনাল রিডেবল সোর্স স্ট্যাটাস; কখনই কোন বিষয় তৈরি করে না। |
| `partial` | বাউন্ডেড কাজের দরকারী কিন্তু অসম্পূর্ণ ফলাফল আছে৷ | নন-টার্মিনাল source/accounting অবস্থা; মালিক কর্মী পুনরায় শুরু করুন। |
| `deferred` | কাজ ইচ্ছাকৃতভাবে মুলতুবি আছে। | অন্তর্মিনাল উৎস অবস্থা; কোনো ত্রুটি বা সমাপ্তি নয়। |
| `unavailable` | উৎসটি বর্তমানে ব্যবহার করা যাবে না। | টার্মিনাল গ্যাপ; একটি প্রয়োজনীয়-উৎস ব্যবধান অ্যাকাউন্টিং অনুপলব্ধ করে তোলে। |
| `malformed` | একটি উৎস বিদ্যমান কিন্তু কাঠামোগতভাবে অবৈধ৷ | টার্মিনাল গ্যাপ সংরক্ষণের বৈধতা বিস্তারিত এবং নির্ভরশীল লেখা বন্ধ করা। |
| `permission_denied` | OS স্পষ্টভাবে অ্যাক্সেস প্রত্যাখ্যান করেছে৷ | টার্মিনাল ফাঁক missing/unavailable. |
| `error` | একটি আবদ্ধ অপারেশন অপ্রত্যাশিতভাবে ব্যর্থ হয়েছে৷ | টার্মিনাল ব্যর্থতার জন্য নাম পুনরুদ্ধারের প্রয়োজন; পাবলিক রিপোর্টে কোন গোপন বিবরণ নেই। |
| `complete` | সমস্ত অ্যাকাউন্টের উৎস কোন ফাঁক ছাড়া টার্মিনাল। | টপ-লেভেল সোর্স অ্যাকাউন্টিং স্ট্যাটাস। |
| `complete_with_gaps` | প্রয়োজনীয় বর্তমান প্রমাণ কাজ করে; ঐচ্ছিক টার্মিনাল ফাঁক রয়ে গেছে। | শীর্ষ-স্তরের অ্যাকাউন্টিং অবস্থা; রুট এখনও তাদের নিজস্ব প্রয়োজনীয়তা প্রয়োগ করে৷ |
| `full` | একটি রুট তার প্রয়োজনীয় নন-খালি চুক্তির সাথে সম্পন্ন হয়েছে। | সম্পূর্ণ বর্তমান-চক্র আউটপুট সহ রুট প্রুফ enum৷ |
| `limited_expected_empty` | একটি রুট সম্পূর্ণ হয়েছে এবং কোন যোগ্য পাওয়া যায়নি subject/failure. | এর সাথে রুট প্রুফ enum `completed=true`, `expected_empty=true`. |
| `missing` | রুট সম্পূর্ণ হওয়ার প্রমাণ অনুপস্থিত বা ব্যর্থ৷ | এর সাথে রুট প্রুফ enum `completed=false`; আউটবক্সের জন্য কখনই যোগ্য নয়৷ |
| স্ট্রাকচার্ড রিপোর্ট | মেশিন-পাঠযোগ্য রুট আউটপুট। | `<route>_latest.json` ব্যবহার করে `randomdayguard.report/v1`. |
| অনুবাদিত প্রতিবেদন | একই রুটের মানব-পাঠযোগ্য রেন্ডারিং। | `<route>_latest.txt` নির্দিষ্ট অবজারভড-টু-সোর্স-রেফারেন্স অর্ডার সহ। |
| রুট প্রমাণ | ক্রস-রুট কমপ্লিশন লেজার। | `route_proof.json` বাঁধাই version/boot/epoch/poll/freshness/output পাথের বাইরে ফাইলগুলিকে ওভাররাইট করার ক্ষমতা৷ |
| বর্তমান প্রমাণ | সক্রিয় চক্রের মালিকানাধীন পর্যবেক্ষণ। | স্কোপ `current`; পুরানো থেকে পুনর্গঠিত নয় filenames/reports. |
| ঐতিহাসিক প্রমাণ | আগের চক্র বা ধীর স্ক্যান থেকে প্রসঙ্গ ধরে রাখা। | স্কোপ `historical`; পর্যালোচনা জানাতে পারে কিন্তু বর্তমান উপস্থিতি দাবি করতে পারে না৷ |
| শুধুমাত্র পর্যালোচনা | বিনা পর্যালোচনার প্রমাণ তৈরি করুন Admin.ini লেখে। | ডিফল্ট `review_only_mode=true`, `auto_ban=false`, `write_admin_ini=false`. |
| নিষিদ্ধ তালিকা নিরাপত্তা পরীক্ষা | এটি পরিবর্তন হওয়ার আগে একটি প্রশ্ন গার্ডকে অবশ্যই উত্তর দিতে হবে `Admin.ini`. | এটিকে অবশ্যই অ্যাকাউন্ট এবং স্কোর নিশ্চিত করতে হবে, বিশ্বস্ত অ্যাকাউন্ট এবং সদৃশগুলি বাদ দিতে হবে, একটি ব্যাকআপ যাচাই করতে হবে, বাইরের পরিবর্তনগুলি সনাক্ত করতে হবে, উদ্দিষ্ট আপডেটটি সংরক্ষণ করতে হবে এবং সম্পূর্ণ ফাইলটি যাচাই বা নিরাপদে পুনরুদ্ধার করতে হবে৷ |
| স্থানীয় আউটবক্স | ঐচ্ছিক প্রদানকারী-নিরপেক্ষ বিজ্ঞপ্তি হ্যান্ডঅফ। | JSON এর সাথে ফাইল `delivery_backend="none"` এবং `delivery_attempted=false`. |
| বেসলাইন | কমপ্লিটেড বাউন্ডেড সেভড-ফাইল কনটেক্সট স্ন্যাপশট। | Manifest/object/world শুধুমাত্র সামঞ্জস্যপূর্ণ এবং যথেষ্ট তাজা হলেই রাষ্ট্র পুনরায় ব্যবহার করা হয়। |
| চেকপয়েন্ট | অসম্পূর্ণ স্ক্যান কাজের জন্য পুনরায় শুরু করুন। | `scan_checkpoint.json`; মুছে ফেলা ডিফল্ট পুনরুদ্ধার নয়৷ |
| পুনঃনির্মাণযোগ্য সূচক | সারাংশ যা পুনরায় তৈরি করা যেতে পারে। | Daily/weekly/forensic/final পর্যালোচনা আউটপুট; উৎস প্রমাণ প্রামাণিক থেকে যায়। |
| প্রমাণের সীমানা | কোন উৎস কী সমর্থন করতে পারে তার সীমাবদ্ধতা। | স্পষ্ট `does_not_prove`, অজানা, পরিচয় শক্তি, এবং সুযোগের নিয়ম। |
