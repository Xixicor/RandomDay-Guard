# বৈধকরণ এবং প্রকাশ

> **ক্যাননিকাল ইংরেজি উৎস:** [VALIDATION_AND_RELEASE.md](../../VALIDATION_AND_RELEASE.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন।


এই পৃষ্ঠাটি অবদানকারীদের এবং রিলিজ রক্ষণাবেক্ষণকারীদের জন্য৷ ইনস্টল করার জন্য সার্ভার অপারেটরদের এই কমান্ডগুলি চালানোর প্রয়োজন নেই RandomDayGuard.

<a id="user-visible-proof"></a>
## ব্যবহারকারীর দৃশ্যমান প্রমাণ

একটি রিলিজ বোধগম্য যখন একটি নতুন অপারেটর এটি ইনস্টল করতে পারে, প্রথম সার্ভার-স্ট্যাটাস রিপোর্টটি খুঁজে বের করতে পারে, পাঁচটি প্রতিবেদনের রুটগুলিকে আলাদা করতে পারে এবং একটি কার্যকর উদাহরণ থেকে একটি স্পষ্ট পদক্ষেপ অনুসরণ করতে পারে৷ পাঠকের কাজগুলির জন্য অবশ্যই গিট, PowerShell, পাইথন বা চেকসাম জ্ঞানের প্রয়োজন হবে না৷

<a id="contributor-checks"></a>
## কন্ট্রিবিউটর চেক

```powershell
python -B tools/validate_repo.py
python -B tools/test_public_pipeline.py
python -B -m unittest discover tests
```

কখন `luac` উপলব্ধ:

```powershell
luac -p RandomDayGuard/Scripts/main.lua
luac -p RandomDayGuard/Scripts/public_pipeline.lua
```

লুয়া ফিক্সচার পরীক্ষা লোডার, সময়সূচী, রিপোর্ট রুট এবং ঐচ্ছিক Admin.ini লেনদেন লিখুন। এনফোর্সমেন্ট ফিক্সচারগুলি শুধুমাত্র অস্থায়ী ফাইলগুলি ব্যবহার করে এবং পরিচয় যাচাই করে, বিশ্বস্ত-অ্যাকাউন্ট প্রত্যাখ্যান, থ্রেশহোল্ড, ব্যাকআপ, সমবর্তী-পরিবর্তন প্রত্যাখ্যান, রিডব্যাক এবং রোলব্যাক৷

<a id="package-proof"></a>
## প্যাকেজ প্রমাণ

```powershell
python -B tools/build_release_zip.py --check
git diff --check
```

- সমস্ত সংস্করণ মার্কার মেলে `VERSION`.
- শুধুমাত্র বর্তমান সংস্করণ `releases/`.
- দি ZIP ক্যানোনিকাল `RandomDayGuard/Scripts/main.lua` পাথ এবং ছোট হাতের কেস-ভেরিয়েন্ট লোডার নেই৷
- রানটাইম আউটপুট, ব্যক্তিগত কনফিগারেশন, শংসাপত্র, স্থানীয় পাথ, ক্যাশে এবং পরীক্ষার আর্টিফ্যাক্টগুলি বাদ দেওয়া হয়েছে৷
- সর্বজনীন কনফিগারেশনটি কেবলমাত্র এনফোর্সমেন্ট অক্ষম করে পর্যালোচনার জন্য থাকে৷
- পাঁচটি কাজ করা রিপোর্টের উদাহরণ রুটের মালিকানা এবং রিলিজ টেস্ট ফিক্সচারের সাথে সামঞ্জস্যপূর্ণ থাকে।
- ZIP বাইটগুলি নির্ধারক এবং মেলে `CHECKSUMS.sha256`.
- সমস্ত স্থানীয় ডকুমেন্টেশন লিঙ্ক এবং 27টি লোকেল এন্ট্রি পৃষ্ঠা যাচাই করে৷

<a id="avoid-validation-environment-pitfalls"></a>
## বৈধকরণ পরিবেশের ত্রুটিগুলি এড়িয়ে চলুন

- অস্থায়ী-ফাইল বিবাদ এড়াতে ধারাবাহিকভাবে সংগ্রহস্থল-লেখার পরীক্ষা চালান।
- Windows-এ, ডুপ্লিকেট লোডার চেক করার সময় একটি কেস-অসংবেদনশীল ফাইল লুকআপের পরিবর্তে সংরক্ষণাগারভুক্ত সদস্যদের নাম বা গণনাকৃত পাথ বানান পরীক্ষা করুন৷
- একটি অনুপস্থিত `luac` কমান্ড বা লুয়া রানটাইম একটি অনুপলব্ধ ক্ষমতা, পাসিং সিনট্যাক্স বা রানটাইম পরীক্ষা নয়৷
- একটি ফিক্সচার শুধুমাত্র তার মডেল করা ইনপুট প্রমাণ করে৷ এটি প্রমাণ করে না যে একটি লাইভ সার্ভার একটি বর্তমান প্রতিবেদন তৈরি করেছে৷
- কমান্ড টাইমআউট এবং আংশিক আউটপুট সম্পূর্ণ হওয়ার পরিবর্তে রেকর্ড করুন।

<a id="repair-failed-repository-validation"></a>
## বিফল রিপোজিটরি যাচাইকরণ মেরামত

প্রথম রিপোর্ট করা পথ বা চুক্তি দিয়ে শুরু করুন৷ সেই আইটেমটি সংশোধন করুন, সংকীর্ণ পরীক্ষাটি পুনরায় চালান, তারপর সম্পূর্ণ ম্যাট্রিক্সটি পুনরায় চালান। যে পরীক্ষাটি প্রয়োজন তা সরিয়ে একটি অনুপস্থিত ক্ষমতা লুকাবেন না৷

<a id="known-limits-and-release-decision"></a>
## পরিচিত সীমা এবং প্রকাশের সিদ্ধান্ত

স্থানীয় চেকগুলি উত্স, ফিক্সচার, প্যাকেজ এবং ডকুমেন্টেশন চুক্তিগুলি প্রমাণ করে৷ একটি নির্দিষ্ট সার্ভার ইনস্টলেশন, দীর্ঘস্থায়ী স্থায়িত্ব উইন্ডো, বা ক্লায়েন্ট প্রদর্শনের জন্য একটি পৃথক ইন্টিগ্রেশন ফলাফল প্রয়োজন। ম্যাচিং দাবি করার আগে তার বিল্ড, কনফিগারেশন, সময়কাল এবং পর্যবেক্ষণ করা আউটপুট সহ ফলাফল রেকর্ড করুন।
