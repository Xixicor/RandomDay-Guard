# FAQ

> **ক্যাননিকাল ইংরেজি উৎস:** [FAQ.md](../../FAQ.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন।


<a id="is-randomdayguard-the-randomday-mod"></a>
## এটি RandomDayGuard RandomDay মোড?

না। RandomDay মোড সার্ভারের অভিজ্ঞতা পরিবর্তন করে। RandomDayGuard সার্ভার প্রমাণ স্তর দেখে।

<a id="does-live-defense-work-before-the-scan-completes"></a>
## স্ক্যান সম্পূর্ণ হওয়ার আগে কি লাইভ ডিফেন্স কাজ করে?

হ্যাঁ। লাইভ ডিফেন্স লগ এবং সেশন ইভেন্ট ব্যবহার করে। বেসলাইন স্ক্যান পরে প্রসঙ্গ উন্নত করে।

<a id="why-can-the-first-scan-take-a-long-time"></a>
## প্রথম স্ক্যান করতে কেন দীর্ঘ সময় লাগতে পারে?

প্রথম স্ক্যানটি তৈরি হয় world/object প্রসঙ্গ, ফাইল ম্যানিফেস্ট এবং পুনরায় ব্যবহারযোগ্য বেসলাইন ডেটা।

<a id="what-do-i-check-first-after-startup"></a>
## স্টার্টআপের পরে আমি প্রথমে কী পরীক্ষা করব?

```text
runtime/current/poll_status.json
```

এর জন্য দেখুন:

```text
scheduler_status=running
poll_id increasing
poll_in_flight=false
```

<a id="where-are-player-summaries"></a>
## প্লেয়ারের সারাংশ কোথায়?

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

<a id="where-is-the-daily-quick-review-package"></a>
## দৈনিক দ্রুত-পর্যালোচনা প্যাকেজ কোথায়?

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

<a id="which-file-should-i-upload-for-fastest-review"></a>
## দ্রুত পর্যালোচনার জন্য আমার কোন ফাইল আপলোড করা উচিত?

```text
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="can-it-write-bans-automatically"></a>
## এটি কি স্বয়ংক্রিয়ভাবে নিষেধাজ্ঞা লিখতে পারে?

শুধুমাত্র যদি স্পষ্টভাবে সক্ষম করা হয়।

ডিফল্ট:

```lua
review_only_mode = true
auto_ban = false
write_admin_ini = false
```

<a id="what-does-adminini-receive"></a>
## কি করে Admin.ini গ্রহণ করবেন?

শুধুমাত্র:

```ini
BannedPlayer=<ID>
```

কোন নাম, মন্তব্য, কারণ বা প্রত্যয় নেই।

<a id="is-a-display-name-enough-to-ban"></a>
## একটি প্রদর্শন নাম কি নিষিদ্ধ করার জন্য যথেষ্ট?

না। একটি সার্ভার লগ ব্যবহার করুন `Login request` এর সাথে `ConnectID` বা সমতুল্য সার্ভার প্রমাণ।

<a id="can-one-crash-ban-someone"></a>
## একটি ক্র্যাশ কি কাউকে নিষিদ্ধ করতে পারে?

ডিফল্টভাবে না।

<a id="can-object-count-alone-ban-someone"></a>
## অবজেক্ট গণনা একা কাউকে নিষিদ্ধ করতে পারে?

ডিফল্টভাবে না।

<a id="should-savedroottxt-point-to-the-world-folder"></a>
## কি SavedRoot.txt বিশ্ব ফোল্ডারে নির্দেশ করা উচিত?

না। এটিকে `AbioticFactor/Saved`.

<a id="what-if-the-world-folder-changes"></a>
## এ নির্দেশ করুন যদি বিশ্ব ফোল্ডার পরিবর্তিত হয়?

এটিকে একটি বেসলাইন পরিচয় পরিবর্তন হিসাবে বিবেচনা করুন৷ পুরানো বেসলাইন সংরক্ষণ করুন এবং একটি নতুন তৈরি করুন৷
