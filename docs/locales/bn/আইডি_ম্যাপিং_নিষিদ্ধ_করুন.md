<a id="ban-id-mapping"></a>
# আইডি ম্যাপিং নিষিদ্ধ করুন

> **ক্যাননিকাল ইংরেজি উৎস:** [BAN_ID_MAPPING.md](../../BAN_ID_MAPPING.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন।


একটি খেলোয়াড়ের নাম নিরাপদে রূপান্তর করার সময় এই পৃষ্ঠাটি ব্যবহার করুন `Admin.ini` ব্যান লাইন।

<a id="core-rule"></a>
## মূল নিয়ম

একটি প্রদর্শন নাম একটি নিষিদ্ধ ID নয়৷

`Admin.ini` ব্যবহার করে:

```ini
BannedPlayer=<raw numeric player ID>
```

<a id="evidence-hierarchy"></a>
## প্রমাণ অনুক্রম

| র্যাঙ্ক | উৎস | ব্যবহার করুন |
|---:|---|---|
| 1 | সার্ভার লগ `Login request` | সর্বোত্তম নাম-টু-আইডি ম্যাপিং |
| 2 | `Player_<ID>.sav` | আইডি আছে নিশ্চিত করুন |
| 3 | বিদ্যমান `Admin.ini` | বিদ্যমান bans/moderators |
| 4 | বাহ্যিক বিজ্ঞপ্তি বা হোস্টিং-প্যানেল কার্যকলাপ | Time/name শুধুমাত্র প্রসঙ্গ; আইডি প্রুফ নয়  |
| 5 | UE4SS focus/player লাইন | Presence/context শুধুমাত্র |
| 6 | সিস্টেম লাইফ সাইকেল বা কন্টেইনার লগ | শুধুমাত্র হোস্ট লাইফসাইকেল প্রসঙ্গ; আইডি প্রুফ নয়  |

<a id="extract-the-clean-id"></a>
## ক্লিন আইডি বের করুন

কাঁচা উদাহরণ:

```text
ConnectID=2535422284688820_+_|0002d07b...
```

পরিষ্কার করুন `Admin.ini` মান:

```ini
BannedPlayer=2535422284688820
```

পেস্ট করবেন না `_+_|...`.

<a id="verify-with-playerdata"></a>
## এর সাথে যাচাই করুন PlayerData

এর জন্য চেক করুন:

```text
Saved/SaveGames/Server/Worlds/<WorldName>/PlayerData/Player_<ID>.sav
```

অর্থ:

```text
The ID exists in the world save.
```

সীমাবদ্ধতা:

```text
PlayerData may not prove the display name unless another source maps it.
```

<a id="when-not-to-ban"></a>
## কখন নিষিদ্ধ করবেন না

নিষেধ আইডি বরাদ্দ করবেন না যখন:

```text
the name only appears in an external notification
the name only appears in hosting-panel activity
UE4SS shows a name but no ConnectID
only system lifecycle or container logs exist
the ID is trusted or moderator
```
