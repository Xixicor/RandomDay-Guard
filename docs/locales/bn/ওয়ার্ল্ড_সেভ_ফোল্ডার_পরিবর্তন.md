# বিশ্ব সংরক্ষণ ফোল্ডার পরিবর্তন

> **ক্যাননিকাল ইংরেজি উৎস:** [WORLD_SAVE_FOLDER_CHANGES.md](../../WORLD_SAVE_FOLDER_CHANGES.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন।


সক্রিয় বিশ্ব ফোল্ডার পরিবর্তিত হলে এই পৃষ্ঠাটি ব্যবহার করুন৷

<a id="normal-layout"></a>
## সাধারণ বিন্যাস

```text
Saved/SaveGames/Server/Worlds/<WorldName>/
```

`SavedRoot.txt` এখনও নির্দেশ করা উচিত:

```text
AbioticFactor/Saved
```

ওয়ার্ল্ড ফোল্ডার নয়৷

<a id="case-1-same-world-renamed"></a>
## কেস 1: একই বিশ্বের নাম পরিবর্তন করা হয়েছে

উদাহরণ:

```text
Worlds/OldName/
Worlds/NewName/
```

প্রত্যাশিত আচরণ:

```text
Reuse cached evidence where fingerprints match.
Rescan files whose path/cache no longer matches.
Preserve old evidence.
```

<a id="case-2-different-world-or-restored-backup"></a>
## কেস 2: ভিন্ন বিশ্ব বা পুনরুদ্ধার করা ব্যাকআপ

প্রত্যাশিত আচরণ:

```text
Preserve old completed baseline.
Start a new baseline generation.
Do not overwrite old baseline until the new one completes.
```

<a id="case-3-partial-scan-existed-before-the-change"></a>
## কেস 3: পরিবর্তনের আগে আংশিক স্ক্যান বিদ্যমান ছিল

প্রত্যাশিত আচরণ:

```text
Mark the old checkpoint stale.
Preserve partial evidence.
Start a new baseline for the current world.
```

<a id="case-4-completed-baseline-existed-before-the-change"></a>
## কেস 4: সম্পূর্ণ বেসলাইন পরিবর্তনের আগে বিদ্যমান ছিল

প্রত্যাশিত আচরণ:

```text
Load the old baseline for visibility.
Mark it as previous-world context.
Build a new baseline safely.
```
