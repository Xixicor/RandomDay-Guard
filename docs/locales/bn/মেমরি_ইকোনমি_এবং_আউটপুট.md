<a id="memory-economy-and-output-files"></a>
# মেমরি ইকোনমি এবং আউটপুট ফাইল

> **ক্যাননিকাল ইংরেজি উৎস:** [MEMORY_ECONOMY_AND_OUTPUTS.md](../../MEMORY_ECONOMY_AND_OUTPUTS.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন।


এই পৃষ্ঠাটি ব্যাখ্যা করে যে কোন ফাইলগুলি বৃদ্ধি পায়, কোন ফাইলগুলি ওভাররাইট করা হয় এবং দ্রুত পর্যালোচনার জন্য কী আপলোড করতে হয়৷

<a id="fast-answer"></a>
## দ্রুত উত্তর

| প্রশ্ন | খুলুন |
|---|---|
| রক্ষী কি বেঁচে আছে? | `runtime/current/poll_status.json` |
| কাকে দেখা হয়েছিল? | `runtime/account_evidence.json` |
| সেশনের কি হয়েছে? | `runtime/evidence/session_events.jsonl` |
| আজ কি হয়েছে? | `runtime/forensic_days/YYYY-MM-DD/` |
| সরল-ভাষার সারাংশ কী? | `runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt` |
| স্ক্যানের অগ্রগতি কি? | `runtime/scan_progress.json` |
| বিশ্বের প্রেক্ষাপট কী? | `runtime/world_state/current/world_state_latest.json` |
| কি নিষেধাজ্ঞা লেখা হয়েছে? | `runtime/enforced_bans.jsonl` |

<a id="output-model"></a>
## আউটপুট মডেল

| প্রকার | আচরণ | উদাহরণ |
|---|---|---|
| বর্তমান স্ন্যাপশট | ওভাররাইট | `runtime/current/*.json` |
| ইভেন্ট লগ | শুধুমাত্র যোগ করুন | `runtime/evidence/*.jsonl` |
| সারণী | আপডেট করা বা যুক্ত করা হয়েছে | `*.tsv` |
| বেসলাইন | সম্পূর্ণ হওয়ার পরে পুনরায় ব্যবহার করা হয় | `runtime/baselines/*` |
| দৈনিক রোলআপ | স্থানে আপডেট করা হয়েছে | `runtime/forensic_days/YYYY-MM-DD/*` |
| চূড়ান্ত লগ | সরল-ভাষা দৈনিক সারাংশ | `runtime/final_logs/YYYY-MM-DD/*` |

<a id="current-snapshots"></a>
## বর্তমান স্ন্যাপশট

এগুলি ছোট থাকে এবং উত্তর দেয় "এখন কি সত্য।"

```text
runtime/current/poll_status.json
runtime/current/session_state.json
runtime/current/active_accounts.json
runtime/current/forensic_today.json
runtime/current/forensic_today.md
runtime/current/forensic_today.txt
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/world_state/current/world_state_latest.json
```

<a id="player-summaries"></a>
## খেলোয়াড়ের সারাংশ

এগুলি হল প্রথম ফাইল যা অ্যাকাউন্ট পর্যালোচনার জন্য পরীক্ষা করে৷

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

তারা সংক্ষিপ্ত করে:

```text
account_id
ban_id
name
identity_confidence
first_seen
last_seen
join_count
leave_count
status
score
```

## ইভেন্ট লগ

এগুলি টাইমলাইন সংরক্ষণ করে৷

```text
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/warning_events.jsonl
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/evidence/live_defense_events.jsonl
```

<a id="daily-forensic-rollups"></a>
## দৈনিক ফরেনসিক রোলআপ

এগুলি দ্রুত আপলোড প্যাকেজ৷

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

আপনি যখন দ্রুত সময়ের বিশ্লেষণ চান তখন সেই ফোল্ডারগুলির মধ্যে একটি আপলোড করুন৷

<a id="scan-and-baseline-files"></a>
## স্ক্যান এবং বেসলাইন ফাইল

বিশ্বের প্রসঙ্গ আংশিক নাকি সম্পূর্ণ তা বোঝার জন্য এগুলো ব্যবহার করুন।

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/scan_complete.json
runtime/object_registry_partial.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
```

<a id="enforcement-files"></a>
## এনফোর্সমেন্ট ফাইল

এগুলি ব্যবহার করুন শুধুমাত্র যখন এনফোর্সমেন্ট সক্রিয় থাকে৷

```text
runtime/enforced.txt
runtime/enforced_bans.jsonl
runtime/ban_queue.json
runtime/evidence/enforced_bans.jsonl
```

`Admin.ini` শুধুমাত্র গ্রহণ করা উচিত:

```ini
BannedPlayer=<ID>
```
