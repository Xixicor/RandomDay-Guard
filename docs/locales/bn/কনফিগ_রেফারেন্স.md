<a id="configuration-concepts"></a>
# কনফিগারেশন ধারণা

> **ক্যাননিকাল ইংরেজি উৎস:** [CONFIG_REFERENCE.md](../../CONFIG_REFERENCE.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন।


এই ব্যাখ্যাটি বর্ণনা করে যে প্রতিটি প্রধান কনফিগারেশন এলাকা কী নিয়ন্ত্রণ করে, কখন এটি চলে এবং কীভাবে এটি প্রমাণ এবং নিরাপত্তা গেটের সাথে ইন্টারঅ্যাক্ট করে। এটি সঠিক ফিল্ড ক্যাটালগ বা প্রোফাইল পদ্ধতির মালিক নয়৷

টাস্ক-ভিত্তিক প্রিসেট এবং নিরাপদ পরিবর্তন পদক্ষেপের জন্য, ব্যবহার করুন [`CONFIG_PROFILES.md`](%E0%A6%AA%E0%A7%8D%E0%A6%B0%E0%A7%8B%E0%A6%AB%E0%A6%BE%E0%A6%87%E0%A6%B2_%E0%A6%95%E0%A6%A8%E0%A6%AB%E0%A6%BF%E0%A6%97%E0%A6%BE%E0%A6%B0_%E0%A6%95%E0%A6%B0%E0%A7%81%E0%A6%A8.md)। প্রতিটি সঠিক উৎস ক্ষেত্রের জন্য, ডিফল্ট, টাইপ, অপরিবর্তনীয়, আউটপুট প্রভাব এবং পুনরুদ্ধারের নিয়ম, তৈরি করা ব্যবহার করুন [`CONFIG_FIELD_CATALOG.md`](%E0%A6%95%E0%A6%A8%E0%A6%AB%E0%A6%BF%E0%A6%97_%E0%A6%AB%E0%A6%BF%E0%A6%B2%E0%A7%8D%E0%A6%A1_%E0%A6%95%E0%A7%8D%E0%A6%AF%E0%A6%BE%E0%A6%9F%E0%A6%BE%E0%A6%B2%E0%A6%97.md); প্রতি পাঠানোর জন্য যাচাইকারীর সেখানে একটি সারি প্রয়োজন `config.lua` পাতার ক্ষেত্র।

<a id="top-level-safety"></a>
## শীর্ষ-স্তরের নিরাপত্তা

| বিকল্প | ডিফল্ট | অর্থ |
|---|---:|---|
| `enabled` | `true` | গার্ডের জন্য মাস্টার সুইচ |
| `enforcement.review_only_mode` | `true` | Record/recommend শুধুমাত্র |
| `enforcement.auto_ban` | `false` | ডিফল্টরূপে স্বয়ংক্রিয়ভাবে নিষিদ্ধ করবেন না |
| `enforcement.write_admin_ini` | `false` | লিখবেন না Admin.ini ডিফল্টরূপে |

সার্ভার মালিক আউটপুট পর্যালোচনা না করা পর্যন্ত এগুলিকে নিরাপদে রাখুন৷

<a id="saved"></a>
## `saved`

নিয়ন্ত্রণ করে কিভাবে গার্ড সার্ভার খুঁজে পায় `Saved/` ফোল্ডার এবং কোন ফাইল ফ্যামিলি এটি স্ক্যান করতে পারে৷

ব্যবহার করুন যখন:

```text
Saved root auto-detection fails.
World folder changed.
Provider or container path is unusual.
```

চেক করুন:

```text
runtime/saved_path_probe.json
RandomDayGuard/SavedRoot.txt
```

নিয়ম:

```text
SavedRoot.txt -> AbioticFactor/Saved
not -> Worlds/<WorldName>
```

<a id="log_tail"></a>
## `log_tail`

লাইভ লগ পড়া নিয়ন্ত্রণ করে।

উপযোগী বিকল্প:

| বিকল্প | নিরাপদ মান | কেন |
|---|---|---|
| `enabled` | `true` | লাইভ প্রতিরক্ষার জন্য প্রয়োজন |
| `start_at_end_on_first_run` | `true` | লাইভ ইভেন্ট হিসাবে পুরানো লগ এড়িয়ে চলে |
| `tail_backup_logs` | `false` | ব্যাকআপ লগগুলি ইতিহাস, লাইভ নয় |
| `max_lines_per_poll` | বাউন্ডেড | পোল লুপ প্রতিক্রিয়াশীল রাখে |

চেক করুন:

```text
runtime/log_offsets.tsv
runtime/evidence/session_events.jsonl
runtime/current/poll_status.json
```

<a id="runtime"></a>
## `runtime`

পোলিং এবং বাজেট নিয়ন্ত্রণ করে।

প্রধান স্বাস্থ্য নিয়ম:

```text
poll_id increases
poll_in_flight returns false
poll_scheduled is true
```

চেক করুন:

```text
runtime/current/poll_status.json
```

যদি `poll_id` থামে, কিছু লুপ ব্লক করছে।

<a id="source_accounting"></a>
## `source_accounting`

স্পষ্ট প্রমাণ-উৎস কভারেজ এবং সুযোগ নিয়ন্ত্রণ করে।

| কী | ডিফল্ট | অর্থ |
|---|---:|---|
| `enabled` | `true` | পাবলিক রুট রিপোর্টের জন্য সোর্স অ্যাকাউন্টিং লেখে। |
| `require_terminal_status` | `true` | একটি সুস্পষ্ট টার্মিনাল বা অসম্পূর্ণ অবস্থা প্রকাশ করার জন্য প্রতিটি উত্সের প্রয়োজন৷ |
| `distinguish_current_from_historical` | `true` | বর্তমান এবং ঐতিহাসিক প্রমাণ আলাদা রাখে। |
| `slow_world_scan_blocks_current_reports` | `false` | বর্তমান রিপোর্টগুলিকে এটা বলার অনুমতি দেয় যে বাউন্ডেড ওয়ার্ল্ড স্ক্যানিং স্থগিত বা আংশিক৷ |
| `changed_file_manifest` | বেসলাইন ম্যানিফেস্ট পথ | বাউন্ডেডের জন্য ব্যবহৃত রেফারেন্স historical/world অ্যাকাউন্টিং। |

উৎস রাজ্যগুলি হল `available`, `expected_empty`, `partial`, `deferred`, `unavailable`, `malformed`, `permission_denied` বা `error`.

সেটিং `source_accounting.enabled = false` নীরবে স্ট্যাটাস আউটপুট মুছে দেয় না। পাইপলাইন এখনো লিখছে `runtime/final_logs/source_accounting_latest.json` এর সাথে `enabled=false`, `status="unavailable"` এবং `disabled_reason="source_accounting_disabled"`। এটি অনুপলব্ধ অ্যাকাউন্টিং সহ ঐতিহাসিক-স্থিতি রেকর্ডও লিখে। কারণ সোর্স অ্যাকাউন্টিং রিপোর্ট চুক্তির অংশ, প্রতিটি রুট `missing`; অ্যাকাউন্টিং নিষ্ক্রিয় থাকা অবস্থায় কোনো রুটকে সম্পূর্ণ হিসাবে বিবেচনা করা হয় না।

<a id="reports"></a>
## `reports`

জেনারিক স্থানীয় রিপোর্টিং পাইপলাইন নিয়ন্ত্রণ করে৷

ডিফল্ট সমস্ত পাঁচটি রুট সক্রিয় করে এবং `runtime/final_logs`:

```text
server_status
daily_rollup
player_activity
case_review
critical_guard
```

প্রত্যেক রুটে অবশ্যই স্ট্রাকচার্ড এবং অনুবাদিত আউটপুট প্লাস প্রুফ লিখতে হবে `route_proof.json`। একটি রুট নিষ্ক্রিয় করলে `missing` এটি সম্পূর্ণ হয়েছে এমন ভান না করে প্রমাণ৷

<a id="notification"></a>
## `notification`

ঐচ্ছিক জেনেরিক স্থানীয় ফাইল আউটবক্স৷ এটি ডিফল্টরূপে অক্ষম থাকে এবং বহিরাগত সরবরাহকারীকে কিছুই পাঠায় না৷

ডিফল্ট:

```lua
notification = {
    enabled = false,
    mode = "local_file_outbox",
    include_expected_empty = false,
},
```

প্রতিটি বিজ্ঞপ্তি রুট ডিফল্টরূপে অক্ষম থাকে৷ ইচ্ছাকৃতভাবে সক্রিয় করা হলে, আউটবক্স `route_proof.json` লেখা আছে। স্থানীয় প্রমাণ এবং রিপোর্ট প্রামাণিক থেকে যায়. প্রদানকারী-নির্দিষ্ট ডেলিভারি, ডেলিভারি এন্ডপয়েন্ট, শংসাপত্র, এবং সেতুগুলি পাবলিক স্বাধীন-ওয়াচডগ চুক্তির অংশ নয়৷

<a id="scanning"></a>
## `scanning`

বেসলাইন স্ক্যান, চেকপয়েন্টিং এবং পরিবর্তিত ফাইল রিফ্রেশ নিয়ন্ত্রণ করে।

ব্যবহার করুন যখন:

```text
building first world baseline
resuming after crash
refreshing changed files later
```

চেক করুন:

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/scan_complete.json
runtime/baselines/file_manifest.tsv
```

গুরুত্বপূর্ণ সেটিংস:

```lua
scanning = {
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
    changed_file_detection = true,
},
```

<a id="forensic_rollup"></a>
## `forensic_rollup`

দ্রুত দৈনিক আপলোড প্যাকেজ এবং চূড়ান্ত সরল-ভাষা লগগুলি নিয়ন্ত্রণ করে৷

আউটপুট:

```text
runtime/current/forensic_today.json
runtime/current/forensic_today.md
runtime/current/forensic_today.txt
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

ব্যবহার করুন যখন:

```text
You want one daily folder that summarizes what happened.
You want a plain-language TXT to upload for quick analysis.
```

চেক করুন:

```text
runtime/forensic_days/YYYY-MM-DD/forensic_day_summary.json
runtime/forensic_days/YYYY-MM-DD/players.tsv
runtime/forensic_days/YYYY-MM-DD/ban_recommendations.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

নিয়ম:

```text
Daily summaries are rebuildable indexes.
Source evidence remains authoritative.
```

<a id="logging"></a>
## `logging`

ইভেন্টের ভলিউম এবং কম-গুরুত্বপূর্ণ একত্রীকরণ নিয়ন্ত্রণ করে।

ব্যবহার করুন যখন:

```text
actor-touch events are noisy
raw event files grow too quickly
```

নিরাপদ প্যাটার্ন:

```lua
logging = {
    low_importance_mode = "aggregate",
    write_low_importance_raw_events = false,
},
```

<a id="retention"></a>
## `retention`

ফাইল কতক্ষণ রাখা হবে এবং কখন JSONL লগগুলি ঘোরে৷

ব্যবহার করুন যখন:

```text
disk usage grows too fast
you need more audit history
you need shorter live-history windows
```

গুরুত্বপূর্ণ বিকল্প:

```text
detailed_retention_days
rotate_jsonl_when_bytes_exceed
max_raw_events_lines
keep_enforced_forever
keep_evidence_forever
```

<a id="warning_bursts"></a>
## `warning_bursts`

সতর্কতা-উইন্ডো সনাক্তকরণ নিয়ন্ত্রণ করে।

উদাহরণ:

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

নিয়ম:

```text
Warnings are context until correlated with mapped sessions and thresholds.
```

<a id="crash_correlation"></a>
## `crash_correlation`

নিয়ন্ত্রণ পুনরাবৃত্তি crash/reconnect পর্যালোচনা।

নিরাপদ ডিফল্ট:

```lua
crash_correlation = {
    single_crash_never_bans = true,
    require_same_account = true,
},
```

উপযোগী কাউন্টার:

```text
server_crash_overlap_count
post_crash_reconnect_count
unclean_disconnect_count
```

<a id="join_leave"></a>
## `join_leave`

মন্থন এবং জয়েন-ওয়েভ ট্র্যাকিং নিয়ন্ত্রণ করে।

নিরাপদ ডিফল্ট:

```lua
join_leave = {
    churn_alone_never_bans = true,
},
```

এর জন্য ব্যবহার করুন:

```text
rapid reconnect loops
join waves
short-session patterns
```

<a id="raid_detection"></a>
## `raid_detection`

সম্পর্কিত উইন্ডোতে সক্রিয় গ্রুপ অ্যাকাউন্ট।

নিয়ম:

```text
A raid case groups accounts for review.
It does not make every account guilty.
```

প্রতিটি প্রয়োগকৃত অ্যাকাউন্টের এখনও অ্যাকাউন্ট-নির্দিষ্ট প্রমাণের প্রয়োজন৷

<a id="object_registry"></a>
## `object_registry`

নিয়ন্ত্রণ object/class পঠনযোগ্য সংরক্ষিত প্রমাণ থেকে টোকেন নিষ্কাশন।

আউটপুট:

```text
runtime/object_registry_partial.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
```

নিয়ম:

```text
Object/class context is not a ban reason by itself.
```

<a id="world_state"></a>
## `world_state`

নিয়ন্ত্রণ boot/current/session বিশ্ব-রাষ্ট্রের স্ন্যাপশট।

আউটপুট:

```text
runtime/world_state/current/world_state_latest.json
runtime/world_state/sessions/<date>/<session_id>_<account_id>/
```

সেশন পর্যালোচনা এবং বিশ্ব প্রসঙ্গের জন্য ব্যবহার করুন৷

<a id="enforcement"></a>
## `enforcement`

নিয়ন্ত্রণ করে সুপারিশ এবং প্রকৃত Admin.ini লেখে।

গার্ড একটি নিষেধাজ্ঞা যোগ করার আগে, নীচের প্রতিটি বিবৃতি সত্য হতে হবে:

```text
review_only_mode == false
auto_ban == true
write_admin_ini == true
ban_id is clean numeric
account identity is mapped
not trusted
not moderator
threshold is met
```

একটি বিবৃতি মিথ্যা হলে বা চেক করা না গেলে, গার্ড চলে যায় `Admin.ini` অপরিবর্তিত এবং কারণ রেকর্ড করে৷

<a id="admin_ini"></a>
## `admin_ini`

নিরাপদ ফাইল লেখা নিয়ন্ত্রণ করে।

নিয়ম:

```text
Back up before writing.
Preserve existing bans.
Preserve moderators.
Write clean BannedPlayer=<ID> only.
```

<a id="restart_request"></a>
## `restart_request`

ঐচ্ছিক স্থানীয় মার্কার ফাইলগুলিকে নিয়ন্ত্রণ করে যা অন্য অপারেটরের মালিকানাধীন প্রক্রিয়া পরিদর্শন করতে পারে৷ এটি সার্ভার পুনরায় চালু বা মেরে ফেলে না৷

ডিফল্ট:

```lua
restart_request = {
    enabled = false,
    restart_marker_file = "runtime/request_restart.flag",
```
