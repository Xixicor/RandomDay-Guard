# নিরাপত্তা নীতি

> **ক্যাননিকাল ইংরেজি উৎস:** [SECURITY.md](../../../SECURITY.md). এই স্থানীয় ডকুমেন্টেশন সঠিক কমান্ড, পাথ, কী, স্থিতি মান, হ্যাশ এবং ফাইলের নাম সংরক্ষণ করে। প্রযুক্তিগত শব্দের ভিন্নতা থাকলে, ইংরেজি উৎস ব্যবহার করুন।


<a id="report-a-vulnerability-privately"></a>
## একটি দুর্বলতা ব্যক্তিগতভাবে রিপোর্ট করুন

ব্যবহার করুন [GitHub ব্যক্তিগত দুর্বলতা প্রতিবেদন](https://github.com/Xixicor/RandomDay-Guard/security/advisories/new) সংগ্রহস্থলের মালিকের কাছে একটি গোপনীয় প্রতিবেদন পাঠাতে। যদি সেই ফর্মটি উপলব্ধ না হয়, তাহলে [মালিকের সর্বজনীন GitHub প্রোফাইল](https://github.com/Xixicor) দুর্বলতার বিবরণ অন্তর্ভুক্ত না করে একটি ব্যক্তিগত যোগাযোগের চ্যানেলের অনুরোধ করতে৷

শোষণের পদক্ষেপ, শংসাপত্র, ব্যক্তিগত সার্ভার পাথ, প্লেয়ার শনাক্তকারী, `Admin.ini`, সংরক্ষিত ডেটা, ওয়েবহুক ইউআরএল বা লাইভ প্রমাণ ফাইল।

<a id="include-useful-evidence"></a>
## উপযোগী প্রমাণ অন্তর্ভুক্ত করুন

প্রদান করুন:

- আক্রান্ত RandomDayGuard সংস্করণ বা প্রতিশ্রুতি;
- প্রভাবিত উপাদান এবং প্রত্যাশিত নিরাপদ আচরণ;
- স্যানিটাইজড ফিক্সচার ব্যবহার করে ন্যূনতম প্রজনন পদক্ষেপ;
- পর্যবেক্ষিত প্রভাব এবং এটি পুনরাবৃত্তিযোগ্য কিনা; এবং
- যেকোন প্রস্তাবিত প্রশমন যা ব্যক্তিগত ডেটা প্রকাশ করে না।

প্রকৃত গোপনীয়তা পাঠাবেন না। সমস্যাটি পুনরুত্পাদন করার জন্য প্রয়োজনীয় কাঠামো সংরক্ষণ করার সময় ব্যক্তিগত পাথ, অ্যাকাউন্ট শনাক্তকারী, হোস্টনাম এবং টোকেনগুলিকে পরিষ্কার স্থানধারকগুলির সাথে প্রতিস্থাপন করুন৷

<a id="expect-review-first-handling"></a>
## পর্যালোচনা-প্রথম হ্যান্ডলিং প্রত্যাশা করুন

একটি প্রতিবেদন রক্ষণাবেক্ষণকারীর পর্যালোচনার প্রমাণ, সার্ভার অ্যাক্সেস করার অনুমোদন নয়, একটি লাইভ লক্ষ্য পরীক্ষা করা, শোষণের বিবরণ প্রকাশ করা, বা ব্যর্থ-বন্ধ ডিফল্ট দুর্বল করে দেওয়া। মালিক সুযোগ যাচাই করবে এবং ব্যক্তিগত প্রতিবেদনের মাধ্যমে কোনো প্রকাশের সমন্বয় করবে।
