# RandomDayGuard la documentation

> **Source canonique en anglais:** [README.md](../../README.md). Cette documentation localisée conserve les commandes, chemins, clés, valeurs d'état, hachages et noms de fichiers exacts. Si la formulation technique diffère, utilisez la source anglaise.


RandomDayGuard lit les enregistrements d'un serveur dédié à Abiotic Factor et les transforme en rapports distincts sur l'état du serveur, l'historique quotidien, les sessions des joueurs, les cas d'examen et les échecs de Guard.
