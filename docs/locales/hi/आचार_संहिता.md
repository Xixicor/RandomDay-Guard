# आचार संहिता

> **कैनोनिकल अंग्रेजी स्रोत:** [CODE_OF_CONDUCT.md](../../../CODE_OF_CONDUCT.md). यह स्थानीयकृत दस्तावेज़ सटीक कमांड, पथ, कुंजियाँ, स्थिति मान, हैश और फ़ाइल नाम सुरक्षित रखता है। यदि तकनीकी शब्दांकन भिन्न है, तो अंग्रेजी स्रोत का उपयोग करें। यह अनुवाद सूचनात्मक है; अंग्रेजी कानूनी पाठ नियंत्रण करता है।


चर्चा को तकनीकी, विशिष्ट और साक्ष्य-आधारित रखें। सार्वजनिक मुद्दों में निजी प्लेयर डेटा, सर्वर क्रेडेंशियल, या लाइव घटना लॉग पोस्ट न करें।
