# शब्दावली

> **कैनोनिकल अंग्रेजी स्रोत:** [GLOSSARY.md](../../GLOSSARY.md). यह स्थानीयकृत दस्तावेज़ सटीक कमांड, पथ, कुंजियाँ, स्थिति मान, हैश और फ़ाइल नाम सुरक्षित रखता है। यदि तकनीकी शब्दांकन भिन्न है, तो अंग्रेजी स्रोत का उपयोग करें।


| शब्द | सादा अर्थ | सटीक तकनीकी अर्थ |
|---|---|---|
| सक्रिय लॉग | ताजा साक्ष्य के लिए वर्तमान सर्वर लॉग का उपयोग किया जाता है। | आवश्यक `active_log` स्रोत; मार्ग पूरा करने के लिए पठनीयता और वर्तमान वंशावली की आवश्यकता है। |
| बूट आईडी | एक निगरानी प्रक्रिया प्रारंभ। | वर्तमान रनटाइम पहचानकर्ता का उपयोग पूर्व-बूट को अस्वीकार करने के लिए किया जाता है errors/reports. |
| एपोक आईडी | एक सर्वर निरंतरता अंतराल। | पहचानकर्ता सामान्य रनटाइम को तब तक फैलाता है जब तक निरंतरता तर्क एक और युग शुरू नहीं कर देता। |
| पोल आईडी | एक सीमित मतदान का अवसर। | सकारात्मक मोनोटोनिक चक्र क्षेत्र; zero/missing कोई रूट पूरा नहीं कर सकता। |
| स्रोत ताजगी | क्या वर्तमान स्रोत और मतदान वंश सहमत हैं। | `fresh_current_poll` या `stale_or_unproven` टाइमस्टैम्प और सक्रिय-लॉग स्थिति के साथ। |
| स्रोत लेखांकन | साक्ष्य की उपलब्धता और सीमाओं की सूची। | `randomdayguard.source-accounting/v1` आठ स्रोत वर्गों और current/historical दायरा। |
| `available` | एक स्रोत मिला और पढ़ा गया। | टर्मिनल स्रोत स्थिति `available=true`, `readable=true`. |
| `expected_empty` | एक वैकल्पिक स्रोत की जाँच की गई और वैध रूप से absent/empty. | टर्मिनल पठनीय स्रोत स्थिति; कभी भी किसी विषय का निर्माण नहीं करता. |
| `partial` | सीमाबद्ध कार्य के उपयोगी लेकिन अधूरे परिणाम होते हैं। | नॉनटर्मिनल source/accounting स्थिति; मालिक कर्मचारी को फिर से शुरू करें। |
| `deferred` | जानबूझकर काम लटकाया जा रहा है। | नॉनटर्मिनल स्रोत स्थिति; कोई त्रुटि या पूर्णता नहीं. |
| `unavailable` | वर्तमान में स्रोत का उपयोग नहीं किया जा सकता। | टर्मिनल गैप; एक आवश्यक-स्रोत अंतर लेखांकन को अनुपलब्ध बना देता है। |
| `malformed` | एक स्रोत मौजूद है लेकिन संरचनात्मक रूप से अमान्य है। | टर्मिनल गैप सत्यापन विवरण को संरक्षित करता है और आश्रित लेखन को बंद करता है। |
| `permission_denied` | OS ने स्पष्ट रूप से पहुंच को अस्वीकार कर दिया। | टर्मिनल गैप missing/unavailable. |
| `error` | एक बाउंडेड ऑपरेशन अप्रत्याशित रूप से विफल हो गया। | टर्मिनल विफलता जिसके लिए नामित पुनर्प्राप्ति की आवश्यकता है; सार्वजनिक रिपोर्टों में कोई गुप्त विवरण नहीं है। |
| `complete` | सभी लेखांकन स्रोत बिना किसी अंतराल के टर्मिनल हैं। | शीर्ष-स्तरीय स्रोत लेखांकन स्थिति। |
| `complete_with_gaps` | आवश्यक वर्तमान साक्ष्य कार्य; वैकल्पिक टर्मिनल अंतराल बने हुए हैं। | शीर्ष-स्तरीय लेखांकन स्थिति; मार्ग अभी भी अपनी स्वयं की आवश्यकताएं लागू करते हैं। |
| `full` | एक रूट अपने आवश्यक गैर-रिक्त अनुबंध के साथ पूरा हुआ। | पूर्ण वर्तमान-चक्र आउटपुट के साथ रूट प्रूफ एनम। |
| `limited_expected_empty` | एक मार्ग पूरा हो गया और कोई पात्र नहीं मिला subject/failure. |  `completed=true`, `expected_empty=true`. |
| `missing` | रूट पूर्णता प्रमाण अनुपस्थित या विफल है। |  `completed=false`; आउटबॉक्स के लिए कभी पात्र नहीं। |
| संरचित रिपोर्ट | मशीन-पठनीय मार्ग आउटपुट। | `<route>_latest.json` `randomdayguard.report/v1`. |
| अनुवादित रिपोर्ट | उसी मार्ग का मानव-पठनीय प्रतिपादन। | `<route>_latest.txt` निश्चित अवलोकन-से-स्रोत-संदर्भ क्रम के साथ। |
| रूट प्रूफ़ | क्रॉस-रूट पूर्णता बही। | `route_proof.json` बाइंडिंग version/boot/epoch/poll/freshness/output पथ. |
| वर्तमान साक्ष्य | सक्रिय चक्र के स्वामित्व वाला अवलोकन। | दायरा `current`; पुराने filenames/reports. |
| ऐतिहासिक साक्ष्य | पहले के चक्रों या धीमे स्कैन से संदर्भ बरकरार रखा गया। | दायरा `historical`; समीक्षा की सूचना दे सकता है लेकिन वर्तमान उपस्थिति का दावा नहीं कर सकता। |
| केवल समीक्षा | बिना Admin.ini लिखता है। | डिफ़ॉल्ट `review_only_mode=true`, `auto_ban=false`, `write_admin_ini=false`. |
| प्रतिबंध-सूची सुरक्षा जांच | एक प्रश्न बदलने से पहले गार्ड को इसका उत्तर देना होगा `Admin.ini`. | इसे खाते और स्कोर की पुष्टि करनी होगी, विश्वसनीय खातों और डुप्लिकेट को बाहर करना होगा, बैकअप सत्यापित करना होगा, बाहरी परिवर्तनों का पता लगाना होगा, इच्छित अपडेट को सहेजना होगा और पूरी फ़ाइल को सत्यापित या सुरक्षित रूप से पुनर्स्थापित करना होगा। |
| स्थानीय आउटबॉक्स | वैकल्पिक प्रदाता-तटस्थ अधिसूचना हैंडऑफ़। | JSON फ़ाइलें `delivery_backend="none"` और `delivery_attempted=false`. |
| बेसलाइन | पूरा बाउंडेड सेव्ड-फ़ाइल संदर्भ स्नैपशॉट। | Manifest/object/world स्थिति का पुन: उपयोग केवल तभी किया जाता है जब वह संगत और पर्याप्त ताज़ा हो। |
| चेकपॉइंट | अधूरे स्कैन कार्य के लिए स्थिति फिर से शुरू करें। | `scan_checkpoint.json`; हटाना डिफ़ॉल्ट पुनर्प्राप्ति नहीं है। |
| पुनर्निर्माण योग्य सूचकांक | सारांश जिसे पुनर्जीवित किया जा सकता है। | Daily/weekly/forensic/final समीक्षा आउटपुट; स्रोत साक्ष्य आधिकारिक बना हुआ है। |
| साक्ष्य सीमा | यह सीमित करें कि कोई स्रोत किस चीज़ का समर्थन कर सकता है। | स्पष्ट `does_not_prove`, अज्ञात, पहचान की ताकत और दायरा नियम। |
