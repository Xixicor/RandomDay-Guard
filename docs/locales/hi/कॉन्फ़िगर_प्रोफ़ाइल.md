# कॉन्फ़िगरेशन प्रोफ़ाइल

> **कैनोनिकल अंग्रेजी स्रोत:** [CONFIG_PROFILES.md](../../CONFIG_PROFILES.md). यह स्थानीयकृत दस्तावेज़ सटीक कमांड, पथ, कुंजियाँ, स्थिति मान, हैश और फ़ाइल नाम सुरक्षित रखता है। यदि तकनीकी शब्दांकन भिन्न है, तो अंग्रेजी स्रोत का उपयोग करें।


व्यावहारिक कॉन्फ़िगरेशन प्रोफ़ाइल चुनने और लागू करने के लिए इस 'कैसे करें' मार्गदर्शिका का उपयोग करें। सेटिंग समूह कैसे इंटरैक्ट करते हैं, इसकी व्याख्या के लिए [`CONFIG_REFERENCE.md`](%E0%A4%95%E0%A5%89%E0%A4%A8%E0%A5%8D%E0%A4%AB%E0%A4%BC%E0%A4%BF%E0%A4%97%E0%A4%B0_%E0%A4%B8%E0%A4%82%E0%A4%A6%E0%A4%B0%E0%A5%8D%E0%A4%AD.md). सटीक फ़ील्ड, डिफ़ॉल्ट, प्रकार और अपरिवर्तनीय के लिए, जेनरेट किए गए [`CONFIG_FIELD_CATALOG.md`](%E0%A4%95%E0%A5%89%E0%A4%A8%E0%A5%8D%E0%A4%AB%E0%A4%BC%E0%A4%BF%E0%A4%97_%E0%A4%AB%E0%A4%BC%E0%A5%80%E0%A4%B2%E0%A5%8D%E0%A4%A1_%E0%A4%95%E0%A5%88%E0%A4%9F%E0%A4%B2%E0%A5%89%E0%A4%97.md).

नीचे दिया गया प्रत्येक लुआ ब्लॉक शीर्ष-स्तरीय प्रविष्टियों का एक सेट है जो शिप किए गए अंदर मेल खाने वाली प्रविष्टियों को प्रतिस्थापित कर सकता है `return { ... }` तालिका।

<a id="profile-chooser"></a>
## प्रोफ़ाइल चयनकर्ता

| स्थिति | इस प्रोफ़ाइल का उपयोग करें |
|---|---|
| पहले इंस्टॉल करें | सबसे पहले सुरक्षित इंस्टॉल |
| सर्वर अस्थिर है और अक्सर क्रैश हो जाता है | धीमे स्कैन के बिना वर्तमान साक्ष्य |
| आप चाहते हैं object/world संदर्भ | पूर्ण आधार रेखा |
| आप पुराने लॉग की समीक्षा करना चाहते हैं | फॉरेंसिक बैकफ़िल |
| आप सिफ़ारिशें चाहते हैं लेकिन लिखना नहीं | प्रवर्तन परीक्षण |
| आप गार्ड को प्रतिबंध लिखने देने के लिए तैयार हैं | प्रवर्तन सक्षम |
| डिस्क सीमित है | कम डिस्क वृद्धि |
| आपने एक साफ़ आधार रेखा पूरी कर ली है | स्टिकी बैकअप सेटअप |

<a id="safe-first-install"></a>
## सबसे पहले सुरक्षित इंस्टॉल

इसे पहले किसी लाइव सर्वर पर उपयोग करें।

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

log_tail = {
    enabled = true,
    start_at_end_on_first_run = true,
    tail_backup_logs = false,
},

scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

यह क्या करता है:

```text
Tracks live sessions.
Starts the baseline scan.
Does not edit Admin.ini.
Avoids treating old backup logs as fresh live events.
```

<a id="current-evidence-without-slow-scan"></a>
## धीमे स्कैन के बिना वर्तमान साक्ष्य

यदि सर्वर अस्थिर है और आपको crash/reconnect भारी स्कैन से पहले सबूत।

```lua
log_tail = {
    enabled = true,
},

scanning = {
    full_scan_on_start = false,
},

enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

यह क्या करता है:

```text
Tracks logins, joins, leaves, reconnects, crashes, and unclean sessions.
Delays heavy world scanning.
```

<a id="full-baseline"></a>
## पूर्ण आधार रेखा

सर्वर स्कैन करने के लिए पर्याप्त समय तक चालू रहने के बाद इसका उपयोग करें।

```lua
scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},
```

यह क्या करता है:

```text
Builds object registry.
Writes world-state context.
Creates file manifest.
Enables changed-file refresh later.
```

<a id="forensic-backfill"></a>
## फॉरेंसिक बैकफ़िल

इसका उपयोग केवल तभी करें जब जानबूझकर ऐतिहासिक लॉग की समीक्षा की जा रही हो।

```lua
log_tail = {
    start_at_end_on_first_run = false,
    tail_backup_logs = true,
    backfill_backup_logs_on_start = true,
},
```

इसका उपयोग करने से पहले:

```text
Back up runtime/log_offsets.tsv.
Expect old events to be reprocessed.
Return to live settings when finished.
```

<a id="enforcement-testing"></a>
## प्रवर्तन परीक्षण

वास्तविक Admin.ini लेखन।

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},
```

क्या निरीक्षण करें:

```text
runtime/account_evidence.json
runtime/warnings/
runtime/forensic_days/YYYY-MM-DD/ban_recommendations.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="enforcement-enabled"></a>
## प्रवर्तन सक्षम

समीक्षा आउटपुट सही होने के बाद ही इसका उपयोग करें।

```lua
enforcement = {
    review_only_mode = false,
    auto_ban = true,
    write_admin_ini = true,
    require_clean_ban_id = true,
    preserve_existing_bans = true,
    preserve_moderators = true,
},
```

सक्षम करने से पहले:

```text
Trusted IDs are configured.
Moderator IDs are preserved.
Admin.ini backups work.
Ban recommendations are understandable.
Thresholds are accepted by the server owner.
```

<a id="low-disk-growth"></a>
## कम डिस्क वृद्धि

जब रनटाइम फ़ाइलें बहुत तेज़ी से बढ़ रही हों तो इसका उपयोग करें।

```lua
logging = {
    low_importance_mode = "aggregate",
    write_low_importance_raw_events = false,
},

retention = {
    detailed_retention_days = 7,
    rotate_jsonl_when_bytes_exceed = 5242880,
    max_raw_events_lines = 20000,
    compact_json_outputs = true,
},
```

<a id="sticky-backup-setup"></a>
## स्टिकी बैकअप सेटअप

पहली पूर्ण बेसलाइन के बाद उपयोग करें।

जांचें कि ये मौजूद हैं:

```text
runtime/scan_complete.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
runtime/world_state/current/world_state_latest.json
```

फिर `config.lua`, `SavedRoot.txt`, और `Admin.ini`.
