# FAQ

> **कैनोनिकल अंग्रेजी स्रोत:** [FAQ.md](../../FAQ.md). यह स्थानीयकृत दस्तावेज़ सटीक कमांड, पथ, कुंजियाँ, स्थिति मान, हैश और फ़ाइल नाम सुरक्षित रखता है। यदि तकनीकी शब्दांकन भिन्न है, तो अंग्रेजी स्रोत का उपयोग करें।


<a id="is-randomdayguard-the-randomday-mod"></a>
## है RandomDayGuard RandomDay मॉड?

नहीं. RandomDay मॉड सर्वर अनुभव को बदल देता है। RandomDayGuard सर्वर साक्ष्य परत पर नज़र रखता है।

<a id="does-live-defense-work-before-the-scan-completes"></a>
## क्या स्कैन पूरा होने से पहले लाइव डिफेंस काम करता है?

हाँ। लाइव डिफेंस लॉग और सत्र ईवेंट का उपयोग करता है। बेसलाइन स्कैन बाद में संदर्भ में सुधार करता है।

<a id="why-can-the-first-scan-take-a-long-time"></a>
## पहले स्कैन में लंबा समय क्यों लग सकता है?

पहला स्कैन बनता है world/object संदर्भ, फ़ाइल मैनिफ़ेस्ट, और पुन: प्रयोज्य बेसलाइन डेटा।

<a id="what-do-i-check-first-after-startup"></a>
## स्टार्टअप के बाद मैं सबसे पहले क्या जांचूं?

```text
runtime/current/poll_status.json
```

खोजें:

```text
scheduler_status=running
poll_id increasing
poll_in_flight=false
```

<a id="where-are-player-summaries"></a>
## खिलाड़ियों के सारांश कहां हैं?

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

<a id="where-is-the-daily-quick-review-package"></a>
## दैनिक त्वरित-समीक्षा पैकेज कहां है?

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

<a id="which-file-should-i-upload-for-fastest-review"></a>
## सबसे तेज़ समीक्षा के लिए मुझे कौन सी फ़ाइल अपलोड करनी चाहिए?

```text
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="can-it-write-bans-automatically"></a>
## क्या यह स्वचालित रूप से प्रतिबंध लिख सकता है?

केवल तभी जब स्पष्ट रूप से सक्षम किया गया हो।

डिफ़ॉल्ट:

```lua
review_only_mode = true
auto_ban = false
write_admin_ini = false
```

<a id="what-does-adminini-receive"></a>
## क्या करता है Admin.ini प्राप्त करें?

केवल:

```ini
BannedPlayer=<ID>
```

कोई नाम, टिप्पणी, कारण या प्रत्यय नहीं।

<a id="is-a-display-name-enough-to-ban"></a>
## क्या प्रदर्शन नाम प्रतिबंधित करने के लिए पर्याप्त है?

नहीं. सर्वर लॉग का उपयोग करें `Login request` `ConnectID` या समतुल्य सर्वर साक्ष्य।

<a id="can-one-crash-ban-someone"></a>
## क्या कोई किसी पर प्रतिबंध लगा सकता है?

डिफ़ॉल्ट रूप से नहीं।

<a id="can-object-count-alone-ban-someone"></a>
## क्या केवल ऑब्जेक्ट काउंट ही किसी को प्रतिबंधित कर सकता है?

डिफ़ॉल्ट रूप से नहीं।

<a id="should-savedroottxt-point-to-the-world-folder"></a>
## चाहिए SavedRoot.txt विश्व फ़ोल्डर की ओर इंगित करें?

नहीं. इसे `AbioticFactor/Saved`.

<a id="what-if-the-world-folder-changes"></a>
## यदि विश्व फ़ोल्डर बदल जाए तो क्या होगा?

इसे आधारभूत पहचान परिवर्तन के रूप में मानें। पुरानी आधार रेखा को सुरक्षित रखें और एक नई आधार रेखा का निर्माण करें।
