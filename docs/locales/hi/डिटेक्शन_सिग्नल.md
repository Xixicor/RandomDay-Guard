# डिटेक्शन सिग्नल

> **कैनोनिकल अंग्रेजी स्रोत:** [DETECTION_SIGNALS.md](../../DETECTION_SIGNALS.md). यह स्थानीयकृत दस्तावेज़ सटीक कमांड, पथ, कुंजियाँ, स्थिति मान, हैश और फ़ाइल नाम सुरक्षित रखता है। यदि तकनीकी शब्दांकन भिन्न है, तो अंग्रेजी स्रोत का उपयोग करें।


सिग्नल समीक्षा इनपुट हैं, स्वचालित आरोप नहीं।

<a id="signal-table"></a>
## सिग्नल तालिका

| सिग्नल | मतलब | जब मजबूत हो... | अपने आप में पर्याप्त नहीं है |
|---|---|---|---|
| लॉगिन पहचान | नाम को खाता आईडी से मैप करता है | ConnectID मौजूद है | प्रतिबंध |
| साफ छोड़ें | सामान्य सत्र समापन | शामिल हों और मैच छोड़ें | संदेह |
| रैपिड रीकनेक्ट | Churn/probing संदर्भ | जल्दी से दोहराया जाता है | प्रतिबंध |
| अस्वच्छ डिस्कनेक्ट | सत्र ठीक से बंद नहीं हुआ | क्रैश को दोहराता या ओवरलैप करता है | प्रतिबंध |
| क्रैश ओवरलैप | खाता क्रैश होने के निकट सक्रिय है | वही खाता दोहराया जाता है | प्रतिबंध |
| दुर्घटना के बाद वापसी | खाता पुनरारंभ होने के बाद वापस आ जाता है | युगों-युगों में दोहराया जाता है | एक घटना द्वारा प्रतिबंध |
| चेतावनी विस्फोट | सर्वर चेतावनी विंडो | मैप किए गए सत्रों को ओवरलैप करता है | एक विस्फोट से प्रतिबंध |
| एक्टर सेव टच | विश्व-सेव संदर्भ | सत्रों से संबंधित है | का प्रमाण use/theft |
| ऑब्जेक्ट डेल्टा | World/class परिवर्तन | सत्रों से संबंधित है | अकेले गिनती से प्रतिबंध |
| छापे का मामला | मल्टी-अकाउंट क्लस्टर | केंद्रीय खाता दोहराया जाता है | सभी खातों पर व्यापक प्रतिबंध |

<a id="login-identity"></a>
## लॉगिन पहचान

सर्वश्रेष्ठ स्रोत:

```text
Login request
Name=
ConnectID=
UniqueId=
```

मैप करने के लिए इसका उपयोग करें:

```text
display/log name -> account_id -> ban_id
```

<a id="rapid-reconnect"></a>
## रैपिड रीकनेक्ट

पैटर्न:

```text
join -> leave -> join -> leave -> join
```

दोहराए जाने पर समीक्षा के लिए उपयोग करें।

सुरक्षा:

```text
churn_alone_never_bans = true
```

<a id="crash-overlap-and-post-crash-return"></a>
## क्रैश ओवरलैप और क्रैश के बाद रिटर्न

पैटर्न:

```text
account active before crash
server restarts
same account returns quickly
```

युगों के दौरान दोहराए जाने पर समीक्षा के लिए उपयोग करें।

सुरक्षा:

```text
single_crash_never_bans = true
```

<a id="warning-bursts"></a>
## चेतावनी विस्फोट

उदाहरण:

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

मैप किए गए सत्रों और थ्रेशोल्ड से लिंक होने तक संदर्भ के रूप में उपयोग करें।

<a id="actor-save-touch"></a>
## एक्टर सेव टच

अर्थ:

```text
The server evidence referenced a class or actor.
```

मतलब नहीं:

```text
A player opened it.
A player stole from it.
A player duplicated through it.
A player damaged it.
```

<a id="raid-cases"></a>
## छापे के मामले

एक छापेमारी का मामला खातों को समय और साझा विंडो के आधार पर समूहित करता है।

नियम:

```text
Do not auto-ban every account in a raid case.
Each account needs account-specific evidence.
```
