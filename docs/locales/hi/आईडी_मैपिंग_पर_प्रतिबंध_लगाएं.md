# आईडी मैपिंग पर प्रतिबंध लगाएं

> **कैनोनिकल अंग्रेजी स्रोत:** [BAN_ID_MAPPING.md](../../BAN_ID_MAPPING.md). यह स्थानीयकृत दस्तावेज़ सटीक कमांड, पथ, कुंजियाँ, स्थिति मान, हैश और फ़ाइल नाम सुरक्षित रखता है। यदि तकनीकी शब्दांकन भिन्न है, तो अंग्रेजी स्रोत का उपयोग करें।


खिलाड़ी के नाम को सुरक्षित में परिवर्तित करते समय इस पृष्ठ का उपयोग करें `Admin.ini` प्रतिबंध रेखा।

<a id="core-rule"></a>
## मुख्य नियम

एक डिस्प्ले नाम एक प्रतिबंध आईडी नहीं है।

`Admin.ini` उपयोग करता है:

```ini
BannedPlayer=<raw numeric player ID>
```

<a id="evidence-hierarchy"></a>
## साक्ष्य पदानुक्रम

| रैंक | स्रोत | उपयोग करें |
|---:|---|---|
| 1 | सर्वर लॉग `Login request` | सर्वश्रेष्ठ नाम-से-आईडी मैपिंग |
| 2 | `Player_<ID>.sav` | पुष्टि करता है कि आईडी मौजूद है |
| 3 | मौजूदा `Admin.ini` | मौजूदा bans/moderators |
| 4 | बाहरी अधिसूचना या होस्टिंग-पैनल गतिविधि | Time/name केवल संदर्भ; आईडी प्रूफ नहीं |
| 5 | UE4SS focus/player पंक्तियाँ | Presence/context केवल |
| 6 | सिस्टम जीवनचक्र या कंटेनर लॉग | केवल होस्ट जीवनचक्र संदर्भ; आईडी प्रूफ नहीं |

<a id="extract-the-clean-id"></a>
## साफ आईडी निकालें

कच्चा उदाहरण:

```text
ConnectID=2535422284688820_+_|0002d07b...
```

साफ करें `Admin.ini` मान:

```ini
BannedPlayer=2535422284688820
```

पेस्ट न करें `_+_|...`.

<a id="verify-with-playerdata"></a>
##  PlayerData

इसके लिए जाँच करें:

```text
Saved/SaveGames/Server/Worlds/<WorldName>/PlayerData/Player_<ID>.sav
```

अर्थ:

```text
The ID exists in the world save.
```

सीमा:

```text
PlayerData may not prove the display name unless another source maps it.
```

<a id="when-not-to-ban"></a>
## कब प्रतिबंध नहीं लगाना चाहिए

प्रतिबंध आईडी निर्दिष्ट न करें जब:

```text
the name only appears in an external notification
the name only appears in hosting-panel activity
UE4SS shows a name but no ConnectID
only system lifecycle or container logs exist
the ID is trusted or moderator
```
