<a id="memory-economy-and-output-files"></a>
# मेमोरी इकोनॉमी और आउटपुट फ़ाइलें

> **कैनोनिकल अंग्रेजी स्रोत:** [MEMORY_ECONOMY_AND_OUTPUTS.md](../../MEMORY_ECONOMY_AND_OUTPUTS.md). यह स्थानीयकृत दस्तावेज़ सटीक कमांड, पथ, कुंजियाँ, स्थिति मान, हैश और फ़ाइल नाम सुरक्षित रखता है। यदि तकनीकी शब्दांकन भिन्न है, तो अंग्रेजी स्रोत का उपयोग करें।


यह पृष्ठ बताता है कि कौन सी फ़ाइलें बढ़ती हैं, कौन सी फ़ाइलें अधिलेखित हैं, और त्वरित समीक्षा के लिए क्या अपलोड करना है।

<a id="fast-answer"></a>
## त्वरित उत्तर

| प्रश्न | खोलें |
|---|---|
| क्या गार्ड जीवित है? | `runtime/current/poll_status.json` |
| किसको देखा गया? | `runtime/account_evidence.json` |
| सत्रों का क्या हुआ? | `runtime/evidence/session_events.jsonl` |
| आज क्या हुआ? | `runtime/forensic_days/YYYY-MM-DD/` |
| साधारण भाषा में सारांश क्या है? | `runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt` |
| स्कैन प्रगति क्या है? | `runtime/scan_progress.json` |
| विश्व संदर्भ क्या है? | `runtime/world_state/current/world_state_latest.json` |
| क्या प्रतिबंध लिखे गए थे? | `runtime/enforced_bans.jsonl` |

<a id="output-model"></a>
## आउटपुट मॉडल

| प्रकार | व्यवहार | उदाहरण |
|---|---|---|
| वर्तमान स्नैपशॉट | ओवरराइट | `runtime/current/*.json` |
| इवेंट लॉग | केवल-जोड़ें | `runtime/evidence/*.jsonl` |
| टेबल्स | अद्यतन या जोड़ा गया | `*.tsv` |
| बेसलाइन | पूरा होने के बाद पुन: उपयोग किया गया | `runtime/baselines/*` |
| दैनिक रोलअप | स्थान पर अपडेट किया गया | `runtime/forensic_days/YYYY-MM-DD/*` |
| अंतिम लॉग | सामान्य भाषा में दैनिक सारांश | `runtime/final_logs/YYYY-MM-DD/*` |

<a id="current-snapshots"></a>
## वर्तमान स्नैपशॉट

ये छोटे रहते हैं और उत्तर देते हैं "अभी क्या सच है।"

```text
runtime/current/poll_status.json
runtime/current/session_state.json
runtime/current/active_accounts.json
runtime/current/forensic_today.json
runtime/current/forensic_today.md
runtime/current/forensic_today.txt
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/world_state/current/world_state_latest.json
```

<a id="player-summaries"></a>
## खिलाड़ियों का सारांश

ये खाते की समीक्षा की जांच करने वाली पहली फ़ाइलें हैं।

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

वे संक्षेप में बताते हैं:

```text
account_id
ban_id
name
identity_confidence
first_seen
last_seen
join_count
leave_count
status
score
```

<a id="event-logs"></a>
## इवेंट लॉग

ये समयरेखा को सुरक्षित रखते हैं।

```text
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/warning_events.jsonl
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/evidence/live_defense_events.jsonl
```

<a id="daily-forensic-rollups"></a>
## दैनिक फोरेंसिक रोलअप

ये त्वरित अपलोड पैकेज हैं।

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

जब आप त्वरित अवधि विश्लेषण चाहते हैं तो उनमें से एक फ़ोल्डर अपलोड करें।

<a id="scan-and-baseline-files"></a>
## स्कैन और बेसलाइन फ़ाइलें

यह समझने के लिए इनका उपयोग करें कि विश्व संदर्भ आंशिक है या पूर्ण।

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/scan_complete.json
runtime/object_registry_partial.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
```

<a id="enforcement-files"></a>
## प्रवर्तन फ़ाइलें

इनका उपयोग केवल तभी करें जब प्रवर्तन सक्षम हो।

```text
runtime/enforced.txt
runtime/enforced_bans.jsonl
runtime/ban_queue.json
runtime/evidence/enforced_bans.jsonl
```

`Admin.ini` को केवल प्राप्त होना चाहिए:

```ini
BannedPlayer=<ID>
```

<a id="what-updates-when-a-player-joins"></a>
## जब कोई खिलाड़ी शामिल होता है तो क्या अपडेट होता है

अपेक्षित अपडेट:

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/current/session_state.json
runtime/forensic_days/YYYY-MM-DD/players.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="what-updates-when-the-server-crashes-or-restarts"></a>
## जब सर्वर क्रैश होता है या पुनरारंभ होता है तो क्या अपडेट होता है

अपेक्षित अपडेट:

```text
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/account_evidence.json
runtime/forensic_days/YYYY-MM-DD/crash_reconnects.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="what-updates-when-the-scan-progresses"></a>
## स्कैन आगे बढ़ने पर क्या अपडेट होता है

अपेक्षित अपडेट:

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/object_registry_partial.json
runtime/world_state/current/world_state_latest.json
runtime/forensic_days/YYYY-MM-DD/forensic_day_summary.json
```
