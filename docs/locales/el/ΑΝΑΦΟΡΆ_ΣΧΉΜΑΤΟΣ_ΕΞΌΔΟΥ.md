# Αναφορά σχήματος εξόδου και κατάστασης

> **Κανονική αγγλική πηγή:** [OUTPUT_SCHEMA_REFERENCE.md](../../OUTPUT_SCHEMA_REFERENCE.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Αυτή είναι η κανονική σύμβαση για τα δημιουργημένα αρχεία που αντιμετωπίζουν τον χειριστή. Μόνο κατέχει ακριβείς διαδρομές εξόδου, ονόματα πεδίων, επιτρεπόμενες τιμές, απαιτήσεις σειράς και σχήματα διαδρομής. Οι διαδικαστικοί οδηγοί συνδέονται εδώ αντί να επαναπροσδιορίζουν αυτά τα γεγονότα.

Τα στοιχεία χρόνου εκτέλεσης είναι έγκυρα. ένα όνομα αρχείου, ο καρδιακός παλμός προγραμματιστή, η μεταφρασμένη αναφορά ή το τοπικό αντικείμενο εξερχόμενων δεν αποδεικνύεται περισσότερα από τα δικά του πεδία και τη γενεαλογία του.

<a id="public-report-routes"></a>
## Διαδρομές δημόσιας αναφοράς

Ο εργαζόμενος αναφοράς κατέχει πέντε διαδρομές υπό `runtime/final_logs/`:

| Διαδρομή | Σύμβαση | `full` απαίτηση | Σημασία αναμενόμενου κενού |
|---|---|---|---|
| `server_status` | Τρέχουσα κατάσταση προγραμματιστή, ενεργού αρχείου καταγραφής, εκκρεμής σάρωσης και κάλυψης πηγής. | Τρέχον boot/epoch/poll γενεαλογία, νέο ενεργό αρχείο καταγραφής, accounting/history γράφει και το JSON/TXT ζεύγος. | Δεν χρησιμοποιείται για έναν κατά τα άλλα υγιή τρέχοντα κύκλο. η γενεαλογία που λείπει είναι `missing`. |
| `daily_rollup` | Τρέχον day/window συνέχεια σε διακομιστή, συσκευές αναπαραγωγής, θήκες, σάρωση και κάλυψη. | Το ιστορικό λογιστικό τερματικό επαρκεί για τη διαδρομή και την απόδειξη του τρέχοντος κύκλου. | Δεν υπάρχουν προγράμματα αναπαραγωγής που διατηρούνται και δεν υπάρχουν υποθέσεις αξιολόγησης. |
| `player_activity` | Διαχωρίστε το τρέχον και το ιστορικό player/account παρατηρήσεις. | Απόδειξη τρέχοντος κύκλου συν ένα ή περισσότερα current/historical σειρές. | Δεν υπάρχουν κατάλληλες σειρές αναπαραγωγής σε περιορισμένες εισόδους. χωρίς συνθετικό θέμα. |
| `case_review` | Ονομασμένες υποθέσεις και τρέχουσες review/BAN-ELIGIBLE υποψήφιοι. | Απόδειξη τρέχοντος κύκλου συν μία ή περισσότερες επώνυμες περιπτώσεις με αναφορές πηγής. | Καμία κατονομαζόμενη υπόθεση δεν πληρούσε τα κριτήρια ελέγχου. χωρίς συνθετική θήκη. |
| `critical_guard` | Αποτυχία προγραμματισμού τρέχουσας εκκίνησης, εκκίνησης, δημοσκόπησης ή ακεραιότητας αποδεικτικών στοιχείων. | Απόδειξη τρέχοντος κύκλου συν μια τρέχουσα κρίσιμη αποτυχία. | Δεν υπάρχει τρέχουσα κρίσιμη αποτυχία. Τα σφάλματα παλιού κειμένου δεν ανήκουν σε αυτήν τη διαδρομή. |

Κάθε ενεργοποιημένη διαδρομή γράφει `<route>_latest.json` και `<route>_latest.txt`. Το ζεύγος δεν έχει ολοκληρωθεί μέχρι `runtime/final_logs/route_proof.json` καταγράφει την ίδια έκδοση, εκκίνηση, εποχή, δημοσκόπηση και φρεσκάδα πηγής.

<a id="report-json-schema"></a>
## Αναφορά JSON σχήμα

Όλη η διαδρομή JSON χρησιμοποιεί `schema="randomdayguard.report/v1"`.

| Πεδίο | Πληκτρολογήστε | Σημασία και αμετάβλητο |
|---|---|---|
| `schema` | συμβολοσειρά | Ακριβώς `randomdayguard.report/v1`. |
| `generated_ts`, `report_date` | συμβολοσειρά | Χρονική σήμανση δημιουργίας και ημερομηνία αναφοράς. |
| `version` | συμβολοσειρά | Runtime/package ταυτότητα για αυτόν τον κύκλο. |
| `boot_id`, `epoch_id` | συμβολοσειρά | Εποχή εκκίνησης τρέχουσας διαδικασίας και συνέχειας διακομιστή. Απαιτούνται και τα δύο για την ολοκλήρωση. |
| `poll_id` | ακέραιος | Θετικό αναγνωριστικό τρέχουσας δημοσκόπησης. Zero/missing δεν μπορεί να ολοκληρώσει μια διαδρομή. |
| `source_freshness` | αντικείμενο | `status`, `checked_ts`, κατάσταση ενεργού καταγραφής, χρονική σήμανση τελευταίας δημοσκόπησης και χρονική σήμανση τελευταίας ολοκληρωμένης δημοσκόπησης. |
| `current_cycle_proof_complete` | boolean | Αληθής μόνο όταν η καταγωγή και είναι φρέσκο ​​active-log/current-poll αποδεικτικά στοιχεία συμφωνούν. |
| `route` | enum | Μία από τις πέντε παραπάνω διαδρομές. |
| `route_proof_status` | enum | `full`, `limited_expected_empty` ή `missing`. |
| `coverage_status` | enum | Ακριβώς `complete`, `complete_with_gaps`, `partial` ή `unavailable`. |
| `completed`, `expected_empty` | boolean | `completed` είναι ψευδές μόνο για `missing`; `expected_empty` ισχύει μόνο για `limited_expected_empty`. |
| `observed` | πίνακας συμβολοσειρών | Το σκυρόδεμα διατηρείται facts/counts/statuses. |
| `interpretation` | πίνακας συμβολοσειρών | Προληπτικό νόημα βαθμονομημένο στα αποδεικτικά στοιχεία. |
| `unknown` | πίνακας συμβολοσειρών | Λείπει ταυτότητα, ιστορικό, πηγή ή περιβάλλον. |
| `does_not_prove` | πίνακας συμβολοσειρών | Συμπεράσματα που τα στοιχεία δεν μπορούν να υποστηρίξουν. |
| `next_action` | συμβολοσειρά | Ενέργεια χειριστή με τον ασφαλέστερο περιορισμό. |
| `source_references` | πίνακας συμβολοσειρών | Μοναδική ταξινόμηση runtime/Saved αναφορές. |
| `enforcement_authority` | boolean | Πάντα ψευδής. Μια αναφορά δεν εξουσιοδοτεί ποτέ μια εγγραφή. |
| `output_paths` | δύο συμβολοσειρές | JSON και TXT μονοπάτια προστέθηκαν πριν από τη ζεύξη εγγραφών. |

`coverage_status` είναι μόνο λογιστική ανώτατου επιπέδου. Οι εγγραφές πηγής ανήκουν χωριστά `available`, `expected_empty`, `partial`, `deferred`, `unavailable`, `malformed`, `permission_denied` και `error`. Το Route proof κατέχει ξεχωριστά το `full`, `limited_expected_empty` και `missing`; Οι τιμές δεν ξεπερνούν ποτέ αυτά τα όρια.

Επεκτάσεις διαδρομής:

- `server_status`: `scheduler_status`, `active_log_status` και `server_metrics`. Οι μετρήσεις καταγράφουν την τρέχουσα έναρξη της εποχής, την τελευταία ολοκληρωμένη χρονική σήμανση δημοσκόπησης και το αναγνωριστικό, τον αριθμό ενεργών παικτών, active/backup-log μετράει, σάρωση pending/progress τιμές και configured/usable/unavailable λογιστική ομάδας πηγής. Δεν επινοούν χρόνο λειτουργίας, μετρήσεις επανεκκίνησης, εφεδρικές χρονικές σημάνσεις ή διάρκεια διακοπών όταν καμία πηγή δεν αποκαλύπτει αυτά τα γεγονότα.
- `player_activity`: `player_activity_present`, `movement`, `same_day_sessions`, `current_player_count`, `current_evidence_player_count`, `historical_player_count`, `historical_session_count`, `current_players`, `historical_players` και πίνακας συμβατότητας `players`. Κάθε αυθημερόν συνεδρία διατηρεί το αναγνωριστικό περιόδου σύνδεσης, το αναγνωριστικό λογαριασμού, το εμφανιζόμενο όνομα όταν είναι γνωστό, join/leave χρονικές σημάνσεις, σημαίες καθαρής εξόδου και κύκλου ζωής και αναφορές πηγών. Διατηρήθηκε η ταυτότητα και PlayerData η παρουσία παραμένει πλαίσιο, όχι απόδειξη δραστηριότητας σήμερα.
- `case_review`: `cases`, `review_subjects`, `current_case_count` και `retained_case_count`. Ένα τρέχον θέμα αξιολόγησης καταγράφει το case/account Αναγνωριστικό, εμφανιζόμενο όνομα όταν είναι γνωστό, κατάσταση, βαθμολογία, εμπιστοσύνη ταυτότητας, first/last παρατήρηση, πλήθος προειδοποιήσεων, λόγοι, τρέχουσα ζωντανή σημαία και αναφορές πηγής. Οι περιπτώσεις που διατηρούνται δεν δημιουργούν από μόνες τους τρέχον θέμα.
- `critical_guard`: `critical_failure_present` και `current_boot_error_only=true`.
- `daily_rollup`: `daily_maturity`, `once_per_day_continuity`, `dedupe_window` και `daily_metrics`. Οι μετρήσεις καταγράφουν την ημερομηνία αναφοράς, ενεργούς παίκτες, λογαριασμούς με δραστηριότητα αυθημερόν, συμμετοχές, αποχωρήσεις, καθαρές και ακάθαρτες εξόδους, επιστροφές κύκλου ζωής, τρέχοντα επώνυμα θέματα αξιολόγησης, διατηρούμενες υποθέσεις, current/retained μετρήσεις ταυτότητας και κάλυψη ομάδας πηγών.

<a id="translated-txt-schema"></a>
## Μετάφραση TXT σχήμα

Το ζευγοποιημένο αρχείο κειμένου οδηγεί με το αναγνώσιμο από τον χειριστή αποτέλεσμα και μετακινεί τις λεπτομέρειες της γενεαλογίας στο τέλος. Διατηρεί αυτήν ακριβώς τη σειρά ενότητας:

```text
RandomDayGuard <route title>
Generated: <timestamp>

Summary
<one plain-language route summary>

What Guard observed
- ...

What it means
- ...

What remains unknown
- ...

Recommended next step
...

Evidence boundary
- ...

Rating explanation
- ...

Technical record
- Route: <route>
- Version: <version>
- Cycle: boot=<boot> epoch=<epoch> poll=<poll>
- Source freshness: <status>
- Route result: <full|limited_expected_empty|missing>
- Coverage: <status>

Translation notes
- ...

Source references
- ...
```

Η μετάφραση χρησιμοποιεί μόνο τα πεδία δομημένης αναφοράς και εγκεκριμένες αντιστοιχίσεις λεξικού. Δεν μπορεί να προσθέσει παίκτες, περιπτώσεις, παράδοση, αιτιώδη συνάφεια, ιδιοκτησία, πρόθεση ή καταλληλότητα επιβολής που λείπουν από τη δομημένη αναφορά. Οι τεχνικές λεπτομέρειες παραμένουν διαθέσιμες χωρίς να μετατοπίζεται το αναγνώσιμο αποτέλεσμα.

<a id="source-accounting-schema"></a>
## Σχήμα λογιστικής πηγής

`runtime/final_logs/source_accounting_latest.json` χρησιμοποιεί `randomdayguard.source-accounting/v1` με δημιουργία reason/status, enablement/disabled λόγος, current/historical διάκριση, δήλωση αλλαγμένου αρχείου, εγγραφές πηγής, usable/unavailable λίστες τάξεων και ένα όριο αξίωσης.

Κάθε εγγραφή πηγής περιέχει:

| Πεδίο | Πληκτρολογήστε | Σημασία |
|---|---|---|
| `source_class` | συμβολοσειρά | Μία από τις οκτώ παρακάτω κατηγορίες. |
| `scope` | `current` ή `historical` | Ιδιοκτησία χρόνου. Τα πεδία δεν συγχωνεύονται ποτέ σιωπηλά. |
| `required` | boolean | Μόνο `active_log` απαιτείται για τη φρεσκάδα της διαδρομής του τρέχοντος κύκλου. |
| `status` | enum | Το αποτέλεσμα της πηγής παρατίθεται παρακάτω. |
| `terminal` | boolean | Λάθος μόνο για `partial` και `deferred`. |
| `available`, `readable` | boolean | Σωστό μόνο για `available` και `expected_empty`. |
| `file_count` | ακέραιος | Οριοθετημένη λογιστική file/reference μέτρηση. |
| `source_references` | πίνακας | Ταξινομημένη μοναδική πηγή paths/references. |
| `detail` | συμβολοσειρά | Οριοθετημένο αποτέλεσμα ή λεπτομέρεια σφάλματος. |
| `does_not_prove` | συμβολοσειρά | Η διαθεσιμότητα δεν αποτελεί απόδειξη πρόθεσης, ιδιοκτησίας, ζημιάς, αντιγραφής ή επιβολής. |

Τάξεις πηγής:

| Κλάση πηγής | Εύρος | Τι συνεισφέρει | Τι δεν μπορεί να αποδείξει |
|---|---|---|---|
| `active_log` | τρέχον, απαιτείται | Αναγνώσιμο ενεργό αρχείο καταγραφής διακομιστή και νέα σειρά δημοσκοπήσεων. | Πλήρης ιστορία ή ενοχή παίκτη. |
| `admin_ini` | τρέχον, προαιρετικό | Δομικά έγκυρο ρεύμα moderator/ban κατάσταση ή αναμενόμενη απουσία. | Συμπεριφορά του προγράμματος αναπαραγωγής ή έγκυρος λόγος μεταδεδομένων. |
| `recent_backup_logs` | ιστορικό | Ανάγνωση rotated/backup αναφορές καταγραφής. | Τρέχουσα παρουσία ή τρέχουσα κατάσταση εκκίνησης. |
| `playerdata_filenames` | τρέχον περιβάλλον | Οριοθετημένες αναγνώσιμες αναφορές ονόματος αρχείου κάτω από την επιλεγμένη Αποθηκευμένη ρίζα. | Ιδιοκτησία αρχείου, ζωντανή παρουσία, περιεχόμενο ταυτότητας ή κακή συμπεριφορά. |
| `existing_cases` | ιστορικό | Διατηρήθηκε ονομαστική υπόθεση files/index εγγραφές που καταγράφηκαν πριν από τις τρέχουσες εξόδους. | Τρέχουσα δραστηριότητα ή ορθότητα παλαιών συμπερασμάτων. |
| `existing_reports` | ιστορικό | Διατηρήθηκε final/forensic/warning αναφορές αναφοράς. | Αντικατάσταση έγκυρης πηγής. |
| `existing_evidence` | ιστορικό | Διατηρούμενες αναφορές αποδεικτικών στοιχείων. | Πληρότητα συμβάντων που ο διακομιστής δεν εξέθεσε ποτέ. |
| `world_save_scan` | ιστορικό | Πλήρης, μερική, αναβαλλόμενη ή μη διαθέσιμη περιορισμένη scan/checkpoint κατάσταση. | Ενέργεια ή ιδιοκτησία συγκεκριμένου παίκτη. |

Τιμές κατάστασης πηγής:

| Κατάσταση | Τερματικό | Σημασία και ενέργεια χειριστή |
|---|---:|---|
| `available` | ναι | Υπάρχει ευανάγνωστη χρήσιμη πηγή. ελέγξτε τις αναφορές του. |
| `expected_empty` | ναι | Ελέγχθηκε η προαιρετική πηγή και ήταν νόμιμα absent/empty. Μην εφευρίσκετε δεδομένα. |
| `partial` | όχι | Η περιορισμένη εργασία ή το όριο αποθέματος δεν έχει ολοκληρωθεί. επιτρέπεται η συνέχιση. |
| `deferred` | όχι | Η εργασία εκκρεμεί σκόπιμα. περιμένετε τον ιδιοκτήτη του εργάτη. |
| `unavailable` | ναι | Source/path/tool απουσιάζει ή δεν μπορεί να χρησιμοποιηθεί. επισκευάστε μόνο εάν χρειάζεται από τη διαδρομή. |
| `malformed` | ναι | Απέτυχε η δομική επικύρωση του περιεχομένου. διατηρήστε το και επιδιορθώστε τη μορφή. |
| `permission_denied` | ναι | Απαγορεύτηκε ρητά η πρόσβαση. επαναφέρετε την πρόσβαση ανάγνωσης ελάχιστων προνομίων. |
| `error` | ναι | Περιορισμένο σε επίπεδο πηγής probe/read απέτυχε απροσδόκητα. επιθεωρήστε `detail` χωρίς να αποκαλύπτονται μυστικά. |

Ανώτατο επίπεδο `coverage_status` είναι ακριβώς `complete`, `complete_with_gaps`, `partial` ή `unavailable`. Απαιτούμενο επίπεδο πηγής `error`, `malformed` ή `permission_denied` συγκεντρώνεται σε ανώτατο επίπεδο `unavailable`; επίπεδο πηγής `deferred` συγκεντρώνεται σε ανώτατο επίπεδο `partial`. Η απενεργοποίηση της λογιστικής πηγής εξακολουθεί να γράφει μια κατάσταση μη διαθέσιμη και αναγκάζει κάθε διαδρομή σε `missing`.

<a id="historical-status-schema"></a>
## Σχήμα ιστορικής κατάστασης

`runtime/final_logs/historical_backfill_latest.json` χρησιμοποιεί `randomdayguard.history/v1`: `generated_ts`, λογιστική `status`, `resumable=true`, `changed_file_refresh=true`, `current_evidence_is_not_history=true`, ο πίνακας προέλευσης-λογιστικής, μη διαθέσιμες κλάσεις και περιορισμένος `next_action`.

`runtime/history/public_accounts.tsv` είναι ανθεκτικό δημόσιο ιστορικό με αυτήν την κεφαλίδα:

```text
account_id	ban_id	display_name	identity_confidence	status	score	first_seen	last_seen	source_references
```

Οι σειρές ταξινομούνται κατά αναγνωριστικό λογαριασμού, τα πεδία είναι single-line/tab-safe και οι αναφορές είναι sorted/unique. Αυτό το αρχείο διατηρεί το ιστορικό πλαίσιο στις αθόρυβες επανεκκινήσεις. δεν μετατρέπει ποτέ την ιστορία σε τρέχουσα παρουσία.

<a id="route-proof-schema"></a>
## Σχήμα απόδειξης διαδρομής

`runtime/final_logs/route_proof.json` χρησιμοποιεί `randomdayguard.route-proof/v1` και καταγράφει χρονική σήμανση γενιάς ανώτατου επιπέδου, έκδοση, εκκίνηση, εποχή, δημοσκόπηση, φρεσκάδα πηγής, πληρότητα τρέχοντος κύκλου, επιτρεπόμενες καταστάσεις και `routes` πίνακας.

Κάθε καταχώρηση διαδρομής περιέχει route/status, version/boot/epoch/poll, αντικείμενο φρεσκάδας πηγής, πληρότητα τρέχοντος κύκλου, διαδρομές εξόδου και αναφορές πηγής. Μια απενεργοποιημένη διαδρομή καταγράφει `status="missing"` και `reason="route_disabled"`. Εάν αποτύχει η εγγραφή με προστασία διαδρομής, κάθε διαδρομή ξαναγράφεται ως incomplete/missing πριν γίνει αποδεκτή οποιαδήποτε υποψήφια ειδοποίηση.

<a id="notification-schemas"></a>
## Σχήματα ειδοποιήσεων

Η προαιρετική δημόσια λειτουργία είναι μόνο τα εξερχόμενα τοπικά αρχεία.

`runtime/notifications/pending/<route>_latest.json` χρησιμοποιεί `randomdayguard.notification/v1` με δημιουργημένη χρονική σήμανση, version/boot/epoch/ poll/source φρεσκάδα, διαδρομή, `completed_output`, κατάσταση ασφαλούς διαδρομής, δομημένες και μεταφρασμένες διαδρομές αναφοράς, αναφορές πηγών, `delivery_backend="none"` και `delivery_attempted=false`. Κατάλληλες χρήσεις εξόδου `status="ready_for_local_consumer"`, `delivery_eligible=true` και `delivery_allowed=true`. Ένα ρυθμισμένο αλλά missing/ineligible εξακολουθεί να γράφει έναν φάκελο ελέγχου με `status="suppressed_current_cycle"`, και οι δύο σημαίες παράδοσης είναι ψευδείς και `suppression_reason="route_or_completion_policy_blocked"`. Επομένως η παρουσία ενός αρχείου κάτω από το `pending/` δεν σημαίνει από μόνο του ότι βρίσκεται στην ουρά ή είναι κατάλληλο.

`runtime/notifications/notification_status.json` χρησιμοποιεί `randomdayguard.notification-status/v1` με την ίδια καταγωγή, `generic_local_outbox_only=true`, `delivery_attempted=false` και ανά διαδρομή `queued`/`outcome` σειρές. `full` είναι κατάλληλο. Το αναμενόμενη-κενό είναι κατάλληλο μόνο όταν `include_expected_empty=true`; `missing` δεν είναι ποτέ κατάλληλο. Σε μια αποτυχία εγγραφής χωρίς διαδρομή, το αποτέλεσμα κατάστασης είναι `route_proof_write_failed`; μπορεί να εξακολουθεί να γράφεται ένας κλειστός φάκελος ελέγχου, αλλά δεν γίνεται αποδεκτός ως έξοδος.

## Απόθεμα εξόδου χρόνου εκτέλεσης

Το ευρετήριο ιχνηλασιμότητας έχει μία σειρά μηχανής για κάθε διαδρομή ή κλάση δυναμικού αρχείου. Αυτό το ευανάγνωστο απόθεμα ομαδοποιεί αρχεία κατά σκοπό χειριστή.

| Διαδρομή ή μοτίβο | Producer/trigger | Πολιτική και χρήσιμες καταστάσεις | Failure/recovery |
|---|---|---|---|
| `runtime/loader_probe.txt`, `runtime/loader_probe.json` | Εισαγωγή φορτωτή. | Αντικατάσταση εκκίνησης identity/probe. | Λείπει δεν αποδεικνύει φόρτωση. επιθεωρήστε UE4SS αρχεία καταγραφής και ενεργοποίηση. |
| `runtime/config_load_error.txt` | Αποτυχία φόρτωσης διαμόρφωσης. | Μόνο σφάλμα, διατηρεί την περιορισμένη αιτία. | Επαναφέρετε τις έγκυρες δημόσιες ρυθμίσεις παραμέτρων και κάντε επανεκκίνηση. |
| `runtime/saved_path_probe.json` | Αποθηκευμένη ανάλυση ρίζας. | Candidate/readability λογιστική. | Ορισμός `SavedRoot.txt` ή επιδιορθώστε ένα γενικό υποψήφιο. |
| `runtime/startup_status.json`, `runtime/startup_error.txt`, `runtime/current/startup_error.json` | Κύκλος ζωής εκκίνησης. | Σφάλμα τελευταίας εκκίνησης και τρέχουσας εκκίνησης. | Μόνο η αντίστοιχη εκκίνηση ανήκει στην τρέχουσα κρίσιμη κατάσταση. |
| `runtime/runtime_version.json`, `runtime/runtime_capabilities.json`, `runtime/public_pipeline_status.json` | Startup/report ενσωμάτωση. | Τελευταία version/capability/handoff κατάσταση. | Το drift έκδοσης ή ικανότητας αποκλείει τις αξιώσεις ολοκλήρωσης. |
| `runtime/poll_status.json`, `runtime/current/poll_status.json`, `runtime/poll_error.txt`, `runtime/current/poll_error.json` | Δημοσκόπηση finalizer/error. | Τελευταία poll/scheduler/in-flight σφάλμα κατάστασης και τρέχουσας εκκίνησης. | Επισκευάστε την οριοθετημένη επανάκληση και απαιτήστε μια νεότερη ολοκληρωμένη δημοσκόπηση. |
| `runtime/logs/current.jsonl`, `runtime/raw_events.jsonl` | Καταγραφή συμβάντων. | Οριοθετημένο append/rotation. | Διατήρηση προηγούμενων byte. επισκευή disk/retention πριν βασιστείτε σε κενά. |
| `runtime/log_offsets.tsv`, `runtime/log_registry.json` | Αρχείο καταγραφής tail/registry. | Τελευταίες μετατοπίσεις και κανονικές ταυτότητες καταγραφής. | Ανακατασκευάστε προσεκτικά. Τα αρχεία καταγραφής αντιγράφων ασφαλείας παραμένουν ιστορικά. |
| `runtime/log_continuity_events.jsonl`, `runtime/evidence/log_continuity_events.jsonl`, `runtime/server_lifecycle_events.jsonl`, `runtime/evidence/lifecycle_events.jsonl` | Continuity/lifecycle κανονικοποιητής. | Περιεχόμενο μόνο για προσθήκη. | Το περιεχόμενο που λείπει δεν μπορεί να αποδειχθεί graceful/crash κατάσταση. |
| `runtime/current_server_epoch.json`, `runtime/server_epochs.jsonl`, `runtime/epochs/**` | Κάτοχος εποχής. | Τρέχουσες και διατηρημένες εποχές διακομιστή. | Ξεκινήστε μια νέα εποχή μετά την επισκευή. μην ξαναγράψετε την παλιά ιστορία. |
| `runtime/session_events.tsv`, `runtime/evidence/session_events.jsonl`, `runtime/sessions/**` | Κάτοχος περιόδου σύνδεσης. | Current/historical συμβάντα περιόδου σύνδεσης και στιγμιότυπα. | Οι μη αντιστοιχισμένες σειρές παραμένουν άγνωστες. καμία εφεύρεση ταυτότητας. |
| `runtime/account_evidence.tsv`, `runtime/account_evidence.json`, `runtime/history/public_accounts.tsv` | Account/session ενότητα συγκέντρωσης και αναφοράς. | Τρέχον στιγμιότυπο και ανθεκτικό ιστορικό. | Διατηρήστε τα πεδία χωριστά και επαναφέρετε από στοιχεία, όχι εικασίες. |
| `runtime/current/session_state.json`, `runtime/current/active_accounts.json`, `runtime/current/spatial_context.json`, `runtime/current/actor_touch_rollup.json` | Poll/current-state συγγραφείς. | Αντικαταστάθηκαν τρέχοντα στιγμιότυπα. | Stale/missing είναι άγνωστο, δεν αναμένεται κενό. |
| `runtime/days/**`, `runtime/weeks/**` | Daily/weekly συγκέντρωση. | Επανοικοδομήσιμα ευρετήρια. | Ανακατασκευή από έγκυρα συμβάντα. |
| `runtime/scan_started.json`, `runtime/scan_progress.json`, `runtime/scan_checkpoint.json`, `runtime/scan_complete.json`, `runtime/scan_error.txt` | Εργάτης σάρωσης. | Ξεκίνησε, partial/deferred, σημείο ελέγχου, ολοκλήρωση ή σφάλμα. | Σημείο ελέγχου συνέχισης. ανακατασκευή μόνο με καταγεγραμμένο λόγο. |
| `runtime/baselines/last_scan.json`, `runtime/baselines/last_completed_baseline.json`, `runtime/baselines/file_manifest.tsv` | Εργαζόμενος βασικής γραμμής. | Τελευταία scan/baseline και δέσμευση αλλαγμένου αρχείου. | Stale/incompatible απαιτούν ρητή ανακατασκευή. |
| `runtime/object_registry_partial.json`, `runtime/object_registry_counts_partial.tsv`, `runtime/object_registry.json`, `runtime/object_registry_counts.tsv` | Σάρωση αντικειμένων. | Partial/final περιβάλλον τάξης. | Οι μετρήσεις δεν αποδεικνύουν τη δράση του παίκτη. συνέχιση ή ανοικοδόμηση σάρωσης. |
| `runtime/new_classes_detected.jsonl`, `runtime/class_deltas.jsonl` | Σύγκριση αντικειμένων. | Μόνο προσάρτημα new/delta πλαίσιο. | Έλεγχος mapping/baseline πριν από το συμπέρασμα. |
| `runtime/playerdata_index.json`, `runtime/admin_state.json` | Αποθηκευμένα ευρετήρια ρίζας. | Filename/admin πλαίσιο δομής. | Τα ονόματα αρχείων είναι αδύναμα. λανθασμένη μορφή διαχειριστή κλείνει εγγραφές. |
| `runtime/world_state/boot/**`, `runtime/world_state/current/world_state_latest.json`, `runtime/world_state/sessions/**` | Συγγραφέας παγκόσμιας πολιτείας. | Boot/current/session στιγμιότυπα και διαφορές. | Μόνο περιεχόμενο. αναγέννηση μετά από scan/source επισκευή. |
| `runtime/warning_events.jsonl`, `runtime/warnings/**`, `runtime/evidence/critical_events.jsonl`, `runtime/evidence/high_events.jsonl`, `runtime/evidence/medium_events.jsonl` | Warning/evidence συγγραφείς. | Περιορισμένο προσάρτημα και per-player/session ελέγξτε τα αρχεία. | Η αναφορά που λείπει δεν είναι απόδειξη συμβάντος που λείπει. επιθεωρήστε αποδεικτικά στοιχεία πηγής. |
| `runtime/raid_cases/**`, `runtime/raid_cases/index.jsonl`, `runtime/ban_queue.json` | Case/review συγκέντρωση. | Ονομασμένο υλικό κριτικής και υποψήφιοι ουράς. | Υπόθεση membership/threshold δεν παρακάμπτει ποτέ τις πύλες για συγκεκριμένο λογαριασμό. |
| `runtime/backups/Admin_*.ini`, `runtime/enforced.txt`, `runtime/enforced_bans.jsonl`, `runtime/evidence/enforced_bans.jsonl`, `runtime/evidence/enforcement_failed_*` | Προαιρετικό Admin.ini συναλλαγή. | Δημιουργία αντιγράφων ασφαλείας, βιβλίο επιτυχίας ή ρητή failure/rollback αποδεικτικά στοιχεία. | Οποιαδήποτε backup/write/readback/rollback η αποτυχία κλείνει την επιβολή. επαναφορά αντιγράφων ασφαλείας. |
| `runtime/request_restart.flag`, `runtime/restart_reason.json` | Προαιρετικό πρόγραμμα εγγραφής δείκτη. | Μόνο τοπικό αίτημα. | Δεν αποδεικνύει κατανάλωση ή επανεκκίνηση. |
| `runtime/current/forensic_today.json`, `.md`, `.txt`, `runtime/forensic_days/YYYY-MM-DD/**`, `runtime/final_logs/YYYY-MM-DD/**` | Σύλληψη εγκληματολογίας. | Τρέχοντα και χρονολογημένα ευρετήρια αναθεώρησης με δυνατότητα ανακατασκευής. | Ανακατασκευή από στοιχεία πηγής. Μην αντιμετωπίζετε ποτέ τη σύνοψη ως αρχή. |
| `runtime/final_logs/source_accounting_latest.json`, `historical_backfill_latest.json`, `<route>_latest.json`, `<route>_latest.txt`, `route_proof.json` | Εργαζόμενος δημόσιας αναφοράς. | Σχήματα και κανόνες ολοκλήρωσης παραπάνω. | Επισκευή πρώτης ασυμφωνίας lineage/source/write; λείπει παραμένει. |
| `runtime/notifications/pending/<route>_latest.json`, `runtime/notifications/notification_status.json` | Προαιρετικά τοπικά εξερχόμενα. | Κατάλληλος ή ρητά αποκλεισμένος τοπικός φάκελος συν κατάσταση. | Missing/ineligible μπορεί να έχουν αποθηκευμένα αρχεία, αλλά δεν βρίσκονται ποτέ στην ουρά. Επιθεωρήστε τις σημαίες παράδοσης και συμπεράστε ότι δεν υπάρχει εξωτερική παράδοση. |

Overwrite/append/retention ελέγχεται από την ενότητα παραγωγής στο [`CONFIG_FIELD_CATALOG.md`](%CE%9A%CE%91%CE%A4%CE%86%CE%9B%CE%9F%CE%93%CE%9F%CE%A3_%CE%A0%CE%95%CE%94%CE%8A%CE%A9%CE%9D_%CE%94%CE%99%CE%91%CE%9C%CE%8C%CE%A1%CE%A6%CE%A9%CE%A3%CE%97%CE%A3.md). Τα ZIP των πακέτων περιέχουν μόνο κενά `.gitkeep` σύμβολα κράτησης θέσης στην περιοχή `runtime/`; οποιαδήποτε evidence/output byte σε ένα πακέτο έκδοσης αποτυγχάνει.

<a id="failure-and-recovery-matrix"></a>
## Πίνακας αποτυχίας και ανάκτησης

| Αποτυχία | Απαιτούμενη κατάσταση | Ασφαλής ανάκτηση | Μη έγκυρο συμπέρασμα |
|---|---|---|---|
| Τρέχουσα καταγωγή absent/stale | Όλες οι διαδρομές `missing`. | Επαναφορά active-log/current-poll απόδειξη και αναγέννηση. | Τα παλιά αρχεία διαδρομής δεν έχουν ολοκληρωθεί. |
| Η προαιρετική πηγή αναμένεται κενή | Πηγή `expected_empty`; η κατάλληλη διαδρομή μπορεί να είναι `limited_expected_empty`. | Καμία επιδιόρθωση εκτός εάν πρέπει να υπάρχει η πηγή. | Το κενό δεν είναι διαθέσιμο και δεν αποδεικνύει ιστορική απουσία. |
| Η σάρωση δεν ολοκληρώθηκε | Πηγή `partial` ή `deferred`. | Να επιτρέπεται το περιορισμένο βιογραφικό. διατηρήστε σαφή την τρέχουσα πολιτική διαδρομής. | Η μερική δεν είναι καταστροφή. |
| Η απαιτούμενη πηγή δεν είναι διαθέσιμη | `coverage_status=unavailable`; εξαρτώμενες διαδρομές `missing`. | Επισκευή επιλεγμένης Saved/log πρόσβαση. | Άλλες υγιείς πηγές δεν αντικαθιστούν την απαιτούμενη πηγή. |
| Απαιτούμενα σφάλματα ανιχνευτή πηγής | Κατάσταση πηγής `error` με περιορισμένο `detail`; `coverage_status=unavailable`; εξαρτώμενες διαδρομές `missing`. | Επισκευάστε το όνομα source/probe και δημιουργήστε έναν νεότερο κύκλο. | Ένα σφάλμα προέλευσης δεν είναι τιμή κάλυψης πέμπτου ανώτατου επιπέδου. |
| Αποτυχία εγγραφής ζευγαρωμένης αναφοράς | `coverage_status=unavailable`; η διαδρομή συγκλίνει σε `missing`. | Επισκευάστε το σύστημα αρχείων και ξαναγράψτε και τα δύο μέλη του ζεύγους συν την απόδειξη. | Το αρχείο ενός αδελφού δεν ολοκληρώνεται και η αποτυχία εγγραφής δεν είναι ανώτατου επιπέδου `error`. |
| Αποτυχία εγγραφής με προστασία διαδρομής | Λείπει κάθε διαδρομή που έχει ξαναγραφτεί. δεν υπάρχει κατάλληλη αποστολή. Οι διαμορφωμένες διαδρομές ενδέχεται να λαμβάνουν κλειστούς φακέλους ελέγχου. | Επιδιορθώστε την εγγραφή χωρίς διαδρομή και ανανεώστε εξόδους ίδιου κύκλου. | Έγκυρη αναφορά JSON ή ένας αποθηκευμένος φάκελος δεν είναι ασφαλής για τη διαδρομή. |
| Αποτυχία εγγραφής ειδοποίησης | Αποτέλεσμα `local_outbox_write_failed`. | Επισκευή τοπικής ρίζας εξόδου. αναδημιουργία από την ολοκληρωμένη αναφορά. | Δεν πραγματοποιήθηκε εξωτερική παράδοση. |
| Admin.ini η συναλλαγή αποτυγχάνει | Η επιβολή αποκλείστηκε με backup/write/readback/rollback αποδεικτικά στοιχεία. | Επαναφορά επαληθευμένου αντιγράφου ασφαλείας. παραμένουν μόνο για έλεγχο. | Ένα όριο ή μια αναφορά δεν μπορεί να δικαιολογήσει την παράκαμψη της ανάκτησης. |
