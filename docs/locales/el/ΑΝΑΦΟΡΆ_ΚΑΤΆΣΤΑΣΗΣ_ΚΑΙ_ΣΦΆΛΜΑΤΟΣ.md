# Αναφορά κατάστασης και σφάλματος

> **Κανονική αγγλική πηγή:** [STATUS_AND_ERROR_REFERENCE.md](../../STATUS_AND_ERROR_REFERENCE.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Χρησιμοποιήστε αυτήν την αναφορά αφού ένα σύμπτωμα έχει ταξινομηθεί σε [Αντιμετώπιση προβλημάτων](%CE%91%CE%9D%CE%A4%CE%99%CE%9C%CE%95%CE%A4%CE%8F%CE%A0%CE%99%CE%A3%CE%97_%CE%A0%CE%A1%CE%9F%CE%92%CE%9B%CE%97%CE%9C%CE%86%CE%A4%CE%A9%CE%9D.md). Διαβάστε το δομημένο αρχείο κατάστασης που ονομάστηκε από το σφάλμα. Οι διακριτοί κωδικοί αντιπροσωπεύουν διακριτές καταστάσεις ασφάλειας και κύκλου ζωής. Μην τα συμπτύξετε σε ένα γενικό αποτέλεσμα "Η φύλαξη απέτυχε".

<a id="route-and-source-states"></a>
## Καταστάσεις διαδρομής και πηγής

| Τιμή | Σημασία | Απόκριση χειριστή |
|---|---|---|
| `full` | Η σύμβαση διαδρομής ολοκληρώθηκε με απόδειξη πηγής τρέχοντος κύκλου. | Διαβάστε το όριο αποδεικτικών στοιχείων της διαδρομής. δεν υπονοείται καμία επισκευή. |
| `limited_expected_empty` | Η διαδρομή ολοκληρώθηκε και η δραστηριότητα που λείπει είναι νόμιμη για αυτόν τον κύκλο. | Χωρίς συνθετικό player/case συμβάν. |
| `missing` | Δεν υπάρχει υποχρεωτική έξοδος, πεδίο γενεαλογίας ή απόδειξη πηγής. | Επιθεωρήστε την αιτία της διαδρομής και την κατάσταση της ονομασμένης πηγής. |
| `available` | Η ονομαζόμενη πηγή ήταν αναγνώσιμη και χρησιμοποιήσιμη. | Καμία ενέργεια. |
| `expected_empty` | Η πηγή ελέγχθηκε και νόμιμα δεν είχε σειρές. | Καμία ενέργεια εκτός και αν αναμενόταν ανεξάρτητη δραστηριότητα. |
| `partial` / `complete_with_gaps` | Υπάρχουν αποδεικτικά στοιχεία που μπορούν να χρησιμοποιηθούν, αλλά οι ονομασμένες κατηγορίες πηγών είναι ελλιπείς. | Περιορίστε τα συμπεράσματα στα συλλεγμένα στοιχεία. |
| `deferred` | Η περιορισμένη εργασία έχει προγραμματιστεί για μια μεταγενέστερη ευκαιρία εργαζομένου. | Επιβεβαιώστε την πρόοδο προόδου πριν αλλάξετε τη διαμόρφωση. |
| `unavailable` | Το περιβάλλον δεν παρείχε την πηγή. | Καταγράψτε το όριο. διορθώστε μόνο ένα αποδεδειγμένο πρόβλημα διαδρομής ή άδειας. |
| `malformed` | Η πηγή ήταν αναγνώσιμη αλλά απέτυχε η δομική επικύρωση. | Διατηρήστε το και διορθώστε την πηγή. μην μαντέψετε. |
| `permission_denied` | Η πηγή υπάρχει αλλά δεν ήταν δυνατή η ανάγνωση. | Εκχωρήστε μόνο τη στενή απαιτούμενη άδεια ανάγνωσης. |
| `error` | Η συλλογή απέτυχε για τον καταγεγραμμένο λόγο. | Διατηρήστε το σφάλμα και διαγνώστε αυτό το στάδιο. |

<a id="playerdata-and-inventory-codes"></a>
## PlayerData και κωδικοί αποθέματος

| Κωδικός | Σημασία | Ασφαλής απάντηση |
|---|---|---|
| `saved_root_unavailable` | Καμία επαληθευμένη αποθηκευμένη ρίζα δεν ήταν διαθέσιμη στη δημόσια διοχέτευση. | Σωστό `SavedRoot.txt` και ελέγξτε ξανά τον ανιχνευτή διαδρομής. |
| `unsafe_playerdata_root` | PlayerData επιλύθηκε εκτός της περιορισμένης Αποθηκευμένης ρίζας. | Διορθώστε τη διαδρομή. Μην αποδυναμώνετε ποτέ τα όρια. |
| `playerdata_discovery_not_run` | Το οριοθετημένο εργαλείο εντοπισμού δεν έχει τρέξει ακόμα. | Ελέγξτε την πρόοδο του προγραμματιστή και του εργαζόμενου. |
| `playerdata_discovery_read_failed:*` | Δεν ήταν δυνατή η ανάγνωση της εξόδου Discovery. | Διατηρήστε τη λεπτομέρεια του επιθήματος και επαληθεύστε την εντολή περιορισμένου αποθέματος. |
| `inventory_command_open_failed` | Δεν ήταν δυνατή η έναρξη της διαδικασίας απογραφής. | Επαληθεύστε ότι ο χρόνος εκτέλεσης παρέχει τη διαμορφωμένη γέφυρα εντολών. |
| `inventory_command_read_failed` | Η έξοδος του αποθέματος απέτυχε κατά την ανάγνωση. | Διατηρήστε τη μερική έξοδο και εκτελέστε ξανά μόνο αφού διορθωθεί το υποκείμενο σφάλμα. |
| `inventory_command_close_failed` | Το απόθεμα ολοκληρώθηκε χωρίς ένα αξιόπιστο αποτέλεσμα κλεισίματος. | Θεωρήστε την πηγή ως ελλιπή. |
| `identity_ledger_row_limit_exceeded` | Η είσοδος ανθεκτικής ταυτότητας υπερέβη τα όρια δημόσιας ασφάλειας. | Αρχειοθετήστε και ελέγξτε το καθολικό. μην το περικόψετε σιωπηλά σε πλήρη απόδειξη. |

<a id="adminini-enforcement-codes"></a>
## Admin.ini κωδικοί επιβολής

Όλοι οι κωδικοί σε αυτήν την ενότητα έχουν κλείσει λόγω αποτυχίας. Δεν εξουσιοδοτούν τη μη αυτόματη απαγόρευση από μόνα τους.

| Κωδικός | Σημασία | Ασφαλής απάντηση |
|---|---|---|
| `admin_ini_write_disabled` / `admin_ini_disabled` | Οι πύλες εγγραφής με ασφάλεια για το κοινό είναι απενεργοποιημένες. | Αναμένεται σε λειτουργία μόνο για έλεγχο. |
| `admin_ini_backup_disabled` / `backup_safety_gate_disabled` | Η απαιτούμενη πολιτική δημιουργίας αντιγράφων ασφαλείας δεν είναι ενεργή. | Διατηρήστε τις εγγραφές απενεργοποιημένες. |
| `enforcement_disabled` / `ban_on_threshold_disabled` / `auto_ban_disabled` | Μία ρητή πύλη επιβολής είναι απενεργοποιημένη. | Αναμένεται σε προεπιλογές μόνο για δημόσιο έλεγχο. μην το ερμηνεύσετε ξανά ως αποτυχία εγγραφής. |
| `review_only_mode_enabled` | Η λειτουργία μόνο για έλεγχο αποκλείει σκόπιμα τη μετάλλαξη. | Ελέγξτε μόνο αποδεικτικά στοιχεία. |
| `duplicate_prevention_disabled` | Η διπλότυπη προστασία απενεργοποιήθηκε. | Διατηρήστε τις εγγραφές απενεργοποιημένες μέχρι να αποκατασταθεί η πύλη ασφαλείας. |
| `readback_safety_gate_disabled` / `rollback_safety_gate_disabled` | Η επαλήθευση μετά την εγγραφή ή η προστασία επαναφοράς απενεργοποιήθηκε. | Διατηρήστε τις εγγραφές απενεργοποιημένες. ποτέ μην προσπερνάτε αυτές τις πύλες. |
| `clean_id_safety_gate_disabled` / `account_specific_evidence_gate_disabled` | Η επιβολή καθαρής ταυτότητας ή αποδεικτικών στοιχείων για συγκεκριμένο λογαριασμό απενεργοποιήθηκε. | Επαναφέρετε την πύλη πριν από οποιαδήποτε δοκιμή επιβολής. |
| `moderator_preservation_disabled` / `existing_ban_preservation_disabled` | Η διατήρηση προστατευμένου λογαριασμού ή υπάρχουσας απαγόρευσης απενεργοποιήθηκε. | Διατηρήστε τις εγγραφές απενεργοποιημένες. |
| `clean_numeric_identity_required` | Το προτεινόμενο αναγνωριστικό δεν είναι η πλήρης αποδεκτή φόρμα σύνδεσης ή το καθαρό αριθμητικό αναγνωριστικό. | Λάβετε μια επαληθευμένη αντιστοίχιση. ποτέ μην περικόψετε ένα αυθαίρετο πρόθεμα. |
| `identity_strength_below_minimum` | Τα στοιχεία ταυτότητας είναι πιο αδύναμα από το διαμορφωμένο όριο. | Ελέγξτε μόνο αποδεικτικά στοιχεία. |
| `playerdata_verification_required` | Η διαμόρφωση απαιτεί PlayerData επιβεβαίωση και ο λογαριασμός δεν την έχει. | Διατήρηση του υποψηφίου για έλεγχο μόνο. μην συναγάγετε την ιδιοκτησία από ένα όνομα αρχείου. |
| `trusted_or_moderator_identity` | Ο λογαριασμός προστατεύεται από κατάσταση αξιόπιστου ή επόπτη. | Δεν επιτρέπεται η εγγραφή. |
| `admin_ini_path_invalid` / `admin_ini_path_outside_saved_root` | Η διαδρομή προορισμού δεν είναι έγκυρη ή ξεφεύγει από την Αποθηκευμένη ρίζα. | Σωστή διαμόρφωση. ποτέ μην παρακάμπτετε το προστατευτικό μονοπατιού. |
| `admin_ini_unavailable` | Δεν έχει διαμορφωθεί δυνατότητα ανάγνωσης Admin.ini βρέθηκε μέσα στην Αποθηκευμένη ρίζα. | Διορθώστε την οριοθετημένη διαδρομή ή διατηρήστε την επιβολή απενεργοποιημένη. |
| `admin_ini_read_failed` | Δεν ήταν δυνατή η ανάγνωση των έγκυρων byte. | Διακοπή πριν από τη μετάλλαξη. |
| `admin_ini_parse_failed` | Admin.ini απέτυχε χωρίς πιο συγκεκριμένο δομικό κώδικα. | Διατηρήστε το αρχείο και επιθεωρήστε τη δομή ενότητας και γραμμής. |
| `admin_ini_contains_nul` | Το αρχείο περιέχει NUL byte και δεν γίνεται αποδεκτό ως κείμενο. | Διατηρήστε το αρχείο και επιδιορθώστε το εκτός του Guard. |
| `admin_ini_duplicate_banned_players_section` | Περισσότερα από ένα `[BannedPlayers]`. | Συγχώνευση ενοτήτων με μη αυτόματο τρόπο ενώ έχει διακοπεί. |
| `admin_ini_banned_player_outside_section` | Μια σειρά απαγόρευσης εμφανίζεται έξω από το `[BannedPlayers]`. | Διορθώστε τη διάταξη με μη αυτόματο τρόπο. |
| `admin_ini_invalid_banned_player_line` | Μια γραμμή αποκλεισμού δεν είναι ακριβώς μια καθαρή υποστηριζόμενη σειρά αναγνωριστικών. | Διορθώστε τη γραμμή με λανθασμένη μορφή. |
| `admin_ini_backup_failed` | Το μοναδικό αντίγραφο ασφαλείας δεν εγγράφηκε και δεν αναγνώστηκε το byte με τον ίδιο τρόπο. | Δεν επιτρέπεται καμία μετάλλαξη. |
| `admin_ini_external_change_detected` | Ένας άλλος συγγραφέας άλλαξε το αρχείο μετά το στιγμιότυπο του Guard. | Διατηρήστε τα εξωτερικά byte και δοκιμάστε ξανά μόνο αφού συντονίσετε τους συντάκτες. |
| `atomic_rename_unavailable` | Ζητήθηκε η ατομική αντικατάσταση αλλά ο Lua δεν παρείχε `os.rename`. | Καμία εγγραφή δεν είναι αξιόπιστη. χρησιμοποιήστε έναν υποστηριζόμενο χρόνο εκτέλεσης ή διατηρήστε την επιβολή απενεργοποιημένη. |
| `admin_ini_write_failed` | Η ελεγχόμενη αντικατάσταση δεν ολοκληρώθηκε. | Επιθεωρήστε το καταγεγραμμένο σφάλμα αντικατάστασης και δημιουργία αντιγράφων ασφαλείας. |
| `post_write_verification_failed` | Τα byte παραγωγής δεν ισοδυναμούσαν με τον υποψήφιο. | Έλεγχος `rollback_success` και `rollback_refused_external_change` πριν από οποιαδήποτε ενέργεια. |

<a id="startup-scheduler-and-backlog-states"></a>
## Καταστάσεις εκκίνησης, χρονοπρογραμματισμού και ανεκτέλεσης

Αυτές οι τιμές είναι απόδειξη κύκλου ζωής, όχι απόδειξη διαδρομής. Διαβάστε τα με τρέχοντα αρχεία δημοσκόπησης, εργαζομένου αναφοράς και απαραίτητων δρομολογίων.

| Τιμή | Σημασία | Ασφαλής απάντηση |
|---|---|---|
| `not_started` | Το στάδιο εκκίνησης ή προγραμματισμού με το όνομα δεν έχει ξεκινήσει. | Κατά την εκκίνηση, περιμένετε για το τεκμηριωμένο διάστημα. στη συνέχεια επιθεωρήστε την πρώτη αμετάβλητη φάση. |
| `main_lua_loaded` / `starting` | Ο κανονικός φορτωτής έτρεξε και το Guard μπήκε στην εκκίνηση. | Συνέχεια σε μεταγενέστερες φάσεις. Αυτό από μόνο του δεν είναι ετοιμότητα. |
| `saved_root_found` / `log_tail_initialized` / `epoch_started` | Η προετοιμασία της βασικής πηγής και της συνέχειας έχει προχωρήσει. | Καμία ενέργεια εκτός εάν σταματήσει να προχωρά η επόμενη φάση. |
| `admin_state_written` / `playerdata_index_written` | Έγιναν εξαγωγή αρχικών περιορισμένων ευρετηρίων. | Καμία ενέργεια. Η μεταβίβαση προγραμματιστή πρέπει να συνεχίσει να ακολουθεί. |
| `watchdog_started` | Η ομάδα παρακολούθησης αναφορών και δημοσκοπήσεων καταχωρήθηκε. | Επιβεβαιώστε τον προγραμματιστή και την πρόοδο της δημοσκόπησης στη συνέχεια. |
| `ready_degraded` / `scan_running` | Η φύλαξη εκτελείται ενώ η περιορισμένη σάρωση ιστορικού παραμένει σε εκκρεμότητα. | Προσοχή, όχι αποτυχία. επαληθεύστε εκ των προτέρων τους μετρητές προόδου. |
| `ready` | Η εκκίνηση και η τρέχουσα οριοθετημένη σάρωση έφτασε σε κατάσταση ετοιμότητας. | Ελέγξτε την απόδειξη διαδρομής ξεχωριστά. |
| `scan_failed` / `error` | Η εκκίνηση ή η σάρωση τερματίστηκε με καταγεγραμμένο σφάλμα. | Διατηρήστε το όνομα του αρχείου σφάλματος ή κατάστασης και κάντε διάγνωση αυτού του σταδίου. |
| `running` | Ο προγραμματιστής διαθέτει μελλοντικές ευκαιρίες δημοσκόπησης. | Επιβεβαίωση `poll_id` και `poll_completed_count` εκ των προτέρων. |
| `manual_only` | Ο προγραμματισμός βρόχου δεν ήταν διαθέσιμος. μόνο ρητή εργασία μπορεί να εκτελεστεί. | Θεωρήστε τη λειτουργία χωρίς επίβλεψη ως μη διαθέσιμη. |
| `stopped` | Η λειτουργία χρονοπρογραμματιστή έληξε. | Επιθεωρήστε την προηγούμενη ένδειξη στάσης και σφάλματος πριν από την επανεκκίνηση. |
| `active_log_caught_up` | Δεν υπάρχει μη αναγνωσμένο ανεκτέλεστο ενεργό αρχείο καταγραφής. | Η σάρωση ιστορικού ενδέχεται να συνεχιστεί. |
| `active_log_unavailable_nonblocking` | Το ενεργό αρχείο καταγραφής απουσίαζε, αλλά η εκκίνηση παρέμεινε μη αποκλεισμένη. | Καταγράψτε το όριο πηγής και επαληθεύστε άλλες πηγές. |
| `active_log_read_failed` | Το ενεργό αρχείο καταγραφής υπήρχε αλλά δεν ήταν δυνατή η ανάγνωση. | Διατηρήστε το σφάλμα και διορθώστε μόνο την αποδεδειγμένη διαδρομή ή το πρόβλημα άδειας. |
| `budget_exhausted` / `active_log_has_unread_bytes` | Το δεσμευμένο ουραίο πάσο σταμάτησε με το ανεκτέλεστο υπόλοιπο. | Επιβεβαιώστε ότι οι μετέπειτα δημοσκοπήσεις μειώνουν τον αριθμό των μη αναγνωσμένων. |
| `offset_commit_failed_after_events_applied` | Τα συμβάντα υποβλήθηκαν σε επεξεργασία αλλά η διαρκής μετατόπιση του αρχείου καταγραφής απέτυχε. | Η επιβολή αναβάλλεται. επιδιορθώστε την αποθήκευση offset πριν βασιστείτε σε άλλο κύκλο. |

<a id="scheduler-report-and-notification-codes"></a>
## Κωδικοί προγραμματιστή, αναφοράς και ειδοποιήσεων

| Κωδικός ή κατάσταση | Σημασία | Ασφαλής απάντηση |
|---|---|---|
| `poll already in flight` | Έφτασε μια δεύτερη επανάκληση ενώ η τρέχουσα δημοσκόπηση κατείχε τον κύκλο ζωής. | Επιβεβαιώστε τις υπάρχουσες προόδους δημοσκόπησης. μην προσθέσετε άλλον κάτοχο βρόχου. |
| `no_log_files_found` | Δεν βρέθηκε διαμορφωμένο ενεργό ή εφεδρικό αρχείο καταγραφής. | Επαληθεύστε τη διαμόρφωση αποθηκευμένης ρίζας και πηγής. |
| `current_poll_error` | Ο τρέχων κύκλος κατέγραψε μια αποτυχία πηγής δημοσκόπησης. | Διαβάστε `runtime/current/poll_error.json`. |
| `cadence_deferred` | Ο διεκπεραιωτής ολοκλήρωσης δεν έχει ολοκληρωθεί ακόμη. | Αναμένεται μέχρι την επόμενη περιορισμένη ευκαιρία. |
| `reports_disabled` | Η δημιουργία δημόσιας αναφοράς είναι απενεργοποιημένη. | Ενεργοποίηση μόνο εάν πρόκειται για αναφορές. |
| `local_outbox_write_failed` | Δεν ήταν δυνατή η εγγραφή μεταφρασμένου τοπικού φακέλου. | Επισκευή του καταλόγου εξόδου χρόνου εκτέλεσης. αυτό δεν είναι σφάλμα μεταφοράς ειδοποίησης. |
| `source_accounting_disabled` | Η απόδειξη διαδρομής δεν μπορεί να διεκδικήσει πλήρη κάλυψη πηγής. | Ενεργοποιήστε τη λογιστική πηγή ή αποδεχτείτε ρητά την απόδειξη που λείπει. |
| `route_disabled` | Η διαδρομή είναι σκόπιμα απενεργοποιημένη. | Δεν αναμένεται παράδοση για αυτήν τη διαδρομή. |
| `poll_owner_between_polls` | Ο εργαζόμενος στην αναφορά βρίσκεται στην ουρά για το κενό που ανήκει στον προγραμματιστή μεταξύ των δημοσκοπήσεων. | Αναμένεται μόνο όταν οι χρονικές σημάνσεις και οι δρομείς συνεχίζουν να προχωρούν. |
| `unsafe_shell_path` | Ένα περιορισμένο απόθεμα ή διαδρομή κελύφους απέτυχε στην επικύρωση ασφαλούς πλατφόρμας. | Διορθώστε τη διαδρομή. Μην αποδυναμώνετε ποτέ την επικύρωση παραθέσεων ή διαδρομής. |
