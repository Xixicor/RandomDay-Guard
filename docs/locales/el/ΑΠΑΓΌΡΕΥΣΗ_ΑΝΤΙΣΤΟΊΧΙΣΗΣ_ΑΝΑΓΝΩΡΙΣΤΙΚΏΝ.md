# Απαγόρευση αντιστοίχισης αναγνωριστικών

> **Κανονική αγγλική πηγή:** [BAN_ID_MAPPING.md](../../BAN_ID_MAPPING.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Χρησιμοποιήστε αυτήν τη σελίδα κατά τη μετατροπή ενός ονόματος παίκτη σε χρηματοκιβώτιο `Admin.ini` γραμμή απαγόρευσης.

<a id="core-rule"></a>
## Βασικός κανόνας

Το εμφανιζόμενο όνομα δεν είναι αναγνωριστικό απαγόρευσης.

`Admin.ini` χρησιμοποιεί:

```ini
BannedPlayer=<raw numeric player ID>
```

<a id="evidence-hierarchy"></a>
## Ιεραρχία αποδεικτικών στοιχείων

| Κατάταξη | Πηγή | Χρήση |
|---:|---|---|
| 1 | Αρχείο καταγραφής διακομιστή `Login request` | Η καλύτερη αντιστοίχιση ονόματος σε αναγνωριστικό |
| 2 | `Player_<ID>.sav` | Επιβεβαιώνει την ύπαρξη αναγνωριστικού |
| 3 | Υπάρχον `Admin.ini` | Υπάρχον bans/moderators |
| 4 | Εξωτερική ειδοποίηση ή δραστηριότητα του πίνακα φιλοξενίας | Time/name μόνο πλαίσιο. όχι απόδειξη ταυτότητας |
| 5 | UE4SS focus/player γραμμές | Presence/context |
| 6 | Κύκλος ζωής συστήματος ή αρχεία καταγραφής κοντέινερ | Μόνο περιβάλλον κύκλου ζωής κεντρικού υπολογιστή. όχι απόδειξη ταυτότητας |

<a id="extract-the-clean-id"></a>
## Εξαγωγή του καθαρού αναγνωριστικού

Ακατέργαστο παράδειγμα:

```text
ConnectID=2535422284688820_+_|0002d07b...
```

Καθαρισμός `Admin.ini` τιμή:

```ini
BannedPlayer=2535422284688820
```

Μην επικολλήσετε `_+_|...`.

<a id="verify-with-playerdata"></a>
## Επαλήθευση με PlayerData

Έλεγχος για:

```text
Saved/SaveGames/Server/Worlds/<WorldName>/PlayerData/Player_<ID>.sav
```

Σημασία:

```text
The ID exists in the world save.
```

Περιορισμός:

```text
PlayerData may not prove the display name unless another source maps it.
```

<a id="when-not-to-ban"></a>
## Πότε να μην απαγορεύεται

Μην εκχωρείτε αναγνωριστικό αποκλεισμού όταν:

```text
the name only appears in an external notification
the name only appears in hosting-panel activity
UE4SS shows a name but no ConnectID
only system lifecycle or container logs exist
the ID is trusted or moderator
```
