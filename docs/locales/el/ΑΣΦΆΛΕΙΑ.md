# Πολιτική ασφαλείας

> **Κανονική αγγλική πηγή:** [SECURITY.md](../../../SECURITY.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


<a id="report-a-vulnerability-privately"></a>
## Αναφορά μιας ευπάθειας ιδιωτικά

Χρησιμοποιήστε [GitHub ιδιωτική αναφορά ευπάθειας](https://github.com/Xixicor/RandomDay-Guard/security/advisories/new) για να στείλετε μια εμπιστευτική αναφορά στον κάτοχο του αποθετηρίου. Εάν αυτή η φόρμα δεν είναι διαθέσιμη, χρησιμοποιήστε το [δημόσιο του κατόχου GitHub προφίλ](https://github.com/Xixicor) για να ζητήσετε ένα ιδιωτικό κανάλι επαφής χωρίς να συμπεριλάβετε λεπτομέρειες ευπάθειας.

Μην ανοίγετε δημόσιο ζήτημα που περιέχει βήματα εκμετάλλευσης, διαπιστευτήρια, διαδρομές ιδιωτικών διακομιστών, αναγνωριστικά προγράμματος αναπαραγωγής, `Admin.ini`, Αποθηκευμένα δεδομένα, διευθύνσεις URL webhook ή αρχεία ζωντανών αποδεικτικών στοιχείων.

<a id="include-useful-evidence"></a>
## Συμπεριλάβετε χρήσιμα στοιχεία

Παρέχετε:

- το επηρεασμένο RandomDayGuard έκδοση ή δέσμευση;
- το στοιχείο που επηρεάζεται και η αναμενόμενη ασφαλής συμπεριφορά;
- ελάχιστα βήματα αναπαραγωγής με χρήση απολυμαντικών συσκευών.
- ο παρατηρούμενος αντίκτυπος και αν είναι επαναλαμβανόμενος. και
- οποιοσδήποτε προτεινόμενος μετριασμός που δεν εκθέτει προσωπικά δεδομένα.

Μην στέλνετε πραγματικά μυστικά. Αντικαταστήστε τις ιδιωτικές διαδρομές, τα αναγνωριστικά λογαριασμού, τα ονόματα κεντρικών υπολογιστών και τα διακριτικά με σαφή σύμβολα κράτησης θέσης, διατηρώντας παράλληλα τη δομή που απαιτείται για την αναπαραγωγή του ζητήματος.

<a id="expect-review-first-handling"></a>
## Αναμένεται χειρισμός πρώτου ελέγχου

Μια αναφορά είναι απόδειξη για έλεγχο από τον συντηρητή, όχι εξουσιοδότηση για πρόσβαση σε διακομιστή, δοκιμή ζωντανού στόχου, δημοσίευση λεπτομερειών εκμετάλλευσης ή αποδυνάμωση των προεπιλογών που έχουν κλείσει λόγω αποτυχίας. Ο κάτοχος θα επικυρώσει το εύρος και θα συντονίσει οποιαδήποτε αποκάλυψη μέσω της ιδιωτικής αναφοράς.
