# Προφίλ διαμόρφωσης

> **Κανονική αγγλική πηγή:** [CONFIG_PROFILES.md](../../CONFIG_PROFILES.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Χρησιμοποιήστε αυτόν τον οδηγό για να επιλέξετε και να εφαρμόσετε ένα πρακτικό προφίλ διαμόρφωσης. Για μια εξήγηση του τρόπου αλληλεπίδρασης των ομάδων ρυθμίσεων, διαβάστε το [`CONFIG_REFERENCE.md`](%CE%91%CE%9D%CE%91%CE%A6%CE%9F%CE%A1%CE%86_%CE%94%CE%99%CE%91%CE%9C%CE%8C%CE%A1%CE%A6%CE%A9%CE%A3%CE%97%CE%A3.md). Για ακριβή πεδία, προεπιλογές, τύπους και αμετάβλητα, χρησιμοποιήστε το [`CONFIG_FIELD_CATALOG.md`](%CE%9A%CE%91%CE%A4%CE%86%CE%9B%CE%9F%CE%93%CE%9F%CE%A3_%CE%A0%CE%95%CE%94%CE%8A%CE%A9%CE%9D_%CE%94%CE%99%CE%91%CE%9C%CE%8C%CE%A1%CE%A6%CE%A9%CE%A3%CE%97%CE%A3.md).

Κάθε μπλοκ Lua παρακάτω είναι ένα σύνολο από καταχωρήσεις ανώτατου επιπέδου που μπορούν να αντικαταστήσουν τις αντίστοιχες καταχωρήσεις εντός του αποσταλμένου `return { ... }` πίνακας.

<a id="profile-chooser"></a>
## Επιλογέας προφίλ

| Κατάσταση | Χρησιμοποιήστε αυτό το προφίλ |
|---|---|
| Πρώτη εγκατάσταση | Ασφαλής πρώτη εγκατάσταση |
| Ο διακομιστής είναι ασταθής και διακόπτεται συχνά | Τρέχοντα στοιχεία χωρίς αργή σάρωση |
| Θέλετε object/world πλαίσιο | Πλήρης γραμμή βάσης |
| Θέλετε να ελέγξετε τα παλιά αρχεία καταγραφής | Διαδικαστική συμπλήρωση |
| Θέλετε προτάσεις αλλά όχι εγγραφές | Δοκιμή επιβολής |
| Είστε έτοιμοι να αφήσετε τον φύλακα να γράψει απαγορεύσεις | Ενεργοποιήθηκε η επιβολή |
| Ο δίσκος είναι περιορισμένος | Χαμηλή ανάπτυξη δίσκου |
| Ολοκληρώσατε μια καθαρή γραμμή βάσης | Ρύθμιση σταθερής δημιουργίας αντιγράφων ασφαλείας |

<a id="safe-first-install"></a>
## Ασφαλής πρώτη εγκατάσταση

Χρησιμοποιήστε αυτό πρώτα σε ζωντανό διακομιστή.

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

log_tail = {
    enabled = true,
    start_at_end_on_first_run = true,
    tail_backup_logs = false,
},

scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

Τι κάνει αυτό:

```text
Tracks live sessions.
Starts the baseline scan.
Does not edit Admin.ini.
Avoids treating old backup logs as fresh live events.
```

<a id="current-evidence-without-slow-scan"></a>
## Τρέχοντα στοιχεία χωρίς αργή σάρωση

Χρησιμοποιήστε αυτό εάν ο διακομιστής είναι ασταθής και χρειάζεστε crash/reconnect στοιχεία πριν από μια βαριά σάρωση.

```lua
log_tail = {
    enabled = true,
},

scanning = {
    full_scan_on_start = false,
},

enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},

reports = {
    enabled = true,
},

notification = {
    enabled = false,
},
```

Τι κάνει αυτό:

```text
Tracks logins, joins, leaves, reconnects, crashes, and unclean sessions.
Delays heavy world scanning.
```

<a id="full-baseline"></a>
## Πλήρης γραμμή βάσης

Χρησιμοποιήστε το αφού ο διακομιστής μπορεί να παραμείνει σε λειτουργία αρκετό καιρό για σάρωση.

```lua
scanning = {
    full_scan_on_start = true,
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
},
```

Τι κάνει αυτό:

```text
Builds object registry.
Writes world-state context.
Creates file manifest.
Enables changed-file refresh later.
```

<a id="forensic-backfill"></a>
## Διαδικαστική συμπλήρωση

Χρησιμοποιήστε αυτό μόνο όταν ελέγχετε σκόπιμα αρχεία καταγραφής ιστορικού.

```lua
log_tail = {
    start_at_end_on_first_run = false,
    tail_backup_logs = true,
    backfill_backup_logs_on_start = true,
},
```

Πριν τη χρησιμοποιήσετε:

```text
Back up runtime/log_offsets.tsv.
Expect old events to be reprocessed.
Return to live settings when finished.
```

<a id="enforcement-testing"></a>
## Δοκιμή επιβολής

Χρησιμοποιήστε το πριν από την πραγματική Admin.ini γραφή.

```lua
enforcement = {
    review_only_mode = true,
    auto_ban = false,
    write_admin_ini = false,
},
```

Τι πρέπει να επιθεωρήσετε:

```text
runtime/account_evidence.json
runtime/warnings/
runtime/forensic_days/YYYY-MM-DD/ban_recommendations.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="enforcement-enabled"></a>
## Ενεργοποιήθηκε η επιβολή

Χρησιμοποιήστε το μόνο αφού η έξοδος ελέγχου είναι σωστή.

```lua
enforcement = {
    review_only_mode = false,
    auto_ban = true,
    write_admin_ini = true,
    require_clean_ban_id = true,
    preserve_existing_bans = true,
    preserve_moderators = true,
},
```

Πριν από την ενεργοποίηση:

```text
Trusted IDs are configured.
Moderator IDs are preserved.
Admin.ini backups work.
Ban recommendations are understandable.
Thresholds are accepted by the server owner.
```

<a id="low-disk-growth"></a>
## Χαμηλή ανάπτυξη δίσκου

Χρησιμοποιήστε το όταν τα αρχεία χρόνου εκτέλεσης μεγαλώνουν πολύ γρήγορα.

```lua
logging = {
    low_importance_mode = "aggregate",
    write_low_importance_raw_events = false,
},

retention = {
    detailed_retention_days = 7,
    rotate_jsonl_when_bytes_exceed = 5242880,
    max_raw_events_lines = 20000,
    compact_json_outputs = true,
},
```

<a id="sticky-backup-setup"></a>
## Ρύθμιση σταθερής δημιουργίας αντιγράφων ασφαλείας

Χρήση μετά την πρώτη ολοκληρωμένη γραμμή βάσης.

Βεβαιωθείτε ότι υπάρχουν:

```text
runtime/scan_complete.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
runtime/world_state/current/world_state_latest.json
```

Στη συνέχεια δημιουργήστε αντίγραφα ασφαλείας με `config.lua`, `SavedRoot.txt` και `Admin.ini`.
