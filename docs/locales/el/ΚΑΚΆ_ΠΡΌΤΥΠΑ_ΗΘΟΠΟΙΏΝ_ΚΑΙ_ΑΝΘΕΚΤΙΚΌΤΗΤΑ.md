# Μοτίβα κακών ηθοποιών και ανθεκτικότητα

> **Κανονική αγγλική πηγή:** [BAD_ACTOR_PATTERNS_AND_RESILIENCE.md](../../BAD_ACTOR_PATTERNS_AND_RESILIENCE.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Χρησιμοποιήστε αυτήν τη σελίδα για να κατανοήσετε πώς ο φύλακας βοηθά στον έλεγχο της κατάχρησης σφαλμάτων, της συμπεριφοράς παρακείμενης εκμετάλλευσης και του σχεδιασμού ανάκτησης.

<a id="what-the-guard-can-help-with"></a>
## Σε τι μπορεί να βοηθήσει ο φύλακας

| Μοτίβο | Τι να ελέγξετε |
|---|---|
| Επιστροφές που σχετίζονται με σφάλματα | Ο ίδιος λογαριασμός είναι ενεργός πριν από τις διακοπές λειτουργίας και επιστρέφει μετά την επανεκκίνηση |
| Διερεύνηση ταχείας επανασύνδεσης | Επανάληψη join/leave ή timeout/reconnect βρόχοι |
| Συμπλέγματα πολλών λογαριασμών | Συμμετοχή σε waves, κοινόχρηστα παράθυρα προειδοποίησης, κοινόχρηστα παράθυρα αποτυχίας |
| Προειδοποιητικό στρες έκρηξης | Επανάληψη ActorChannelFailure ή παράθυρα προειδοποίησης αποθήκευσης |
| Περιβάλλον εκτός ορίων | PlayerData/map/world περιβάλλον όταν είναι αναγνώσιμο |
| Επικάλυψη αποθήκευσης-αγγίγματος | Αλληλεπικαλυπτόμενες αντιστοιχισμένες συνεδρίες περιβάλλοντος εξοικονόμησης κόσμου |
| Σύγχυση ταυτότητας | Ονόματα που χρειάζονται αντιστοίχιση ConnectID |

<a id="why-it-avoids-memory-access"></a>
## Γιατί αποφεύγει την πρόσβαση στη μνήμη

RandomDayGuard λειτουργεί από αρχεία που ανήκουν σε διακομιστή:

```text
Saved/Logs/*.log
Admin.ini
World saves
PlayerData
Backups
runtime evidence
```

Αυτό το καθιστά λιγότερο εξαρτημένο από την κατάσταση της μνήμης στην πλευρά του πελάτη και λιγότερο εύθραυστο στις ενημερώσεις του παιχνιδιού.

Εμπορία:

```text
It cannot prove hidden live actions unless the server writes evidence.
```

<a id="crash-correlated-returners"></a>
## Επιστροφές που σχετίζονται με σφάλματα

Μοτίβο:

```text
Account joins.
Server crashes or restarts.
Same account reconnects quickly.
Pattern repeats.
```

Χρήσιμα αρχεία:

```text
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/account_evidence.json
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="rapid-reconnect-probers"></a>
## Εξερευνητές ταχείας επανασύνδεσης

Μοτίβο:

```text
join -> leave -> join -> leave -> join
```

Χρήσιμα αρχεία:

```text
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/account_evidence.json
runtime/forensic_days/YYYY-MM-DD/players.tsv
```

<a id="multi-account-clusters"></a>
## Συμπλέγματα πολλών λογαριασμών

Μοτίβο:

```text
Several accounts join in the same window.
Warnings or crashes follow.
Some accounts rotate or reconnect after restart.
```

Χρήσιμα αρχεία:

```text
runtime/raid_cases/
runtime/forensic_days/YYYY-MM-DD/raid_cases.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

Κανόνας:

```text
A cluster is not a mass-ban list.
Each account still needs its own evidence.
```

<a id="sticky-backup-recommendation"></a>
## Συστατική πρόταση δημιουργίας αντιγράφων ασφαλείας

Δημιουργήστε ένα αυτοκόλλητο αντίγραφο ασφαλείας μετά:

```text
first full baseline completes
object_registry.json exists
file_manifest.tsv exists
world_state_latest.json has scan_complete=true
Admin.ini is verified
trusted IDs are configured
```

Δημιουργία αντιγράφων ασφαλείας:

```text
RandomDayGuard/config.lua
RandomDayGuard/SavedRoot.txt
RandomDayGuard/runtime/baselines/
RandomDayGuard/runtime/object_registry.json
RandomDayGuard/runtime/world_state/current/world_state_latest.json
Saved/SaveGames/Server/Admin.ini
```

<a id="recovery-model"></a>
## Μοντέλο ανάκτησης

```text
Clean install
-> verify live defense
-> complete first baseline
-> create sticky backup
-> run server normally
-> use daily rollups for review
-> restore sticky backup if needed
```
