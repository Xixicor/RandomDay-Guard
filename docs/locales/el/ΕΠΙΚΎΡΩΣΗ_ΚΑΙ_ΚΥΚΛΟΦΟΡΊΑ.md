# Επικύρωση και κυκλοφορία

> **Κανονική αγγλική πηγή:** [VALIDATION_AND_RELEASE.md](../../VALIDATION_AND_RELEASE.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Αυτή η σελίδα προορίζεται για συνεισφέροντες και συντηρητές εκδόσεων. Οι χειριστές διακομιστών δεν χρειάζεται να εκτελούν αυτές τις εντολές για να εγκαταστήσουν RandomDayGuard.

<a id="user-visible-proof"></a>
## Απόδειξη ορατή από το χρήστη

Μια έκδοση είναι κατανοητή όταν ένας νέος χειριστής μπορεί να την εγκαταστήσει, να βρει την πρώτη αναφορά κατάστασης διακομιστή, να διακρίνει τις πέντε διαδρομές αναφοράς και να ακολουθήσει μια σαφή ενέργεια από ένα επεξεργασμένο παράδειγμα. Οι εργασίες αναγνώστη δεν πρέπει να απαιτούν γνώσεις Git, PowerShell, Python ή αθροίσματος ελέγχου.

<a id="contributor-checks"></a>
## Έλεγχοι συνεργατών

```powershell
python -B tools/validate_repo.py
python -B tools/test_public_pipeline.py
python -B -m unittest discover tests
```

Όταν `luac` είναι διαθέσιμο:

```powershell
luac -p RandomDayGuard/Scripts/main.lua
luac -p RandomDayGuard/Scripts/public_pipeline.lua
```

Οι δοκιμές επισκευής Lua καλύπτουν τον φορτωτή, τον προγραμματιστή, τις διαδρομές αναφοράς και προαιρετικά Admin.ini εγγραφή συναλλαγής. Τα προγράμματα επιβολής χρησιμοποιούν μόνο προσωρινά αρχεία και επαληθεύουν την ταυτότητα, την απόρριψη αξιόπιστου λογαριασμού, τα όρια, τη δημιουργία αντιγράφων ασφαλείας, την άρνηση ταυτόχρονης αλλαγής, την επιστροφή και την επαναφορά.

<a id="package-proof"></a>
## Απόδειξη πακέτου

```powershell
python -B tools/build_release_zip.py --check
git diff --check
```

- Όλοι οι δείκτες έκδοσης ταιριάζουν με `VERSION`.
- Μόνο η τρέχουσα έκδοση υπάρχει στο `releases/`.
- Το ZIP περιέχει τα κανονικά `RandomDayGuard/Scripts/main.lua` διαδρομή και χωρίς φόρτωση παραλλαγής πεζών.
- Η έξοδος χρόνου εκτέλεσης, η ιδιωτική διαμόρφωση, τα διαπιστευτήρια, οι τοπικές διαδρομές, οι κρυφές μνήμες και τα τεχνουργήματα δοκιμής εξαιρούνται.
- Η δημόσια διαμόρφωση παραμένει μόνο έλεγχος με την επιβολή απενεργοποιημένη.
- Τα παραδείγματα των πέντε επεξεργασμένων αναφορών εξακολουθούν να συνάδουν με την ιδιοκτησία διαδρομής και το πρόγραμμα δοκιμής κυκλοφορίας.
- ZIP byte είναι ντετερμινιστικά και ταιριάζουν με `CHECKSUMS.sha256`.
- Όλοι οι σύνδεσμοι τοπικής τεκμηρίωσης και οι 27 σελίδες καταχώρισης τοπικών ρυθμίσεων επικυρώνονται.

<a id="avoid-validation-environment-pitfalls"></a>
## Αποφύγετε τις παγίδες του περιβάλλοντος επικύρωσης

- Εκτελέστε σειριακά ελέγχους εγγραφής αποθετηρίου για να αποφύγετε τη διαμάχη για προσωρινά αρχεία.
- Στα Windows, επιθεωρήστε τα αρχειοθετημένα ονόματα μελών ή την απαριθμημένη ορθογραφία διαδρομής αντί για αναζήτηση αρχείων χωρίς διάκριση πεζών-κεφαλαίων κατά τον έλεγχο για διπλότυπα προγράμματα φόρτωσης.
- Λείπει `luac` ή ο χρόνος εκτέλεσης Lua είναι μια μη διαθέσιμη δυνατότητα, όχι μια επιτυχής σύνταξη ή δοκιμή χρόνου εκτέλεσης.
- Ένα εξάρτημα αποδεικνύει μόνο τις μοντελοποιημένες εισόδους του. Δεν αποδεικνύει ότι ένας ζωντανός διακομιστής παρήγαγε μια τρέχουσα αναφορά.
- Καταγράψτε τα χρονικά όρια εντολών και τη μερική έξοδο αντί να υποθέσετε την ολοκλήρωση.

<a id="repair-failed-repository-validation"></a>
## Επισκευή αποτυχημένης επικύρωσης χώρου αποθήκευσης

Ξεκινήστε με την πρώτη διαδρομή ή σύμβαση που αναφέρθηκε. Διορθώστε αυτό το αντικείμενο, εκτελέστε ξανά τη στενή δοκιμή και, στη συνέχεια, εκτελέστε ξανά τον πλήρη πίνακα. Μην αποκρύψετε μια δυνατότητα που λείπει αφαιρώντας τη δοκιμή που την απαιτεί.

<a id="known-limits-and-release-decision"></a>
## Γνωστά όρια και απόφαση έκδοσης

Οι τοπικοί έλεγχοι αποδεικνύουν συμβάσεις προέλευσης, εξοπλισμού, πακέτου και τεκμηρίωσης. Μια συγκεκριμένη εγκατάσταση διακομιστή, μακροχρόνιο παράθυρο σταθερότητας ή εμφάνιση πελάτη απαιτεί ξεχωριστό αποτέλεσμα ενοποίησης. Καταγράψτε αυτό το αποτέλεσμα με την κατασκευή, τη διαμόρφωση, τη διάρκεια και το παρατηρούμενο αποτέλεσμα πριν υποβάλετε την αντίστοιχη αξίωση.
