# FAQ

> **Κανονική αγγλική πηγή:** [FAQ.md](../../FAQ.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


<a id="is-randomdayguard-the-randomday-mod"></a>
## Είναι RandomDayGuard το RandomDay Mod;

Αρ. RandomDay Το Mod αλλάζει την εμπειρία διακομιστή. RandomDayGuard παρακολουθεί το επίπεδο στοιχείων διακομιστή.

<a id="does-live-defense-work-before-the-scan-completes"></a>
## Λειτουργεί η ζωντανή άμυνα πριν ολοκληρωθεί η σάρωση;

Ναι. Η ζωντανή άμυνα χρησιμοποιεί αρχεία καταγραφής και συμβάντα συνεδρίας. Η σάρωση γραμμής βάσης βελτιώνει το πλαίσιο αργότερα.

<a id="why-can-the-first-scan-take-a-long-time"></a>
## Γιατί η πρώτη σάρωση μπορεί να διαρκέσει πολύ;

Η πρώτη έκδοση σάρωσης world/object περιβάλλον, δηλώσεις αρχείων και επαναχρησιμοποιήσιμα δεδομένα βασικής γραμμής.

<a id="what-do-i-check-first-after-startup"></a>
## Τι πρέπει να ελέγξω πρώτα μετά την εκκίνηση;

```text
runtime/current/poll_status.json
```

Αναζητήστε:

```text
scheduler_status=running
poll_id increasing
poll_in_flight=false
```

<a id="where-are-player-summaries"></a>
## Πού βρίσκονται οι περιλήψεις των παικτών;

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

<a id="where-is-the-daily-quick-review-package"></a>
## Πού είναι το καθημερινό πακέτο γρήγορου ελέγχου;

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

<a id="which-file-should-i-upload-for-fastest-review"></a>
## Ποιο αρχείο πρέπει να ανεβάσω για ταχύτερο έλεγχο;

```text
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="can-it-write-bans-automatically"></a>
## Μπορεί να γράψει αυτόματα απαγορεύσεις;

Μόνο εάν είναι ρητά ενεργοποιημένο.

Προεπιλογή:

```lua
review_only_mode = true
auto_ban = false
write_admin_ini = false
```

<a id="what-does-adminini-receive"></a>
## Τι κάνει Admin.ini λήψη;

Μόνο:

```ini
BannedPlayer=<ID>
```

Δεν υπάρχουν ονόματα, σχόλια, λόγοι ή επιθήματα.

<a id="is-a-display-name-enough-to-ban"></a>
## Αρκεί ένα εμφανιζόμενο όνομα για αποκλεισμό;

Αρ. Χρησιμοποιήστε ένα αρχείο καταγραφής διακομιστή `Login request` με `ConnectID` ή ισοδύναμο αποδεικτικό διακομιστή.

<a id="can-one-crash-ban-someone"></a>
## Μπορεί ένα σφάλμα να αποκλείσει κάποιον;

Όχι από προεπιλογή.

<a id="can-object-count-alone-ban-someone"></a>
## Μπορεί το αντικείμενο από μόνο του να αποκλείσει κάποιον;

Όχι από προεπιλογή.

<a id="should-savedroottxt-point-to-the-world-folder"></a>
## Θα πρέπει SavedRoot.txt δείχνει στον κόσμο φάκελο;

Αρ. Τοποθετήστε το στο `AbioticFactor/Saved`.

## Τι γίνεται αν αλλάξει ο φάκελος του κόσμου;

Αντιμετώπισέ το ως αλλαγή ταυτότητας βάσης. Διατηρήστε την παλιά γραμμή βάσης και δημιουργήστε μια νέα.
