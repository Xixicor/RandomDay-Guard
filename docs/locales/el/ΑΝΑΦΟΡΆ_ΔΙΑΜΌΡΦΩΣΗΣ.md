# Έννοιες διαμόρφωσης

> **Κανονική αγγλική πηγή:** [CONFIG_REFERENCE.md](../../CONFIG_REFERENCE.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Αυτή η εξήγηση περιγράφει τι ελέγχει κάθε κύρια περιοχή διαμόρφωσης, πότε εκτελείται και πώς αλληλεπιδρά με στοιχεία και πύλες ασφαλείας. Δεν κατέχει τον ακριβή κατάλογο πεδίων ή τις διαδικασίες προφίλ.

Για προεπιλογές προσανατολισμένες στην εργασία και ασφαλή βήματα αλλαγής, χρησιμοποιήστε [`CONFIG_PROFILES.md`](%CE%94%CE%99%CE%91%CE%9C%CE%8C%CE%A1%CE%A6%CE%A9%CE%A3%CE%97_%CE%A0%CE%A1%CE%9F%CE%A6%CE%8A%CE%9B.md). Για κάθε πεδίο ακριβούς πηγής, προεπιλογή, τύπο, αμετάβλητο, εφέ εξόδου και κανόνα ανάκτησης, χρησιμοποιήστε το παραγόμενο [`CONFIG_FIELD_CATALOG.md`](%CE%9A%CE%91%CE%A4%CE%86%CE%9B%CE%9F%CE%93%CE%9F%CE%A3_%CE%A0%CE%95%CE%94%CE%8A%CE%A9%CE%9D_%CE%94%CE%99%CE%91%CE%9C%CE%8C%CE%A1%CE%A6%CE%A9%CE%A3%CE%97%CE%A3.md); ο επικυρωτής απαιτεί μια σειρά εκεί για κάθε αποστολή `config.lua` φύλλο φύλλου.

<a id="top-level-safety"></a>
## Ασφάλεια ανώτατου επιπέδου

| Επιλογή | Προεπιλογή | Σημασία |
|---|---:|---|
| `enabled` | `true` | Κύριος διακόπτης για τον προφυλακτήρα |
| `enforcement.review_only_mode` | `true` | Record/recommend |
| `enforcement.auto_ban` | `false` | Να μην αποκλειστεί αυτόματα από προεπιλογή |
| `enforcement.write_admin_ini` | `false` | Μην γράφετε Admin.ini από προεπιλογή |

Διατηρήστε τα ασφαλή μέχρι ο κάτοχος του διακομιστή να ελέγξει τα αποτελέσματα.

<a id="saved"></a>
## `saved`

Ελέγχει τον τρόπο με τον οποίο ο φύλακας βρίσκει τον διακομιστή `Saved/` φάκελο και ποιες οικογένειες αρχείων μπορεί να σαρώσει.

Χρήση όταν:

```text
Saved root auto-detection fails.
World folder changed.
Provider or container path is unusual.
```

Έλεγχος:

```text
runtime/saved_path_probe.json
RandomDayGuard/SavedRoot.txt
```

Κανόνας:

```text
SavedRoot.txt -> AbioticFactor/Saved
not -> Worlds/<WorldName>
```

<a id="log_tail"></a>
## `log_tail`

Ελέγχει την ανάγνωση ζωντανών αρχείων καταγραφής.

Χρήσιμες επιλογές:

| Επιλογή | Ασφαλής τιμή | Γιατί |
|---|---|---|
| `enabled` | `true` | Απαιτείται για ζωντανή άμυνα |
| `start_at_end_on_first_run` | `true` | Αποφεύγει παλιά αρχεία καταγραφής ως ζωντανές εκδηλώσεις |
| `tail_backup_logs` | `false` | Τα αρχεία καταγραφής αντιγράφων ασφαλείας είναι ιστορικό, όχι ζωντανά |
| `max_lines_per_poll` | περιορισμένο | Διατηρεί την απόκριση του βρόχου δημοσκόπησης |

Έλεγχος:

```text
runtime/log_offsets.tsv
runtime/evidence/session_events.jsonl
runtime/current/poll_status.json
```

<a id="runtime"></a>
## `runtime`

Ελέγχει τη δημοσκόπηση και τους προϋπολογισμούς.

Κύριος κανόνας υγείας:

```text
poll_id increases
poll_in_flight returns false
poll_scheduled is true
```

Έλεγχος:

```text
runtime/current/poll_status.json
```

Αν `poll_id` σταματά, κάτι μπλοκάρει τον βρόχο.

<a id="source_accounting"></a>
## `source_accounting`

Ελέγχει την κάλυψη και το εύρος της ρητής πηγής αποδεικτικών στοιχείων.

| Κλειδί | Προεπιλογή | Σημασία |
|---|---:|---|
| `enabled` | `true` | Γράφει λογιστική πηγή για δημόσιες αναφορές διαδρομής. |
| `require_terminal_status` | `true` | Απαιτεί κάθε πηγή να εκθέτει ένα ρητό τερματικό ή μια ημιτελή κατάσταση. |
| `distinguish_current_from_historical` | `true` | Διατηρεί ξεχωριστά τα τρέχοντα και τα ιστορικά στοιχεία. |
| `slow_world_scan_blocks_current_reports` | `false` | Επιτρέπει στις τρέχουσες αναφορές να αναφέρουν ότι η σάρωση περιορισμένου κόσμου έχει αναβληθεί ή μερική. |
| `changed_file_manifest` | διαδρομή δήλωσης γραμμής βάσης | Αναφορά χρησιμοποιείται για περιορισμένο historical/world λογιστική. |

Οι καταστάσεις πηγής είναι `available`, `expected_empty`, `partial`, `deferred`, `unavailable`, `malformed`, `permission_denied` ή `error`.

Ρύθμιση `source_accounting.enabled = false` δεν καταργεί σιωπηλά την έξοδο κατάστασης. Ο αγωγός εξακολουθεί να γράφει `runtime/final_logs/source_accounting_latest.json` με `enabled=false`, `status="unavailable"` και `disabled_reason="source_accounting_disabled"`. Γράφει επίσης την εγγραφή ιστορικής κατάστασης με μη διαθέσιμη λογιστική. Επειδή η λογιστική πηγή είναι μέρος της σύμβασης αναφοράς, κάθε διαδρομή αποτυγχάνει να κλείσει στο `missing`; καμία διαδρομή δεν αντιμετωπίζεται ως ολοκληρωμένη ενώ η λογιστική είναι απενεργοποιημένη.

<a id="reports"></a>
## `reports`

Ελέγχει τη γενική γραμμή τοπικής αναφοράς.

Οι προεπιλογές ενεργοποιούν και τις πέντε διαδρομές και γράφουν κάτω από `runtime/final_logs`:

```text
server_status
daily_rollup
player_activity
case_review
critical_guard
```

Κάθε διαδρομή πρέπει να γράφει δομημένη και μεταφρασμένη έξοδο συν απόδειξη στο `route_proof.json`. Η απενεργοποίηση μιας διαδρομής παράγει `missing` απόδειξη αντί να προσποιείται ότι ολοκληρώθηκε.

<a id="notification"></a>
## `notification`

Προαιρετικά γενικά εξερχόμενα τοπικά αρχεία. Είναι απενεργοποιημένο από προεπιλογή και δεν στέλνει τίποτα σε εξωτερικό πάροχο.

Προεπιλογές:

```lua
notification = {
    enabled = false,
    mode = "local_file_outbox",
    include_expected_empty = false,
},
```

Κάθε διαδρομή ειδοποιήσεων είναι απενεργοποιημένη από προεπιλογή. Όταν ενεργοποιηθεί σκόπιμα, τα εξερχόμενα ενδέχεται να καταναλώσουν μόνο μια ολοκληρωμένη μεταφρασμένη αναφορά μετά το `route_proof.json`. Τα τοπικά στοιχεία και αναφορές παραμένουν έγκυρα. Η παράδοση για συγκεκριμένο πάροχο, τα τελικά σημεία παράδοσης, τα διαπιστευτήρια και οι γέφυρες δεν αποτελούν μέρος της δημόσιας σύμβασης ανεξάρτητης παρακολούθησης.

<a id="scanning"></a>
## `scanning`

Ελέγχει τη σάρωση γραμμής βάσης, το σημείο ελέγχου και την ανανέωση αλλαγμένου αρχείου.

Χρήση όταν:

```text
building first world baseline
resuming after crash
refreshing changed files later
```

Έλεγχος:

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/scan_complete.json
runtime/baselines/file_manifest.tsv
```

Σημαντικές ρυθμίσεις:

```lua
scanning = {
    resume_incomplete_scan = true,
    reuse_completed_baseline = true,
    incremental_refresh_after_baseline = true,
    changed_file_detection = true,
},
```

<a id="forensic_rollup"></a>
## `forensic_rollup`

Ελέγχει το πακέτο γρήγορης ημερήσιας μεταφόρτωσης και τα τελικά αρχεία καταγραφής σε απλή γλώσσα.

Έξοδοι:

```text
runtime/current/forensic_today.json
runtime/current/forensic_today.md
runtime/current/forensic_today.txt
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

Χρήση όταν:

```text
You want one daily folder that summarizes what happened.
You want a plain-language TXT to upload for quick analysis.
```

Έλεγχος:

```text
runtime/forensic_days/YYYY-MM-DD/forensic_day_summary.json
runtime/forensic_days/YYYY-MM-DD/players.tsv
runtime/forensic_days/YYYY-MM-DD/ban_recommendations.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

Κανόνας:

```text
Daily summaries are rebuildable indexes.
Source evidence remains authoritative.
```

<a id="logging"></a>
## `logging`

Ελέγχει τον όγκο συμβάντων και τη συγκέντρωση χαμηλής σημασίας.

Χρήση όταν:

```text
actor-touch events are noisy
raw event files grow too quickly
```

Ασφαλές μοτίβο:

```lua
logging = {
    low_importance_mode = "aggregate",
    write_low_importance_raw_events = false,
},
```

<a id="retention"></a>
## `retention`

Ελέγχει πόσο καιρό διατηρούνται τα αρχεία και πότε JSONL τα αρχεία καταγραφής περιστρέφονται.

Χρήση όταν:

```text
disk usage grows too fast
you need more audit history
you need shorter live-history windows
```

Σημαντικές επιλογές:

```text
detailed_retention_days
rotate_jsonl_when_bytes_exceed
max_raw_events_lines
keep_enforced_forever
keep_evidence_forever
```

<a id="warning_bursts"></a>
## `warning_bursts`

Ελέγχει την ανίχνευση παραθύρου προειδοποίησης.

Παραδείγματα:

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

Κανόνας:

```text
Warnings are context until correlated with mapped sessions and thresholds.
```

<a id="crash_correlation"></a>
## `crash_correlation`

Στοιχεία ελέγχου επαναλαμβανόμενα crash/reconnect κριτική.

Ασφαλείς προεπιλογές:

```lua
crash_correlation = {
    single_crash_never_bans = true,
    require_same_account = true,
},
```

Χρήσιμοι μετρητές:

```text
server_crash_overlap_count
post_crash_reconnect_count
unclean_disconnect_count
```

<a id="join_leave"></a>
## `join_leave`

Ελέγχει την παρακολούθηση ανατροπής και σύνδεσης κυμάτων.

Ασφαλής προεπιλογή:

```lua
join_leave = {
    churn_alone_never_bans = true,
},
```

Χρήση για:

```text
rapid reconnect loops
join waves
short-session patterns
```

<a id="raid_detection"></a>
## `raid_detection`

Ομαδοποιεί λογαριασμούς ενεργούς σε σχετικά παράθυρα.

Κανόνας:

```text
A raid case groups accounts for review.
It does not make every account guilty.
```

Κάθε επιβεβλημένος λογαριασμός εξακολουθεί να χρειάζεται αποδεικτικά στοιχεία για συγκεκριμένο λογαριασμό.

<a id="object_registry"></a>
## `object_registry`

Στοιχεία ελέγχου object/class εξαγωγή διακριτικού από αναγνώσιμα αποθηκευμένα στοιχεία.

Έξοδοι:

```text
runtime/object_registry_partial.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
```

Κανόνας:

```text
Object/class context is not a ban reason by itself.
```

<a id="world_state"></a>
## `world_state`

Στοιχεία ελέγχου boot/current/session στιγμιότυπα παγκόσμιων κρατών.

Έξοδοι:

```text
runtime/world_state/current/world_state_latest.json
runtime/world_state/sessions/<date>/<session_id>_<account_id>/
```

Χρήση για ανασκόπηση περιόδου σύνδεσης και παγκόσμιο πλαίσιο.

<a id="enforcement"></a>
## `enforcement`

Ελέγχει τις προτάσεις και τις πραγματικές Admin.ini γράφει.

Προτού το Guard προσθέσει απαγόρευση, κάθε δήλωση παρακάτω πρέπει να είναι αληθής:

```text
review_only_mode == false
auto_ban == true
write_admin_ini == true
ban_id is clean numeric
account identity is mapped
not trusted
not moderator
threshold is met
```

Αν μία δήλωση είναι ψευδής ή δεν μπορεί να ελεγχθεί, ο Φρουρός αποχωρεί `Admin.ini` αμετάβλητο και καταγράφει τον λόγο.

<a id="admin_ini"></a>
## `admin_ini`

Ελέγχει την ασφαλή εγγραφή αρχείων.

Κανόνες:

```text
Back up before writing.
Preserve existing bans.
Preserve moderators.
Write clean BannedPlayer=<ID> only.
```

<a id="restart_request"></a>
## `restart_request`

Ελέγχει τα προαιρετικά αρχεία τοπικών δεικτών που μπορεί να επιθεωρήσει άλλη διεργασία που ανήκει στον χειριστή. Δεν επανεκκινεί ούτε σκοτώνει τον διακομιστή.

Προεπιλογές:

```lua
restart_request = {
    enabled = false,
    restart_marker_file = "runtime/request_restart.flag",
    restart_reason_file = "runtime/restart_reason.json",
},
```

Έξοδοι:

```text
runtime/request_restart.flag
runtime/restart_reason.json
```

Δεν υπάρχει πακέτο φιλοξενίας, γέφυρας παρόχου ή αυτοματισμού επανεκκίνησης. Η ενεργοποίηση της δημιουργίας δείκτη δεν αποδεικνύει ότι μια εξωτερική διεργασία κατανάλωσε το αίτημα ή έκανε επανεκκίνηση του διακομιστή.
