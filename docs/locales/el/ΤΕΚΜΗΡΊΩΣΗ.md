# RandomDayGuard τεκμηρίωση

> **Κανονική αγγλική πηγή:** [README.md](../../README.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


RandomDayGuard διαβάζει εγγραφές από έναν αποκλειστικό διακομιστή Abiotic Factor και τις μετατρέπει σε ξεχωριστές αναφορές για την υγεία του διακομιστή, το ημερήσιο ιστορικό, τις περιόδους σύνδεσης του προγράμματος αναπαραγωγής, τις υποθέσεις ελέγχου και τις αποτυχίες του Guard.
