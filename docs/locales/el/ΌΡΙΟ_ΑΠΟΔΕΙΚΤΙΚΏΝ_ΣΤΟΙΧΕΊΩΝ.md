<a id="evidence-boundary"></a>
# Όριο αποδεικτικών στοιχείων

> **Κανονική αγγλική πηγή:** [EVIDENCE_BOUNDARY.md](../../EVIDENCE_BOUNDARY.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Χρησιμοποιήστε αυτήν τη σελίδα για να αποφασίσετε τι RandomDayGuard μπορεί να αναφέρει και ό,τι εξακολουθεί να απαιτεί ανθρώπινο έλεγχο.

<a id="core-rule"></a>
## Βασικός κανόνας

RandomDayGuard καταγράφει περιορισμένες παρατηρήσεις από αρχεία που ανήκουν σε διακομιστή. Πρέπει να προσδιορίζει την πηγή, το εύρος, την κατάσταση συλλογής και τα όρια για κάθε υλικό συμπέρασμα.

Τα δομημένα στοιχεία είναι έγκυρα. Μια μεταφρασμένη έκθεση εξηγεί τα στοιχεία. δεν μπορεί να προσθέσει γεγονότα που απουσιάζουν από τη δομημένη εγγραφή.

<a id="evidence-source-classes"></a>
## Τάξεις πηγών αποδεικτικών στοιχείων

| Κλάση πηγής | Τυπική χρήση | Δεν αποδεικνύεται από μόνο του |
|---|---|---|
| `admin_ini` | Υφιστάμενη κατάσταση διαχείρισης και ελεγμένο write/readback πλαίσιο | Ποιος προκάλεσε ένα περιστατικό |
| `active_log` | Τρέχον server/session συμβάντα ορατά στο ενεργό αρχείο καταγραφής | Πρόθεση, ιδιοκτησία ή άμεση ζημιά |
| `recent_backup_logs` | Πλαίσιο ιστορικού αρχείου καταγραφής | Συνέβη ένα τρέχον συμβάν |
| `playerdata_filenames` | Επιβεβαίωση ότι υπάρχει καθαρό αναγνωριστικό λογαριασμού | Συμπεριφορά, ενοχή ή ιδιοκτησία ταυτότητας πέρα ​​από το εκτεθειμένο αναγνωριστικό |
| `existing_cases` | Πλαίσιο προηγούμενου ελέγχου | Ότι μια προηγούμενη ερμηνεία παραμένει σωστή |
| `existing_reports` | Προηγούμενες περιλήψεις και αποφάσεις | Τρέχουσα αλήθεια χωρίς τρέχουσα επιβεβαίωση |
| `existing_evidence` | Ιστορικά δομημένα στοιχεία | Τρέχουσα δραστηριότητα |
| σάρωση περιορισμένης εξοικονόμησης κόσμου | Αργό world/class πλαίσιο | Ενέργεια παίκτη, ιδιοκτησία, κλοπή, αντιγραφή ή ζημιά |

Κάθε πηγή καταγράφει availability/readability, πλήθος αρχείων, αναφορές πηγής, τρέχον ή ιστορικό εύρος και ρητό `does_not_prove` δήλωση.

<a id="source-states"></a>
## Καταστάσεις πηγής

| Κατάσταση | Σημασία χειριστή |
|---|---|
| `available` | Η πηγή ήταν ευανάγνωστη και συγκεντρώθηκαν στοιχεία. |
| `expected_empty` | Η πηγή ήταν αναγνώσιμη και νόμιμα δεν είχε αντίστοιχη εγγραφή. |
| `partial` | Συλλέγονται κάποια στοιχεία. Η κάλυψη δεν είναι πλήρης. |
| `deferred` | Οι περιορισμένες εργασίες αναβλήθηκαν σκόπιμα. |
| `unavailable` | Η πηγή δεν υπάρχει σε αυτό το περιβάλλον. |
| `malformed` | Η πηγή υπάρχει αλλά δεν μπορεί να αναλυθεί με ασφάλεια. |
| `permission_denied` | Το φύλακας δεν έχει άδεια ανάγνωσης. |
| `error` | Η συλλογή απέτυχε για άλλη καταγεγραμμένη αιτία. |

Το αναμενόμενο κενό είναι έγκυρη παρατήρηση. Δεν πρέπει ποτέ να μετατραπεί σε κατασκευασμένο παίκτη, υπόθεση, περιστατικό ή κατηγορία.

<a id="current-versus-historical-evidence"></a>
## Τρέχοντα σε σχέση με ιστορικά στοιχεία

Τα τρέχοντα στοιχεία ανήκουν στο ενεργό παράθυρο συλλογής ή την εποχή του διακομιστή. Τα ιστορικά στοιχεία προέρχονται από προηγούμενα αρχεία καταγραφής, υποθέσεις, αναφορές, αρχεία αποδεικτικών στοιχείων, αντίγραφα ασφαλείας ή βασικές γραμμές.

Τα ιστορικά στοιχεία μπορούν να παρέχουν το πλαίσιο. Δεν μπορεί να καλύψει σιωπηλά ένα κενό από τα τρέχοντα στοιχεία. Οι αναφορές πρέπει να επισημαίνουν και τα δύο πεδία και να αναφέρουν τις πηγές τους ξεχωριστά.

<a id="corroboration-rule"></a>
## Κανόνας επιβεβαίωσης

Αυτά είναι χρήσιμα συμφραζόμενα αλλά δεν αποτελούν άμεση απόδειξη από μόνα τους:

- εμφάνιση ονομάτων ή ομοιότητα ονομάτων;
- σύμπτωση χρονισμού;
- απενεργοποίηση αποσύνδεσης ή επανασύνδεσης;
- μία σύγκρουση ή προειδοποίηση;
- κλάση, διαδρομή, ηθοποιός, χάρτης ή κουπόνια μέτρησης αντικειμένων.
- συμμετοχή σε μια αυτόματα ομαδοποιημένη περίπτωση;
- προηγούμενες αναφορές χωρίς επιβεβαίωση τρέχουσας πηγής.

Μην ισχυριστείτε ενοχή, πρόθεση, εξαπάτηση, ιδιοκτησία, κλοπή, διπλασιασμό, άμεση ζημιά, άμεση χρήση κοντέινερ, άμεση ενέργεια αποθέματος, ακριβείς ζωντανές συντεταγμένες, ζωντανό ping ή συμπεριφορά σε επίπεδο μνήμης χωρίς στοιχεία που αποκαλύπτουν άμεσα το γεγονός.

<a id="truthful-report-language"></a>
## Αληθής γλώσσα αναφοράς

Χρήση:

```text
Observed: the account was active in the recorded crash window.
Interpretation: repeated overlap warrants operator review.
Unknown: the cause of the crash.
Does not prove: that the account caused the crash.
Next action: compare the cited current session and lifecycle records.
```

Αποφύγετε:

```text
The player crashed the server.
The player stole or duplicated items.
The world token proves who used the object.
```

<a id="report-reading-order"></a>
## Αναφορά σειράς ανάγνωσης

Κάθε δημόσια αναφορά πρέπει να εξηγεί:

1. Απλή έννοια.
2. Γιατί έχει σημασία.
3. Τεχνική απόδειξη και αναφορές πηγής.
4. Επόμενη ενέργεια.
5. Όρια, άγνωστα και αξιώσεις δεν αποδείχθηκαν.
