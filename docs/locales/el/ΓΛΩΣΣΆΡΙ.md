# Γλωσσάρι

> **Κανονική αγγλική πηγή:** [GLOSSARY.md](../../GLOSSARY.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


| Όρος | Απλή έννοια | Ακριβής τεχνική σημασία |
|---|---|---|
| Ενεργό αρχείο καταγραφής | Το τρέχον αρχείο καταγραφής διακομιστή χρησιμοποιείται για νέα στοιχεία. | Απαιτείται `active_log` πηγή; Για την ολοκλήρωση της διαδρομής απαιτείται η αναγνωσιμότητα και η τρέχουσα γραμμή. |
| Αναγνωριστικό εκκίνησης | Έναρξη μιας διαδικασίας παρακολούθησης. | Αναγνωριστικό τρέχοντος χρόνου εκτέλεσης που χρησιμοποιείται για την απόρριψη της προηγούμενης εκκίνησης errors/reports. |
| Αναγνωριστικό εποχής | Διάστημα συνέχειας ενός διακομιστή. | Αναγνωριστικό που εκτείνεται σε κανονικό χρόνο εκτέλεσης έως ότου η λογική συνέχειας ξεκινήσει μια άλλη εποχή. |
| Αναγνωριστικό δημοσκόπησης | Ευκαιρία δημοσκόπησης με μία περιορισμένη. | Θετικό μονοτονικό πεδίο κύκλου. zero/missing δεν μπορεί να ολοκληρώσει μια διαδρομή. |
| Φρεσκάδα πηγής | Αν συμφωνούν η τρέχουσα πηγή και η γενεαλογία δημοσκόπησης. | `fresh_current_poll` ή `stale_or_unproven` με χρονικές σημάνσεις και κατάσταση ενεργού καταγραφής. |
| Λογιστική πηγής | Απόθεμα διαθεσιμότητας αποδεικτικών στοιχείων και ορίων. | `randomdayguard.source-accounting/v1` με οκτώ κατηγορίες πηγών και current/historical. |
| `available` | Βρέθηκε και διαβάστηκε μια πηγή. | Κατάσταση προέλευσης τερματικού με `available=true`, `readable=true`. |
| `expected_empty` | Μια προαιρετική πηγή ελέγχθηκε και νόμιμα absent/empty. | Κατάσταση αναγνώσιμη πηγή από το τερματικό. ποτέ δεν κατασκευάζει θέμα. |
| `partial` | Οι περιορισμένες εργασίες έχουν χρήσιμα αλλά ελλιπή αποτελέσματα. | Μη τερματικό source/accounting κατάσταση; συνέχιση του ιδιοκτήτη του εργαζόμενου. |
| `deferred` | Η εργασία εκκρεμεί σκόπιμα. | Κατάσταση μη τερματικής πηγής. δεν είναι σφάλμα ή ολοκλήρωση. |
| `unavailable` | Η πηγή δεν μπορεί να χρησιμοποιηθεί αυτήν τη στιγμή. | Κενό τερματικού. ένα κενό απαιτούμενης πηγής καθιστά τη λογιστική μη διαθέσιμη. |
| `malformed` | Υπάρχει πηγή αλλά είναι δομικά μη έγκυρη. | Το κενό τερματικού διατηρεί τις λεπτομέρειες επικύρωσης και κλείνει τις εξαρτημένες εγγραφές. |
| `permission_denied` | Το λειτουργικό σύστημα απέρριψε ρητά την πρόσβαση. | Το κενό τερματικού διαφέρει από το missing/unavailable. |
| `error` | Μια περιορισμένη λειτουργία απέτυχε απροσδόκητα. | Αποτυχία τερματικού που απαιτεί την ονομαζόμενη ανάκτηση. καμία μυστική λεπτομέρεια δεν ανήκει στις δημόσιες αναφορές. |
| `complete` | Όλες οι λογιστικές πηγές είναι τερματικές χωρίς κενό. | Κατάσταση λογιστικής πηγής ανώτατου επιπέδου. |
| `complete_with_gaps` | Τα απαιτούμενα τρέχοντα στοιχεία λειτουργούν. Προαιρετικά κενά ακροδεκτών παραμένουν. | Λογιστική κατάσταση ανώτατου επιπέδου. οι διαδρομές εξακολουθούν να εφαρμόζουν τις δικές τους απαιτήσεις. |
| `full` | Μια διαδρομή που ολοκληρώθηκε με την απαιτούμενη μη κενή σύμβαση. | Αριθμός απόδειξης διαδρομής με ολοκληρωμένες εξόδους τρέχοντος κύκλου. |
| `limited_expected_empty` | Μια διαδρομή ολοκληρώθηκε και δεν βρέθηκε κατάλληλη subject/failure. | Αριθμός απόδειξης διαδρομής με `completed=true`, `expected_empty=true`. |
| `missing` | Η απόδειξη ολοκλήρωσης διαδρομής απουσιάζει ή απέτυχε. | Αριθμός απόδειξης διαδρομής με `completed=false`; ποτέ δεν πληροί τα κριτήρια για εξερχόμενα. |
| Δομημένη αναφορά | Έξοδος διαδρομής αναγνώσιμη από μηχανήματα. | `<route>_latest.json` χρησιμοποιώντας `randomdayguard.report/v1`. |
| Μεταφρασμένη αναφορά | Αναγνώσιμη από τον άνθρωπο απόδοση της ίδιας διαδρομής. | `<route>_latest.txt` με σταθερή σειρά παρατήρησης σε πηγή αναφοράς. |
| Απόδειξη διαδρομής | Καθολικό ολοκλήρωσης διαδρομών. | `route_proof.json` δεσμευτική version/boot/epoch/poll/freshness/output μονοπάτια. |
| Τρέχοντα στοιχεία | Παρατήρηση που ανήκει στον ενεργό κύκλο. | Πεδίο εφαρμογής `current`; δεν έχει ανακατασκευαστεί από παλιά filenames/reports. |
| Ιστορικά στοιχεία | Διατηρήθηκε το πλαίσιο από προηγούμενους κύκλους ή αργή σάρωση. | Πεδίο εφαρμογής `historical`; μπορεί να ενημερώσει τον έλεγχο, αλλά δεν μπορεί να διεκδικήσει την τρέχουσα παρουσία. |
| Μόνο για κριτική | Δημιουργήστε αποδεικτικά στοιχεία ελέγχου χωρίς Admin.ini γράφει. | Προεπιλογή `review_only_mode=true`, `auto_ban=false`, `write_admin_ini=false`. |
| Έλεγχος ασφαλείας απαγόρευσης | Μία ερώτηση πρέπει να απαντήσει ο Φρουρός για να αλλάξει `Admin.ini`. | Πρέπει να επιβεβαιώσει τον λογαριασμό και τη βαθμολογία, να εξαιρέσει αξιόπιστους λογαριασμούς και διπλότυπα, να επαληθεύσει ένα αντίγραφο ασφαλείας, να εντοπίσει εξωτερικές αλλαγές, να αποθηκεύσει την προβλεπόμενη ενημέρωση και να επαληθεύσει ή να επαναφέρει με ασφάλεια το πλήρες αρχείο. |
| Τοπικά εξερχόμενα | Προαιρετική μεταβίβαση ειδοποιήσεων ουδέτερη από τον πάροχο. | JSON αρχεία με `delivery_backend="none"` και `delivery_attempted=false`. |
| Βασική γραμμή | Ολοκληρώθηκε στιγμιότυπο περιβάλλοντος με περιορισμένο αποθηκευμένο αρχείο. | Manifest/object/world η κατάσταση επαναχρησιμοποιείται μόνο όταν είναι συμβατή και αρκετά φρέσκια. |
| Σημείο ελέγχου | Συνέχιση θέσης για ημιτελή εργασία σάρωσης. | `scan_checkpoint.json`; Η διαγραφή δεν είναι η προεπιλεγμένη ανάκτηση. |
| Επανοικοδομήσιμο ευρετήριο | Σύνοψη που μπορεί να αναδημιουργηθεί. | Daily/weekly/forensic/final έξοδος ελέγχου. Τα στοιχεία πηγής παραμένουν έγκυρα. |
| Όριο αποδεικτικών στοιχείων | Περιορίστε το τι μπορεί να υποστηρίξει μια πηγή. | Ρητή `does_not_prove`, άγνωστα στοιχεία, ισχύς ταυτότητας και κανόνες εμβέλειας. |

Οι κανονικοί ορισμοί για σχήματα βρίσκονται στο [`OUTPUT_SCHEMA_REFERENCE.md`](%CE%91%CE%9D%CE%91%CE%A6%CE%9F%CE%A1%CE%86_%CE%A3%CE%A7%CE%89%CE%9C%CE%91%CE%A4%CE%9F%CE%A3_%CE%95%CE%9E%CE%8C%CE%94%CE%9F%CE%A5.md); οι όροι διαμόρφωσης είναι σε [`CONFIG_FIELD_CATALOG.md`](%CE%9A%CE%91%CE%A4%CE%86%CE%9B%CE%9F%CE%93%CE%9F%CE%A3_%CE%A0%CE%95%CE%94%CE%8A%CE%A9%CE%9D_%CE%94%CE%99%CE%91%CE%9C%CE%8C%CE%A1%CE%A6%CE%A9%CE%A3%CE%97%CE%A3.md).
