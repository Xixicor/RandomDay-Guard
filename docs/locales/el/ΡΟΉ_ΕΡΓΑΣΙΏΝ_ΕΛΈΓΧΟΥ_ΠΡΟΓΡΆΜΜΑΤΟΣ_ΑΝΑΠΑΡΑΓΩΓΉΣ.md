# Ροή εργασιών ελέγχου προγράμματος αναπαραγωγής

> **Κανονική αγγλική πηγή:** [PLAYER_REVIEW_WORKFLOW.md](../../PLAYER_REVIEW_WORKFLOW.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Χρησιμοποιήστε αυτήν τη σελίδα για έναν παίκτη, λογαριασμό ή υπόθεση. Ο σκοπός είναι μια αναπαραγώγιμη απόφαση επανεξέτασης, όχι μια αυτοματοποιημένη κατηγορία.

<a id="quick-path"></a>
## Γρήγορη διαδρομή

1. Άνοιγμα `runtime/final_logs/player_activity_latest.json`.
2. Επιβεβαιώστε την κατάσταση διαδρομής στο `runtime/final_logs/route_proof.json`.
3. Προσδιορίστε ποιες παρατηρήσεις είναι τρέχουσες και ποιες ιστορικές.
4. Ελέγξτε την αναφερόμενη ταυτότητα και τις αναφορές πηγής περιόδου σύνδεσης.
5. Έλεγχος `case_review_latest.json` όταν υπάρχει συσχετισμένη περίπτωση.
6. Καταγραφή αγνώστων και `does_not_prove` πριν επιλέξετε μια ενέργεια.
7. Αφήστε την επιβολή απενεργοποιημένη, εκτός εάν αποδειχθούν οι ξεχωριστές πύλες επιβολής.

<a id="1-confirm-route-proof"></a>
## 1. Επιβεβαιώστε την απόδειξη διαδρομής

Ερμηνεύστε τη διαδρομή του προγράμματος αναπαραγωγής ως:

| Κατάσταση | Ενέργεια |
|---|---|
| `full` | Συνεχίστε, ενώ εξακολουθείτε να ελέγχετε τα όρια πηγής. |
| `limited_expected_empty` | Συνεχίστε μόνο με τα πραγματικά παρόντα θέματα. μην εφεύρετε έναν παίκτη ή θήκη που λείπει. |
| `missing` | Διακοπή της απόφασης του προγράμματος αναπαραγωγής και αντιμετώπιση προβλημάτων της διαδρομής. |

Ένας υγιής προγραμματιστής δεν αντικαθιστά την απόδειξη διαδρομής.

<a id="2-establish-identity"></a>
## 2. Καθιερώστε ταυτότητα

Προτιμήστε ένα καθαρό αναγνωριστικό λογαριασμού που επιβεβαιώνεται από στοιχεία ταυτότητας που εκτίθενται από διακομιστή και, όπου είναι διαθέσιμο, PlayerData ονόματα αρχείων. Διατηρήστε την αναφορά πρωτογενούς πηγής.

Να μην επιβάλλεται από:

- ένα εμφανιζόμενο όνομα μόνο;
- ένα όνομα που εμφανίζεται σε έναν πίνακα ειδοποιήσεων ή φιλοξενίας.
- ομοιότητα χρονισμού;
- μια μη χαρτογραφημένη ταυτότητα ή ταυτότητα ασθενούς εμπιστοσύνης,
- μια ιστορική αναφορά χωρίς τρέχουσα επιβεβαίωση.

<a id="3-separate-current-from-historical"></a>
## 3. Διαχωρίστε το ρεύμα από το ιστορικό

Τα τρέχοντα στοιχεία περιγράφουν το ενεργό παράθυρο αναφοράς ή την εποχή του διακομιστή. Τα ιστορικά στοιχεία μπορεί να εξηγούν ένα μοτίβο, αλλά δεν μπορούν να καλύψουν σιωπηλά τα κενά στο τρέχον παράθυρο.

Καταγράψτε και τα δύο πεδία ανεξάρτητα:

```text
Current observations:
Current source references:
Historical context:
Historical source references:
```

<a id="4-review-observations-and-interpretation"></a>
## 4. Ελέγξτε τις παρατηρήσεις και την ερμηνεία

Διαβάστε ευδιάκριτα αυτές τις ενότητες αναφοράς:

```text
observed
interpretation
unknown
does_not_prove
next_action
source_references
```

Ανοίξτε ξανά τα αναφερόμενα δομημένα στοιχεία για οποιαδήποτε ουσιαστική απόφαση. Μια μετάφραση είναι πλοήγηση και επεξήγηση, όχι νέα στοιχεία.

<a id="5-calibrate-the-decision"></a>
## 5. Βαθμονόμηση της απόφασης

| Απόφαση | Χρήση όταν |
|---|---|
| `INFO` | Κανονική παρατήρηση ή παρατήρηση χαμηλού περιεχομένου. |
| `WATCH` | Ασθενές ή ημιτελές σήμα αξίζει να παρακολουθείται. |
| `REVIEW` | Τα συσχετισμένα αποδεικτικά στοιχεία χρειάζονται την κρίση του διαχειριστή. |
| `BAN-ELIGIBLE` | Η καθαρή ταυτότητα και τα διαμορφωμένα όρια αποδεικτικών στοιχείων πληρούνται. Οι πύλες εγγραφής εξακολουθούν να ισχύουν. |
| `AUTO-BANNED` | Η επιβολή ενεργοποιήθηκε ρητά και η δημιουργία αντιγράφων ασφαλείας, η εγγραφή, η ανάγνωση και ο έλεγχος ολοκληρώθηκαν με επιτυχία. |

Καμία ετικέτα απόφασης δεν αποδεικνύει ενοχή ή πρόθεση.

<a id="6-apply-the-evidence-boundary"></a>
## 6. Εφαρμόστε το όριο αποδεικτικών στοιχείων

Σφάλματα, επανασυνδέσεις, προειδοποιήσεις, object/class και η ομαδοποίηση περιπτώσεων μπορούν να υποστηρίξουν τον έλεγχο. Από μόνες τους, δεν αποδεικνύεται η εξαπάτηση, η κλοπή, η αντιγραφή, η ιδιοκτησία, η άμεση ζημιά ή η αιτία περιστατικού.

Εάν η ταυτότητα, η ανάλυση, η δημιουργία αντιγράφων ασφαλείας, η εγγραφή, η ανάγνωση ή η επαναφορά είναι αδύναμες ή αποτυγχάνουν, η επιβολή πρέπει να αποτύχει να κλείσει.

```text
Coverage status:

Identity confidence and source:
Current observations:
Historical context:
Interpretation:
Unknown:

```
