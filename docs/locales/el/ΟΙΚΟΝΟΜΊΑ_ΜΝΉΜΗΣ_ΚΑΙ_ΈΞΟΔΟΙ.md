# Εξοικονόμηση μνήμης και αρχεία εξόδου

> **Κανονική αγγλική πηγή:** [MEMORY_ECONOMY_AND_OUTPUTS.md](../../MEMORY_ECONOMY_AND_OUTPUTS.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Αυτή η σελίδα εξηγεί ποια αρχεία αναπτύσσονται, ποια αρχεία αντικαθίστανται και τι να ανεβάσετε για γρήγορο έλεγχο.

<a id="fast-answer"></a>
## Γρήγορη απάντηση

| Ερώτηση | Άνοιγμα |
|---|---|
| Ζει ο φύλακας; | `runtime/current/poll_status.json` |
| Ποιος εμφανίστηκε; | `runtime/account_evidence.json` |
| Τι συνέβη με τις περιόδους σύνδεσης; | `runtime/evidence/session_events.jsonl` |
| Τι συνέβη σήμερα; | `runtime/forensic_days/YYYY-MM-DD/` |
| Τι είναι η περίληψη σε απλή γλώσσα; | `runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt` |
| Τι είναι η πρόοδος σάρωσης; | `runtime/scan_progress.json` |
| Ποιο είναι το παγκόσμιο πλαίσιο; | `runtime/world_state/current/world_state_latest.json` |
| Ποιες απαγορεύσεις γράφτηκαν; | `runtime/enforced_bans.jsonl` |

<a id="output-model"></a>
## Μοντέλο εξόδου

| Πληκτρολογήστε | Συμπεριφορά | Παραδείγματα |
|---|---|---|
| Τρέχοντα στιγμιότυπα | Αντικαταστάθηκε | `runtime/current/*.json` |
| Αρχεία καταγραφής συμβάντων | Μόνο προσάρτηση | `runtime/evidence/*.jsonl` |
| Πίνακες | Ενημερώθηκε ή προστέθηκε | `*.tsv` |
| Βασικές γραμμές | Επαναχρησιμοποίηση μετά την ολοκλήρωση | `runtime/baselines/*` |
| Καθημερινές συνάθροιση | Ενημερώθηκε επί τόπου | `runtime/forensic_days/YYYY-MM-DD/*` |
| Τελικά αρχεία καταγραφής | ημερήσια σύνοψη σε απλή γλώσσα | `runtime/final_logs/YYYY-MM-DD/*` |

<a id="current-snapshots"></a>
## Τρέχοντα στιγμιότυπα

Αυτά παραμένουν μικρά και απαντούν "τι ισχύει τώρα".

```text
runtime/current/poll_status.json
runtime/current/session_state.json
runtime/current/active_accounts.json
runtime/current/forensic_today.json
runtime/current/forensic_today.md
runtime/current/forensic_today.txt
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/world_state/current/world_state_latest.json
```

<a id="player-summaries"></a>
## Περιλήψεις προγράμματος αναπαραγωγής

Αυτά είναι τα πρώτα αρχεία που πρέπει να ελέγξετε για έλεγχο λογαριασμού.

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
```

Συνοψίζουν:

```text
account_id
ban_id
name
identity_confidence
first_seen
last_seen
join_count
leave_count
status
score
```

<a id="event-logs"></a>
## Αρχεία καταγραφής συμβάντων

Αυτές διατηρούν τη γραμμή χρόνου.

```text
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/warning_events.jsonl
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/evidence/live_defense_events.jsonl
```

<a id="daily-forensic-rollups"></a>
## Καθημερινές ιατροδικαστικές συγκεντρώσεις

Αυτά είναι τα πακέτα γρήγορης μεταφόρτωσης.

```text
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```

Ανεβάστε έναν από αυτούς τους φακέλους όταν θέλετε μια γρήγορη ανάλυση περιόδου.

<a id="scan-and-baseline-files"></a>
## Σάρωση και βασικά αρχεία

Χρησιμοποιήστε τα για να κατανοήσετε εάν το παγκόσμιο πλαίσιο είναι μερικό ή πλήρες.

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/scan_complete.json
runtime/object_registry_partial.json
runtime/object_registry.json
runtime/object_registry_counts.tsv
runtime/baselines/last_completed_baseline.json
runtime/baselines/file_manifest.tsv
```

<a id="enforcement-files"></a>
## Αρχεία επιβολής

Χρησιμοποιήστε τα μόνο όταν είναι ενεργοποιημένη η επιβολή.

```text
runtime/enforced.txt
runtime/enforced_bans.jsonl
runtime/ban_queue.json
runtime/evidence/enforced_bans.jsonl
```

`Admin.ini` θα πρέπει να λαμβάνει μόνο:

```ini
BannedPlayer=<ID>
```

<a id="what-updates-when-a-player-joins"></a>
## Τι ενημερώνεται όταν συμμετέχει ένας παίκτης

Αναμενόμενες ενημερώσεις:

```text
runtime/account_evidence.json
runtime/account_evidence.tsv
runtime/evidence/session_events.jsonl
runtime/session_events.tsv
runtime/current/session_state.json
runtime/forensic_days/YYYY-MM-DD/players.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="what-updates-when-the-server-crashes-or-restarts"></a>
## Τι ενημερώνεται όταν ο διακομιστής διακόπτεται ή επανεκκινείται

Αναμενόμενες ενημερώσεις:

```text
runtime/server_lifecycle_events.jsonl
runtime/server_epochs.jsonl
runtime/evidence/crash_reconnect_events.jsonl
runtime/account_evidence.json
runtime/forensic_days/YYYY-MM-DD/crash_reconnects.tsv
runtime/final_logs/YYYY-MM-DD/final_forensic_log.txt
```

<a id="what-updates-when-the-scan-progresses"></a>
## Τι ενημερώνεται όταν προχωρά η σάρωση

Αναμενόμενες ενημερώσεις:

```text
runtime/scan_progress.json
runtime/scan_checkpoint.json
runtime/object_registry_partial.json
runtime/world_state/current/world_state_latest.json
runtime/forensic_days/YYYY-MM-DD/forensic_day_summary.json
```

<a id="what-to-upload-for-quick-analysis"></a>
## Τι να ανεβάσετε για γρήγορη ανάλυση

Καλύτερο πακέτο:

```text
runtime/final_logs/YYYY-MM-DD/
```

Περισσότερο πλήρες πακέτο:

```text
runtime/forensic_days/YYYY-MM-DD/
```

Πλήρες πακέτο αποδεικτικών στοιχείων:

```text
runtime/account_evidence.json
runtime/evidence/session_events.jsonl
runtime/server_lifecycle_events.jsonl
runtime/warning_events.jsonl
runtime/forensic_days/YYYY-MM-DD/
runtime/final_logs/YYYY-MM-DD/
```
