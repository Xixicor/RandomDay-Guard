# Σήματα ανίχνευσης

> **Κανονική αγγλική πηγή:** [DETECTION_SIGNALS.md](../../DETECTION_SIGNALS.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Τα σήματα είναι είσοδοι ελέγχου και όχι αυτόματες κατηγορίες.

<a id="signal-table"></a>
## Πίνακας σημάτων

| Σήμα | Σημασία | Ισχυρότερο όταν... | Δεν αρκεί από μόνο του |
|---|---|---|---|
| Ταυτότητα σύνδεσης | Όνομα χαρτών σε αναγνωριστικό λογαριασμού | Το ConnectID υπάρχει | Αποκλεισμός |
| Καθαρή άδεια | Κανονικό κλείσιμο συνεδρίας | Εγγραφείτε και αποχωρήστε από τον αγώνα | Υποψία |
| Ταχεία επανασύνδεση | Churn/probing πλαίσιο | Επαναλαμβάνεται γρήγορα | Αποκλεισμός |
| Μη καθαρή αποσύνδεση | Η περίοδος λειτουργίας δεν έκλεισε καθαρά | Επαναλαμβάνει ή επικαλύπτει σφάλματα | Αποκλεισμός |
| Επικάλυψη σφαλμάτων | Λογαριασμός ενεργός κοντά σε συντριβή | Ο ίδιος λογαριασμός επαναλαμβάνεται | Αποκλεισμός |
| Επιστροφή μετά το σφάλμα | Ο λογαριασμός επιστρέφει μετά την επανεκκίνηση | Επαναλαμβάνεται ανά εποχές | Αποκλεισμός κατά ένα συμβάν |
| Προειδοποίηση ριπής | Παράθυρο προειδοποίησης διακομιστή | Αλληλεπικαλύπτει αντιστοιχισμένες περιόδους σύνδεσης | Αποκλεισμός κατά μία ριπή |
| Άγγιγμα αποθήκευσης ηθοποιού | Πλαίσιο αποθήκευσης στον κόσμο | Συσχετίζεται με περιόδους σύνδεσης | Απόδειξη use/theft |
| Δέλτα αντικειμένου | World/class αλλαγή | Συσχετίζεται με περιόδους σύνδεσης | Αποκλεισμός μόνο από την καταμέτρηση |
| Υπόθεση Raid | Σύμπλεγμα πολλών λογαριασμών | Επανάληψη κεντρικού λογαριασμού | Μαζική απαγόρευση όλων των λογαριασμών |

<a id="login-identity"></a>
## Ταυτότητα σύνδεσης

Καλύτερη πηγή:

```text
Login request
Name=
ConnectID=
UniqueId=
```

Χρησιμοποιήστε το για χαρτογράφηση:

```text
display/log name -> account_id -> ban_id
```

<a id="rapid-reconnect"></a>
## Ταχεία επανασύνδεση

Μοτίβο:

```text
join -> leave -> join -> leave -> join
```

Χρήση για έλεγχο όταν επαναλαμβάνεται.

Ασφάλεια:

```text
churn_alone_never_bans = true
```

<a id="crash-overlap-and-post-crash-return"></a>
## Επικάλυψη σφαλμάτων και επιστροφή μετά το σφάλμα

Μοτίβο:

```text
account active before crash
server restarts
same account returns quickly
```

Χρησιμοποιήστε για αναθεώρηση όταν επαναλαμβάνεται ανά εποχές.

Ασφάλεια:

```text
single_crash_never_bans = true
```

<a id="warning-bursts"></a>
## Εκρήξεις προειδοποίησης

Παραδείγματα:

```text
ActorChannelFailure
DeployableSaveWarning
UpdateActorToWorldSave
ServerMove warnings
```

Χρησιμοποιήστε ως περιβάλλον έως ότου συνδεθείτε με αντιστοιχισμένες περιόδους σύνδεσης και όρια.

<a id="actor-save-touch"></a>
## Άγγιγμα αποθήκευσης ηθοποιού

Σημασία:

```text
The server evidence referenced a class or actor.
```

Δεν σημαίνει:

```text
A player opened it.
A player stole from it.
A player duplicated through it.
A player damaged it.
```

<a id="raid-cases"></a>
## Θέσεις Raid

Μια υπόθεση επιδρομής ομαδοποιεί λογαριασμούς κατά χρονισμό και κοινόχρηστα παράθυρα.

Κανόνας:

```text
Do not auto-ban every account in a raid case.
Each account needs account-specific evidence.
```
