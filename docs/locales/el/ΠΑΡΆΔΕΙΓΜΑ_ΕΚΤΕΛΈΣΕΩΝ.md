<a id="worked-operation-examples"></a>
# Παραδείγματα λειτουργιών

> **Κανονική αγγλική πηγή:** [EXAMPLE_RUNS.md](../../EXAMPLE_RUNS.md). Αυτή η τοπική τεκμηρίωση διατηρεί ακριβείς εντολές, διαδρομές, κλειδιά, τιμές κατάστασης, κατακερματισμούς και ονόματα αρχείων. Εάν η τεχνική διατύπωση διαφέρει, χρησιμοποιήστε την αγγλική πηγή.


Αυτά τα παραδείγματα χρησιμοποιούν επινοημένες τιμές για να εξηγήσουν τις αναμενόμενες μεταβάσεις κατάστασης. δεν αποτελούν ζωντανή συμβατότητα ή αποδεικτικά στοιχεία παίκτη.

<a id="successful-current-cycle"></a>
## Επιτυχής τρέχων κύκλος

Είσοδοι: αναγνώσιμο ενεργό αρχείο καταγραφής, version/boot/epoch, `poll_id=41`, ολοκληρωμένη τρέχουσα δημοσκόπηση, εγγράψιμο accounting/history/report ρίζες, χωρίς πολιτική αργής σάρωσης αποκλεισμού.

Αναμενόμενο:

```text
server_status = full
player_activity = full or limited_expected_empty
case_review = full or limited_expected_empty
daily_rollup = full or limited_expected_empty
critical_guard = full or limited_expected_empty
```

Κάθε ενεργοποιημένη διαδρομή έχει JSON/TXT και η ίδια γραμμή στο `route_proof.json`. Η κατάσταση της διαδρομής εξαρτάται από τα δικά της θέματα και όχι από ένα γενικό μήνυμα επιτυχίας.

<a id="expected-empty-player-and-case-routes"></a>
## Αναμενόμενα-κενά προγράμματα αναπαραγωγής και θήκες

Είσοδοι: η απόδειξη του τρέχοντος κύκλου έχει ολοκληρωθεί. δεν υπάρχουν τρέχουσες ή διατηρημένες σειρές παίκτη. καμία θήκη και κανένα ρεύμα REVIEW/BAN-ELIGIBLE λογαριασμός.

Αναμενόμενο:

```text
player_activity.route_proof_status = limited_expected_empty
player_activity.expected_empty = true
player_activity.players = []

case_review.route_proof_status = limited_expected_empty
case_review.expected_empty = true
case_review.cases = []
```

Οι μεταφρασμένες αναφορές λένε ότι δεν παρατηρήθηκε κατάλληλο περιορισμένο θέμα. Λένε επίσης ότι αυτό δεν αποδεικνύει ότι κανείς δεν συνδέθηκε ποτέ ή ότι δεν λείπει κανένα πλαίσιο. Δεν υπάρχει σύμβολο κράτησης θέσης player/case.

<a id="partial-bounded-scan"></a>
## Μερική περιορισμένη σάρωση

Είσοδοι: νέο ρεύμα log/poll; `scan_checkpoint.json` ή `scan_progress.json` υπάρχει. Η σάρωση δεν έχει ολοκληρωθεί. προεπιλογή `slow_world_scan_blocks_current_reports=false`.

Αναμενόμενο:

```text
world_save_scan.status = partial
source accounting = partial
server_status may still be full for fresh current state
historical routes name the scan limitation
```

Ορισμός `slow_world_scan_blocks_current_reports=true` μόνο όταν ο χειριστής θέλει αυτή η προαιρετική αργή πηγή να αποκλείει τις τρέχουσες αναφορές. Η ανάκτηση επιτρέπει στον εργαζόμενο σάρωσης να συνεχίσει και όχι να διαγράψει το σημείο ελέγχου.

<a id="missing-current-cycle-proof"></a>
## Λείπει η απόδειξη του τρέχοντος κύκλου

Είσοδοι: το ενεργό αρχείο καταγραφής δεν είναι διαθέσιμο, `poll_id=0` ή boot/epoch/last-poll λείπει η γενεαλογία.

Αναμενόμενο:

```text
current_cycle_proof_complete = false
all route proof statuses = missing
each configured route envelope status = suppressed_current_cycle
delivery_eligible = false
delivery_attempted = false
```

Ο κλειστός φάκελος είναι ένα αρχείο ελέγχου και όχι μια παράδοση σε ουρά. Τα παλιά τελικά αρχεία καταγραφής παραμένουν μόνο ιστορικά. Επιδιορθώστε το πρώτο που λείπει lineage/source και δημιουργήστε έναν νεότερο κύκλο.

<a id="malformed-optional-adminini-source"></a>
## Προαιρετικό με κακή μορφή Admin.ini πηγή

Είσοδοι: `Admin.ini` υπάρχει αλλά αποτυγχάνει η καθαρή δομική επικύρωση.

Αναμενόμενο:

```text
admin_ini.status = malformed
source reference preserved
write/enforcement path closed
```

Διατηρήστε το αρχείο και επαναφέρετε μια ελεγμένη καθαρή μορφή. Διατηρήστε το επεξηγηματικό κείμενο σε στοιχεία χρόνου εκτέλεσης. κάθε `Admin.ini` η απαγόρευση καταχώρισης παραμένει μόνο `BannedPlayer=<ID>`.

<a id="required-active-log-probe-error"></a>
## Απαιτούμενο σφάλμα ανίχνευσης ενεργού καταγραφής

Είσοδοι: ο περιορισμένος απαιτούμενος ανιχνευτής ενεργού καταγραφής αποτυγχάνει με ένα απολυμανθέν σφάλμα ανάγνωσης.

Αναμενόμενο:

```text
source_accounting.sources[active_log].status = error
source_accounting.sources[active_log].detail = "bounded active-log probe failed: <sanitized reason>"
coverage_status = unavailable
all route proof statuses = missing
```

`error` παραμένει στη γραμμή πηγής με τις περιορισμένες λεπτομέρειες. Η αναφορά ανώτατου επιπέδου χρησιμοποιεί `unavailable` και η απόδειξη διαδρομής παραμένει `missing` έως ότου ένας νεότερος τρέχων κύκλος αποδείξει την απαιτούμενη πηγή.

<a id="incompatible-or-stale-baseline"></a>
## Μη συμβατή ή μπαγιάτικη γραμμή βάσης

Είσοδοι: άλλαξε package/source ταυτότητα ή stale/incompatible δήλωση βάσης.

Αναμενόμενο: η κατάσταση επικύρωσης ή χρόνου εκτέλεσης καταγράφει την ασυμβατότητα. Η κατάσταση σάρωσης δεν διεκδικεί ολοκληρωμένη επαναχρησιμοποίηση. Διατηρήστε προηγούμενα στοιχεία, ξεκινήστε μια ρητή ανακατασκευή γραμμής βάσης και περιμένετε για νέα απόδειξη τερματικού. Μια αναγκαστική ανακατασκευή χωρίς καταγεγραμμένο λόγο δεν είναι η προεπιλεγμένη ανάκτηση.

<a id="paired-report-write-failure"></a>
## Αποτυχία εγγραφής ζευγαρωμένης αναφοράς

Είσοδοι: JSON πετυχαίνει αλλά TXT η εγγραφή αποτυγχάνει ή το αντίστροφο.

Αναμενόμενο:

```text
route_proof_status = missing
completed = false
coverage_status = unavailable
output_write_detail = "paired JSON/TXT write failed: <sanitized reason>"
next_action = repair both route output writes
```

Ο συγγραφέας best-effort ξαναγράφει και τα δύο αδέρφια για να συγκλίνουν στην αποτυχία. Ένα επιτυχημένο αδερφάκι δεν μπορεί να παραμείνει ως ισχυρισμός επιτυχίας. Η περιορισμένη λεπτομέρεια εγγραφής δεν δημιουργεί μια πέμπτη τιμή κάλυψης ανώτατου επιπέδου.

<a id="route-proof-write-failure"></a>
## Αποτυχία εγγραφής με προστασία διαδρομής

Είσοδοι: γράφτηκαν ζεύγη διαδρομής αλλά `route_proof.json` δεν μπορεί να αντικατασταθεί.

Αναμενόμενο: όλες οι αναφορές ξαναγράφονται `missing`, όλα τα αποτελέσματα ειδοποιήσεων είναι `route_proof_write_failed` και δεν γίνεται αποδεκτός φάκελος. Μια διαμορφωμένη διαδρομή μπορεί να έχει `suppressed_current_cycle` φάκελος ελέγχου με ψευδείς σημαίες παράδοσης. Επιδιορθώστε τη ρίζα εξόδου και δημιουργήστε ξανά τον ίδιο τρέχοντα κύκλο.

<a id="review-only-enforcement-example"></a>
## Παράδειγμα επιβολής μόνο για έλεγχο

Διαμόρφωση:

```lua
review_only_mode = true
auto_ban = false
write_admin_ini = false
```

Αναμενόμενο: μπορεί να γραφτούν βαθμολογίες, περιπτώσεις και προτάσεις. `Admin.ini` παραμένει αμετάβλητο. Αυτή είναι η δημόσια προεπιλογή.

<a id="approved-write-success-example"></a>
## Παράδειγμα εγκεκριμένης επιτυχίας εγγραφής

Μόνο μια ξεχωριστά εγκεκριμένη δοκιμή μπορεί να ρυθμίσει και τους τρεις διακόπτες εγγραφής. Πρέπει επίσης να αποδεικνύει καθαρή αριθμητική ταυτότητα, trust/moderator εξαίρεση, καταλληλότητα ορίου, έγκυρη Admin.ini path/parse, επιτυχία δημιουργίας αντιγράφων ασφαλείας, επιτυχία εγγραφής, ισότητα επανάληψης και αποδεικτικά στοιχεία για συγκεκριμένο λογαριασμό.

Αναμενόμενο:

```text
runtime/backups/Admin_<timestamp>_<source-fingerprint>_<clean-ID>.ini
Admin.ini contains one clean BannedPlayer=<ID>
runtime/enforced_bans.jsonl and evidence mirror record success
```

Το επιτυχημένο παράδειγμα δεν επιτρέπει την αυτόματη επιβολή για άλλους λογαριασμούς.

<a id="writereadback-failure-with-rollback"></a>
## Write/readback αποτυχία με επαναφορά

Είσοδοι: πέρασε κάθε πύλη προεγγραφής. Η εγγραφή αντικατάστασης ή η επαναφορά αποτυγχάνει. `rollback_on_readback_failure=true` και το επαληθευμένο αντίγραφο ασφαλείας είναι διαθέσιμο.

Αναμενόμενο: στοιχεία αποτυχίας καταγράφουν το στάδιο και `rollback_success`; το πρωτότυπο Admin.ini byte αποκαθίστανται και ο λογαριασμός δεν αναφέρεται ως επιτυχής επιβολή. Εάν επίσης αποτύχει η επαναφορά, σταματήστε την εγγραφή, διατηρήστε και τα δύο files/evidence και ανακτήστε μη αυτόματα από το αντίγραφο ασφαλείας.

<a id="local-outbox-example"></a>
## Παράδειγμα τοπικών εξερχόμενων

Είσοδοι: η ειδοποίηση ενεργοποιήθηκε στο `local_file_outbox`, ενεργοποιημένη διαδρομή, ολοκληρωμένη απόδειξη διαδρομής και `full` ή επιτρέπεται ρητά το αναμενόμενο-κενό.

Αναμενόμενος φάκελος:

```text
schema = randomdayguard.notification/v1
completed_output = true
status = ready_for_local_consumer
delivery_eligible = true
delivery_backend = none
delivery_attempted = false
```

Για missing/ineligible, η ίδια διαδρομή μπορεί να περιέχει `status=suppressed_current_cycle`, `completed_output=false` και `delivery_eligible=false`. Οποιοδήποτε από τα αρχεία αποδεικνύει μόνο τοπική εγγραφή. Κανένας πάροχος, απόδειξη μεταφοράς, παράδοσης ή ανάγνωσης δεν συσσωρεύεται ούτε συνάγεται.
