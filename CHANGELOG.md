# Changelog

## v0.4.12-alpha

- Added bounded server-data collection with explicit source coverage and
  uncertainty.
- Added readable server status, daily rollup, player activity, case review,
  and critical Guard reports with strict route ownership.
- Added current and historical player identity separation, session summaries,
  evidence references, and expected-empty report states.
- Added optional Admin.ini enforcement with trusted-account protection,
  thresholds, backup, concurrent-change detection, readback, and rollback.
- Added a portable public configuration, exact Saved-root override, full output
  and error references, and worked report examples.
- Added a complete English guide library and 27 localized entry pages.
- Validated the release package as a deterministic, canonical-case UE4SS
  layout with no private configuration, delivery credentials, or runtime data.
