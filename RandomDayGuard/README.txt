RandomDayGuard v0.4.12-alpha

RandomDayGuard reads available Abiotic Factor dedicated-server records and
writes readable server, daily, player, case, and Guard-health reports.

Install this RandomDayGuard folder directly under ue4ss/Mods, enable
RandomDayGuard in UE4SS mods.txt, and start the server. The public default is
review-only and does not edit Admin.ini.

For complete instructions, open INSTALL.md and docs/START_HERE.md in the
repository or release page.
